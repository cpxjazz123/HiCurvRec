# Graphlet-edge recovery vs Stage3 recall (48 standard-VQ TIGER arms)

日期：2026-11-16  
对象：48 个标准 `3×(256,32)` VQ 码本 TIGER arm；从 checkpoint 码本 + 导出 SID 重建 32 维 q，建全局 k=10 q-kNN 图。  
不包含 mixed/hyperbolic/非标准码本 arm。

## 1. 结构边集合

| 结构 | 定义 | 边数 |
|---|---|---:|
| K1,4 星形 | 严格采样的 5-node K1,4 实例，边去重 | 1,200 |
| P5 链状 | 严格采样的 5-node P5 实例，边去重 | 1,199 |
| T5 分叉树 | 严格采样的 5-node T5 实例，边去重 | 1,195 |
| C5 环 | 严格采样的 5-node C5 实例，边去重 | 1,495 |
| triangle | 原始行为图的所有三角形边，精确 | 185,711 |
| K4 | 原始行为图的所有 K4 边，精确 | 104,441 |
| inside | 社区内真实行为边，精确 | 188,588 |
| cross | 跨社区真实行为边，精确 | 126,803 |

行为图：24,587 商品，315,391 边。社区：Louvain，6 个活跃社区。

Graphlet 边集是**严格实例**，但只覆盖每类 300 个采样实例；K1,4/P5/T5/C5 不是全图枚举。Triangle/K4/inside/cross 是精确全图边集。

## 2. 恢复率与 Recall 的相关性（n=48）

- `direct`：恢复率 vs `test_recall@10` 的 Spearman / Pearson。
- `partial`：控制总体恢复率、q-kNN 边数、L3 collision，以及**社区内/跨社区恢复率**后的部分相关。
- `degree-excess`：先减去该 arm 在同样度数分位上的期望恢复率；`ΔR² excess` 是该 excess 对 Recall 的增量解释力。
- `ΔR² rate/excess`：在 `[总体恢复率, q-kNN 边数, L3 collision, inside, cross]` 基础上增加该结构指标后的 R² 增量；p 为 F 检验。

| K1,4 | +0.676 | +0.801 | +0.280 | +0.468 | -0.115 | **+0.082** | **0.0016** | **+0.0705** | **0.0037** |

## 3. 结论

### 3.1 直接相关几乎都高，但不能直接解释

所有结构的原始恢复率都与 Recall 正相关（Spearman 0.54–0.68，Pearson 0.64–0.80）。  
这主要反映：**整体 q 质量高的模型，对所有结构恢复得都更好**。所以只看 direct correlation 会误以为每种结构都重要。

### 3.2 独立预测价值

控制总体恢复率、q-kNN 边数、L3 collision、inside/cross 后：

**有明显独立增量的结构：**

1. **triangle**：ΔR² rate **0.141**（p=1.2e-5），degree-excess 后 **0.155**（p=3.3e-6）——最强。
2. **K4**：ΔR² **0.130**（p=3.2e-5），excess **0.148**（p=6.5e-6）——与 triangle 接近。
3. **K1,4 星形**：ΔR² **0.082**（p=0.0016），excess **0.071**（p=0.0037）——有中等独立信号。
4. **T5 分叉树**：ΔR² **0.065**（p=0.0055），excess **0.054**（p=0.0123）——有中等独立信号。

**没有独立增量：**

- **P5 链状**：ΔR² 0.005（p=0.45），excess 0.008（p=0.36）；直接相关 0.61 完全被总体/社区指标解释。
- **C5 环**：ΔR² 0.009（p=0.32），excess 0.005（p=0.48）。
- **inside / cross**：ΔR² 均 0.034（p=0.055），excess 0.012（p=0.26）；在控制总体恢复率后，社区内外恢复率没有显著额外信息。

### 3.3 对“哪种结构值得优先保护”的启示

- **密集结构（triangle/K4）最值得优先保护**：不仅直接相关高，而且对 Recall 有最大的独立增量。
- **星形 K1,4 和分叉 T5 有独立价值，但弱于稠密结构**。
- **纯 P5 链和 C5 环没有独立预测价值**：它们的高直接相关主要来自“整体 q 好”，而不是链/环本身。
- 因此，“链状结构最重要”的直觉没有得到当前数据支持；更准确的是：**稠密局部结构 + 星形/分叉关系** 与推荐性能的关系更强。
- 这支持后续探索能表达**分叉、层级、中心-外围**关系的几何/结构监督；但不能据此说链状结构不重要，因为 P5 采样边集小、估计噪声大。

## 4. 度数控制

Degree-excess 的原始相关：

- triangle +0.651、K4 +0.495、inside +0.653、cross -0.653；
- K1,4 -0.115、P5 +0.106、T5 +0.205、C5 +0.313。

K1,4 的 degree-excess 原始相关接近 0，但在控制总体/社区后仍有 ΔR²=0.071；说明它的独立信号是**条件性**的，不能只靠一个简单相关判断。  
P5/C5 的 excess 也不支持独立增量。

## 5. 限制

- K1,4 / P5 / T5 / C5 每类只有 **300 个严格采样实例**，边集 1,195–1,495；不是全图枚举，相关性有采样噪声。
- Triangle/K4/inside/cross 是精确边集。
- 只覆盖 48 个标准 VQ 码本 arm；26 个 mixed/hyperbolic/非标准 q arm 未纳入。
- 8 个结构 concurrent 比较；p 是 nominal，未做多重比较校正；T5 excess p=0.012 在 Bonferroni 0.05/8 下不显著；K1,4 excess p=0.0037 仍低于 0.05/8=0.00625。
- partial Pearson 对 triangle/K4 等出现负号，原因是总体/inside/cross 多重共线性；不要把 partial 符号解释为“负面影响”，以 ΔR²/F 检验为主。
- 跨臂观察性，不是因果；没有 Stage3 重训。
