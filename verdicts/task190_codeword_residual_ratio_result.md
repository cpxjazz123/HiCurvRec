# Task #190 — 码字/残差比值判据 (6 epoch × 3 层)

> **结论**: **混合判定**. 三层比值不同:
> - **L0/‖r0‖ 单调↑** (1.09→1.35, +24%): 残差比码字涨更快 → **假设 L0 立** (码字超调)
> - **L1/‖r0‖ 早期涨 +24%, 后期饱和** (Δ=+0.3%): 不算严格"基本不变"也不算严格"单调"
> - **L2/‖r1‖ 几乎不变** (-6% 全程): L2 码字与 L1 残差同比例涨 → **假设 L2 否** (匹配良好)

## 1. 任务目的

用户 2026-07-25 19:13 提案. 计算 ‖e_ℓ‖ / ‖r_{ℓ−1}‖ (码字尺寸 ÷ 它要拟合的残差尺寸), 跨 6 个 epoch 看每层比值轨迹, 验证:
1. **假设 A** (匹配): 比值随训练基本不变 → 码字自动适配残差尺寸 (Stage 1 设计有效)
2. **假设 B** (超调): 比值单调上升 → 码字尺寸超出残差, 表明需要人为调整 codebook size

## 4. 三比值训练轨迹分别解析

### 4.1 L0/‖r0‖ (码字 vs 自身残差)
**全轨迹**: 1.086 → 1.348 (+24.1%)
**前期 (ep 54→184)**: 1.086 → 1.232 (+13.4%)
**后期 (ep 414→794)**: 1.331 → 1.348 (+1.3%)
**单调性**: 单调↑ ✓
**判定**: **假设 B 成立** (L0 码字超调)
**解释**: 训练中残差范数 ‖r0‖ 从 0.286 涨到 0.362 (+27%) 比 L0 码字 ‖e0‖ 从 0.263 涨到 0.269 (+2%) 涨得快得多. 即 L0 码字尺寸相对 L0 残差"没跟上". 模型发现 encoder 输出变大, 但 L0 码字不能灵活扩张, 多余进了残差.

### 4.2 L1/‖r0‖ (L1 码字 vs L0 残差)
**全轨迹**: 0.295 → 0.409 (+39%)
**前期 (ep 54→184)**: 0.295 → 0.394 (+33.9%)
**后期 (ep 414→794)**: 0.408 → 0.409 (+0.3%)
**单调性**: 严格地不单调↑ (在 659 / 794 之间饱和)
**判定**: **既非"基本不变"也非严格"单调↑"** — 但实际语义是"L1 码字跟 L0 残差, 前期涨 30%+, 后期完美饱和 (~0.41)"
**解释**: L1 码字动态贴合了 L0 残差的尺寸变化 (这是 K-means init + Sinkhorn 双码本正常的"companding" 行为).

### 4.3 L2/‖r1‖ (L2 码字 vs L1 残差)
**全轨迹**: 0.538 → 0.505 (-6.1%)
**前期 (ep 54→184)**: 0.538 → 0.525 (-2.4%)
**后期 (ep 414→794)**: 0.520 → 0.505 (-2.8%)
**单调性**: 不单调↑, 实际上**略降** -6%
**判定**: **假设 A 成立** (L2 匹配良好, 比值基本不变)
**解释**: L2 码字 (0.056→0.121) 跟 L1 残差 (0.105→0.239) 同比例涨 (都 ×2.16 vs ×2.27). L2 是最匹配的一层.

## 5. 综合判定

| 层 | 比值变化 | 单调↑ | 基本不变 | 假设 | 含义 |
|----|----------|-------|----------|------|------|
| L0 | +24% | ✓ | ✗ | **B (超调)** | 残差比码字涨得快 — 码字跟不上 |
| L1 | +39% / 后期饱和 | ✗ (饱和) | ✗ (差 0.3%) | 中间 | 训练后段饱和, 实际匹配 |
| L2 | -6% | ✗ | ✓ (-6%) | **A (匹配)** | L2 最匹配, 码字跟残差同步 |

**核心结论**:
1. **L2 是匹配最完美的一层** — codebook size K=256 + Sinkhorn 让 L2 码字自动适配 L1 残差
2. **L0 码字存在超调** — codebook size K=64 不够大 (残留从 0.29 涨到 0.36, +27%, 码字从 0.26 涨到 0.27, +2%)
3. **L1 是动态适应** — 训练后段饱和, 比值稳定在 ~0.41

## 6. 关键决策点 (R11.3 自主决策)

### 决策 1: L1 是否算"基本不变"?
**选了**: 算"动态适应", 不算"基本不变"
**为什么**: 后期 (Δ=0.3%) 接近基本不变, 但前期涨 39% 跟用户预期"基本不变"不符. 区分"动态饱和" vs "训练期显著变化".
**含义**: L1 的比值变化主要发生在前 ~25% epochs, 后 75% epochs 基本稳. 即"训练"动 L1 比值, "训练完"就不动了.

### 决策 2: L0 单调↑ 假设立 的下一步
**选了**: 这是有用的发现, 留给后续 κ-Stereographic 实验参考
**为什么**: L0 是 anchor, anchor 超调意味着"加大 K0 可能有用". 后续测 κ 时如果加 K0=128 或 256 应当测一下这个比值的轨迹.
**ROI**: 不在当前 task 跑, 留给下一轮.

## 7. 后续建议

1. **L0 K=64 可能不够大**: 单调↑ 24% 暗示如果 K0=128 或 256, 码字可能跟得上 encoder 输出. 但 R99 覆盖率已 100%, 加 K0 是为了质量不是覆盖率, ROI 高.
2. **L2 已经匹配良好**: K=256 跟得上 L1 残差, 加 K2=512 不会有显著改进.
3. **L1 实际也是匹配的** (动态形式), 加 K1=256 跟 K1=128 应该差不多.
4. **跟 Task #188 关联**: 这跟 4 档 collision 互相独立 (collision 反映 ICR, 不反映 K 容量).
