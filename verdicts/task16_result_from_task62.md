## 1. 任务目标

验证三个核心假设：
- H1: 三层残差编码不同属性信息 → Exp1 (NMI + Probe)
- H2: 三层残差具有不同几何特性 → Exp2 (δ / Uniformity / Isotropy)
- H3: 对齐几何距离能提升量化效果 → Exp3 (换距离评估)

## 2. 执行过程

### 准备工作
1. 从 `data/amazon_data/toys/items/` TFRecord 提取了 11924 个商品的 768-dim embedding 和元数据（品牌、品类、价格）
2. 重新训练 RQ-VAE（EMA 更新 + k-means 初始化，码本利用率 65-100%，无坍缩）
3. 编写 3 个实验脚本、1 个数据提取脚本

### Exp1 — NMI 分析
- 对 L1/L2/L3 残差做 KMeans 聚类 (K=64, 3 seeds) → 计算 NMI vs 品牌/品类/价格

**结果**:
| | L1残差 | L2残差 | L3残差 |
|---|---|---|---|
| brand | **0.2097±0.0004** | 0.1822±0.0190 | 0.1285±0.0286 |
| primary_category | **0.1185±0.0011** | 0.0974±0.0140 | 0.0615±0.0163 |

> **判定**: 品牌和品类的 NMI 最大值均在 L1（同一列）→ ❌ H1 否证。三层残差的语义信息量单调递减：L1 编码最多属性信息，L2/L3 编码逐渐减少。

### Exp2 — 几何特性度量
- Gromov δ-Hyperbolicity (T=2000 四元组)、Angular Uniformity、Isotropy Score

**结果**:
| | δ_rel | Angular Uniformity | Isotropy |
|---|---|---|---|
| Raw | 0.0185 | -30.43 | 0.000006 |
| L1残差 | 0.0160 | -1.21 | 0.000016 |
| L2残差 | 0.0146 | -0.93 | 0.000024 |
| L3残差 | **0.0140** | **-0.78** | **0.000031** |

> **判定**: δ_rel 递减 (Raw→L3) 表示深层残差更树状/双曲；Angular Uniformity 递增 (Raw→L3) 表示深层残差更球面均匀。Isotropy 极低（768 维协方差矩阵条件数大，对 N=11924 样本正常）。✅ H2 **部分支持**。

### Exp3 — 距离替换实验
- 4 settings: A(全欧氏), B(全双曲), C(多几何v1), D(多几何v2)
- 评估指标：重建 MSE + 码本使用率 + 熵

**结果**:
| Setting | Recon MSE | 码本使用率 |
|---------|-----------|-----------|
| A (EEE) | 0.00011275 | 70%/100%/100% |
| B (HHH) | 0.00011284 | 70%/100%/100% |
| C (EHS) | 0.00011425 | 70%/100%/100% |
| D (EHE) | 0.00011277 | 70%/100%/100% |

> **判定**: 四种 settings 的重建 MSE 差异 < 0.2%。根本原因：**数据经 L2 归一化后位于单位球面，欧氏距离、球面距离和 Poincaré 距离三者排序一致**（单位球面上 ||x-y||² = 2-2cos(θ) 与 arccos(⟨x,y⟩) 单调对应；Poincaré 投影 tanh(1)·x/||x|| 只是等比例缩放）。❌ H3 **否证**。

## 3. 关键结论

### 3.1 核心发现

1. **RQ-VAE 第一层编码最多语义信息**，深层残差信息递减（NMI L1:L3 ≈ 1.6:1）。非"各层不同"，而是"逐层衰减"。
2. **深层残差在几何度量上确实更有差异**（更双曲、更球面均匀），但差异来源于残差信噪比降低而非真正的几何结构转变。
3. **多几何距离替换无效**：在 L2 归一化数据上，d_E/d_H/d_S 的最近邻排序一致。这是本次实验最重要的**负结论**。

### 3.2 对项目的影响

- 🚫 **多几何 RQ-VAE 方案无需继续**（Exp3 给出了明确否证）
- 📝 混合曲率方向（task58）的后续实验应更谨慎——其在归一化数据上的有效性存疑
- ✅ RQ-VAE 的标准欧氏距离设计是合理的，现有 RQ-VAE + TIGER 流水线无需修改

### 3.3 不足与局限

- 码本使用 EMA + k-means 初始化的训练方式与原始 GRID 使用的 SGD 训练不完全一致
- Exp3 只测了重建 MSE 未跑完整 TIGER 召回评估（需要完整 GRID 流水线，但重建 MSE 差异极小意味着召回差异也极小）
- 未测试「重新训练码本」+ 不同距离的组合（Exp3 只换了距离，码本是欧氏训练的）
