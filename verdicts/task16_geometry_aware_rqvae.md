## 4. 分析与解读

### 4.1 为什么 Exp2 失败

| 因素 | 影响 |
|------|------|
| Task #63 结论：C_E ≈ C_S | 选择球面码书 = 选择欧氏码书，无差异 |
| Poincaré 码书质量差 | 6.4× 更高 loss，选到即损失 |
| 三码书余弦相似度 | 均值 0.885，C_E 与 C_S 最接近，C_H 与二者差异大 |

**根因**：三个优化约束训出的码书不是"不同但等价"的——它们一个是"好的"（欧氏/球面），一个是"坏的"（Poincaré）。几何指导无法区分好坏，选到坏的反而更糟。

### 4.2 与 Task #63 联动

```
Task #63: 三个优化约束的码书结构几乎相同 (Δ ≈ 0)
          但 Poincaré 的 loss 高 6.4×
Task #64: 即使几何可预测，选码书也无法改善 MSE
```
