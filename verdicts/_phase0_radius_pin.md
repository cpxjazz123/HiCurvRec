## 三个核心结论

### 1. **钉半径激活 κ 几何信号** ✓
- L1 agreement 从钉前 1.0 跌到 0.34-0.85 (κ=±3 到 ±10 区间)
- L2 agreement 从钉前 1.0 跌到 0.43-0.87 (κ=±10 区间)
- **半径是激活 κ 几何的开关** — 跟之前 Phase 0 范数放大观察一致

### 2. **2D 钉半径下利用率永远 ≤ 22%** ❌
- L1 usage 全部 6-9%, L2 13-22%, L0 反而 98% (码字只 64 个, 容易选满)
- **根因**: 2D 投影 + 钉半径 = latent 全在同一圆上; 码字也钉同圆, 角度分布稀疏 → 大部分码字不被选中
- 这是 2D 投影的特殊性, 不是 κ 几何本身的失败

### 3. **用户判据 "agreement 60-90% AND usage ≥ 80%" 永远不成立** ❌
- 11 个测试配置 (3 半径 × 3-4 κ 几何激活点), 全部 usage ≤ 22%
- 几何激活 ↔ 利用率崩 = 同一个现象的两种表现
- 几何激活意味着分配规则跟欧式不一致, 但**码字分布是为欧式 argmin 优化的**, κ 几何下码字分布不再均匀

## 跟 Task #218 的关系

- Task #218 (per-codeword κ) 是攻前提 (b)+(d), **不是**球面/双曲几何
- 这个 5-min 测试只验证"钉半径"是否能激活 κ 几何 (✓), 不影响 Task #218 的 R@10 验证
- Task #218 优势在 per-codeword κ (码字分布为欧式 argmin 优化, 但评分函数非线性), 不是几何激活

## 综合判据更新

球面/双曲 κ 几何 vs 欧式 argmin, 在任何配置 (E1 normcap / 范数放大 / 2D 钉半径 / 32D 钉大半径) 下都满足:
