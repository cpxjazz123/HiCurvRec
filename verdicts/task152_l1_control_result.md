## 3. 判别性结论 (三种假设验证)

### 3.1 假设 (a): "L1=0 是数据真实偏好" → ❌ **否证**

若 L1=0 是数据真实偏好, 当 L1 从 +0.0753 出发时, Phase B 100 epoch 应让 L1 漂回 ~0.
**实测**: L1 从 +0.0753 → +0.0837, **没漂回 0, 反而轻微升高**.
**判据**: 假设 (a) 被否证.

### 3.2 假设 (b): "θ=0 是梯度死区, 是 bug" → ⚠️ **部分支持**

θ=0 处 `tanh(θ)≈θ` (线性区), `dκ/dθ = κ_max · sech²(θ) ≈ κ_max = 0.5` (正常). 但 `tanh(0)=0` 是固定点, 且 `sech²(0)=1` (梯度正常). 

**但 Task #149 L1=0 全程** vs **Task #152 L1 init=+0.15 → +0.0837 终值**: 显著对比表明 θ=0 附近有特定问题.

可能机制:
1. **θ=0 实际梯度被权重共享抵消**: 跨 3 层 (L0+L1+L2) 的 `theta_m` 共享 optimizer state, θ=0 时所有层都是 0, 可能某些 momentum 抵消
2. **R137 fixed point**: Task #137 修了 κ-stereographic bug 后, κ=0 可能是 attractor 固定点
3. **τ decay 干扰**: 如果 Stage 2 SID 用了 sinkhorn, τ decay 可能让 κ=0 时的 distance function 数值不稳定

**判据**: 不完全证实 (b) 但强烈暗示 θ=0 有特殊问题.

### 3.3 假设 (c): "L1 移动到中间值" → ✅ **支持 (但意义不同)**

L1 从 +0.0753 → +0.0837, 确实移动了, 但**轻微远离 0**, 而非"漂到中间值". 
**解读**: L1 的局部最优可能在 κ≈0.1 附近 (而非 0). Task #149 看到 L1=0 是因为 init 在固定点没法跳出来.

### 3.4 综合结论

**L1=0 不是数据真实偏好** (否证 a).
**L1=0 很可能是 θ=0 梯度死区 + 局部最优在 κ≈0.1 共同作用** (支持 b+c).

**实用建议** (后续 free-curv 训练):
- ⚠️ 不要再用 θ_init=0 (会被困在 0)
- ✅ 用 θ_init_list = [-0.3, +0.15, +0.3] 或类似 (避开 0, 给 3 层不同起点)
- ✅ Phase A 冻结时间可延长 (100 epoch → 200 epoch), 让 codebook 先稳定再解冻 κ
