## 2. 数学验证 (用户原话正确)

**符号反了** (跟距离 argmin 相反):
- 距离 argmin: `1/(1−c‖e_k‖²)` → **惩罚**大半径 → 饿死
- Gromov argmax: `+ρ_k` → **奖励**大半径

实测 (验证):

```
Gromov_k = ½ · (d(0,z) + d(0,e_k) - d(z,e_k))
        = ½ · (ρ_z + ρ_e - d(z,e_k))
        ∝ ρ_e - d(z,e_k)
```

实测: **argmax(ρ_e - d) ≡ argmax(Gromov) 100% 一致** (三层均验证). 数学等价, 用户原话正确.

## 4. 关键洞察: 码字半径 spread 决定 Gromov 强度

| 层 | ‖e‖_E spread | 一致率 | 解释 |
|---|---|---|---|
| L0 | 0.107-0.352 (range 0.245) | 79.65% OPEN | spread 大 → ρ_e 区分力强, Gromov 有信号但不淹没欧式 |
| L1 | 0.040-0.168 (range 0.128) | 50.21% TOO_STRONG | spread 中, ρ_e 跟 d(z,e) 同量级, 平衡差 |
| L2 | 0.031-0.127 (range 0.096) | 40.48% TOO_STRONG | spread 小, ρ_e 主导, Gromov 几乎完全替代欧式 |

**结论**: Gromov 跟码字半径 spread 强耦合. spread 越大, Gromov 信号越自然 (✅); spread 越小, Gromov 越激进 (TOO_STRONG).
