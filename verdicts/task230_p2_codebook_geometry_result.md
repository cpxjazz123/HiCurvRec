## 3. ⚠️ 临界 c 两因子分解 — 用户 2026-07-28 公式

**用户两因子公式**: $c = \frac{4}{\rho^2} \times [\text{arcsinh}(\cot(\theta/2))]^2$ = 边长因子 × 夹角因子

实测 (baseline ep59, 用 ρ_p50 + θ_min/p1):

| 层 | 边长因子 (4/ρ²) | 夹角因子 θ_min | 夹角因子 θ_p1 | c(θ_min) | c(θ_p1) | safe_c | **缺(min)** | **缺(p1)** |
|----|----|----|----|----|----|----|----|----|
| **L0** | **13.96** | 5.95 | 4.07 | **83.04** | **56.84** | 3.93 | **21.13×** | **14.46×** |
| L1 | 32.32 | 13.31 | 8.62 | 430.09 | 278.62 | 27.36 | **15.72×** | **10.19×** |
| L2 | 69.93 | 13.25 | 8.10 | 926.12 | 566.05 | 53.31 | **17.37×** | **10.62×** |

### 3.1 排序验证 — 用户纠正确认

**AI 之前误判**: "per-layer c 必须 L0 > L1 > L2" (只看夹角因子)
**正确结论**: 排序**仍是 L0 < L1 < L2** (边长因子压倒夹角因子)
- 边长因子 L0/L2 = 13.96/69.93 = 5.01× (L0 小)
- 夹角因子 L0/L2 = 5.95/13.25 = 2.23× (L0 大)
- 乘积 L0/L2 = c_L0/c_L2 = 83.04/926.12 = 0.090× = 1/11.1 → L0 c 是 L2 的 1/11.1

**两个因子方向相反, 边长因子压倒夹角因子** (优势 5× vs 2×).

### 3.2 p1 vs min 口径差异 (用户纠正)

锥不重叠要求**所有**码字对都满足, 起约束作用的是**最小夹角**, 不是 p1:

| 层 | c(θ_p1) | c(θ_min) | 差 |
|----|----|----|----|
| L0 | 56.84 | 83.04 | +46% |
| L1 | 278.62 | 430.09 | +54% |
| L2 | 566.05 | 926.12 | +64% |

**min 比 p1 显著高 46-64%**. 用户原估计 (基于 p1) 系统性低估了临界 c.

### 3.3 需求 vs 安全上限缺口

**safe_c = 0.5 / max‖e‖²** (cond5 = 0.5 警戒线, 此时梯度剩余 62.9%)
**c_min / c_p1 = 几何需求** (码字对不重叠所需最小 c)
**缺口 = 临界 c / safe_c**:

| 层 | 缺口 (min) | 缺口 (p1) |
|----|----|----|
| L0 | **21.13×** | **14.46×** |
| L1 | **15.72×** | **10.19×** |
| L2 | **17.37×** | **10.62×** |

> AI 上一轮报"13.9×/7.6×/7.6×"是基于 p1 + max_c2_p50 (vs max), 这里用 max + min 重算 = 14-21×, 缺口更大.

## 4. ❗ 核心判定 — 几何需求 vs 安全上限完全不重叠

即使开到临界 c, 每层 c·‖e‖²_p50 已经远超 0.5 警戒线:

| 层 | c(θ_min) | c·‖e‖²_p50 @ c(θ_min) | 梯度剩余 (tanh) |
|----|----|----|----|
| L0 | 83.04 | **5.94** | **49.3%** (健康线 62.9%) |
| L1 | 430.09 | 3.33 | 71.1% |
| L2 | 926.12 | 3.31 | 71.3% |

**L0 在临界 c 下梯度只剩 49.3%** — 低于 cond5 警戒线 62.9%, 已经在崩溃区. L1/L2 71% 略好但仍 < 100% 峰值.

**这跟之前 c=10 ep1 ckpt 观测一致** (L2 max c·‖e‖²=24, 梯度 0.03%) — c 越大饱和越快.

### 结论 1: 让几何真正起作用这条路大概率不可行
- 几何需求 c_min = 83/430/926
- 安全上限 safe_c = 3.9/27.4/53.3
- 缺口 14-21×, 跨越**一个数量级**
- 即使强行开到临界 c, L0 梯度 < 50%, 已经在崩溃区

### 结论 2: 排序仍是 L0 < L1 < L2
- 用户原口径 [3.93, 27.36, 53.31] (按 max‖e‖² 反比 = max_c2 安全上限) 在排序上**是对的**, 但不是几何需求
- 用户原口径 [23.7, 182.7, 407.5] (按两因子估计, p1 夹角) 高估了安全余量 (实际 c=20~50 epoch 后跑飞)
- 用户新口径 [54.7, 207.4, 404.3] (实测 p1) → 缺口 14-21×

## 5. 对 paper 价值 — 实测夹角 vs 随机估计 (新 finding)

**之前从未测过**: 码字两两夹角的实测分布
**实测发现**:
- L0: 训练后 θ_min=19.97° 远紧于随机 59.35° (2.97×)
- L1/L2: 跟随机一致 (θ_p50 ≈ 90°, 跟 d-dim sphere packing 一致)

**含义**:
1. **RQ-VAE 第一层粗聚类训练强制码字对齐到一个低维子空间** — D_eff=5.88 跟 θ_min=20° 完全一致, 不是偶然
2. **深层码字自由分布** — L1/L2 的 32-d 不被训练显著压缩, 跟随机一致
3. **论文 Eq11/12 ρ 递增假设** (L0 ρ < L1 ρ < L2 ρ) **实测是反向** (L0 ρ=0.535 > L1 ρ=0.176 > L2 ρ=0.120) — 训练 dynamics 跟理论假设结构性矛盾

**paper 怎么写**:
- §x.x "码字夹角实测分布" — 第一次报告 L0 训练后码字对的真实最小夹角 (vs 随机放置)
- §x.x "RQ-VAE 第一层低维子空间压缩" — D_eff + θ_min + ρ 三独立测量一致
- §x.x "HG-Rec Eq11/12 假设 vs 实测" — 递增 vs 递减, 训练强制反向
