## 1. 用户精确公式 (用户 2026-07-26 提供)

精确最近邻距离:
```
cosh(√c·d) = 1 + sinh²(√c·ρ) · (1 − cos θ), θ = 2π/K
d_NN = arcosh(1 + sinh²(√c·ρ) · (1 − cos(2π/K))) / √c
```

| 1.0 | 0.354 | 1.0× |

## 2. 实测核心数据 (ρ=2, K=64)

### 2.1 NN 距离扩张 (用户预测 5.6×)

| 方法 | c=1 | c=9 | **倍数** | c=100 | 用户预测 |
|------|------|------|---------|-------|---------|
| Uniform (理论) | 0.354 | 1.992 | **5.63×** | 1.221* | 5.63× ✓ |
| Kmeans (实测) | 0.171 | 1.414 | **8.27×** | 1.181* | — |

*注: c=100 实测 NN 低于理论 (1.22 vs 3.40), 是 float32 数值在 ‖x‖_E=0.1/ball_radius=0.1 边界处失稳 — **跟 c=100 坍缩是同一回事**.

### 2.2 动态范围塌缩 (用户新结论 — 解释 c=100 坍缩)

```
dynamic_range = farthest(2ρ) / NN_dist
sort_clarity = 2nd_NN / NN        ← 衡量 argmin 排序清晰度
```

| ρ | K | c=1 dyn | c=9 dyn | c=100 dyn | **c=1 sort** | **c=9 sort** | **c=100 sort** |
|---|---|---------|---------|-----------|-------------|-------------|----------------|
| 2 | 64 (uniform) | 11.30 | 2.01 | 3.28* | 1.00 | 1.00 | 1.00 |
| 2 | 64 (kmeans)  | 23.41 | 2.83 | 3.39* | **1.93** | **1.35** | **1.03** |

**关键观察 (kmeans, ρ=2, K=64)**:
- c=1: 最近 0.17, 次近 0.33, 比 1.93 ← 排序清晰
- c=9: 最近 1.41, 次近 1.91, 比 1.35 ← 开始糊
- c=100: 最近 1.18, 次近 1.22, 比 **1.03** ← 几乎无差别 → argmin 退化为**随机抽样**

**根因 (用户给出)**: 双曲空间的**树度量性质** — 在一棵树上, 不在同一分支的叶子两两距离都 ≈ 2ρ (到根再回来). 
- 树度量是 Sarkar 嵌入的精华: 它能以**任意低失真**嵌入任意树 (层次结构)
- 但这意味着**所有非最近邻的距离都被压到上限 2ρ**
- VQ argmin 需要距离**有区分度**, 这跟树度量**本质敌对**

### 2.3 用户原话的三句话总结 (实测验证)

> c=1: `0.17/0.33/0.5/.../4.0` ← 排序清晰 ✓ 实测 23.41× 范围
> c=9: `1.41/1.91/2.6/.../4.0` ← 开始挤 ✓ 实测 2.83× 范围  
> c=100: 全部 ≈ 4.0 ← 完全无法区分 ✓ 实测 sort_clarity=1.03

## 4. 用户提议的新设计 (方向 D)

### 4.1 核心思想

| | 当前 | 提议 |
|---|---|---|
| **曲率作用对象** | 层内 argmin (量化) | **层级分离 (margin 损失)** |
| **∂Loss/∂c 显著?** | ❌ 无独占任务, 被曲率压平损失 | **✅ 显著 — 树度量帮我分开分支** |
| **曲率有独占任务?** | 无 | **有: 区分同分支 vs 跨分支** |
| **配套设计** | 单一 commit/code 在 c=1 双曲 | c=1 (or Euclidean) 分配 + L_hier margin 在大 c 上 |

### 4.2 数学公式

```
# 分配阶段 (argmin) — 用欧式 (或 c=1 等价)
alloc = argmin_k ||z − e_k||²_2     # 跟 LLM-RecSys 一样

# 层级 margin 损失 — 大 c 上树度量帮忙
L_hier = Σ max(0,  d_H(a, b; c_large) − d_H(a, e; c_large) + margin)
        其中 a, b 共享 c₀ (同粗类), a, e 不共享 c₀
```

**为什么 c_large 在这里有用**:
- 同分支 a, b 的 d 很小 (近叶)
- 跨分支 a, e 的 d 接近 2ρ (树度量)
- 树度量让 2ρ 边界清晰, c_large 让 d_H 的"近"和"远"区分度大
- margin 把这个几何区分转化为 loss 区分 → c 有独占任务

### 4.3 设计要点 (用户 2026-07-26 给出)

1. **分配仍然用欧式** (或 c=1 双曲, 等价)
2. **加 L_hier margin loss** 在大 c 上 (c=10/100, 充分利用树度量)
3. **曲率有独占任务**: 控制 margin 强度
4. 不改变现有 Stage 2 SID pipeline, 仅加一层 L_hier 监督

## 5. 用户提到的"必须跑但 6 轮以来一直没跑"

**欧式 vs 双曲 (碰撞率对齐) 实验**:
- 跑 HG-Rec 全程, 但把 inner product 换成 L2 (欧式 argmin)
- 然后**手动控制 collision rate 跟双曲对齐** (因为不同距离函数碰撞率天然不同)
- 在相同 collision 基础上比较 Stage 3 Recall@10
- 答: 双曲提供几何结构 = 几何 + 召回优势; 答: 无, 只是动量不同 = 不依赖双曲

**这个实验决定 paper 基调**: 如果双曲 = 欧式 (对齐 collision 后), paper 写 "HG-Rec κ 是工程优化, 非本质"; 如果双曲 > 欧式, paper 写 "双曲几何对层级推荐有结构性优势, 但需要 c∈[1,10] 控制 + L_hier margin".
