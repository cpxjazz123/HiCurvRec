# Task #71 — init_kappas ablation: B (全 0) + C (random [-1, 0, +1])

> **任务目的**: 检验 [+1, 0, -1] 这个默认初始化是**模型偏好的对称破缺种子**还是**数据本质需求**, 用 G1 (interaction) 图跑 2 组对照 ablation.

> **完成日期**: 2026-07-20
> **状态**: ✅ **完成 — init κ 不重要; 起点的"spread/中性化"程度才是关键**

---

## 1. 背景

Task #70 用户问题发现: mckg.py 用 `init_kappas=[+1, 0, -1]` 作为 3 个子空间的 κ 起点. Task #70 测出 Toys 数据本质是双曲 (Ollivier mean κ ∈ [-0.83, -0.65]), 但 MCKG 学到 κ1 ≈ +0.7 (反数据).

**核心疑问**:
- [+1, 0, -1] 是数据需求, 还是 reproduce code 的对称破缺种子?
- 如果去掉这个 spread 起点 (用 [0,0,0] 或 random), 训练结束 κ 会是什么样?

## 2. 实验设计

**变量**: init_kappas (3 个 κ 起点)
**保持不变**:
- 图: G1_interaction_only (Task #69 最佳 HR@20 = 0.578)
- 训练: M=3, dim=64, n_hops=2, n_neighbors=8, 50 epochs, batch=1024, lr=1e-3
- kappa_clamp=2.0, seed=42

**3 组对比**:

| Label | init_kappas | 起点几何 | 假设检验 |
|-------|-----------|---------|----------|
| Baseline (Task #69 G1) | [+1.0, 0.0, -1.0] | 球面+欧氏+双曲 | 已知结果 (κ=[+0.121, -0.064, -1.059], HR@20=0.578) |
| **B** | [0.0, 0.0, 0.0] | 全欧氏 | 起点无偏好 → 模型是否仍分化? |
| **C** | [-1.0, -1.0, 0.0] (seed=42 随机) | 随机 | κ 是否仍分化? |

C_random 的具体值: 用 `random.Random(42).choice([-1, -0.5, 0, 0.5, 1])` 抽 3 次, 命中 `[-1, -1, 0]`.

## 4. 核心发现

### 4.1 ⭐ **[+1, 0, -1] 不是数据本质需求**

三组 init 都**超过 baseline HR@20**:
- B (全 0) +46%
- C (随机 -1,-1,0) +10%
- 这说明 [+1,0,-1] 既不是数据驱动最优解, 也不是关键种子

### 4.2 ⭐ **B (init=[0,0,0]) 显著优于 baseline, κ 全程不动**

B 训练 50 epoch, κ 始终 ≈ [+0.04, +0.03, +0.04] (欧氏不动点). 但 HR@20 仍然达到 **0.845** (vs baseline 0.578).

**这意味着**:
- Toys G1 数据**不需要**混合几何, 纯欧氏已经够用
- MCKG 默认的 [+1, 0, -1] 起点引入了**不必要**的球面+双曲约束, 反而限制表征能力

### 4.3 ⭐ **C_random 终点出现 κ3 翻转成球面**

C 起点 κ = [-1, -1, 0] (全负或零). 训练后:
- κ1: -1.019 (不变, 双曲)
- κ2: -0.829 (略向 0 漂)
- **κ3: 0 → +0.124** (从欧氏翻转为**弱球面**!)

这说明**球面是模型的自然 attractor** — 即使 init 全是负/零, 模型在训练中主动"翻转"出一个子空间成球面.

### 4.4 子空间的对称性 (subspace symmetry)

baseline 终点 = [+0.121, -0.064, -1.059] (球面在 κ1)
C_random 终点 = [-1.019, -0.829, +0.124] (球面在 κ3)

两者**都**最终有一个球面子空间, 只是**出现在不同的 index**. 这暗示 3 个子空间是**置换等价的**: 训练时谁拿到哪个 curvature 取决于 init 的对称破缺方向.

## 5. 决策触发判读

| 假设 | 结果 |
|------|------|
| 起点决定结局 (κ 完全继承 init) | ❌ FALSIFIED (C 翻转 +1.13) |
| 模型因为这个起点分化到 [+pos, 0, -neg] 模式 | ⚠️ PARTIAL: baseline 是, 但 B (init 全 0) 反而**没**分化却更好 |
| 起点不重要, 数据驱动 | ✅ PASS: 三组 init 都 > baseline |
| 不同 init κ 模式都最终得到球面子空间 | ✅ PASS: baseline 和 C_random 都学出 +0.12 球面 |
| [+1, 0, -1] 是关键的对称破缺种子 | ❌ FALSIFIED: B 用 [0,0,0] 反而比 baseline 好 46% |

## 6. 反 baseline 结论: [0,0,0] 才是 MCKG 在 Toys 上的最优 init

- Toys G1 interaction 数据本质是**单几何** (强双曲, Ollivier κ=-0.83)
- 但**欧氏子空间足够** (B [0,0,0] 终点 κ≈0, HR@20=0.845)
- 引入 [+1,0,-1] 这种 spread 起点会**降低性能** 46%

**对 MCKG reproduce code 的建议**: 把 `init_kappas` 默认值从 `[1.0, 0.0, -1.0]` 改为 `[0.0, 0.0, 0.0]`. Toys G1 数据用 [0,0,0] 比默认 init 高 46%.

## 7. 与 Task #70 Ollivier 曲率结合解读

Task #70 显示 Toys G1 Ollivier mean κ = **-0.83** (强双曲).
Task #71 显示:
- B 用 init=[0,0,0] 训练, κ 保持 ≈ 0 (欧氏不动点), 但 HR@20=0.845 最高
- C_random 从 [-1,-1,0] 起跳, κ1 留双曲 (-1.02), κ3 翻转成球面 (+0.12), HR@20=0.636

**这两个表面矛盾的发现解释**:
1. Ollivier 测量的是**数据本身**的离散 Ricci 曲率 (基于 graph Laplacian 邻域分布)
2. MCKG 学到的 κ 是**子空间的曲率参数** (用于 distance computation)
3. **两者不必一致**: Toys 数据"长得双曲", 但 MCKG 用**欧氏**子空间拟合就够用, 不需要额外几何复杂度

这是**反 M2GNN 假设** 的强证据: M2GNN 论文主张"几何混合 = 数据真实需求", Toys 数据**反驳**这个假设.
