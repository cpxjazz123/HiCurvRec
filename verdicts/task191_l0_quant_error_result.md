## 5. 机制解释

### 5.1 训练在做什么

SGD 优化 RQ-VAE 损失 = `recon_loss + β · quant_loss`. 训练后期:
1. **Encoder 输出扩张**: Encoder MLP 学到越来越"宽"的隐空间分布 (latent ‖z‖ 涨)
2. **K=64 码本容量上限**: 64 个码字覆盖不了 encoder 输出的扩张范围
3. **L0 量化误差 ↑**: ‖z − e_L0‖ 从 0.082 涨到 0.253 (+207%)
4. **残差携带漏过去信息**: residual = z − e_L0 把这些"漏过去"信息送给 L1
5. **碰撞率 ↑**: L1/L2 残差范数涨, 与码字范数比值越来越大 (Task #190 已证), 碰撞率同步↑

### 5.2 为什么 collision 涨得比 L0_err 慢

- L0_err 涨 207%, collision 只涨 46%
- 解释: L0 残差范数涨, 但 L0_err 是 per-item 平均, 每个 item 涨一些. 而 collision 是"两个 item 撞到同一 SID", 需要残差涨得多才能触发. 所以 collision 涨得慢, 但是跟着趋势.

### 5.3 反向佐证: Task #190 比例结论

- L0/‖r0‖ 单调↑ +24% (码字超调)
- L2/‖r1‖ 基本不变 -6% (匹配良好)
- 现在 L0_err 也单调↑ → 说明 L0 是 bottleneck

## 6. 关键决策点 (R11.3 自主决策)

### 决策 1: 判定机制坐实 vs 假设二
**选了**: **机制坐实**

- corr 0.861 远大于经验阈值 0.7 (高同步)

**含义**: Task #188 的核心机制 — "L0 容量受限 → 全层退化" — 已有定量证据.

### 决策 2: step-by-step Δ 同步性为什么负 (-0.087)?
**选了**: 不影响主结论
**为什么**:
- 绝对值 corr 是 0.861 (同步趋势对)
- step Δ 是相邻步变化, 易被 epoch-level noise 影响 (训练后期 collision 在 0.119-0.130 之间抖动, 而 L0_err 还在缓慢 ↑)
- 这反映的是"碰撞率晚期的 plateau 不稳定", 不是反向因果.
- 真正有用的判定用 epoch 级绝对值关联.

### 决策 3: 这意味着什么后续行动?
**选了**:
- Task #188 的 4 个 collision tier (8.62% / 10.09% / 11.17% / 12.76%) 应该会按 collision 涨 → test R@10 跌 (用户已经预期 Table 7 行为)
