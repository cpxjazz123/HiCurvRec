## 3. 关键独立硬发现 — L0 高曲率利好均匀

**L0 c=118/282: util 上升到 34.4%/31.3%** (vs c=1 时 25%, +9.4pp/+6.3pp).

**这不是 v2 的出球假象**, 数据完全有效:
- c·max‖x‖² = 0.897 / 0.985 < 1 ✅
- c·mean‖x‖² = 0.581 / 0.821 (跟用户预测 0.60 / 0.85 几乎一样)
- 16/64 → 22/64 → 20/64 码字被使用

**解释**: L0 残差大 (用户实测 r_mean=0.095), 高 c 时 expmap0 把码字推到球内深位置, 但 L0 latent 也跟着推到深位置 → 几何软化, 码字反而覆盖更广. 跟 HG-Rec paper "更均匀利用"主张**一致** (但仅限 L0).

**L2 反向**: 残差链累积后 r 很小 (L2 切空间 r < L0 10×), 高 c 时 c·max‖x‖² ≈ 0.59 已经触及"硬边界前"区域 → 几何激进, 饿死外圈码字 → util 单调降.

**结论**: HG-Rec paper "双曲 → 更均匀" 论断**只对小 layer (L0) 成立**, 大 layer (L2) 反而退化. 这是 paper 没提到的 layer-dependent effect.
