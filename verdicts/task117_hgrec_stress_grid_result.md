## 1. 任务目的

用 **Task #82 B 加密网格** [0.0, -0.05, -0.10, -0.15, -0.20, -0.25, -0.30, -0.50, -1.00, -1.50, -2.00] 对 HG-Rec 两个版本做 **逐层 stress 失真度网格搜索**, 验证"per-layer curvature 是否让 residual 几何可被双曲空间拟合":

- **原版 (Task #84)**: c=[1.0, 1.0, 1.0]
- **改造版 (Task #88)**: c=[0.5, 0.5, 0.5]

**Stress 定义**: Kruskal stress-1 = Σ(d_hyper - d_eucl_target)² / Σ d_eucl_target²

**算法**:
1. 取 300 个 residual 点 (stratified subsample)
2. 计算 pairwise Euclidean distance 作为 target
3. 对每个候选 κ, 在 Poincaré ball (κ<0) 或 Euclidean (κ=0) 做 Riemannian gradient descent MDS
4. 报告 stress(κ) → best κ* = argmin_κ stress(κ)

复用 Task #80 的 `compute_true_distortion` 函数 (已通过 Task #81/82 验证).

## 3. 解读

### 3.1 核心结论: HG-Rec residual 几何 = 欧氏

**所有 8 个 (层 × 版本) 组合都 best κ=0**, 这与 Task #82 B (phonism 4 层 × 11 κ) 结论**完全一致**: phonism 和 HG-Rec 的 RQ-VAE residual 空间都被 **欧氏 MDS 拟合得最好**, 双曲空间没有优势.

### 3.2 改造版 vs 原版的 stress 对比

| Layer | Task #84 c=[1,1,1] stress(0) | Task #88 c=[0.5,0.5,0.5] stress(0) | Δ |
|-------|------------------------------|------------------------------------|---|
| L0 | 4.80 | 5.64 | **+17.4%** ⚠️ |
| L1 | 7.20 | 6.56 | **-8.9%** ✓ |
| L2 | 16.61 | 15.72 | **-5.4%** ✓ |
| L3 | 33.34 | 32.52 | **-2.5%** ✓ |

- **L1/L2/L3**: 改造版 stress 略低 (欧氏拟合更紧), 提示 c=0.5 让下层 residual 更"集中"
- **L0 raw encoder**: 改造版 stress 反而**高 17%**, 与 Task #116 δ_95/d 升高方向一致

### 3.3 与 Task #116 δ_95/d 的交叉验证

| Layer | c111 δ_95/d | c111 stress(0) | c555 δ_95/d | c555 stress(0) | Δ δ | Δ stress |
|-------|-------------|----------------|-------------|----------------|-----|----------|
| L0 | 0.0985 | 4.80 | 0.1034 | 5.64 | +5.0% | +17.4% |
| L1 | 0.0792 | 7.20 | 0.0812 | 6.56 | +2.5% | -8.9% |
| L2 | 0.0748 | 16.61 | 0.0762 | 15.72 | +1.9% | -5.4% |
| L3 | 0.0703 | 33.34 | 0.0703 | 32.52 | ±0.0% | -2.5% |

两个独立诊断一致地显示:
- **L0 raw encoder**: 改造版几何**更不规则** (δ↑, stress↑)
- **L1/L2/L3 residual**: 改造版几何**略更紧凑** (δ微↑, stress微↓), 方向相反但效应弱

**解释**: c=[0.5,0.5,0.5] 的 Poincaré ball 半径 r=1/sqrt(0.5) ≈ 1.414, 让 encoder 输出的 raw z (norm~0.6) 在 ball 中相对距离变长 → L0 δ/d 升高. 但 residual (norm 0.07-0.13) 投影到 ball 后接近原点附近 → distances 收缩, 接近欧氏 (stress 略降).

### 3.4 与 Phonism (Task #82) 对比

| 数据集 | 最佳 κ* (4 层) | margin vs κ=0 |
|--------|---------------|----------------|
| Phonism (Task #82 B) | 全 0.0 | 4-5× |
| HG-Rec c=[1,1,1] (Task #84) | 全 0.0 | 5-50× |
| HG-Rec c=[0.5,0.5,0.5] (Task #88) | 全 0.0 | 4-40× |

**Phonism 和 HG-Rec 都一致**: RQ-VAE / HRQ-VAE 学到的 residual 空间在 metric 拟合上**欧氏始终优于双曲**. HG-Rec 的 margin 略高于 phonism (Euclidean 优势更明显), 说明 HG-Rec 的 hyperbolic-aware training 没有"拉弯"几何.

### 3.5 弱信号灵敏度结论

参考 Task #82 A 弱信号对照: 即使 κ=-0.05 的弱双曲信号也能被检测到 (phonism 实测无弱信号). HG-Rec 在 κ=-0.05 时 stress 比 κ=0 高 4-7× (绝对差距 28 vs 5, 35 vs 7, 79 vs 17, 158 vs 33), **远超 weak signal detection floor**, 结论可信.

## 7. 综合结论 (Task #116 + #117)

两个独立诊断一致证实:

**HG-Rec HRQ-VAE residual 空间是欧氏主导的**, per-layer curvature c=[0.5,0.5,0.5] 不能让几何变成双曲. 这与 phonism (Task #82 B) 的结论**结构一致**.

差异方向相反但效应弱:
- δ_95/d (Task #116): 改造版 L0/L1/L2 略**不树状** (+1-5%)
- stress(0) (Task #117): 改造版 L0 略**难拟合** (+17%), L1/L2/L3 略**易拟合** (-2 to -9%)

**对 Idea1 (per-layer curvature 提高下游 R@10) 的预测**:
- 如果几何诊断完全不能区分两版本 → 改造版下游 R@10 应接近原版 (差异 <5%)
- 实际 Task #88 Stage 3 的 val Recall@10 (R@10) 范围 [0.12-0.125] 已与 Task #84 复现 0.1020 拉开 +20% 差距
- **这意味着即使几何差异小, 改造版的训练动态/优化景观可能更利于下游** — 即"几何"不是 bottleneck, "训练"才是
