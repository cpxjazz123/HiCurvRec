### NaN 根因 (Post-mortem)

HResModule residual = log_map_0(exp_map_0(h, c), c) - h. 数学上 exp_map_0 + log_map_0 链应是严格 identity, 但数值实现有数值稳定性问题:

1. **c_avg=3.917 (单曲率)**: √c ≈ 1.98, R = 1/√c ≈ 0.505. T5 d_model=128 hidden state norm ‖h‖ ≈ 1-3 (fp32 训练初期)
2. **exp_map_0 边界**: 当 √c · ‖h‖ → ∞, tanh → 1, factor → 1/(√c·‖h‖), h_hyp ≈ h_normalized (norm ≈ 1, 但 R=0.505). h_hyp norm > R.
3. **proj_to_ball clamp**: 强制 norm ≤ R=0.505. h_hyp_norm 接近 R=0.505 时, √c · h_hyp_norm 接近 1.0
4. **log_map_0 边界**: artanh(x) 在 x → 1 时 → +∞. 当 √c · h_hyp_norm 接近 1.0 (h_hyp_norm 接近 R), artanh → Inf → h_tan = Inf → residual = Inf - h ≈ Inf
5. **β · Inf = NaN**: β_eff=0.2512, β · Inf = Inf, 后续 lm_head logits 全部 NaN → CE loss NaN → backward NaN → all params NaN

### 修复方向 (备 v34_v2 用, 当前 line 终止)

R36 严守曲率机制, 但数值不稳定需要 hard cap:
1. **safety clamp**: log_map_0 输入 hard clamp 到 √c·norm ≤ 0.99 (留 1% 边界)
2. **β_init 实际有效值**: 当前 sigmoid(0.01)≈0.5 · beta_max=0.5 → β_eff=0.2512, 与 "near-identity 起步" 不符. 应让 β_eff init ≈ 0.001: logit_init = log(0.001/0.5)/(1-0.001/0.5) ≈ -6.2 (用 Sigmoid(beta_raw) * beta_max)
3. **单曲率 vs per-layer**: c_avg=3.917 偏大, 用 c_max (Stage2 L1=6.0021) 太大, 用 c_min (L0=1.3547) 更稳定. 或 per-layer HRes (4 个 c, 但 hook 4 个 block 各用对应 c)
4. **降 dim 投影**: HRes 只在 d_model=128 子空间 (e.g., dim=32) 应用, 不动全 d_model, 减少数值风险
