## 3. κ 学习轨迹 — 用户核心问题 2

**答: 用户假设方向相反. 数据上 κ 要么 ↓ 跌到 0 (坍缩), 要么 ↓↓ 跌到负值 (球面). 不是 ↑ 涨到 boundary.**

### task164 κ 轨迹 (kappa_history + 最终 θ_m)

| 时间点 | L0 θ_m | L0 κ = 2·tanh(θ_m) | 解读 |
|--------|--------|---------------------|------|
| epoch=1 (init) | -0.142 | -0.279 | **初始化就已经偏负** |
| epoch=16 (final) | **-1.249** | **-1.696** | θ_m 进一步下跌, 跑到球面 regime |

**轨迹是 θ_m ↓, κ ↓**, 跟用户假设的 "κ ↑" 相反.

### task169/170/171/172 κ 轨迹

| 任务 | κ_max | epochs 记录 | θ_m 各 epoch | 解读 |
|------|-------|------------|--------------|------|
| task169 | 2.0 | [1, 20] | epoch 1: 0.0 → epoch 20: **0.0** | **从未离开 0** |
| task170 | 2.0 | [1] | epoch 1: 0.0 (崩溃 13 epoch 止) | 未启动就坍缩 |
| task171 | 2.0 | [1] | epoch 1: 0.0 (崩溃 11 epoch 止) | 未启动就坍缩 |
| task172 | 4.0 | [1, 20] | epoch 1: 0.0 → epoch 20: **0.0** | κ_max 调到 4 也救不回来 |

**这些任务的 θ_m 初始化就是 0 (tanh(0)=0 → κ=0), 然后**整个训练过程 θ_m 没动** (lr_theta 太小?梯度近零?), κ 永远停在 0.** 这部分跟之前 verdict §5 的 "kappa 几乎不影响 loss, 往哪个方向漂都随机" 假设**吻合** — 当范数‖x‖_E 很小, ∂L/∂θ_m 接近 0, κ 永远学不动. 用户在最早问题里说的 "几乎不影响 loss 的参数" 实锤了.

### 为什么 user 反推的 c≈1.38 没有出现在我们数据里?

用户给的 c≈1.38 是从 λ 反推的, 可能来自 task180_graph_aware 200 epoch 训练 (那次报告 L0 mean ‖x‖_E=0.899). 那个 run 用的是 Phase 0 修过的代码 + κ=1 fixed. 在那 200 epoch 跑里, κ=1 是硬约束 — **没有 κ 学习轨迹可言**, 因为 κ=1 是写死的. 所以 user 反推 c≈1.38 的来源是**几何上 c 等价于 1** (即 κ=1 的硬约束).

但**如果 Phase 0 修复后 ‖x‖_E 真的涨到了 0.899 (200 epoch)**, 而 κ 始终是 1, 那 conformal factor λ_κ = 2/(1 - 1·0.899²) = 2/(1 - 0.808) = 2/0.192 = **10.4**, 跟我们之前诊断的 "λ_κ ≈ 20000" 还差很远. 真正的"饱和区"还需要更多训练 epoch 或者更大 ‖x‖.

## 4. 综合重写: 之前 verdict 的"超线性增长"表述

之前 verdict 写的:
> "范数增长是超线性的 (epoch 50-194 captures 79% of growth). 这意味着未来 κ 实验 MUST train ≥200 epoch."

**重新校准**:
- task181 (50 epoch, 4 ckpts): 范数增长是**线性的**, 不是超线性 (epoch 29→49, +20 epoch, ‖x‖_E 涨 ×1.4)
- 但 task181 训到 50 epoch 时 L0 ‖x‖_E mean 才 0.26, 而 task180 200 epoch 跑到 0.899 — 这中间确实有范数的显著上升
- **关键: 这个增长是 κ=1 fixed 下的真实范数增长, 不是 boundary 收缩** (因为 c‖x‖² 在所有 ckpt 都是 0% near 1)
- 所以 "200 epoch 才能让 κ 生效" 这条结论**仍成立**, 但理由是 "需要时间让范数从 ~0.26 长到能让 λ_κ 显著偏离 2 的水平", **不是** "κ 在涨导致 boundary 内缩"

## 5. 用户假设的 falsification

用户原本说:
> "如果诊断结果是范数确实很小,那'模型学到 κ≈0'这个结论就要整个重新解读"
> "这个诊断如果是阳性,那它比后面任何架构改动都重要,因为它说明问题在 embedding 的尺度上,不在几何选择上"

**Falsification 总结**:
1. ✅ 范数确实很小 (task181 50 epoch 训练后 L0 mean ‖x‖_E ≈ 0.26, 离 1/√κ = 1 还有 74% 余量) — **确认用户原始假设**
2. ✅ learnable κ 任务里 κ 永远停在 0 (lr_theta 太小或 ∂L/∂θ_m ≈ 0) — **确认 "曲率从来没参与过计算"**
3. ❌ "κ 在训练后期上涨" — **数据反驳**. 实际是 κ 跌到 0 (坍缩) 或跌到负值 (球面). 方向相反.
4. ⚠️ 但**根本结论仍然成立**: "问题在 embedding 的尺度, 不在几何选择" — 因为范数没长到能让 κ 真正起作用的水平, κ 的数值漂移没有物理意义.
