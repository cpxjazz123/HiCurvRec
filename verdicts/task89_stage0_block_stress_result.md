## 4. 解读

### 4.1 跨任务一致性

| 任务 | 测什么 | 结论 |
|------|--------|------|
| Task #117 (整体 stress) | 32 维 latent 整块 | 4/4 层 best κ*=0 |
| **Task #89 Stage 0 (分块 stress)** | **32 维 latent 切 1/2/3 块** | **24/24 块 best κ*=0** |
| Task #116 (δ_95/d) | 4-point condition | δ_95/d ~7-10%, 不是树状 |
| Task #70 (Ollivier 真实曲率) | Toys 数据本体 | κ_real ≈ 0.7 接近欧氏 |

**三重独立测量 (整体/分块/δ/真实曲率) 一致**: Musical_Instruments 数据集在 latent 任何子空间分解下都是**欧氏优于双曲**.

### 4.2 即使分块也不能挖出双曲结构

把 32 维切成 11+11+10 这种**更小的子空间**反而让 stress 值降低 (L0 整体 5.49 → 各 11 维块 ~1.4-1.9), 但**没有任何子块"突然变成双曲"** — best κ 仍是 0.

这说明:
- **不存在"局部双曲, 整体欧氏"的结构** — 如果存在, 某个 11 维块会显示出非零最优 κ
- HG-Rec 学的 latent 是**真正的各向同性欧氏分布**
- 用户假设 R2 (子空间结构不同) 在 Stage 0 已经被否证
