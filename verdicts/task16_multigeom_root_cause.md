## 2. 关键修复

**BUG 发现**：原版 Task #70 报告 `top1_match = 24.61%`（与 Task #67 的 100% 矛盾）。

**根因**：`d_E` 中存在大量 ties（多个码字与 r 等距，如 `d_E[0, 0] = d_E[0, 85] = d_E[0, 193] = 0.3888`）。原因：码字 0 是全零向量 + 多个码字与 r 距离都是 `||r||`。

PyTorch 的 `torch.argsort` 在 ties 上**不稳定**，导致 `argsort()[:, 0]` 与 `argmin()` 结果不一致。

**修复**：
- `top1_match` 用 `argmin(dim=1)` 替代 `argsort()[:, 0]`
- `full_match`/`top3_match` 用 `torch.argsort(stable=True)`

修复后跑出真实结果（见下）。

## 3. 关键结果

### 3.1 Exp D1：函数单调性（纯数学，与 RQ-VAE 无关）

| cos | d_E | d_H | 单调性 |
|-----|-----|-----|--------|
| 0.10 | 1.342 | 5.097 | d_E↓ d_H↓ |
| 0.50 | 1.000 | 4.519 | ↓ |
| 0.90 | 0.447 | 2.991 | ↓ |
| 0.99 | 0.141 | 1.256 | ↓ |

| 度量 | 值 |
|------|---|
| d_E 单调递减 | ✅ True |
| d_H 单调递减 | ✅ True |
| 排序（按 cos 升序→d 降序） | ✅ **完全相同** |
| Pearson correlation | **0.9700** |

**结论**：d_E 和 d_H 都是 cos 的严格单调递减函数，**假设 A 成立**：tanh+norm 参数化本身是 d_E 的单调变换。

### 3.2 Exp D4：实际 RQ-VAE 残差的一致性

| 度量 | 数值 | 含义 |
|------|------|------|
| **Top-1 一致率** | **100.00%** | 最近邻 100% 一致（与 Task #67 吻合） |
| **Top-3 一致率** | **100.00%** | 比 Task #67 证据更强 |
| Full sort 一致率 | 0.07% | ties 让完整排序不一致（不可避免） |

**结论**：
- top-1=100% → **假设 C 部分成立**：码书 + 残差分布使得最近邻等价
- top-3=100% → 排序等价性扩展到 top-3 范围（这是 Task #67 未测的）
- full sort=0.07% → 因为 ties 是连续距离的固有问题，不影响最近邻决策

### 3.3 Exp D5：距离数值差异分布

| 度量 | 数值 |
|------|------|
| Δ mean | 0.901 |
| Δ std | 0.354 |
| Δ max | **1.509** |
| Δ min | 0.000235 |
| nn Δ mean (最近邻处) | 0.364 |
| nn Δ max | 0.613 |

**结论**：
- Δ_max = 1.509 表明 d_E 和 d_H **数值差异巨大**（约 1.5 个单位）
- 但 nn Δ mean = 0.364 = ||r|| 的 1.0× 量级，与 `d_H ≈ 2·d_E` 观察一致
- 这是**保序单调变换的典型表现**：放大差异但保持排序

## 4. 最终决策

**Scenario B 确认**：等价性源于排序保持（d_H 是 d_E 的保序单调变换），而非数值相等。

| 触发条件 | 实测 | 决策 |
|---------|------|------|
| D1 排序一致 | ✅ True | → 假设 A 确认 |
| D4 top-1=100% | ✅ True | → 假设 C 部分确认（残差 + 码书分布导致） |
| D5 Δ_max>0.1 | ✅ 1.509 | → 排序保持 ≠ 数值相等 |

---

## 5. 物理解释

Poincaré 投影 `r_H = tanh(||r||) · r/||r||` 是 d_E 的**保序单调变换**：

1. **数学层面**（D1）：d_E 和 d_H 都是 cos 的严格单调函数 → 任何 argmin 都等价
2. **实践层面**（D4）：在 11924 个残差 × 256 个码字上，最近邻 100% 相同
3. **数值层面**（D5）：变换放大距离值（约 2×），但保持排序

直觉：tanh 把所有向量压到 Poincaré 球**内部**（norm < 1），但投影方向 `r/||r||` 不变 → 角距离不变 → 排序不变。

### 6.2 关键定理（待形式化）

**Theorem (informal)**: Let x, y ∈ ℝᵈ with ||x||, ||y|| < 1. Define the Poincaré projection:
```
x_H = tanh(||x||) · x/||x||,    y_H = tanh(||y||) · y/||y||
```
Then d_H(x_H, y_H) is a strictly increasing function of d_E(x, y) (for fixed ||x||, ||y||).

**Corollary**: argmin_k d_H(x, c_k) = argmin_k d_E(x, c_k) for any codebook C = {c_k}.
