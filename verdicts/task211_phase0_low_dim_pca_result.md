## §1 关键解读 (R11.3 决策)

用户方案给 ρ=[2.0, 2.7, 3.4] 同时给 gate "max ‖x‖ ≤ 0.95". 这两个表面矛盾. 

**R11.3 自主决策 (per R11.2 项目规则 + 物理解读)**:
- ρ 是 **双曲空间半径** (Poincaré ball 中从原点到 x 的 hyperbolic distance, d_B(0, x))
- 对应 Euclidean norm = tanh(ρ/2) (c=1.0): ρ=2.0 → ‖x‖_E=0.762, ρ=2.7 → 0.874, ρ=3.4 → 0.935
- 所有 Euclidean norm < 0.95 ✅, 跟 Task #209 软约束 norm_target_list=[1.0,1.35,1.70] 对齐 (但 norm_target 在 Task #209 是切空间 norm, 跟这里的 Euclidean norm 数值上接近但语义不同)
- **备选解读 (报告用户)**: 如果用户原意 ρ 是 Euclidean norm target, 则 ρ 应 clip 到 0.95, 全部 d=4 不通过. 请用户确认本 verdict 解读.

## §4 推荐 d_hyp (R11.3 决策)

**主选: d_hyp = 4** (用户方案默认预期值)
- 备选理由: L0 angle 17.6° + L1 13.1° + L2 9.1° — 三层都有健康角分辨率 (无 L2 0.7° 退化风险)
- dyn_range = 6.5/8.8/12.7 (三层单调上升, 几何层次清晰)

**备选: d_hyp = 2** (若想最大 dyn)
- 优势: dyn = 35-165, 远超 2.0 gate
- 风险: L2 angle 0.7° 太小, KMeans 在 2D 球面 L2 (256 个码字) 可能不够分 → 训练时可能 mode collapse

**不推荐: d_hyp = 8**
- dyn 较小 (4.7-8.1), 不如 d=2/4 优势明显

## §6 物理意义 (为什么 d=4 是 sweet spot)

- **d=2**: 球面 2D 容量上限 = K · min_angle ≈ 256 · 0.012 = 3 rad. 几何层次过强, 但 L2 角度近 0, 容易饱和.
- **d=4**: 球面 4D 容量 = K · min_angle ≈ 64 · 0.308 = 19.7 (L0); 256 · 0.158 = 40.4 (L2). 几何层次丰富 + 角度健康.
- **d=8**: 球面 8D 容量更大, 但 dyn 较小, "几何 vs 容量" trade-off. d=4 是中间点.
