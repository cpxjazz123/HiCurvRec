## 6. 判读

1. **非惰性成立**：三层换码数几乎等于 batch 大小，说明在 `λ=3.5211e-06` 下结构项确实经得起 100 步优化并改变离散码。
2. **L1 坍缩**：前缀 37 → 6，96.9% 商品共享同一 L1 码；L2 在 50 步时降到 15、100 步回到 26。坍缩方向与 `question1.md` 关注的"前缀分组"直接相关，不能当作改善来读。
3. **邻居对同前缀率上升**（L1 0 → 0.75，L2 0 → 0.375）说明边两端被拉进同一前缀；结合 L1 只有 6 个前缀，这一上升可能主要来自坍缩而非结构区分。
4. **训练/导出分支在该 batch 无差异**，但全量 SID 的初期 `collision=0.902` 提示实际训练中两分支差异需要单独测量，不能由本 batch 推断。
5. 重构 MSE 下降 82.5% 只说明模型在拟合，不构成结构改善或召回收益的证据。
