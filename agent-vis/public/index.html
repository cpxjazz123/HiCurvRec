      新建组

      组里的 agent 会一起收到同一条消息，并且各自都要回应。选好成员再点「新建组」。

      全局设置

      所有 agent 共用：会话的工作目录与运行主机。改完立刻对下一次运行生效。

      Group

      把若干 agent 放在一组里。交接目标可以指向某一个 agent，也可以指向一个 group —— 发给 group 时，组里每个人都会收到同一条消息，并且各自都要回应。

      重置 agent 会话

      清掉对话记录与模型上下文：被重置的 agent 下一次运行从空白开始。
