## 1. 用户提议的核心论点

**不用距离, 用"共同祖先深度"**:

```
score_k = ½ [ d(0,z) + d(0,e_k) − d(z, e_k) ]
        ∝  ρ_k − d(z, e_k)          ← 选最大的
```

**含义**: 选那个"和我共享路径最长"的码字 — 也就是"我在哪个分支上".

## 2. 为什么这是逃法

**符号反了**.

| 判据 | 码字半径的作用 |
|---|---|
| 距离 argmin | `1/(1−c‖e_k‖²)` → **惩罚**大半径 → 饿死 |
| **Gromov argmax** | `+ρ_k` → **奖励**大半径 |

**失效模式从"饿死"变成"过度选用"** — 而过度选用可以用熵正则治, 饿死不行 (死了就没梯度了).

## 3. 用户验算 (z 在 ρ=2.0)

| 码字 | ρ_k | 角度 | 距离 | **Gromov 分数** |
|---|---|---|---|---|
| A | 0.5 | 0.1 (几乎同向) | 1.504 | **0.498** |
| B | 3.4 | 0.5 (偏 29°) | 2.865 | **1.268** |

**B 胜** — 尽管它偏了 29°, 而 A 几乎同向. 因为 z 和 B 共享了 1.27 的路径, 和 A 只共享 0.50.

**这就是"树上的亲缘关系", 不是"欧氏的接近"**.

**距离 argmin 会选 A, Gromov argmax 会选 B. 两者不等价 → 几何真的参与了**.

## 4. 需要配套

Gromov 判据天然偏爱深层码字. 所以必须:

1. **层内半径要有差异** (否则 ρ_k 是常数, 又退化成距离)
   - baseline 码字 ‖e_k‖_E ∈ [0.03, 0.17] (用户原话), ρ = arctanh(‖e_k‖) ∈ [0.03, 0.17] (因为 c=1.0, 反正切双曲和反正切在 ‖e_k‖ ≪ 1 时几乎相等)
2. **加熵正则**, 防止深层码字被过度选用

## 5. 第一步 (半天, 不训练)

在现有 baseline 码本上, 用 Gromov 积算 score, 测:

```
argmax(Gromov score) vs argmin(欧式)  的一致率
```

| 一致率 | 判定 |
|---|---|
| > 95% | 逃法失败, Gromov 的影响被淹没 |
| **60–90%** | ✅ **通道打开了** |
| < 50% | 几何主导过头, 要调 |

## 6. 决策点 (R11.3 自主决策, 已记录)

1. **ρ_k 计算**: 用户原话"半径本来就有差异 0.03~0.17". baseline 实际查 ckpt (Task #84) 确认 ‖e_k‖_E 范围. 用 ρ_k = arctanh(‖e_k‖_E) (c=1.0 双曲空间半径).
2. **Gromov product 公式**: 在 Poincaré 球 (c=1.0) 内:
   ```
   Gromov_k = ½ · (d(0, z) + d(0, e_k) - d(z, e_k))
   ```
   **关键**: `d(0, x) = 2·arctanh(‖x‖_E)` (Poincaré 球原点到 x 的距离), 不需要 c.
3. **baseline ckpt**: 跟 Task #218 同一个 ckpt (Task #84).
4. **per-layer**: 三层码本各测.
5. **不训练**: 纯前向 + 几何计算.
