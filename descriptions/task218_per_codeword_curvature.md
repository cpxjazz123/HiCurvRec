# Task #218 — 逃法一: 逐码字曲率 (Per-Codeword Curvature) 判据检查

**日期**: 2026-07-26
**任务类型**: 判据检查 (半天, CPU only, 不占 GPU)
**优先级**: 🔴 最高 — 用户 2026-07-26 提议, "**攻其中两个, 能真正逃出来**"

## 1. 用户提议的核心论点

命题: `argmin_k d_B(z, e_k) ≡ argmin_k ‖z−e_k‖²/(1−c‖e_k‖²)`.

**化简依赖 4 个前提**:
- (a) 判据是**点到点的距离**
- (b) **所有码字共享同一个曲率 c**  ← **可攻**
- (c) latent 是单个点
- (d) `(1−c‖z‖²)` 对所有 k 相同, 可以约掉  ← **可攻**

## 2. 逃法一: 让每个码字自带曲率 c_k

**距离公式 (Berman-Metzler 2020 κ-Stereographic)**:
```
score_k = (1/√c_k) · arccosh( 1 + 2c_k‖z−e_k‖² / [(1−c_k‖z‖²)(1−c_k‖e_k‖²)] )
```

**关键**:
- `(1−c_k‖z‖²)` 现在随 k 变化, 前提 (d) 被打破
- `1/√c_k` 也随 k 变, arccosh 单调性不再能把它化简掉
- 这不再是"每个码字乘一个标量", 而是**依赖距离的非线性重加权**

## 3. 用户验算 (z 在 0.3, 码字在 0.26)

| δ | c=1 | c=10 | **比值** |
|---|---|---|---|
| 0.05 | 0.109 | 0.502 | **4.6×** |
| 0.15 | 0.325 | 1.072 | **3.3×** |
| 0.30 | 0.644 | 1.496 | **2.3×** |

**比值随 δ 变化 (4.6 → 2.3) — 这就是"非常数重加权"的直接证据.** 如果是命题里那种单一通道, 比值必须恒定. 它不恒定, 所以逃出来了.

## 4. 语义

```
c_k 大 = 这个码字"界限分明", 距离涨得快 → 只收非常贴合的 item
c_k 小 = 这个码字"弥散"           → 收得宽松
```

而且因为 `(1−c_k‖z‖²)` 里有 ‖z‖ — **item 自己的半径会调节它能碰到哪些码字**. 这是一个 **item-自适应机制**, 现有工作里完全没有.

## 5. 重要松绑

这样定义的 score 不再是全局度量 (跨码字三角不等式可能不成立). 但**分配不需要度量, 只需要打分**. 这个松绑是关键 — 它把"必须是一个流形"的约束去掉了, 而代价只是失去全局度量, 对 argmin 无影响.

## 6. 为什么不会重现之前的失效

| 之前的死因 | 这里为什么不同 |
|---|---|
| 大半径码字被单调惩罚 → 饿死 | **惩罚不再单调**, c_k 小的码字反而更容易被选中 |
| 距离都饱和 → 分不开 | **不同 c_k 饱和点不同**, 不会同时饱和 |
| 半径钉住 → 退化成余弦 | **c_k 各异就不会退化**, 即使半径全相同, 几何仍通过 c_k 参与 |

**最后一条尤其重要**: 这个方案**不需要半径有差异**. 半径可以全钉在同一个值上 (避免饿死), 几何仍然参与 — 通过 c_k.

## 7. 第一步 (半天, 不训练)

在现有 baseline 码本上, 给每个码字随机赋 c_k ∈ [0.5, 20], 然后测:

```
argmin(per-codeword score) vs argmin(欧式)  的一致率
```

| 一致率 | 判定 |
|---|---|
| > 95% | 逃法失败, c_k 的影响也被淹没 |
| **60–90%** | ✅ **通道打开了** |
| < 50% | 几何主导过头, 要调 |

## 8. 决策点 (R11.3 自主决策, 已记录)

1. **c_k 分布**: 用户指定 `c_k ∈ [0.5, 20]` 均匀分布 (或对数均匀). 我用 `np.random.uniform(0.5, 20)` 单 seed, 跑 3 次取 mean 排除随机性.
2. **baseline ckpt**: 用 Task #84 HG-Rec baseline (R@10=0.1020) 的 vanilla RQ-VAE ckpt. 跟 Task #212 (方向二) 同一 ckpt, 便于横向对比.
3. **per-layer**: 三层码本 (L0=64, L1=128, L2=256) 都测.
4. **不训练**: 纯前向 + argmin 比较.

## 9. 跟之前方向的本质区别

**之前 7 个方向都攻 "几何激活"** (怎么让 √c·ρ 进入激活区).
**这个方向攻 "几何激活的化简前提"** — 假设激活了, 让分配判据跟欧式不等价.

更深层的攻击: 即使没有几何激活, c_k 变化本身就让分配判据非线性.
