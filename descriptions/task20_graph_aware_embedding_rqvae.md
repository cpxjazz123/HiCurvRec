## 1. 阶段 ①: 图质量事后核验 (半天)

**目的**: 确认 e 确实学到图结构信息 (不是训练完了就盲目信任).

**做法**:
- 抽查一些"同品牌"商品的 e, 计算两两余弦相似度
- 与随机两个商品的 e 相似度做对比
- 统计指标: 同品牌平均相似度 / 随机平均相似度 比值

**通过判据**:
- 比值 ≥ 1.5 → 通过, 继续
- 比值 ∈ [1.0, 1.5] → 信号弱, 检查 margin loss 训练曲线 / 图构建
- 比值 < 1.0 → 训练没收敛, 回退不往下走

**GPU**: 不需要 (embedding 已训好, 只需 numpy 计算)

## 2. 阶段 ②: 最小可行性验证 (1 天, ★ 关键决策点)

**目的**: 决定"图结构 → RQ-VAE"整个方向是否值得继续.

**做法**:
```
A 组 (baseline): 原始文本 embedding x → 标准欧氏 RQ-VAE → Recall@10 = 0.0971 (Task #65 baseline)
B 组 (新方案):  图结构 embedding e → 标准欧氏 RQ-VAE → Recall@10 = ?
```

**关键约束**: 阶段 ② **不改 RQ-VAE 本身**, 只改输入. 用现有标准欧氏 RQ-VAE 流水线 (`src/train.py experiment=rqvae_train_flat`).

**启动命令**:
```bash
# B 组: 用 e 替换 x (Stage 1 产物由 (N, 2048) text emb 改为 (N, e_dim) graph emb)
python -m src.train experiment=rqvae_train_flat data_dir=<path> \
  sem_embeds_path=products/task77/inference/<id>/pickle/e_tensor.pt \
  [其他 Stage 1 override 用 task77 产物的字段名]
```

**通过判据 (★ B > A 是方向死活的分水岭)**:
- B > A +1-2% → 通过, 继续阶段 ③
- B ≈ A (差异 < 1%) → 信号弱, 停下来检查 e 与 x 融合方式
- B < A → 方向否定, 不投入更复杂架构

**GPU**: 1 张 (Stage 2 RQ-VAE 15k steps ≈ 2-3h)

## 3. 阶段 ③: 残差链条诊断 (1-2 天, 仅当 ② 通过)

**目的**: 回应核心问题 "L1/L2/L3 分别捕获了什么结构信息", 用 probe 实验看结构信号落在哪一层.

**做法**:
用 e 跑完标准 RQ-VAE 后, 对 L1/L2/L3 每层残差做 probe:

| 层 | probe 目标 | 预期信号 | 通过判据 |
|----|-----------|----------|----------|
| **L1 残差** | 节点连接度 / 是否枢纽热门 | 强信号 (最大方差方向) | probe 准确率 ≥ 70% |
| **L2 残差** | 具体品牌/品类归属 (层级信息) | ★ 关键检验: 旧 x 跑 RQ-VAE 时 L2 测不出任何品类信号, 若 e 的 L2 能测出, 说明图结构带来增量 | probe 准确率 ≥ baseline+5% |
| **L3 残差** | 是否与特定商品强共同购买 (环状/共现) | 中等信号 | probe 准确率 ≥ 60% |

**核心比较**: e-L2 probe vs x-L2 probe (用 Task #65 baseline 旧产物的 L2 残差作对照). 只有 e-L2 显著优于 x-L2 才有依据说"图结构改变了信息分布".

**GPU**: probe 实验不需要 GPU (numpy/逻辑回归即可)

## 4. 阶段 ④: 针对该层几何优化 (视情况, 仅当 ③ 发现某层确实携带此前没有的结构信号)

**目的**: 有了 ③ 的诊断依据, 再决定给哪一层引入哪种几何量化.

**设计原则 (吸取 Task #71 教训)**:
- **距离函数 / 残差计算 (Möbius 减法 / Log 映射) / 码书学习 (是否用双曲 KMeans) 三者必须几何一致**
- ❌ 不能只在"选最近邻"用双曲距离, 残差和码书还用欧氏逻辑 (Task #71 踩坑)
- ❌ 不能凭空假设三层都要套三种几何 (Task #71 踩坑)
- ✅ 必须 ③ 证明某层携带特定结构信号后, 才给该层配对应几何

**决策表**:
| ③ 发现 | ④ 几何方案 |
|--------|-----------|
| L2 携带层级信息 | L2 用双曲距离量化 (Poincaré ball) |
| L3 携带共现/环状信息 | L3 用球面距离量化 |
| L1 携带枢纽/度信号 | L1 保持欧氏 |
| 三层都没新信号 | 不引入几何, 阶段 ② 已证明图结构足够 |

**GPU**: 1 张 (若 ④ 启动, Stage 2 RQ-VAE 15k steps × 几何变体 ≈ 3-5h)
