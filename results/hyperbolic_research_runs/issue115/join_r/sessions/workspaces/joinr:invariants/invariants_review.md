# 候选机制不变量审查（对抗性审阅）

## 审查边界

冻结条件不变：32 维、每阶段 256 个码、恰好三个整数 SID、原数据/划分/Stage-2 与 Stage-3 配方；成功必须同时严格超过 ER `16.38953942232631`、Recall@10 `0.06406796775709883`、NDCG@10 `0.03530651701940677`。本审查只判断两个候选是否能被现有证据证伪，不把 CGV/H1–H7 通过等同于科学有效。

现有产物能支持的核心证据是逐阶段 SID 分区统计（distinct、最大 cell share 等）、CGV/H1–H7 的实现/数值/梯度等门禁，以及冻结 ER 和通过 ER 门槛后的一次 Stage-3 指标。**这些产物本身不包含候选操作对每个样本的分项分数、消融后 SID、曲率趋零的 SID、逐样本 gyration/面积值。** 因此，仅凭当前产物不能完成提案中若干机制级 falsifier；若不把这些量写入正式、可审计的运行产物，相关声称不可测。

## 机制 1：有向测地三角面积分配

### 逐项审查

| 提案检查 | 现有产物可测？ | 审查意见 |
|---|---|---|
| 面积相对距离项是否可忽略、面积占 score 方差至少一半 | 否 | 分区表和性能指标不含每个候选码的 `A_c`、距离项或 score 方差。需把验证样本的两项分布/方差比写入审计报告；不能从 SID 变化反推贡献大小。 |
| `A_c=0` 后 assignment agreement | 否 | 需要真实的零面积反事实重分配。当前分区统计只有实际 SID，不能给出反事实一致率。 |
| 几何恒等式、Gauss–Bonnet 误差、等距不变性 | 有条件 | 若 H1–H7 的独立 oracle 明确覆盖这些输入、反例和误差，门禁能验证实现；仅有“CGV 通过”或训练成功不能替代。提案需在冻结前把 oracle 覆盖列为必需项。 |
| 分区是否塌缩、ER 是否过门槛 | 是 | 分区统计能发现常量/极端不平衡分配；冻结 ER 可判定 ER 门槛。两者不能证明面积是有效原因。 |
| Recall/NDCG 是否过门槛 | 是 | 仅在 ER 严格通过后按冻结流程执行 Stage-3；三个指标必须同时严格通过。 |

### 不变量是否空泛

- “共线三点面积为零”“交换 `q,z` 反号”“Gauss–Bonnet 一致”“共同等距变换不变”主要是几何实现正确性测试。对固定公式而言，它们不证明 assignment 使用了面积：把面积从决策中完全删掉的距离量化器仍可通过这些独立单元测试。
- “`c→0` 面积消失”也不具区分力：欧氏极限下面积项消失是定义性质；若真实训练中的面积贡献始终为零，仍能满足该检查。
- “256 码、三 token”是协议约束，不是机制不变量或效果证据。

### 改写为有区分力的不变量

1. **决策贡献（必要）**：在同一已训练模型、同一批冻结验证样本上，保存完整 256 路分数；实际面积项方差占总 score 方差至少 50%，且报告逐阶段 `A_c=0` 反事实 SID agreement。预注册一个严格小于 100% 的 agreement 上限（建议 ≤95%）；超限即面积对决策近乎无效。另报告被面积项改变的样本比例及其面积/距离分数，不可只报总方差。
2. **方向性区分（必要）**：构造保持 host、两边长度和距离项不变、只反转候选相对残差的成对输入；非零曲率下有向面积必须造成预期的 score 次序反转，平坦极限下反转效应消失。oracle 应断言具体 score 差异，而非只断言公式能算出非零数。
3. **数值正确性（必要但非充分）**：对非退化、近退化、共线及反射输入验证面积符号、Gauss–Bonnet 误差和等距变换误差，并报告误差上界、测试覆盖与 clamp 比例。
4. **实质分区和结果（必要但非因果证据）**：每阶段通过既有 partition-degeneracy 门槛，报告占用码数、最大 cell share、熵；冻结 ER、Recall、NDCG 三者均严格过线。熵或码使用率本身不证明面积机制有效。

### 最简单的非装饰性控制臂

同一实现、同一初始化/种子/数据/配方，唯一改动为决策 score 中令 `A_c≡0`，其余距离项、参数量、训练流程和评估完全相同（必要时保留不可参与 assignment 的面积计算以隔离计算图差异）。对照实际机制的逐阶段 SID agreement、分区统计及冻结指标。若 assignment 几乎相同，或面积臂没有通过三重门槛，则面积不是被证明有效的机制；禁止用另换种子/配方解释差异。

### 判定

**判定：按当前仓库产物为 UNMEASURABLE；补齐下述日志与控制后才可 FALSIFIABLE。** 分区统计和最终指标可证伪“分区有效/三重目标达成”，但不能测 proposal 自己列出的核心 falsifier（面积贡献及去面积后的 assignment agreement）。几何恒等式本身可由 oracle 检验，却不解决此缺口。

## 机制 2：非结合 gyro-composition 量化

### 逐项审查

| 提案检查 | 现有产物可测？ | 审查意见 |
|---|---|---|
| 实际残差/码对上的 gyration 是否近恒等 | 否 | 当前分区统计不记录 gyration 角度/位移或残差-码配对量。CGV/H oracle 可验证人为输入的代数性质，不代表真实数据上有足够非平凡作用。 |
| 删除 gyration 项后的 assignment agreement | 否 | 必须对相同样本、相同模型做第二次反事实 argmin，并记录逐阶段 agreement；现有产物没有该项。 |
| `c→0` assignment 是否复现 | 否 | 单测可检查算子极限，但实际反事实 SID 不在现有产物中。且不允许把正式实验变成曲率 sweep；它应是冻结实现的审计性控制/小型预注册 oracle。 |
| 边界/clamp 率 | 不确定/当前不足 | 提案称需报告，但给定现有分区、CGV/H oracle、冻结指标中没有可见的运行级 clamp 统计；须显式归档。 |
| 结合律、单位元、保范、球内性 | 有条件 | H1–H7 若覆盖正确的独立 oracle 可验证算子；仅通过 CGV 不足。正确实现仍可能在实际样本上 gyration 几乎为零。 |
| 分区、ER、Recall/NDCG | 是 | 可用现有产物评估分区非退化和冻结三重门槛，但不能归因于 gyration。 |

### 不变量是否空泛

- `u⊕0=0⊕u=u`、平坦极限、gyration 保范、transport 保范、球内性主要是一般算子/实现性质；恒等传输、近零向量或未触发 gyration 的样本也可使多项检查通过。
- “某组非共线输入的两种结合顺序不同”只证明存在性。训练数据上的残差与码向量可能始终落在近共线/近原点区域，因而机制实际贡献近零。
- “256/三 token”仍只是冻结协议，不是机制证据。
- 公式层面还需防止量纲/切空间混用：第二项比较的 gyration 作用对象与 `Exp_p(r)` 的类型、度量所在切空间必须由 oracle 明确规定；不能把点差当作切向量再直接用 `g_p` 计量。需固定 gyrovector 约定并以独立实现交叉核对。

### 改写为有区分力的不变量

1. **真实数据作用幅度（必要）**：在每阶段所有实际 residual/code 候选对上报告 gyration 的角度或切向位移范数分布（中位数、95 分位、最大值及近零比例），并报告其相对 residual 范数的比值。预注册非零下限；不能只展示人工构造的非共线例子。
2. **决策贡献（必要）**：保存 gyration 分项及总分，对同一模型计算 `γ=0` 的反事实 argmin 和逐阶段 SID agreement；预注册 agreement 上限（建议 ≤95%）。同时报告有多少样本的 top-1/top-2 次序因 gyration 改变。只报告“平均 gyration 非零”不够，因为小扰动可能从不影响决策。
3. **曲率特异性（必要）**：在独立 oracle 的成对输入上验证平坦极限的 `gyr→Id`、组合回到向量加法；并验证相同输入在非零曲率下产生预注册的可测差异。记录数值误差。assignment 级平坦反事实可作为机制控制，但不得以调参或曲率扫描改变正式协议。
4. **数值/几何正确性（必要但非充分）**：独立 oracle 覆盖左右单位元、结合顺序反例、保范、平行移动范数、切空间类型、严格球内性和 clamp 计数；实际训练运行报告 clamp 率，若触发非零 clamp，应报告其影响样本，不能仅以有限性过门。
5. **分区和目标（必要但非因果证据）**：通过既有逐阶段非退化门槛，并同时严格超过 ER、Recall@10、NDCG@10 门槛。指标改善不能单独证明非结合项起作用。

### 最简单的非装饰性控制臂

在完全相同的训练模型/候选码/数据上，唯一移除决策 score 的 gyration 惩罚项（设 `γ=0`），重算硬 assignment；不改重建目标、训练配方、代码数或评估数据。直接比较逐阶段 SID agreement、top-1/top-2 翻转、分区统计和冻结指标。若 assignment 不变或变化极少，gyration 只是附加标签/装饰；若改变 assignment 但三重指标未全过线，也不能宣称成功。单纯欧氏/`c→0` 单元测试不能取代这个消融臂。

### 判定

**判定：按当前仓库产物为 UNMEASURABLE；补齐真实样本 gyration、反事实 assignment、分项分数与 clamp 日志后才可 FALSIFIABLE。** H1–H7/CGV 可以审查算子和梯度实现，但它们不自动测得真实训练对上的 gyration 是否非平凡，也不提供删项控制的 assignment agreement。

## 总结性裁决

| 候选 | 当前判定 | 当前可证伪部分 | 必须补齐的最小证据 |
|---|---|---|---|
| 有向测地三角面积 | **UNMEASURABLE** | 分区退化、冻结 ER/Stage-3 三重门槛；适用的 oracle 可测公式实现 | 面积/距离分项日志、面积方差占比、零面积反事实 assignment agreement、同模型面积消融控制 |
| 非结合 gyro-composition | **UNMEASURABLE** | 分区退化、冻结三重门槛；适用的 oracle 可测算子性质 | 真实输入 gyration 分布、gyration 分项、`γ=0` 反事实 assignment agreement、实际 clamp 率及一致的平坦极限控制 |

因此两项在现阶段都不能因“列出了 falsifier”而算作已具备可证伪性。冻结 ER 和 Stage-3 是结果门槛，不是机制归因工具；CGV/H1–H7 是实现证据，不是效果证据。应先把最小审计量与控制臂写进 proposal/实验产物契约，再决定是否值得进入正式冷跑。
