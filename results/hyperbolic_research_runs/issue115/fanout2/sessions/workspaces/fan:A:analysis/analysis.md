# 冻结证据分析：共同瓶颈与失败机制

## 结论范围

以下只复述仓库中已测量结果，不改变 32 维、3×256、三个整数 SID、数据/划分及 Stage2/Stage3 配方。严格成功门槛仍是同一候选同时满足 Hard-L1 ER > 16.38953942232631、Stage3 Recall@10 > 0.06406796775709883、NDCG@10 > 0.03530651701940677。

## 1. 哪个量能让 ER 与 Stage3 排名一起动？

证据没有证明某个已报告的单一几何量或占用量，能因果地让冻结 ER 和 Stage3 排名同向变化。最接近共同量、且与两者任务定义直接相连的，是 **L1 SID 对真实观测下一物品关系的行为条件区分力**，即 Hard-L1 正负对的区分，而不是单纯让码字使用更均匀。

测量支持这一判断的边界如下：

- Stage2 的 Hard-L1 ER 是正负关系的比值；控制臂正例 share 为 **0.07908428720083246**、负例 share 为 **0.004841547630309337**。报告明确指出 ER 可因正例碰撞增加或负例碰撞减少而上升，两种变化不是同一主张。
- R8 十个机制的 ER 为 **1.000694623689–15.913043478261**，全部没有越过严格门槛，也没有任何一臂启动 Stage3；因此这些行不能提供 ER 对 Stage3 排名的直接协变估计。
- 跨 R7/R8 的总结记录了：改善 L0 占用和改善行为区分力反向变化；R7-F 的 L0 占用更好但区分力更差。占用不是共同目标量。
- issue112 的几何测量中，Möbius 链将 L3 的“单一 L3 码”细胞比例从欧氏链的 **0.9208** 变为 **0.9263**，尽管 within-cell spread/codeword spacing 从 **0.7895** 增至 **1.4251**。几何明显改变了距离比，却没有改善第三 token 的冗余结构。

所以，按现有测量能回答的最强版本是：要让 ER 与 Stage3 排名有共同方向，必须移动“SID 对真实行为关系的区分力”；现有证据**尚未测得**它与 Recall/NDCG 的定量共同响应。不能把 ER 数值本身、L0 占用或几何距离比冒充已验证的共同因果量。更重要的是，冻结阈值也落在控制自身运行波动内：冷控制 ER **16.358737490377**，历史 R4-08 为 **16.402627511591962**，相差约 **0.044**；故仅跨过 ER 门槛不足以证明机制改善。

## 2. 失败臂改变了什么，又留下了什么？

### Issue112 的几何/布局臂

- **产品测地 L0 量化器**改变的是 L0 的分配打分/几何。实际结果不是形成新的有效分区：24,587 个项目全部分配给码 148，L0 distinct codes **1**、最大格 **24,587**、ER **1.0**；存储码本本身没有塌缩（每层仍有 256 个不同码字）。因此它改变了 assignment operator，却没有保住有信息的 L0 分区；按门槛没有 Stage3。
- **Busemann/horospheric 层族**改变的是边界水平集/层间距离规则。记录结论是 level gap 没有分开宿主标签且方向相反，探测到的是近径向等距算子；没有证据显示它触及了训练后码本的容量或重训残差分布。
- **平行移动框架残差**尝试改变残差坐标框架；其良定形式被测为共同坐标变换，assignment 改变数 **0.0**，故未改变 SID 分区。
- **角色分配 token 布局**声称改变 token 角色，但 forward 中声明几何是 VESTIGIAL；有效前向没有使用该几何，因而没有改变实际分配机制。
- **度量/曲率变化**主要改变“最近码字是谁”，不改变训练码本所拟合的数据尺度/容量。 issue112 实测每层 assignment 可变化（L0 **19.35%**；level-wise probe 每层 **3.5–6.9%**），但 L3 单码细胞比例仍约 **0.921→0.926**。曲率 sweep 亦被排除：在归一化半径上曲率只是重标度，测得相同归一化条件下相关偏差 **0.5143924039356781**（c=0.25、1、4）。

### Stage2 arms（对照 issue112 的另一组实测）

- R8 的十个冷跑均在相同宿主训练路径/协议上加入各自辅助项；改变的是目标项（NCE、下一物品预测、JS、OT、蒸馏、图扩散或几何机制），宿主的 PCGrad、损失组装、AdamW 与 scheduler 未改。它们没有改变冻结数据、切分、3-token/3×256/32D 容量或 Stage3 配方。ER 全部未过门槛（最佳 **15.913043478261**），故 Stage3 均未运行。
- 实测形态分为码本/分配重组导致的塌缩（ER **2.7751、3.8413、6.7968、6.8477**，以及约 **1.0007** 的极端塌缩）、温和退化（**15.03599–15.91304**）和 OT 失配（**8.83536**）。归纳上，重组码本的目标破坏硬 ID；重加权类目标则在原区分 regime 中损失 **0.45–1.32 ER**。没有一项增加行为区分力。

共同留下的部分：实验并未移动冻结协议本身；失败主要在现有训练出的离散 L1 表示/其分区及对真实行为关系的区分上。issue112 的测量还显示每层码本几乎满用（**243/255/256**），但 L3 在 **92.08%** 的 (L1,L2) 单元中只有一个码，平均每单元仅 **1.0969** 个 L3 码。单纯改查询度量并未重训码本，所以未改变这个信息结构瓶颈。

## 3. 一个可证伪的中心失败解释及判别测量

**解释（假说，不冒充已证事实）：** 一些臂提高 ER，是通过扩大/重排 L0 分区尾部或改变正负对碰撞比例取得的；这种变化不增加 SID 对真实下一物品关系的可排序信息，甚至会损伤前缀/分支结构，因此 Stage3 排名会持平或下降。现有记录中，历史 cohort 的 ER 门槛清除臂都没有改善下游；尾部例子从 L0 最大格 **237** 增至 **374**（Case A）或 **382**（Case E）。R8 汇总也观察到占用改善与区分力恶化反向出现。但这是跨臂观察，不是已完成的受控因果识别。

**唯一判别测量：** 对同一冻结宿主状态、同一候选、同一数据和 Stage3 recipe，成对测量（a）候选相对控制的 L0 最大格/尾部分布、正负 share 与 Hard-L1 ER，（b）Stage3 Recall@10、NDCG@10，并额外报告 L1 对 held-out 真实下一物品正负关系的排序区分（按同一 held-out 对集合计算）。该解释预言：如果 ER 的提升只伴随尾部变粗/正负 share 的机械变化，而 held-out 行为排序区分没有上升，则 Stage3 不会共同改善；若行为排序区分上升且尾部未变粗，同时两项 Stage3 指标均严格越过 **0.06406796775709883** 与 **0.03530651701940677**，则“只靠尾部/碰撞比制造 ER”这一解释被证伪。注意 issue112 的历史边界因果审计本身因控制复现失败而判为 **INCONCLUSIVE**：各臂 fork 点 L1 使用数和三层碰撞率与独立 probe 不匹配，不能把其 FULL-vs-NO-DEEP 对照当因果证据。
