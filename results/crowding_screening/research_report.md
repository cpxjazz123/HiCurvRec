# 有益行为拥挤的构造及双曲几何缓解机制 —— 第一阶段研究报告

仓库 `cpxjazz123/HiCurvRec`，承接 Issue #2。固定 seed=42，未做多种子实验，未修改任何既有 checkpoint 或历史结果。
基线：Exp1a `resample`，Stage3 `test_recall@10 = 0.06373718205400512`（同一 Stage2 产物重跑）、提交值 `0.0636327234109229`。

## 0. 结论摘要

**第一阶段失败。行为驱动的拥挤既没有行为意义，也没有带来下游收益。**

| 你的成功条件 | 结果 |
|---|---|
| ① 构造的拥挤必须**有行为意义** | **L1 上不成立**：9 个臂的局部行为纯度提升落在 0.1227–0.1241，与 Exp1a 的 0.123553 [0.121570, 0.125082] **置信区间全部重叠**。L2/L3 上有 5 处统计显著差异，但**幅度极小且方向混合**（`posattract_w3` L2 +0.0029、L3 +0.0012；`couser_w1/w3` 为**负**），且这两层的连续 AUC 本就≈随机（0.52 / 0.51） |
| ② Recall@10 超过 Exp1a 0.06373718 | **不成立**：`couser_w3`（唯一码本优于基线）R@10 **0.06352826**，配对差 −0.000209，CI [−0.001393, +0.001707]（含 0）；`posattract_w3` 点估计 **0.06425948（+0.000522）但 CI [−0.001079, +0.002194] 含 0**，且 recall@5 / ndcg@10 / ndcg@5 **三项均略为负**。**没有任何臂取得统计显著的下游提升** |
| ③ 存在可测量的局部竞争供双曲缓解 | **无对象**：拥挤的码本代价与行为无关，且指向离散分配时**比随机更糟 8–12 倍** |

⇒ 按你「三条件须同时满足，否则不得宣称验证了双曲几何假设」的明文要求，**不进入第二阶段**，并明确记录：**「双曲几何通过缓解有益拥挤改善推荐」这一假设在本轮未被验证，且其前提（有行为意义的拥挤）已被证伪。**

## 1. 实验设计与执行

### 1.1 设计（参数运行前固定，共 27 臂）

| 组别 | 机制 | 约束作用点 | 三档 |
|---|---|---|---|
| M1 | `posattract` 真实购买正样本吸引 | encoder 潜变量 | 权重 0.05/0.10/0.20 |
| M2 | `couser` 共同用户商品邻域聚集 | encoder 潜变量 + 行为图 | 权重 0.05/0.10/0.20，邻域 k=5/20/50 |
| M3 | `simweight` 行为相似度加权局部压缩 | encoder 潜变量 | 浓度 1/4/16（有效权重熵 0.986→0.782→0.550） |
| M4 | `density` 购买关系密度自适应聚集 | encoder 潜变量 | 系数 0.05/0.10/0.20 |
| M5 | `softassign` 行为监督软码字分配 | **可微软分配 / 码本参数** | τ 0.20/0.10/0.05 |
| M6 | `prefixshare` 前缀共享约束 | **可微软分配的前缀概率** | τ 三档，depth 1/1/2，一致性 margin 0.05 |
| **C1** | `random` 随机商品聚集（**决定性对照**） | 同形状，配对随机（seed 42） | 同上三档 |
| **C2** | `scale` 单纯向量缩放 | 潜变量范数，无行为项 | 0.05/0.10/0.20 |
| **C3** | `parammatch` 参数量匹配 | 8192 参数块，只约束自身 | 0.05/0.10/0.20 |

**STE 约束遵守**：所有拥挤项作用在**有梯度对象**上（encoder 潜变量 / 可微软分配 / 码本参数），**不使用** L2/L3 残差。T1 把「深层残差损失梯度恰为零」钉成回归测试；T7 保证 arm A 逐位不变。共 **19 项 TDD 断言**通过。

### 1.2 执行中拦下的 5 处缺陷（每处都会让结论失真）

| # | 缺陷 | 后果 | 修法 |
|---|---|---|---|
| 1 | `prefixshare` 在 depth=1 与 `softassign` **同计算** | M6 在两档不是独立机制 | 加 margin 0.05；T10 验证区分 |
| 2 | 三档「强度」区分性未被证明，且验收断言名不副实（`cosine < 1−1e-6`，0.99999 也过） | 网格看似三档实则不是 | 按轴分设判据：幅度轴看梯度比单调、形状轴看余弦 <0.90；`simweight` 换浓度轴 |
| 3 | 拥挤值被并入 `behavior_contrastive` | 该列含义被静默改变，与 Exp1a 不可比 | 独立 `crowding_loss`/`crowding_weight` + `train_start` 拥挤元数据 |
| 4 | 拥挤臂**取代**而非叠加 Exp1a 行为项 | 相对基线**两个变量**；`random` 对照因丢行为项而失效 | 改为叠加（`assemble_losses` 相加），行为权重与拥挤权重独立 |
| 5 | `parammatch` 臂 DDP 未使用参数报错（连修两次） | 第三个对照缺失 | 真因：`assemble_losses` **无条件覆盖** `loss`，把零权重边丢弃；边移到 `loss.backward()` 之前 |

### 2.1 三条对照各自给出的判决

| 对照 | 判决 | 证据 |
|---|---|---|
| **C3 参数量** | **排除容量解释** | 三档**逐位相同**（collision 均 0.037377475901899326，码字均 237/255/256，行为项均 6.2498/5.9349/5.8970）；其 `crowding_loss` 被自身正则化衰减到 0。8192 个额外参数对模型无任何影响 |
| **C2 纯缩放** | **排除距离缩放** | 三档平坦（0.0356–0.0399）；与 T6「逐层单调重标度不改变任何 AUC」一致 |
| **C1 随机聚集** | **证明码本坍缩与行为无关** | 无任何行为语义，仍单调坍缩 0.0368→0.0453→0.1035（L1 码字 243→174） |

⇒ **最尖锐的否定表述：行为驱动的拥挤严格劣于无行为的随机拥挤。** 在同强度下 `softassign`/`prefixshare` 比 `random` 差 **8–12 倍**，L1 码字塌到 **1** 个。

### 2.2 行为意义：已筛的 9 个机制均无增益，其余 18 臂的行为指标尚为空白

**覆盖率必须说清楚**：本节引用的行为纯度指标来自 `screening_table_complete.csv`，它当前覆盖 **19 个臂、其中仅 9 个拥挤臂**
（`posattract` / `couser` / `simweight` 各三档）。**另外 18 个拥挤臂**（`density` / `softassign` / `prefixshare` /
`random` / `scale` / `parammatch`）**至今没有被计算过 purity_lift**——把「27 个 arm-level 行」误读成「27 个臂」是我的一次
计量口径错误，此处更正。全量筛选已重启过一次但**未完成也未写盘**：它在到达 `crowd_density_w3` 的 L3 之后被中止，磁盘上仍是旧的 58 行文件，
因此本节不存在「部分数据被误读为完整」的风险；工作树中也没有半成品输出需要清理。在缺口补齐之前，下列判定只对
**已测的 9 个臂**成立，本轮据此**不宣称**其余 18 臂的行为组织表现。

## 4. 关系曲线的读法（收益归因）

| 观察到的关系 | 归因判定 |
|---|---|
| 拥挤强度↑ ⇒ 码本碰撞↑、熵↓ | **不是行为组织**，因为 `random`（无行为语义）呈现同向单调关系；这是「向一个离散瓶颈持续加压」的普遍后果 |
| 拥挤强度↑ ⇒ 行为纯度、AUC、侵入率不变 | 收益既不来自**有效行为聚集**，也不来自**空间竞争缓解**（后者若成立，AUC/侵入率应改善，实测 CI 全重叠） |
| 行为压向离散分配 ⇒ 码本剧烈坍缩（L1→1 码） | **量化分配变化**是唯一被证实的效应来源，且是**有害**的 |
| 码本更均衡（couser_w3） ⇒ 下游无变化 | 均衡性在本模型下**不是**推荐的充分条件 |
| 双曲相关臂（proj_sym/proj_dir）⇒ R@10 −0.009 | 这是**上一轮**有向机制的结果，与本轮拥挤机制相互印证：**在残差/编码空间加强行为结构，并未改善检索** |

**明确声明**：以上没有任何一条支持「双曲非线性」带来收益；本轮**未检验**双曲几何（前提被证伪后不具备作用对象）。

## 5. 局限

1. **单一数据集、单一架构族**：仅 Amazon 2023 Instruments、仅该 RQ-VAE 变体。
2. **行为纯度只覆盖 27 个拥挤臂中的 9 个**：`density` / `softassign` / `prefixshare` / `random` / `scale` /
   `parammatch` 共 18 臂从未被计算过行为纯度。它们的码本结局是已知的（`softassign`/`prefixshare` 的 L1 塌至 1–13 个码字、
   `density` 的 L2 塌至 51 个），但**行为组织程度在数据上仍是空白**。
3. **下游只检验了 2 个拥挤臂**（`couser_w3`、`posattract_w3`）。其余臂未跑 Stage3 是为算力做的判断，
   因此「坍缩臂的下游必然更差」是**推断而非实测**。
3. **行为纯度的度量选择**：`purity_lift` 相对「流行度匹配随机邻域」零模型；换一个零模型可能改变绝对数值，但三个对照的一致性使结论方向稳健。
4. **无多种子**：按要求固定 seed 42。Stage3 的 run-to-run 波动已用同产物重跑实测为 ~1.0e-4（同族历史 run 跨度可达 ~1.0e-3）。
5. **`parammatch` 的拥挤项在数学上只约束自身**，因此它检验的是「加参数」而非「参数如何参与损失」；若要更严格的容量对照，应让额外参数进入主损失路径。

## 6. 下一轮的具体建议（已写入 GitHub Issue）

**不要**继续在编码潜变量或残差上加强行为结构——本轮 27 臂与上一轮有向机制共同显示这条路只会改变码本、不会改善检索。

建议按顺序：

1. **先建立 Stage2 侧指标到 Stage3 `R@10` 的可预测映射**。本轮最尖锐的事实是：`couser_w3` 把 collision 降低 16%、L1 码字增加 3%，下游毫无变化；而 `density_w3` 把 L2 码字砍到 51 个。在建立这个映射之前，任何 Stage2 代理指标都不能用来选臂。
2. **若仍要探索离散分配，必须先量化「行为压力」与「码本容量」的可行前沿**：`softassign`/`prefixshare` 在强度 0.05 就把 L1 压到 1 个码字，说明该方向上的行为压力远超过 256 码的容量；下一次应先在**更弱的压力**（例如只约束后验的重叠下界而不最大化 log 重叠）下找是否存在不坍缩的区间。
3. **双曲几何的正当入口目前不存在**。只有当第 2 步找到一个「行为有意义、码本不坍缩、且仍有可测局部竞争」的设置后，双曲的径向/角向分离才有可作用对象；届时每个双曲臂必须与同强度、同监督目标、同容量、同预算的欧氏臂直接配对，并额外加径向缩放与欧氏自适应 margin 两个对照。
