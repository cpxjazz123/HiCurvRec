## 1. 结论摘要

**核心假设（待检验）**：真实用户购买关系具有方向性，A→B 频繁不意味着 B→A 频繁；Exp1a 在三层残差上用对称欧氏 `torch.cdist` 计算 InfoNCE，评分无法区分 A→B 与 B→A，因此引入有向投影对比学习应能改善 Semantic ID 并提升 Stage3 `Recall@10`。

**结论：假设被否证。有向机制在相同的 Stage3 T5 协议下没有任何 `Recall@10` 提升，反而显著劣于基线。**

| 臂 | 唯一变量 | Stage3 R@10 | R@5 | NDCG@10 | NDCG@5 |
|---|---|---|---|---|---|
| **A** `resample`（Exp1a 原实现，cdist 对称） | — | **0.06373718** | 0.04254949 | 0.03511032 | 0.02830163 |
| **B** `resample_proj_sym`（双投影头，对称评分） | 投影评分 + 对称化 | 0.05452741 | 0.03622974 | 0.02989158 | 0.02398476 |
| **C** `resample_proj_dir`（双投影头，有向评分） | 仅改为有向 | 0.05484079 | 0.03736137 | 0.03020304 | 0.02459197 |

用户级配对 bootstrap（n = 57439，1000 次重采样，配对同一用户）：

| 对比 | ΔR@10 [95% CI] | 判读 |
|---|---|---|
| A − B | **+0.00920977** [0.00757325, 0.01081147] | CI 不含 0；A 显著更好 |
| **B − C** | **−0.00031338** [−0.00188113, **+0.00118386**] | **CI 含 0；有向与对称不可区分** |

**两条决定性事实**：

1. **投影评分本身造成 −0.009 R@10 的损失**（A−B 与 A−C 的 CI 均不含 0），约为 Stage3 run-to-run 噪声底线（**1.045e-4**，由同条件重跑实测，见 §7.3）的 **88 倍**；
2. **在此代价之内，方向性买不到任何东西**：C 相对其容量匹配的对称对照 B 的差异为 −3.1e-4，CI 跨越 0。

按任务书第 8 步的明文规定（「若有向机制没有稳定收益，应明确停止扩展」），**分层消融（L1/L2/L3 等 6 组）不执行**：其前置条件「方向性有明显收益」不成立，继续扫描分层贡献只会是在一个已被否证的方向上寻找可汇报的数字。同时**不通过调整其他机制（双曲、逐层温度、margin、码本预算、负采样）来掩盖负面结果**。

### 三个层次的结论必须分开陈述

| 层次 | 结论 | 依据 |
|---|---|---|
| **观察事实** | 有向评分**确实学到了真实方向性**（在连续残差上）：C 的方向差在「反向真实存在」配对上为正、在「仅未观察」配对上≈0 | §5 |
| **观察事实** | 但只有 **L1** 的方向性穿过量化进入离散 SID；L2 边际、**L3 丢失（符号反转）** | §6 |
| **观察事实** | 方向差的符号**依赖 hub 程度**：非头部商品为正（+0.14~+0.17），头部为负（−0.065） | §5 |
| **机制假设（未证）** | 方向性未带来检索收益的可能原因：量化后只剩 L1、hub 符号翻转、以及投影头的损失尺度效应 | §9 |
| **因果结论** | 在**本协议、本数据、本容量**下，有向投影对比学习**不是**提升 Stage3 `Recall@10` 的有效机制 | §7 |

## 2. 步骤 1：现有实现的审查（全部结论来自实际代码）

`stage2_RQ-VAE/TIGER_BEHAVIOR_SAMPLE_RQ-VAE/train_rqvae.py`（678 行，本轮唯一改动的 Stage2 文件）
+ 保持逐字节不变的 `model/`。

| 项目 | 实际实现 |
|---|---|
| 监督信号 | `TransitionPairs`：对训练 parquet 每一行取 `(history[-1], target)`，**重复保留** → 确认为 `history[-1] → target` |
| 三层残差 | `_residuals_with_trace(raw_module, pair_batch)` → `(3, 2B, 32)`；`level0 = encoder(x)`，`level_l = 上一级残差 − quant_l(上一级残差)`，即**进入该层前的残差**；前 B 为 source、后 B 为 candidate |
| 对比损失 | `behavior_contrastive_loss`：`torch.cdist(source, candidates, p=2)`，`logits = -dist/0.07`；**对称**，故 `s(A,B) ≡ s(B,A)` |
| 负样本过滤 | 仅屏蔽**重复 target**（对角线置假）。`FALSE_NEGATIVE_MASK = (EXPERIMENT_ARM == "resample_fn_mask")`，故 Exp1a 臂 `resample` **不屏蔽已知后继假负样本**；B/C 沿用同一协议 |
| 梯度通路 | `pair_batch → _residuals_with_trace → behavior_contrastive_loss → loss + w·behavior → 单次 backward → clip_grad_norm_(1.0) → AdamW.step()`。因 `level_l` 含 `−quant_l(...)`，梯度**同时**进入 encoder 与各层量化器 |
| 协议常量 | 3000 epoch、bs 1024/卡×4、lr 1e-3、wd 1e-4、warmup 50、AdamW、码本 256³、dim 32、BETA 0.25、**T = 0.07**、ramp 1500→3000 到 **0.2**、pair bs 512/卡、seed 42 |
| 导出 | `raw_module.get_indices(all_embeddings, infer_use_sk=False)` → `_extend_collisions` → `(24587, 4)`，`unique == 24587` |
| Stage3 | 冻结：150 epoch、early-stop 禁用、NO_EVAL=True、SKIP_TEST=False、seed 42、beam 20、topk [5,10]；用 `genrec_env`(py3.10)；分片 `Subset(range(rank, n, world_size))` |

## 3. 步骤 2/3：三组设计与唯一变量

B、C 使用**完全相同**的两套可训练投影头 `f_source`、`f_target`（`Linear(32→32)`，输出 L2 归一化），作用于**每层量化前残差**：

$$s_l(A\to B)=\frac{\langle f_{\text{source}}(r_l(A)),\, f_{\text{target}}(r_l(B))\rangle}{\tau},\qquad \tau = 0.07$$

- **C**（`resample_proj_dir`）：$s_l(A\to B)$
- **B**（`resample_proj_sym`）：$\tfrac{1}{2}[s_l(A\to B)+s_l(B\to A)]$（同一头、同一归一化、同一温度，仅评分是否对称）
- **A**（`resample`）：原 `cdist` 实现，一字未改

**参数量**：A = **395072**，B = C = **397184**，差 **2112** = 2×(32×32+32)，即两套投影头的全部参数。B 与 C 参数**严格相等**。

**屏蔽与标签共用一个代码路径**（`_contrastive_ce`），使 A 的语义不可能与 B/C 漂移；A 与独立参考实现的逐位一致性由 T1 钉死。

**单变量对照在真实训练上被验证**（而不是仅被声称）：

| 验证项 | 结果 |
|---|---|
| B、C 与 A 在 ramp 前 1500 个 epoch 的 loss / recon | **逐位相同**（0/1500 差异） |
| 同期 30 次 collision 评估 | **全部相同**（30/30） |
| 首次分歧 epoch | **1501**（两者皆是，恰为 ramp 激活的第一个 epoch） |
| `train_start` 行冻结字段（epochs / batch / 码本 / seed / resample / fn_mask / T / ramp / pair batch） | 三臂完全一致，仅 `directional_mode` 为 none / sym / dir |

**RNG 隔离**是做到这一点的前提：`init_codebook` 用 sklearn `KMeans(random_state=None)` 消耗 **numpy 全局 RNG**，而投影头若用默认 `nn.Linear` 初始化会推进 **torch 全局 RNG**，可能改变码本初始化。因此投影头以**显式 `torch.Generator(SEED+7919)`** 构造并置于 `torch.random.fork_rng` 内，并加 T10 断言三种模式下 encoder+码本参数逐位相同。

## 5. 步骤 5：真实数据上是否学到方向性

有向转移图取自 `train.parquet`；评估用 **valid 划分**（57439 对；其中 **REVERSE-OBSERVED 4207**、**REVERSE-UNOBSERVED 53232**），**未使用 test 划分**。

### 5.1 校准检查：零是真零

A 与 B 的方向差在**每一层、每一类**都是**恰好 0.000000**（A 因 `cdist` 对称、B 因评分被对称化）。这说明该度量里的 0 是结构性的零，而不是"没测出来"。

### 5.2 方向差（均值，连续残差）

| 配对类别 | C 的 L1 | C 的 L2 | C 的 L3 |
|---|---|---|---|
| **反向真实存在**（n=4207） | **+0.011622** | +0.008633 | +0.006262 |
| **反向仅未观察**（n=53232） | −0.001373 | +0.001018 | +0.003524 |

→ 方向差在**反向关系真实存在**的配对上明显为正、在**仅未观察**的配对上≈0。**这是"学到的是真实方向性、而非稀疏性假象"的直接证据**，也是任务书要求区分这两类的原因。

### 5.3 但方向符号依赖 hub 程度（必须报告的限定）

按**源商品出度四分位**分层（arm C，反向下已观察类）：

| 源度数分位 | L1 | L2 | L3 | n |
|---|---|---|---|---|
| q0（最低） | **+0.1653** | +0.0115 | +0.0263 | 570 |
| q1 | +0.1384 | −0.0279 | +0.0355 | 1059 |
| q2 | +0.1625 | +0.0184 | +0.0230 | 2718 |
| **q3（最高）** | **−0.0648** | +0.0099 | −0.0044 | 8274 |
| （反向仅未观察）q3 | −0.3179 | +0.0221 | +0.0108 | 34521 |

→ 池化后的正号由**非头部商品**驱动；对头部 hub 商品，模型系统性地给**反向**更高分。**因此不能把 §5.2 的池化正号当成一致的方向性信号**。任务书要求「控制商品流行度和观察次数」，此处即为该控制的结论：方向性存在，但**不是全局一致的**。

### 5.4 各层评分与批内后继判别（REVERSE-OBSERVED）

| 臂 | 层 | 方向差 | 正-负 logit gap | R@1 | R@5 | R@10 | ‖r_l‖ |
|---|---|---|---|---|---|---|---|
| A | L1 | 0.0000 | 2.4254 | 0.1635 | 0.3392 | **0.4238** | 0.3964 |
| A | L2 | 0.0000 | 0.2724 | 0.0606 | 0.1188 | 0.1502 | 0.1362 |
| A | L3 | 0.0000 | 0.1311 | 0.0269 | 0.0647 | 0.0903 | 0.0991 |
| B | L1 | 0.0000 | 3.8921 | 0.1543 | 0.3247 | 0.4103 | 0.2062 |
| B | L2 | 0.0000 | 2.0998 | 0.0939 | 0.2232 | 0.2969 | 0.0638 |
| B | L3 | 0.0000 | 2.2931 | 0.0841 | 0.2108 | 0.2833 | 0.0445 |
| **C** | L1 | **+0.0116** | 2.4795 | 0.1555 | 0.3311 | 0.4145 | 0.1755 |
| **C** | L2 | **+0.0086** | 1.0375 | 0.0958 | 0.2270 | 0.3069 | 0.0540 |
| **C** | L3 | **+0.0063** | 1.1850 | 0.0851 | 0.2080 | 0.2800 | 0.0401 |

两个重要观察：

1. **哪一层从有向评分中获益最大 = L1**：C 的方向差在 L1 最大（+0.0116），且只有 L1 的方向性穿过量化（§6）。
2. **一个与「层越深越无效」相反的现象**：B/C 在 **L2/L3** 的批内后继判别（R@10 约 0.28~0.31）**远强于 A**（0.150 / 0.090），正-负 logit gap 也大一个量级。即投影头**大幅改善了深层残差的对比判别力**——但这**完全没有转化为**下游检索（§7）。这是任务书所警告的那类诱人但无效的代理指标的直接实例。
3. **残差尺度随层递减被实测确认**：A = 0.396 → 0.136 → 0.099；B/C 更小（0.206/0.064/0.045 与 0.176/0.054/0.040）。这是任务书第 8 步关心的现象；但**没有做分层消融**（§8）。

### 5.5 梯度尺度：一个必须报告的对照破绽

在固定真实批次上对各臂自身损失做一次 backward：

| 臂 | 对比损失（checkpoint 处） | encoder 梯度范数 | 投影头梯度范数 |
|---|---|---|---|
| A | 5.52 / 6.28 / 6.26（L1/L2/L3） | **1.296** | — |
| **B** | **32.84 / 30.71 / 35.62** | **487.661** | 138.427 |
| **C** | 5.61 / 6.11 / 6.29 | 5.689 | 1.808 |

→ **对称化涌现地把损失放大到约 5.5 倍、把 encoder 梯度放大约 380 倍**。因此 B 与 C 的差别**不只是"有无方向"**，还包含优化强度的巨大差异。这一点削弱了「B 是 C 的容量匹配对照」的说法，必须如实报告：CIPS 式的严格对照只在**评分函数构造**层面成立，在**损失尺度**层面不成立（温度与归一化虽相同，评分分布不同）。这也是解释 §7 中 B 略差于 C 的候选机制（§9），但**不足以**解释 A 优于两者。

## 6. 步骤 6：对 Semantic ID 的影响

### 6.1 三层码字使用率 / 熵 / Collision / 重构

| 臂 | collision（扩展前） | 不同码字 L1 / L2 / L3 | L1 熵(bits) | 重构 MSE（解码 vs 输入） | 量化 vs encoder MSE |
|---|---|---|---|---|---|
| A | **0.036279** | 241 / 256 / — | **7.826** | 1.4134e-4 | 2.0673e-4 |
| B | 0.059584 | 184 / 233 / — | 6.580 | 1.2405e-4 | 6.1421e-5 |
| C | 0.077887 | 220 / 243 / — | 6.513 | 1.1821e-4 | 5.4182e-5 |

扩展后三臂均 `collision = 0`（`distinct_sids = 24587`）。

### 6.2 行为富集比（ER）与正/负共享率

| 臂 | ER L1 | ER L1+L2 | ER L1+L2+L3 | 正共享 L1 | 负共享 L1 |
|---|---|---|---|---|---|
| A | **19.739** | **94.520** | — | 0.09563 | 0.00484 |
| B | 4.239 | 9.727 | — | 0.07812 | 0.01843 |
| C | 4.004 | 8.909 | — | 0.09542 | 0.02383 |

→ **两个投影臂在 collision（高 1.6~2.1×）与 ER（L1 从 19.74 崩到 4.0~4.2；L1+L2 从 94.5 崩到 8.9~9.7）上都明显退化**。重构误差 B/C 反而略好（1.18~1.24e-4 vs 1.41e-4），恰好证明**重构误差不能代表 SID 质量**。

### 6.3 量化后的方向性是否仍可利用（关键）

在**量化码字**上重算方向差（arm C）：

| 层 | 反向真实存在 | 反向仅未观察 |
|---|---|---|
| **L1** | **+0.023065** | −0.003154 |
| L2 | +0.007618 | +0.000204 |
| **L3** | **−0.001365** | +0.003717 |

→ **只有 L1 的方向性成功地穿过量化**（连续 +0.0116 → 量化后 +0.0231，且与"真实反向"一致）；L2 边际；**L3 丢失并符号反转**。连续残差上的有向监督**确实部分进入了离散 SID，但只到第一层**。

### 6.4 关于 Semantic ID 质量的声明边界

按任务书要求：**不得仅因 ER 或方向分类准确率提高就宣称 Semantic ID 质量提高**。本轮证据方向恰好相反——ER 与 collision 都退化；且 §5.4 已显示「对比空间内判别力提升」与「离散 SID 的推荐能力」可以完全脱钩。因此本报告的声明边界是：

- **可以说**：方向性在连续残差上被学到，且 L1 部分穿过量化（有测量支持）。
- **不可以说**：Semantic ID 质量因此提高（无任何测量支持，且相反方向的测量存在）。
- **可以说**：在本协议下，投影式对比评分使 SID 的行为富集与 collision 同时退化，且下游 `R@10` 显著下降。

## 7. 步骤 7：相同 Stage3 T5 协议下的最终比较

## 8. 步骤 8：为什么不做分层消融

任务书的第 8 步是**条件性**的：「如果方向性有明显收益，再做分层消融」。本轮的判定是反向的：

- C 相对其容量匹配的对称对照 B：ΔR@10 = −3.1e-4，CI 含 0（无收益）；
- C 相对基线 A：ΔR@10 = −8.9e-3，CI 不含 0（显著更好的是 A）。

在没有收益的前提下扫描「仅 L1 / 仅 L2 / 仅 L3 / L1+L2 / L2+L3 / L1+L2+L3」，得到的最好结果也只能是"某个子集不比全量更差"，**不足以**支撑任何正向结论。因此按「不通过调整其他机制掩盖负面结果」的要求，**终止扩展**。

已有的分层证据（不额外训练）已经回答了第 8 步想测的一半问题：**深层残差即便用有向评分也难以有效学习行为关系**这一假说，在**量化后**得到支持——L2 边际、L3 方向性丢失（§6.3）；但在**连续层**并不成立——L2/L3 的批内判别反而被投影头大幅改善（§5.4）。两者合起来指向：**瓶颈不在"深层残差尺度小"，而在"连续层的判别力无法传递到离散 SID 与下游检索"**。

## 9. 失败原因分析（严格区分事实 / 假设 / 因果）

### 9.1 已确认的观察事实

1. 有向评分学到了真实方向性（连续层；反向已观察 vs 仅未观察的对照）。
2. 只有 L1 的方向性穿过量化；L3 丢失。
3. 方向差符号依赖 hub 程度。
4. 投影头把 L2/L3 的批内后继判别力提升到 A 的 2~3 倍（R@10 0.28~0.31 vs 0.090~0.150），却伴随 SID 的 ER / collision 同时退化与下游 `R@10` 下降约 0.009。
5. 对称化把损失放大 ~5.5×、encoder 梯度放大 ~380×。

### 9.2 机制假设（未证实，明确标注）

- **H-a 量化瓶颈**：有向监督作用在**连续残差**上，而 Stage3 只消费**离散 SID**；L1 之外的方向信息在 `argmin` 量化中被丢弃。§6.3 的层间衰减与之一致，但本实验无法排除其他原因。
- **H-b 孔径过窄**：方向差在全体 64×64 候选上的均值仅 0.001~0.012（相对评分量级约 0.2%），方向信号太弱，不足以改变量化边界。
- **H-c hub 符号翻转**：头部商品的负方向差（−0.065）与整体正方向差相互抵消，使方向性的净收益为零。
- **H-d 损失尺度失配**：投影评分在 τ=0.07 下的 logit 分布与 cdist 完全不同（B 尤甚），导致反向传播的强度与基线不可比；对残差结构的压力过大（残差范数被压小 2~2.5×）。
- **H-e 代理指标脱钩**：对比空间的判别力与 SID 的推荐能力之间没有单调关系（本实验最强的反例）。

### 9.3 设计许可的因果结论（以及不许可的）

- **许可**：B 与 C 之间的唯一差别是评分是否对称（同头、同参数量、同归一化、同温度、同数据、ramp 前逐位相同的轨迹），故 **B−C 的差异可归因于对称化本身**；其结论是「方向性不带来收益」。
- **许可**：A 与 B/C 的差别包含"投影评分取代 cdist"与"多出 2112 参数"两者，故 **A−B / A−C 只能归因于"投影式对比评分"这一整体**，不能单独归因于"方向性"——尽管方向上 C 并未比 B 好，已足以否证核心假设。
- **不许可**：「方向性在购买数据中不存在」——本实验只说明**它不以可提升检索的形式进入该 RQ-VAE 的离散 SID**；方向性在连续层被学到，且与真实反向行为一致。

## 10. 失败的实验与实现缺陷（完整记录）

本轮共暴露 6 个实质缺陷，其中 3 个会产出"看起来合理但错误"的结果。**作废的中间结果全部丢弃，未保留、未用于叙述。**

| # | 缺陷 | 症状 / 如何被发现 | 处理 |
|---|---|---|---|
| 1 | **嵌套 DDP**：把投影头再套一层 DDP 作为外层 DDP 的子模块 | epoch 1501 崩于 `'DistributedDataParallel' object has no attribute 'n_parameters'` | 删除内层 DDP |
| 2 | **DDP 未使用参数失效组合**：把投影头挂在**外层** DDP + `find_unused_parameters=True` | epoch 1501 崩于 `Expected to mark a variable ready only once`（`directional_heads.f_target.bias`）。原因是每个头在一次迭代被**调用两次**（source + candidates），且在前 1500 epoch **完全未被使用** | 改为：投影头在 DDP 包装**之后**挂到 `raw_module`（在 `state_dict` 内、不在 DDP reducer 内），backward 后手动 `all_reduce` 求和并除以 `world_size`（与 DDP 均值语义等价）；A 的 `find_unused_parameters=False` 保持不变 |
| 3 | **跨 run 协调文件残留**：`_ddp_sync/run_dir.txt` 从不在 run 开始时清理 | 非零 rank 在 rank0 覆写前读到上一次 smoke 的 `cur_time`，把 shard 写进旧目录 → rank0 等待 19 分钟直到 30 分钟安全上限 | 核实四个 shard 逐位属于本次 run（含 `n_eval` 与 mtime 交叉验证）后归位；rank0 完成归约，其聚合值与 main 独立组装**逐位相同**。已加入启动器层清理（不触碰冻结训练器） |
| 4 | **Stage3 启动解释器错误**（main 的指令错误） | `torchvision::nms does not exist` / 无法导入 `T5ForConditionalGeneration`；Stage3 需 `genrec_env` 而 Stage2 用 `genrec_env_v2` | 纠正并重跑 smoke，实印冻结协议横幅与 epoch 1 |
| 5 | **`eval_token_level.py` 陈旧的 dataset 路径** | `FileNotFoundError: dataset/valid_recbole.parquet`（旧布局） | 按当前约定改为 `results/stage0_build_parquet/` + `valid.parquet`，并以 `rows=57439 / vocab=781 / eos=780` 校验 |
| 6 | **arm→mode 名称前缀映射**（同类风险预防性修正） | 在 Stage2 侧以显式 `ARM_TO_MODE` 取代前缀推断 | 已在机制实现中固定为字典映射 |

另有 **8 项实现缺陷**在切片初期被发现并修复（TDD 过程中：`config` 未初始化、padding 语义、`leaf→parent` 逆置换、冻结字段漂移防护等），此处不重复展开。

## 11. 局限性

1. **单一数据集、单一架构族**：仅 Amazon 2023 Instruments；仅"投影头作用在量化前残差"这一种实现方式。其他实现（例如把方向性做进量化器内部、或对码字而非残差做有向约束）不在本轮结论的覆盖范围内。
2. **单一 Stage2 种子（42）用于端到端比较**：run-to-run 非确定性已用同条件重跑实测为 ~1e-4，效应量为其 88 倍，故主结论不受此限；但**更小效应**（如 B−C 的 3e-4）在本设计下不可判定。
3. **B 与 C 的损失尺度不可比**（§5.5）：温度与归一化相同，但评分分布不同导致损失/梯度放大。因此「B 是 C 的严格容量匹配对照」只在**评分构造**层面成立；这是本实验最重要的方法论限定。
4. **分层结论是间接的**：第 8 步的分层消融未执行（§8），"哪一层受益"的结论来自已有指标（量化后方向性、批内判别力、残差范数），而非 6 组消融对照。
5. **方向性评价的 cohort 不平衡**：REVERSE-OBSERVED 仅 4207/57439（7.3%），且其判据是"训练集中出现过反向边"，仍受观察次数影响，已用度数分层部分控制但未完全消除。
6. **未做超参搜索**：τ 固定 0.07（任务书要求不改），投影头的形状固定为 32→32 线性。这些选择都由任务书冻结，非本实验的发现。

## 12. 下一步决策

按任务书「若有向机制没有稳定收益，应明确停止扩展，分析失败原因」的要求：

- **停止**该机制的所有扩展（含分层消融、seed 43/44、以及把方向性迁移到其他 Stage2 变体）。
- **不推进**任何"以调整其他机制来掩盖本轮负面结果"的方向。

若要继续本方向，必须先解决本报告指出的**核心断裂**（连续判别力 → 离散 SID → 下游检索），优先级顺序建议为：

1. **先解决代理指标脱钩**：本轮最强的反例是"L2/L3 批内判别力提升 2~3 倍、ER/collision 退化、R@10 下降 0.009"三者同时发生。在信任任何新的对比损失之前，应先建立"Stage2 侧指标 → Stage3 R@10"的可预测映射；否则每一轮都会在黑暗中调参。
2. **把有向性放进量化器而不是残差**：若方向信息必须在离散 SID 中存活，约束应作用在**码字/分配**层面（例如让 L1 分配对方向敏感），而不是在会被 `argmin` 丢弃的连续残差上。§6.3 显示只有 L1 幸存，指向"作用点应更靠上、且需显式保留"。
3. **控制损失尺度再谈评分函数**：任何与 cdist 不同的评分都应先做尺度/梯度匹配（例如按 checkpoint 处的梯度范数标定 τ 或加尺度归一），否则 A/B/C 的比较会同时改变两个变量。
