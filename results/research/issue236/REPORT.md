## 3. 方法(C11–C16)

利用线性可分解性,把逐三元组遍历参考点变为一次累加:

$$\kappa(m;b,c) = \frac{S[m]}{R} + \frac{d(b,c)^2}{4} - \frac{1}{2}\left(\frac{S[b]}{R} + \frac{S[c]}{R}\right),\qquad S[v]=\sum_{a} d(a,v)^2$$

- `S[v]` 用 **int64 精确累加**(24556 × 24555² 会溢出 int32,已测试),最终 float64。
- 距离用**批量前沿扩展**(每批 512 个源),不存稠密矩阵(那会是 24,556² × 2 B ≈ 1.2 GB)。
- 不可达参考点**剔除**,不当零(C14);零容差 1e-9,未归一化,单位平方跳数。
- **18 项单元测试**验证流式实现与逐三元组暴力全参考计算逐位等价。

### 单元测试覆盖

| 测试 | 内容 |
|---|---|
| 流式 vs 稠密逐位等价 | 环/格点/星形/路径/断连 五种图 |
| 流式 κ vs 暴力全参考 | 同上,每个 geodesic 三元组逐一比对 |
| 分母是共享参考数不是总数 | 断连图 |
| 不可达不记零 | 断连图,S[3] = 0+1 而非 (0+1)/5 |
| 孤立点无三元组且不填零 | 带孤立边的小图 |
| 非测地邻居对被主口径排除 | K4 |
| int64 必要性 | 24,556 × 24,555² > int32 max |
| 精确整数累加 | 值类型为 Python int |

### 声明的限制

1. 无向投影,**不推断边方向**;链式/分叉/汇合的有向类型无法识别。
2. **曲率不能唯一识别 Graphlet**,它是结构的一个标量投影。
3. **度数相关含代数成分**:曲率定义在 open wedge 上,该数量随度数平方增长;高度数节点的邻居对
   两端距离更远,曲率更负。这解释了"全局负、商品级正",但**不构成"高度数商品具有负曲率几何"
   的独立证据**。

## 8. GraphMoRE 官方代码核实(C21)

**仓库**:https://github.com/Vic-GoodLuck/GraphMoRE(commit `1948d3c5`)

**结论:无法核实论文 Appendix A.1 的绘图参考数与归一化。**

| 检索项 | 结果 |
|---|---|
| 截面曲率计算函数 | **不存在** |
| 参考节点 `a` 采样代码 | **不存在** |
| 归一化实现 | **不存在** |

- `utils.py::cal_shortest_dis` 只返回每条边两端的最短路距离,**未组合成 κ(m;b,c)**。
- `models.py::kappaLinear` / `kappaGCNConv` 的 κ 是**可学习曲率参数 k**(κ-GCN),
  与截面曲率公式无关。
- `compute_distortion` 用 `dis_shortest` 算距离失真损失,是训练目标,不是 Eq. A.1。

**因此本项目实现的是论文公式,不是官方绘图管线。不能声称完全复现。**
