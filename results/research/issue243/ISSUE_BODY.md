## 目标与边界
接续已关闭 #242（9c9d0cc1）。保留主线：商品对是监督单位，但同一商品同时参与多个局部子图，商品对之间的关系需要在同一表示空间内兼容；研究节点自适应混合曲率是否有助于同时保留这些关系，并传递到 SID。#242 只发现门控权重集中和球面距离退化，尚未完成 Teacher 或 RQ-VAE，不能视为机制无效。本轮先修实现，再验证原假设，不通过增加额外 loss 掩盖错误。
参考 GraphMoRE https://arxiv.org/pdf/2412.11085 §4、Eq.3–10；官方实现 https://github.com/Vic-GoodLuck/GraphMoRE 。严格区分论文原机制与本项目有向适配。单 Agent 执行，不使用多 Agent。

## 步骤2：修复 #242 的已确认实现问题（尚不启动正式训练）
1. 球面：核查 project_spherical、dist_spherical 及专家最后一层 ReLU。零向量不在球面上，禁止通过 normalize 静默保留零向量；使用官方 κ-stereographic exp/log 与流形距离或经独立验证的等价实现。测试同点0、正交 π/(2√c)、对跖 π/√c（球面环境），零输入、梯度、周期/边界；分别记录每个专家输出范数、零向量率、距离方差与梯度。确认 π/2 的真正来源，不能凭均值断言所有点对恒定。
2. 双曲：#242 的 Poincaré acosh 公式多乘2；修复为正确尺度，并使用独立 float64 参考与测地已知点测试；自距离/对称/径向距离/有限差分通过，检查极限曲率、边界及梯度。
3. 专家：不允许普通欧氏 GNN 最末尾投影冒充 κ-GCN。按官方实现核对每层 logmap/消息聚合/expmap，使用真实曲率算子；有向适配分别处理入/出边。五专家初始曲率 {-3,-1,0,+1,+3}，记录实际是否可学习；门控 T_i、W_i、流形缩放、拼接、对齐距离严格核对 Eq.8–10，区分节点权重与 pair 权重（后者 softmax 后不能直接解释为94%）。验证每个专家对距离及梯度的实际贡献。
4. 子图：先采样节点集合，再从原始有向图提取该集合的全部诱导边，不得只保留遍历树；去重节点，双向邻居保留双角色，根标记和 hop 特征实际输入 GNN；入/出/全子图 Pooling 及空集合 mask 符合契约。用三角、链、分叉、汇合、双向边、孤立点检查精确节点和边集合。采用固定可复现采样，训练/导出/评估口径一致。
5. pair bank：共同后继 i→k←j 用 out(i) 与 in(k)；共同前驱 i←k→j 用 in(i) 与 out(k)；两跳链另列。逐条用独立邻接集合验证类型，排除自配对、重复、直接边（仅对要求无边的组）、处理类别重叠并报告。度数/流行度匹配候选不得冒充已证实负例。
6. 评估：Jaccard 必须实际计算交集/并集，Spearman 必须处理 ties（对常数返回 NA），方向反转测试保证 T 128 维并同步正确的结构属性及方向池化；不能用64维输入128维门控。独立小图手算验证指标。检查冻结评估对是否与 Teacher 距离采样重叠，区分已见图距离重建与未见关系泛化。
- 上述每条均需独立参考/手算测试、真实小批量分模块检查及故障变异证据。全局梯度有限不能代替各专家有效梯度；半径有限不能代替数学正确；无误后才进入步骤3。禁止放宽测试或以作者自证代替执行。

## 步骤3：训练一个 GraphMoRE 式 Teacher
- 沿用 #242 方法：双尺度有向 ego + GNN + Pooling 得到商品 T_i；门控 MLP 输出5维 W_i；五个真实曲率专家各16维，共80维，使用原始768语义及训练图；训练目标仅 GraphMoRE 距离失真 L_D=mean |(D_geo/g)^2−1|，g 为可见图无向投影最短路径。方向通过有向编码及后续上下文进入，对称距离不声称恢复边方向。
- 预先用合法训练探针确定各空间输入尺度与初始化，避免球面零向量/边界饱和；原论文门控机制不变，不引入负载均衡 loss，不冻结均匀门控，不引入下一商品分类任务。若门控集中，先看 pair 权重、距离方差、每专家梯度及贡献，不能单凭节点权重集中判死。
- 真入口多步 smoke 通过后一次正式 Teacher 训练。逐专家记录距离分布、权重、门控熵、梯度、更新、输出范数及独立验证失真；若发现代码错误先修复并复测，不改变科学目标或擅自重复正式训练。

## 步骤4：验证重叠子图的几何兼容性（主线关键）
- 在同一冻结评估集，按中心商品采样多个局部子图（包含链式、分叉、汇合及其他可计算的连通模式），保留具体节点身份、边方向及图距离。报告商品参与的结构类型数、子图数量、正负几何异质性统计（已有曲率仅作诊断）。
- 定义每个局部子图 t 的距离失真 E_t=mean_(i,j∈t,i≠j) |(D(i,j)/g(i,j))²−1|；对参与多个子图的同一中心商品报告平均 E、最差子图 E、p90 E、同时达到预冻结保真阈值的子图比例；度数匹配、固定规模，避免 hub/子图数量混淆。阈值和尺度开训前冻结。相同商品的表示必须固定，禁止按子图重新编码并选择不同最终 SID 来伪造兼容性。
- 比较原始语义欧氏距离、Teacher 原生混合几何距离；廉价诊断使用同一 checkpoint 的单专家距离及固定均匀权重（不重新训练任何专家/基线），并用可见图的 PPR/共同邻域作为关系强度非训练参照，区分间接可达性与多关系联合保真；PPR 不直接当距离，如需比较失真须预冻结合法尺度转换及说明限制。不要宣称这些诊断等同于严格训练消融或证明独立因果。
- 报告在多结构商品中是否改善最差子图误差与同时保真率，而非仅全局平均；验证是否只是度数或图距离的重新编码。若没有额外价值，如实报告；不预设混合空间必须优越。无可用结构信号则停止 Stage2，先定位证据。

## 步骤5：冻结商品对关系监督
- 沿用 #242 已定义 S_geo=exp(-D_geo/τ)，τ 为训练对有限正距离中位数；C_in/C_out 为可见有向图归一化前驱/后继分布的 Bhattacharyya 重叠，C_ctx 对有效方向取平均；S_G=(S_geo+C_ctx)/2，有效性规则沿用 #242。记录每组目标分布、缺失及哈希。
- 商品对不限直接边。用步骤2修正的 bank，独立评估实际共同上下文和多跳关系；不能用 Teacher 自身拟合分数证明真实结构保留。若无向几何与有向上下文贡献无法隔离，明确限制，不宣称恢复方向。
- 冻结 Teacher checkpoint、T、W、专家表示、pair bank、配置及哈希，保证每商品固定表示；不使用增强向量作为 RQ-VAE 输入。

## 步骤6：训练一个 RQ-VAE 候选
- 从已有冻结 TIGER 派生独立树；原始768输入、32瓶颈、三层256码本、欧氏码字选择、STE、Sinkhorn、残差更新、重建/量化 loss 与训练协议不变。
- 仅增加 Encoder-only L_topo=mean Huber((1+cos(z_i,z_j))/2−S_G(i,j))；z 为量化前连续32维。L_total=L_RQVAE+λ(t)L_topo。前1500 epoch 仅原损失，后1500 epoch 线性 ramp，λ_max 按预冻结梯度标定规则（实际完整 base 系数、梯度绝对值、方向及参数位移）。不使用 InfoNCE/截面曲率 loss/分层 loss，不直接更新码本，不照搬0.2。
- 真入口测试：原机制不变、关闭结构项等价、只 Encoder 有直接结构梯度、参数更新、DDP、数值与原护栏；检查训练/导出 SID 一致性。通过后一次3000 epoch Stage2，记录全过程梯度、裁剪、码本、重建、碰撞。不要重训 TIGER，不扫参，不多种子。

## 步骤7：真实离散 SID 与 Stage3 验收
- 与已有冻结 TIGER 同口径比较 z、硬 q、SID重建 q、实际三级 SID；关系分数误差/秩相关、真实共享前后继/间接关联、prefix@1/2/3、关系强弱分位数共享差、碰撞、各层利用率、重建MSE及导出一致性。
- 特别报告多子图商品的最差子图距离保真、同时保真率及 SID 前缀兼容性（以同一 SID 的归一化前缀距离或预冻结排序规则测量，不混用连续距离）；与少子图、度数匹配商品分别比较。核心假设是共同保真改善而非单一 pair 排名提高。不能把连续表示或 Teacher 改善直接当成离散 SID 改善。
- 达已有 Stage3 准入后按冻结协议运行一次150 epoch Stage3，记录 Recall/NDCG、实际 SID 哈希，与历史 TIGER 比较；不声称单次小差值显著。
