# #254：#253 相对 #252 的 Stage3 退化诊断

## 结论

**退化属实，但无法归因于单一几何或门控因素。** 最明确的输出事实是目标分支在保存候选中缺席；有统计支持的机制线索是训练可见邻居的 L1 SID 前缀保持度下降。总体“更偏欧氏”不能解释受损目标：受损目标的欧氏权重反而明显下降。这里完成的是只读诊断，不是混合曲率优势或 graphlet-specific 几何必要性的证明。

无新训练、无新模型/基线、无调参、多种子或 PPR。所有统计置信区间只针对这两个已完成模型及当前用户/商品总体，不表示跨训练种子的稳定性。

## 1. 身份、口径与限制

两臂权威数据为各自正式3000-epoch checkpoint 导出的 SID，随后各一次150-epoch Stage3。源/SID/checkpoint/export/binding 与 R2 100/101 ledger 对账；复用历史下载校验凭据，不声称本次重新下载。两臂相同 trainer SHA、seed42、split、beam20、cutoffs5/10、历史过滤和解码规则。除路径外，目录派生的词表/EOS也不同：#252 为781/780，#253 为779/778。因此不是严格相同词表的单因素对照。

原 dump 无独立 user/history 字段。用原始 test parquet SHA `5290abf0073d798401b56bd0a9ec5f710ed2c01ae9fa4cb8bd3906c1a55f0bfc`、已核验分片公式、每行目标商品与权威规范 SID 重建身份，再按 user/完整历史与seen_history及目标的SHA/target 连接。57,439样本/用户全部匹配，16,462个不同目标；原 dump 未保存的输入 tensor 摘要不补造。历史按实际模型截断到最后20项，全 seen_history 用于过滤。

搜索beam20，但只保存最终10个商品。目标缺席表示 **>10 / 右截尾**，不是具体第11名、更不是已知落在20名之外。无完整beam树、被过滤候选或概率，因此不能定位T5剪枝/概率路径。前三码用于几何前缀，第四色为解冲突计数器；跨模型整数码号没有共同语义。

## 7. 假设分级与下一步

| 假设 | 判断 | 依据/反例 |
|---|---|---|
| 退化来自总体更偏欧氏 | **不支持这种均值解释** | 受损目标欧氏权重反而下降，改善也下降；调整后关联未显著 |
| 曲率保真不足单独解释退化 | **未识别** | 同一common metric下改善目标MAE恶化更多，条件关联未过校正 |
| 真实行为邻居前缀关系下降与退化关联 | **观察关联** | 组间差异和含混杂控制的L1保持系数均支持；不是因果证明 |
| 语义重建下降单独解释退化 | **未识别** | 退化/改善都变差；条件关联未显著 |
| SID冲突/非法解码是主要原因 | **保存输出不支持** | 选中decode合法，退化中仅1例覆盖目标L3；原被过滤beam未知 |
| T5内部prefix pruning/概率或精确后续排序导致 | **未识别** | 没有完整轨迹/概率，不能从final rank反推 |
| 混合曲率更适合、不同graphlet必须不同几何 | **未测试/未建立** | 同时改变专家数、监督度量、执行实现、训练轨迹及派生词表，且类型分层几乎全chain |

**只建议一个下一轮修改：在一级分配代价内加入训练可见转移邻域的几何前缀保持项。** 保留三专家门控/固定监督与完整训练配方，使用同一个mixed distance把候选L1码字与冻结训练图邻居的L1表示联系起来，而非另加不相干后缀或事后修SID；保留框架分配规则。仅用训练划分确定归一化/权重，冻结规格后执行一次完整候选，不用本次错误商品清单、test派生关系或成绩调参。不在本issue创建/启动它。

可证伪预测：真实训练边L1保持度先提高，最终相同测试总体的配对R@10相对现有#253改善；若保持度提高却R@10未改善，则“前缀保持项能修复性能”的提议被否定。采用仍需独立满足仓库>0.065标准。风险是邻居拉拢增加碰撞/抹平可分性，必须记录；本次条件关联不保证该干预有效。
