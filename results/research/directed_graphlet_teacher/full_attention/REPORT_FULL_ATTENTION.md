# 全连接注意力结构识别：A–E 五组对照

**问题**：在可信的结构识别模型上，先确认"知道真实连接时能识别结构"，再判断"不给真实连接、
只给 Embedding 时能恢复多少"，最后看量化前后（`z` 与 `q`）的差异。

## 1. 模型与协议

| 项 | 内容 |
|---|---|
| 样本 | `directed_graphlet_role/instances.npz` 的真实实例；**3 节点与 4 节点分别训练/评估**，宽度不再暴露家族 |
| 输入 | 成员 Embedding（A=768 语义，B=`z` 32，C=`q` 32），**全连接注意力**，没有 KNN、没有真实邻接（E 组除外） |
| 答案 | 全局 family（5 类）、全局 subtype（47 类）、全局 orbit（376 类），来自 `directed_role.instance_targets` |
| 划分 | 实例池 split 0 训练 / split 1 留出，再丢弃"任一成员出现在训练集"的留出行；**丢弃数见 `labels`** |
| 模型 | 2 层 4 头 Transformer，HIDDEN=128，三头联合损失，150 epoch，**单一 seed** |
| 每族 | 训练 8000 / 留出 3000 条实例 |

## 2. 结果（3 节点：P3 + K3）

| 组 | family 准确率 / Macro-F1 | subtype 准确率 / Macro-F1（多数类 0.542） | orbit 准确率 / Macro-F1 |
|---|---|---|---|
| A 语义 768 | 0.713 / 0.711 | 0.380 / 0.083 | 0.136 / 0.032 |
| B `z` 32 | **0.827 / 0.826** | 0.450 / 0.114 | 0.173 / 0.062 |
| C `q` 32 | **0.829 / 0.828** | 0.450 / 0.114 | 0.174 / 0.062 |
| D 打乱标签 | 0.648 / 0.645 | 0.281 / 0.037 | 0.084 / 0.018 |
| E 真实邻接 + `z` | **0.844 / 0.844** | **0.523 / 0.265** | **0.360 / 0.206** |

## 3. 结果（4 节点：C4 + P4 + K1_3）

| 组 | family 准确率 / Macro-F1 | subtype 准确率 / Macro-F1（多数类 0.363） | orbit 准确率 / Macro-F1 |
|---|---|---|---|
| A 语义 768 | 0.528 / 0.527 | 0.181 / 0.031 | 0.073 / 0.005 |
| B `z` 32 | 0.664 / 0.661 | 0.231 / 0.047 | 0.085 / 0.017 |
| C `q` 32 | 0.664 / 0.661 | 0.232 / 0.051 | 0.085 / 0.016 |
| D 打乱标签 | 0.413 / 0.389 | 0.188 / 0.019 | 0.066 / 0.002 |
| E 真实邻接 + `z` | 0.673 / 0.668 | 0.304 / 0.119 | 0.188 / 0.071 |

## 4. 读数（按预设的四分支）

1. **E 组证明模型能识别结构**：给真实有向邻接后，3 节点 subtype Macro-F1 从 0.114 升到 **0.265**、
   orbit Macro-F1 从 0.062 升到 **0.206**；4 节点同样三倍以上提升。模型本身不是瓶颈所在的那一端。
2. **B 与 C 几乎相同**（3 节点 0.827 vs 0.829、subtype 0.450 vs 0.450、orbit F1 0.062 vs 0.062；
   4 节点 0.664 vs 0.664）：**量化前后在这些任务上持平**，即 z→q 没有可测的损失。
3. **Embedding 侧仍有明显缺口**：不给邻接时 subtype Macro-F1 只有 E 的 43%（0.114/0.265），
   orbit 只有 30%（0.062/0.206）。按预设分支，这属于"当前 Embedding 缺乏足够结构预测信息"，
   而不是"模型不行"（E 组已排除）。
4. **打乱标签对照现在真的有效**：D 组 family 0.648（3 节点）与 0.413（4 节点）明显低于 B/C 的
   0.83 / 0.66，说明真实标签提供了可学习信号。上一版对照之所以与真实运行一模一样，是因为
   标签**在宽度组内**置换，而宽度可分的任务对该置换不变——这一版改为跨整体训练集置换。
5. subtype 与 orbit 的**准确率都低于多数类基线**（0.450 vs 0.542；0.231 vs 0.363），只有 Macro-F1
   能反映"有一定判别但覆盖不到多数类"；这与 47 类 / 376 类的极不平衡一致。

## 5. 结论

- 结构识别模型**可用**：有真实邻接时 family/subtype/orbit 都达到可测水平；
- **量化前后（z vs q）没有测到结构损失**；
- **不给邻接时，Embedding 对 subtype/orbit 的信息量只有上限的三到四成**——这是当前真正的瓶颈，
  下一步应针对"Embedding 缺少结构信息"（例如加入结构监督或改善表示），而不是继续改量化。
