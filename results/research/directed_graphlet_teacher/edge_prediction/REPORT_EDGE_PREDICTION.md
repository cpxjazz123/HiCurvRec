# 增强后的 768 维状态能否预测具体有向边：四状态对照

## 判据（先写后测）

只有 **D（有向 GNN 增强）同时优于 A（原始语义）、B（无向增强）、C（随机方向增强）**
在 ROC-AUC、AP、Direction Accuracy 三项上，才算"注入了可利用的方向信息"，才进入 RQ-VAE。

## 设置

| 项 | 内容 |
|---|---|
| 输入 | 四个 768 维状态：A 原始语义 / B 无向增强 / C 随机方向增强 / D 有向增强 |
| 预测头 | `P(A→B)=σ(f_s(x_A)·f_t(x_B))`，两个 64 维投影，**四状态完全相同** |
| 训练三元组 | 60,000 真实边（1）、其反向（0，困难负样本）、度数匹配无关联对（0） |
| 隔离 | 留出边不参与消息传递/监督/负采样；评估对与训练对不重合 |
| 评估 | 8,000 条留出单向边 + 8,000 个无关联对 + 每条正样本的反向 |
| 噪声 | direction 的 SE ≈ 0.0056 |

## 结果

| 状态 | ROC-AUC | AP | Direction | 正样本均值 | 反向均值 | 无关联均值 |
|---|---|---|---|---|---|---|
| A 原始语义 | 0.7196 | 0.7009 | **0.5465** | 0.358 | 0.354 | 0.294 |
| B 无向增强 | 0.7828 | 0.7352 | 0.4815 | 0.334 | 0.348 | 0.118 |
| C 随机方向增强 | **0.8052** | **0.7663** | 0.4918 | 0.357 | 0.364 | 0.127 |
| D 有向增强 | 0.7842 | 0.7408 | **0.4794** | 0.335 | 0.348 | 0.117 |

σ 读数：`D − A`（direction）= **−12.0σ**；`D − C` = **−2.2σ**。

## 读数

1. **判据不通过，且方向是"更差"而不是"没变"**：D 的 direction 0.4794 **低于随机**，
   也低于原始语义 0.5465（−12σ）。同时 D 在 AUC/AP 上不优于 B（0.7842 vs 0.7828）与
   C（0.8052）。
2. **增强买到的是"是否相关"，不是"方向"**：三种增强把无关联对的分数从 0.294 压到 0.117–0.127
   （AUC 从 0.72 升到 0.78–0.81），但正样本与反向样本的分数几乎相同（0.335 vs 0.348），
   方向差异被抹平。
3. **原始语义反而保留了最多方向信息**（0.5465），这与"增强会稀释方向"的假设一致。
4. 头只在"存在边"上可分，说明困难负样本确实阻止了模型用"相关"蒙对——它现在诚实地显示
   方向信息不存在。

## 结论

- **按你的判据，D 未通过**：不同时优于 A/B/C，因此**不进入 RQ-VAE**，也不做
  768 → z → q → SID 的逐级对照；
- 这是本轮最干净的一次否定：四个状态、同一预测头、同一预算、困难负样本就位、
  留出边完全隔离；
- 方向信息在**商品级静态语义**里本就微弱（0.547），而当前的图增强（无论无向、随机方向
  还是有向）都会把它冲掉。继续在这条线上加模块，只会得到更漂亮的 AUC 和更差的方向。

## 下一步（建议）

要么换信息源（用户行为序列的时间先后，静态 embedding 里没有），要么承认
"商品级有向边预测"不是合适的中介任务，回到主目标（Stage3 `test_R@10`）用可检验的
SID 结构做评估。当前不建议再往 RQ-VAE 注入任何结构损失。
