# 有向邻接重建：先预测两条商品之间的边，再用确定性规则算 Graphlet / Orbit

**问题**：把"预测 376 种 Orbit"换成"预测每一对成员之间的有向边"，再交给仓库里既有的
`directed_graphlets.classify` 推出 Graphlet 家族与每个成员的 Orbit——量化前后各损失多少？

## 1. 设置

| 项 | 内容 |
|---|---|
| 样本 | 宽度 3 的实例（P3 + K3），每族 split 0 训练、split 1 留出 |
| 输入 | 成员向量（A=768 语义、B=`z`、C=`q`）**外加一个行为度特征**（按最大度归一化；无它时模型只学到"两端都热门就连边"） |
| 预测 | 每一对**有序**成员一个 logit，共 3×3（对角不计）；BCE 监督来自真实训练图的边 |
| 从不提供 | 真实邻接矩阵作为输入 |
| 切分 | 60,000 训练 / 6,000 留出；留出还要求不与训练实例共享商品——**本规模下丢弃 116,252 行后不足 500，回退为实例隔离**，记录在 `labels.isolation` |
| 阈值 | **在训练划分上按边 F1 选择**，留出只做报告 |
| 对手 | 度数基线：两端度数都过同一阈值就预测连边 |
| 模型 | 2 层 4 头 Transformer + 对头（每对 (u, v, u*v)），60 epoch，单一种子 |

## 2. 结果（留出 6,000 条，阈值在训练上选）

| 组 | 边 F1 | 邻接完全一致 | 可被 classify 的比例 | family 准确率 | Orbit 准确率 |
|---|---|---|---|---|---|
| A 语义 768 | 0.000 | 0.146 | 0.000 | 0.580（全猜空图） | 0.000 |
| **B `z`** | **0.140** | 0.131 | 0.056 | 0.580 | **0.338** |
| **C `q`** | **0.140** | 0.130 | 0.057 | 0.581 | **0.325** |
| 度数基线 | 0.097 | 0.142 | — | — | — |

（邻接完全一致的 0.146 是"一条边都不预测"时的水平，因为 14.6% 的留出实例确实没有观察到的边。）

## 3. 读数

1. **重建几乎不成立**：边 F1 0.140 只比度数基线 0.097 高 0.043；只有 5.6% 的留出子图能重建出
   一个可分类的结构，其余预测矩阵在 `classify` 下返回 None。
2. **"family 0.58"不能读**：那是全猜空图得到的水平；真正从重建推出的 family 只在 5.6% 的样本上存在。
3. **Orbit 0.338 的样本基础只有约 267 个位置**，置信区间很宽，不能作为"结构被恢复"的证据。
4. **z 与 q 再次持平**（边 F1 同为 0.140，Orbit 0.338 vs 0.325）：量化没有测到损失，但任务本身也没做成。
5. **语义几乎不产生任何边**（F1 0.000）：768 维语义里没有可用的连接线索，与前面几轮一致。

## 4. 结论与下一步

- 有向边重建**当前不可用**：5.6% 的可分类率无法支撑任何下游结构监督；
- 瓶颈与上一轮相同——**表示里缺结构信息**，而不是"376 类太多"（换成 6 个二分类仍然失败）；
- 若要继续这条路：先让"每对成员的边概率"在训练集上达到可用水平（例如把行为度作为显式特征
  并允许对称性/传递性约束），再谈接入；**本轮不修改 RQ-VAE**。
