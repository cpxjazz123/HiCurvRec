# 有向邻接重建（v2，标签改为完整行为图）

## 撤回 v1

v1 用 `message_edges`（行为图**去掉被遮蔽的边**之后的消息图）造标签。后果是：
本来标成 P3 的实例，它的中间那条边可能就在被遮蔽的集合里，经过 `classify` 之后不是 P3、
甚至是一条边都没有的空图。**训练目标与被问的问题不是同一件事**，所以 v1 的
边 F1 0.140、可分类率 5.6%、以及"family 0.58"全部作废（后者本来就是空图水平）。

## v2 的修正

| 审阅指出的问题 | 处理 |
|---|---|
| 标签来自 `message_edges` | 改用**完整**行为图 `behavior_graph_directed/graph.npz`（323633 条有向边）；训练前断言每个实例的完整邻接经 `classify` 都能还原其家族（五族抽样各 500 条全过，脚本内置该断言） |
| BCE 含对角线 | 对角线从损失中去除（mask 广播到 batch） |
| 度数基线只用源节点 | 改为**两端度数之积**，阈值同样在训练集上选 |
| 额外输入真实度数 | 移除；模型只读商品表示 |
| 比局部 Orbit 编号 | 用 `directed_role.instance_targets` 的**全局** Orbit id |
| 只在可分类样本上算 Orbit | 全部留出实例计分，**不可分类记错** |
| 只有 3 节点 | 3 节点与 4 节点分别训练与评估 |

## 读数

1. **修正标签后边预测明显变强**：3 节点 0.554、4 节点 0.389（v1 为 0.14），双端度数基线只有 0.001–0.002。
   说明 v1 的低分确实主要来自错标；但把训练池放大 3.3 倍只带来 +0.014（4 节点），**不是样本量问题**。
2. **但结构重建仍未做成**：邻接完全一致率≈0，Orbit 仅 0.04（3 节点）/ 0.00（4 节点）。
3. **语义在 3 节点上把边全点亮**（召回 1.000、精确率 0.383），是"全预测有边"的退化行为；
   `z`/`q` 是 0.40 / 0.91，同样远不足以还原结构。4 节点上语义退化到召回 0.272，z/q 为 0.34/0.44。
4. **z 与 `q` 全程持平**（3 节点 0.554 vs 0.553；4 节点 0.375 vs 0.376），量化依旧没有测到损失。
5. 商品级隔离在两种宽度下分别丢弃 116252 / 127273 行，均回退为实例隔离，记录在 `labels`。
