# Directed RRWP：多阶有向拓扑是否携带被 Embedding 丢掉的方向

**问题**：一步邻接在留出边上必然为零，但**两跳路径**可以提供"方向证据"。Directed RRWP
（相对随机游走概率）是否真的能预测留出边的方向？

## 实现

| 项 | 内容 |
|---|---|
| 转移矩阵 | `P = D_out⁻¹A`、`P² = P·P`，**只用训练边**构建 |
| 特征 | `[P[a,b], P[b,a], P²[a,b], P²[b,a], log(1+out_deg a), log(1+out_deg b)]` |
| 样本 | 30,709 条留出单向边，正反两个顺序各一条（正反均衡） |
| 探针 | 按商品隔离（训练对与评估对无共同商品）、固定初始化，5,514 对评估，SE ≈ 0.0067 |
| 注意 | 一步特征对留出边本身为零；能回答问题的只有两跳 |

## 结果

| 输入 | 方向准确率 |
|---|---|
| 语义 768 | 0.4971 |
| 语义 + RRWP | 0.5042 |
| z（32 维） | 0.5071 |
| **z + RRWP** | **0.5230** |
| 仅 RRWP（零向量 + 6 维特征） | **0.5141** |

## 读数

1. **RRWP 本身携带方向**：零输入 + 6 维 RRWP 特征就有 **0.5141（约 2.1σ）**。
   这是本轮第一个**不与图上下文混淆**的方向信号——它来自两跳路径的**有向**计数，而不是
   节点度数或邻域平均。
2. **叠加到 z 上有增益**：0.5071 → **0.5230（+0.0159，约 2.4σ）**；叠加到语义上为 0.4971 → 0.5042（1.1σ）。
   说明 RRWP 提供的是 z 里没有的那部分信息。
3. **幅度仍然小**（0.52），单次运行、2 个标准误左右，不能宣称"解决了方向问题"。

## 结论与下一步

- **Directed RRWP 是当前最有依据的方向特征**：它可独立预测方向，且能与 z 互补；
- 下一步建议按你的路线：把 RRWP 作为**候选子图内的注意力偏置**喂给结构预测器
  （而不是只做节点对特征），检验它能否提升 3/4 节点子图的 family / subtype / Orbit；
- 在此之前不做 RQ-VAE 改动：RRWP 是"可注入的额外输入"，而注入效果要先在结构预测器上被证明。
