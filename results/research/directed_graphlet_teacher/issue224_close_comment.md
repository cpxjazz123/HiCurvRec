## 结项:关系蒸馏接口已实现;但冻结 Teacher 的节点关系不是商品属性,四条独立测量一致否定

按你的方案实现了"跳过 Student 分类器、用 Teacher 节点表示的关系分布直接监督量化器",并先做了
你点名的那个风险检查。**结论是那个风险成立**:目标依赖实例邻接,固定 SID 匹配不到它。

### 1. 方法(已实现,9 项测试)

```text
h_T = Teacher(items, adjacency)        (B,k,128)  no_grad
P_T(i,j)=softmax_j(cos(h_Ti,h_Tj)/τ)   τ=0.1
P_Q(i,j)=softmax_j(cos(q_i ,q_j )/τ)   q 来自真实三层量化器
L_rel = mean_i KL(P_T(i,·) ‖ P_Q(i,·)) 反向经 q_st → 编码器 + 三层码本
```

维度不必一致(128 vs 32)。测试覆盖:行归一、对角线、**KL 方向**(写反会被抓)、置换不变、
目标无梯度、编码器与三层码本都收到非零梯度、邻接对照、单节点拒绝。

### 2. 先行检查:Teacher 状态是不是商品的属性(`relation_stability.json`)

| 量 | 数值 |
|---|---|
| 同一商品**跨实例**余弦相似度 | 均值 **0.4507**(中位 0.4518,p10 0.3709,p90 0.6163) |
| 同一实例内**不同商品**余弦相似度 | 均值 **0.4432**(中位 0.3870,p10 0.0436,p90 0.9904) |
| 768 维 Embedding → Teacher 状态线性探针 | held-out **R² = −4.09** |

同一个商品在两个子图里的 Teacher 状态,和两个不同商品的状态一样相似。

### 4. 这个 0.24 算不算学到东西(`relation_reference.json`)

| 参考 | KL ↓ |
|---|---:|
| **均匀分布**(什么都不知道的最优常数解) | **0.2216** |
| k-means 初始化后的 q(第 0 步) | 0.5065 |
| 打乱实例的 q(有正确边缘、无实例结构) | 0.4865 |
| 目标熵 H(P_T) | 0.4716 |

**没有一个臂超过均匀基线**:最好的 0.2237 只是逼近 0.2216。0.286→0.24 是模型漂向均匀,不是学到了关系。

### 5. 上限:只读商品 Embedding 能不能预测这个目标(`relation_ceiling.json`)

线性读出(768·k → k²,零初始化,3000 步)直接拟合教师关系:训练 KL **0.0016**(记住),
held-out KL **0.6658**,比"均匀"的 0.2216 差三倍 —— 典型过拟合,目标在商品 Embedding 里没有可泛化结构。

### 6. 判定

- **不是损失的问题,是目标的问题**:跨实例稳定性、Embedding 探针、教师 vs 打乱对照、held-out 上限,
  四项独立证据指向同一结论。这与 #222(只能转移无向骨架)和 #223(放大权重就坍缩)互相印证。
- 没有启动 Stage2/Stage3。要继续,必须改**目标**而不是改**损失**:只蒸馏跨实例稳定的关系子集
  (要先定义"稳定",且可能为空),或者把 Teacher 的输入本身换成商品级表示(那时它就不再是结构 Teacher)。
