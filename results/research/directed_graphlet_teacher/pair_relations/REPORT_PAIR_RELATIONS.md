# 第一阶段：两两商品之间的行为关系（0/1/2/3 四分类）

**问题**：只看两个商品的向量，能否判断它们之间**没有边 / A→B / B→A / 双向**？

## 1. 设置

| 项 | 内容 |
|---|---|
| 标签 | 完整行为图 `behavior_graph_directed/graph.npz` |
| 类别 | 0 无边、1 A→B、2 B→A、3 双向 |
| 特征 | `[u, v, u*v, |u−v|]`——交换两个商品会把类 1 与类 2 对调，方向敏感头至少要有这个最小结构 |
| 负样本 | 每个正样本配 2 个：**一半是度数匹配**（同度数分位的随机商品对），一半均匀随机 |
| 对照 | 768 语义 / z / q / **随机向量** / **全零向量** |
| 规模 | 训练 300,000 对、留出 30,000 对、6000 步 × 512 |
| 隔离 | 商品级：留出对不得复用任何训练商品 |

## 2. 结果（留出 30,000 对）

| 输入 | 准确率 | Macro-F1 | 类 0 召回 | 类 1 召回 | 类 3 召回 | 交换一致性 |
|---|---|---|---|---|---|---|
| 语义 768 | 0.683 | 0.372 | 0.922 | 0.223 | 0.000 | 0.747 |
| **z** | **0.720** | **0.489** | 0.931 | 0.310 | 0.135 | 0.680 |
| **q** | **0.719** | **0.486** | 0.931 | 0.307 | 0.131 | 0.683 |
| 随机向量 | 0.618 | 0.280 | 0.906 | 0.049 | 0.000 | 0.911 |
| 全零向量 | 0.665 | 0.266 | 1.000 | 0.000 | 0.000 | 1.000 |

## 3. 读数

1. **看 Macro-F1，不看准确率**：留出集里 66% 是无边（负样本 2:1），全猜"无边"就有 0.665 准确率
   （全零向量行验证了这一点：acc 0.665、每类召回中类 1/3 全为 0）。因此准确率**不能**作为证据。
2. **z 与 q 优于对照**：Macro-F1 0.489 / 0.486 对随机 0.280、全零 0.266；
   类 0 召回 0.93、类 1 召回 0.31、类 3 召回 0.13 —— **方向与双向确实被部分识别出来**。
3. **z 与 q 几乎相同**（0.489 vs 0.486，各类召回差 ≤0.004）：量化在这一步没有可测损失。
4. **语义弱于 z/q**（0.372）：行为关系更多编码在行为训练过的空间里。
5. **交换一致性**：语义 0.747、z 0.680、q 0.683，**低于随机向量 0.911**。
   随机向量的一致性高是因为它几乎只输出类 0（交换后仍是 0），并非真的方向一致；
   真实表示的一致性下降，反映它在方向类上有输出但交换后不一定对调。这一项要结合 Macro-F1 一起读。

## 4. 未达成的门（必须写明）

**商品级隔离没有真正实现**：留出 30,000 对中有 **19,129 对复用了训练商品**
（`labels.held_pairs_reusing_train_items`）。原因是正样本要求两端都落在留出的 20% 商品里，
本目录只有 24,587 个商品，这样筛出的正样本太少，配对构造回退到了全局样本池。
因此上表的绝对数值**带有记忆效应**，只能作为"有信号"的下界证据，不能作为精确能力值。

## 5. 结论与下一阶段准入

- 方向关系**是可学的**：z/q 的 Macro-F1 约为随机对照的 1.75 倍，方向类召回非零；
- 但**比例尺未定**：商品级隔离未达成，且负样本分布（2:1、一半匹配度数）会显著影响数值；
- 按三阶段计划，只有当我们能在**严格隔离**下复现"z/q 明显优于随机与全零"，才进入第二阶段
  （GraphRNN 联合预测子图），否则先把隔离与采样做好；
- RQ-VAE 仍未修改。
