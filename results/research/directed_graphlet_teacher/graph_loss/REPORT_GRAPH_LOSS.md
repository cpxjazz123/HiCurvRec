# 用真实邻接矩阵监督 q：`L = L_RQVAE + λ·L_graph`

## 设计

| 项 | 内容 |
|---|---|
| 目标 | `Â = σ(Q W Qᵀ)`，`W ∈ ℝ³²ˣ³²` 可学习、天然非对称 |
| 损失 | 加权 BCE，屏蔽对角线与被留出边；真实边与**其反向非边**权重 1，普通负边 0.1 |
| Batch | 种子商品 + 其 3 个出邻居，512 个商品/批；共 1000 步 |
| λ | 由编码器梯度范数比在第一步标定：B 3.1e-2、C 2.0e-2、D 2.1e-2 |
| 码本 | **冻结**（只更新编码器 + `W`） |
| 评估 | 留出方向探针（含空对照）、邻居 recall@5、SID 碰撞率、语义探针 R² |

## 结果

| 臂 | 方向探针 | 空对照 | recall@5 | **SID 碰撞率** | 语义 R² |
|---|---|---|---|---|---|
| A 无图损失 | 0.4953 | 0.5024 | 0.0015 | **0.1304** | 0.266 |
| B 无向邻接 | 0.4978 | 0.4996 | 0.0030 | **0.8267** | 0.132 |
| C 随机方向邻接 | 0.5074 | 0.4873 | 0.0050 | **0.9144** | 0.159 |
| D 真实有向邻接 | 0.5089 | 0.4900 | 0.0065 | **0.8751** | 0.172 |

## 读数

1. **三个图损失臂把码本打崩**：SID 碰撞率 0.83–0.91，基线 0.13。按仓库既有规则（§89，
   Stage3 入场要求碰撞率 < 0.10），**这三组 SID 连 Stage3 的门都进不去**。
2. **语义也被破坏**：q 的语义探针 R² 从 0.266 掉到 0.13–0.17。
3. **方向没有改善**：0.4953 → 0.5089，且空对照在 0.49–0.50，差值仍在噪声内。
4. **λ 标定不足以约束后续**：梯度比只在第一步匹配，图项的 loss 值（≈0.6）远大于
   RQ-VAE 项（≈3e-4），随着训练推进辅助项持续主导。这是本轮最关键的技术教训。
5. 三个图臂之间（无向 / 随机方向 / 有向）**没有可分辨差异**：碰撞率 0.83/0.91/0.88、
   方向 0.498/0.507/0.509，全部落在噪声与非功能区间。

## 结论

- **按当前形式不能采用**：它破坏了 SID 的可用性（碰撞率超门槛 8 倍），且没有带来方向；
- 若要继续这条路，必须先解决**优化器层面的支配问题**（例如把图项梯度裁剪到 RQ-VAE 项的
  固定比例、或按 loss 值比例动态设 λ），并把 **SID 碰撞率作为硬门槛**纳入每次评估；
- 在碰撞率回到 < 0.10 之前，不应该用任何图损失臂的 SID 去做 Stage3。
