# 降低结构监督强度：不够，且说明了强度该按什么尺度定义

## 1. 设置

不改损失公式、不改正负样本，只降强度：L1 结构代价权重 0.10 → **0.01**，
L2 梯度预算 40% → **10%**。其余全部不变（按商品 ID 取邻居、温度标定 L2、守卫全开、
同一 batch 序列、同一评估函数）。

新增一个直接测量"结构代价对码字选择影响"的指标：**`offset_changes_choice`**
= 在同一个 batch 上，比较"仅按距离取最近码字"与"距离+结构偏移后取最近码字"的选择差异比例。
（按你的提醒：不看 loss 数值，看它是否真的改变了选择。）

## 2. 结果

| 配置 | L1 权重 | L2 预算 | 链 Δ | L1 相邻/两端 | L2 相邻/两端 | 碰撞率 | 语义 R² | 改变选择比例 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 对照组（无结构） | – | – | +0.0018 | 0.0114 / 0.0098 | 0.0004 / 0.0003 | **0.0729** | 0.277 | – |
| 强监督 | 0.10 | 40% | +0.0686 | 0.1989 / 0.1962 | 0.0214 / 0.0139 | **0.5369** | 0.255 | –（未测） |
| **弱监督** | **0.01** | **10%** | **+0.0516** | 0.1622 / 0.1540 | 0.0149 / 0.0086 | **0.3519** | 0.280 | **50.3%** |

## 3. 读数

1. **强度降 10 倍，效果只降 25%**：链 Δ 0.0686 → 0.0516，碰撞 0.537 → 0.352。
   相对对照（0.0729），碰撞仍高 **4.8 倍**。
2. **原因被直接影响指标抓住**：即使 `align = 0.01`，结构偏移仍然改变了 **50.3%** 商品的
   码字选择。也就是说，"1% 的距离标准差"在实际决策里是**支配性**的。
3. **尺度选错了**：偏移按"该行距离的**散布**（std）"缩放，而选择由"最近与次近码字的
   **间隔**"决定；间隔通常远小于散布，因此按散布的 1% 依然能翻转一半商品。
   继续沿这条尺度调小（再降 10 倍）只会把影响变成零或保持跳变，得不到"温和区"。
4. **语义损伤与强度相关**：弱监督下语义 R² 回到 0.280（强监督 0.255），但碰撞仍 0.352
   —— 说明碰撞主要由 L1 的集中造成，不是语义漂移的副产物。

## 4. 结论

- **"监督过强"是问题的一部分，但当前强度参数的定义方式让它无法被调对**：按散布归一化的
  权重不是影响大小的度量。
- 正确的控制量应是 **`offset_changes_choice`**，目标区间取 **≤10%**（对照组为 0）。
- 尺度应改为按**局部间隔**：只在前两个候选码字的间隔内允许偏移生效，并把偏移裁剪到
  `β × gap`（β = 0.5）。这样偏移只能翻转本来就接近平手的商品，容量不会被牺牲。

## 5. 下一步（单一改动，可执行）

实现"间隔裁剪"的 L1 偏移：
1. 取每个商品距离最近的两个码字 `(k1, k2)` 与间隔 `gap = d(k2) − d(k1)`；
2. 只在这两个候选之间用 `clamp(offset(k2) − offset(k1), −β·gap, +β·gap)` 决定选择；
3. 目标：`offset_changes_choice` ≤ 10%；
4. 判据：碰撞率 ≤ 对照 0.0729，且链 Δ 显著高于对照 +0.0018。

若在该约束下链 Δ 仍不高于对照，则说明 L1 的"整体对齐"没有可用空间，应回到只保留 L2
的最小机制。
