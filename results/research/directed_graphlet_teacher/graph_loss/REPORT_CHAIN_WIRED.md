# 结构代价接入真实量化器（守卫全开）+ 统一口径复评

## 1. 按审查意见改的三件事

| 审查项 | 上一版 | 本版 |
|---|---|---|
| L1 是否进入真实量化器 | 另建一套 Sinkhorn 软分配，**没有接进 `model.rq`** | 包装 `VQLayer._distances`：L1 代价改为 `distance + offset`，在臂自己的 `constrained_assignment` **之前**生效 |
| 防坍缩保护 | `ASSIGNMENT_FLOOR` 被设为 0 | **保持原值**；`verify_separation`、`verify_margins` 全部照常运行 |
| L3 碰撞识别 | 软分配 `argmax`，且未去重商品 | 本次 L3 不施加损失；碰撞一律按**本步离散 tokens** 统计，评估时对商品去重 |
| 评估口径 | 对照组漏算 L3 | 统一为 **L1+L2+L3 累积共享**（`cumprod` 求和），对照组与机制组同一函数 |

`offset = −log(邻居当前 L1 码字频率)`，按行标准化后按 **`ALIGN = 0.1 × 该行距离标准差`** 缩放
（相对尺度，不靠试值）。

## 2. 结果（守卫全开，400 步，同一 batch 序列，同一评估函数）

| 指标 | 初始 | 接入对照组 | 结构接入组 |
|---|---:|---:|---:|
| 链 Δ（L1+L2+L3 累积） | −0.0008 | +0.0018 | +0.0022 |
| 置换零模型 95% 区间 | [−0.003, +0.003] | [−0.003, +0.003] | [−0.003, +0.004] |
| L1 相邻 / 两端 | 0.0076 / 0.0083 | 0.0114 / 0.0098 | 0.0119 / 0.0101 |
| 三码碰撞率 | 0.0253 | 0.0729 | 0.0705 |
| 语义 R² | 0.280 | 0.277 | 0.274 |

**结构接入组与对照组不可区分**（+0.0022 对 +0.0018，都在零模型内）。

## 3. 为什么接入后没有效果

- L2 的替代损失在接入组里是"把 L1、L2 的 softmax 概率按 `std` 归一化后算 margin"，
  其 hinge 全程停在 **0.5000003**（= margin 0.5），即软共享概率差 ≈ 0，梯度是噪声；
  梯度预算给到 `1.0`（远小于重构项）也没用，因为损失本身不下降。
- 反观**未接入**的单链 margin 原型：它用臂自己的 `measure_temperature` 归一化的
  `level_softmax`，同一个 400 步把离散链 Δ 推到 **+0.0258**（统一口径下对照为 +0.0018，
  约 14 倍差距）。差别在**软近似的温度归一化**，不在预算大小。
- 因此"接入后无效"不能归因于 L1 不可行；**当前接入组里真正起作用的 L2 近似被写钝了**。

## 4. 修正后的关键结论

1. **L1 结构监督仍未被否决**：本轮只是证明"用 `std` 归一化的 softmax + 直接加在距离上的
   offset"这组实现不产生可测变化，且它没有触发任何守卫——说明这条路径是**安全但惰性**的，
   而不是有害的。
2. **链式 margin 的作用仍然成立**：统一口径下，未接入组 +0.0258 对同预算对照 +0.0018。
3. **同预算对照必须包含在同一评估函数里**（已修正），碰撞率上升（0.025 → 0.07）是微调本身
   的属性，两组几乎相同（0.0705 对 0.0729）。

## 5. 下一步（最小改动）

把**已验证有效的** L2 软近似（`measure_temperature` + `level_softmax` + 平均共享 margin）
放进接入组，保留：
- 臂自己的 `constrained_assignment` 与 floor（守卫全开）；
- L1 的 offset 仍走 `_distances`（本轮已证明它安全）；
- 统一评估函数与同预算对照。

若该组合能把链 Δ 推到显著高于对照且碰撞率不高于对照，这才构成"分层结构监督可行"的第一份
证据；否则应回到"只保留 L2、不做 L1"的最小机制。
