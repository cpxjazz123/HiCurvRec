# L2 独立监督（去掉 L1 乘积）：信号变大但仍未超出噪声；"只取已共享 L1 的链"不可行

## 1. 你的更正成立

上一份报告说"margin 0.5 太大导致 hinge 未激活"是错的：当 `m = 0.5`、共享差 ≈ 0 时
`hinge ≈ 0.5`，**一直处于激活区**。本轮日志里 `l2_loss = 0.4985`，确认了这一点。
真正的削弱来自 `S₂ = S₁ · S₂` 的乘积：L1 共享概率只有 1e-3 量级，把 L2 的梯度也乘掉了。

## 2. 本轮改动

| 项 | 上一轮 | 本轮 |
|---|---|---|
| L2 统计量 | `S₂ = S₁ · ⟨p₂,p₂⟩`（含 L1 乘积） | **`S₂ = ⟨p₂,p₂⟩`，不含 L1 乘积** |
| L1 结构代价 | 无 | 无（保持） |
| Batch 商品去重 | 未实现（同 batch 内同一商品可出现多次） | **按商品 ID 去重**：前向只跑唯一商品（实测每步 626–646 / 768），链三元组重映射到该池 |
| L1 门控（"只取已共享 L1 的链"） | — | **测量后判定不可行**，见下 |

## 3. L1 门控不可行（先验证再实现）

| 统计（13,076 条训练链，冻结基线 SID） | 数量 | 比例 |
|---|---:|---:|
| 三个商品 L1 全相同 | **1** | 7.6e-5 |
| AB 与 BC 两对都共享 L1 | 1 | 7.6e-5 |
| 至少一对共享 L1 | 301 | 2.3% |

按 256 条链/批，期望合格链 **0.02 条/批**；实测日志中 `eligible_chains` 全程为 **0**。
因此"只监督已共享 L1 的商品"在当前 SID 上无法执行——除非先人为提高 L1 共享率，
而那正是 L1 结构代价做的事（代价是碰撞）。本轮保留该门控的**诊断记录**，损失改为在全部
链上用无乘积的 `S₂` 计算。

## 4. 结果（400 步，pair-disjoint，去重 batch，同 batch 序列）

| 组 | 链 Δ | 置换零模型 | L1 相邻/两端 | **L2 相邻/两端** | 碰撞率 | 语义 R² |
|---|---:|---|---:|---:|---:|---:|
| 控制（同协议，无结构） | +0.0004 | [−0.0060, +0.0041] | 0.0097 / 0.0092 | 0.0001 / 0.0003 | 0.0829 | 0.273 |
| **L2 独立（无乘积）** | +0.0032 | [−0.0051, +0.0053] | 0.0126 / 0.0100 | **0.0011 / 0.0005** | 0.0861 | 0.271 |

软共享（训练日志）：`s_ab` 0.0092–0.0125，`s_ac` 0.0089–0.0099；`l2_loss` 0.4985–0.4995；
梯度缩放 1.2e-4–3.7e-4。

## 5. 读数

1. **去掉乘积后信号确实变大**：链 Δ 从控制的 +0.0004 变成 +0.0032（+0.0028），
   L2 相邻−两端差从 −0.0002 变成 +0.0006。方向与假设一致。
2. **但仍未超出噪声**：Δ 的置换零模型半宽约 ±0.005，0.0032 落在区间内。
3. **碰撞基本不动**：0.0861 对 0.0829（+4%），远离此前带 L1 的 0.10–0.54。
4. **语义不变**：0.271 对 0.273。
5. **L1 门控不可执行**：见第 3 节，1/13,076。

## 6. 结论与下一步

- **L2 独立监督第一次出现方向正确、量级可比的位移**，但 400 步、10% 预算下还不足以
  与同预算控制区分。
- 由于门控不可行，"L2 只作用在已共享 L1 的商品上"这一形式在当前 SID 上无法验证；
  可行的最小形式就是本轮的无乘积 L2（全部链上计算）。
- 下一步：把这一个形式**延长到 2000 步**（其余不变，仍无 L1、预算 10%、去重 batch），
  看 +0.0028 的位移是否随训练累积；判据沿用：最终 Δ 高于同预算控制、L2 差值显著提高、
  碰撞 ≤ 1.5× 控制、语义 R² ≥ 95% 控制。
