# 分配层机制(§19h 允许的唯一剩余杠杆)— 设计与成本

## 为什么只剩这一条

| 已试路线 | 结果 | 失效原因 |
|---|---|---|
| L2 结构 hinge(链) | 召回 0.0561 ≤ 噪声 | 效果只落在 L2/L3,主指标在 L1 |
| 三结构叠加 | 判据 FAIL 2/5 | 固定预算被稀释 |
| 近对吸引(capacity) | 判据 3/4 FAIL | 需 9–25× 权重,落在坍缩区 |

三条路都在**分配之外**动手。§19h 明确允许的是:**把结构打分放进 Sinkhorn 的代价矩阵,均衡规则不变**。这是唯一会直接改变
第一层分区的杠杆,而第一层正是对齐指标 87% 的载体。

## 设计(最小可实现)

对第一层,在第 $t$ 步:

1. 由当前指派得到每个商品的码字索引 $k_i^{(t)}$;
2. 对商品 $i$,取其**结构近邻集** $\mathcal N(i)$(链:出边邻居;分叉/汇合:兄弟对),计算结构原型
   $$\pi_i=\frac1{|\mathcal N(i)|}\sum_{j\in\mathcal N(i)} e_{k_j^{(t)}}\quad(\text{detach})$$
3. 代价矩阵加一项结构偏移:
   $$D_{ik}\leftarrow D_{ik}+\alpha\,\lVert z_i-\pi_i\rVert_2-\alpha\,\lVert e_k-\pi_i\rVert_2$$
   即"离自己近邻当前所在码字越近的码字更便宜";$\alpha=0.25\times$ 该 batch 上 $D$ 的最近/次近间隔中位数(可推导,不试值);
4. Sinkhorn 照常(**均衡不变**),$k_i^{(t+1)}=\arg$ 自该代价的 Sinkhorn 指派。

预期效应(由第 25 节前沿推导):第一层按结构聚集 → 近对 L1 共享上升、碰撞从 0.152–0.170 升到 **0.18–0.22**,
链/汇合 Δ 上升 **+0.01…+0.03**,分叉可能下降。

## 成本与风险

1. **改模型 forward 签名**:`VQLayer.forward` 需要 `ids`(或一个 setter),训练器与 `get_indices`/导出路径都要传;会
   影响所有复用该文件的臂,因此必须**独立候选树 + 独立测试**(§32b 先红后绿,§73 每个故障一条回归)。
2. **STE 正确性**:原型是 detach 的常数,梯度只经 $z_i$ 与 $\exp(-D/\tau)$ 回传;须验证编码器收到梯度
   (§84 的 `encoder_gradient` 只对重构损失,仍需单独验证这一项不制造 NaN)。
3. **收敛风险**:自指原型可能振荡(指派 → 原型 → 指派);需要 1 个 epoch 级振荡检查(相邻 epoch 的指派变化率)。
4. **可比性**:碰撞与对齐口径不变,可与现有四臂直接比;但 optimizer step 会多两次 `cdist`(B×256),
   单 epoch 预计 +10–15%。

## 判定(若批准)

预注册:碰撞 0.18–0.22;**链与汇合 Δ ≥ 基线 **且** 分叉 ≥ 基线**才判"三结构同时更高";否则按权衡记录。
Stage3 仅在满足"三结构同时 ≥ 基线"时启动(§19 成功线 0.065 vs 基线 0.0555)。
