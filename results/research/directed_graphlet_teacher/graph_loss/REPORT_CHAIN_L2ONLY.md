# 只保留 L2 链式对比监督（取消 L1 结构代价）：碰撞回到基线，但对齐信号很弱

## 1. 设置

| 项 | 内容 |
|---|---|
| 结构 | 有向链 A→B→C，严格诱导 |
| 划分 | pair-disjoint（训练与评估不共享任何商品对）；batch 内无重复链；两臂同一 batch 序列 |
| 控制组 | 原始量化，无结构项 |
| 实验组 | **L1 不施加任何结构监督**；L2 用 `max(0, m + S₂(A,C) − (S₂(A,B)+S₂(B,C))/2)`，梯度预算 **10%** |
| 预算 | 400 步，种子 42，码本冻结，守卫全开 |
| 补充诊断 | 同一 L2-only 组在 40% 预算下再跑一次（**不属于预注册比较**，只用于判断"碰撞是否来自 L1"） |

## 2. 结果（400 步，离散 SID，评估链与训练链无共享商品对）

| 组 | 链 Δ | 置换零模型 | L1 相邻/两端 | **L2 相邻/两端** | 碰撞率 | 语义 R² |
|---|---:|---|---:|---:|---:|---:|
| A 原始 RQ-VAE（控制） | +0.0045 | [−0.0057, +0.0058] | 0.0126 / 0.0092 | 0.0011 / 0.0000 | 0.0754 | 0.271 |
| **B 仅 L2，10%** | +0.0035 | [−0.0057, +0.0068] | 0.0126 / 0.0097 | 0.0009 / 0.0003 | **0.0712** | 0.275 |
| 诊断：仅 L2，40% | +0.0071 | [−0.0055, +0.0059] | 0.0160 / 0.0092 | 0.0005 / 0.0003 | **0.0725** | 0.276 |

## 3. 判据

| 判据 | 10% 结果 | 40% 诊断 |
|---|---|---|
| 链 Δ 高于同预算基线 | ✗（0.0035 对 0.0045） | ✓（0.0071 对 0.0045，略高于零模型上界 0.0059） |
| L2 共享率差值明显提高 | ✗（0.0006 对 0.0011） | ✗（0.0002 对 0.0011） |
| 碰撞率接近基线 | ✓（0.0712 对 0.0754） | ✓（0.0725 对 0.0754） |
| 语义保留 | ✓（0.275 对 0.271） | ✓（0.276 对 0.271） |

## 4. 读数

1. **碰撞问题确实来自 L1**：取消 L1 结构代价后，即使 L2 预算提到 40%，碰撞仍是 0.0725，
   与控制组 0.0754 同水平（此前带 L1 的配置是 0.10–0.54）。你的判断成立。
2. **但 L2-only 的对齐信号很弱**：10% 预算下链 Δ 低于控制（0.0035 对 0.0045），与零模型不可区分；
   40% 预算下才略高于零模型上界（0.0071 对 0.0059），且只比控制高 0.0026。
3. **L2 专有指标没有提高**：三组的 L2 相邻−两端差值都在 0.0002–0.0011（控制自身就有 0.0011），
   即"前两层共享差"并没有被 margin 拉开。这说明当前的软近似（温度标定的 `level_softmax` +
   margin 0.5）在梯度预算内几乎不产生可测的 L2 结构，链 Δ 的微小变化更多来自训练噪声。
4. **语义与碰撞都不受影响**：L2-only 是安全的，但"安全但几乎无效"。

## 5. 结论

- **"碰撞由 L1 造成"已被证实**：去掉 L1 后碰撞回到基线。
- **"L2 单独就够"尚未成立**：在 400 步、10% 预算下没有可测效果；40% 时只有边缘信号，
  且 L2 专有指标没有改善。
- 因此当前的最小机制还差一步：需要让 **L2 的软共享概率真正可分辨**（现在三类对的软共享差
  都在 1e-3 量级，margin 0.5 从未接近饱和），否则无论预算多大，梯度都只是噪声。

## 6. 下一步（单一改动）

把 L2 的 margin 从 0.5 降到与当前软共享同量级的水平（例如取 **m = 该 batch 软共享差值的中位数**，
相对尺度、不试值），使 hinge 真正处于激活区；其余全部不变（无 L1、预算 10%、pair-disjoint、
同 batch 序列）。判据沿用本轮：链 Δ 高于控制、L2 差值显著提高、碰撞 ≤ 1.5× 控制、语义 R² ≥ 95% 控制。
