# 按 graphlet 结构设计监督规则 — 决策简报

## 问题

为不同 graphlet 结构(链 / 分叉 / 汇合 / 环)设计不同的监督规则,在 3000 epoch 完整训练后,
使**每个结构**的 SID 结构对齐量都高于基线。

## 答案(一句话)

**目标未达成**:在全量 60k 池上,链臂在链(−0.0036)与汇合(−0.0040)稳定低于基线,分叉仅 +0.0014 且符号不稳。
但在**同碰撞预算**下比较,规则的残差是链 **+0.0044**、汇合 **+0.0022**、分叉 **−0.0026**——即它确实
把链/汇合的形态区分度推到预测线上方,代价是分叉;而"三项同时 ≥ 基线"的可行窗口只有
**碰撞 ∈ [0.1507, 0.1804]**,本臂落在下沿(0.1522),余量 0.0015 小于池间噪声,故不可分辨。
**按结构叠加不可行**:三条规则共享同一份 10% 梯度预算,链规则边际收益(0.00897/份额)是分叉
(0.00328)的 2.7 倍,叠加把链的正残差抹成 −0.0026。

## 规则(按实测作用面,形式即实现)

| 结构 | 规则 | 作用层 |
|---|---|---|
| 链 | `max(0, m + S2(A,C) − [S2(A,B)+S2(B,C)]/2)` | 写 L2,效果经编码器落 L1/L3 |
| 分叉 | `max(0, m − S2(parent,child))`,只对共享 L1 的父子对 | 写 L2,落 L1;但同预算残差 **−0.0026**(L1 提升不跨池稳健) |
| 汇合 | 同分叉,权重 0.5 | L2/L3 改善但 L1 反向,净零 |
| 环 | `spread(S2(AB), S2(BC), S2(CA))` | 未训练 |

注入:`loss.backward()` 后把梯度加到 `mlp.weight.grad`,总预算 = 实测 RQ-VAE 梯度范数的 10%;
`S₂ = ⟨p₂,p₂⟩`(不含 L1 乘积)。

## 数字与它们的不确定性

| 结构 | 链臂 − 基线(种子 42 留出集) | **全量 60k 池,6 种子(均值/sd)** | 判读 |
|---|---:|---|---|
| 链 | +0.00144 | **−0.00364 / 0.00152** | 6/6 为负 |
| 分叉 | +0.00972 | **+0.00137 / 0.00260** | 符号不稳 |
| 汇合 | +0.00026 | **−0.00398 / 0.00236** | 6/6 为负 |

- 池间 sd 0.002–0.009 > 配对三元组抽样 CI(±0.005):**任何 <0.01 的对齐差不可解释**;
- 同配方重训方差未测(§19g 禁多种子),仓库无同配方重训对;
- 判据在固定池上预登记,结果照实记录(链臂 5/5 PASS、三结构臂 FAIL 2/5),但适用范围限于该池。

## 条件与可行性(为什么"没达成"不等于"不可能")

| 项 | 数值 |
|---|---|
| 链 Δ 的碰撞斜率 | +0.233(collision),r = +0.938 |
| 分叉 Δ 的碰撞斜率 | −0.343(collision),r = −0.955 |
| 汇合 Δ 的碰撞斜率 | +0.192(collision),r = +0.926 |
| 三项同时 ≥ 基线的碰撞窗口 | **c ∈ [0.1507, 0.1804]** |
| 本臂位置 | c = 0.1522(下沿,余量 0.0015) |

链/汇合与分叉在同一个"共享预算"上互斥:提高碰撞能买到链/汇合对齐,同时压低分叉。窗口宽度
(0.03)与余量(0.0015)均小于评估池噪声(0.002–0.009),所以观测无法落在显著区间内。
