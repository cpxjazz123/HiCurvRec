# 三层分别监督（L1 全局 / L2 局部 / L3 身份）：可行性与失败点

## 1. 设置

| 项 | 内容 |
|---|---|
| 结构 | 严格诱导的 A→B→C（有向训练图），60,000 条，60/40 划分 |
| 损失 | `L = L_RQVAE + L_global + L_local + L_unique` |
| `L_global` | 三种节点对**绝对**共享 L1 的对数损失 |
| `L_local` | 相邻对共享 L1+L2 的对数损失，减两端对共享 L1+L2 的项（软约束，不指定哪一对） |
| `L_unique` | 随机商品对的完整三码一致度（软碰撞代理） |
| 梯度预算 | 每项分别 ≤ 重构项实测梯度的 0.4 / 0.4 / 0.2 倍，每步测量 |
| 码本 | 冻结；400 步；评估一律用离散 SID |

## 2. 三次运行

| 变体 | L1 平均共享 | L1 AB / BC / AC | L2 gap | 三码碰撞率 | 语义 R² |
|---|---|---:|---:|---:|---:|
| 训练前 | 0.0078 | 0.0061 / 0.0091 / 0.0083 | −0.0001 | **0.0253** | 0.280 |
| ① 绝对全局 | 0.1860 | 0.2177 / 0.1874 / 0.1530 | +0.0081 | **0.6280** | 0.261 |
| ② 相对全局（margin 0.05） | 0.2675 | 0.3617 / 0.2429 / 0.1979 | +0.0204 | **0.5109** | 0.272 |
| ③ 相对全局 + L1 使用熵（预算 0.3） | 0.0577 | 0.1276 / 0.0254 / 0.0200 | +0.0071 | **0.1780** | 0.278 |
| 参考：上一轮单链 margin | — | — | 链 Δ +0.0258 | **0.0830** | 0.271 |

每一层在训练后仍使用全部 256 个码字，但**分布极度不均**——"用了几个码字"不是坍缩的判据，
碰撞率与使用分布才是。

## 3. 读数

1. **绝对 `L_global` 是最退化的一项**：它的最优解就是"所有商品共享一个 L1 码"。冻结码本下
   编码器把 L1 压到有效约 5 个码（两商品共享概率 0.186），三码碰撞率从 0.025 升到 **0.628**。
2. **把 `L_global` 改成相对形式（链路对共享 > 随机对共享 + 0.05）并没有解决**：坍缩时随机对
   也一起变高，margin 仍可满足，于是系统停在"整体很高、差距也够"的坍缩态（L1 0.268、碰撞 0.511）。
3. **加 L1 使用熵约束有效但不充分**：碰撞 0.511 → 0.178，语义 R² 恢复到 0.278，但仍比基线
   高 7 倍；L1 共享 0.058 仍偏高（AB 0.128）。
4. **上一轮的单一链式 margin 反而最好**：它只约束"相邻对共享 > 两端对"（结构内的对比），
   不要求任何绝对共享水平，所以没有坍缩的最优解——碰撞 0.083，链 Δ +0.0258。
5. **`L_unique` 太弱**：随机对的三码一致度在 256³ 空间里本来接近 0（对数 0.0000），梯度范数
   1e-4~1e-5，几乎不产生约束。它无法阻止前两层造成的坍缩。

## 4. 结论与修正建议

**"三层分别监督"这个方向需要改写两项约束：**

- `L_global` 不能是"提高共享概率"，它有无坍缩的最优解。要么放进 Sinkhorn 的**均衡分配**
  里（均衡本身就是容量约束，§19h），要么显式写成"共享程度与使用分布熵的联合约束"。
- `L_unique` 不能作为独立损失项（量级太小）；三码身份应由**碰撞率作为硬性诊断/门**承担，
  而不是由一个 1e-5 量级的梯度去维持。
- **可保留的是 `L_local` 的对比形式**：结构内相邻 vs 两端，这是上一轮唯一没有导致坍缩、
  且把离散指标推出零模型的项。

因此下一步实现应写成：L1 的对齐项进入 Sinkhorn 代价（均衡分配保留容量），L2 用结构内对比
margin，L3 只监控碰撞率并在超出阈值时报告，而不是叠加一个弱损失。
