# 邻接矩阵监督 v3：真正的屏蔽、自由的 W、统一 Batch 与 SID 结构保真

## 这三处修了什么

| 审查意见 | v2 的实际行为 | v3 |
|---|---|---|
| 测试边屏蔽无效 | 遍历 `out_table`（由训练边构成），留出边永远不在其中，**屏蔽分支从未触发**；它们只能作为普通负样本出现 | 屏蔽改为对**批内每一对**用完整图的留出集判定；采样器刻意把留出伙伴放进 batch，使屏蔽必须真实发生（实测每批约 **180.8 对**被排除） |
| W 的梯度被一起缩放 | `relation.grad = scale * grad` | `relation.grad = grad`，只有编码器受预算约束 |
| 随机方向对照每批重抽 | 每个 batch 重新随机定向 | 每条训练边**定向一次**并全程复用 |
| Batch 序列不同 | 各臂各自采样 | 所有臂**重放同一 Batch 序列** |
| 缺少 SID 结构保真评估 | 无 | 新增：在**量化后向量**上测留出边的方向准确率与存在性 AUC（负样本与原边同源，避免用度数作弊） |

## 结果（800 步，码本冻结，BATCH 512，方向探针 5,514 对，SE ≈ 0.0067）

| 臂 | 方向准确率 | 方向空对照 | 存在性 AUC | 存在性空对照 | SID 碰撞率 | 语义 R² | 被屏蔽对数/批 |
|---|---|---|---|---|---|---|---|
| A 无图损失 | 0.5004 | 0.5034 | 0.6788 | 0.6347 | 0.1048 | 0.261 | 0 |
| B 无向监督 | 0.5091 | 0.5015 | **0.7295** | 0.6632 | 0.1173 | 0.258 | 180.8 |
| C 随机方向 | 0.5036 | 0.4853 | 0.7005 | 0.6609 | 0.1208 | 0.261 | 180.8 |
| D 真实有向 | **0.5123** | 0.5082 | 0.6993 | 0.6472 | 0.1439 | 0.259 | 180.8 |

## 读数

1. **屏蔽现在是真的**：每批约 180.8 对留出边被排除；v2 是 0，也就是说 v2 的所有数字都建立在
   "留出边被当成负样本"的标签上，v3 的这批数字取代它们。
2. **W 自由后没有变好也没有变坏**：碰撞率 0.1439（D）、语义 0.259，与 v2 的 0.1558 / 0.257 同级。
3. **存在性 AUC 的提升不来自图监督**：基线 A 自己就有 0.6788（空对照 0.6347，+0.044）——
   这说明该探针测到的是**语义同质性**（同源负样本仍可由 q 的相似度区分），不是图损失引入的结构。
   B 的 0.7295 比 A 高 0.05，但这不是有向监督的证据，且 C（随机方向）0.7005 同样高于 A。
4. **方向仍然没有**：D 0.5123 对自身空对照 0.5082，差 +0.004（约 0.6σ）；C 0.5036、B 0.5091。
   四个臂与各自空对照的差都在 ±0.01 内，无法区分。
5. 若按现行的 Stage3 碰撞门槛（< 0.4），D 的 0.1439 现在可以通过；但那只是门槛放宽的结果，
   不是结构保真的证据。

## 结论

**实现层面的三个缺陷已全部修掉，机制本身仍未被证明。** 在"码本冻结 + 编码器梯度受限 + 800 步"
这个设定下，直接邻接矩阵监督没有让量化后的 SID 携带可读的方向信息（增益 ≤ 0.005，低于
单次运行的噪声）。

下一步只有两条路有意义：

- **加信号**：把方向信号做成对比目标（正序对 vs 反序对的 margin），而不是在 `qWqᵀ` 上用 BCE
  让 32×32 的 W 自己找方向；或把 W 的拟合与编码器更新拆成两步（先拟合 W 到收敛，再只回传
  编码器）；
- **换读出**：在融合状态上做方向判别（此前的实验中该探针稳定在 0.60–0.64），而不是要求 `q`
  单独承载方向。

在方向能被稳定读出（显著高于空对照）之前，不建议把这个机制推进到正式 Stage2。
