# 首个按设计跑完 3000 epoch 的臂：链对齐超过基线，且碰撞更低

## 1. 臂与机制

| 项 | 内容 |
|---|---|
| 臂 | `TIGER_chain_align_rq`（从冻结基线 `baseline/TIGER_RQ-VAE` 复制，只改 `ARM_NAME` + 机制文件） |
| 机制 | 严格诱导 A→B→C；`S₂ = ⟨p₂,p₂⟩`（无 L1 乘积）；`max(0, m + S₂(A,C) − (S₂(A,B)+S₂(B,C))/2)`，m = 0.5 |
| 接线 | loader 携带 item id；结构项梯度在 `loss.backward()` 之后单独注入，上限为**实测 RQ-VAE 梯度范数的 10%**；不进入报告 loss |
| 预算 | 3000 epoch、seed 42、单卡（全局 batch 4096）、码本参与训练（非冻结） |
| 冒烟 | MCP `SMOKE_PASS`（6 步、梯度范数 1.19e-3–1.83e-3、机制项在 trace 中） |

## 2. 结果（同一评估函数，pair-disjoint 留出集）

| 指标 | 基线 `TIGER_RQ-VAE` | `TIGER_chain_align_rq` | 判定 |
|---|---:|---:|---|
| **链 Δ（L1+L2+L3）** | +0.03807 | **+0.04151** | ✓ 高于基线 +0.0034 |
| 分叉 Δ | −0.06211 | −0.05249 | 负得少一些（仍为负） |
| 汇合 Δ | +0.03516 | +0.03529 | 持平 |
| **三码碰撞率** | 0.1693 | **0.1521** | ✓ 低于基线（不是用碰撞换来的） |
| 语义 R² | 0.041* | 0.403* | —（见下注） |

\* 基线的语义探针数值异常偏低（其 checkpoint 与 SID 表的对应关系历史上存在导出偏差），
因此这一列不用于判定；机制臂侧的 0.403 与离线原型的 0.27–0.28 同量级。

## 3. 逐层分解：增益来自哪里

| 臂 | Δ@L1 | Δ@L1L2 | Δ@L1L2L3 | 碰撞率 |
|---|---:|---:|---:|---:|
| 基线 | +0.03308 | +0.00381 | +0.00118 | 0.1693 |
| **L2 监督臂** | **+0.03544** | +0.00381 | **+0.00223** | **0.1521** |

- L1 增加 **+0.00236**（+7%），L3 累积增加 **+0.00105**，L2 层持平；
- 也就是说：**在 L2 上施加的对比监督，经完整训练后把收益转移到了 L1 与 L3**，而碰撞率反而下降。
  这与离线原型（冻结码本、400 步）里"只动 L2"的观察不同——码本可训练时，层的角色会重排。

## 4. 结论

1. **用户的目标达成**：完整 3000 epoch 后，链对齐从 +0.0381 提到 **+0.0415**，且碰撞率
   0.1693 → **0.1521**（低于基线），不是用碰撞换对齐。
2. **判据**（此前登记）：Δ > 基线 ✓；碰撞 ≤ 1.5× 基线 ✓（实际更低）；语义 R² 无法用基线
   判定，机制臂自身 0.403 属正常区间。
3. **分叉仍为负**（−0.052 对基线 −0.062）：路径式组织依旧，改变分叉需要独立规则（已写入
   设计文档 `DESIGN_PER_GRAPHLET.md` 第 5 节）。
4. **可进入 Stage3**：碰撞 0.1521 < 0.40 的入场门槛；按本轮机制"one run"纪律，
   该臂是当前唯一的正式候选。
