# 第一轮：只监督有向链 A→B→C，能否主动改变码字分布

## 1. 设置

| 项 | 内容 |
|---|---|
| 结构 | 有向训练图里**严格诱导**的 A→B→C（无反向边、无 A→C 捷径、B–C 不相邻） |
| 实例 | 60,000 条；按三元组哈希 60/40 划分 → 训练 36,009 / 评估 23,991 |
| 软统计量 | `S(u,v) = p1·p1 + p1p2·p1p2 + p1p2p3·p1p2p3`（期望共享的前导层数，0..3） |
| 损失 | `max(0, m + S(A,C) − (S(A,B)+S(B,C))/2)`，`m = 0.5` |
| 梯度预算 | 链项对编码器的梯度 ≤ 重构项实测梯度的 **0.5 倍**，每步测量并缩放 |
| 码本 | 冻结；只更新编码器 |
| 训练 | 400 步，每步 256 条链（768 个商品），AdamW 1e-3 |
| 评估 | 一律用**离散 SID**；零模型 = item→码字置换 200 次 |

## 2. 结果

| 指标 | 训练前 | 训练后 |
|---|---:|---:|
| 链 Δ = (S(A,B)+S(B,C))/2 − S(A,C) | **−0.00077** | **+0.02578** |
| 置换零模型 95% 区间 | [−0.00257, +0.00321] | [−0.00323, +0.00369] |
| 相邻对平均共享 | 0.00786 | **0.03533**（×4.5） |
| 两端对平均共享 | 0.00863 | 0.00955 |
| 逐实例排序成立比例 | 0.015 | 0.062 |
| 三码碰撞率 | 0.02534 | 0.08252 |
| 语义探针 R² | 0.27998 | 0.27099 |
| 软 hinge（训练批） | 0.4977 | 0.4860 |

## 3. 读数

1. **目标达成**：链 Δ 从 −0.0008（零模型内）变成 **+0.0258**，是零模型半宽的约 **7 倍**。
   变化来自相邻对的共享率（0.0079 → 0.0353），而两端对几乎不动（0.0086 → 0.0096）——
   说明不是"整体把码字挤在一起"，而是**按链的局部关系**移动了码字。
2. **没有强制"哪一对相邻共享 L2"**：损失只约束均值，训练后 A–B 与 B–C 的共享都上升，
   符合"前缀共享传递性无法强制指定某一对"的设计意图。
3. **代价与边界**：
   - 三码碰撞率 0.025 → 0.083（×3.3）。仍低于旧门槛 0.10 与新门槛 0.4，但这是必须持续监控的量；
   - 语义 R² 0.280 → 0.271（−0.009），轻微下降；
   - **逐实例排序成立比例只有 0.062**：这是均值位移，不是"每条链都满足"。要看 Stage3 才能
     判断这种均值位移是否有用。
4. **梯度预算**：链项梯度是重构项的 200–2000 倍（|g_chain| 0.30–1.13 对 |g_rq| 3–20e-4），
   每步缩放系数只有 3e-4~1e-3。软 hinge 本身只从 0.4977 降到 0.4860，但离散指标发生了
   4.5 倍变化——小步多次累积的效果，说明**不能**用 loss 数值判断机制是否起作用。

## 4. 结论

**可以。** 单一链式 margin 损失（无分叉/汇合、无邻接重建）足以把离散 SID 的链式共享结构
从"与随机置换不可区分"推到显著位置，且两端对保持不变。这验证了"通过统一损失主动改变
结构码字分布"这条路可行。

下一步（按 §19g 的纪律）：把这个损失以 `a_k(i) = −log Σ_{j∈R(i)} P[j→k]` 的形式接入
Sinkhorn 代价矩阵，跑**一次**正式 Stage2（seed=42、3000 epoch、冻结四卡配方），
由 Stage3 `test_R@10` 判定；不做消融、扫参、多种子。碰撞率与语义 R² 作为强制诊断一并记录。
