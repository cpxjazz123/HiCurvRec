# 邻接矩阵监督 v2：去重、严格屏蔽、分类均值与实测梯度预算

## 相对 v1 的修正

| 审查意见 | 处理 |
|---|---|
| Batch 内商品重复，导致真实边被错误标为负 | `np.unique` 先去重再建标签 |
| 测试边未真正屏蔽 | 任一端点涉及留出边的**两个方向**都从损失中排除（既不是正也不是负） |
| 负样本主导 | 正边 / 反向非边 / 普通非边各自求均值，权重 1 / 1 / 0.25 |
| 梯度只在第一步标定 | **每一步实测**图项梯度范数，并缩放到不超过 RQ-VAE 梯度的 **0.5 倍** |
| 用 loss 数值推断主导 | 改为记录实测 `|g_rq|`、`|g_graph|` 与缩放系数 |

## 结果（800 步，码本冻结，留出方向探针 5,514 对，SE ≈ 0.0067）

| 臂 | 方向探针 | 空对照 | SID 碰撞率 | 语义 R² |
|---|---|---|---|---|
| A 无图损失 | 0.4982 | 0.4964 | 0.1187 | 0.260 |
| B 无向邻接 | 0.5069 | 0.4975 | 0.1149 | 0.262 |
| C 随机方向邻接 | 0.5007 | 0.5004 | 0.1295 | 0.266 |
| D 真实有向邻接 | **0.5123** | 0.4956 | 0.1558 | 0.257 |

实测梯度：`|g_graph|` 0.26–0.97 对 `|g_rq|` 0.0004–0.0018，**比值约 200–2000 倍**，
因此缩放系数只有 0.001–0.005。

## 读数

1. **坍缩被治住了**：碰撞率从 v1 的 0.83–0.91 回到 0.115–0.156，语义 R² 保持 0.26。
   这说明 v1 的坍缩确实来自"图项梯度支配"，而不是邻接监督本身不可行。
2. **实测证实了主导关系**：图项梯度比 RQ-VAE 项大 200–2000 倍，仅靠第一步的 λ 标定
   完全无法约束；必须每步缩放。
3. **D 的碰撞率 0.1558 仍高于 Stage3 门槛 0.10**：这组 SID 目前仍不能进入 Stage 3，
   只是从"完全不可用"变成了"接近可用"。
4. **方向仍未确立**：D 0.5123 对空对照 0.4956（+0.017，约 1.7σ，单次运行），
   C（随机方向）0.5007 与 B（无向）0.5069 同量级；三臂之间无法区分。
5. 语义 R² 0.257–0.266，与基线持平：在梯度受限后，图监督不再伤害语义。

## 结论

- **方案未被否定**：修正实现后，邻接监督可以在不破坏 SID 与语义的前提下运行；
- **但也未被证实**：方向提升只有约 1.7σ，且随机方向对照同样在 0.50 附近；
- 下一步的最小充分实验：只跑 **A 与 D**，把碰撞率压回 < 0.10（更小的梯度份额或更长的
  RQ-VAE 预训练），并把方向探针的评估集扩大到约 15,000 对（SE ≈ 0.004）；
  只有在"碰撞 < 0.10 且 D 显著优于 A"同时成立时，这个机制才值得进入正式 Stage2。
