# 五个方向相关改进的对照（A–E）

**问题**：在双表示 DiGAE 上，逐个加入方向专用损失、边权重、注意力与角色特征，
哪些真正提升"方向可读性"？固定同一划分、seed、预算与探针。

## 设置

| 项 | 内容 |
|---|---|
| 基点 | 双表示传播（source 读出邻居的 target，反之亦然），融合被训练 |
| A | 仅 BCE（有向边存在性） |
| B | A + 方向排序损失 $-\\log\\sigma(s_A\\cdot t_B - s_B\\cdot t_A)$（只对单向后验成立的正样本） |
| C | B + **行为计数边权**（`weight` 列，均值 1.049） |
| D | C + **入/出邻居注意力**（对邻居做分段 softmax） |
| E | D + **角色特征**（`neighbour_family` 5 维比例拼到输入） |
| 评估 | 留出单向边上的方向探针（按商品隔离、固定初始化）、边头自身方向、SID 前不涉及量化 |

## 结果（探针 5,514 对，SE ≈ 0.0067）

| 臂 | 边头方向 | 融合位移 | 探针 | 相对 A |
|---|---|---|---|---|
| A 双表示 + BCE | 0.4676 | 0.0209 | 0.5078 | — |
| **B + 方向损失** | 0.4734 | 0.0249 | **0.5065** | **−0.19σ** |
| C + 边权重 | 0.4708 | 0.0254 | 0.5187 | +1.6σ |
| D + 注意力 | 0.4755 | 0.0215 | **0.5239** | +2.4σ |
| E + 角色特征 | 0.4733 | 0.0214 | 0.5199 | +1.8σ |

## 读数

1. **优先项 B 没有效果**：方向排序损失 0.5065，比不加（0.5078）还低 0.0013（−0.19σ）。
   边头自身方向也没动（0.4676 → 0.4734，仍在随机附近）。**这个最直接的改法失败了。**
2. **边权重几乎无法起作用**：`weight > 1` 的边只占 **3.2%**（10,458 / 323,633），
   均值 1.049、p99 = 2。C 相对 B 的 +0.012（1.6σ）不可能是"重复转移次数"带来的，
   更像训练噪声——这条路线在当前数据上**没有可用的信号源**。
3. **注意力与角色特征**分别 +2.4σ 与 +1.8σ，但探针绝对水平仍只有 0.52；
   且 D 与上一轮双表示（0.5259）几乎相同，说明提升来自"更多图上下文"，而非方向。
4. **边头自身方向所有臂都在 0.467–0.476**：没有任何一个变体让 `s·t` 分数本身可读方向。

## 结论

- 按预设顺序，**B（方向专用损失）未通过**，因此 C/D/E 的"叠加"缺少基础：
  在方向损失本身不产生可读方向的前提下，附加的图结构技巧只提升上下文信息量；
- 若继续这条线，应换一个问题设定：**在同一张图、同一度数分布下只交换边的方向**，
  使"上下文"与"方向"在数据上可分；否则每个改进都会落到"图上下文更好"这一解释上。
- 本轮结论不影响 RQ-VAE：未跑正式 Stage2。
