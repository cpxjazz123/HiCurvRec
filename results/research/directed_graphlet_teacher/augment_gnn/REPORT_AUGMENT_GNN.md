# 有向 GNN 增强（v2：修正三处对照与筛选错误）

## 撤回 v1 的正向结论

审查指出三处实现错误，全部成立，v1 的"首次正向结果"作废：

| 缺陷 | 后果 |
|---|---|
| 无向对照把**全部正负样本标为 1** | 等于告诉模型"每对都相连"，不是"无向边监督" |
| 随机方向对照**翻转的是标签**（含负样本） | 负样本被翻成正样本；破坏的是"有无边"，不是"方向" |
| 单向边筛选拿**无序对**判反向 | 实际按商品 id 排列筛选（held 中 94.9% 被判为单向），预测器可学编号规律 |

## v2 修正

1. **无向监督**：正样本两个顺序都是 1、负样本两个顺序都是 0（"有连接"可学，"谁指向谁"不可学）；
2. **随机方向**：只随机化**呈现顺序**，标签与边集不变——存在性可学，方向不可学；
3. **单向边筛选**：对**有向**反向边判存在（`(b,a) ∈ held_directed`），留出集中单向占 94.9% 是真实比例；
4. 探针仍按商品隔离，正反各半。

## 结果（留出单向对 30,709，探针评估段 5,514 对，SE ≈ 0.0067）

| 臂 | 边头方向 | 融合位移 | **独立探针** |
|---|---|---|---|
| A 原始语义 | — | 0 | 0.4951 |
| **C 有向增强** | 0.4751 | 0.0298 | **0.5267** |
| B 无向增强 | 0.4733 | 0.0283 | 0.5243 |
| D 随机方向 | 0.5073 | 0.0225 | 0.5201 |
| E α=0 | 0.5057 | 0 | 0.4951 |

## 读数

1. **原始语义没有任何方向信号**：0.4951，v1 的 0.5698 是错误筛选（按 id 排序）造成的假象。
2. **GNN 增强整体有效**：C 比原始高 +0.032（约 4.7σ），但**无向 B（+0.029）与随机方向 D（+0.025）
   同样有效**——增益来自**图上下文本身**（入/出邻居聚合带来的度数不对称信息），
   而不是"有向监督学到了方向"。
3. **有向监督相对随机方向没有优势**：C − D = **+0.0066 ≈ 1.0σ**，无法区分。
   按预设判据（C 必须超过 D），**有向监督这一层的价值仍未被证明**。
4. 边头自身方向 0.4751–0.5073，全部在随机附近：模型能读"有连接"，读不出"谁指向谁"。

## 结论

- 修正后，**图的上下文信息有效但"方向"无效**：任何把图聚合进 768 维的增强都能提升 +
  0.03，与监督的方式无关；
- 因此**不建议**把这套增强当作"方向信息注入"进入量化对照；可以作为"图上下文增强"单独研究；
- 若要真正检验方向，需要构造一个**无向图也能做到、但有向图才能更好**的对照（例如在同一
  度数分布下只交换边的方向），当前的无向对照与随机方向对照都无法把"图上下文"和"方向"分开。
