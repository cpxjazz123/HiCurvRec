# 有向 GNN 增强：融合网络真的被训练之后

## 撤回上一版

审查指出：`fuse` 从未出现在任何损失里，所以"增强"其实是 `x + α·随机(...)`；
同时没有实现图消息传递，也没有按商品隔离探针。三条都成立，上一版数字作废。

## 本版实现

| 项 | 内容 |
|---|---|
| 图消息传递 | 用真实行为图，**分别聚合入边/出边邻居均值**，2 层残差 + LayerNorm |
| 边监督 | `s = S(h)`、`t = T(h)`，`P(i→j)=σ(s_i·t_j)` |
| 融合 | `x' = x + α·f([s,t])`，α=1 |
| **融合被训练** | 第二个边头直接读 `x'`（`S'(x')·T'(x')`），其损失与第一个边头相加，`f` 必然进入梯度 |
| 泄漏 | 边按无序对 9:1 切分；消息传递与监督只用 291,262 条训练边，全部指标在 32,371 条留出边上算 |
| 探针 | 768 维方向头，**按商品隔离**（训练对与评估对无共同商品），正反各半 |
| 探针有效性 | 把一半留出对随机反向 → 0.4982，说明读数不是探针本身的偏置 |

## 结果

| 臂 | 边头方向 | 融合后位移 | **独立探针（按商品隔离）** |
|---|---|---|---|
| C_directed | 0.4571 | 0.0287 | **0.5845** |
| B_undirected | 0.5031 | 0.1395 | **0.5433** |
| D_random_direction | 0.5113 | 0.0027 | **0.5659** |
| E_alpha_zero | 0.4799 | 0.0000 | **0.5698** |

留出单向对 15,521（探针评估段约 9,313），二项标准误 ≈ 0.0052。

## 读数

1. **探针通过自检**：随机反向一半后为 **0.4982**，而留出边的存储方向没有 id 排序偏置
   （a<b 占 0.52），所以下面的差异是真实读数。
2. **原始语义本身有弱信号**：A 0.5698 / E(α=0) 0.5698，显著高于 0.5。
   这与前几轮"0.49–0.51"不同，原因是本轮探针只使用**真实存在且方向唯一**的留出边，
   而不是"边 + 随机负例"的混合样本；混合样本把弱信号稀释掉了。
3. **有向 GNN 增强是第一个正向结果**：C 0.5845，比原始（0.5698）高 **+0.015（约 2.9σ）**，
   比随机方向对照（D 0.5659）高 **+0.019（约 3.6σ）**。无向对照 B 0.5433 低于原始，
   说明"丢掉方向"确实损失了这部分信息。
4. **幅度必须如实标注**：+0.015 是弱效应、单次运行、单一 seed；`edge-head direction`
   （C 0.4571）仍低于 0.5，说明边头自身没有把方向学成可读的分数，增益来自融合后的 768 维状态。

## 结论

- 与上一版相比，这次**方向确实被学进了增强表示**（C > D 与 C > 原始均超过 3σ）；
- 但增益很小（0.57 → 0.58），因此下一步的量化对照应给出**明确的可分阈值**：
  只有增强状态在量化后仍保持 C > D 的优势，才能说"行为信息被保留进 SID"；
- 上一版"方向不可学"的结论**撤回**：那是融合网络未训练造成的假阴性。
