# 双表示传播（DiGAE 原版）对比共享表示

**问题**：把 source/target 在**传播过程中**分开（每一步 source 读邻居的 target、target 读邻居的
source），是否比"先融合成一个 128 维再分裂成两个头"更能保留方向？

## 实现

| 项 | 内容 |
|---|---|
| 双表示 | `s^{l+1}_v = norm(s_v + W_ss s_v + W_st·mean_{u∈Out(v)} t_u)`，`t` 对称（读入邻居的 `s`） |
| 边预测 | `P(v→u) = σ(s_v·t_u)`（两个变体相同） |
| 融合 | `x' = x + α·f([s,t])`，第二个边头读 `x'`，`f` 必然被训练 |
| 数据/切分/预算 | 与共享变体完全相同：291,262 训练边、32,371 留出边、1200 步 × 4096、α=1 |
| 对照 | 有向 / 无向标签 / 随机呈现顺序 / α=0 |
| 探针 | 按商品隔离、正反各半、**已固定初始化**（此前未固定，同一输入可差 0.014） |

## 结果（留出单向 30,709，探针 5,514 对，SE ≈ 0.0067）

| 变体 | 臂 | 边头方向 | 位移 | 探针 |
|---|---|---|---|---|
| shared | C_directed | 0.4746 | 0.0288 | **0.5131** |
| shared | B_undirected | 0.4754 | 0.0292 | **0.5196** |
| shared | D_random_direction | 0.5076 | 0.0227 | **0.5091** |
| shared | E_alpha_zero | 0.5040 | 0.0000 | **0.4971** |
| dual | C_directed | 0.4648 | 0.0234 | **0.5259** |
| dual | B_undirected | 0.4651 | 0.0269 | **0.5076** |
| dual | D_random_direction | 0.4668 | 0.0167 | **0.5136** |
| dual | E_alpha_zero | 0.4687 | 0.0000 | **0.4971** |

## 读数

1. **探针自身噪声曾与效应同量级**：固定初始化后，同一份原始语义在两次运行里从 0.4951 变到 0.4971，
   而共享变体的 C 从 0.5267 降到 0.5131——**上一次 0.5267 里有一部分是探针初始化噪声**。
   这也是为什么本报告不再引用上一版的"4.7σ"。
2. **双表示优于共享表示**：有向臂 0.5259 vs 0.5131，**+0.0128（约 1.9σ）**。方向与你的预期一致，
   但幅度只有约 2 个标准误，单次运行下不算决定性。
3. **双表示内部，有向仍优于随机方向对照**：0.5259 vs 0.5136，**+0.0123（约 1.8σ）**；
   共享变体内部这一差只有 +0.004（0.6σ）。也就是说**把两种角色分开传播，才让"方向监督"表现出一点作用**。
4. **边头自身方向依旧在随机附近**（0.465–0.507）：可读性出现在融合后的 768 维状态上，不在 `s·t` 分数上。
5. 无向臂在两个变体里分别是 0.5196（共享）与 0.5076（双），没有稳定优势。

## 结论

- **你的判断得到支持**：提前融合确实稀释了方向信息；分开传播带来约 +0.013 的探针提升，
  且让"有向 vs 随机方向"的差距从 0.6σ 变为 1.8σ；
- **但幅度仍然很小**，单次运行、约 2σ，不能宣称"方向被可靠学到"；
- 下一步若继续：把这个双表示增强状态（`gnn_state_dual_*.npz`）送进量化对照，
  判据是**量化后 C 仍高于随机方向对照**，而不是只看量化前的 0.526。
