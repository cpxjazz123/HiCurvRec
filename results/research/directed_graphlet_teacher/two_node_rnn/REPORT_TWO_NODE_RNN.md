# 第一阶段（课程学习）：两节点 GraphRNN

**问题**：输入两个商品的向量，按顺序预测 A→B 与 B→A 两条有向边（第二步读取第一步的决定），
方向识别是否显著超过随机基线？

## 1. 设置

| 项 | 内容 |
|---|---|
| 结构 | 作为两个 token 输入，编码器 2 层 4 头；解码器依次输出 `A→B`、`B→A`，第二步读第一步 |
| 标签 | 完整行为图；训练集：双向 7750、正向 146125、反向 146125、无边 0；留出：726 / 12174 / 12174 / 4926 |
| 采样 | 训练、留出各自只在**自己商品池**内取样（正样本单向边随机取向，负样本度数匹配），越界即断言失败 |
| 输入 | 768 语义、z、q、z 的 32 维白化 PCA、随机向量、全零向量 |
| 规模 | 300,000 训练对 / 30,000 留出对 / 6000 步 × 512 |

## 2. 结果（留出 30,000 对；单向对 24,348 对）

| 输入 | edge0 (A→B) | edge1 (B→A) | 四结果全对 | **单向对方向准确率** |
|---|---|---|---|---|
| 语义 768 | 0.478 | 0.531 | 0.410 | **0.5053** |
| z | 0.553 | 0.463 | 0.414 | **0.5072** |
| q | 0.541 | 0.472 | 0.412 | **0.5046** |
| z 的 PCA 32 | 0.506 | 0.504 | 0.410 | **0.5002** |
| 随机向量 | 0.493 | 0.507 | 0.405 | **0.4986** |
| 全零向量 | 0.430 | 0.570 | 0.406 | **0.5000** |

## 3. 读数

1. **方向识别没有超过随机**：六组单向对方向准确率全在 0.4986–0.5072，彼此的差距小于 0.009，
   而单向对样本量 24,348，标准误约 0.0032——**没有任何一组显著高于 0.5**。
2. **逐边准确率是偏置，不是学习**：全零向量能拿到 edge0 0.430 / edge1 0.570，说明模型学的是
   "A→B 更少、B→A 更多"这类输出偏置；z 的 0.553 / 0.463 只是把同一偏置翻了个方向。
3. **四结果全对率 0.405–0.414**，与"几乎不预测任何边"的先验一致（留出集 16% 无边、41% 单向、2.4% 双向）。
4. **z 与 q 无差异**（0.5072 vs 0.5046），量化在这一步仍无可测损失，但任务本身已经失败。

## 4. 结论

- **第一阶段不通过**：条件式两节点 GraphRNN 在这个数据上无法区分 A→B 与 B→A；
- 这与上一轮四分类的结论方向一致但更强：上一轮还能靠"有边/无边"拿到 Macro-F1 0.39，
  一旦要求"谁指向谁"，信号消失；
- 因此**不进入第二阶段（三/四节点课程学习）**：在方向都学不到的前提下增加节点只会放大噪声；
- 可能的排查方向（都未做）：方向标签是否与可用特征在物理上相关（例如行为图的方向可能主要由
  时间序列决定，而静态 Embedding 不含时间信息）；或把方向任务改为"给定候选对与候选方向，
  判别二者是否存在"，而不是从两个静态向量凭空判方向。
