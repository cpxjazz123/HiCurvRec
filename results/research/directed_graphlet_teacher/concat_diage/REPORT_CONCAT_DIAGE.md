# DiGAE-1L 双表示拼接（x' = [s‖t] ∈ ℝ⁷⁶⁸）

## 设置

| 项 | 内容 |
|---|---|
| 架构 | 一层有向传播，两个 384 维半向量拼接成 768 |
| 边损失 | BCE：正边、其反向困难负样本、随机负样本 |
| 语义损失 | `MSE(decoder([s‖t]), x)`，权重 1.0（仅 C 臂） |
| 训练 | 1200 步 × 4096，80,000 正边、同量反向负样本、同量随机负样本 |
| 评估 | 留出 8,000 条单向边 + 8,000 随机负样本 + 每条正样本的反向；**三臂使用同一个非对称头**（64 维），同预算 |
| 语义保留 | **线性探针 R²**（state → 原语义，80/20 商品划分）——不是坐标余弦：B/C 在各自空间里，坐标余弦无意义 |

## 结果

| 臂 | ROC-AUC | AP | **Direction** | 语义探针 R² |
|---|---|---|---|---|
| A 原始 768 语义 | 0.7194 | 0.6990 | **0.5354** | 1.000 |
| B 拼接，仅边损失 | **0.7331** | **0.7119** | **0.4642** | 0.748 |
| C 拼接，边损失 + 语义重建 | **0.7336** | **0.7128** | **0.4645** | 0.753 |

## 读数

1. **"是否存在边"略升**：AUC 0.7194 → 0.7336（+0.014），AP +0.014。拼接表示确实带来了
   一点商品级关联信息。
2. **语义基本保住**：线性探针 R² 0.75，即三成方差被行为目标改写；加入语义重建项只把它
   从 0.748 提到 0.753（+0.005），**重建监督几乎没有作用**。
3. **方向反而变差**：B/C 的 Direction 0.464–0.465，**低于原始语义 0.535**。与"增强会稀释方向"
   的前几轮观察一致。
4. 按你的判据（C 必须**同时**保留语义并提升有向边预测），**C 未通过**：语义保住了，
   方向掉了；有向边的"方向"部分没有改善。

## 结论

- 拼接方案在"关联"维度有效、在"方向"维度无效；语义重建项在本设定下是空操作；
- 因此**不把 C 作为 RQ-VAE 的 768 维输入**，也不进入量化后的 z/q/SID 对照；
- 若仍要方向，需要的是**成对（pairwise）顺序统计**这类显式携带方向的输入特征，
  而不是把商品自身的两个向量拼起来——后者仍然只描述单个商品。
