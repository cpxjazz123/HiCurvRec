# 结构预测器能力阶梯（v2，修复隐藏状态泄漏）

## 撤回 v1

v1 报 A/B 同为 0.987 / 0.943 并据此宣称"结构预测器已验证"。审查指出该结果不可采信，
本版逐条修复后重跑，**v1 的全部数字与结论作废**：

| v1 的问题 | 处理 |
|---|---|
| A、B 实际执行同一份代码 | A 给"除被问外全部边"，B **一条边都不给**，两条真正的不同路径 |
| GRU 隐藏状态泄漏：预测第 k 条边时状态里已记得第 k+1 条的真值 | 被问边在 **encoder 输入**中清除（邻接经 `edge_bias` 进编码器），**每格独立前向、GRU 零状态** |
| 随机向量是每商品固定向量，可能被当 ID 记忆 | 新增 **E 全零向量**对照：没有身份可记 |
| 自回归用 0.5、评估用 0.3 | 评估阈值统一在训练集上选并写入 `threshold_chosen_on_train`；前缀生成仍固定 0.5（明示，不隐含） |
| 商品级隔离未解决 | 仍只做到实例隔离：丢弃 116,252 行后不足 500 条，记录在 `labels` |

|---|---|---|---|---|---|---|
| A | 除被问外全部边 + z | 0.918 | **0.802** | 0.938 | 0.830 | 0.802 |
| B | 一条边都不给 + z | 0.583 | **0.0038** | 0.975 | 0.660 | 0.004 |

## 读数

1. **A 仍有 0.802**：给足上下文时，编码器确实在用边信息，不是纯先验。
   但比泄漏版的 0.943 低 0.14，**说明旧分数里确实有泄漏成分**。
2. **B 只剩 0.0038**：不给任何上下文时无法补出结构。**"单条未知边可推断"的结论撤回**；
   v1 里 A≈B 完全是因为两路共用同一份泄漏代码。
3. **B ≈ C ≈ 0.002–0.027**：模型在"无上下文"时全部退化为先验，与输入是语义、z 还是 q 无关。
4. **D 与 E 的对照解决了一个反常**：随机向量 0.147、全零向量 0.0002。
   若 D 的收益来自商品 ID 记忆，E 没有 ID 却仍能拿到 0.147 是不该出现的——事实相反，
   说明 **D 的 0.147 来自"每个商品固定向量"这一可记忆的身份**，**不是结构先验**；
   全零输入下模型只能学到一个常数结构，实际接近空图。
   → 因此 **C 与 D 之间那 0.14 的差距不能解释为语义信息**；它同样来自身份可记忆性。
5. **z 与 q 依旧几乎相同**（0.0028 / 0.0017），语义 0.0265 也同量级：
   在"完整结构恢复"这件事上，三种表示都没有可用的结构信息被读出。

## 结论

- 结构预测器**在给定上下文时可用**（A = 0.80），**在无上下文时不可用**（B/C/E ≈ 0）；
- 因此瓶颈明确落在 **Embedding → 结构** 这一侧，而不是模型实现；
- 之前任何"语义/量化表示携带结构信息"的说法都缺少支持：C 组与全零输入同量级；
- 商品级隔离仍未达成，是数据规模的硬限制，已在 `labels` 中记录；
- RQ-VAE 未修改。

## 下一步

1. 先解决商品级隔离（例如按商品划分实例池后重采样子图），否则所有数字都带记忆效应；
2. 把"无上下文"与"有上下文"两条曲线作为后续任何结构监督提案的准入基线；
3. 若要做 Embedding → 结构，需要先证明存在可学的映射，而不是继续换模型。
