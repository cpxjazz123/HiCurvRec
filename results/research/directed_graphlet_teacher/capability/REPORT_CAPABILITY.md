# 结构预测器能力阶梯：A / B / C / D

**问题**：在讨论量化之前，先证明这个 GraphRNN 真的会读结构。四个输入条件，同一模型、
同一标签（完整行为图）、同一切分（200k 训练 / 6k 留出）、同一预算（6000 步 × 512）、宽度 3。

## 1. 设定与泄漏规则

| 组 | 输入 | 问题 |
|---|---|---|
| A | 每步给出"除被问那条以外的全部真值" + known 掩码 | 编码器+解码器能否使用答案 |
| B | 同 A；**被问的边从前缀与掩码中同时移除** | 单条未知边能否被推断 |
| C | 不给邻接，喂自身 arg-max 前缀（语义 / z / q 三条） | 仅凭 Embedding 能恢复多少 |
| D | C 的随机 Embedding 版本 | C 的优势是否只是结构统计 |

宽度 3、label = 完整行为图；评估使用全部留出实例，不可分类记错；Orbit 经 `orbits_of` 映射为全局 id。

## 2. 结果（留出 6,000）

| 组 | 边 F1 | 精确 / 召回 | 邻接完全一致 | 可分类 | family | Orbit（全局） |
|---|---|---|---|---|---|---|
| A 给出全部真值（z） | **0.987** | 0.996 / 0.979 | **0.943** | 1.000 | **0.957** | **0.943** |
| B 单条未知（z） | **0.987** | 0.996 / 0.979 | **0.943** | 1.000 | **0.957** | **0.943** |
| C 仅语义 768 | 0.586 | 0.469 / 0.783 | 0.0265 | 0.976 | 0.599 | 0.031 |
| C 仅 z | 0.581 | 0.449 / 0.821 | 0.0028 | 0.967 | 0.663 | 0.003 |
| C 仅 q | 0.579 | 0.446 / 0.824 | 0.0017 | 0.975 | 0.637 | 0.002 |
| D 随机向量（同 C 协议） | 0.569 | 0.591 / 0.549 | **0.1470** | 0.774 | 0.520 | **0.159** |

## 3. 定位

按预设分支：

- **A 好（0.94 完全一致）**：模型实现与训练流程没有坏，编码器能读结构、解码器能用已知边；
- **B 与 A 完全相同（0.987 / 0.943）**：单条缺失边可被上下文推断，**推断能力存在**；
- **C 大幅下降（完全一致 0.003–0.027）**：仅靠 Embedding 无法恢复完整结构 —— 但注意 D；
- **D（随机向量）在"完全一致"与 Orbit 上反而高于 C**（0.147 vs 0.003–0.027；0.159 vs 0.002–0.031）：
  这说明 **C 的成绩不是从语义里读出来的**，随机输入下模型退化为"按训练集里最常见的结构模式生成"
  （空图/单边），而真实 Embedding 把输出推向了更稠密但**更不一致**的预测。

也就是说：**C 的边际优势（F1 比 D 高 0.01）不构成"语义携带结构信息"的证据**；真正被证明的是
A/B 的能力存在、C 的完整结构恢复失败。

## 4. 结论与下一步

1. 结构预测器**已被证明可用**（A/B ≈ 0.94–0.99 完全一致），不再是"实现坏了"的状态；
2. **瓶颈在 Embedding → 结构的映射**：给出上下文即可推断，仅凭向量则不行；
3. 因此在 32 维量化前后比较之前，要先解决"Embedding 里到底缺什么"——D 组提醒我们，
   任何比较都必须同时报告随机向量基线，否则会把结构先验误读成语义信息；
4. RQ-VAE 仍未修改。
