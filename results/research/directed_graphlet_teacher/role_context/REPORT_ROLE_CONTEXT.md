# 同一商品在多个子图中的角色区分（下一轮前置验证）

**问题**：能否让同一个商品在多个不同子图中接受训练与预测，检验 Graph Transformer 能否根据
上下文正确区分它承担的不同 Orbit 角色？**在接入任何结构损失之前**先验证这一点。

## 1. 度量单位：`(item, 两个角色不同的子图)`

商品级平均准确率会把"位置效应"和"上下文区分"混在一起。这里只取这样一对样本：同一商品出现在
两个子图里、两处的真实 Orbit **不同**；模型必须分别答对两次，且**判对两次**才算一次成功。
理想情况（模型读懂了上下文）是两次都对；一个"每个商品只有一个角色"的模型在结构上不可能做到。

| 项 | 值 |
|---|---|
| 宽度 | 3 节点（P3 + K3），3 与 4 节点分开研究，避免宽度泄漏 |
| 训练实例 | 16000 条（宽度 3 训练集共 467200 条，这里做了确定性抽样，**这是当前最大的限制**） |
| 评估对 | 2022 对、337 个留出商品，全部来自"训练实例中未出现过的商品" |
| 模型 | 2 层 4 头全连接注意力 + 角色槽位嵌入，`orbit` 头对每个成员独立输出 |
| 预算 | 40 epoch，单一种子，无 KNN、无真实邻接（E 组除外） |

## 2. 结果

| 集合 | 含义 | z | q |
|---|---|---|---|
| **A per-instance orbit** | 同一商品分别答对两次 | 0.1004 / 0.1123（两次） | 0.0994 / 0.1103 |
| A 判对两次 | 严格成功 | **0.0000** | **0.0000** |
| A 平均 Macro-F1 | 单次判别的 F1 | 0.0216 | 0.0215 |
| B 上下文消融 | 只保留商品自身 token | 0.0974 / 0.1172，F1 0.0089 | 与 z 相同 |
| **A vs B 切换率** | 同一商品被给出**两个不同**角色的比例 | **0.4159**（B 为 0） | 0.4154 |
| D 无上下文基线 | 每商品固定一个角色组的头 | 上下文一致率 0.9881 | 0.9881 |
| **E 真实邻接上限** | 给真实有向边 | 0.1103 / 0.1286，F1 **0.0255**，判对两次 **0.003** | — |

## 3. 读数

1. **有上下文区分，但不是"学会"**：模型在 A 中给出两个不同角色的比例是 **0.4159**，消融上下文后
   结构性为 0，说明它确实把邻域信息用上了；但**两次都判对的样本是 0**，单次准确率 0.10–0.13，
   与"全猜一个常量 Orbit"同量级：多数商品以少数几个 Orbit 为主，单次命中率就在 0.10–0.14 附近，
而"两次都判对"需要模型真的分开两个上下文，当前为 0。
2. **z 与 q 几乎完全相同**（0.1004 vs 0.0994 等），量化在这一步仍未测到损失。
3. **E 只把上限抬到 F1 0.0255、判对两次 0.003**：连"给真实邻接"都学不动，说明**当前模型与预算
   是瓶颈**，不是表示——与上一轮 4 节点子图任务的结论一致。
4. 因此**还不能**把这套输出当作结构监督：`L_item`/`L_subgraph` 若以当前精度为信号，等于给 RQ-VAE
   注入接近噪声的梯度。

## 4. 局限（必须一并读）

- 训练实例只有 16000 条（宽度 3 池的 3.4%），40 epoch；这些数字描述的是"小样本下这个模型的表现"，
  不是该任务的上限；
- 337 个留出商品、2022 对样本，单次判别的置信区间很宽；
- 角色槽位嵌入与"位置"绑定，位置 0..2 的真实语义在旋转后不再固定，模型需要自行从 token 内容
  判断"我是谁"，这比给它位置标签更难；
- 没有做"仅用商品向量 + 全连接注意力但隐藏其他成员 token"以外的其他消融（例如随机置换成员顺序）。

## 5. 下一步（在接损失之前）

1. 把训练样本从 16000 提到池子上限附近（>30 万），epoch 提到 150，先看 A 的"两次都判对"能否离开 0；
2. 位置语义解码：让模型先预测成员在真实子图中的位置/角色，再判 Orbit；
3. 只有 A 的严格成功率显著 > 0 且 E 明显更高时，才讨论 `L_item` / `L_subgraph` 的接入；
4. 当前**不修改 RQ-VAE**。
