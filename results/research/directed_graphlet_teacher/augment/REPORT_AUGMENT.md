# 行为增强的商品向量：方向到底有没有被学进去？

**问题**：把方向信息先学进 768 维输入（`x' = x + α·f(s,t)`，宽度不变），再交给 RQ-VAE，
是否比直接在量化过程里加损失更容易？

## 1. 设置

| 项 | 内容 |
|---|---|
| 行为表示 | `s = W_s x`、`t = W_t x`（dim 64），`P(i→j) = σ(s_i·t_j)`（非对称） |
| 融合 | `x' = x + α·f([s,t])`，`f` 映射回 768，`α = 1`，`|f|` 有界（Tanh） |
| 训练 | 3000 步 × 1024，40 万对（一半真实边、一半无边），AdamW 1e-3 |
| 探针 | 留出方向上：独立 768 维方向头（70/30 切分），另有**边头自身**的方向读出 |
| 隔离 | 训练对与评估对不相交（商品级隔离会清空探针，已回退为**对级隔离**并记录） |
| 臂 | A 原始 / B 无向增强 / C 有向增强 / D 增强路径但 α·输出置零（α=0） |

## 2. 结果

| 臂 | 融合后向量上的方向头 | **边头自身方向** | 与原始语义的位移 |
|---|---|---|---|
| A 原始语义 | 0.4933 | — | 0 |
| B 无向增强 | 0.5053 | 0.4941 | 0.0199 |
| **C 有向增强** | **0.5036** | **0.4976** | 0.0127 |
| D α=0（路径训练后置零） | 0.4933 | 0.4976 | 0 |

留出单向对约 2,917（探针评估段），二项标准误 ≈ 0.0093。

## 3. 读数

1. **连"边头自身"的方向都只有 0.498**：C 臂训练了 3000 步、BCE 从 1.387 降到 1.060，
   但学到的 `s/t` 在任何留出对上都分不出 A→B 与 B→A。这是**在更强的模型容量下**重复了
   前几轮的结论——**方向不在静态向量所张成的空间里**。
2. **融合后的 768 维向量也没有方向**：C 0.5036 对 A 0.4933，差 0.010，仅约 1 个标准误；
   B（无向，理论上没有方向信号）0.5053 反而最高——三者不可区分。
3. **D 的读数证明位移不是"学到了方向"**：α=0 臂与 A 完全相同（0.4933），说明上表的
   0.4933 就是随机水平；B/C 的 0.50–0.51 落在同一噪声带里。
4. 融合只把向量移动了 1.3–2.0%，即使方向被写进 `f`，幅度也不足以承载判别信息。

## 4. 结论

- 按预设判据（C 必须超过 B 与 D 一个标准误以上）：**不通过**；
- 这轮的意义在于**方式换了、结论没变**：不是"损失接错了地方"，而是**在只给商品自己
  768 维语义的情况下，行为方向本身就不可学**——边头、融合向量、下游方向头三条通路一致；
- 因此**不建议**把这条增强路线推进到 A–E 五臂 Stage2 对照：在没有"方向可被学到"的前提下，
  五臂之间的差异只会反映训练噪声；
- 若要继续这条线，需要引入静态语义之外的信息（例如用户序列的时间先后、共现时间窗），
  否则换任何融合形式都会停在随机水平。
