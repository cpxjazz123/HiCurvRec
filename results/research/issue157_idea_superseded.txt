Idea：把 AF3 结构监督改成**尺度无关的序目标**（修正 #156 的坍缩，不是新方向）
英文名称：Scale-Free AF3 Rank Consistency (corrected from #156)

#156 是本线路第一次真正跑完 Stage2 的臂，也是第一次看清失败形态：

- 接线与学习都成立：两臂差分 200 步里 R 的秩一致性改善 0.08860、N 只有 0.02111（比值 **4.197**），
  拟合后梯度方向余弦 0.1269，`c=1` 与 `c=0` 差 0.3543；
- 但 **Stage2 坍缩**：3000 epoch 后 24587 个商品只剩 **10 个不同三码 SID**，最大码占比 99.12%，
  入口碰撞 `0.999593`，Stage3 被 §89 拒绝。

根因（可机械判定）：目标 `t_e = d_ref·(1−u_e)` 配 `mean|d−t|/d_ref` 是**绝对距离回归**，而
`d_ref = 1.52e-4` 在 `mixed_cost` 尺度上极小；把全体前缀距离一起缩小就能降低损失，末级均衡
分配只约束列边际、拦不住这种整体收缩，导出 argmin 于是处处取同码。**目标函数自带坍缩激励。**

## 一、主张（一句话）

只约束 AF3 与前缀距离之间的**序**：同一 batch 内，高 AF3 边的前缀距离必须小于低 AF3 边的
前缀距离；距离按 batch 自身的均值归一，使目标对整体缩放完全免疫，坍缩失去任何收益。

## 二、设计

1. **冻结结构证据（沿用，不重建）**：逐边 `AF3 = 4 − deg − deg + 3m` 与 `q05/q95`、`u_e` 归一、
   高/低边集与全高三角形表，SHA `017e47e9…`（#155 产物）。
2. **尺度无关的距离量**：对同一 batch 的抽样边取 `ρ_e = d_e / mean_batch(d)`，`d_e` 为边两端第 ℓ 级
   前缀嵌入的 Poincaré 距离（`mobius_add` + `d_c`，c=1），三层平均。
3. **序目标**：`L_rank = mean_{(h,b) ∈ H×B} softplus(ρ_b − ρ_h)`，`[0,1]` 归一化；不含任何绝对
   距离目标、不含 `d_ref`。整体缩放同时改变分子与 `mean_batch(d)`，`ρ` 不变 ⇒ **零坍缩收益**。
4. **展布下限（防止退化成常数）**：`L_spread = relu(σ_min − std(ρ))`，`σ_min = 0.5 · std(ρ)` 在冻结
   探针上初始化时实测、写盘记 SHA；`λ_rank = λ_spread = 1`。
5. **三角闭合项**（保留，量纲同步为 ρ）：`L_tri = mean over 三边均属高 AF3 的三角形 (1 − min_{三边}(1 − ρ_e))`，`[0,1]`。
6. **其余不动**：代价函数、末级 Sinkhorn（均匀列目标、`SK_EPSILON=0.003`、`SK_ITERS=50`）、
   残差递推、读出、导出、三 token 结构；不引入桶/掩码/π/层心平移。
7. **开关**：`STRUCTURE_OFF`（两项置 0，逐位等于基线）、`GEOMETRY_OFF`（`c=0` 欧氏极限）、
   `BOTH_ON`（出厂）；只要求实现正确与廉价接线检查，不训练关闭臂（§19g）。

## 三、验收（派发前，冻结探针，全部可测）

1. **尺度不变性（新增，直接针对 #156 的根因）**：把同一 batch 的所有 `d_e` 同时乘以 0.25 / 4，
   `L_rank` 与 `L_spread` 的变化 ≤ 1e-6。
2. **两臂差分学习**（沿用 #155 协议）：同 seed、同数据顺序、固定 200 步、训练器自身优化器；
   R 用真实 AF3、N 用置换目标；要求 R 的秩一致性改善 ≥ N 的 2 倍，两臂都非惰性。
3. **试跑占用护栏（新增，坍缩前置拦截）**：同样 200 步后，末级 `codes_used ≥ 0.8 × 基线`、
   `max_bucket_share ≤ 2 × 基线`，且 batch 平均前缀距离相对初始值不低于 **0.5×**（尺度护栏）。
   任一项越界即判负，不派发。
4. **曲线耦合**：同一 batch 上 `c=0` 与 `c=1` 的损失值不同（欧氏极限 1e-6）。
5. **接线与一致**：`STRUCTURE_OFF` 与基线逐位一致（**含导出**）；训练与导出取同一码。
6. **覆盖**：全局 batch（4096）100% 同时含 ≥1 条高边与 ≥1 条低边；per-rank 只作诊断。
7. **TDD**：先写会失败的测试（尺度不变性、序目标梯度方向、展布下限触发、c=0 极限、训练/导出同码），
   确认红后再实现。
8. 任一门不过：按预派发负结果记录并停止，不改 `σ_min`、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融、不做调参扫描、不做多种子（§19g）。
- 结构证据只来自训练划分；商品级 SID 全局一致；源码无绝对路径；`/tmp` 不落产物。
- 训练中保留既有曝光护栏（`codes_used ≥ 128`、`max_bucket_share ≤ 10%`），越界即 FAIL 停止——
  这是 #156 坍缩本应在训练中被拦下的位置。
- 风险：序目标对"整体拉近"免疫，但如果编码器把所有距离推到同一个值，`L_spread` 会顶住；若展布下限
  与序目标互相抵消导致学不动（两臂比值 < 2），按负结果归档，不改 σ_min 重跑。

## 五、与 #156 的差异（必须逐条写进规格）

| 项 | #156（坍缩） | 本臂 |
|---|---|---|
| 目标 | 绝对距离 `t = d_ref(1−u)` | **序**：`softplus(ρ_b − ρ_h)` |
| 尺度 | 以 `d_ref = 1.52e-4` 为尺度，整体收缩即降损失 | `ρ = d / mean_batch(d)`，对缩放完全免疫 |
| 坍缩防线 | 只有 Sinkhorn 列边际（拦不住） | 尺度不变性 + 展布下限 + 200 步试跑占用护栏 |
| 常数 | `d_ref`、λ | `σ_min`（初始展布的一半，实测）、λ |

## 六、路线（供下一臂开局）

1. 结构证据冻结不变；改的只有"怎么把 AF3 变成损失"。
2. 任何绝对距离目标都必须先通过尺度不变性测试，否则不许派发。
3. 派发前必须跑 200 步试跑，并在试跑后检查码占用与平均距离，坍缩前置拦截。
4. 逐层记录 `codes_used` / `max_bucket_share` / 归一化熵 / 平均前缀距离 / 秩一致性，不得只记平均损失。
