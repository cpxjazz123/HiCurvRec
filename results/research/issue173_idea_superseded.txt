Idea：为搁浅行加**有界增广**（≤2 跳换位），把双容量放宽做回 0（修正 #172）
英文名称：Two-Sided Quotas with Bounded Augmentation (corrected from #172)

#172 把结构做满，也第一次让"放宽计数"暴露出来：

| 观测（未训练全量导出 24587） | 数值 |
|---|---|
| 入口碰撞 | **0.0000407** |
| 二级不同前缀 | **24328** |
| 逐层占用 | 256/256/256 码，份额 0.3945 / 0.4930 / 0.3945 % |
| 导出耗时 | **3.99 s** |
| 偏好保真度（诊断） | 0.5439 |
| **放宽次数** | **280 / 73761 = 0.38%** |

含义：行优先**正是靠这 280 行超配额**才把碰撞压到 0；小规模（1024 行）放宽为 0，导出规模（每码容量 96）必然搁浅。
要做到真正 0 放宽，需要"给搁浅行腾位"的增广——完整 min-cost flow 已被 #169 测得 900× 超时，但**有界增广**（1–2 跳换位）是廉价的。

## 一、主张（一句话）

在行优先贪心之后，对每个搁浅行做**≤2 跳的交替路**：找到一条 `搁浅行 → 码 k（已满）→ 该码上的某行 → 码 k'（有余量）`
的链，若换位后**总代价不增**则执行；重复直到无可行链；把 `relaxations` 压到 0。

## 二、设计

1. **结构证据（沿用）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **逐商品曲率（沿用 #167）**：`κ_i = (1 − u_i)/mean_frozen(1 − u)`，均值 1。
3. **两重配额（沿用）**：`q_k = ⌊B/K⌋`（余数按码索引）+ `r_g = ⌈n_g/K⌉`。
4. **指派（沿用 #171 行优先）+ 有界增广（本臂唯一改动）**：
   - 行优先贪心后，收集搁浅行（首选码与其后若干码都满）；
   - 对每个搁浅行做 BFS 深度 ≤2：`行 i → 码 k → 码 k 上的行 j → 码 k'`，要求 `k'` 对 `j` 的父前缀有余量、且对 `i` 的父前缀无冲突；
   - **接受条件**：换位后的总代价 ≤ 换位前的总代价（不引入新阈值）；
   - 反复直到无链或达到固定预算（≤3 轮，轮数只是循环上限，不是调参项），残差记入 `relaxations`。
5. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003`/`50 sweeps`/centring、残差递推、读出、导出、三 token 结构；
   训练目标仍只有 `L_RQ`；开关语义不变。
6. **身份**：`ARM_NAME="TIGER_two_sided_augment_rq"`、`ARM_VARIANT="2SAUG"`、`OUTER_LOOP=False`、
   `AUX_AF3=False`、`CURVATURE=1.0`；树内无绝对路径；`/tmp` 不落产物；checkpoint 绑结构表 SHA 与 κ 表 SHA。

## 三、验收（派发前，全量导出 + 冻结探针 + 200 步试点，全部可测）

1. **放宽次数 = 0**（本臂核心门；#172 为 280）；增广轮次、被换位行数、总代价变化写入报告。
2. **项目口径结构门全过（复测）**：入口碰撞 ≤ 0.05、二级前缀 ≥ 0.5·B、逐层 256 码、份额 ≤ 10%。
3. **双容量恒等式**：每父前缀每码 ≤ `r_g`、每码总数 ≤ `q_k`（增广后逐行复核）。
4. **时间**：全量导出 ≤ 60 s；rank-batch 指派 ≤ 0.15 s。
5. **200 步试点**：逐层 ≥128 码、份额 ≤10%、平均前缀距离 ≥ 0.5× 初值。
6. **训练中护栏**：每个评估 epoch 用项目口径检查，越界即 FAIL 停止。
7. **接线与一致**：`ROUNDING_OFF` 同模型内逐位一致（含导出）；训练/导出三级一致率 1.0；checkpoint 绑定。
8. **诊断（不设门）**：偏好保真度、精确解抽样差距、逐层边际份额、导出分块数。
9. **TDD**：先写会失败的测试（增广的接受条件、无可行链时退化、双容量恒等式、`ROUNDING_OFF` 恒等、`c=0`、训练/导出同码）。
10. 1–3、5–8 任一不过：按预派发负结果记录并停止，不改容量规则/κ/λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 双容量指派 + 有界增广）；Sinkhorn 本体不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：增广可能无解（链条不存在）；此时 `relaxations > 0`，按负结果归档，不改容量规则。
