Idea：秩监督改在**父前缀组内**比较（修正 #165：条件配额与全局秩项互相拉扯）
英文名称：Within-Parent Rank Supervision (corrected from #165)

#165 第一次让机制通过六道门，也第一次让监督项**反向**：

| 门 | 结果 |
|---|---|
| 1 入口碰撞 | **0.000000**（24587/24587 不同三元组） |
| 2 容量恒等式 | PASS（逐层 ≥240/256，每父组配额精确） |
| 3 单一实现 + 开关 | PASS（开启 `ROUNDING_OFF` 时 3921 个不同三元组；跨树逐位比对因 `init_codebook` 的 KMeans **未定种子**不可测） |
| 5 尺度/曲线 | PASS（0.25×/4× 变化 0.00e+00；c=1 0.582659 对 c=0 0.515371） |
| 6 训练护栏 | PASS |
| 7 训练/导出 | PASS（三级一致率 1.0/1.0/1.0） |
| **4 两臂差分** | **FAIL：U −0.06320、R −0.03656、N −0.04995 → R 的改善 −0.02664（比无监督更差）** |

成因清楚：条件配额强制"同一父前缀下的行摊到不同子码"，把秩项依赖的**邻域结构打散**；
全局比较前缀距离时，秩项想拉近的边恰好被配额推开。两者在全局口径下天然对立。

## 一、主张（一句话）

把秩项与展布项的作用域从"全局 batch"改成"**同一父前缀组**"：只比较共享父前缀的行之间的距离，
因为这些行之间的"谁拿哪个子码"正是配额留给模型自由度的地方；跨组边不参与监督。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **配额与指派（沿用 #165，不改）**：第 1 层均匀；第 2/3 层按父前缀条件化均分；组内单一向量化贪心。
3. **监督（本臂唯一改动）**：
   - 第 1 层无父前缀：沿用全局比较；
   - 第 2 层：在每个一级组内计算 `ρ^{(2)}`（组内 `mean(d)` 归一）与 `L_rank^{(2)}`、`L_spread^{(2)}`；
   - 第 3 层：在每个二级前缀组内同理；
   - 只保留**两端同组**的高/低 AF3 边对；跨组边不计入，其覆盖比例如实报告；
   - `λ_rank = λ_spread = 1`；三角项同理改为组内三边。
4. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003` / `50 sweeps` / centring、残差递推、读出、导出、三 token 结构。
5. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，**同模型内**逐位一致）、`GEOMETRY_OFF`（`c=0`）、
   `BOTH_ON`（出厂）。
6. **测量口径更正（#165 留下）**：`init_codebook` 的 KMeans 未定种子 ⇒ 跨树"逐位一致"不可测，
   一律改用"同模型内恒等"；该限制写入报告。

## 三、验收（派发前，冻结探针，全部可测）

1. **两臂差分（决定性）**：同 seed/数据顺序/固定 200 步；R 的改善必须 **> 0 且 ≥ 2×max(N,0)**；
   并列报每组平均参与边对数（要求 ≥ 1000 对/臂，不足则判门不过）。
2. **入口碰撞 ≤ 0.05**（沿用 #165 的实测口径），二级前缀 ≥ 0.5·B。
3. **容量恒等式**：每个父前缀下各子码计数等于配额；行和恰 1。
4. **尺度不变性 / 曲线耦合**：组内 `d` 乘 0.25/4 时两项变化 ≤ 1e-6；`c=0` 与 `c=1` 损失不同（1e-6）。
5. **接线**：`ROUNDING_OFF` 同模型内逐位一致（含导出）；训练与导出取同一码（三级 1.0）。
6. **训练中护栏**：逐层 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`。
7. **覆盖报告**：两端同组的高/低 AF3 边占比、被排除的跨组边数，必须列在报告里。
8. **TDD**：先写会失败的测试（组内归一化、组内边筛选、空组退化、`ROUNDING_OFF` 恒等、c=0 极限、
   训练/导出同码），确认红后再实现。
9. 任一门不过：按预派发负结果记录并停止，不改配额规则、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 条件配额指派）；Sinkhorn 本体（ε、迭代数、centring、代价）不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：组内比较会显著减少可用边对；若"同组边对 < 1000/臂"导致信号不足，按负结果归档，
  不改配额规则重跑（可选方向：放宽到"同父或同祖父"，属另一方案）。

## 五、与 #165 的差异（必须逐条写进规格）

| 项 | #165 | 本臂 |
|---|---|---|
| 秩项作用域 | 全局 batch | **同一父前缀组内** |
| 与配额的冲突 | 实测 R 改善 −0.02664 | 由构造成立：组内才是配额留下的自由度 |
| 跨组边 | 计入 | 不计入，覆盖比例如实报告 |
| 逐位比对口径 | 跨树（因 KMeans 未定种子不可测） | 同模型内恒等 |
