# 两层同时生效:容量 + 有界几何(第一次真的训出来)

前几轮把"容量层"训出来过(round 8/9),**几何层只做过单元测试**。本轮把两层都装进 F0 派生树,跑 300 epoch,逐 epoch / 逐观测点测量两个保证。

## 机制

| 层 | 实现 | 保证 |
|---|---|---|
| 容量 | 每步分配满足 `n_k ≥ 1`(`constrained_assignment`) | 构造性:吸收态不可达 |
| 几何 | `c_k = a_k + clip(Δ_k, ‖Δ_k‖ ≤ ρ)`,`a_k` 为固定原型,`2ρ < δ` | 结构性:任意两码字不可能重合 |

`a_k` = 该层初始残差的 **KMeans 中心**(与冻结基线的初始化同源),`δ` = 原型最小两两距离,`ρ = 0.25·δ`。偏移从 0 开始、原型不动,学的是球内的偏移。

## 实测(300 epoch,K1_floor_bounded)

| 保证 | 测量 | 结果 |
|---|---|---|
| 容量 | 每 epoch 三级活跃码的最小值 | **256 / 256 / 256**(300/300 个 epoch) |
| 几何 | `δ > 2ρ` | 每级每观测点 **True** |
| 几何 | 实测混合度量下最小两两距离 | L1 **0.0056–0.0059**;L2 1.9e-4–2.5e-4;L3 1.1e-4–1.7e-4 —— **始终 > 0** |
| 质量 | L3 行为 AUC / collision | **0.6446** / **0.2901** |
| 参考 | F0(无保护) | 0.6592 / 0.3447 |

## 必须写下的两条发现

1. **几何层的"保证"是真的,但它的强度由数据自己决定。** `δ` 来自 KMeans 中心在**欧氏半**的间距,`ρ = 0.25δ = 0.0042`,而码本整体量级约 0.1 —— 也就是说码字被允许移动的幅度只有码本尺度的 4 %,模型几乎学不动:重建损失 2.1e-4,比基线 1.55e-4 差 36 %,L3 掉 1.5 pp。
2. **混合度量下的实际间距比欧氏界小 1–2 个数量级。** L1 的欧氏界 `δ − 2ρ = 0.0083`,但实测混合最小距离只有 0.0056;L3 更是 **1.1e-4**。原因在双曲半:KMeans 中心在球面上可以几乎重合,而双曲距离没有"减法三角不等式"。**所以 `ρ` 若按欧氏 δ 定,几何层在混合度量里既不是最优、也不代表真实余量。**

## 结论与建议

**容量层可以作为通用默认**:它只改分配、对任何机制成立、健康时零成本(0 次搬运),并且已在两套量化器上各跑出 256/256(round 8 混合、round 9 冻结基线)。它现在由框架在候选创建时安装、在准入时机器检查。

**几何层不应该按当前形式默认开启**:在 256 码 + 本仓库的混合度量下,`2ρ < δ` 要么把 ρ 压到无法学习(本轮),要么在双曲半实际上不成立。要让它有意义,只有一条路:

- 用**训练度量本身**定义 δ(每层实测混合最小间距),再取 `ρ = fraction · δ_mixed`;本轮实测 `δ_mixed` 在 L3 只有 1e-4 量级 → 该层的 ρ 会小到 1e-5,**说明在这套码本容量下"有界几何"与"可学习"是互斥的**;
- 或者降低码字数(每层更少、间距更大),这已经不是防坍缩问题而是容量设计问题。

因此本轮的交付是:**容量层默认、几何层可选且默认关闭**,并把"ρ 必须由混合度量定"写进 `qda_geometry` 的文档与测试。任何声称"几何保证成立"的臂,必须同时报告实测 `min_pair_distance`,不能只报欧氏界 —— 本轮的 1e-4 就是这个要求的由来。

## 更正(后续轮次发现)

本轮用的保护补丁当时自带 `FORCE_CONSTRAINED_ALL = True`,它把基线的 **Sinkhorn 平衡分配关掉了**(`use_sk = ... and not FORCE_CONSTRAINED_ALL`)。冻结配置里 `SK_EPSILON = 0.003`、`SK_ITERS ≥ 1`,也就是说**基线本来开着平衡分配**。

因此本表的两个结论要分开看:

- **几何结论不受影响**:码字两两距离的实测(0.0056 / 2e-4 / 1e-4,始终 > 0)与平衡分配无关,`2ρ < δ` 的构造也不受影响。
- **质量对比被污染**:`K1_floor_bounded` 与 F0 的差异同时包含"下限""有界几何""关掉 Sinkhorn"三件事,L3 AUC 的 1.5 pp 不能全部归因于几何约束。要归因必须重跑一个保留 Sinkhorn 的臂。

保护补丁此后已改为**在 Sinkhorn 的输出上施加下限**(不再关闭它),并在准入探测中同时验证 `argmin` 与 `argmax(q)` 两条通路。第 8、9 轮的树未受影响(它们的 `use_sk` 行保持原样)。
