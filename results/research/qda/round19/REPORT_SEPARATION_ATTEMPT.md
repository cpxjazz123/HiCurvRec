# 尝试把"信息量"检查前移到训练期:失败,已回滚

上一轮结论说"再往前需要把信息量那一环前移到训练期"。这轮真的做了:一个**无参数**判据 —— 码字间最小距离必须不小于量化器自身的分辨率(每个商品到其被分配码字的距离均值的平方根)。含义是:如果两个码字比量化噪声还近,模型就无法区分落在它们上面的商品。

## 收敛后的测量:判据确实区分得开

| 运行 | L1 / L2 / L3 = min_pair / resolution |
|---|---|
| 完整预算(健康) | **2.09 / 1.35 / 1.56** |
| 接近坍缩敌手 | **0.00 / 0.01 / 0.03** |

按"连续 50 步触发才拒绝"接入后,敌手如预期在训练中被拒:

```
CodebookCollapse: codewords are closer (9.03e-03) than the quantiser's own resolution
(4.23e-02, ratio 0.213) for 50 consecutive steps
```

## 但它也会拒绝健康运行 —— 假阳性

同一个检查装上后跑一次普通基线(60 epoch):

```
CodebookCollapse: codewords are closer (1.25e-02) than the quantiser's own resolution
(4.11e-02, ratio 0.305) for 50 consecutive steps
```

**训练早期比值只有 0.30**,而收敛后是 1.35–2.09。也就是说这个比值在训练过程中会穿越 1.0,`factor = 1` 这条"由定义给出"的边界**只在收敛附近成立**,不能当训练期的闸门。

## 处理:回滚

- `verify_separation` 及三个调用点全部移除,测试 34 项重跑通过;
- 结论写在这里而不是留在代码里:一个能用的版本需要**校准系数**(例如 0.1,可被说成"比噪声低一个数量级",但那是调参)或**预热规则**(前 N epoch 豁免,又是超参)。

两者都违反 §19g"常量必须可推导"的要求,所以它们属于**设计决定**,而不是可以自行拍板的工程实现。

## 因此边界维持原样

守卫负责**占用与区分性**(每步每码非空、码字互不相同、分配不由平手决定),**信息量**由 Stage3 的碰撞门槛裁决(实测:0.930 → REFUSED)。这不是没做,而是做了一版、被测出会误杀健康运行后撤掉了。
