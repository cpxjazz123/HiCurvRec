Idea：CMR——一级分配用**相对曲率** ρ_ik = κ_i / κ_k（商品曲率对码组曲率之比）作度量
英文名称：CMR — Curvature-Ratio Metric in the Level-1 Assignment

## 一、已有读数（非对比、几何进通路的全部实测）

| 臂 | 曲率如何进量化器 | `test_recall@10` |
|---|---|---|
| 冻结基线 | 常数 κ=1 | 0.056216 |
| `TIGER_struct_mixed_rq` | **实测逐商品 κ_i** 进一级代价 | **0.057905**（+3.0%） |
| LKC（#184） | 由分配结果**学出**的每码 κ_k 进一级代价 | 0.056408（+0.3%，≈ 基线） |
| HC-3（#177） | 三层前缀平均曲率进三层代价 | 0.054023（−3.9%） |
| AF3 结构蒸馏（#181） | 无标签 KL（非对比） | 0.054266（低于基线） |

两条可用的结论：

1. **用实测 κ 比学出来的 κ 好**（0.0579 vs 0.0564）——学到的 κ_k 把一级码压成 72/256、份额 8.34%，结构变了但召回没变。
2. 把同一个量**铺到三层**会掉分（#177）。

所以下一步不是再改 κ 的来源，而是改它**怎么进入代价**：现在两种做法都是"用绝对值 κ 当度规"，
而主线要求的结构量里还有一个从未用过的量——**组内外曲率差**。把它写成无量纲比值，就是"商品比它要去的桶更曲还是更平"。

## 二、主张（一句话）

一级代价的度规曲率不是 κ_i，也不是 κ_k，而是**两者的比** `ρ_ik = κ_i / κ_k`：
同一件商品放到"曲率相近"的码上代价小，放到"曲率差得远"的码上代价大，于是码本按几何区域自行分工，
而分配规则（Sinkhorn）与残差递推完全不变。

## 三、公式（唯一改动）

```
κ_i      = 冻结 AF3 表 results/research/issue167/kappa.json（均值 1.0、中位 0.9147、max 8.2671；缺失 31 项按 mean_frozen）
κ_k      = mean{ κ_i : 上一轮被一级分到码 k }        # 与 LKC 同口径，detach，每 epoch 刷新，空码保持，<1e-3 取 1.0
ρ_ik     = clip(κ_i / κ_k, 1e-3, 1e3)               # 无量纲比值，无自由参数
一级代价：C_1(i,k) ∝ d_{ρ_ik}( to_ball(r_1,i; ρ_ik), to_ball(c_{1,k}; ρ_ik) )
          d_κ(p,q) = (2/√κ)·asinh( √κ‖p−q‖_ε / √((1−κ‖p‖²)(1−κ‖q‖²)) )
          ‖p−q‖_ε = sqrt(‖p−q‖² + ε_pq), ε_pq = finfo(dtype).eps·max(‖p‖²,‖q‖²,1)
```

- **不变**：E16×H16 乘积装配（`d_M²=‖e1−e2‖²+d_H²/4`）、Sinkhorn（ε=0.003、50 sweeps、centring）、码本 K=256、三级残差递推、
  读出与导出、3000 epoch、seed 42、全局 batch 4096、无任何对比/配对损失。
- 与既有两臂的区别（必须写进规格）：`struct_mixed` 用 κ_i、LKC 用 κ_k、**本臂用比值 ρ_ik**；三者几何不同，故不是调参。
- 无新增可调常数：比值、刷新、触底、clip 界都由实测表与定义决定（clip 是数值护栏）。

## 四、开关（存在且接线正确，**不训练关闭臂**）

- `RATIO_OFF`：`ρ_ik ≡ 1`（等价基线的常数曲率）→ **必须与冻结基线损失与导出逐位一致**。
- `NUMERATOR_ONLY`：`ρ_ik ≡ κ_i`（退化为 `struct_mixed` 的几何）→ 必须与该臂损失逐位一致。
- `DENOMINATOR_ONLY`：`ρ_ik ≡ 1/κ_k`（只保留分母）。
- `BOTH_ON`：出厂（ρ_ik = κ_i/κ_k）。

## 五、验收（派发前，全部可测）

1. **`RATIO_OFF` 逐位一致**（对冻结基线）；**`NUMERATOR_ONLY` 逐位一致**（对 `struct_mixed`）——两臂都在库内，可作强回归。
2. **`d_κ` 性质**：κ=1 与冻结 `poincare_contract.distance` 一致（rtol 1e-6）；`p=q` 与 `‖p−q‖∈{1e-12,1e-9,1e-6,1e-3}` 梯度有限且 gradcheck（双精度）通过；对称、零距离、抽样三角不等式；`to_ball` 球内。
3. **`ρ_ik` 正确**：手算断言 `ρ = κ_i/κ_k`；clip 边界命中计数；`κ_k` 空码/触底规则生效。
4. **无梯度泄漏**：`κ_i`、`κ_k` 均 detach；编码器梯度只经 `d_{ρ}` 里的坐标项回传。
5. **一 epoch 真实入口冒烟**：损失有限、`ρ` 分位数有记录、代价矩阵非恒定、导出 SID 有效。
6. **导出统计**：全量 24587，逐层码数/最大份额（≤10%）、二级前缀、三级碰撞（并列基线 0.162444）、§63 `l3_collision`；`collision < 0.40`。
7. **TDD**：先写会失败的测试（两种退化态的逐位一致、`ρ` 手算与 clip、`κ_k` 刷新、`d_κ` 边界梯度），确认红后再实现。
8. 1–6 任一不过：按预派发负结果记录并停止，不改 ε/码本/刷新/clip。
