Idea：用 AF3 直接给出**每个行为边的目标前缀距离**（修正 #154 的度量，不是新方向）
英文名称：AF3-Targeted Prefix Distance Regression (corrected from #154)

#154 的三项监督已经接通（`L_gap` 向编码器回传 480.3、`L_tri` 9419.7 的 |grad|，c=1 与 c=0 的损失差
6.94e-4，8/8 batch 同时含高/低 AF3 边），但它被一条派发前门槛判负：把 `H`/`B` 换成同规模随机
边集时 `L_gap` 只变 6.0–7.0%（0.66336 对 0.70805 / 0.70470 / 0.70805），未达 2×。

这条门槛是**我写错的**：初始化时编码器完全不知道 AF3，任何"距离 vs AF3"的统计量都必然接近
零相关，"换成随机边集数值就该差 2×"要求的其实是"初始化就已经编码了结构"。真正要问的是
**这个监督项能不能把结构学进去**，这只能由两条同预算的拟合来回答。

同时 #154 的实现里有一处真实缺陷：`s_ℓ` 用 batch 内中位数与 MAD 标准化，所有 pair 的归属度被
压到 0.5 附近，损失对"到底用了哪些边"几乎不敏感（这正是 6–7% 的来源）。

## 一、主张（一句话）

把每条行为边的 AF3 换算成一个**目标前缀距离**，直接回归前缀空间里的 Poincaré 距离；
高 AF3（三角丰富、局部重叠）的边要求更近，低 AF3（树状分支）的边要求更远。

## 二、设计

1. **冻结结构证据（TRAIN only）**：逐边 `AF3(e) = 4 − deg(u) − deg(v) + 3·m_e`；取 5%/95% 分位
   `q05/q95` 做单调归一 `u_e = clip((AF3_e − q05)/(q95 − q05), 0, 1)`；表与分位写盘、记 SHA-256。
2. **目标距离**：`t_e = d_ref · (1 − u_e)`，`d_ref` = 冻结探针上同一批边的平均前缀距离（实测量，
   每个 run 只算一次并记入 checkpoint）。删掉 batch 内标准化（它抹平了 pair 之间的差别）。
3. **回归项**：`L_struct = mean_{e ∈ sampled edges} |d_e − t_e| / d_ref`，`d_e` 为边两端第 ℓ 级前缀嵌入
   的 Poincaré 距离（`mobius_add` + `d_c`，c=1），三层取平均；`[0,1]`。
4. **三角闭合项**（保留）：`L_tri = mean over 三边均属高 AF3 的三角形 (1 − min_{三条边} (1 − d_e/d_ref))`，
   归一化到 `[0,1]`；`λ_struct = λ_tri = 1`。
5. **其余不动**：代价函数、末级 Sinkhorn（均匀列目标、`SK_EPSILON=0.003`、`SK_ITERS=50`）、
   残差递推、读出、导出、三 token 结构；不引入桶/掩码/π/层心平移。
6. **开关**：`STRUCTURE_OFF`（两项置 0，逐位等于基线）、`GEOMETRY_OFF`（`c=0` 欧氏极限）、
   `BOTH_ON`（出厂）；只要求实现正确与廉价接线检查，不训练关闭臂（§19g）。

## 三、验收（派发前，冻结探针，全部可测）

1. **两臂差分学习（取代 #154 那条错误门槛）**：同一探针、同一数据顺序、同一 seed、同样固定
   200 步与训练器自身的优化器配置，跑两臂——R 用真实 AF3 目标，N 用同规模随机目标；要求
   R 的 "AF3 与前缀距离的秩一致性"（Spearman，越负越好）改善量 ≥ N 的 2 倍，且两臂都非惰性。
   只跑一次，不选模型、不调参。
2. **非惰性**：相对无监督基线，末级改码 ≥ 10%。
3. **对边集敏感**：同一 batch 上把边换成同规模随机边，`L_struct` 的**梯度**（而非损失值）方向
   余弦相似度 < 0.5 —— 直接检验"哪些边被用"是否真的决定梯度。
4. **曲线耦合**：同一 batch 上 `c=0` 与 `c=1` 的损失值不同（欧氏极限 1e-6 判据）。
5. **接线与一致**：`STRUCTURE_OFF` 与基线逐位一致（**含导出路径**）；训练与导出取同一码；
   checkpoint 绑 AF3 表 SHA、`q05/q95` 与 `d_ref`。
6. **覆盖**：≥95% 抽样 batch 含 ≥1 条高 AF3 边与 ≥1 条低 AF3 边；如实记录盲区（验证/测试商品
   无 AF3 边的比例）。
7. **TDD**：先写会失败的测试（目标距离单调性、`L_struct` 定义域与梯度、c=0 极限、训练/导出同码），
   确认红后再实现。
8. 任一门不过：按预派发负结果记录并停止，不改 `q05/q95`、不改 `d_ref`、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融、不做调参扫描、不做多种子（§19g）。
- 结构证据只来自训练划分；商品级 SID 全局一致；源码无绝对路径；`/tmp` 不落产物。
- 风险：`d_ref` 只在初始化测量，训练中尺度会漂移 → 由 `L_struct` 的归一化与两臂差分门控住；
  若两臂差分不成立，按负结果归档，不改目标函数重试。

## 五、与 #154 的差异（必须逐条写进规格）

| 项 | #154 | 本臂 |
|---|---|---|
| 归属度 | batch 内中位数/MAD 标准化的 sigmoid | **删除**，改为逐边目标距离回归 |
| 结构信号 | 高/低 AF3 两组均值差（对边集不敏感，实测 6–7%） | 逐边 AF3 → 目标距离（对边集敏感） |
| 闸门 | 随机边集须让损失变 2×（我写错的初始化期门槛） | **两臂同预算差分学习**（真实 vs 随机目标） |
| 常数 | `δ_ℓ`（初始化实测）、`d̄_ℓ`、MAD | `q05/q95`（数据分位）、`d_ref`（实测平均距离） |
