## 1. 闭合测试:三角形 vs 开放楔形(度数匹配)

两者都是"中心 + 两个相邻商品",都有两条行为边,唯一区别是**两个叶子是否相连**。中心与叶子的度数按桶匹配;采样 20000 个三角形、15315 个匹配的开放楔形。

**叶子对共享同一码的概率**

| 臂 | L1 三角形 | L1 开放楔形 | 倍数 | L1+L2 三角形 | L1+L2 开放 | 完整 SID 三角形 | 完整 SID 开放 |
|---|---|---|---|---|---|---|---|
| 基线 `TIGER_RQ-VAE` | **9.90 %** | 2.40 % | 4.1× | 1.01 % | 0.15 % | 0.27 % | 0.01 % |
| `TIGER_sinkhorn_all_levels_rq` | 6.93 % | 1.51 % | 4.6× | 1.15 % | 0.22 % | 0.17 % | 0.03 % |
| `resample`(召回 0.0634) | **13.08 %** | 1.67 % | **7.9×** | 1.20 % | 0.07 % | 0.16 % | ~0 |
| `mixed_rq_F0`(召回 0.0573) | 16.68 % | 5.54 % | 3.0× | 2.33 % | 0.35 % | 0.35 % | 0.01 % |

三项**全部**共享 L1 的比例(更严格):基线 2.65 % 对 0.57 %;`resample` 5.03 % 对 0.65 %。

结论:SID 确实能区分"闭合三角形"与"只是共享邻居的开放楔形",但幅度只有 **3–8 倍**,且绝对水平低(叶子对同 L1:7–17 %)。

## 2. AF3 分层:固定度数,看闭合度

`κ_ij = 4 − d_i − d_j + 3T_ij` 被度数主导,所以按**较大端点度数的桶 × 边自身三角数**(T=0 / 1 / ≥2)分层,近似固定度数只看闭合度。

**边的两端共享 L1 的比例**

| 度数桶 | T | 边数 | 平均 AF3 | 基线 | `resample` |
|---|---|---|---|---|---|
| ≤50 | 0 | 47801 | −45.0 | 8.14 % | 11.24 % |
| ≤50 | 1 | 15791 | −48.4 | 16.27 % | 26.42 % |
| ≤50 | ≥2 | 1789 | −47.6 | **31.30 %** | **57.57 %** |
| ≤100 | 0 | 29715 | −87.7 | 5.36 % | 5.83 % |
| ≤100 | 1 | 23029 | −98.0 | 9.44 % | 12.38 % |
| ≤100 | ≥2 | 7478 | −112.2 | 19.38 % | 28.34 % |
| ≤200 | 0 | 16848 | −153.7 | 3.90 % | 3.34 % |
| ≤200 | 1 | 22248 | −167.2 | 6.14 % | 6.68 % |
| ≤200 | ≥2 | 23796 | −204.7 | 11.22 % | 13.74 % |
| ≤500 | 0 | 7140 | −298.6 | 2.86 % | 1.74 % |
| ≤500 | 1 | 13777 | −313.8 | 4.42 % | 3.51 % |
| ≤500 | ≥2 | 37107 | −383.2 | 6.63 % | 6.02 % |

三点结论:

1. **在固定度数下,SID 对闭合度有单调响应**:每个度数桶里 T 越大、两端同 L1 的比例越高(基线 ≤50 桶:8.1 % → 16.3 % → 31.3 %)。
2. **低度数区差别最大**:`resample` 在 deg≤50、T≥2 时达到 **57.6 %**,是基线(31.3 %)的近两倍;而 deg≤500 时两者反而差不多(6.0 % 对 6.6 %)。
3. **AF3 值的符号区间不能直接当分组**:AF3 主要由度数决定(−45 到 −2200),同度数桶内 T 只带来 3–40 的变化,所以"高曲率区/低曲率区"必须换成"同度数下的 T 分层"才有意义。

## 3. 对机制的含义

- 现有 SID 已经保留了**部分闭合信号**(4–8 倍),不是完全没有;
- 但绝对量低:deg≤50、T≥2 的边也只有 31 %(基线)两端同 L1;
- 想要提升,目标应写成:**在同一度数层内,把 T≥1 的边的两端同 L1 比例继续推高**(而不是笼统地"让相邻商品同码")。
