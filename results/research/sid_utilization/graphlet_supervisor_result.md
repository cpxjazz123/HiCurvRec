# Graphlet Structural Supervisor(三角形/楔形分类)结果

## 机制

```
L = L_RQVAE + λ·BCE( f_θ(z_a,z_b,z_c), y )     y=1 三角形, 0 度数匹配楔形
```

- `f_θ` 排列不变:`φ(z)` 逐节点项 + `ψ((z_a*z_b + z_a*z_c + z_b*z_c)/3)` 成对交互项(消融开关 `interaction=False`);
- 梯度穿 `f_θ` 回到 Encoder,迫使商品向量携带结构;`f_θ` 训练后丢弃,导出仍为三层 SID;
- 楔形按三个节点各自度数桶匹配;图读取前校验 sha256;
- λ 由首 20 步中位数标定为总损失的 10 %(实测 7.45e-5)。

## 训练(4 × L40S DDP,1024/rank,全局 4096,seed 42)

| 量 | 值 |
|---|---|
| 分类准确率(末段) | **0.9189** |
| BCE(末段) | **0.1832**(起点 ln 2 = 0.693) |
| 最终碰撞率 | **0.1162** |
| 时长 | 20 分钟 |

**准确率 0.92 说明:仅凭三个商品向量,分类器就能以 92 % 的把握区分"闭合三角形"与"度数匹配的开放楔形"** —— 编码器确实携带了局部结构。

## 结论

1. **结构监督第一次"既学得到、又落到 SID 上"**:准确率 0.92、BCE 0.18,同时 SID 的 L1 增益 5.20(高于 L1 graphlet 4.28 与无图项 4.99),碰撞率 0.1162(仅次于 L1 graphlet 0.1134)。
2. **L2 前缀数最高(12329)**:说明细化层没有被牺牲。
3. **但仍未跨过 Stage3 门槛 0.10**;且相对普通边对比(增益 5.52、L1+L2 4.47),本次在 SID 层的结构增益并不更高。
4. 因此:**"编码器能否表示 graphlet"已得到肯定回答;"这种表示能否转化为更好的 SID"只得到部分肯定** —— 增益存在但未超过简单边对比。

## 下一步(按用户计划)

- 实验 C:在分类器输入中加入 AF3 曲率预测头(或在同一 `f_θ` 上多任务),比较 B vs C 是否带来额外 SID 增益;
- 若 C 不优于 B,则 AF3 对 SID 结构保留无增量价值的结论就有了直接证据。
