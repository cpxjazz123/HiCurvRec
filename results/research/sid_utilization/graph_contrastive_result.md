# 图对比结构项:结果(3000 epoch 完成)

## 机制

```
L = L_RQVAE + λ · L_contrast
L_contrast = −log softmax_{j,k}(cos(z_i,z_j)/τ, cos(z_i,z_k)/τ)
```

- 正样本:行为图的一条边;负样本:度数匹配的**非边**(同桶抽样、逐槽拒绝重抽,1024 锚 × 8 负样本,实测 100 % 填满);
- 余弦相似度(有界,不能靠缩小向量降损);
- τ:第一步用 `mean s(pos) − mean s(neg)` 标定,使初始 logit 差 = 1 nat;
- λ:第一步用 `0.1·r₀/(0.9·g₀)` 标定,实测 **1.862e-5**;
- 图来自 `results/research/behavior_graph/graph.npz`,读取前校验 sha256 与 metadata。

## 两个关键问题的回答

1. **边共享 L1 是否从 ~5 % 提升**:是,但幅度小 —— **5.58 % → 5.89 %**(+0.31 pp,+6 % 相对)。提升集中在**低度数边**:≤50 桶 8.81 % → **10.07 %**(+14 %);而高 degree 桶反而下降(≤500:3.00 % → 2.61 %)。
2. **是否损害码本利用率**:没有,反而改善 —— 碰撞率 **0.1938 → 0.1377**(−29 %),L2 前缀 **8548 → 10674**(+25 %),L1 仍 256/256 满用。

## 其它事实

- **没有坍缩**:跑满 3000 epoch;无界距离版在 ~150 epoch 被防坍缩地板中止。
- 与冻结基线相比,share-L1 仍低(5.89 % vs 8.11 %),但碰撞率更低(0.1377 vs 0.1693)。
- Stage3 门槛:collision 0.1377 ≥ 0.10 → **拒绝进入 Stage3**。
- τ 的实测值没有写入 metrics(只记录了 `graph` 与 `graph_weight`),属记录缺口。
