# E2:L2 组内 Graphlet 监督 —— 结果

## 机制

```
L = L_RQVAE + λ₂·L_graphlet2
S2(x,y) = Σ_k p2_x(k) p2_y(k)          (L2 的 256 个码字)
正样本 = 同 L1 组内的行为邻居;负样本 = 同 L1 组内、度数匹配的非邻居
```

L1 组由模型当前硬分配给出,每 50 epoch 重建;τ 与 λ 由首 20 步窗口的中位数标定(τ = max(中位正负差, 分数离散度),λ = share·median(recon)/((1−share)·median(term)))。

## 每轮实况

| 轮次 | λ₂ | graphlet2 项 | 说明 |
|---|---|---|---|
| 第 1 次 | 3.16e-7(0.07 %) | 0.74→2.5 漂移 | 单步标定取到离群点 → 该项 no-op |
| 第 2 次 | 4.9e-7 | 首步 80.5 | τ 的固定下限 1e-3 把 logit 放大到 ±80 → 中止 |
| **第 3 次(正式)** | **6.62e-5** | **0.693 全程 = ln 2** | 标定正确,但正负样本在 S2 上完全不可分 |

## 判读

1. **E2 的监督项全程停在 ln 2**:同 L1 组内,L2 的软分配没有把"行为邻居"与"度数匹配非邻居"分开。机制层面的假设**在当前形态下不成立**。
2. E2 相对自身 λ≈0 对照的结构增益升了 12 %(4.27→4.77、3.70→4.16),但**碰撞率从 0.1427 升到 0.1777**,L2 前缀从 10892 降到 9360 —— 有得有失,且考虑到该项处于随机水平,这部分差异不足以归因于机制。
3. **绝对最好的对照仍是**:碰撞率最低 = L1 graphlet(0.1134);结构增益最高 = edge-contrastive(5.52 / 4.47)。
4. 与冻结基线比:所有含监督的臂碰撞率都更低,但结构增益差异不大;基线的绝对共享最高(0.0964),因为它的 L1 使用更集中。

## 下一步可选

- **改接入位置**:把组内结构对比放在 L1 分配**之前**(用组掩码约束 L1 的 Sinkhorn 代价),而不是让 L2 去修补 L1 的残差;
- **加大项份额**:当前 3.4 %,可试 20 %(需理由,属常数变更而非扫描);
- 或按上述结果判定 E2 不成立,回到 L1/边层继续。
