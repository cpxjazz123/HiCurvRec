# 商品向量区分度 vs Stage3 召回(全臂)

数据:`results/research/sid_utilization/vector_stats_all.json`(脚本 `vector_stats_all.py`)。
口径:74 个「Stage3 有 `test_recall@10` + Stage2 `rqvae_best.pth` 与 `item_sids.json` 同时在盘上」的臂(165 个 Stage3 臂中其余 91 个的 Stage2 产物已被清理)。
商品向量 = Stage2 编码器对 `stage1_GeneEmbedding/output/sentence_t5.npy`(24587×768)的前向输出;SID 取前三码。

| 指标 | 定义 | Pearson | Spearman |
|---|---|---|---|
| PR | 协方差特征值的参与比(有效秩) | +0.08 | −0.03 |
| sep | 不同 SID 商品距离 / 同 SID 商品距离 | +0.22 | +0.06 |
| qerr | ‖z − Σ 码字‖ 均值 | −0.47(离群值驱动) | −0.06 |
| distinct | 不同三级 SID 数 / 商品数 | **+0.37** | **+0.26** |

分组中位数:

| 组 | n | PR | sep | qerr | distinct |
|---|---|---|---|---|---|
| recall > 0.06 | 12 | 7.65 | 2.71 | 0.336 | **0.960** |
| recall ≤ 0.06 | 62 | 11.17 | 3.86 | 0.116 | 0.783 |

`distinct` 的判别力(阈值扫描,低召回组通过率):

| cut | 高召回通过率 | 低召回通过率 |
|---|---|---|
| ≥0.90 | 12/18 = 67 % | 56/56 = 100 % |
| ≥0.93 | 9/13 = 69 % | 58/61 = 95 % |
| ≥0.95 | 9/12 = 75 % | 59/62 = 95 % |

结论:
1. 高召回臂的商品向量**不**更分散:PR 中位数更低(7.65 vs 11.17),sep 中位数更低(2.71 vs 3.86),秩相关均≈0。
2. 唯一正相关的是 **SID 区分率**(r=+0.37, ρ=+0.26):高召回臂的三级 SID 几乎一物一码(中位 0.960)。
3. 区分率只是**弱必要条件**,远非充分:`curvature-embedding-rq`(0.990)、`dul_rq`(0.984)、`dul_s_rq`(0.956)都高区分但召回 0.026–0.049。
4. 20 臂子集上观察到的 qerr 正相关(+0.77)在 74 臂上**不成立**(Spearman −0.06),是小子集伪影。
