# Graphlet-aware L1 结构监督:结果(3000 epoch 完成)

## 机制

```
L = L_RQVAE + λ · L_graphlet
L_graphlet = −log softmax( S1(三角形)/τ , S1(匹配楔形)/τ )
S1(a,b,c) = Σ_k p_a(k)·p_b(k)·p_c(k)     (k = L1 的 256 个码字)
```

- `p` = L1 软分配:量化器自己的距离矩阵,按 `VQLayer.center_distance` 居中,`softmax(−d/ε)`,`ε = SK_EPSILON`(0.003);
- 负样本 = **度数匹配的开放楔形**(三个节点各自的度数桶都匹配);
- 4096 对(三角形, 楔形)冻结池,每步抽 256 对;
- τ = 初始 `mean S1(三角形) − mean S1(楔形)`;λ = 首个 step 的 10 % 份额,实测 **7.79e-5**;
- 保留重建/量化损失、三层 Sinkhorn 与防坍缩地板;L2/L3 机制未改动。

## 逐条对照成功判据

| 判据 | 结果 | 结论 |
|---|---|---|
| 三角形共享 L1 概率提升 | 0.0175 → 0.0121(同一棵树) | **未提升** |
| **相对匹配楔形的结构对齐增益提升(核心)** | 5.04 → **5.35**(+6 %);但仍低于普通边对比 5.48 | **小幅改善,未超过对照** |

| L2 条件结构保留不恶化 | L1+L2 增益 **4.57**(四者最高),L2 前缀 11370(最高) | **改善** |
| 完整 SID collision 不恶化、目标 <10 % | 0.1938 → **0.1134**(四者最低),仍 ≥ 0.10 | 改善但未达标 |
| 码本不坍缩 | L1 256/256 满用,最小码距 0.0182(基线 0.0309) | 未坍缩,但码字更挤 |

## 判读

1. **Graphlet 监督在"相对结构"上有效但幅度有限**:同一棵树去掉该项是 5.04,加入后 5.35(+6 %),且 L1+L2 的相对增益是所有臂里最高的(4.57)——说明它主要改善**二级细化**方向。
2. **它没有超过普通边对比的核心指标**(5.48),按预先定义的判据,这一轮**不能宣称 Graphlet 监督优于边对比**。
3. **代价与收益同时出现**:collision 降到四者最低(0.1134)、L2 前缀最高(11370),但绝对三角形共享与边共享都下降 —— 即"更难撞车,但对同一条边的绝对聚集变弱"。
4. **仍未跨过 Stage3 硬门槛**(0.1134 ≥ 0.10)。

## 结论

- 假设 H1(Graphlet 信息本身能提高 SID 结构保真度):**部分成立** —— 相对增益与深层(L1+L2)结构改善,但绝对共享未升,且未超过边对比对照;
- 尚不足以支持"Graphlet 监督优于普通行为边对比"的主张;按判据应先补强(例如把负样本改为**同前缀内的难负样本**、或把 S1 作用到 L2),再谈加入 AF3。
