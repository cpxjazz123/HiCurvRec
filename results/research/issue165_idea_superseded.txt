两条结论：①"总耗时 ≤1.5× 基线"与"每层保留均衡计划"在本机制下**先天不相容**——基线导出不含任何 Sinkhorn；
②合批改的是指派规则，不是加速，必须删掉。

导出是一次性成本（3–4 s），相对 3000 epoch 的训练预算（≈15 分钟以上）不构成科学判据。因此本臂：
**把导出时间从派发门降为记录项**（只保留 ≤60 s 的合理性上限），改回单一贪心实现，并补齐 #162–#164 遗留的接线与门。

## 一、主张（一句话）

机制不变——第 1 层均匀配额、第 2/3 层按父前缀条件化配额、组内向量化贪心（单一实现）；
碰撞由配额保证（实测 0.0）；导出时间只记录并设 60 s 合理性上限；补齐 `ROUNDING_OFF` 接线、
两臂拟合、训练中护栏与 rank-batch 计时后派发一次 Stage2。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157 起，不改）**：`ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **配额（沿用 #162/#163，不改）**：第 1 层均匀 `⌊B/256⌋` + 余数；第 2 层在每个一级组内均分到 256 个二级码；
   第 3 层在每个二级前缀内均分到 256 个三级码。
4. **指派（单一实现）**：只用向量化贪心（按计划质量降序 + 并行配额计数器 + 剩余行按代价补齐）；
   删除 `assign_bucketed` 路径（#164 证明不等价）。
5. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003` / `50 sweeps` / centring、残差递推、读出、导出、三 token 结构。
6. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，逐位一致，**必须真正接到模块常量**）、
   `GEOMETRY_OFF`（`c=0`）、`BOTH_ON`（出厂）。

## 三、验收（派发前，全量导出 + 冻结探针，全部可测）

1. **入口碰撞 ≤ 0.05**（实测 0.0），二级前缀 ≥ 0.5·B；训练后同规则再测。
2. **容量恒等式**：每个父前缀下各子码计数等于配额；行和恰 1；逐层 `codes_used ≥ 240/256`。
3. **单一实现**：仓库内不存在第二条指派路径；`ROUNDING_OFF` 与基线逐位一致（含导出）。
4. **两臂差分学习**：R 改善 ≥ N 的 2 倍（分母为负时 `R ≥ 2·max(N,0)`）。
5. **尺度不变性 / 曲线耦合**：`d` 乘 0.25/4 时两项变化 ≤ 1e-6；`c=0` 与 `c=1` 损失不同（1e-6）。
6. **训练中护栏**：逐层 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`，越界即 FAIL 停止。
7. **训练与导出取同一码**；checkpoint 绑结构表 SHA 与 `σ_min`。
8. **时间（记录项，不是门）**：导出总耗时、三层计划耗时、指派耗时、rank-batch 指派耗时全部写入报告；
   只保留"导出总耗时 ≤ 60 s"的合理性上限。
9. **TDD**：先写会失败的测试（配额恒等式、`ROUNDING_OFF` 恒等、c=0 极限、训练/导出同码），确认红后再实现。
10. 1–7 任一不过：按预派发负结果记录并停止，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 配额指派）；Sinkhorn 本体（ε、迭代数、centring、代价）不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：碰撞按构造为 0 之后，召回是否提升取决于"配额强制的组合分散是否保留语义"——这正是 Stage3 要回答的；
  若 `test_R@10 ≤ 0.065`，按负结果归档，不改配额规则重跑。
