IDEA: HORIZON-MID-RQ
TITLE: Horizon-matched curved transition targets for every RQ prefix level (Klein-model Einstein midpoints of l-step behaviour successors as the level-l training target)
MOTIVATION: A generative recommender plays out an SID as a token sequence, so the coarse prefix is decided first and later tokens can only refine it. In a plain RQ-VAE every level is trained to reconstruct the item itself, so the coarse levels spend their capacity on item identity and carry no information about where the user goes next; prefix-conditioned generation then has to guess the transition from tokens that were never trained for it. This idea makes level l of the SID answerable for the l-step behaviour horizon, so the prefix hierarchy is aligned with the order in which the recommender emits it.
NOVELTY: Earlier rounds changed the quantizer's objects (Frechet/Karcher codebook means, feedback-driven per-level curvature, behaviour-entropy radial assignment) and the probes covered successor geo-shift, cones, Lorentz profile smoothing, curvature mixtures. This changes the LEVEL-WISE TRAINING TARGET instead: level l's partial code is pulled toward a closed-form curved midpoint between the item and the hyperbolic barycentre of its exact l-step training successors. The curved objects are the Klein-model Einstein midpoint and the Poincare distance of the partial code; no Karcher iteration, no per-level curvature, no radial re-scaling, no change to the Stage 3 protocol.
CHANGE: For each item and each RQ level l, build a target that is the geodesic (Einstein) midpoint between the item's latent and the hyperbolic barycentre of its l-step successors taken from a training-only transition matrix, and add the Poincare distance from the level-l partial quantized code to that target, normalised by the batch's own level-l reconstruction distance, to the RQ-VAE objective.
SPECIFICATION: p_i^l = EinsteinMid_kappa( z_i , Bary_kappa({w_ij^(l)}, {z_j}) ), Bary = exp_0(sum_j w_ij^(l) log_0(z_j)); loss adds (1/L) sum_l mean_i[ m_i * d_kappa(zhat_i^(l), p_i^l)^2 / Dhat_l^2 ] where zhat_i^(l)=exp_0(sum_{m<=l} c_m) with straight-through codes, w^(l) = top-k row of (S)^l with S = row-normalised training transition counts, Dhat_l^2 = stop-grad batch mean of d_kappa(zhat_i^(l), z_i)^2, m_i = 0 if item i has no training successors. kappa=1 fixed, L=3, k=8, no tuned weight.
COST: One one-off sparse precompute of S^1,S^2,S^3 (24556 x 8 x 8 per level, seconds, on CPU before training). Per step at the frozen scale (24556 items, 24 steps/epoch, 3000 epochs, assume batch B=1024): one stop-grad gather of 3 x B x 8 x d (d=64) = ~1.6M floats, three B x d Poincare barycentre/distance evaluations (~0.2M flops each) and one write of B rows into the running latent table; no additional encoder forward pass. Expected +2-5% wall clock, <2% peak memory, so the 3000-epoch four-card Stage 2 budget is unchanged.
HYPOTHESIS: For the idea to be worth keeping, level-1 prefix classes must become l=1 transition communities rather than item-identity clusters, so that a prefix emitted by the generator already narrows the next item's transition regime. Observable: level-1 code of an item changes more often than its level-3 code relative to a behaviour-off baseline, the transition-term gradient reaches the codebook (non-zero codebook grad norm attributable to L_trans), successor prefix predictability (held-out next-item rank given only the first SID to

ken) improves, and Stage 3 test_recall@10 exceeds 0.065 in the single coupled run.
RISKS: The midpoint targets can blur item identity so that distinct items collide at level 1 and reconstruction/recall fall; the running latent table is non-stationary early in training and can push codes before the encoder is meaningful (mitigated by the validity mask and by renormalising away unseen successors); a horizon-matched target may be hardest exactly where the user's branching is high, so items with diffuse successors get a near-mean target and no signal; if the batch-normalised scale Dhat_l^2 is dominated by a few outliers the term could be effectively dead for most items.
BEHAVIOR SIGNAL: Directed item-transition horizons from training sequences, i.e. the exact l-step transition distribution w_ij^(l) for l = 1..L, with top-k truncation and row renormalisation.
BEHAVIOR COMPUTATION: From the Stage 2 training split only: count all consecutive directed pairs (i_t -> i_{t+1}) inside each training sequence into a sparse C; row-normalise to S; S^1 = topk_renorm(S,8); S^2 = topk_renorm(S^1 S,8); S^3 = topk_renorm(S^2 S,8); store three fixed CSR matrices plus a per-item validity mask m_i (m_i = 0 when the row of S has zero mass). Computed once before training and frozen for all 3000 epochs.
LEAKAGE BOUNDARY: The transition matrices are built exclusively from the training-split interaction sequences that Stage 2 already trains on; validation and test sequences are never read, no user-level validation/test statistic enters, and the matrices are frozen before the first optimiser step, so no validation/test interaction can influence the SID construction or the codebook. The SID is still produced by the same frozen RQ-VAE pipeline and Stage 3 consumes it unchanged.
HYPERBOLIC OPERATOR: Poincare ball of fixed curvature kappa = 1 (radius 1), with exp_0(v) = tanh(|v|) v/|v|, log_0(p) = artanh(|p|) p/|p|, Poincare distance d_kappa(p,q) = arcosh(1 + 2|p-q|^2/((1-|p|^2)(1-|q|^2))), and the Klein-model Einstein midpoint of two points with weights 1/2: k = (g_a a_K + g_b b_K)/(g_a + g_b), g_x = 1/sqrt(1-|x_K|^2), a_K = 2a/(1+|a|^2), back-map p = k/(1+sqrt(1-|k|^2)).
HYPERBOLIC LOCATION: In training, inside the RQ-VAE objective: at each of the L residual-quantization levels, on the straight-through partial code position (so it back-propagates into the encoder, the level codebooks and hence the SID assignment). It does not act at inference; SID emission and the Stage 3 protocol are untouched.
COUPLING PATH: behaviour matrices S^l -> successor set and weights (i, l) -> hyperbolic barycentre of successor latents -> Einstein midpoint with the item latent -> Poincare distance to the level-l partial code -> gradient into codebook c_l and encoder -> which code each item receives at level l, i.e. its SID prefix. Behaviour supplies the target location and the horizon per level, geometry supplies both the target construction and the metric in which the partial code is scored; deleting the behaviour (weights zero, mask zero) makes the term identically zero, deleting the geometry turns the target into a Euclidean mean and the metric into L2, so either removal changes the same number that produces the codebook and encoder update.
COUPLING EQUATION: L_trans = (1/L) * sum_{l=1..L} mean_i [ m_i * d_kappa( exp_0(sum_{m<=l} c_m(i)) , (g_a a + g_b b)/(g_a+g_b) with a=Klein(z_i), b=Klein(exp_0(sum_j w_ij^(l) log_0(z_j))) )^2 / Dhat_l^2 ] with w_ij^(l) the behaviour term (top-k of S^l

) and d_kappa / Klein / Einstein-midpoint the curved terms; total objective L = L_rec + L_trans.
OBSERVABLES: (1) change in SID assignment: the fraction of items whose level-1 code differs from the behaviour-off baseline should exceed the fraction whose level-3 code differs; (2) codebook gradient norm contributed by L_trans (non-zero on all three levels); (3) prefix behaviour predictability: held-out next-item rank given only the first SID token, and the entropy of the l-step successor set conditioned on the level-l prefix, both should drop; (4) Stage 3 test_recall@10 as the judgement, compared against the 0.065 target.
ABLATION BEHAVIOR OFF: BEHAV=False sets every w_ij^(l) and every m_i to zero, so L_trans is identically zero and the run is exactly the frozen baseline RQ-VAE plus the (unused) transition code path; the SID assignment is the plain item-reconstruction assignment. This arm is implemented and switchable but is not trained.
ABLATION GEOMETRY OFF: GEOM=False replaces exp_0/log_0/Klein/Einstein-midpoint with Euclidean arithmetic (target = mean of tangent latents, two-point midpoint = 0.5(h_i + sum_j w_ij h_j)) and d_kappa with the Euclidean L2 norm, keeping the same behaviour matrices, horizons and normalisation; this is the Euclidean horizon-regularised RQ-VAE. Implemented, not trained.
ABLATION BOTH ON: GEOM=True and BEHAV=True: behaviour-derived l-step horizon targets, built by the Klein/Einstein midpoint and scored by the Poincare distance, on the straight-through partial code of every level; this is the single trained candidate.
SPEC EQUATIONS: # once, training split only
C[i,j] += 1 for each consecutive (i -> j) in a training sequence
S = rownorm(C); S1 = topk_renorm(S, k=8); S2 = topk_renorm(S1 @ S, 8); S3 = topk_renorm(S2 @ S, 8)
mask_i = 1[S row i has mass > 0]
# state: running latent table U (N x d), counts n (N); kappa = 1; L = 3
for each step with batch ids b, features x:
  h = E(x); z = exp0(h)                                  # tangent -> Poincare
  r = h; P = 0
  for l in 1..L:
     e = nearest_codebook(C_l, r)                        # straight-through
     P = P + e; r = r - e
     zhat = exp0(P)                                      # partial code position
     (idx, w) = S_l[b]                                   # (B,k) successor ids, weights
     valid = n[idx] > 0                                  # suppress unseen successors
     w = w * valid; w = w / max(sum_j w, eps) ; w = w * mask[b]
     zn = exp0(U[idx].detach())                          # stop-grad successor positions
     b_hyp = exp0( sum_j w_j * log0(zn_j) )               # hyperbolic successor barycentre
     pb = einstein_midpoint_2pt(z.detach(), b_hyp, 0.5, 0.5)   # Klein coords, g_x = 1/sqrt(1-|k|^2)
     D2[l] = sg( mean_i d_kappa(zhat_i, z_i.detach())^2 ) + eps
     Ltrans += (1/L) * mean_i[ w_row_mass_i * d_kappa(zhat_i, pb_i)^2 / D2[l] ]
  loss = L_rec + Ltrans
  # streaming stop-grad table update for the batch rows only
  n[b] += 1; U[b] += (h[b].detach() - U[b]) / n[b]
einstein_midpoint_2pt(a, p, wa, wb): aK = 2a/(1+|a|^2); bK = 2p/(1+|p|^2); g = 1/sqrt(1-|.|^2); k = (wa*g_a*aK + wb*g_b*bK)/(wa*g_a + wb*g_b); return k/(1+sqrt(1-|k|^2))
SPEC INPUTS OUTPUTS: Inputs: encoder tangent latents h (B x d), the three level codebooks, the frozen sparse behaviour matrices S1,S2,S3, the running latent table U and counts n, masks. Outputs: the scalar L_trans and, through straight-through gradients, updated encoder parameters and level codebook vectors,

i.e. a changed SID assignment; plus the updated rows of U and n. Returns no new tensors to the inference path.
SAFEGUARDS: clamp all Poincare radii to 1 - 1e-5 before every log/distance; clamp the arcosh argument to >= 1 + 1e-7 and use the log1p form arcosh(1+x) = log1p(x + sqrt(x(x+2))); clamp tangent norms to 30 before tanh; add eps = 1e-8 to Dhat_l^2 and to the successor weight normaliser; drop successors with n=0 and renormalise, set the item's weight to 0 if all are dropped; stop-gradient on every target, on the behaviour weights and on Dhat_l^2 so the term cannot be gamed by shrinking its own scale; torch.nan_to_num on L_trans; the behaviour matrices are read-only and the latent table is written only for items present in the batch.
