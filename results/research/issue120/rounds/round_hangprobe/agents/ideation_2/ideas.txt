STEP 2 (final answer, complete block) — one idea, Sinkhorn/OT coupling position, distinct from all earlier rounds.

IDEA: glsink-sid
TITLE: Graph-Laplacian-regularized Poincare Sinkhorn: the RQ-VAE assignment at every level is an optimal-transport plan whose cost is a hyperbolic distance and whose coupling term is the training transition graph.
MOTIVATION: A generative recommender emits SID prefixes; today each RQ level assigns items to codes by an independent hard argmin against a Euclidean residual, so items that users actually move between (directed transitions u->v) often land under different level-1 prefixes, and the generator must spend probability mass on prefixes that are behaviourally unrelated. The SID partition should be a balanced behavioural partition (co-occurring / transition-linked items share coarse prefixes, fine prefixes separate them only where content forces it) while still reconstructing item content.
NOVELTY: The curvature is not in a codebook update rule, not in a per-level curvature scalar, not in a radial or conical gate, and not in a successor-profile loss (all of which exist here). Here the whole RQ assignment is replaced by a Sinkhorn transport plan between the batch of item points and the code points, and the training transition graph enters as a Laplacian penalty on that plan; the curved cost and the behaviour penalty act on the same decision variable Q, so neither can be removed without changing the codes. The uniform column marginal of Sinkhorn also removes the usual code-usage weight (no constant to tune there).
CHANGE: At each RQ level the codebooks are points in a fixed-curvature Poincare ball, the item residual is mapped by exp_0 into the same ball, and the level's assignment is the entropy-regularized OT plan minimizing squared Poincare distance minus/plus a scaled behaviour-graph Dirichlet energy on the plan; the soft plan then forms the level's tangent residual and is passed to the next level, so every prefix in the hierarchy is shaped by both the geometry and the transitions.
SPECIFICATION:
 c = 1.0 (fixed negative curvature -c, unit ball); encoder f_theta(item features) -> x in R^d, u_i = x, p_i = exp_0(u_i) clipped to ||p|| <= 0.9.
 Codebooks: learnable tangent vectors U_l in R^{K x d}, l = 1..L; code points c_{l,k} = exp_0(u_{l,k}).
 Residual: r_i^{(1)} = u_i (tangent at origin); p_i^{(l)} = exp_0(r_i^{(l)}).
 Curved cost at level l: D^{(l)}_{ik} = d_{P,c}(p_i^{(l)}, c_{l,k})^2.
 Behaviour penalty on plan Q: R(Q) = sum_i sum_j P_ij ||Q_i - Q_j||_2^2 = 2 Tr(Q^T L Q) with L = I - P_sym, P the row-normalized top-k transition graph.
 Plan: Q^{(l)} = argmin_{Q in U(a,b)} <Q, D^{(l)}> + lambda * R(Q) + eps * sum Q log Q, a = 1/N_b (rows), b = 1/K (columns).
 Soft residual: ub_i = sum_k Q_ik u_{l,k}; r_i^{(l+1)} = r_i^{(l)} - ub_i; hard tokens for SID = argmax_k Q_ik (straight-through).
 Loss: reconstruction d_{P,c}(exp_0(sum_l ub^{(l)}), p_i)^2 + beta * sum_l ||r_i^{(l)} - ub_i^{(l)}||^2 (tangent commitment) + lambda_b * R(Q^{(1)}).
 Constants derived, never swept: lambda = median_{i,k} D_{ik} / (2 * median_i ||r_i - sum_j P_ij r_j||^2) measured once on the first batch at step 0 with no gradient; eps = 0.1 * median_{i,k} D_{ik} measured the same way; Sinkhorn iterations T = 10 (documented default); K = 256, L = 3, N_b = 1024.
COST: Graph build is a one-off O(nnz(T)) over the training split (24556 items, top-10 kept, sparse). Per step at the frozen scale (N_b = 1024 items/step = ceil(24556/24), K = 2

56, L = 3): the K x K curved code-distance matrix is 3 * 65,536 exp/log/distance evaluations (~2e5 ops) once per step; Sinkhorn is T = 10 iterations on 3 * 1024 x 256 = 7.9e5 plan entries (~8e6 elementwise ops forward, ~2.4e7 with the unrolled backward, memory ~10*0.79M floats per level, well under 1 GB); the Laplacian term is a sparse-dense product with ~1e4 nonzeros per batch times K (~2.6e6 flops). Total added work is ~3e7 flops per step, versus 72,000 steps (3000 epochs x 24), i.e. roughly +10 to +15 percent wall clock on Stage 2 and zero change to Stage 3 (inference uses the frozen tokenizer). No extra forward passes of the encoder.
HYPOTHESIS: If transition-linked items are pulled into the same coarse prefixes by the coupled plan, the prefix marginal the generator learns becomes sharper and less behaviourally diffuse, so Stage 3 test Recall@10 rises above 0.065 with one run. Observable: level-1 prefix co-membership of directed successor pairs and prefix predictability of v's first token from u both increase relative to the Euclidean/behaviour-off configurations, code usage stays near uniform by construction (column marginal 1/K), and Recall@10 exceeds the frozen baseline.
RISKS: The graph term may dominate at coarse levels and force a behaviour clustering that loses content information, damaging reconstruction and therefore the tail items; the derived lambda may be mis-scaled for the item-degree distribution; the 10-iteration unrolled Sinkhorn may be unstable early in training when codes are random; sparse graphs leave many items with an all-zero Laplacian row (they then fall back to pure curved assignment, which weakens the effect); Stage 3 may under-use the improved structure because of its own decoding constraints.
BEHAVIOR SIGNAL: Directed item-transition graph with popularity (in-degree) debiasing, built from consecutive-item transitions inside training-split user sequences.
BEHAVIOR COMPUTATION: For every training user sequence, add one count for each observed adjacent pair (u_t -> u_{t+1}); symmetrize by max(T_uv, T_vu) after in-degree debiasing (counts divided by log(1 + in_degree(v)) to stop hub items from dominating), keep the top-10 neighbours per item, drop self-loops, then row-normalize to get P (rows with no neighbour become identity rows). Computed once before Stage 2 from the train split only.
LEAKAGE BOUNDARY: The graph is a function only of train-split interaction sequences; validation and test interactions are never read in Stage 2, never enter P, never enter the codebooks, and Stage 3's test items are only scored with the frozen tokenizer, so no validation or test interaction can influence the SID construction or the derived constants.
HYPERBOLIC OPERATOR: Poincare distance d_{P,c}(x,y) = (2/sqrt(c)) artanh(sqrt(c) ||(-x) +_c y|| / (1 - c<x,y>_c)) with the exp_0 / log_0 maps, at fixed negative curvature c = 1.0.
HYPERBOLIC LOCATION: Inside quantization, at every RQ level: the assignment cost, the code-point parameterization, the soft residual composition and the reconstruction metric all live in the ball, so the curvature acts on the token partition itself rather than on a side loss.
COUPLING PATH: P -> Laplacian penalty on plan Q^{(l)} -> Q^{(l)} selects and weights codes -> soft tangent residual r^{(l+1)} -> curved cost d_{P,c}^2(exp_0(r^{(l+1)}), c_{l+1,k}) of the next level -> hard prefixes. Setting lambda = 0 changes Q, hence the codes; replacing d_{P,c} by the Euclidean distance changes Q, hence the codes

; the two cannot be separated because both live inside the same minimization.
COUPLING EQUATION: Q^{(l)} = argmin_{Q in U(1/N_b, 1/K)} sum_{i,k} Q_ik * d_{P,c}(exp_0(r_i^{(l)}), exp_0(u_{l,k}))^2 + lambda * sum_{i,j} P_ij ||Q_i - Q_j||^2 + eps * sum_{i,k} Q_ik log Q_ik
OBSERVABLES: (1) SID assignment changes: level-1 prefix co-membership rate of top-transition successor pairs and the fraction of distinct level-1 codes; (2) parameter updates change: gradient of the codebook tangents U_l now contains a Laplacian term through Q, and code usage is forced to 1/K by the column marginal instead of by a usage weight; (3) prefix behaviour predictability: accuracy of predicting v's first prefix token from u's prefix tokens on train-sequences; (4) Stage 3 test Recall@10 versus the frozen baseline.
ABLATION BEHAVIOR OFF: lambda = 0 and P = I, i.e. a purely geometric Sinkhorn assignment with curved cost and no behaviour coupling; the switch exists in code and is correct but is not trained in this round.
ABLATION GEOMETRY OFF: c -> 0 with exp_0/log_0 replaced by the identity, D^{(l)} = ||r_i^{(l)} - u_{l,k}||^2, reconstruction in R^d; the graph Laplacian term and Sinkhorn stay, giving a Euclidean graph-regularized RQ-VAE.
ABLATION BOTH ON: full coupled run, curved cost and Laplacian term active in the same plan, all levels.
SPEC EQUATIONS:
 # once, from train split
 for each train sequence, for t: C[u_t][u_{t+1}] += 1
 C_hat[u][v] = C[u][v] / log(1 + indeg(v))
 W[u][v] = max(C_hat[u][v], C_hat[v][u]); keep top-k (k = 10); W[u][u] = 0
 P = row_normalize(W); P[u][u] = 1 if row u has no neighbour
 # per step, for l = 1..L
 p_i = exp_0(clip_c(r_i, 0.9));  c_{l,k} = exp_0(u_{l,k})
 D_ik = d_{P,c}(p_i, c_{l,k})**2
 # Sinkhorn in log domain, T = 10
 K_mat = exp(-(D + lambda * (2 * (Q_prev - P @ Q_prev))) / eps)   # (N_b x K), Q_prev detached
 f = 0; g = 0
 repeat T: f = eps * log(a) - eps * logsumexp((K_mat + g) / eps, dim=0)
           g = eps * log(b) - eps * logsumexp((K_mat + f) / eps, dim=1)
 Q = softmax((K_mat + f + g) / eps, dim=1)    # rows and columns approximately a and b
 ub_i = Q @ U_l ;  r_i = r_i - ub_i ;  token_l(i) = argmax_k Q_ik (straight through)
 loss = d_{P,c}(exp_0(r_i), p_i_original)**2 + beta * sum_l ||r_i^{(l)} - ub_i^{(l)}||^2 + lambda_b * 2 * Tr(Q_1^T (I - P) Q_1)
SPEC INPUTS OUTPUTS: Inputs: item feature batch (N_b x d), learnable codebook tangents U (L x K x d), transition matrix P (24556 x 24556 sparse, top-10 rows), constants c, eps, lambda, T, K, L, beta, lambda_b. Outputs: per item per level the soft plan Q^{(l)} (N_b x K), the accumulated tangent residual r^{(L+1)}, the L hard SID tokens (integers in [0,K)), the differentiable loss.
SAFEGUARDS: clip ||r_i^{(l)}|| so that ||p_i|| <= 0.9 (equivalently ||r|| <= (1/sqrt c) artanh(0.9) = 1.472), preventing artanh blow-up at the ball boundary; compute d_{P,c} via the artanh form with the argument clamped to 1 - 1e-7; Sinkhorn in log domain with logsumexp, rows without graph neighbours replaced by identity rows in P so the penalty is zero rather than NaN; if any row of Q is all-zero or any column marginal collapses, fall back to the uniform plan for that row/column; lambda and eps computed once at step 0 from medians on the first batch and frozen (no sweeping); if lambda or eps is non-finite, set lambda = 0 and eps = 1 (documented fallback); detach Q_prev in the Laplacian gradient to keep the unrolled Sinkhorn stable; straight-through hard tokens for SID export, soft plan for grad

ients; top-k graph rows guarantee O(10 * N_b) work regardless of item degree.
