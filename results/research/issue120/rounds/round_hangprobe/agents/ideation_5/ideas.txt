IDEA: MOBIUS-PARALLEL-BEHAVIOUR-CARRY-RQ
TITLE: A behaviour target carried as a parallel Möbius hyperbolic residual through every RQ-VAE level, fused with the content residual in one Lorentz assignment cost resolved by a balanced Sinkhorn with no tunable constant.
MOTIVATION: A generative next-item recommender consumes SID prefixes, so a prefix is only useful if it is predictable from the user's history. A Euclidean RQ-VAE splits prefixes purely by reconstruction error: two items whose users behave completely differently can share a level-1 token, and two items that are virtual behavioural synonyms can get different level-1 tokens because of irrelevant numeric detail. The hierarchy therefore carries content detail at every depth and never carries behaviour, which is what the generator actually has to predict.
NOVELTY: Earlier rounds edited the codebook (successor-weighted Fréchet updates), the curvature scalar per level, successor-profile smoothing, cones, a successor boost/geometric shift of the latent, per-item radial ranking, and branch-conditioned mixture curvature. This idea touches none of those: the codebook, the curvature and the item latent all stay as in the baseline, and the change is a second residual stream. A behaviour target point is pushed through the SAME Möbius subtraction by the SAME selected codes as the content stream, so each deeper level quantises the leftover behaviour disagreement instead of only leftover reconstruction error; the assignment itself becomes an entropic Sinkhorn with uniform row and column marginals, which also removes any code-usage weight constant from the design.
CHANGE: For each level l, the item's level-l residual is scored against every code by a Lorentz distance to a behaviour residual point as well as to the content residual point; the behaviour residual point is produced by Möbius-subtracting the codes already chosen at levels 1..l-1 from a successor-averaged behaviour point. The fused cost is turned into a balanced soft assignment matrix by Sinkhorn, and the hard code is the argmax of that matrix.
SPECIFICATION: (1) Offline, from Stage-2 TRAIN sequences only: counts n_ij of directed transitions i->j inside a sliding window of 5 within each training session; row totals c_i; marginal q_j = (sum_i n_ij)/(sum_ij n_ij); add-one popularity-smoothed transition P(i,j) = (n_ij + q_j)/(c_i + 1). Stored as a CSR matrix, no validation or test interaction. (2) Behaviour point: m_i = sum_j P(i,j) * log_0^kappa(x_j) computed with detached item latents x_j once per epoch; b_i = exp_0^kappa(clip(m_i, R_tan)) where R_tan = 2 * median_i ||m_i|| measured once at the end of epoch 1 (clipped to 1/sqrt(kappa) - 1e-3). (3) Level loop with kappa = 1 fixed (curvature -1), codebooks C_l of the baseline size, content stream u^(1) = x_i, behaviour stream v^(1) = b_i: G_ik = d_L(u^(l), c_lk)^2 / Tu_l + d_L(v^(l), c_lk)^2 / Tv_l, where Tu_l, Tv_l are running medians of the two distance columns (reservoir of 4096 values per level, initialised from the first mini-batch), so the two terms are scale-normalised and the fusion weight is 1 by derivation rather than by sweep. (4) pi = Sinkhorn(-G / T) with row marginals 1/B and column marginals 1/K, 20 iterations, T = running median of G (same reservoir) so the entropic temperature is a measured quantity; hard code a_l(i) = argmax_k pi_ik. (5) Straight-through quantisation exactly as the baseline (forward c_{l,a}, backward identity), and after each level u^(l+1) = (-c_{l,a})

oplus_kappa u^(l), v^(l+1) = (-c_{l,a}) oplus_kappa v^(l). (6) The decoder, the RQ-VAE reconstruction loss and the Stage-3 protocol are unchanged.
COST: About +3 to +6 percent wall clock. Frozen scale: 24556 training items, 24 steps per epoch, roughly 1023 items per step, 3000 epochs = 72000 steps. Per step, with L levels and K codes: distance evaluations 1023*K*L (two Lorentz distances each, about 4d flops with d=64), i.e. about 0.2 GFLOP at K=256, L=3; Sinkhorn 20 iterations on a 1023*K*L cost tensor, about 0.06 GFLOP; two Möbius updates per item per level, about 2 MFLOP. Total extra forward cost is under 0.3 GFLOP per step, one to two percent of a transformer step at that batch. Once per epoch: one sparse-dense product (nnz(P) * d) plus one exp_0 and one clip over 24556 items, well under 1 GFLOP per epoch. One extra backward pass through the Lorentz/Möbius path, small relative to the encoder. No extra parameters and no extra training epochs.
HYPOTHESIS: If prefix predictability rather than reconstruction fidelity is what limits Stage-3 recall, then making each deeper level refine the behaviour residual must move the level-1 and level-2 partitions toward behavioural equivalence classes. It is worth keeping only if, on the single run, the mean Lorentz distance from an item's level-1 code to the level-1 codes of its high-probability successors falls relative to the Euclidean arm, the train-only successor-prefix agreement P(a_1(i)=a_1(j) | P(i,j) > tau) rises, and Stage-3 test_recall@10 exceeds 0.065. If those diagnostics move but recall does not, the generator is not the bottleneck and the idea is falsified by its own single run.
RISKS: The behaviour term can dominate at deep levels (it is scale-normalised, not bounded), duplicating codes and creating full-SID collisions; mitigated by the per-level medians, the R_tan clip and the baseline collision tie-break. Sinkhorn can become near-degenerate when G has a very large spread (max-normalisation of G inside the log-domain is required). Items with few training transitions get b_i close to the origin, so the behaviour term degenerates to a radius penalty for them. Hyperbolic residual carries shrink toward the origin at deep levels, which can make the behaviour stream vanish exactly where it should discriminate. The extra cost is small but the mechanism adds a second-order dependency on previously chosen codes, which can oscillate early in training.
BEHAVIOR SIGNAL: Popularity-adjusted directed item transitions. One signal, one computation, deliberately single (no branching, no co-consumption term) so that the coupling stays auditable.
BEHAVIOR COMPUTATION: From the Stage-2 training split only: for each training session, all ordered item pairs (i, j) with j occurring within a forward window of 5 positions after i are counted into n_ij; q_j is the global in-degree marginal over the same training split; the smoothed row is P(i,j) = (n_ij + q_j)/(c_i + 1) with c_i = sum_j n_ij. The behaviour point is m_i = sum_j P(i,j) log_0^kappa(x_j), b_i = exp_0^kappa(clip(m_i, R_tan)), recomputed once per epoch from detached latents. Nothing from the validation split and nothing from the test split enters n_ij, q_j, R_tan, Tu_l or Tv_l.
LEAKAGE BOUNDARY: All transition counts, the marginal q_j, the smoothing, R_tan and the running medians Tu_l and Tv_l are computed from the Stage-2 training interactions only, and the ReservoirMedians are updated from training mini-batches only; validation interactions are u

sed solely by the frozen Stage-3 evaluation that never feeds back into the SID encoder, so no validation or test interaction can enter the SID construction.
HYPERBOLIC OPERATOR: Fixed negative curvature kappa = 1 (sectional curvature -1) in the Poincare ball of radius 1/sqrt(kappa), with the Lorentz-equivalent geodesic distance d_L(x,y) = (2/sqrt(kappa)) artanh(sqrt(kappa) ||(-x) oplus_kappa y||), Möbius addition oplus_kappa, and the exp_0^kappa / log_0^kappa maps at the origin; it acts inside the assignment cost and inside the residual carry.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantisation step of every level, both in the assignment cost and in the residual update; the encoder, the decoder and the reconstruction loss are untouched. Curvature is fixed, not trained, so no auxiliary curvature loss exists.
COUPLING PATH: one path, two streams, one codebook. The behaviour distributions P(i,j) define the point b_i; b_i becomes the level-l behaviour residual v^(l) through the same Möbius subtractions applied to the content residual; v^(l) enters the same distance matrix that the content residual enters; the Sinkhorn on that fused matrix decides the code; that code is appended to the SID and is also subtracted from v^(l) for the next level. Setting P(i,j) to be uninformative destroys b_i and therefore the behaviour column; replacing the curved operators by Euclidean ones removes the geodesic geometry from both columns and from the carry. Either switch changes the selected codes, hence the SIDs and the generator's input tokens.
COUPLING EQUATION: G_ik^(l) = d_L(u_i^(l), c_lk)^2 / Tu_l + d_L(v_i^(l), c_lk)^2 / Tv_l, with v_i^(l) = (-c_(l-1),a_(l-1)(i)) oplus_kappa v_i^(l-1), v_i^(1) = exp_0^kappa(clip(sum_j P(i,j) log_0^kappa x_j, R_tan)), and a_l(i) = argmax_k Sinkhorn(-G^(l)/T)_ik. The behaviour term is P(i,j) through v_i^(l); the curved term is d_L / oplus_kappa / exp_0 / log_0 at kappa = 1.
OBSERVABLES: (i) SID assignment shift: the fraction of the 24556 training items whose level-1 and level-2 codes differ from the Euclidean arm; (ii) prefix behaviour predictability: train-only successor agreement P(a_1(i) = a_1(j) | P(i,j) > tau) and the mean geodesic distance from a_1(i)'s code to the level-1 codes of i's top-5 successors; (iii) code usage entropy per level, which should rise because the Sinkhorn marginals are uniform; (iv) Stage-3 test_recall@10 against the 0.065 target; (v) full-SID collision count, which must not regress.
ABLATION BEHAVIOR OFF: run_behaviour=False: P is replaced by a single uniform row (b_i = exp_0^kappa(clip(mean of log_0^kappa x_j, R_tan)), identical for every item, dependence on i removed) and the behaviour column is suppressed, so G_ik^(l) = d_L(u_i^(l), c_lk)^2 / Tu_l and no v stream exists; the curved code is untouched. Code exists, is exercised by unit tests against the behaviour-on path on a tiny batch, and is not trained as an arm.
ABLATION GEOMETRY OFF: run_geometry=False: kappa is replaced by the Euclidean limit, i.e. oplus_kappa becomes vector addition, exp_0/log_0 become the identity, d_L becomes ||u - c||^2 and the residual carry becomes plain subtraction, while the behaviour column keeps its full P and R_tan-based construction. The code path shares one function signature with the curved version so that only the operator table changes; it is not trained as an arm.
ABLATION BOTH ON: run_behaviour=True and run_geometry=True: the full coupled run, the single candidate run of this round, trained once on t

he frozen budget of 3000 Stage-2 epochs on four cards followed by the frozen Stage-3 protocol, no early stopping, no seed repetition.
SPEC EQUATIONS: kappa = 1; R = 1/sqrt(kappa) - 1e-3; eps = 1e-9.
exp_0^kappa(v) = (tanh(sqrt(kappa)*||v||) / (sqrt(kappa)*max(||v||, eps))) * v
log_0^kappa(x) = (artanh(min(sqrt(kappa)*||x||, sqrt(kappa)*R)) / (sqrt(kappa)*max(||x||, eps))) * x
x oplus_kappa y = ((1 + 2*kappa*<x,y> + kappa*||y||^2)*x + (1 - kappa*||x||^2)*y) / (1 + 2*kappa*<x,y> + kappa^2*||x||^2*||y||^2)
d_L(x,y)^2 = (4/kappa) * artanh(min(sqrt(kappa)*||(-x) oplus_kappa y||, sqrt(kappa)*R))^2
P(i,j) = (n_ij + q_j)/(c_i + 1); m_i = sum_j P(i,j) log_0^kappa(sg(x_j)); b_i = exp_0^kappa(clip_norm(m_i, R_tan))
u^(1) = x_i ; v^(1) = b_i
for l = 1..L:
  G = d_L(u^(l), C_l)^2 / Tu_l + d_L(v^(l), C_l)^2 / Tv_l        # shape B x K
  G <- G - G.min(dim=k)                                   # stabilise before exp
  Kt = exp(-G / max(T, eps))                               # B x K
  for t = 1..20:  r = (1/B) / (Kt.sum(dim=1) + eps); Kt = Kt * r; c = (1/K) / (Kt.sum(dim=0) + eps); Kt = Kt * c
  pi = Kt / (Kt.sum(dim=1, keepdim=True) + eps)
  a_l = argmax_k pi ;  code = C_l[a_l] ;  append code to SID
  u^(l+1) = (-code) oplus_kappa u^(l) ; v^(l+1) = (-code) oplus_kappa v^(l)
  quantised_z = code + (u^(l)_pre - sg(u^(l)_pre))      # straight-through, as baseline
ReservoirMedians: Tu_l, Tv_l, T updated every 50 steps from the current mini-batch; values frozen at eval.
SPEC INPUTS OUTPUTS: Inputs: item latents x_i from the encoder (batch of B x d, B ~ 1023), the codebooks C_l (K x d points in the ball, baseline size and initialisation), the fixed CSR transition matrix P with its row totals, and the three measured scalars per level (Tu_l, Tv_l, T). Outputs: per item an L-token SID (a_1..a_L), the same quantised latents and commitment/reconstruction losses the baseline already computes, and per level the soft matrix pi which is used only for the argmax and the usage-entropy diagnostic. No new learnable parameters are added other than the optional per-item behaviour points, which are cached buffers, not weights.
SAFEGUARDS: all norms clipped to R = 1 - 1e-3 before artanh, so the geodesic distance is always finite; Möbius denominator clamped to 1e-8 and the result re-projected onto the ball after every addition; exp_0 uses max(||v||, 1e-9) so the origin is safe; the commit of v^(1) uses detached latents so no gradient flows through the sparse transition row; R_tan is a measured median-doubled bound, not a chosen constant; the two cost columns are divided by their own running medians so neither can silently dominate; G is min-shifted before the exponential; if any Sinkhorn iterate contains a non-finite value the step falls back to pi = uniform and a_l = argmin_k G; remaining full-SID collisions are resolved by the baseline tie-break so injectivity is preserved; Tu_l, Tv_l and T are frozen at evaluation so the Stage-3 mapping is deterministic.
