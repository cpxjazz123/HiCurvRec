IDEA: HOPFRAME-TANGENT-RQ
TITLE: Hop-nested hyperbolic tangent frames: each item's residual quantisation is measured in a different negative-curvature reference frame at every RQ level, the frame being the geodesic barycentre of its h-hop training successors
MOTIVATION: A flat RQ-VAE measures every item's residual against the origin, so two items only get the same prefix when they are close in the encoder's absolute coordinates. But what makes two items "the same kind of next click" is that they *lead to* the same places: their successors overlap. The prefix hierarchy should therefore be relative to the item's own behavioural neighbourhood, coarse levels keyed to long-horizon successors and fine levels to immediate successors. Encoding that relative structure needs a curved frame: the successor means of a branching, heavy-tailed item sit near the ball boundary where Euclidean averaging collapses them, while the Poincare barycentre keeps them separated with depth proportional to branching.
NOVELTY: The three shipped mechanisms moved the *codebook update* (successor-weighted Frechet centroids), a *per-level scalar* (curvature from hard prefix-transition score) or the *radial rank* of assignment (context entropy). This idea leaves the codebook, the loss weights and the curvature scalar exactly as the baseline and instead changes the *reference frame of the residual*: an exact isometry (log map at a data-dependent point a_i^(l)) re-expresses both the item and every codebook entry in the frame of that item's h-hop successor barycentre, and the assignment metric is the pullback of the hyperbolic metric there. The frame is nested by hop count across RQ levels, which no earlier round used, and no cone, Sinkhorn or Frechet codebook update is involved.
CHANGE: Before each RQ level l, the encoder output p_i is exactly rewritten as z_i^(l) = log^kappa_{a_i^(l)}(p_i) in the tangent frame of a_i^(l), the weighted hyperbolic barycentre of the item's training successors within <= l hops, and each codebook point c_{l,k} is rewritten as u_{l,k}^(l) = log^kappa_{a_i^(l)}(c_{l,k}); the ordinary RQ residual/argmin/straight-through steps then run in that per-item frame and the reconstruction error is the geodesic distance back on the manifold.
SPECIFICATION: kappa = 1 (unit Poincare ball, curvature -1, documented default). p_i = exp^kappa_0(s * e_i) with s = 1/sqrt(d) and ||p_i|| clamped to 1-1e-5 along the ray. For l = 1..L, S_i^(<=l) = set of items reachable from i in 1..l directed training transitions, weights w_ij = n_ij / sum_{j'} n_ij' * (1/sqrt(pop_j)) / Z (pop = training interaction count, Z = normaliser). a_i^(l) = detached, EMA-smoothed (m = 0.9) Karcher mean in the ball of {p_j : j in S_i^(<=l)} with weights w_ij, 5 iterations; empty set -> a_i^(l) = 0. Assignment: r_0 = log^kappa_{a_i^(l)}(p_i); k_l = argmin_k || r_{l-1} - log^kappa_{a_i^(l)}(c_{l,k}) ||^2_2; r_l = r_{l-1} - log^kappa_{a_i^(l)}(c_{l,k_l}). Reconstruction loss = d^kappa( p_i, exp^kappa_{a_i^(l)}( sum_l log^kappa_{a_i^(l)}(c_{l,k_l}) ) )^2, geodesic distance on the ball; codebook loss = the same term with the straight-through copy for the codes; commitment = 0.25 * mean || r_{l-1}.detach() - log^kappa_{a_i^(l)}(c_{l,k_l}) ||^2_2. IDEA: DEMAND-SINKHORN-RQ
TITLE: Demand-matched hyperbolic Sinkhorn assignment: each RQ level's codeword usage target is the measured training transition demand of its items, balanced against a squared Poincare distance cost.
MOTIVATION: In a plain RQ-VAE every level assigns by nearest-code argmin, so code usage is an accident of encoder geometry while the generative recommender's decoding demand is extremely uneven: a handful of regions absorb most next-item transitions and the rest are starved (or, with balance-forcing, the hot regions are truncated). Items that the model must decode often get no dedicated prefix capacity, and their SIDs are forced to share a codeword with behaviourally unrelated items. The prefix hierarchy therefore does not allocate capacity where the next-item prediction mass actually lands.
NOVELTY: Previous mechanisms here moved codebook positions (successor-weighted Frechet means), the curvature value per level, or the radial magnitude of the item embedding. This idea changes neither: codebooks stay plain, curvature is a fixed kappa=-1, and item embeddings are untouched. What changes is the ASSIGNMENT OPERATOR at every level, from an independent per-item argmin to a small entropic optimal-transport problem whose column marginal is a measured behavioural demand vector (incoming directed transition mass of each codeword, refreshed with stop-gradient each 5 epochs). Equilibrium of the transport problem is a codeword partition matched to decode demand, not to raw encoder density; the curvature makes the transport cost a hyperbolic one so that coarse (near-origin, cheap) codes are preferentially claimed by high-demand mass and peripheral codes serve the sparse tail.
CHANGE: At each RQ level replace argmin_j d(z_i, c_j) by argmax_j P_ij where P is the Sinkhorn coupling of items to codes with cost C_ij = d_kappa(z_i, c_j)^2 and column marginal q = 0.5*pi + 0.5/K, pi being the normalized training-transition demand accumulated by the items currently sitting in each codeword.
SPECIFICATION: See SPEC EQUATIONS. Fixed kappa = -1 Poincare ball; cost mean-normalized so the entropic temperature eps=0.1 is dimensionless; T=5 log-domain Sinkhorn iterations; hard argmax + straight-through estimator, residual chain and commitment loss unchanged; demand vector pi computed only from training-split transitions with stop-gradient from a snapshot assignment refreshed every 5 epochs.
COST: Forward-only extra work. Per step (B=1024 items, L=4 levels, K=256): cost matrix 1024x256 = 262144 hyperbolic pairs per level (~25 flops each, ~6.6 MFLOP) plus 5 log-domain Sinkhorn sweeps (~1.3 MFLOP per level) => ~8 MFLOP/level, ~32 MFLOP/step, ~0.8 GFLOP per 24-step epoch. Sinkhorn is non-differentiable (selector only), so backward cost is unchanged; memory +4 MB (cost matrices). Demand refresh: one no-grad forward pass over all 24556 training items every 5 epochs, i.e. ~1/5 of a forward-only epoch amortized, about +0.8% per epoch. Measured wall-clock expectation 1.03x-1.08x baseline for 3000 epochs; no extra parameters, no extra seeds, no sweeps.
HYPOTHESIS: Worth keeping if (a) the realized per-codeword assignment counts become positively rank-correlated with measured transition demand (Spearman > 0 at coarse levels) while utilization (codes with >=1% of items) stays above the baseline's, and (b) this can only happen because the column marginal and the curved cost interact: with uniform q the counts revert to encoder density, with Euclidean cost t

he partition flattens toward near-origin codes. The single judged quantity is Stage3 test_recall@10 above 0.065 on the frozen protocol; the diagnostic is recorded, never used to gate.
RISKS: Sinkhorn with a non-uniform marginal can concentrate hot items onto a few cheap near-origin codes and starve tail prefixes, degrading prefix behaviour predictability; the 5-epoch snapshot of pi can lag a fast-moving assignment and oscillate; hyperbolic distance at high radii is ill-conditioned and can dominate the cost matrix; the residual chain may amplify a bad level-1 partition; the gain may be within single-seed noise.
BEHAVIOR SIGNAL: Directed item transitions aggregated as per-item incoming transition demand (destination flow), computed per codeword through the current prefix assignment.
BEHAVIOR COMPUTATION: From the training split only: over all training sequences, count every consecutive user transition u->i (all 24556 training items only) and set d_i = number of incoming transitions to item i; p = d / sum(d). At refresh time (every 5 epochs, no grad) compute each training item's codeword a_i^l for every level l with the current model, then pi^l_j = sum_{i: a_i^l = j} p_i normalized to sum 1, and q^l = 0.5*pi^l + 0.5/K. Codeword identity already carries its parent prefix, so the marginal is automatically prefix-conditional.
LEAKAGE BOUNDARY: Only training-split sequences are read; validation and test sequences are never touched by the demand computation, by the cost, or by the snapshot forward pass (snapshot uses training items in eval mode, no labels). No future-item information enters: d_i uses transitions inside training sequences only. The marginal is a function of training counts and of the current model parameters, never of evaluation interactions.
HYPERBOLIC OPERATOR: Squared Poincare distance with fixed negative curvature kappa = -1 (ball radius 1), C_ij = d_{-1}(z_i, c_j)^2 with d(x,y) = arcosh(1 + 2||x-y||^2 / ((1-||x||^2)(1-||y||^2))); it is the ground cost of the entropic transport problem at every RQ level.
HYPERBOLIC LOCATION: Inside quantization, at the assignment step of every RQ level in Stage 2 training (and identically at inference-time encoding, frozen), as the ground metric of the Sinkhorn coupling that produces the hard code index.
COUPLING PATH: behaviour demand p -> snapshot codewords -> column marginal q^l -> Sinkhorn coupling P (whose cost rows are hyperbolic) -> argmax -> discrete SID digit and residual r = z - c_a. Removing the behaviour marginal makes the transport balanced/uniform and the partition collapses back to encoder density; replacing the hyperbolic cost with the Euclidean one changes which codes are cheap for high-radius items, hence changes P. Both enter the SAME matrix iteration, so neither can be removed without changing the emitted SIDs.
COUPLING EQUATION: P = Sinkhorn_{eps}( C_ij = d_{-1}(z_i, c_j)^2 , r = 1/B , q^l = 0.5*pi^l + 0.5/K ), with pi^l_j = normalize( sum_{i: a_i^l = j} p_i ); a_i^l = argmax_j P_ij.
OBSERVABLES: (1) Discrete SIDs: level-wise assignment changes versus a plain-argmin record, and a codeword-demand rank correlation that is positive at levels 1-2; (2) codebook utilization per level and the count of empty/hot codes; (3) the induced prefix behaviour predictability (mean log-likelihood of the observed next-item prefix under the empirical prefix->next-prefix table built on training data) recorded as a diagnostic; (4) Stage3 test_recall@10 versus the 0.065 target on the frozen pr

otocol, single run.
ABLATION BEHAVIOR OFF: use_behaviour_marginal=False makes q^l = uniform 1/K at every level; the hyperbolic cost and Sinkhorn iterations stay, so the transport reduces to balanced hyperbolic assignment (equivalent to a soft k-means with capacity constraint).
ABLATION GEOMETRY OFF: use_hyperbolic_cost=False replaces C_ij by ||z_i - c_j||^2 with the same mean-normalization and the same demand marginal q^l, keeping Sinkhorn identical.
ABLATION BOTH ON: q^l from measured demand AND the squared Poincare cost: the full coupled run, which is the only arm trained.
SPEC EQUATIONS: Precompute (training split only): d_i = #{u -> i transitions in training sequences}, p = d/sum(d).
Every R=5 epochs, no grad: a_i^l = current hard codeword of training item i at level l; pi^l_j = sum_{i:a_i^l=j} p_i; pi^l /= sum_j pi^l_j; q^l = 0.5*pi^l + 0.5/K.
At each Step 2 training step, for l = 1..L:
  z <- residual input at level l (B x d), C_ij <- d_{-1}(z_i, c_j)^2, C <- C / mean(C)
  Lp <- -C / eps with eps = 0.1 (dimensionless because C is mean-normalized)
  repeat T = 5 times:
     Lp <- Lp - logsumexp_over_j(Lp) + log(1/B)      (row marginal uniform)
     Lp <- Lp - logsumexp_over_i(Lp) + log(q^l)      (column marginal demand)
  P <- exp(Lp); a_i <- argmax_j P_ij
  if row is all NaN/-inf or ties for more than 1 code: a_i <- argmin_j C_ij
  quantize q_i <- c_{a_i} (straight-through), r <- z - q_i, feed r to level l+1
Frozen-scale instantiation: 24556 training items, B = 1024 (24 steps/epoch covers the training set), L = 4 levels, K = 256 codes/level, 3000 epochs.
SPEC INPUTS OUTPUTS: Inputs: residual z (B x d real), level codebook C^l (K x d on the Poincare ball), curvature kappa=-1, refreshable demand marginal q^l (K,), constants eps=0.1, T=5, R=5. Outputs: integer code index a_i per item per level (defining the K^L SID digits), the quantized vector for the straight-through path, and the residual for the next level; plus the updated pi^l at refresh epochs.
SAFEGUARDS: (1) Project every code and every residual input into the ball with ||x|| <= 1 - 1e-3 before computing the distance (and rescale by 0.9999 if a norm exceeds it); (2) clamp the arcosh argument to >= 1 + 1e-7 and floor (1-||x||^2) at 1e-6; (3) mean-normalize C per level per step so eps is scale-free and cannot drift with training; (4) log-domain Sinkhorn with logsumexp over masked finite entries, replace non-finite cost entries with the per-level max finite cost; (5) floor the marginal at 1e-6 and renormalize so log(q) is finite for every code - no codeword can be structurally forbidden; (6) deterministic fallback argmin_j C_ij whenever a coupling row fails; (7) demand vector is a stop-gradient buffer, never differentiated, and is only read after the refresh so it cannot create a parameter feedback loop inside a step; (8) if V<K or a code is empty in the snapshot, its pi_j is the prior 1/K before shrinkage, so q stays valid.
