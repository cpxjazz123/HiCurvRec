IDEA: PMIANCHOR-CURVED-RQ
TITLE: Popularity-adjusted neighbour anchors steer a curved RQ-VAE residual: a behaviour-conditioned Poincare code selection that constrains every SID prefix level
MOTIVATION: Content-only RQ-VAE Semantic IDs place items that play the same behavioural role in different prefix subtrees, because a co-consumed complement and its partner usually look nothing alike. The Stage-3 generative recommender then has to learn the same next-prefix distribution once per subtree and adjacent prefixes compete, so recall saturates below the 0.065 target. The aim is a prefix hierarchy that is partially role-aware while remaining content-decisive, without touching the codebook size, the curvature schedule or the frozen Stage-3 protocol.
NOVELTY: Neither the codebook nor the curvature is changed: no Frechet/Einstein codebook update, no per-level curvature control, no radial or rank modulation, no successor-profile smoothing, no cones, no mixture-of-branches. The behaviour signal is a symmetric popularity-corrected (PMI) co-consumption graph, not the directed successor distribution used by the earlier rounds. It enters as a SECOND GEODESIC ENDPOINT inside the level-wise argmin: every level compares the same candidate code both to the current content remainder point and to the current behaviour-anchor remainder point in the same Poincare metric, and the anchor remainder is propagated with the chosen code tangent vector, so the behaviour constraint is active at levels 1..L rather than at one level or in one loss term.
CHANGE: The residual chain is redefined in the tangent chart at the ball origin, the level-l code is chosen by a two-term Poincare score (content-remainder distance plus clipped behaviour-anchor-remainder distance), and the reconstruction loss becomes the Poincare distance to the exponential image of the sum of chosen code tangent vectors.
SPECIFICATION: Frozen training-item embeddings z_i (N=24556, dim d). Scale kappa = artanh(r_max)/(sqrt(c)*s) with s = 99th percentile of ||z_i||, r_max = 0.9, c = 1, so p_i = exp_0(kappa*z_i) and its tangent vector is r_1^i = kappa*z_i. From training-session co-occurrence build positive-PMI neighbours j of i (top k=20) with weights w_ij proportional to PMI_ij normalized to one; the behaviour anchor is the closed-form Einstein midpoint a_i = sum_j w_ij*gamma_j*p_j / ||sum_j w_ij*gamma_j*p_j||, gamma_j = 1/(1-c||p_j||^2), and a_1^i = log_0(a_i). Greedy loop l = 1..L: atilde_l = a_l * min(1, ||r_l||/||a_l||); score_k = d_c(exp_0(r_l), e_{l,k})^2 + d_c(exp_0(atilde_l), e_{l,k})^2; take the argmin, emit SID_i[l] = k, set u = log_0(e_{l,k}), then r_{l+1} = r_l - u and a_{l+1} = a_l - u. Loss = mean_i d_c(p_i, exp_0(sum_l u_{l,c_l}))^2 plus the baseline commitment term; codebook update rule unchanged. Both score terms carry weight 1 by unit symmetry, the anchor clip ratio is 1, k = 20 is a documented default (twice the Recall@10 cut-off) and only positive PMI is admitted, so no constant is swept.
COST: Per step: 2*L*K*B = 2*3*256*1024 = 1.57M curved distance evaluations (about 40 MFLOP plus ~5M tanh/artanh) plus B*L = 3072 exp_0/log_0 calls, against a transformer step of order 1e11 FLOP, i.e. expected below 3% step time and below 2% wall-clock over 3000 epochs x 24 steps = 72000 steps. One-off CPU preprocessing: sparse session co-occurrence over 24556 items (10^5-10^6 pair increments), top-20 neighbour lists about 4 MB, N*d anchor floats; zero recurring cost because training-split transitions are fixed.
HYPOTHESIS: If SID prefixes carry behavioural role, then items co-consumed far more than popularity predicts will share level-1 and level-2 prefixes far more often than content-only assignment allows, level-2/3 prefix conditional entropy on training sequences will fall, and the single frozen Stage-3 run will give test_recall@10 above 0.065. The idea is worthless if recall stays at or below 0.065 while the logged steering rate (share of items whose chosen code differs from the content-only argmin) exceeds 5% and the PMI prefix share rose, or if the steering rate is near zero, in which case the coupling is inert.
RISKS: Behaviour anchors can drag items into codes that no longer decode their content, raising reconstruction error and making the SID ambiguous for the recommender.; Chain-like catalogues may compress into shared level-1 codes and inflate collisions, so the generative model cannot resolve adjacent items.; PMI counts over long sessions are noisy for rare and cold items, whose anchors are then neutral and contribute nothing.; The discrete argmin gives no direct gradient, so the encoder only feels the behaviour through reconstruction of the newly chosen code; the effect may be too weak.; A single seed may not separate a small genuine gain from seed noise near the 0.065 threshold.
BEHAVIOR SIGNAL: Popularity-adjusted co-consumption neighbours of each training item (positive-PMI top-20) and their PMI weights, condensed into one Einstein-midpoint anchor per item.
BEHAVIOR COMPUTATION: Training split only: for every training user sequence, deduplicate items, increment item counts n_i and unordered pair counts n_ij; p_ij proportional to n_ij, p_i proportional to n_i; PMI_ij = log(p_ij/(p_i*p_j)); keep neighbours with PMI_ij > 0, top 20 by PMI, weights w_ij proportional to PMI_ij. Computed once before Stage 2 and stored as a frozen buffer.
LEAKAGE BOUNDARY: The PMI graph, the anchor tensor, the scale s and the clip ratio are all computed from training-split sequences and training-item embeddings before Stage 2 and stored read-only. No validation or test interaction enters the counts, the anchors or the SID construction; no checkpoint selection, early stopping or Stage-3 tuning touches them, and every constant is fixed before the run starts.
HYPERBOLIC OPERATOR: Poincare ball with fixed negative curvature c = 1: origin exponential and logarithmic maps exp_0(v) = tanh(sqrt(c)||v||)*v/(sqrt(c)||v||), log_0(p) = artanh(sqrt(c)||p||)*p/(sqrt(c)||p||), Moebius distance d_c(x,y) = (2/sqrt(c))*artanh(sqrt(c)||(-x) xor_c y||), and the closed-form Einstein midpoint for the anchor.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantization during Stage-2 training: the level-wise code selection score, the residual recursion and the reconstruction term. The codebook entries remain ball points used through the tangent chart at the origin, with unchanged count and update rule.
COUPLING PATH: One loop per item: the content remainder r_l and the behaviour-anchor remainder a_l are both exp-mapped into the ball and both compared to the SAME candidate code with the SAME curved metric; the winning code's tangent vector updates both remainders. The chosen code therefore depends jointly on the PMI-derived anchor and on the curvature, and removing either (anchor term or curved metric) changes the code sequence produced at every level.
COUPLING EQUATION: score_l(k) = d_c(exp_0^c(r_l^i), e_{l,k})^2 + d_c(exp_0^c(atilde_l^i), e_{l,k})^2 with atilde_l^i = a_l^i * min(1, ||r_l^i||/||a_l^i||), r_{l+1} = r_l - u_{l,c_l}, a_{l+1} = a_l - u_{l,c_l}, a_1^i = log_0^c(EinsteinMidpoint{w_ij, p_j}), u_{l,k} = log_0^c(e_{l,k}).
OBSERVABLES: Steering rate per level (share of items whose chosen code differs from the content-only argmin, logged in the same run); PMI-neighbour prefix share at level 1 and level 2 of the produced SIDs; per-level code usage entropy; level-2 and level-3 prefix conditional entropy on training sequences; reconstruction Poincare error; Stage-3 test_recall@10 as the judgement.
ABLATION BEHAVIOR OFF: Flag behaviour_anchor = False sets atilde_l := r_l at every level, so the two score terms coincide, the argmin equals the pure curved RQ ordering and the mechanism reduces to the curved baseline. The flag exists and is unit-tested on a fixed batch, but no such arm is trained.
ABLATION GEOMETRY OFF: Flag hyperbolic = False replaces exp_0/log_0/d_c by identity maps and Euclidean norms: score_k = ||r_l - e_{l,k}||^2 + ||atilde_l - e_{l,k}||^2, the anchor is the weighted Euclidean mean of neighbour embeddings and the reconstruction is a squared Euclidean error. Exists, never trained.
ABLATION BOTH ON: The full coupled run: PMI Einstein-midpoint anchors active and the Poincare metric active at every level. This is the single trained candidate.
SPEC EQUATIONS: p_i = exp_0(kappa z_i), kappa = artanh(0.9)/s, s = q99(||z||); gamma_j = 1/(1-||p_j||^2); a_i = (sum_j w_ij gamma_j p_j)/||sum_j w_ij gamma_j p_j||, w_ij proportional to max(PMI_ij,0) over the top-20; a_1 = log_0(a_i); for l = 1..L: atilde = a_l * min(1, ||r_l||/max(||a_l||,1e-8)); s_k = d_c(exp_0(r_l), e_{l,k})^2 + d_c(exp_0(atilde), e_{l,k})^2; c_l = argmin_k s_k (lowest index on ties); SID_i[l] = c_l; u = log_0(e_{l,c_l}); r <- r - u; a <- a - u; loss = mean_i d_c(p_i, exp_0(sum_l u_{l,c_l}))^2 + beta*mean_i ||r_1^i - sg(sum_l u_{l,c_l})||^2 with beta as in the baseline.
SPEC INPUTS OUTPUTS: Inputs: frozen training-item content embeddings z_i, training-split SID-construction session sequences for the PMI graph, an L-level x K-code codebook of ball points, and the two flags behaviour_anchor and hyperbolic. Outputs: one SID tuple (c_1..c_L) per item, the curved reconstruction loss with gradients for encoder and codebook, and a diagnostics record with steering rates, PMI prefix shares, usage entropy and per-level prefix entropy.
SAFEGUARDS: Clamp ||p|| <= 0.9 and every artanh argument to 1-1e-7; eps = 1e-8 in the clip-ratio denominator and in all norms; if the Einstein-midpoint numerator norm is below eps or the item has no positive-PMI neighbour, set a_1 := r_1 so the anchor term duplicates the content term and the baseline ordering is exactly preserved; keep the anchor a detached frozen buffer so no gradient forces the encoder to satisfy behaviour; deterministic tie-break by lowest code index; no codebook reinitialisation, usage-weight or temperature sweep is introduced; all diagnostics are recorded only and never gate the run.
END IDEA
