IDEA: SUCC-CHART-RQ
TITLE: Successor-anchored exponential chart: every RQ residual is geodesically re-expressed at a behaviour-derived prefix-successor basepoint
MOTIVATION: A generative recommender consumes SID prefixes as tokens, so what matters is that an early prefix already narrows the plausible NEXT item. A plain residual quantiser spends levels 2..L on the reconstruction error of the item's own embedding, which is behaviour-blind: two items in the same prefix bucket with disjoint successor sets keep diverging down branches that carry no transition information.
NOVELTY: The earlier rounds moved the codebook centroids (Poincare-Frechet successor codebook), the per-level curvature scalar (CURVCTRL-SID), or the radial rank of the assignment (BRad-RQ). SUCC-CHART-RQ keeps the codebook shared and unmoved and keeps curvature fixed at c=1; it changes the POINT AT WHICH THE RESIDUAL IS EXPRESSED (basepoint of exp/log), chosen per item and per level from the successor distribution of that item's current PREFIX bucket, and it transports the residual along a geodesic with a weight equal to the error-to-signal ratio, so there is no coupling hyperparameter to tune.
CHANGE: After each level's code is chosen, the residual is replaced by the point on the Poincare geodesic running from that code to a successor-Frechet basepoint of the item's prefix bucket, blended by error/(error+behaviour gap), and that point is what level l+1 quantises.
SPECIFICATION: Directed within-session training transitions give p(j|i). The level-(l+1) basepoint b_{l+1,i} is the weighted Poincare (Karcher) Frechet mean of the ball-mapped encoder outputs of the top-M=16 successors of the level-l prefix bucket of i. Geometry: fixed curvature c=1 Poincare ball, Mobius addition, exp/log at the chosen code, geodesic interpolation, hyperbolic reconstruction distance. Coupling: x_{l+1} = exp_c((1-a_l) log_c(x_l) + a_l log_c(b_{l+1,i})), a_l = d_P(x_l,c)/(d_P(x_l,c)+d_P(c,b_{l+1,i})+eps). Switches B (behaviour off) and G (geometry off) exist in code; only both-on is trained.
COST: Per step (batch 1023, L=4, d=64): 4x1023 exp/log pairs plus 4x1023 Mobius sums ~12k curved ops, under 1 ms on one card, under 5% of baseline step time. Per epoch (24 steps, 24556 items): prefix-bucket hashing 24556x4 keys (~0.1 s) plus basepoint refresh 24556 items x 5 levels x M=16 neighbours x 5 Karcher iterations x d=64 ~5e8 flops (~0.05 s). Over 3000 epochs the refresh is the only recurring addition, ~1.5e12 flops total (minutes), on the same four cards with stop-gradient.
HYPOTHESIS: If the successor basepoint is a genuinely useful conditioning signal, levels 2..4 stop encoding pure reconstruction error and start encoding which successor branch the item belongs to: P(next item's level-l code | first l codes) rises at l=2..4 versus a plain hyperbolic RQ, and the single both-on run exceeds Stage 3 test_recall@10 = 0.065. If prefix predictability rises but recall does not, the generative model is not exploiting the reallocated bits and the idea should be dropped.
RISKS: (1) The behaviour pull corrupts the reconstruction objective, so decoder item identification degrades and nets out negative. (2) Prefix buckets are coarse and noisy early in training, making the basepoint meaningless for the first few hundred epochs; the origin warm start must be fixed a priori, not tuned. (3) Long-tail items with no successors fall back to the origin and gain nothing. (4) Poincare arithmetic near the boundary yields NaNs under mixed precision. (5) Single-run seed noise can swamp a 0.001-0.003 recall effect.
BEHAVIOR SIGNAL: Directed within-session item transitions (successor distribution p(j|i)), aggregated to SID prefix level.
BEHAVIOR COMPUTATION: From the training split only: in every training session, every consecutive pair (u_t, u_{t+1}) increments n(u_t,u_{t+1}); p(j|i) = n(i,j)/sum_j n(i,j) after dropping self-pairs. For level l+1 and item i, q_{l+1}(j|i) = (1/|G_l(i)|) sum_{i' in G_l(i)} p(j|i'), where G_l(i) is the set of training items sharing the first l codes with i (G_0(i)={i}); the basepoint uses the top M=16 entries of q.
LEAKAGE BOUNDARY: p is estimated only from consecutive pairs inside training-split sessions; validation and test sessions never touch n(.,.), never define G_l, never define a basepoint. Prefix buckets come from the model's own assignment of TRAINING items only. No validation or test item enters the codebook, the basepoints, any training SID, or any gradient.
HYPERBOLIC OPERATOR: Poincare ball of fixed curvature c=1 (sectional curvature -1) with Mobius addition a(+)b, exp_x(v) = x (+)( tanh(sqrt(c)||v||/2) v/(sqrt(c)||v||) ), log_x(y) = (2/sqrt(c)) artanh(sqrt(c)||(-x)(+)y||) ((-x)(+)y)/||(-x)(+)y||, d_P(x,y) = (2/sqrt(c)) artanh(sqrt(c)||(-x)(+)y||); the Frechet mean is the Karcher fixed point m <- exp_m( sum_j w_j log_m(z_j) ).
HYPERBOLIC LOCATION: Inside the residual-quantiser recurrence at every level l=1..L (L=4), inside the reconstruction loss d_P(z, MobiusSum(c_1..c_L))^2, and inside the per-epoch basepoint Frechet mean (stop-gradient).
COUPLING PATH: behaviour -> q_{l+1}(.|i) -> top-M -> weighted Karcher mean b_{l+1,i} in the ball -> log_c(b_{l+1,i}) in the geodesic blend -> transported residual x_{l+1} -> code choice k_{l+1} -> SID prefix -> Stage 3 tokens. One chain, no side losses: zeroing the behaviour term sets a_l=0 and degenerates to standard hyperbolic RQ; replacing the curved ops with Euclidean ones degenerates to a linear residual blend.
COUPLING EQUATION: x_{l+1,i} = exp_{c_l}( (1-a_{l,i}) log_{c_l}(x_{l,i}) + a_{l,i} log_{c_l}( b_{l+1,i}(q) ) ), with a_{l,i} = d_P(x_{l,i}, c_l) / ( d_P(x_{l,i}, c_l) + d_P(c_l, b_{l+1,i}(q)) + eps ) and b_{l+1,i}(q) = argmin_m sum_j q_{l+1}(j|i) d_P^2(m, z_j).
OBSERVABLES: (i) prefix-successor diagnostic P(level-(l+1) code of the true next item | first l codes) for l=1..3 must rise; (ii) codebook usage at levels 2..4 shifts toward successor-discriminative directions (entropy of q inside each code); (iii) mean hyperbolic reconstruction error stays within a small factor of plain RQ; (iv) Stage 3 test_recall@10 > 0.065.
ABLATION BEHAVIOR OFF: a_l := 0 for all l and q is never read, so x_{l+1} = x_l and every level quantises the ordinary hyperbolic residual; basepoints may be logged but never enter the computation.
ABLATION GEOMETRY OFF: exp/log/Mobius/d_P replaced by Euclidean counterparts (arithmetic weighted mean for b, L2 distances, linear blend c + (1-a)(x-c) + a(b-c)); behaviour still enters through b and a.
ABLATION BOTH ON: the full coupled run above, the only arm trained in this round.
SPEC EQUATIONS: c=1, eps=1e-7, radius clamp 0.999.
ball(v) = tanh(||v||) v/||v|| with ||v|| clamped to [1e-8, 0.999].
Mobius: x(+)y = ((1+2c<x,y>+c||y||^2) x + (1-c||x||^2) y) / (1+2c<x,y>+c^2||x||^2||y||^2).
Epoch refresh (stop-grad): z_i = ball(enc(i)); for l=1..L: G_l(i) = items sharing the first l codes; q_{l+1}(j|i) = mean over G_l(i) of p(j|.); S = TopM(q); b_{l+1,i} = Karcher(z_S, q(S)/sum q(S)).
Step: for l=1..L: k_l = argmin_k d_P(x_l, C[l,k]); c = C[l,k_l]; g = d_P(c, b_{l+1,i}); e = d_P(x_l, c); a = e/(e+g+eps) if g>1e-6 else 0; a = clamp(a,0,1); x_{l+1} = exp_c((1-a) log_c(x_l) + a log_c(b_{l+1,i})).
Loss: L = mean_i d_P(z_i, MobiusSum_l C[l,k_{l,i}])^2 + 0.25 * mean_i sum_l d_P(x_{l,i}, C[l,k_{l,i}])^2, the 0.25 being the baseline's documented default commitment weight, unchanged and untuned.
SPEC INPUTS OUTPUTS: Inputs: encoder outputs z_i (batch, d), codebooks C[1..L] (K, d) in the ball, sparse successor table p, current prefix buckets, curvature c=1. Outputs: per item the code tuple (k_1..k_L) that is the SID, plus transported residuals x_2..x_{L+1} used for the next level's assignment and for the loss.
SAFEGUARDS: clamp ||z||, ||x||, ||c|| to <= 0.999 before artanh; compute artanh via torch.atanh on a value clamped to 1-1e-6; add eps=1e-7 in every Mobius denominator; set a=0 when g<1e-6 or q is empty (b=0); fall back to basepoint 0 for items whose prefix bucket has zero transition mass; stop-gradient on b and on bucket assignment; initialise the codebook with radius <= 0.5; keep codebook and residual tensors in float32 even under AMP; assert finite loss every 100 steps.
END IDEA
