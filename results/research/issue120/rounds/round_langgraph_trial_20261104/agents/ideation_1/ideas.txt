IDEA: SUCC-ANISO-RQ
TITLE: Successor-direction anisotropic Poincare metric inside every RQ-VAE level assignment (behaviour stretches the quantization cells, curvature bends them)
MOTIVATION: In a plain RQ-VAE the level-1 token splits items by static content similarity, so the first SID token carries no information about where the user actually goes next; the generative model then has to spend capacity re-deriving intent from token 2 and 3. Items that are content-twins but have disjoint successor sets share a prefix (prefix collisions that matter behaviourally), and items with the same next-intent but different surface features get different prefixes. Both hurt next-item recall at short prefix depth.
NOVELTY: The geometry is used to change the SHAPE of the per-level quantization cells, not their radius, their centroids or their curvature scalar. Previous mechanisms here moved codebook means (successor-weighted Frechet/Karcher), set a scalar curvature per level from prefix-transition score, or ranked codes radially by context entropy, or used entailment cones. Here the codebooks, the curvature per level and the Euclidean residual chain are left exactly as in the baseline; what changes is that each item carries its own rank-one deformation of the Poincare metric, aligned with the direction of its training successor flow, so the nearest-code decision at every level measures distance in a behaviour-elongated curved metric. Note explicitly that Mobius transport alone is an isometry and would be a no-op; this mechanism is deliberately non-isometric.
CHANGE: Each item i gets a fixed unit behaviour direction u_i and a behaviour confidence eta_i from its training successor distribution; the level-l code is chosen by nearest neighbour under a deformed Poincare distance that contracts lengths along u_i by a factor sqrt(1 - eta_i cos^2 theta), evaluated at the current residual point with fixed negative curvature C. Removing the behaviour sets eta = 0 (pure Poincare RQ); removing the curvature sets C = 0 (plain Euclidean RQ-VAE).
SPECIFICATION: Fixed curvature C (derived, below). Ball map exp_0^C(x) = tanh(sqrt(C)||x||) x/(sqrt(C)||x||), C>0, identity when C=0. Mobius difference a (+) _C b = ((1 + 2C<a,b> + C||b||^2) a + (1 - C||a||^2) b) / (1 + 2C<a,b> + C^2 ||a||^2 ||b||^2), a = -v. Log map log_v^C(c) = (2/(sqrt(C)(1 - C||v||^2))) artanh(sqrt(C)||(-v)(+)_C c||) * ((-v)(+)_C c)/||(-v)(+)_C c||. Per item: successor weights p_ij = count_train(i->j)/sum_j count_train(i->j), top-1 mass eta_i = p_i,max clipped to [0, 0.9], successor anchor s_i = sum_j p_ij f_j (f = fixed input item feature, not the moving encoder output), u_i(v) = log_v^C(exp_0^C(s_i))/||log_v^C(exp_0^C(s_i))||. Deformed distance d~(v,c) = (2/sqrt(C)) artanh( sqrt(C) ||w|| sqrt(1 - eta_i <w/||w||, u_i(v)>^2) ), w = log_v^C(c). RQ loop becomes v_l = exp_0^C(r_{l-1}), c_{l,k} = exp_0^C(E_l[k]), k_l = argmin_k d~_i(v_l, c_{l,k}), r_l = r_{l-1} - E_l[k_l]; decoder and reconstruction loss unchanged. Derived constants: sqrt(C) = artanh(0.5)/median_train||f|| (so the median item sits at ball radius 0.5); transition window = same session, target within next 3 positions; edges with count < 2 dropped; if an item has no kept successor, eta_i = 0.
COST: Offline once: sparse 24556x24556 training transition matrix and 24556 successor anchors, minutes on CPU, memory ~nnz floats. Per step at the frozen scale (24556 items, 24 steps/epoch, batch ~1023, L=3 levels, K=256): the baseline makes ~786k squared

distances per step; SUCC-ANISO-RQ makes the same 786k but each costs one Mobius difference plus one artanh instead of a subtraction and a dot product, i.e. roughly 2.5x the assignment kernel; the per-item anchor log map is 1023 evaluations per step and is cacheable per epoch. Expect the quantizer block to cost ~2.5x and the whole step ~1.4-1.6x, i.e. total Stage 2 wall clock 1.4-1.6x baseline, with no extra parameters and no extra memory of note.
HYPOTHESIS: If the first SID token should encode next intent rather than surface content, then the coupled run must show (a) a materially different level-1 code histogram than the Euclidean run, with items that are content twins but behaviourally divergent split at level 1, (b) higher next-prefix predictability measured on train-split held-out-by-time transitions, and (c) Stage 3 test_recall@10 above 0.065. It is worth keeping if (a) happens together with (b); it is dropped if the level-1 partition is unchanged (deformation too weak relative to the residual scale) or if recall is at or below baseline.
RISKS: The deformation could be swamped at level 1 because the first residual is dominated by the item's own feature norm, so the angle term matters little; eta_i from a noisy top-1 successor could make cells unstable for low-count items (mitigated by count>=2 and eps-shrinkage); bending the metric per item can create asymmetric or intransitive neighbourhoods, so a minority of items may get codes that no other item shares, wasting vocabulary; the behaviour anchor built from raw features may be a poor proxy for the encoder's learned space late in training.
BEHAVIOR SIGNAL: Directed item-to-item successor flow with its confidence: for each item, the normalised distribution over next items and the top-1 mass, plus the successor-weighted anchor vector.
BEHAVIOR COMPUTATION: From TRAIN-split user sessions only. For every ordered pair (i,j) occurring in the same training session with j in positions t+1..t+3 after i, increment count(i->j); drop edges with count < 2; row-normalise to p_ij over the 24556 training item ids; eta_i = max_j p_ij clipped to [0,0.9]; s_i = sum_j p_ij f_j with f the frozen input feature table of the same 24556 items. Computed once before Stage 2 and frozen.
LEAKAGE BOUNDARY: Only training-split sequences enter the transition counts, the anchors and eta; the item universe is exactly the 24556 training items; validation and test interactions are never read, no validation-derived statistic (no tuning, no early stopping) and no test-time prefix frequency is used; every constant (C, eta clip, window, count threshold) is derived from the train median feature norm, from the train transition table, or is a documented default fixed before the run.
HYPERBOLIC OPERATOR: Fixed negative curvature -C with sqrt(C) = artanh(0.5)/median_train||f||; Poincare ball exp/log maps, Mobius difference, and a rank-one anisotropic deformation of the Poincare metric, G_i(v) = lambda(v)^2 (I - eta_i u_i(v) u_i(v)^T) with lambda(v) = 2/(1 - C||v||^2), collapsed into the closed-form curved distance d~ = (2/sqrt(C)) artanh(sqrt(C) ||log_v^C(c)|| sqrt(1 - eta_i cos^2 theta)).
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer, at the nearest-code decision of every level l = 1..L of the prefix hierarchy (and therefore in the objective that shapes the codebook through the resulting assignments). It changes which code wins, hence which prefix every item receives at every depth.
COUPLING PATH: The training successor d

irection u_i and confidence eta_i of item i directly define the metric tensor at the current residual point, the metric tensor defines the curved distance to each level-l code, and that distance produces the level-l code index; the code index is the SID prefix. There is one path only: item -> (train transitions) -> (u_i, eta_i) -> deformed Poincare distance -> argmin_k at level l -> prefix token. Setting eta_i = 0 deletes the behaviour from the distance and restores the exact Poincare distance; setting C = 0 deletes the curvature and restores the exact Euclidean squared distance; neither switch can be removed without changing the produced SID.
COUPLING EQUATION: k_l(i) = argmin_k (2/sqrt(C)) artanh( sqrt(C) * ||log_{v_l}^C(c_{l,k})|| * sqrt(1 - eta_i * <log_{v_l}^C(c_{l,k})/||.||, log_{v_l}^C(exp_0^C(s_i))/||.||>^2) ), with eta_i = w_behaviour(i) = top-1 training successor mass and the artanh/log terms being the curved part; v_l = exp_0^C(r_{l-1}).
OBSERVABLES: (1) Fraction of items whose level-1 code changes relative to the Euclidean run, and the per-level code histograms; (2) mean hyperbolic prefix-path length and prefix-collision structure; (3) next-prefix predictability on train-split time-held-out transitions (given prefix_{1..l}, how often prefix_{l+1} matches the held-out successor's prefix); (4) Stage 3 test_recall@10, the only judgement.
ABLATION BEHAVIOR OFF: eta_i := 0 for all i (and s_i unused), so the assignment metric is the exact Poincare distance at the same curvature; the run must be identical in code path except that the behaviour terms are zero. Not trained this round, only present and correct in the config.
ABLATION GEOMETRY OFF: C := 0, so exp_0 and log_v collapse to identity and the distance is the plain Euclidean squared distance with sqrt(1 - eta cos^2) still active, i.e. a behaviour-anisotropic Mahalanobis-level RQ; the code path is shared, only the curvature branch changes. Not trained this round.
ABLATION BOTH ON: the single trained run: C derived from the train median feature norm and eta_i from the train successor table, both active in every level's assignment.
SPEC EQUATIONS: # offline
for (i,j,dt) in train_sessions: if 1 <= dt <= 3: cnt[i,j] += 1
cnt[cnt < 2] = 0;  p[i,:] = cnt[i,:] / max(sum_j cnt[i,j], eps)
eta[i] = clip(max_j p[i,j], 0, 0.9) if sum_j cnt[i,j] > 0 else 0
s[i]  = sum_j p[i,j] * f[j]                       # frozen feature table
sqrtC = artanh(0.5) / median_i ||f[i]||           # derived, per dataset
# per step, per item, per level
def exp0(x):  n = sqrtC*||x||;  return (tanh(n)/max(n,eps)) * x        # sqrtC=0 -> identity
def logv(v, c):
    a = -v
    num = (1 + 2C<a,c> + C||c||^2)*a + (1 - C||a||^2)*c
    den = 1 + 2C<a,c> + C^2||a||^2||c||^2
    t   = ||num/den||
    coef = (2/C) * artanh(clamp(sqrtC*t, 0, 1-1e-5)) / max(t,eps)   # limit 2t/... as C->0
    return coef * (num/den)
w = logv(v_l, exp0(E[l][k]));  g = logv(v_l, exp0(s[i]))
cos2 = (<w,g>/(||w||*||g||+eps))^2
d2 = ( (2/sqrtC) artanh(clamp(sqrtC*||w||*sqrt(1 - eta[i]*cos2), 0, 1-1e-5)) )^2
k_l = argmin_k d2 ;  r_l = r_{l-1} - E[l][k_l] ;  v_{l+1} = exp0(r_l)
# loss unchanged: RQ-VAE reconstruction on sum_l E[l][k_l]; gradient to E[l][k_l] via straight-through
SPEC INPUTS OUTPUTS: Inputs: encoder output e_i in R^d per item in the batch, per-level codebooks E[l] in R^{K x d}, frozen per-item successor anchor s_i in R^d, frozen per-item confidence eta_i in [0,0.9], curvature constant C, number of levels L. Outputs: code index seq

uence (k_1..k_L) = the item's SID, the Euclidean residuals r_l, and the unchanged reconstruction x_hat; the straight-through gradient w.r.t. E[l] and the encoder.
SAFEGUARDS: clamp every artanh argument to [0, 1-1e-5]; eps = 1e-8 in all norms and normalisations; eta clipped to [0, 0.9] guarantees positive definiteness of I - eta u u^T; items with zero kept successors get eta=0 so they fall back to the exact Poincare (or Euclidean) distance rather than inventing a direction; s_i standardised to the feature scale of f before use so the anchor direction is not dominated by a single popular successor; sqrtC computed from the train median and frozen so the ball never collapses (median radius 0.5, max radius < 1); the C->0 branch implemented separately (tanh/artanh removed) instead of dividing by C; distance evaluation in float32 with the ||w|| = 0 case returning exactly 0.
