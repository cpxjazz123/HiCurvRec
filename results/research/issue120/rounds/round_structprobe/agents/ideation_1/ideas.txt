IDEA: SAAR-RQ
TITLE: Successor-Aligned Anisotropic Residual in a Poincare RQ-VAE (behaviour-direction damping of the inter-level residual)
MOTIVATION: An RQ-VAE spends its deep prefixes on idiosyncratic reconstruction detail that no history can predict, so the Stage-3 generator must guess level-2/3 tokens that carry no transferable meaning. If the residual handed from level l to level l+1 were stripped of the components that contradict what items of this kind actually transition to, the deep prefixes would encode behaviourally predictable distinctions and the generative model would land on the true SID more often.
NOVELTY: Prior work here touched the codebook mean, the per-level curvature schedule, the radial rank of codes, target smoothing, cone constraints, boost shifts and curvature experts. This proposal touches none of those: it acts on the tangent-space residual that propagates between RQ levels, and it re-anisotropizes that residual with a per-item scalar kappa_x that is MEASURED from the angle between the residual and the training-only successor direction (no entropy, no radius rank, no codebook averaging, no extra parameters).
CHANGE: The level-(l+1) input is no longer a plain residual; it is exp_0^c of a tangent residual whose component perpendicular to the successor direction g_x is scaled by (1-kappa_x), where kappa_x = |cos angle(u_l, g_x)| is measured per item; level-l code selection uses the curvature-c distance d_c(z_l, e_{l,k}) and codebook updates are Riemannian.
SPECIFICATION: For each item at level l: curved assignment k_l = argmin_k (2/sqrt(c)) artanh(sqrt(c)||(-z_l) (+) e_{l,k}||); tangent residual u_l = log_0^c(z_l) - log_0^c(e_{l,k_l}); successor direction g_x precomputed from training transitions; kappa_l = |<u_l, g_x/||g_x||>| / max(||u_l||, eps); residual update u_{l+1} = (1-kappa_l) u_l + kappa_l <u_l, g_hat> g_hat, then ball-clipped and exponentiated as the next level input. Fixed curvature c = 1 with encoder outputs L2-normalized to radius 0.5 (documented default, not tuned); L = 3 levels, K = 256 codes per level. Full pseudocode is in spec_equations.
COST: No new forward passes and no new parameters. Added per step at the frozen scale: batch is ceil(24556/24) = 1023 items, 3 levels x 1023 x 256 Poincare distances (~0.8M artanh per step, ~40 MFLOP), plus three log/exp maps and one 3-term projection per item; roughly 5-10% over the baseline SID-training step, i.e. minutes over the 3000-epoch (72000-step) Stage-2 run. The successor table is one offline pass over the training split (counting top-20 successors per item, minutes on CPU) and is refreshed once at the fixed epoch 1500 using the current encoder (a documented schedule, not a tuned constant).
HYPOTHESIS: Damping the behaviour-contradicting part of the inter-level residual makes deep prefixes transferable, so on the single frozen run the history-conditioned hit rate of the level-2/3 code should exceed that of the plain curved quantizer, per-level assignment entropy should drop, and Stage-3 test_recall@10 should exceed 0.065; if the deep-prefix hit rate stays flat and recall stays at baseline, the mechanism is not worth keeping.
RISKS: Tail items with few or noisy successors give kappa ~ 0 and the mechanism degenerates to the plain curved quantizer (no gain, no harm).; Suppressing the perpendicular residual may remove the capacity needed to separate confusable items, producing coarser prefixes.; Tangent-space residual subtraction in a Poincare ball can shrink residual magnitude and starve level-3 codes (dead codes).; The Stage-3 protocol may not be able to exploit better prefix predictability if generation is dominated by level-1.; A single run leaves seed noise inside the measured delta.
BEHAVIOR SIGNAL: Directed successor direction g_x of each training item, built from training-split sequences only (top-20 successors by count over the next H = 3 positions in the same user's sequence), used as a per-item direction in the tangent space at the origin.
BEHAVIOR COMPUTATION: One pass over the Stage-2 TRAINING split sequences, grouped by user, in time order. For every occurrence of item x, the following H = 3 positions in the same user's sequence contribute one count to each successor item s (self-transitions dropped); counts are summed over all users and occurrences. S_x is the top-20 successors by count; g_x = sum_{s in S_x} count(x,s) * log_0^c(E_s) / sum count(x,s), where E_s is the item embedding under the frozen pretraining encoder snapshot. g_x is stored as a d-vector plus its count; the table is refreshed once at epoch 1500 from the current encoder (fixed schedule). Only training-split sequences are read.
LEAKAGE BOUNDARY: The successor table is built exclusively from the training split that Stage 2 also sees; validation and test interactions are never read by the SID construction, and the epoch-1500 refresh also reads only the training split. The Stage-3 evaluation split is used only after SIDs are frozen, exactly as in the frozen protocol. No test/validation transition, co-occurrence or popularity statistic enters g_x, kappa_x or the codebook.
HYPERBOLIC OPERATOR: Poincare ball of curvature c = 1 (fixed, scale-derived: encoder outputs are L2-normalized to radius 0.5 so that no point approaches the boundary at initialization), with geodesic distance d_c(u,v) = (2/sqrt(c)) artanh(sqrt(c)||(-u) (+) v||), log map log_0^c(z) = (2/sqrt(c)) artanh(sqrt(c)||z||) z/||z||, exp map exp_0^c(a) = tanh(sqrt(c)||a||/2) a/(sqrt(c)||a||), and Riemannian rescaling of codebook gradients.
HYPERBOLIC LOCATION: Inside the quantizer, on two things at once: (i) the code-selection cost of every RQ level, which is the Poincare distance rather than a Euclidean one, and (ii) the residual transport between consecutive levels, where the residual is defined, damped and re-exponentiated in the tangent space at the origin of the curved ball. Codebook updates use the Riemannian exp_0 retraction form.
COUPLING PATH: One chain: curved log-map of the item -> curved residual at level l -> measurement of the angle between that residual and the behaviour direction g_x -> kappa_x sets the anisotropy of that same residual -> curved exp-map produces the level-(l+1) input -> level-(l+1) curved assignment -> SID token. Removing the behaviour makes kappa_x = 0 and the chain collapses to plain curved RQ; removing curvature replaces log/exp/d_c by identity/Euclidean maps so the residual and the assignment change for every item past level 1. Neither term can be deleted without changing the actual quantizer input and therefore the SID assignment.
COUPLING EQUATION: u_{l+1} = (1 - kappa_x) u_l + kappa_x <u_l, g_hat_x> g_hat_x, with u_l = log_0^c(z_l) - log_0^c(e_{l,k_l}) and kappa_x = |<u_l, g_hat_x>| / (||u_l|| ||g_hat_x||); equivalently u_{l+1} = u_parallel + (1 - kappa_x) u_perp where u_parallel = <u_l, g_hat_x> g_hat_x is the training-successor component and log_0^c / exp_0^c with curvature c carry the geometry. k_l = argmin_k (2/sqrt(c)) artanh(sqrt(c)||(-z_l) (+) e_{l,k}||).
OBSERVABLES: (1) Stage-3 test_recall@10 (> 0.065 is the target). (2) History-conditioned hit rate of the level-2 and level-3 token: fraction of test targets whose greedy level-l prefix equals the target's level-l prefix, compared with the level-1 rate. (3) Per-level assignment entropy and dead-code count. (4) Fraction of items whose level-2/3 code differs from the code the Euclidean/behaviour-off geometry would give, from a frozen SID snapshot (diagnostic only, never a gate). (5) Mean measured kappa per level, which should be well away from 0 if the coupling is active.
ABLATION BEHAVIOR OFF: Set g_x = 0 for all items so kappa_x = 0 everywhere; the residual transport becomes u_{l+1} = u_l, i.e. plain curvature-c RQ with Poincare assignment. The switch exists in code (behaviour_weight = 0 or an empty successor table) and is exercised by a unit test, but no arm is trained.
ABLATION GEOMETRY OFF: Replace exp_0^c, log_0^c and d_c by the identity and the Euclidean distance (the c -> 0 limit), keep the same kappa_x damping in flat space and the Euclidean codebook update. The switch exists in code (curvature = 0 / euclidean_geometry = True) and is exercised by a unit test, but no arm is trained.
ABLATION BOTH ON: The full coupled run: curvature c = 1 Poincare assignment and transport plus the successor-direction damping with the measured kappa_x. This is the one and only trained candidate.
SPEC EQUATIONS: Inputs: item target z = normalize_to_radius_0.5(Encoder(x)) in R^d, d = 32 or 64; codebooks E_l = {e_{l,k}} in B_c, k = 1..256, l = 1..3; successor table {g_x}. Constants: c = 1; R = (2/sqrt(c)) artanh(sqrt(c) * 0.5) (max tangent radius); eps = 1e-8; kappa clamp [0, 1 - 1e-6].   a_1 = log_0^c(z)   for l = 1..3:       z_l = exp_0^c(a_l)       d_{l,k} = (2/sqrt(c)) * artanh( min( sqrt(c) * || (-z_l) (+) e_{l,k} ||, 1 - 1e-5 ) )       k_l = argmin_k d_{l,k}    # straight-through: hard index, soft gradient through softmin over -d_{l,k}       u = a_l - log_0^c(e_{l,k_l})       if ||g_x|| > eps and ||u|| > eps:           g_hat = g_x / ||g_x||           kappa = min( |<u, g_hat>| / ||u|| , 1 - 1e-6 )           a_{l+1} = (1 - kappa) * u + kappa * <u, g_hat> * g_hat       else:           a_{l+1} = u       if ||a_{l+1}|| > R: a_{l+1} *= R / ||a_{l+1}||   Loss: standard RQ-VAE objective (reconstruction from the sum of decoded codes, commitment beta unchanged) with the reconstruction distance taken in the curved space: L_rec = d_c(z, exp_0^c(sum_l log_0^c(e_{l,k_l})))^2 plus the commitment term; an implementation may equivalently compare tangent coordinates, the assignment, residual and codebook stay as above.   Codebook step (Riemannian): gradient in tangent coordinates g_e = dL/d(log_0^c e); retraction e <- exp_0^c( log_0^c(e) - eta * g_e * ((1 - c||e||^2)/2)^2 ), e re-clipped to radius (1 - 1e-3)/sqrt(c); eta is the baseline codebook learning rate (no new constant).
SPEC INPUTS OUTPUTS: Takes the encoder output z in the Poincare ball, the three codebooks in the ball, and the precomputed per-item successor direction g_x. Returns the per-level code indices (k_1, k_2, k_3), i.e. the Semantic ID, the per-level tangent residuals for the loss, the measured kappa per item per level, and gradients for the encoder and the codebooks. No new learnable parameters and no change to the Stage-3 interface.
SAFEGUARDS: artanh argument clamped to 1 - 1e-5, computed in log1p form for float32 stability; all ball points re-clipped to radius (1 - 1e-3)/sqrt(c) after every exp map and every codebook step; kappa clamped to [0, 1 - 1e-6] and set to 0 when ||g_x|| < eps or ||u|| < eps (no-successor and degenerate-residual fallback); the residual update is provably non-expansive (||u_{l+1}||^2 = (1-kappa)^2 ||u_perp||^2 + ||u_par||^2 <= ||u||^2) so it cannot blow up; g_x normalized before use and items with fewer than two successor counts fall back to behaviour-off for that item; gradient clipping at the baseline value; straight-through estimator for the hard code index; the successor table is built once and refreshed only at the fixed epoch 1500, reading only the training split; dead-code re-initialization is left exactly as in the baseline so the comparison is not confounded; no ablation arm and no sweep is run.
END IDEA
