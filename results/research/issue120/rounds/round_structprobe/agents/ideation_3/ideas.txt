IDEA: LORENTZ-SUCC-GEODESIC-RQ
TITLE: Behaviour-directed Lorentzian geodesic residual assignment for RQ-VAE semantic IDs
MOTIVATION: RQ-VAE semantic IDs are built from content reconstruction alone; a prefix that is easy to reconstruct can still be a poor predictor of the next item. Directed training transitions contain prefix-level successor structure that the quantizer never sees.
NOVELTY: Unlike successor-Fréchet codebook updates, radial behaviour ranking, or per-level curvature control, this mechanism leaves the codebook update intact and changes the quantizer input/query: every RQ level transports the residual point along a hyperbolic geodesic toward a stop-gradient transition-weighted successor barycenter, then assigns the code by Lorentzian distance. Behaviour and curvature meet inside the same assignment equation.
CHANGE: At each RQ level replace the Euclidean nearest-code query r_i by a geodesic point m_i = exp_{phi(r_i)}(lambda_i log_{phi(r_i)}(phi(b_i))), where b_i is the directed-transition-weighted mean of successor residuals and lambda_i is the measured transition concentration; score codes by -d_L(m_i, phi(c_lk)).
SPECIFICATION: Precompute a sparse row-normalised directed transition matrix P from Stage2 training sequences only. At each level l keep a stop-gradient residual bank R_l. For each batch item compute b_i from P and the bank, set lambda_i from the entropy of P_i, form the Lorentz geodesic point m_i between phi(r_i) and phi(b_i), and choose the code minimising Lorentz distance from m_i to phi(c_lk). Residual update and baseline RQ-VAE losses are otherwise unchanged. Switches: behaviour-off sets lambda_i=0; geometry-off replaces exp/log/d_L by Euclidean linear interpolation and squared distance.
COST: One-time O(T) transition counting with T Stage2 training transitions; memory sparse P plus an N x L x d float32 residual bank, about 18 MB for N=24556, L=3, d=64. Per step O(L B (D d + K d)) against baseline O(L B K d), with D capped at K=256. At the frozen scale (24556 items, 24 steps/epoch, 3000 epochs), expected quantizer overhead about 8-15% and wall-clock 1.1-1.2x baseline; the extra encoder work is zero because b_i reuses stored stop-gradient residuals.
HYPOTHESIS: If directed transitions carry prefix-level information that reconstruction misses, the coupled run should assign prefixes that are more predictable from training transitions and should raise Stage3 test Recall@10 above 0.065. The idea is rejected if recall stays at or below the baseline despite a measured increase in prefix-transition predictability, or if the coupled assignment collapses code usage without a recall gain.
RISKS: Residual bank staleness makes b_i noisy, especially for long-tail items.; For deterministic transitions lambda_i approaches 1 and the query can become the successor barycenter, collapsing distinct predecessors to one prefix.; Sparse or popularity-dominated transitions encode mostly popular successors and hurt tail items.; Lorentz distances saturate for large residual norms, reducing assignment margin.; The hyperbolic query increases reconstruction error because the selected code need not approximate r_i.; Additional gather/scatter over P and the bank may cost more than estimated if the transition graph is dense.; Single-run seed noise can swamp a small recall gain.
BEHAVIOR SIGNAL: Directed item-to-item transitions u_t -> u_{t+1} from the Stage2 training sequences, summarized as a row-normalised successor distribution P_i and a concentration weight lambda_i.
BEHAVIOR COMPUTATION: From Stage2 train split only: count C_ij over consecutive pairs (i,j), i != j; P_ij=C_ij/sum_j C_ij; m_i=number of nonzero successors; H_i=-sum_j P_ij log P_ij; lambda_i=0 if m_i=0, 1 if m_i=1, else max(0,1-H_i/log m_i) times a Laplace trust C_i/(C_i+1) with C_i=sum_j C_ij. Keep at most the K=256 highest-count successors per row. The residual bank is updated only from training-batch items.
LEAKAGE BOUNDARY: P, lambda and the residual bank are built exclusively from Stage2 training sequences and training-batch encoder outputs. Validation and test interactions are never read, counted, or used to update P, lambda or the bank; Stage3 only consumes the frozen SID table produced after Stage2. No user or item from validation/test enters the SID construction.
HYPERBOLIC OPERATOR: Lorentz model with fixed negative curvature -1: phi(v)=(sqrt(1+||v||^2),v); Minkowski inner product <x,y>_L=-x0 y0 + x.y; d_L(x,y)=arcosh(-<x,y>_L); geodesic exp_p and log_p on the hyperboloid, plus the Lorentz distance used as the code-assignment score.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer, at every residual level l, after the encoder produces r_i^(l) and before the code lookup; the same curved metric scores all codebook entries for that level.
COUPLING PATH: P -> (lambda_i, b_i) -> geodesic m_i -> Lorentz distance to codebook -> selected RQ prefix code. Removing behaviour sets lambda_i=0 so m_i=phi(r_i); removing curvature replaces the geodesic and Lorentz distance by Euclidean interpolation and squared distance. Both changes alter the same code-selection computation.
COUPLING EQUATION: m_i^(l) = exp_{phi(r_i^(l))}( lambda_i(P_i) * log_{phi(r_i^(l))}( phi( b_i^(l)(P_i) ) ) );  score_ik = - d_L( m_i^(l), phi(c_lk) );  b_i^(l) = sum_j P_ij R_l[j] / max(sum_j P_ij, eps).
OBSERVABLES: SID prefix assignments and prefix counts; training-split prefix-transition log-likelihood (predicting next item's prefix from current item's prefix under P); fraction of items whose selected prefix changes under behaviour-on; code usage entropy; mean geodesic displacement lambda_i d(phi(r_i),phi(b_i)); Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: The switch exists as lambda_i=0 for every item, so m_i=phi(r_i) and the run is the same Lorentzian RQ assignment without transition guidance. It is not trained in this round.
ABLATION GEOMETRY OFF: The switch exists as m_E=(1-lambda_i) r_i + lambda_i b_i and score_ik=-||m_E-c_lk||^2, keeping the transition term but replacing all exp/log/Lorentz distance by Euclidean computation. It is not trained in this round.
ABLATION BOTH ON: The full coupled run: lambda_i from P, b_i from the stop-gradient residual bank, geodesic transport, and Lorentzian code scoring. This is the single candidate trained once on the frozen budget.
SPEC EQUATIONS: 1) Build P: C_ij=sum_t 1[u_t=i,u_{t+1}=j], i!=j; P_ij=C_ij/sum_j C_ij; m_i=|{j:C_ij>0}|; H_i=-sum_j P_ij log P_ij; lambda_i = 0 if m_i=0; 1 if m_i=1; else max(0,1-H_i/log m_i) * C_i/(C_i+1), C_i=sum_j C_ij. Cap each row to at most K=256 largest C_ij. 2) Bank: for each level l keep R_l in R^{N x d} and mask M_l; initialise 0. At a training step use the previous values; after the forward pass set R_l[i]=sg(r_i^(l)), M_l[i]=1 for batch items i. 3) Query: w_ij=P_ij M_l[j], Z_i=sum_j w_ij; b_i=sum_j w_ij R_l[j]/max(Z_i,eps); if Z_i<eps or lambda_i=0 set m_i=phi(r_i). Else p=phi(r_i), q=phi(b_i), alpha=-<p,q>_L, alpha=max(alpha,1+eps), d=arcosh(alpha), u=(q-cosh(d)p)/sinh(d), m_i=cosh(lambda_i d)p + sinh(lambda_i d)u. 4) Assign: z_ik=-d_L(m_i,phi(c_lk))=-arcosh(max(1+eps, m_i0 sqrt(1+||c_lk||^2)-m_i.spatial . c_lk)); k*=argmax_k z_ik; forward code c_lk*, straight-through gradient to m_i; r_i^(l+1)=r_i^(l)-c_lk*. Keep the baseline commitment, reconstruction and codebook updates unchanged.
SPEC INPUTS OUTPUTS: Inputs: training sequences, item count N, encoder residual r_i^(l) for batch items at each level, codebooks c_l, fixed K=256, fixed curvature -1, epsilon. Outputs: a selected code k* at every level for every item, hence the SID tuple, plus the stop-gradient residual bank used on later steps; also the assignment logits for diagnostics.
SAFEGUARDS: Clip alpha to >=1+eps before arcosh; clip all residual, bank and code norms to 1e4; if d<eps or sinh(d)<eps set m_i=p; if Z_i<eps or lambda_i=0 set behaviour term to zero; cap transition row to K=256 entries; keep lambda_i in [0,1]; use float64 for alpha and arcosh or a stable arcosh(x)=log(x+sqrt(x^2-1)); replace any non-finite m_i or logit with the Euclidean fallback for that item; validate with torch.isfinite before the backward pass.
END IDEA
