IDEA: GEO-SUCC-WARP-RQ
TITLE: Geodesic successor warping of the RQ residual: the training-only transition field moves the point at which each SID level assigns its code
MOTIVATION: RQ-VAE semantic IDs are built from item content/embedding geometry only, so two items that users constantly move between can land in unrelated coarse prefixes, and the Stage 3 generator has to learn prefix transitions that the SID tree actively contradicts. The behaviour information that says "after i, users go to j" exists in the training split but never reaches the coarse levels of the code hierarchy.
NOVELTY: The rejected or earlier mechanisms act on the codebook update (Frechet means), on a per-level curvature or radius schedule, on assignment ranking (radial behaviour rank), or on a separate profile-smoothing loss. Here nothing is added to the codebook and no extra loss is introduced: the curved operation acts on the residual point itself between levels, so the behaviour field changes the ARGUMENT of the next nearest-code search. The behaviour pull weight is derived from the ratio of the geodesic quantization residual to the geodesic distance to the item's successor centroid, so it is scale-free, needs no sweep, and decays automatically at fine levels.
CHANGE: After the Mobius residual q_l = (-e_lk) + p_{l-1} of level l, the residual point is moved a fraction beta_l along the Poincare geodesic toward the item's successor centroid g_i = exp_0(sum_j P(j|i) T_j); level l+1 then assigns on that warped point instead of on q_l. beta_l is the ratio of the geodesic residual length to the geodesic distance to g_i, so the coarse prefixes follow the transition field and the fine levels stay faithful.
SPECIFICATION: Precompute training-split directed counts N_ij, keep top M=16 successors per item (succ_idx, succ_prob) and a mask. Maintain a detached EMA table T of encoder embeddings (decay 0.999) as the successor target. Curvature kappa = softplus(rho), rho initialised so kappa=1.0, clamped to [0.25,4.0]; s = sqrt(kappa). For a batch item i: p_0 = exp_0(z_i); g_i = exp_0(b_i) with b_i = sum_j P(j|i) T_j (masked -> beta=0). For l=1..L=4: k_l = argmin_k d_kappa(p_{l-1}, e_lk); q_l = (-e_lk) (+)_kappa p_{l-1}; beta_l = d(p_{l-1},q_l)/(d(p_{l-1},q_l)+d_kappa(q_l,g_i)+eps), clipped to [0,1-1e-3]; p_l = exp_{q_l}(beta_l * log_{q_l}(g_i)). Codes k_1..k_L are the SID. Reconstruction p_hat = e_1k1 (+) ... (+) e_LkL and hyperbolic VQ loss on d_kappa(p_hat,p_0) plus per-level commitment with straight-through in the tangent space.
COST: Batch B=24556/24 ~ 1024, d=32, L=4, M=16. Extra work per step: successor gather 1024*16*32 = 0.52M MAC, plus per level about 5-6 Mobius/exp/log vector ops on B*d = 33k elements -> about 0.8M FLOP, so under 2% extra FLOPs. Wall clock +5-10% on Stage 2 (72000 steps, roughly +0.5-1.0 ms/step, new kernel launches dominate), negligible on Stage 3. One-off successor table build is O(number of training transitions), about 3.2 MB of int32/float32 tables.
HYPOTHESIS: Coarse SID prefixes that are aligned to the training transition field should make the Stage 3 generator's next-prefix predictions land in the right subtree more often, so Stage 3 test_recall@10 must rise above the frozen baseline and above 0.065 with the coupling on. It is worth keeping only if the recorded per-level beta profile decays with level (coarse levels warped, fine levels spared), if coarse-leve

l code usage entropy does not collapse, and if the recall gain survives the single run despite seed noise.
RISKS: The successor pull can over-smooth coarse prefixes and collapse distinct items into one prefix, which would hurt both discriminability and the generator (self-transition bias); the EMA target table can lag and destabilise the first epochs; long-tail items have empty or near-empty successor rows so the effect may only appear for head items; warped assignments can lower codebook usage and produce dead codes at levels 1-2; with curvature trainable and a single seed there is no recovery check if kappa drifts to a boundary; a wrong corpus-level transition statistic could simply reproduce co-occurrence clusters that the content encoder already captures.
BEHAVIOR SIGNAL: Directed item-to-item transition counts (sequential co-consumption), aggregated into a per-item successor distribution over the training split.
BEHAVIOR COMPUTATION: Stream the training-split user sequences once, count every consecutive pair (i -> j) with time-ordered sessions, keep the top 16 successors per item by count, normalise to P(j|i) = count(i->j)/sum_k count(i->k), and build the successor centroid b_i = sum_j P(j|i) T_j from a detached EMA copy of the encoder embedding table. Recomputed only in the EMA table, never from validation or test.
LEAKAGE BOUNDARY: The successor table is built exclusively from training-split sequences, and the successor centroid uses only encoder embeddings fitted on training items; validation and test sequences are never streamed, counted, or used to update T, the codebook or kappa. Diagnostics that are logged are computed from training-split statistics and from the frozen Stage 3 protocol scores only; nothing about the SID construction reads a validation or test interaction.
HYPERBOLIC OPERATOR: Poincare ball of trainable negative curvature -kappa (kappa = softplus(rho), init 1.0, clamp [0.25,4.0]): exp_0 and log_0 maps, Mobius addition/subtraction, the geodesic step exp_x(u) = x (+)_kappa tanh(s*lambda_x*|u|/2) u/(s|u|), and the Poincare distance d_kappa(x,y) = (2/s) artanh(s |(-x) (+)_kappa y|).
HYPERBOLIC LOCATION: Inside the RQ quantizer loop, between consecutive levels, and in the nearest-code search of every level: the curved residual q_l and the geodesic warp toward the successor centroid determine which codebook point level l+1 selects.
COUPLING PATH: b_i (behaviour) -> g_i = exp_0(b_i) -> beta_l computed with Poincare distances (curvature) -> p_l = geodesic step -> argmin_k d_kappa(p_l, e_{l+1,k}) -> the SID prefix and the gradient that e_{l+1,k} receives. Behaviour-off sets beta_l=0 and the code sequence changes; geometry-off replaces every primitive by its Euclidean counterpart and both beta_l and the assignment change. Neither term is optional in the same expression.
COUPLING EQUATION: p_l = exp^kappa_{q_l}( beta_l * log^kappa_{q_l}(g_i) ), with beta_l = d_kappa(p_{l-1}, q_l) / ( d_kappa(p_{l-1}, q_l) + d_kappa(q_l, g_i) + eps ) and g_i = exp^kappa_0( sum_j P(j|i) T_j ), where q_l = (-e_{l,k_l}) (+)_kappa p_{l-1}.
OBSERVABLES: Mean and per-level value of beta_l (expected to decay from level 1 to level 4); per-level code usage entropy and number of used codes at levels 1-2; the fraction of prefix bigrams of consecutive training items that share the level-1 code (prefix transfer predictability diagnostic); the geodesic reconstruction distance d_kappa(p_hat,p_0) during Stage 2; and, as the judgement, Stage 3 test_recal

l@10 from the single frozen run.
ABLATION BEHAVIOR OFF: Same code, beta_l forced to 0 for every item and level (p_l = q_l), which is plain hyperbolic RQ with the successor table still built and logged but never entering the assignment; not trained in this round.
ABLATION GEOMETRY OFF: Same code, EXP/LOG set to identity, Mobius addition replaced by vector addition, d_kappa replaced by L2, geodesic step replaced by linear interpolation q_l + beta_l (g_i - q_l), and kappa unused; the behaviour signal and the same derived beta formula remain; not trained in this round.
ABLATION BOTH ON: The full coupled run: successor centroids from the training transition field warped along Poincare geodesics with curvature-dependent beta_l, which is the single candidate trained once on the frozen budget.
SPEC EQUATIONS: s = sqrt(kappa); exp_0(v) = tanh(s|v|) v/(s|v|) (0 at v=0); log_0(y) = artanh(s|y|) y/(s|y|); lambda_x = 2/(1-kappa|x|^2); x (+)_kappa y = ((1+2kappa<x,y>+kappa|y|^2)x + (1-kappa|x|^2)y)/(1+2kappa<x,y>+kappa^2|x|^2|y|^2); d_kappa(x,y) = (2/s) artanh(s|(-x)(+)_kappa y|); log_x(y) = (2/(s lambda_x)) artanh(s|(-x)(+)_kappa y|) ((-x)(+)_kappa y)/|(-x)(+)_kappa y|; exp_x(u) = x (+)_kappa ( tanh(s lambda_x |u|/2) u/(s|u|) ). Pseudocode: p = exp_0(z_i); g = exp_0(b_i); for l in 1..L: d = d_kappa(p, e_l); k_l = argmin(d); q = (-e_l[k_l]) (+)_kappa p; if behaviour_on and mask_i: beta = clip(d_kappa(p,q)/(d_kappa(p,q)+d_kappa(q,g)+eps), 0, 1-1e-3); p = exp_q(beta * log_q(g)) else p = q; p = project(p, r_max). Then codes = k_1..k_L; p_hat = e_1k1 (+)_kappa ... (+)_kappa e_LkL; L_rec = d_kappa(p_hat, p_0)^2; per level L_vq = d_kappa(sg[p_{l-1}], e_lk)^2 + eta d_kappa(p_{l-1}, sg[e_lk])^2 with eta = 0.25 documented default; T <- 0.999 T + 0.001 detach(z).
SPEC INPUTS OUTPUTS: Takes the batch item embeddings z_i, the per-level codebooks e_lk, the precomputed successor index/probability rows and the EMA table T; returns the L code indices per item (the SID), the reconstruction point p_hat, and the scalar losses L_rec + sum_l L_vq used for the backward pass.
SAFEGUARDS: Project every point to |p| <= (1-1e-3)/s after each operation; clip the artanh argument to 1-1e-7 and every norm denominator to eps=1e-8; clip beta_l to [0,1-1e-3]; replace NaN/Inf with a skip-to-q_l fallback per item; mask empty successor rows so beta=0 exactly; freeze T for the first 50 steps and use detach so no gradient flows through the successor field (no collapse feedback); clamp kappa to [0.25,4.0] by projection after each optimiser step; keep eta at the documented default 0.25 and the EMA decay at 0.999, no sweep; log the beta profile and codebook usage so a silent collapse is visible even though neither is an admission gate.
END IDEA
