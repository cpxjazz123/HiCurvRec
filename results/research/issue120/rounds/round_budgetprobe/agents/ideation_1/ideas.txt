IDEA: succframe-warp-rq
TITLE: Successor-frame warped Poincare quantization: one determinant-one behaviour metric shared by every RQ level
MOTIVATION: The RQ-VAE spends SID prefix resolution in directions that are convenient for item-content reconstruction, not in the directions in which users actually move. For a generative recommender this is a direct loss: two items a user routinely moves between can land in different level-1 or level-2 prefixes, so the generator cannot condition the next prefix on the current one. The defect is not where the codewords sit but the metric in which each level measures its residual.
NOVELTY: Codeword parameters, codebook initialisation, codebook updates and curvature are left exactly as in the baseline; what changes is the metric of the residual quantizer. Each item gets a determinant-one linear reparametrisation W_i of the hyperbolic chord, built from its training successor second moment in the ball's tangent space at the origin, and the same W_i is applied at every level so it shapes the whole prefix hierarchy at once. Earlier mechanisms here re-positioned codewords (Fréchet/Karcher/mass-weighted), set a per-level curvature (CURVCTRL), set radial position from transition entropy (BRad), smoothed successor profiles in Lorentz coordinates, or imposed behaviour cones; none warps the curved distance that selects codewords, and none derives warp strength from the dominant eigenvalue share of the successor second moment.
CHANGE: Every level's nearest-codeword rule and every level's reconstruction/commitment term use the warped Poincare distance d^W(z, p_{l-1} (+) u) = (2/sqrt(c)) artanh(sqrt(c) * || W_i ( (-z) (+) (p_{l-1} (+) u) ) ||) with W_i = B_i diag(s_i) B_i^T taken from the eigendecomposition of the item's successor second moment M_i = sum_j pi_ij t_j t_j^T, while the prefix itself is composed by Mobius addition p_l = p_{l-1} (+) u_{l,k_l}.
SPECIFICATION: (1) Offline, once per Stage-2 epoch, no gradient: A = directed adjacent-transition counts over training sequences only (item at t -> item at t+1), 24556 x 24556 sparse; z = exp_0^c(clip(E_content, ||.|| <= R)) from the current encoder, detached; t = log_0^c(z). Per item i: S_i = smallest successor set covering >= 0.8 of i's outgoing transition mass; pi_ij = A_ij / sum_{j in S_i} A_ij; if |S_i| < 2 or mass 0 then B_i = I_d, s_i = 1. Else M_i = sum_{j in S_i} pi_ij t_j t_j^T (uncentred, so mean successor direction and spread both enter), eigh -> lambda descending, B_i; lambda <- max(lambda, 1e-6*mean(lambda)+1e-12); alpha_i = lambda_1/sum_k lambda_k; s_i = exp(0.5*alpha_i*(log lambda - mean_k log lambda)) clipped to [1/sqrt(d), sqrt(d)]; W_i = B_i diag(s_i) B_i^T (det = 1). (2) Quantization, levels l = 1..L: p_0 = 0; ch_k = (-z_i) (+) (p_{l-1} (+) u_{l,k}); q_k = W_i ch_k, rescaled to r_max if longer; d_{l,i,k} = (2/sqrt(c)) artanh(sqrt(c)||q_k||); k_l = argmin_k d (straight-through); p_l = clip_ball(p_{l-1} (+) u_{l,k_l}). (3) Loss = sum_l d_{l,i,k_l}^2 + beta * commitment with beta and codebook/EMA settings exactly the baseline's (no new loss constant); codebook entries projected into the ball to radius <= 0.9 after each step; W_i detached.
COST: +10-20% Stage-2 epoch time at the frozen scale (24556 items, 24 steps/epoch, 3000 epochs). Per step: 1023 items x 3 levels x 256 codewords x one d x d matvec (d=32) ~ 0.86 GFLOP forward, ~2.5 GFLOP with backward, versus ~0.05 GFLOP for the baseline assignment; assignment is a small share of the encoder step. One batched 24556-way 32x32 eigh per epoch (~30 ms GPU) plus a sparse successor gather, <= ~5 min over the whole of Stage 2. Stage-3 cost unchanged.
HYPOTHESIS: If successor structure in the training transition graph predicts next-item and the successor directions in the Poincare ball are not the content-reconstruction directions, the single coupled run gives Stage-3 test Recall@10 > 0.065, and training transition pairs (i->j) share level-1 and level-2 prefixes at a higher rate than the same frozen encoder's codes produce under the identity frame (post-hoc re-assignment, no extra training). If Recall lands at or below the identity-frame expectation, the successor second moment is not the right frame and the idea is dropped.
RISKS: alpha_i times the eigenvalue spread may over-concentrate prefix resolution into a few successor directions and damage reconstruction, so codes stop covering the catalogue; 0.8-mass successor sets can be tiny (1-2 items) and noisy for tail items, giving near-degenerate frames; per-epoch frame refresh makes the metric non-stationary, which can stop the codebooks from settling; warping the chord can push ||q|| toward 1, where artanh gradients explode; successor information may already be captured by Stage 3's sequence model, leaving only reconstruction damage; computing a second identity-frame assignment for the diagnostic adds a code path that could silently diverge from the trained one
BEHAVIOR SIGNAL: Directed item transitions: the per-item successor distribution over training sequences.
BEHAVIOR COMPUTATION: Adjacent pairs (item_t, item_{t+1}) counted over all training-split user sequences only, aggregated into a sparse 24556 x 24556 count matrix A; pi_ij normalised over the smallest successor set covering 0.8 of each item's outgoing mass; successors projected through the current detached encoder to tangent coordinates t_j at the origin. Recomputed once per epoch, no gradient.
LEAKAGE BOUNDARY: Transitions and successor sets come only from the Stage-2 training split over the 24556 training items; validation and test interactions are never read, so no validation/test user contributes an edge and no validation/test item can appear as a successor. The SID table is frozen before Stage 3, and Stage 3 trains and is evaluated without any further SID update, so no test statistic can re-enter code construction; the identity-frame diagnostic uses only training transition pairs.
HYPERBOLIC OPERATOR: Fixed negative-curvature Poincare ball with c = 1 (unit ball, r_max = 1 - 1e-3): exp/log maps at the origin, Mobius addition (+) and subtraction, hyperbolic distance (2/sqrt(c)) artanh(sqrt(c)||.||), and a determinant-one linear warp W_i applied to the chord before the artanh. Curvature is fixed, not trainable.
HYPERBOLIC LOCATION: Inside the RQ-VAE residual quantizer of Stage 2, at every level l = 1..L: codeword selection, the per-level reconstruction/commitment term, and the prefix composition p_l = p_{l-1} (+) u_{l,k_l}. Not in the item encoder and not in Stage 3.
COUPLING PATH: One pathway: training successor distribution -> successor second moment in the ball's tangent space -> det-1 warp W_i -> warped Poincare chord -> nearest-codeword index at level l -> level-l SID token -> Mobius composition of the prefix -> loss gradient on encoder and codebooks -> next epoch's frames. Removing behaviour sets W_i = I and the pathway collapses to plain hyperbolic RQ; removing geometry replaces the warped Poincare chord with a warped Euclidean chord and Mobius prefix with plain addition, so neither term can be dropped without changing the selection that produces the SID.
COUPLING EQUATION: d_{l,i,k} = (2/sqrt(c)) * artanh( sqrt(c) * || W_i [ (-z_i) (+) ( p_{l-1,i} (+) u_{l,k} ) ] || ), with W_i = B_i diag(s_i) B_i^T, M_i = sum_{j in S_i} pi_ij t_j t_j^T = B_i diag(lambda) B_i^T, s_i,k = exp(0.5 * alpha_i * (log lambda_k - mean log lambda)), alpha_i = lambda_1 / sum lambda; behaviour enters through pi_ij and alpha_i, curvature through (+), (-) and artanh, and both meet inside the same norm that selects the codeword.
OBSERVABLES: Per-level codeword usage histograms and number of used codewords; the distribution of alpha_i and of s_max/s_min; successor prefix-agreement rate at level 1 and level 2 over training transition pairs for the trained SID versus the same encoder under the identity frame; prefix-transition predictability of the generator (accuracy of predicting the next item's level-l token from the current item's level-l prefix); Stage-3 test Recall@10 against the 0.065 bar; the gradient norm the warped term contributes to the encoder.
ABLATION BEHAVIOR OFF: Identical code with W_i = I_d for every item (no successor second moment, no alpha, no eigenbasis); everything else, including Mobius prefix composition and the Poincare chord, unchanged. The switch exists and is exercised only by unit tests in this round, not trained.
ABLATION GEOMETRY OFF: Identical code with the curved terms replaced: chord measured in flat coordinates, d = || W_i( z_i - (p_{l-1} + u_{l,k}) ) ||^2, prefix composed by plain vector addition; the behaviour warp W_i stays. Switch exists, not trained.
ABLATION BOTH ON: The full coupled run: successor-frame warp W_i inside the warped Poincare chord with Mobius prefix composition, trained once, no sweep, no extra seed, no early stopping.
SPEC EQUATIONS: epoch hook (no grad):   A <- transitions(training sequences); t_i <- log_0^c(z_i) with z_i = exp_0^c(clip(f(e_i), R)), detached   for each i: S_i <- min set covering 0.8 * out_mass(i); pi_i <- normalise(A_i,S_i)      M_i <- sum_{j in S_i} pi_ij t_j t_j^T ; (lambda, B_i) <- eigh_desc(M_i)      lambda <- max(lambda, 1e-6*mean(lambda)+1e-12); alpha_i <- lambda_1/sum(lambda)      s_i <- clip( exp( 0.5*alpha_i*(log lambda - mean(log lambda)) ), 1/sqrt(d), sqrt(d) )      W_i <- B_i diag(s_i) B_i^T          # det = 1   fallback: |S_i| < 2 or out_mass(i)=0 -> W_i <- I_d step hook (levels l = 1..L):   p_0 <- 0   ch_{i,k} <- mobius_add( mobius_neg(z_i), mobius_add(p_{l-1,i}, u_{l,k}) )   q_{i,k} <- W_i ch_{i,k};  q <- q * min(1, r_max/(||q||+1e-12))   d_{i,k} <- (2/sqrt(c)) * artanh( sqrt(c)*||q_{i,k}|| )   # arg clipped to 1-1e-7   k_l <- argmin_k d ; token_l <- k_l ; p_{l,i} <- clip_ball( mobius_add(p_{l-1,i}, u_{l,k_l}), r_max )   loss <- sum_l d_{i,k_l}^2 + beta * commitment(...)  # beta = baseline value   straight-through gradient from p_{l,i} to encoder latent; W_i detached
SPEC INPUTS OUTPUTS: Inputs per item: content embedding e_i, prefix point p_{l-1,i} in the ball, level-l codebook U_l inside the ball, and the precomputed frame (B_i, s_i) i.e. W_i. Outputs per item per level: chosen index k_l and hence the level-l SID token, the new prefix point p_{l,i} in the ball, and the scalar warped Poincare distance used in the loss. Episode-level output: the SID table (item -> (token_1,...,token_L)) consumed by Stage 3, plus recorded frames and distances.
SAFEGUARDS: Mobius arithmetic in the algebraically stable form with denominator floored at 1e-8; every achieved point re-projected to ||p|| <= r_max = 1-1e-3 after each addition and each codebook update; chord rescaled if the warp pushes it past r_max; artanh argument clipped to 1-1e-7 and implemented as 0.5*log((1+x)/(1-x)); eigenvalue floor relative to the measured trace; s_i clipped to [1/sqrt(d), sqrt(d)] so det(W)=1 and no direction is annihilated; alpha_i clipped to [0,1]; frames detached and refreshed only once per epoch; identity fallback for items with fewer than two successors or zero outgoing mass; the identity-frame diagnostic re-uses the same distance function object as the trained path; NaN/Inf guard on the per-level loss with the step skipped and logged if triggered.
END IDEA
