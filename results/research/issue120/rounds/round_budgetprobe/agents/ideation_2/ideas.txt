IDEA: beh-aniso-poincare-rq
TITLE: Behaviour-anisotropic Poincare gauge metric for RQ-VAE residual assignment and codebook update
MOTIVATION: In a plain Euclidean RQ-VAE the level-1 code of an item is a generic residual direction; items that are behaviourally interchangeable as predecessors (their training successors point the same way) are not pushed to share a coarse prefix, so the generative model must spend prefix capacity on behaviour-irrelevant geometry.
NOVELTY: Prior rounds moved codebook placement (Frechet/successor means), curvature schedules, radial ranking, cone/prefix boosting and successor-profile smoothing. This changes the metric itself: each item carries its own anisotropic Poincare gauge whose stretch axis is the training successor direction and whose stretch magnitude is the measured successor concentration, applied inside the same closed-form distance that drives assignment and codebook update.
CHANGE: Residual quantisation runs in the unit Poincare ball with Mobius residuals and a per-item anisotropic gauge (stretch 1+beta_i along u_i), so along-successor mismatches cost more than orthogonal ones; assignment uses that cost and codebooks are updated as tangent Frechet means of the resulting assigned residuals.
SPECIFICATION: c=1 fixed (tanh/artanh chart, scale-free, no normalisation constant). Per item i from training transitions obtain beta_i in [0,1] and unit tangent direction u_i; if the item has no training successors set beta_i=0. At each RQ level l, with base point p_l in the ball and target x_i=exp0(z_i): r_l = (-p_l) (+) x_i; for every code w_k compute d_k = 2*artanh(sqrt(||(-r_l)(+)w_k||^2 + beta_i*<(-r_l)(+)w_k, uhat_l>^2)) with uhat_l = normalise(log0(exp0(u_i) (-) p_l)); assign k* = argmin_k d_k; carry p_{l+1} = p_l (+) w_{k*}. Codebook update: w_k <- exp0(mean over assigned items of log0(r_l)). Behaviour table refreshed once per epoch from the current item embeddings. Three switches exist in code: behaviour off (beta=0), geometry off (c->0 flat limit), both on (the single trained run).
COST: No new parameters, no tuned constants. +1 dot product per (item, level, code) triple: about +30% on the level-wise distance kernel and under 5% wall clock. Per step at the frozen scale (batch B items x L levels x K codes x d dims; e.g. B=1024, L=4, K=256, d=64) that is ~6.7e7 extra multiply-adds for the anisotropic term; 24 steps/epoch and 3000 epochs unchanged. Behaviour refresh costs |E| x d (~5e5 x 64 = 3.2e7 multiply-adds) once per epoch, under 1% of an epoch. Sparse transition matmul, so memory is negligible.
HYPOTHESIS: If the gauge is doing hierarchical work, then with the switches on the level-1 prefix hit rate of training transitions and the RQ reconstruction at level 1 both improve and the single Stage-3 run gives test_recall@10 above 0.065; if recall does not move while the prefix hit rate does, the gain is not reaching the generative model and the idea is dropped.
RISKS: Anisotropy may be too mild: beta in [0,1] bounds the stretch at sqrt(2), so codes may barely move.; Successor direction is noisy for tail items with few training transitions, so beta is small exactly where it could help.; Mobius residuals plus Frechet codebook updates are harder to optimise and may collapse codebook usage.; The once-per-epoch behaviour refresh lags embedding drift and could inject stale directions.; Single run, single seed: the effect may be inside seed noise and the programme cannot repeat it.
BEHAVIOR SIGNAL: Directed item-to-item transitions from the training split only, summarised per item as a successor resultant direction u_i and a successor concentration beta_i.
BEHAVIOR COMPUTATION: From Stage-2 training sequences only, count directed co-occurrences N_ij inside the training window and row-normalise to p_ij = N_ij / sum_j N_ij. With z_j = log0(exp0(.) ) of the item input embedding, b_i = sum_j p_ij * z_j/||z_j||, beta_i = ||b_i|| which lies in [0,1] by convexity of unit vectors, u_i = b_i/||b_i||. Recomputed once per epoch from the current embeddings and frozen within the epoch; items with no training successors get beta_i = 0 and u_i = 0.
LEAKAGE BOUNDARY: N_ij is built exclusively from Stage-2 training-split sequences before Stage 3 starts; item ids are frozen up front and no validation or test interaction is read at any point. The behaviour table is a periodic re-read of training counts only, so no validation or test item, transition or co-consumption can enter the SID construction.
HYPERBOLIC OPERATOR: Fixed negative curvature c = 1: Mobius addition (+), tanh/artanh exponential and logarithmic maps at the origin, Poincare distance d(x,y) = 2*artanh||(-x)(+)y||, extended by the anisotropic gauge q(delta) = ||delta||^2 + beta*<delta,uhat>^2 and d_aniso = 2*artanh(sqrt(q)).
HYPERBOLIC LOCATION: Inside the residual quantiser of every RQ level: both in the assignment step (distance from residual to code) and in the codebook update (tangent-space Frechet mean of the assigned residuals), i.e. in the SID construction itself rather than in an auxiliary loss.
COUPLING PATH: Training transitions -> (beta_i, u_i) -> the anisotropic curved cost that selects the code at level l -> the assigned residual whose tangent mean becomes codebook entry w_k at level l -> the level-(l+1) base point -> the emitted SID. Setting beta=0 removes the behaviour term from that same cost; flattening c removes the Mobius/artanh structure from that same cost; either change alters which code is chosen, hence the codebooks and the SIDs.
COUPLING EQUATION: d_{i,k}^{(l)} = 2*artanh( sqrt( ||(-r_l)(+)w_k||_{c}^2 + beta_i * < (-r_l)(+)w_k , uhat_l >^2 ) ), with beta_i = || sum_j p_ij * zhat_j || (behaviour term) and the Mobius addition and artanh with curvature c = 1 (curved terms).
OBSERVABLES: Per-level code assignment histograms and codebook usage; level-1 and level-2 prefix hit rate of training transitions and prefix counts (diagnostics, recorded not gated); SID drift for items with coherent versus diffuse successor fields; per-level RQ reconstruction error; Stage-3 test_recall@10 as the sole judgement.
ABLATION BEHAVIOR OFF: beta_i set to 0 for every item, everything else identical, so the cost degenerates to the plain isotropic Poincare distance; implemented behind a config flag and NOT trained this round.
ABLATION GEOMETRY OFF: Take the c -> 0 flat limit: (-r)(+)w becomes plain subtraction, 2*artanh(sqrt(c*q))/sqrt(c) becomes 2*sqrt(||x-y||^2 + beta*<x-y,uhat>^2), and the Frechet update becomes a plain mean; implemented behind a config flag and NOT trained this round.
ABLATION BOTH ON: The full mechanism as specified (behaviour-derived beta_i and u_i plus curvature c = 1 Mobius gauge in both assignment and codebook update); this is the single trained run of the round.
SPEC EQUATIONS: exp0(v) = tanh(||v||) * v/||v||; log0(x) = artanh(||x||) * x/||x||; a(+)b = ((1+2<a,b>+||b||^2)a + (1-||a||^2)b) / (1+2<a,b>+||a||^2||b||^2). p_0 = 0; for l = 1..L: r = (-p)(+)x; for k: delta_k = (-r)(+)w_k; q_k = ||delta_k||^2 + beta_i*<delta_k,uhat_l>^2; d_k = 2*artanh(min(sqrt(q_k), 1-1e-6)); k* = argmin_k d_k; p = p(+)w_{k*}; SID_i[l] = k*. Update: w_k <- exp0( sum_{i assigned to k} log0(r_i) / count_k ). Behaviour: p_ij = N_ij/sum_j N_ij, b_i = sum_j p_ij zhat_j, beta_i = ||b_i||, u_i = b_i/||b_i||, uhat_l = normalise(log0(exp0(u_i)(-)p_l)).
SPEC INPUTS OUTPUTS: Inputs: item embedding z_i from the RQ-VAE encoder, the per-item training transition table giving (beta_i, u_i), the current level codebooks as ball points, and the current level base point p_l. Outputs: per-level code indices forming the SID, the quantised ball point p_L, updated codebooks, and the standard reconstruction and commitment losses computed in the tangent space at the origin.
SAFEGUARDS: Clamp ||x|| to at most 1-1e-5 before log0 and before artanh; clamp the artanh argument to 1-1e-6 and use a finite-gradient safe artanh; clamp the Mobius denominator (1+2<a,b>+||a||^2||b||^2) to at least 1e-8; guarantee beta in [0,1] by construction (mean of unit vectors) and set beta=0, u=0 when ||b_i||<1e-8 (cold or unseen items); nan_to_num on the Frechet mean and freeze any code that received no assignment instead of moving it; cast the transition counts to the model dtype and keep the diameter term in float32 for the sparse refresh.
END IDEA
