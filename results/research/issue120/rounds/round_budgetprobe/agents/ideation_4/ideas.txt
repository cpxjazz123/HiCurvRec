IDEA: SUCCFRAME-MOEB-RQ
TITLE: Successor-framed residual quantization: every RQ level re-expresses the residual in a frozen behaviour anchor frame through Mobius isometries, so the whole SID prefix hierarchy is quantized relative to where the item's train-split successors live
MOTIVATION: In a plain RQ-VAE every prefix level quantizes the same item vector, so coarse prefixes and their refinements all describe the item alone; the generative recommender must learn from Stage 3 data which refinements actually separate an item from its behavioural neighbours. Items inside one behaviour cluster get deep prefix bits spent on directions no successor distinguishes, while the direction toward the successor region, the only one Stage 3 needs, is not privileged. The mechanism forces deeper prefixes to encode the offset of the item from its successor region instead of restating the item.
NOVELTY: Earlier rounds changed the codebook (successor-weighted Frechet updates), the curvature scalar (per-level prefix-transition score), or the assignment weight/radius (behaviour-ranked radial assignment, branch-curvature experts). Here the codebook update, the assignment weight and the curvature scalar are untouched: the change is the residual PATH. The residual is carried between frames by Mobius isometries (Mobius subtraction of the chosen codeword, Mobius addition of a frozen behaviour anchor) and the decoder inverts exactly those isometries. Behaviour off reduces the recursion to a plain curved RQ; geometry off reduces it to Euclidean RQ with an additive behaviour offset; neither switch preserves the other.
CHANGE: Replace the Euclidean residual p_l = p_{l-1} - c_l by p_l = (p_{l-1} (-) C_l[k_l]) (+) A_l(i) in the Poincare ball, with A_l(i) a frozen per-item successor anchor, decode by the exact inverse recursion q_L = 0, q_{l-1} = (q_l (-) A_l(i)) (+) C_l[k_l], and use a geodesic reconstruction loss.
SPECIFICATION: Curvature fixed at c=1 (unit Poincare ball, documented default, never tuned). Encoder output z_i in R^d, clipped to ||z_i|| <= R = atanh(0.9) = 1.4722, point x_i = exp_0(z_i) = tanh(||z_i||) z_i/||z_i||. Codebooks stored as tangent tables W_l in R^{K x d}, points C_l = exp_0(W_l); K and L are exactly the frozen baseline config values. BEHAVIOUR ANCHOR, computed ONCE before Stage 2 and frozen: build the row-normalised directed transition matrix M from TRAIN-split session transitions only, M[i,v] = count(i->v)/sum_v count(i->v); take a rank-d randomised SVD M ~ U S V^T with fixed RNG seed and a fixed sign convention (flip each left-singular column so its largest-magnitude entry is positive); item factor b_i = (U S^{1/2})_i; anchor tangent t_i = tau * b_i / max(||b_i||, eps) with tau = atanh(0.5) = 0.5493 (documented mid-ball default) and t_i = 0 when item i has no train successor; a_i = exp_0(t_i); store A_l(i) = exp_0(0.5^{l-1} t_i) for l = 1..L (rho = 0.5 is a documented geometric contraction so the accumulated frame offset sum_l rho^{l-1} < 2 stays bounded; level 1 carries the full successor offset, finer levels the shrunken remainder). ENCODE: p_0 = x_i; for l = 1..L: k_l = argmin_k d_c(p_{l-1}, C_l[k]); p_l = (p_{l-1} (-) C_l[k_l]) (+) A_l(i), where x (-) y = x (+) (-y) and (+) is Mobius addition. DECODE: q_L = 0; for l = L..1: q_{l-1} = (q_l (-) A_l(i)) (+) C_l[k_l]; x_hat_i = q_0; the inversion is exact because each encoding step is an isometry. LOSS: L_rec = mean_i d_c(x_i, x_hat_i)^2 with d_c(x,y) = 2 artanh(||(-x) (+) y||); the baseline's commitment and codebook-usage terms keep their baseline weights, the commitment term evaluated on log_0(p_{l-1}) against W_l[k_l]. Straight-through code selection as in the baseline. SID = (k_1,...,k_L) from the same recursion at the end of training.
COST: One-off randomised rank-d SVD of a 24556 x 24556 sparse matrix (~123k nnz, seconds to about 1 minute); anchors stored as 24556 x L x d float32 (~9 MB at d=32, L=3). Per step at the frozen scale (24 steps/epoch, batch ~1024, 3000 epochs = 72000 steps): L extra Mobius subtractions, about 2L Mobius additions, 2L exp/log on d-vectors plus one exp per level for the decode, i.e. roughly 6L vector ops of size 1024 x 32, well under 1% of the transformer's per-step FLOPs; the K-way argmin distance work is unchanged. Expected wall clock 1.02-1.10x baseline, memory +~10 MB, no extra forward or backward pass, no extra epochs.
HYPOTHESIS: If the successor frame is the right carrier for prefix refinement, then level-2/3 codes of items inside one behaviour cluster will diverge according to which part of the successor region the item points to, geodesic reconstruction loss will fall at equal L, and Stage 3 test_recall@10 will exceed 0.065 with unchanged codebook size, loss weights and epochs; observed from the single logged test_recall@10 and from the shift of the level-2/3 code histogram under the frame relative to Euclidean framing.
RISKS: Sparse tail: most items have fewer than two train successors, so their anchor is near-origin and the mechanism degenerates to plain curved RQ exactly where SIDs are least used; the head may carry the whole gain.; SVD factors of the transition matrix are popularity-driven, so the anchor may encode popularity rather than a behaviour direction.; Mobius recursion drift: accumulated frame offsets can push p_l toward the ball boundary where artanh gradients saturate and the straight-through code choice is unstable.; The geodesic reconstruction loss replaces the baseline squared Euclidean loss, so a recall change could be attributed to the loss rather than to the frame coupling; a single run cannot separate these, the coupling's own evidence being the two switches.; The randomised SVD rank is fixed to the encoder width d rather than chosen by validation, which is a hidden design choice.; If the encoder collapses to near-origin points (common in RQ-VAE), exp/log are almost linear, curvature barely acts, and the both-on arm may behave like the Euclidean one.
BEHAVIOR SIGNAL: Directed item-to-item transitions from TRAIN-split sessions (consecutive next-item edges), summarised as each item's successor-profile anchor in the Poincare ball.
BEHAVIOR COMPUTATION: Training split only: count every ordered consecutive pair (i,v) in training sessions, row-normalise to M, take b = (U S^{1/2}) from a seeded rank-d randomised SVD of M, t_i = tau b_i / max(||b_i||, 1e-8), a_i = exp_0(t_i), A_l(i) = exp_0(0.5^{l-1} t_i). Computed once before Stage 2, stored as a frozen tensor with no gradient, reused every epoch and for the final SID assignment. Popularity is controlled by row normalisation (each source's activity divided out) and absorbed by the leading singular factor.
LEAKAGE BOUNDARY: The transition matrix, its SVD and therefore every anchor A_l(i) are built exclusively from train-split sessions before Stage 2 begins, are frozen with requires_grad=False, and are never recomputed during training or at evaluation. No validation or test interaction and no Stage 3 prefix or successor statistic enters SID construction; validation items only feed the standard reconstruction logging, and an item with no train successor simply gets an origin anchor.
HYPERBOLIC OPERATOR: Fixed negative curvature c=1 Poincare ball: Mobius addition (+) and subtraction (-), exp_0/log_0 maps, and the Poincare distance d_c(x,y) = 2 artanh(||(-x) (+) y||), used both inside the residual recursion and as the reconstruction metric. No trainable curvature, so no curvature sweep exists.
HYPERBOLIC LOCATION: Inside the Stage 2 residual quantizer (encoding recursion p_l and decode recursion q_{l-1}) and in the reconstruction loss; it acts on quantization, not on the recommender backbone.
COUPLING PATH: The single pathway is the residual update p_l = (p_{l-1} (-) C_l[k_l]) (+) A_l(i). The behaviour anchor A_l(i) is the operand of the Mobius addition against which the next level's codeword is measured, so the next level's argmin and hence every deeper prefix code depends on the anchor. Setting A_l(i) to the origin removes behaviour and leaves plain curved RQ; replacing Mobius add/subtract, exp/log and d_c by +, -, identity and L2 removes the geometry, including the anchor's action.
COUPLING EQUATION: p_l = (p_{l-1} (-)_c C_l[k_l]) (+)_c A_l(i), with A_l(i) = exp_0^c(rho^{l-1} * tau * b_i / ||b_i||), k_l = argmin_k d_c^c(p_{l-1}, exp_0^c(W_l[k])), and L_rec = mean_i [d_c^c(x_i, x_hat_i)]^2.
OBSERVABLES: (1) Level-2 and level-3 code identity and code histogram for items with non-degenerate anchors, versus Euclidean framing; (2) geodesic reconstruction loss per level, flat after level 1 meaning the frame does nothing; (3) prefix-to-successor transfer predictability over shared-prefix groups (diagnostic only, never a gate); (4) frame sensitivity: number of items whose nearest codeword changes when the anchor is removed at inference; (5) Stage 3 test_recall@10 against the 0.065 bar.
ABLATION BEHAVIOR OFF: Set A_l(i) = 0 (origin) for all items and levels, giving p_l = p_{l-1} (-) C_l[k_l] and q_{l-1} = q_l (+) C_l[k_l]: exact Mobius residual RQ with geodesic reconstruction and no successor information. Implemented as one boolean that zeroes the frozen anchor table; never run in this round.
ABLATION GEOMETRY OFF: Flat limit c -> 0: exp_0 and log_0 become identity, (+) becomes +, (-) becomes -, d_c becomes L2; the recursion becomes p_l = p_{l-1} - e_l + A_l^Euclid(i), decode x_hat = sum_l e_l - sum_l A_l^Euclid(i), with t_i used unscaled in R^d. Behaviour on, curvature off, selected by one operator-set boolean; never run in this round.
ABLATION BOTH ON: The full recursion with c=1 Mobius operators and frozen successor anchors at every level plus the exact inverse decode, trained once for the 3000 frozen Stage 2 epochs and evaluated once by the frozen Stage 3 protocol.
SPEC EQUATIONS: c=1; R=atanh(0.9)=1.4722; tau=atanh(0.5)=0.5493; rho=0.5. exp_0(v)=tanh(||v||) v/||v|| (0 at v=0); log_0(x)=artanh(||x||) x/||x||; for c=1, x(+)y = ((1+2<x,y>+||y||^2) x + (1-||x||^2) y)/(1+2<x,y>+||x||^2||y||^2); d_c(x,y)=2 artanh(||(-x)(+)y||). Precompute: M = row-normalised train transitions; [U,S,~] = rsvd(M,d); b = U S^{1/2}; sign-fix columns; t_i = tau b_i/max(||b_i||,1e-8) if item i has a successor else 0; A_l(i)=exp_0(rho^{l-1} t_i). Encode: z=E(i); z = clip_norm(z,R); x=exp_0(z); p=x; for l=1..L: dist_k = d_c(p, exp_0(W_l[k])) for k=1..K; k_l = argmin; p = (p (-) exp_0(W_l[k_l])) (+) A_l(i). Decode: q=0; for l=L..1: q = (q (-) A_l(i)) (+) exp_0(W_l[k_l]); x_hat=q. Loss: L = mean_i d_c(x_i,x_hat_i)^2 + beta_cm * mean_{i,l} ||log_0(p_{l-1}) - W_l[k_l]||^2 + baseline usage term, with beta_cm and the usage weight exactly as the baseline config (no new weights), straight-through to codebooks and encoder. SID_i = (k_1..k_L) from the trained recursion.
SPEC INPUTS OUTPUTS: Inputs: encoder tangents z_i (batch x d), codebook tangent tables W_l (K x d), frozen anchor tangents t_i (num_items x d), booleans use_behaviour and use_curvature, curvature c=1. Outputs: chosen code tuple (k_1..k_L) per item, reconstructed ball point x_hat_i, scalar geodesic reconstruction loss and its gradient with respect to the encoder output and to W_l.
SAFEGUARDS: Clip every tangent norm to R=atanh(0.9) before exp_0 so ball points stay at radius <= 0.9 and artanh is never evaluated at 1; clamp the Mobius-addition denominator to >= 1e-8 and clamp ||(-x)(+)y|| to <= 1-1e-7 before artanh; use the stable Mobius form with the (1+2<x,y>+||x||^2||y||^2) denominator and per-batch norm shifting where available; define exp_0(0)=0 and log_0(0)=0 by convention; anchor rows of items with no train successor are exactly zero so they fall back to plain curved RQ; the whole anchor tensor is a frozen buffer built with a fixed seed and a deterministic SVD sign convention so the run is reproducible; rho=0.5 and tau=atanh(0.5) are documented defaults never swept and c=1 is fixed so there is no curvature search; one step-0 check sets codes to the exact per-level residuals and verifies d_c(x_i, x_hat_i) < 1e-3, validating the decode inversion before any training.
END IDEA
