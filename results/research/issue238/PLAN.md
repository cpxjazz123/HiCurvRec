# 探索轮:两条不同机制的 Stage2 → Stage3 闭环

## 依据(来自 #234–#237 的证据)

| 证据 | 结论 |
|---|---|
| #234 六个 λ 全部无质量合格点 | 在 RQ-VAE 目标里**加结构 loss** 会同时损伤重建与 Stage3 recall |
| #234 Stage3 recall 单调下降 | graphlet 对齐指标与 Stage3 收益**不相关** |
| #235/#236 曲率 −1.02、符号由度数决定 | 图整体负曲率,但异质 |
| #237 图传播表示使链接预测 AUC 0.596→0.656,但 cosine 0.005 | 存在**纯结构**表示,且语义代价极大 |

**#237 明确把「是否接入 RQ-VAE」留给后续。** 本轮直接回答这个问题,并加一条对照。

## 两条机制(每臂只改 2 行,机制代码零改动)

| 臂 | 唯一实验变量 | 预期 |
|---|---|---|
| `TIGER_g237_struct_rq` | 输入 Embedding = #237 variant A(纯结构,cos 0.005) | 若 SID 编码图位置,Stage3 可能受益 |
| `TIGER_g237_sem_rq` | 输入 Embedding = #237 variant B(语义保留,cos 0.881) | 语义在场,结构增益较弱 |

两臂都从冻结基线复制,`diff` 只有 `ARM_NAME` 与 `EMBEDDING_FILE` 两行;
RQ-VAE 结构、损失、优化器、Sinkhorn 分配、导出协议**逐字节一致**。

## 为什么这是「不同机制」而不是同一机制的参数

`#234` 改的是**目标函数**(加结构 loss);本轮改的是**输入表示**(数据)。
目标函数不动,所以不存在「结构 loss 与重建竞争」这条 #234 的失效路径。

## 固定基线

`results/stage2_RQ-VAE/TIGER_RQ-VAE`,Stage3 `test_R@10 = 0.055450`(n_eval 57439)。
历史最佳臂 `TIGER_r48k2_rq` = 0.064764。门槛(test 验收)0.065。
