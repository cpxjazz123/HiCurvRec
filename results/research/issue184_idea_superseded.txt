Idea：LKC——一级分配的曲率**按码学习**（每码的 κ_k 由分到该码的商品的实测曲率更新）
英文名称：LKC — Learned Per-Code Curvature in the Level-1 Assignment

## 一、起点与非对比约束

主线新要求：**不允许行为对比正负样本学习**。因此本臂不含任何 InfoNCE/BCE/margin 对比、也不含源–目标对对比；
结构信号只以**度量参数**的形式进入量化通路。

现状：冻结基线（`TIGER_mixed_rq` / `_reference_baseline_deterministic`）的 E16×H16 乘积空间里，**曲率是全局常数 κ=1**
（`mixed_geometry.py`：`CURVATURE = 1.0`）；AF3 实测的逐商品曲率表 `results/research/issue167/kappa.json`
（均值 1.0、中位 0.9147、max 8.2671）从未进入量化器。语料中曲率进代价的探针（`TIGER_struct_mixed_rq` 0.057905、
`TIGER_hc3_rq` 0.054023）用的也都是**固定或按前缀平均**的 κ，且 #177 证明把曲率铺到三层会掉分。

## 二、主张（一句话）

一级分配的曲率不再是常数：每个一级码 `k` 拥有自己的曲率 `κ_k`，由**上一轮被分到该码的商品的实测曲率**取平均得到（detach、
只读训练统计、每轮刷新）；一级代价用 `d_{κ_k}`，Sinkhorn 本体与分配规则仍为基线的。于是"该码适合的几何"是在量化循环里
被数据**学出来的**，而不是外部给定的常数。

## 三、公式（唯一改动）

```
κ_i        = 冻结 AF3 表 results/research/issue167/kappa.json（均值 1.0、中位 0.9147、max 8.2671；缺失 31 项按 mean_frozen）
κ_k(0)     = 1.0                                              # 初始化 = 基线常数
κ_k(t+1)   = mean{ κ_i : i 在本轮被一级分配到码 k }            # 每 epoch 末刷新，detach，无梯度
             （码 k 本轮无商品时保持上次值；κ_k < 1e-3 取 1.0 并计数）
一级代价：  C_1(i,k) ∝ d_{κ_k}( to_ball(r_1,i; κ_k), to_ball(c_{1,k}; κ_k) )
             d_κ(p,q) = (2/√κ)·asinh( √κ‖p−q‖_ε / √((1−κ‖p‖²)(1−κ‖q‖²)) )
             ‖p−q‖_ε = sqrt(‖p−q‖² + ε_pq), ε_pq = finfo(dtype).eps·max(‖p‖²,‖q‖²,1)
```

- **不变**：E16×H16 乘积结构、`d_M² = ‖e1−e2‖² + d_H²/4` 的装配方式、Sinkhorn（ε=0.003、50 sweeps、centring）、码本 K=256、
  三级残差递推、读出与导出、3000 epoch、seed 42、全局 batch 4096。
- 无新增可调常数：`κ_k` 由实测表与分配结果决定；刷新周期就是 epoch，无额外超参。
- 与已作废方向的区别：**没有任何配对/对比损失**；改的是"代价里那个曲率"本身。

## 四、开关（存在且接线正确，**不训练关闭臂**）

- `KAPPA_FROZEN`：`κ_k ≡ 1.0` → **必须与冻结基线逐位一致**（同 batch 同 seed，含导出）。
- `BEHAVIOUR_OFF`：κ 表按商品随机置换（分布不变、对应关系破坏）→ 廉价接线检查，确认信号来自**测到的** κ。
- `LEARNED`：出厂形态（κ_k 每轮刷新）。

## 五、验收（派发前，全部可测）

1. **`KAPPA_FROZEN` 逐位一致**：损失与导出码字与冻结基线完全相同。
2. **`d_κ` 性质**：κ=1 与仓库冻结 `poincare_contract.distance` 一致（rtol 1e-6）；`p=q` 与 `‖p−q‖∈{1e-12,1e-9,1e-6,1e-3}`
   梯度有限、gradcheck（双精度）通过；对称、零距离、抽样三角不等式；`to_ball` 严格球内。
3. **`κ_k` 更新正确**：构造两批可控分配，断言 `κ_k(t+1)` 等于分到 k 的商品的 κ 均值；空码保持旧值；触底规则生效并计数。
4. **无梯度泄漏**：`κ_k` 更新路径不产生梯度（`requires_grad=False`），检查编码器梯度不含该项。
5. **一 epoch 真实入口冒烟**：损失有限、`κ_k` 分布有记录、代价矩阵非恒定、导出 SID 有效。
6. **导出统计**：全量 24587，逐层码数/最大份额（≤10%）、二级前缀、三级碰撞（并列基线 0.162444）、§63 `l3_collision`；
   `collision < 0.40`。
7. **TDD**：先写会失败的测试（`κ_k` 更新的批构造、空码、触底、`d_κ` 边界梯度、`KAPPA_FROZEN` 逐位一致），确认红后再实现。
8. 1–6 任一不过：按预派发负结果记录并停止，不改 ε/码本/刷新规则。

## 六、边界与不变项

- 起点：冻结基线 `stage2_RQ-VAE/TIGER_mixed_rq`（只读、逐文件 SHA 记 manifest）→ 新树 `stage2_RQ-VAE/TIGER_lkc_rq`
  （`ARM_NAME="TIGER_lkc_rq"`、`ARM_VARIANT="LKC"`）。
- 不引入任何对比/正负样本损失、不引入容量规则、不改 Sinkhorn 分配规则（§19h）、不改码本与预算。
- 树内无绝对路径；`/tmp` 不落产物；checkpoint 绑 κ 表 SHA 与刷新规则版本。
- 一个候选只跑一次正式训练（§19g）：seed 42、3000 epoch、全局 batch 4096、四卡 50202；不做消融/多种子/扫描。
- §19 耦合：AF3 结构（逐商品 κ）→ 学到的每码曲率 → 显式双曲距离 → Sinkhorn 选码 → SID，同一条连通通路。
- 判据唯一：`test_R@10`；参照冻结基线 **0.05622**、`struct_mixed` 0.057905、成功线 0.065。
