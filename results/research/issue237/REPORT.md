## 3. 模型(C4–C10)

| 项 | 值 |
|---|---|
| 专家 | 5 个两层 κ-GCN |
| 初始曲率 | {-3, -1, 0, +1, +3},0 冻结,其余可学习 |
| 曲率终值 | **{-3.266, -1.144, 0, +1.012, +3.409}** |
| 专家维度 | 128(5 × 128 = 640) |
| 隐藏维度 | 256 |
| 门控 | 2 层 GCN + 2-hop/3-hop ego 均值池化 + Linear → softmax |
| 输出头 | `Linear(640 → 768)`,与链接预测/失真目标联合训练 |

### κ-GCN 的聚合是流形的

```
x → expmap0(normalize(x) · scale)
h₁ = expmap0( D^-1/2 (A+I) D^-1/2 · logmap0( W₁ ⊗_κ x + b₁ ) )
h₂ = expmap0( D^-1/2 (A+I) D^-1/2 · logmap0( W₂ ⊗_κ h₁ + b₂ ) )
```

即官方 `kappaGCNConv` 的 `logmap0 → GCN 归一化和 → expmap0`,**不是**欧氏加权拼接。

### 与官方实现的逐项对照(C8)

| 官方 | 本实现 | 差异 |
|---|---|---|
| `geoopt.Stereographic.expmap0/logmap0/proju` | `manifold.py` 按 Bachmann et al. κ-stereographic 公式自建 | `geoopt` 未安装 |
| `manifold.mobius_matvec`(几何闭式) | `expmap0(W · logmap0(x))` | 代数等价形式的差别,**已声明** |
| `manifold.mobius_add` | 标准 Poincaré 陀螺向量加法,符号由"与闭合距离公式一致"定标 | 已数值验证 |
| `RiemannianAdam` | 普通 Adam(参数在切空间参数化) | 已声明 |
| `Stereographic(k, learnable=True)` | `±softplus(raw)`,符号恒定 | 等价约束 |
| ego 子图 + `global_mean_pool` | ego 指示矩阵 + 稀疏 `mm` 池化 | 数学等价;**上限 64/128 节点**(图比 Cora 大 9 倍) |

## 4. 训练目标(C11–C12)

```
score(u,v) = sigmoid((r − d_w(u,v)) / t)              FermiDirac, r=2, t=1
d_w(u,v)   = Σ_e softmax(w_u ⊙ w_v)[e] · ‖z_u^e − z_v^e‖²     权重对齐距离
L_lp       = BCE(score(pos),1) + BCE(score(neg),0)    clip 到 [0.01, 0.99]
L_dis      = mean | d_w(m,n) / d_graph(m,n) − 1 |
L          = L_lp + 0.1 · L_dis                       (+ 1.0 · L_sem 仅 variant B)
```

- 归一化:输入按行 L2 归一化后按 `0.5/√|κ|` 缩放,保证落在球内(球面专家不会炸)
- 温度:门控 softmax 温度 1.0;FermiDirac t=1.0
- 采样:每个 epoch 全量 264,929 条正边 + 等量负样本
- 优化:Adam(lr 1e-3, wd 1e-6),梯度裁剪 5.0,seed 42,单次运行(C14)

### 5.4 Graphlet 诊断(C23)

隔离 bank(`results/research/issue231/banks`),评估边不进入传播图。

| 结构 | 原始排序率 | **variant A** | 变化 |
|---|---:|---:|---:|
| chain | 0.3698 | **0.3802** | +0.0104 |
| fork | 0.4228 | **0.4362** | +0.0134 |
| merge | 0.4259 | **0.4753** | +0.0494 |

判据定义(无向投影上的距离序):chain 期望 `d(A,C) > max(d(A,B), d(B,C))`;
fork/merge 期望 `d(B,C) > max(d(A,B), d(A,C))`。

**这三项只证明无向结构。** fork 与 merge 在无向投影上结构相同,因此**这里无法区分方向**,
也**不能**由此断言 embedding 保留了有向的 chain/fork/merge 类型。

## 9. 对后续的启发

1. **结构收益确实存在**(test AUC +0.060,三族 graphlet 排序率全部上升),但代价是把语义
   表示整体替换掉(cosine 0.005)。若下游 RQ-VAE 依赖语义连续性,这不可接受。
2. **加语义约束会让结构收益消失并跌破基线**(0.5551 < 0.5957),且门控塌到欧氏专家。
   这说明**双曲专家的价值来自离开语义空间**,而不是"更贴切地表达语义"。
3. **中间曲率 ±1 从未被选中**,说明 5 专家对这张图过参数化;后续若要再试,应从 3 专家
   {−3, 0, +3} 起步,并显式加语义约束做权衡曲线。
4. 是否把 variant A 接入 RQ-VAE,由本轮证据决定:它在 hold-out 上确实改善了行为结构,
   但语义几乎不可回收,接入前应先确认 RQ-VAE 对语义连续性的依赖程度。
