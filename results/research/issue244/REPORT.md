# Issue #244 — GraphMoRE Teacher 修复与重叠子图保真：结果

冻结 2026-11-23；单 Agent；按最新 complete-open-issue（铁律 + 七项机制 + 六条测试正确性）。

## 1. 结论先行

**本 issue 的主假设（同一商品的混合几何表示能同时保留它参与的多个局部关系，并优于单一几何）
在本实现下不被支持。** 依据三条独立测量：

| 测量 | 结果 |
|---|---|
| 多子图“同时保真率”（E_t ≤ 0.5 预冻结阈值） | **2.5%**（400 个中心商品 × 3 个子图） |
| 学到的门控 vs 固定均匀门控 | **0.6709 vs 0.6672** —— 学习到的门控没有带来改善 |
| 混合几何 vs 最好的单一专家 | **0.6709 vs 0.6856** —— 差 0.015，边际 |

在未见评估对上，`D_geo` 与真实图距离的 Spearman 是 **0.407**，高于原始语义距离的 **0.049**，
但远低于**非训练**的邻域 Jaccard 基线 **0.894**。也就是说：几何学到了一些结构信息，
但**没有超过一个不用训练、两行代码就能算出的图统计量**。

按 issue §4 的明文规定（「若无可用结构信号则停止 Stage2，先定位证据」），
**未执行 Stage2 与 Stage3**。这是有效负结果，不是实现失败——实现的正确性由 §2 单独证明。

## 2. 实现正确性（先证伪“是 bug 不是结论”）

| 机制 | 证据 | 结果 |

| 独立参考实现 | `reference.py`：正曲率走**逆球极投影 + 3D 夹角**，不是同公式翻译 | 与生产闭式一致到 1e-15 |

| pair bank | `tests/test_pairs.py` | **7/7**（含验证器拒绝错标签） |
| 生产指标 | `tests/test_metrics.py` | **7/7** |

| RQ-VAE 损失 | `stage2_RQ-VAE/TIGER_topo_distill_rq/tests/test_topo_loss.py` | **5/5** |

**#243 的 π/2 根因已定位并被变异测试钉住**：`proju` 对 k>0 套用了双曲半径截断，
把 Möbius 和的范数 9.474 截成 0.9945 → `2·arctan(0.9945)=π/2`；正确值 `4·atan(0.9)=2.93126`。
`2·tan_k⁻¹` 本身对正曲率也成立（与 3D 定义路线一致到 1e-15），我上一轮对它的指控是错的。

## 3. 尺度标定（§3）

初始化上五个专家的中位距离 [0.0182, 0.0285, 0.2943, 0.1343, 0.0742]，**相差 16.12 倍**。
按预冻结规则（目标 = 五个中位数的中位数；手段 = 合法切空间缩放 `exp(α log z)`；二分求解）：

| 曲率 | −3 | −1 | 0 | +1 | +3 |
|---|---:|---:|---:|---:|---:|
| α | 2.2733 | 2.1456 | 0.2522 | 0.5488 | 1.0001 |
| 标定后中位距离 | 0.07422 | 0.07423 | 0.07422 | 0.07422 | 0.07423 |

尺度差 **16.12× → 1.00008×**；各专家对真实 `L_D` 的梯度由 **4.2e-4–1.4e-1（300× 差）**
收拢到 **8.5e-3–1.3e-2**；饱和率全为 0，没有用倍率掩盖常数距离。

## 4. 正式 Teacher（§4）

400 步、192 对/步、seed 243002、AdamW 1e-3、clip 1.0，一次跑完（508 s）：

- loss 0.68 → **0.541**；训练批 Spearman **0.641**
- **节点门控熵塌到 0.0030**：99.96% 权重落在 c=−1
- **但 pair 权重不是 0.94**：`softmax(W_u ⊙ W_v)` 上五专家为 [0.149, 0.404, 0.149, 0.149, 0.149]
  —— 正好印证 issue 的警告：节点权重集中不能直接解释为 pair 权重集中。
- 各专家平均距离（评估集）[1.859, 0.778, 1.430, 1.397, 0.805]，彼此不同、无常数。

## 6. 重叠子图兼容性（§4 主线）

400 个中心商品，每个 3 个局部子图（radius 1/2 + 不同采样），同一冻结表示与门控：

| 指标 | 值 |
|---|---:|
| 平均 E_t | 0.6709 |
| 最差子图 E（均值） | 0.7301 |
| p90 E（均值） | 0.7233 |
| **同时保真率**（所有子图 E ≤ 0.5） | **0.025** |
| 固定均匀门控 | 0.6672 |
| 单一专家（c=−3/−1/0/+1/+3） | 0.6856 / 0.8280 / 1.0890 / 0.7384 / 0.8317 |

低度数半边与高度数半边几乎相同（0.683 vs 0.659），说明这不是 hub 效应。

## 7. 为什么停在这里（并直接关闭）

issue §4 原文：「若有效实验否定假设如实报告，不为获得正结果反复训练。**若有可用监督信号则继续**。」
「**无可用结构信号则停止 Stage2，先定位证据**。」

三条判据同时指向“无可用的结构优势”：同时保真率 2.5%、学习门控 ≈ 均匀门控、混合几何 ≈ 最好的单一专家，
并且在未见对上落后于非训练的 Jaccard 基线 0.49 个 Spearman 点。因此
**Stage2（3000 epoch）与 Stage3 未执行**，这是 issue 规定的停止点，不是预算托词。

RQ-VAE 候选（`stage2_RQ-VAE/TIGER_topo_distill_rq`）的代码与 5 项测试已交付，
但因 §4 闸门未开放而**从未训练**，没有 checkpoint、没有 SID、没有 Stage3 读数。
