# 选项 C2 的下一 Issue 草案：序列顺序监督（非成对、单 block）

> 依 #189 的 C 分支（owner 给新轴）。本文件把 C2 写成可执行规格，**不构成实现或派发**；owner 认可该轴后可直接提为 Issue。

## 为什么这条轴与已测穿的不同族

本轮六条允许臂全部是"几何量（半径/曲率/壳）进代价或损失"，最好 **+0.3%**（LKC），最强的损失项 **−0.8%**（RCS）。C2 换的是**监督源**而不是几何：用同一用户历史里"谁在谁之后"的顺序信息作为**逐商品标量**目标，**不采样商品对、不构造正负样本**（相邻项的顺序由序列自身决定，不构成 pair 损失）。

## 机制（唯一改动）

1. 起点：冻结基线 `stage2_RQ-VAE/TIGER_mixed_rq` → 新树 `TIGER_seqpos_rq`（`ARM_VARIANT="SEQP"`）。
2. **train-only 目标**：对每个商品 `i`，用训练序列中它出现的所有位置取"归一化序列位置"的均值
   `s_i = mean_over_occurrences( position_in_history / len(history) ) ∈ [0, 1]`；
   只出现在单个位置的商品取其原值；从未作为相邻项出现的商品**不参与损失**（掩码，记录计数）。
3. **监督形式（逐商品、非成对）**：单层线性头 `g(z_i) → ŝ_i`，损失 `L_seq = mean_i (ŝ_i − s_i)² / var_i(s_i)`（按目标方差归一，无量纲）；梯度只经编码器（单 block），**天然不触碰 #187 的"码本块必须也有梯度"约束**。
4. **λ**：走冻结规则；由于只有编码器 block 参与，`λ* = ‖g_encoder^base‖/‖g_encoder^seq‖`，无 ε、无回退，缺梯度即 `CALIBRATION_DEGENERATE` 拒绝训练。
5. **不变**：分配度规（基线 `mixed_sq`）、Sinkhorn、码本、递推、读出、导出、3000 epoch、seed 42、全局 batch 4096、四卡 50202、Stage3 冻结协议。
6. **开关**：`TERM_OFF`（`L_seq≡0`，与基线逐位一致）、`SHUFFLE_TARGET`（把 `s_i` 在商品间随机置换，分布不变——廉价对照接线检查）、`BOTH_ON`。
7. 树内无绝对路径、`/tmp` 不落产物。

## 验收（派发前）

1. `TERM_OFF` 与冻结基线损失与导出逐位一致。
2. `s_i` 构造正确：手算小例（长度 3 的历史，位置 0/1/2 ⇒ 0、0.333、0.667 的均值）；从未出现者被掩码且计数落盘。
3. **非成对断言**：机器检查代码路径无 pair/triple/margin/InfoNCE/BCE（同 #187/#188 的检查器）。
4. 梯度：只对 `L_seq` 反向时编码器收到非零梯度；`s_i` 无梯度。
5. 一 epoch 真实入口冒烟：损失有限、`ŝ` 与 `s` 的相关性、掩码计数、`λ` 落盘、导出 SID 有效。
6. 导出统计 + §89 `collision < 0.40`；完成后按 §63 记分层指标；Stage3 后 §6b 归档。

## 预注册

- 若 `test_R@10 ≤ 0.056216`（基线），本轴关闭，**不再换监督源重跑**；
- 一次冻结预算、不做消融/多种子/扫描；判据唯一 `test_R@10`。
