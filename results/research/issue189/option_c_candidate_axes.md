# 选项 C 的候选新轴（供 owner 挑一条；未实现、未派发）

选项 C 要求 owner 给出一条当前禁止项之外的新轴。若不便从零设计，以下是依本会话实测可直接落地的三条候选，每条都写明**依据、要求与预期代价**，owner 只需点名其一。

## C1. 解禁「成对」但限定在**对比族的第 1 层**（最省算力的冲刺）

- **依据**：`TIGER_r48k1_rq`（#182）实测 **0.064660**，与三层全曲率的 #179（0.064764）差 **0.000104**（0.16%，单 seed 不可分辨）⇒ 第 1 层的对比距离已承载几乎全部增益。
- **要求**：需 owner 明确解禁"源–目标对对比"这一项；机制只改第 1 层，第 2/3 层保持 `torch.cdist`（代码已在 #182 树里，仅需 owner 授权与一次正式训练）。
- **代价**：一次 3000 epoch + 一次 Stage3；**预期**：0.0646 量级，距 0.065 差 0.0003——仍可能不达标，属"最接近成功线"的赌博。
- **风险**：解禁成对项意味着承认本轮主线的禁令不再适用；需 owner 明确写下这一点。

## C2. 保留禁令，改换**监督源**：用序列位置/时间间隔代替行为对比

- **依据**：本轮所有"结构 → 曲率 → 选码"的允许类都 ≤ +0.3%；未见任何非成对信号越线。序列顺序（同一用户的历史先后）是**非成对**的标量监督（如相邻项的秩相关），与已测穿的几何路径不同族。
- **要求**：需 owner 确认"序列顺序监督"不属禁令范围；机制为逐商品的序列位置回归或秩损失，作用于编码器（单 block），**可绕开 #187 的块预算冲突**。
- **代价**：一次 3000 epoch + 一次 Stage3；**预期**不确定——但它是目前唯一未被测量过的非成对信号族。

## C3. 收束本线，B 结案

- 即 #189 的 B 选项：允许类最好 +0.3%，最强允许类损失 −0.8%，成对族才是唯一越线路径；归档并转投其它方向。
