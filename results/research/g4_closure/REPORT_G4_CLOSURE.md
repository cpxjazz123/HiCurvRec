# Issue #216 — 四环闭合 vs 度分叉：四臂 Stage2 对照（单次冻结预算）

**问题**：在**完全相同的精确度数三元组**下，闭合结构（四环 `b-a-c-d`，`t(a,b)=t(a,c)=0` 且
`(b,c)` 是边）与度分叉（`t(a,b)=t(a,c)=0` 且 `(b,c)` 非边）能否靠商品对的表征区分？
边级共现（A）、冻结对级 InfoNCE（B）、闭合级加性头（C）、闭合级显式交互头（D）
哪一种监督能把这种区分写进 SID 前缀？

**一句话结论**：**四种监督都没有把闭合/分叉的区分写进表征或 SID 前缀。**
边缘/对级监督（A/B）保住了冻结基线的前缀结构（L1 lift 2.72/2.65 vs 2.62），但增量信息为零；
闭合级监督（C/D）只买到码字唯一性（碰撞率 0.169 → 0.010–0.014），同时把前缀结构打塌
（L1 lift 1.35/1.37，`P(L2|L1)` 正类反而低于负类）。issue 的 H1（C>B）与 H2（D>C）**均被拒绝**。

## 2. 四臂（同一棵基线树，只换进入损失的那一项）

| 臂 | 监督 | 进入 SID 的通路 | λ（梯度范数比标定） | 训练墙钟 | 最终碰撞率 |
|---|---|---|---|---|---|
| A Edge | 普通边 InfoNCE，度数匹配负边 | 编码器表征 | 3.56e-07 | 567 s | 0.1240 |
| B Context-Pair | 同池 `(b,c)` 对排序 InfoNCE | 编码器表征 | 1.19e-06 | 525 s | 0.1229 |
| C Context-Add | 三元分类头，**仅节点项聚合** | 编码器 → STE → 码字 | 5.20e-03 | 552 s | **0.0136** |
| D Context-Interact | 同容量 + **显式成对交互** | 同上 | 5.17e-03 | 542 s | **0.0100** |
| — 冻结基线 | 无辅助项（E32） | — | — | — | 0.1693 |

λ 用**梯度范数比**标定：第 20 步时取编码器侧 `‖∇aux‖` 的中位数，令 `λ‖∇aux‖ = 0.1‖∇rq‖`；
不是试值。四臂均 3000 epoch、seed 42、4 卡、全局 batch 4096、无早停、单次运行。

| arm | L1 gap [95% CI] | L1 正/负共享率 | L1+L2 gap | `P(L2\|L1)` 正/负 | L2 前缀数 | 三级碰撞率 |
|---|---|---|---|---|---|---|
| A Edge | **+0.0338** [+0.029, +0.039] | 0.0534 / 0.0197 | +0.0045 | **0.097 / 0.034** | 8860 | 0.1240 |
| B Context-Pair | +0.0325 [+0.028, +0.037] | 0.0523 / 0.0197 | +0.0019 | 0.058 / 0.057 | 9187 | 0.1229 |
| C Context-Add | +0.0022 [−0.000, +0.004] | 0.0083 / 0.0061 | −0.0001 | 0.011 / 0.031 | 14873 | 0.0136 |
| D Context-Interact | +0.0024 [+0.000, +0.005] | 0.0089 / 0.0065 | +0.0001 | 0.011 / 0.000 | 16660 | 0.0100 |

`lift = P(share|1)/P(share|0)` 与 `P(L2|L1)`（后者对绝对共享率不敏感）。

## 4. 表征探针（`analysis_sid_recall/probe_closure_signal.py` → `probe.json`）

| arm | cos(z_b,z_c) AUC | ridge 探针 AUC（`\|z_b−z_c\| ⊕ z_b·z_c`） |
|---|---|---|
| A Edge | 0.5477 | 0.5795 |
| B Context-Pair | 0.5527 | 0.5858 |
| C Context-Add | 0.5157 | 0.5669 |
| D Context-Interact | 0.5442 | 0.5759 |
| 冻结基线 E32 | **0.5790** | 0.5780 |

ridge 探针在 **train 池**拟合、**heldout 池**评估。四臂都在 0.57–0.59，
即"比随机高 7–9 个点"，且没有任何一臂把该值推高到基线之上。
C 的 cos-AUC 最低（0.5157）而它的碰撞率最低（0.0136）——**唯一性与结构是两码事**。

## 5. 结论

1. **H1（C > B，闭合级加性头提升前缀增益）拒绝**：C 的 L1 gap 0.0022，B 是 0.0325，
   C 的 95% CI 上界 0.004 远低于 B 的点估计；条件项 `P(L2|L1)` 在 C 上正类（0.011）
   甚至低于负类（0.031）。
2. **H2（D > C，显式交互优于加性）拒绝**：D 与 C 在 L1 gap（0.0024 vs 0.0022）、
   条件项（0.011/0.000 vs 0.011/0.031）、碰撞率（0.0100 vs 0.0136）上都在同一量级，
   差异不构成一个机制结论。
3. **闭合级监督的真实作用是把码字用光**：碰撞率 0.1693 → 0.0100/0.0136（约 12–17 倍），
   L2 前缀数 7374 → 16660/14873。代价是**商品对几乎不再共享前缀**（L1 正类共享率
   0.0665 → 0.0083/0.0089），闭合结构因此没有载体。
4. **表征层面也没有出现区分**：ridge 探针最高 0.586（B），基线 0.578，即信息量本身
   就没有被这四种监督拉起来。这排除了"信号在表征里、只是被量化器丢掉"的乐观解释——
   编码器自己就没学到。
5. **唯一保留条件结构的是 A（边级）**：`P(L2|L1)` 正 0.097 vs 负 0.034（条件 lift 2.9），
   是全部臂里唯一有条件增益的；但它在 L1 gap 上仍低于冻结基线（0.0338 vs 0.0411）。

**可复现的负结果**：在该容量（512-256-128 → 32 维）与 3000 epoch 冻结预算下，
闭合级监督无法把闭合/分叉结构写进 SID；把码字用光是它唯一可测量的效应。

## 6. 局限（明确记录，不掩饰）

- 单种子单次运行（§19g），无可消融、无多种子；噪声按 issue 记入不确定性。
- 分类头权重未随 checkpoint 保存，因此"头在训练集上是否解出任务"只能由 `aux` 损失
  （末值 0.53/0.58）间接反映，无法在 heldout 上复核。
- gap 与碰撞率耦合：C/D 的 gap 塌缩部分来自"码字几乎唯一"，第 3 节的 lift/条件项
  就是为抵消这一耦合而并列的。
- 臂族内部可比（同架构同预算），基线行（E32、无辅助项）只作背景参照，
  不能当作"几何 + 监督"的干净对照。

## 8. 本轮修掉的工程缺陷（均有树内测试 `tests/test_g4_closure.py`，8/8 通过）

| 缺陷 | 症状 | 修法 |
|---|---|---|
| 度数桶内拒绝采样 | 桶是稠密团，99% 抽样被拒，某步 `filled=0` → `aux=NaN` 直接崩 | 预建邻接集 + 逐行降价，填充率稳定 512/512 |
| τ 用 `max(gap, 1e-3)` | 梯度恒 0 时 gap=0 → logits ±1000，aux 损失 21、λ 被压到 3e-9 | τ = `max(median gap, std, 1e-3)` |
| 标定期在 DDP loss 上 `autograd.grad` | 提前触发 reducer hook，梯度污染，epoch 6 起 NaN | 标定改用本地（非 DDP）前向 |
| 分类头在标定期无梯度 | DDP 报未使用参数 | aux 以 0 系数进入损失图，头始终在图中 |

| arm | L1 码使用 | 最大桶 | 真实边 L1 | 匹配非边 L1 | 边/非边比 | 真实边 L1+L2 | 三角形 L1 |
|---|---|---|---|---|---|---|---|
| A Edge | 256/256 | 496 | 0.0660 | 0.0365 | **1.81** | 0.0070 | 0.0630 |
| B Context-Pair | 256/256 | 578 | 0.0645 | 0.0360 | 1.79 | 0.0066 | 0.0596 |
| C Context-Add | 256/256 | 336 | 0.0090 | 0.0072 | 1.25 | 0.0004 | 0.0109 |
| D Context-Interact | 256/256 | 255 | 0.0092 | 0.0077 | **1.19** | 0.0003 | 0.0131 |

C/D 的真实边保留率是基线的 1/9（0.009 vs 0.081），三角形保留率同样掉到 1/7，

这正是 issue 要求"若结构增益以真边保留退化为代价就诚实记录"的那种情形。

## 11. 对 issue 四个问题的直接回答

1. **同三节点边模式、同度数、同 AF3 时,四环上下文是否构成可学习目标?**
   在本容量与预算下 **没有构成**：四臂编码器表示对闭合/分叉最多的可解码度也只有
   ridge AUC 0.586(基线 0.578),即比随机高 7–9 个点,且无任何臂把它推高;玩具图层面
   两类当然可分(标签完全由结构决定),但真实图上该信号没有进入表征。
2. **该目标能否提高离散 SID 的真实结构保真?** **不能。** C/D 的 L1 结构增益 0.0022/0.0024,
   真实边 L1 保留 0.0090/0.0092(基线 0.0811),三角形保真 0.0109/0.0131(基线 0.0791)。
3. **这种提高是否超出同标签的 pairwise InfoNCE?** 没有提高可言;B(无头、纯 pairwise)
   在 L1 增益(0.0325 vs 0.0022)、真实边保留(0.0645 vs 0.0090)上都远好于 C/D。
4. **是否牺牲碰撞率与真边关系?** 是。C/D 把碰撞率从 0.1693 压到 0.0136/0.0100,
   代价是真实边保留率与三角形保真同时降到基线的 1/9 和 1/7。

**最终判定**：按 issue 预设的停止条件——"若 D 与 B 持平、或结构增益以 SID collision/真边保留
退化为代价,应诚实记录**没有证明高阶联合目标必要**,停止本机制"——本轮记录为
**未证明四节点闭合监督必要**,不追加 AF3/曲率找补,不启动 Stage3。
