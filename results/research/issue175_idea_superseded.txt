Idea：Collision-Triggered Latent Repulsion（DUL，HiD-VAE 的 Uniqueness Loss 独立复现）
英文名称：DUL — Collision-Triggered Latent Repulsion (faithful replication, Euclidean)

owner 2026-11-11 指令：停止继续调码容量分配（#168–#174 的双容量/行优先/增广/软容量路线），
改为把 HiD-VAE 的 **Uniqueness Loss** 作为独立方向先做**原始形式复现**，确认在 RQ-VAE 上是否有效，

## 一、主张（一句话）

不改变码字分配规则、不加任何容量约束：只给 **三级 SID 完全相同、但商品身份不同** 的样本对加一个
余弦边际惩罚 `L_unique = mean max(0, cos(z_i,z_j) − m)`，让这些商品在连续表示上被推开，从而在**下一次量化**
时自然落到不同 SID；训练目标 `L = L_RQ + β_unique·L_unique`，编码器收到梯度，码本/残差/读出不变。

## 二、已核实的基线（决定"是否有效"的对照组，无需新训练）

验收只能在 Stage3 判定，不能拿 2.1% 当门。

## 三、公式与常量（全部来自论文，不做调参）

```
L_unique = (1/|P|) · Σ_(i,j)∈P max(0, cos(z_i, z_j) − m)
L        = L_RQ + β_unique · L_unique
P        = { (i,j) : i≠j, 同一训练 batch 内, 三级码序列 y_i = y_j }
```

- `z_i` = 编码器输出（**量化前**的连续表示，论文的 z_0）；`y_i` = 三级量化码序列（**不求导**的选择步骤）。
- `β_unique = 2.0`、`m = 0.9`（论文 §4.1 与 Table/超参段：β_commit=0.25、β_sup=1.0、β_unique=2.0、m=0.9）。
- **方向性警告（必须写进代码注释与报告）**：按公式 `max(0, cos−m)`，`m` **越大越宽松**（cos≤m 即零损失），
  与论文正文"m 越大越严格"的措辞相反；论文 m 扫描 `{0.3,0.5,0.7,0.9,1.0}` 取 0.9 最优，而 m=1.0 在公式下恒为零损失。
  本臂**照公式实现**并记录该矛盾，不据此调 m。
- 行为关/几何关/双开三开关（§19g 要求存在且接线正确，**不训练任何关闭臂**）：
  `UNIQUE_OFF`（β_unique=0，等价基线损失）、`PAIR_SOURCE_OFF`（P 换成随机商品对，检验"碰撞触发"是否必要）、`BOTH_ON`（出厂）。

## 四、实现要点

1. 起点：冻结基线 `stage2_RQ-VAE/TIGER_mixed_rq`（只读，逐文件 SHA 记 manifest），新树 `stage2_RQ-VAE/TIGER_dul_rq`。
2. **量化/残差/读出/导出全部不变**；只新增：三级码序列计算（已有）、`P` 的选择（detach）、余弦惩罚回传编码器。
3. 每 batch 统计并记录：`|P|`、`cos>m` 的对数占比、`L_unique` 值 → **若长期无对或全部 cos≤m，说明该机制在本数据上惰性，必须如实报告，不得调 m/β**。
4. 跨 batch 碰撞（论文只在本 batch 内找对）**本臂按原文不处理**，但在每次评估时用**全量导出**测量真实完整碰撞率并记录；
   跨 batch 的滚动缓存/周期全量检测作为**后续 Issue**，不在本臂实现。
5. 训练目标仍只有 `L_RQ + β_unique·L_unique`；不引入层级监督、不加容量约束、不改分配规则。
6. 身份：`ARM_NAME="TIGER_dul_rq"`、`ARM_VARIANT="DUL"`、`OUTER_LOOP=False`、`AUX_AF3=False`、`CURVATURE=1.0`；
   树内无绝对路径；`/tmp` 不落产物；checkpoint 绑结构表/常量 SHA。

## 六、验收（派发前，全部可测，全部只判结构正确性）

1. **对集合正确**：单元测试构造同 batch 碰撞对，断言 `P` 恰为"三级码全同且商品不同"的对；含零碰撞 batch（`|P|=0`）不报错、不产生 NaN。
2. **梯度只走连续表示**：`z` 上反向必须到达编码器参数；码本索引（argmin）路径不接收梯度；`UNIQUE_OFF` 与基线损失逐位一致。
3. **开关接线**：`UNIQUE_OFF` / `PAIR_SOURCE_OFF` / `BOTH_ON` 三态行为可区分（廉价检查，不训练）。
4. **一 epoch 真实入口冒烟**：损失有限、`|P|`/`cos>m` 占比有记录、导出 SID 技术有效。
5. **导出与统计**：全量 24587 导出，报告完整三级碰撞率，与基线 **0.162444** 并列；码使用量/份额/二级前缀一并报告。
6. **§89 入场**：`collision < 0.40` 才允许 Stage3（基线已满足；本臂只看是否被破坏）。
7. **TDD**：先写会失败的测试（对集合、梯度通路、开关、零碰撞退化），确认红后再实现；测试与源码 SHA 一起入 commit。
8. 1–5 任一不过：按预派发负结果记录并停止，不改 m/β/码本/ε。
