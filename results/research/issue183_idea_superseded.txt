Idea：R48κE——把逐商品曲率作用在**编码器表示**上（指数映射），而不是只改距离调用点
英文名称：R48κE — Curvature Applied to the Representation (Exponential Map), Not to Distance Call Sites

## 一、证据：改“距离调用点”已经打满，改“表示”从未试过

| 臂 | 曲率作用位置 | `test_recall@10` |
|---|---|---|
| 冻结基线 | — | 0.056216 |
| `TIGER_BEHAVIOR_R48` | 无曲率 | 0.063110 |
| `TIGER_r48k1_rq`（#182） | 对比**第 1 层距离** | 0.064660 |
| `TIGER_r48k2_rq`（#179） | 对比**三层距离** | **0.064764** |
| `TIGER_r48k2u_rq`（#180） | 对比距离 + 选码代价 | 0.063685 |
| `TIGER_hc3_rq`（#177） | 选码三层前缀曲率 | 0.054023 |
| `TIGER_struct_mixed_rq` | 选码仅第 1 层 | 0.057905 |

三条读数：

1. **对比侧的曲率有效**（+2.5% 对 R48），但**层位置无关**：#182 与 #179 只差 0.0001（噪声量级）。
2. 把同一份曲率再接到**选码**代价上会掉分（#180 −1.7%），三层选码曲率更差（#177）。
3. 迄今所有变体都只是**在若干调用点把欧氏距离换成 `d_κ`**；**从未把曲率施加到表示本身**——即先做 `z → exp_0^κ(z)`，再让量化、分配、对比全部在曲线空间里进行。

这就是本臂：一处映射，处处受益，且**不再新增调用点**。

## 二、主张（一句话）

保留 R48 的全部结构（三级残差对比、τ=0.07、权重 0→0.20、Sinkhorn、码本、预算），
但把编码器输出 `z_i` 先用**该商品实测曲率 `κ_i` 的指数映射**投进 Poincaré 球，量化的输入变成 `z'_i`；
于是对比、分配、选码**共享同一份曲线几何**，而 `d_κ`/`τ`/权重这些常数不变。

## 三、公式（唯一改动）

```
κ_i         = 冻结 AF3 表 results/research/issue167/kappa.json（均值 1.0、中位 0.9147、max 8.2671；
              缺失 31 项按 mean_frozen；κ<1e-3 取 1.0 并计数）
z'_i        = exp_0^{κ_i}(z_i) = tanh(√κ_i‖z_i‖)/(√κ_i‖z_i‖) · z_i      # 零向量取极限 1，保证 κ_i‖z'_i‖²<1
量化/残差/对比/分配全部作用在 z'_i 上；距离用
d_κ(p,q)    = (2/√κ)·asinh( √κ‖p−q‖_ε / √((1−κ‖p‖²)(1−κ‖q‖²)) )
              ‖p−q‖_ε = sqrt(‖p−q‖² + ε_pq), ε_pq = finfo(dtype).eps·max(‖p‖²,‖q‖²,1)
```

- **不变**：R48 的三级残差对比配对/过滤/mask、τ=0.07、权重曲线、Sinkhorn（ε=0.003、50 sweeps、centring）、码本 K=256、3000 epoch、seed 42、全局 batch 4096。
- 无新增可调常数：曲率来自实测表，映射是指数映射的闭式，`τ` 与权重沿用 R48。
- 与 #179/#182 的区别必须写清：**它们只把距离换了，表示仍是欧氏点；本臂的表示本身在曲率球内**（量化器看到的坐标不同）。

## 四、开关（存在且接线正确，不训练关闭臂）

- `GEOMETRY_OFF`：`z' = z`（恒等）且距离用欧氏 → **必须与 R48 的行为损失逐位一致**。
- `EMBED_ONLY`：只在表示上做指数映射，距离仍欧氏 → 检验"表示"与"度量"各自的贡献（廉价接线检查，不训练）。
- `BOTH_ON`：映射 + `d_κ`（出厂）。

## 五、验收（派发前，全部可测）

1. **`GEOMETRY_OFF` 逐位一致**：与 R48 损失一致（同 batch 同 seed）。
2. **映射性质**：`exp_0^κ` 严格落在球内（`κ‖z'‖²<1`）、单调、`z=0` 取极限 1、逆映射 `log_0^κ` 往返（rtol 1e-6）。
3. **`d_κ` 性质**：κ=1 与冻结 `poincare_contract.distance` 一致；`p=q` 与 `‖p−q‖∈{1e-12,1e-9,1e-6,1e-3}` 梯度有限、gradcheck（双精度）通过；对称、零距离、抽样三角不等式。
4. **几何一致性**：量化器输入、Sinkhorn 代价、对比距离三处使用**同一** `κ` 表与同一映射（用一次断言把三处绑在一起）。
5. **一 epoch 真实入口冒烟**：`applied_grad_norms` 全有限非零、代价与 logits 非恒定、Sinkhorn 不报错、导出 SID 有效。
6. **导出统计**：全量 24587，逐层码数/最大份额（≤10%）、二级前缀、三级碰撞（并列 0.162444）、§63 `l3_collision`；`collision < 0.40`。
7. **TDD**：先写会失败的测试（映射球内与往返、`d_κ` 边界梯度、`GEOMETRY_OFF` 逐位一致、三处同一个 κ 的绑定断言），确认红后再实现。
8. 1–6 任一不过：按预派发负结果记录并停止，不改 τ/权重/预算/码本。

## 六、边界与不变项

- 起点：`stage2_RQ-VAE/TIGER_BEHAVIOR_R48`（只读，逐文件 SHA 记 manifest）→ 新树 `stage2_RQ-VAE/TIGER_r48ke_rq`（`ARM_NAME="TIGER_r48ke_rq"`、`ARM_VARIANT="R48KE"`）。
- 不引入唯一性损失、容量规则、蒸馏项；不做层位置扫描（已由 #182 判明无关）；树内无绝对路径；`/tmp` 不落产物；checkpoint 绑 κ 表 SHA。
- 一个候选只跑一次正式训练（§19g）：seed 42、3000 epoch、全局 batch 4096、四卡 50202。
- §19 耦合：行为图（AF3 闭合 → κ_i）→ 表示上的显式双曲映射 → 量化与分配 → 选码 → SID，同一条连通通路。
- 判据唯一：`test_R@10`；参照冻结基线 **0.05622**、R48 **0.06311**、#179 **0.064764**、#182 **0.064660**、成功线 **0.065**。
