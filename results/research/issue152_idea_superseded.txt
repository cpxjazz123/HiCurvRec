Idea：冻结配额的结构先验，只在能实现边际的层级施加
英文名称：Frozen-Bucket Structure Prior on the Balanced Assignment (corrected from #150)

这一版是对 #150 那条路线的修正定义，不是新方向。#150 已经在真实训练里证伪了它自己的初版：
目标每 epoch 按当前用量重排（目标追着实现跑）、把列边际目标压在只有 argmin 的一、二层
（迫使编码器扭几何）、没有独立曝光护栏，结果末轮一级只剩 58/256 个码、单码 58.7%、
三码碰撞 0.68215，Stage3 被 §89 拒绝。

修正后的主张只剩一句：**让结构层的商品占比决定末级码本各桶的容量份额，配额在整个 run
内冻结，并且这个份额必须能被末级的均衡分配真正实现。**

二、具体设计

第一步：结构分层（与 #150 相同，仅 TRAIN 图）
按三角参与度 τ 的阈值切分，得到 G = 4 层（τ=0 / (0,1/3] / (1/3,2/3] / (2/3,1]），
层内商品占比 ρ_g 由训练集给出并冻结（#150 实测 ρ = [0.2408, 0.2510, 0.3772, 0.1310]，
表 SHA ca4f07f8…）。

第二步：桶划分**整轮冻结**（这是与 #150 的关键差异）
桶成员在训练开始前定一次，之后不再改动：
- 首选：用码本初始化后的**初始潜空间**做亲和度——对每层取该层商品的初始 encoder 输出均值
  作为层心，码 k 归到最近的层心，得到一个 G 个等量桶的划分（层心与划分写盘、记 SHA-256）；
- 备选（层心退化时）：按码索引等分（`equal_partition`），同样冻结。
两种都必须在训练前确定并记录选用哪一种；**禁止**再用 `usage_running` 重新排序
（#150 的 `set_marginal(usage_partition(usage))` 每 epoch 重排就是失效根因）。

第三步：目标列边际只作用于末级
$$\pi_k=\frac{\rho_{g(k)}}{|B_{g(k)}|}\qquad(\text{仅在末级 Sinkhorn 上})$$

末级仍是基线的均衡分配：同一 `center_distance`、同一 `SK_EPSILON = 0.003`、同一迭代数，
只把列目标从 `1/K` 换成 `π`。一、二层保持基线 `argmin`，**不施加**任何 usage/KL 约束
——它们没有均衡分配，"把使用分布推向非均匀目标"只能靠扭曲几何来实现，这正是 #150 塌掉的地方。

第四步：损失
$$\mathcal L=\mathcal L_{\mathrm{RQ}}+\lambda_{\mathrm{tri}}\mathcal L_{\mathrm{tri}}+\lambda_{\mathrm{prior}}\mathcal L_{\mathrm{prior}}$$

- `L_tri`：batch 内三角形三条边的前缀重叠补，`[0,1]`；
- `L_prior`：**只**对末级计划算 `KL(q̄ ‖ π)`，`q̄` 为该级传输计划的列质量均值；`[0,1]`；
- `λ` 全取 1（两项都按定义归一化到 `[0,1]`）。
`L_fork` 从设计里移除：它在 #150 里全程为 0（定义内已满足），留着只是噪声。

第五步：派发前的可实现性证明（新硬门槛）
在冻结 batch 上，末级计划的实现列质量与 `π` 的相对误差必须 **≤ 5%**；同时逐层记录
`codes_used`、`max_bucket_share`、归一化熵。做不到就说明机制没有实现自己的主张，不派发。
（#150 实测实现/目标比 1.44 / 1.07 / 0.75 / 0.76，正是"没有实现"的样子。）

第六步：训练中的曝光护栏
每个评估 epoch 检查逐层 `codes_used ≥ 128` 且 `max_bucket_share ≤ 10%`；越界即记 FAIL 并
停止，而不是跑满 3000 epoch 再在报告里发现。

三、与 #150 的差异（必须逐条写进规格）

| 项 | #150（失效） | 本臂（修正） |
|---|---|---|
| 桶划分 | 每 epoch 按当前 usage 重排 | **冻结**（初始潜空间亲和度或等分，记 SHA） |
| 边际施加层级 | 三层（KL 平均） | **仅末级** |
| 一、二层约束 | KL 推向非均匀目标 | **无**（基线 argmin 原样） |
| 失效检测 | 事后报告 | 训练中护栏 + 派发前可实现性门槛 |
| 分叉项 | 有（恒 0） | 移除 |

四、边界与不变项

- 不动代价函数、残差递推、读出、导出、三 token 结构；不动 Sinkhorn 的 ε 与迭代数；
  不用 `argmin` 取代均衡分配（§19h）。
- 3000 epoch、全局 batch 4096、seed 42 冻结；单次正式训练，不做消融/调参/多种子（§19g）。
- 结构信号只来自训练划分；商品级 SID 全局一致。
- 风险：ρ 的 2.88× 跨度意味着桶间每码目标质量差 2.88 倍，桶内等量不改变这一点。若护栏
  在早期触发，按负结果记录，不改 ρ、不改 G 重跑。

## 结构先验边际路线的修正定义（来自 #150 根因分析，供下一臂开局）

1. 桶划分冻结：只由训练集统计（τ，或未训练前向一次的码-结构层亲和度）决定一次，写盘记 SHA-256；
   禁止用 run 自身 usage 重排，set_marginal 不再每 epoch 改 partition。
2. 边际只作用于末级 Sinkhorn；一、二层保持基线 argmin，不加 usage/KL 约束（要改须单独立项批准）。
3. 曝光护栏：每个评估 epoch 检查逐层 codes_used / max_bucket_share / 归一化熵；
   max_bucket_share > 10% 或 codes_used < 128 判机制失效并按 FAIL 停止。
4. 先证明边际可实现：冻结 batch 上目标层实现列质量对 π 的相对误差 ≤ 5%，否则不派发。
5. 逐层记录 L_prior 的 KL 与 target-vs-realized 比值，不得只记平均。
6. 新 Issue 以本条开局，并与 #150 的差异（冻结桶 + 只在末级施加 + 曝光护栏）写清楚。
