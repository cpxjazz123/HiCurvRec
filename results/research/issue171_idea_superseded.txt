Idea：双容量指派改为**行优先**（每行先要自己最想要的码），把偏好保真度做上 0.9（修正 #170）
英文名称：Row-Major Two-Sided Assignment (corrected from #170)

#170 把结构做满、把保真度做漏，原因写得很干脆：

| 观测（未训练全量导出，`TIGER_two_sided_final_rq`） | 数值 |
|---|---|
| 入口碰撞 | **0.012324** |
| 二级不同前缀 | **23651**（≥ 0.9·B） |
| 逐层占用 | 每层 256/256 码，最大份额 0.3945 / 0.5490 / 0.3945 % |
| 导出耗时 | 9.59 s（≤60 s） |
| **偏好保真度** | **30.6%**（22547 / 73761 次行级指派），门 0.9 |

成因不是偶然：**码优先**贪心按计划总质量逐个码走，先到先得，后来的行被推到它们并不偏好的码上。
修法是换遍历方向而不是放松门：**行优先**——每行先要它自己最偏好的码，平手按计划质量，双容量仍然强制。

## 一、主张（一句话）

指派改为行优先贪心：按 `plan_i·` 降序逐行请求码（首选 → 次选 → …），只在该码仍有**全局 `q_k` 与父子容量 `r_g`**
时才接受；全部被拒的行再按剩余容量内最小代价补齐。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **逐商品曲率（沿用 #167）**：`κ_i = (1 − u_i)/mean_frozen(1 − u)`，均值 1。
3. **两重配额（沿用 #168/#170）**：`q_k = ⌊B/K⌋`（余数按码索引）+ `r_g = ⌈n_g/K⌉`，`relaxations` 须为 0。
4. **指派（本臂唯一改动）**：行优先（见上）；导出按块执行、块间容量独立（如实报告）。
5. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003`/`50 sweeps`/centring、残差递推、读出、导出、三 token 结构；
   训练目标仍只有 `L_RQ`；开关 `ROUNDING_OFF`/`GEOMETRY_OFF`/`BOTH_ON` 语义不变。
6. **身份**：`ARM_NAME="TIGER_two_sided_rowmajor_rq"`、`ARM_VARIANT="2SROW"`、`OUTER_LOOP=False`、
   `AUX_AF3=False`、`CURVATURE=1.0`；树内无绝对路径；`/tmp` 不落产物；checkpoint 绑结构表 SHA 与 κ 表 SHA。

## 三、验收（派发前，全量导出 + 冻结探针 + 200 步试点，全部可测）

1. **偏好保真度 ≥ 0.9**（本臂核心门；#170 实测同构造为 0.306，须给出提升后的数值与逐层分解）。
2. **三条结构目标同时成立**（#170 已达成，须复测）：入口碰撞 ≤ 0.05、二级前缀 ≥ 0.9·B、逐层 256 码且份额 ≤ 1.5×均匀。
3. **双容量恒等式**：每父前缀每码 ≤ `r_g`、每码总数 ≤ `q_k`、放宽次数 = 0。
4. **时间**：全量导出 ≤ 60 s；rank-batch 指派 ≤ 0.15 s。
5. **200 步试点**：逐层 `codes_used ≥ 240/256`、`max_bucket_share ≤ 5%`、平均前缀距离 ≥ 0.5× 初值。
6. **训练中双侧护栏**：每个评估 epoch 同时检查逐层占用与全局码使用，越界即 FAIL 停止。
7. **接线与一致**：`ROUNDING_OFF` 同模型内逐位一致（含导出）；训练/导出三级一致率 1.0；checkpoint 绑定。
8. **TDD**：先写会失败的测试（行优先遍历顺序、双容量恒等式、保真度定义、`ROUNDING_OFF` 恒等、`c=0` 极限、
   训练/导出同码），确认红后再实现。
9. 任一门不过：按预派发负结果记录并停止，不改容量规则/κ/λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 双容量指派）；Sinkhorn 本体不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：行优先会让"每个码收到谁"更贴计划，但可能抬高总代价；总代价只作诊断，最终由 Stage3 裁决。

## 五、与 #170 的差异（必须逐条写进规格）

| 项 | #170 | 本臂 |
|---|---|---|
| 遍历方向 | 码优先（总质量排序，先到先得） | **行优先**（每行先要首选码） |
| 偏好保真度 | 0.306 | 目标 ≥0.9 |
| 配额 / 容量规则 | 不变 | 不变 |
| 结构三门 | 全过 | 须复测，仍须全过 |
