# B1：真实行为边对比监督的 Stage2 结果

日期：2026-11-18  
范围：**仅 Stage2**；未运行 Stage3，未启动 B2/B3/B4。

## 1. 实验定义

`TIGER_behavior_edge_contrastive_rq` 从冻结的 `baseline/TIGER_RQ-VAE` 复制，只修改 `ARM_NAME` 与机制：

- 训练行为边：`fit=252,313`，`holdout=63,078`（80/20 切分）；
- 正样本：无向边的两个方向；
- 负样本：同度数分层、语义相似度接近正样本的 4 个非邻接商品；
- 损失：对称 InfoNCE，温度 `0.07`，作用于 straight-through 量化后的 32 维表示；
- 结构权重：首步实际 encoder 梯度比例定为 5%，得到固定 `2.965238e-06`；没有扫参；
- 3000 epoch、全局 batch 4096、seed 42、无 early stop；
- 结构边留出集从未进入损失、度数分层或负样本池。

## 2. 结果

### 2.1 留出行为边（主要判据）

| 方法 | held-out q 恢复率 | fit q 恢复率 | 全部 q 恢复率 |
|---|---:|---:|---:|
| B0 严格无 KL 对照 | **1.1732%** | 1.1196% | 1.1303% |
| B1 行为边对比 | **1.0114%** | 0.9567% | 0.9677% |

B1 在真正未见过的行为边上比 B0 **低 0.1618 个百分点**（相对约 −13.8%）。训练 fit 边没有比 held-out 更好，说明不是简单的“记住了训练边”，而是监督目标与可导出的 SID 结构没有形成有效对应。

### 2.2 全量 Experiment-0 指标

| 指标 | B0 对照 | B1 |
|---|---:|---:|
| q 行为边恢复率 | 1.1271% | **0.9602%** |
| z 行为边恢复率 | 1.6988% | 1.6723% |
| x_hat 行为边恢复率 | 1.1162% | 0.9836% |
| x → z 条件保留 | 66.288% | 63.449% |
| x → z → q 条件保留 | 28.477% | **22.280%** |
| z → q（给定 x→z） | 42.960% | 35.115% |
| q → x_hat（给定 x→z→q） | 87.601% | 84.558% |
| q 唯一向量 | 20,084 | **16,171** |
| q K=10 并列率 | 24.63% | **44.75%** |

### 2.3 码本与分层指标

| 指标 | B0 对照 | B1 |
|---|---:|---:|
| L1 已用码字 | 244 | **48** |
| L2 已用码字 | 256 | 256 |
| L3 已用码字 | 256 | 256 |
| L2 不同前缀 | 8,199 | **2,971** |
| L3 distinct triples | 20,084 | 16,171 |
| L3 distinct collision | 18.31% | **48.13%** |
| valid L1 Hard ER | 6.756 | **3.498** |
| technically_valid_sid | true | **false** |

B1 的 SID 在 `stage2_metrics` 中被判定为 **技术无效**，因此即使不把 Stage3 作为本轮目标，也不能把这一 SID 当作可比的 Stage3 输入。

## 3. 导出一致性说明

`b1_vectors_meta.tokens_match_export=false`：checkpoint 在 CPU 上重新编码时有 **139 / 24,587** 个 token 与导出 SID 不同。抽样检查显示，差异集中在距离极接近的 argmin 边界（部分差约 1e-6），属于 GPU 导出与 CPU 重编码的数值 tie 差异。B1 的 q 指标与 `stage2_metrics` 都使用**已导出的 `item_sids.json` 的码本求和**，不是重新编码的 token；因此行为边评估对应的是实际导出 SID。该不一致仍应记录，不应把 B1 称为“checkpoint-bound 完全一致”。

## 4. 结论

1. **B1 没有支持“真实行为边对比监督有效”**：held-out、fit、全量 q 恢复都低于 B0。
2. 结构监督不是简单没起作用，而是伴随 **L2 前缀坍缩（2,971 vs 8,199）** 与 **L3 碰撞上升（48.13% vs 18.31%）**；实际导出 SID 的技术有效性被破坏。
3. 这不支持继续跑 B2/B3/B4。混合曲率或 Graphlet 选择性监督只有在 B1 先显示出可控的结构收益时才有解释价值；当前结果下继续加几何只会增加不可识别的因子。
4. 下一步应重新设计**结构目标与量化通路的耦合方式**，而不是增加实验臂；本轮不启动 Stage3，也不把 B1 作为成功机制。
