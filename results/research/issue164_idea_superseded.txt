Idea：条件配额的指派按**机制自身成本**计量，并把小组合批（修正 #163 的时间门）
英文名称：Conditional Quotas with Batched Small-Group Assignment (corrected from #163)

#163 把碰撞稳在极限、把导出从 13.33 s 压到 3.68 s，同时推翻了我在 Issue 里写的成本归因：

| 观测（未训练、全量导出 24587） | 数值 |
|---|---|
| 入口碰撞 | **0.000000**（24587 个不同三元组） |
| 二级不同前缀 | **24587**（= 商品数）、逐层 256 码（0.394% / 0.781% / 0.492%） |
| 导出总耗时 | 13.33 s → **3.68 s** |
| 其中：第三层指派（逐组调用） | **10.47 s → 0.05 s**（单行父组快路径后） |
| 其中：三层 Sinkhorn 计划 | ≈0.95 s（**冻结，不可动**） |
| 其中：一/二层指派 | 0.22 s + 0.72 s（第二层 256 组 × 每码一次 `topk`） |
| 其中：编码器前向 | ≈1.0–1.5 s（导出必付） |

结论：2 s 门把"编码器前向 + 冻结计划 + 指派"混在一起算，是**门的口径错了**；机制真正拥有的是**指派**，
它与基线导出共享前向与计划。修法两条：① 计时门改为"指派自身 ≤ 0.5 s"与"总耗时 ≤ 1.5 × 同机基线导出"；
② 第二层也做小组合批（现在 256 组逐组 `topk`），把指派压到 0.3 s 量级。

## 一、主张（一句话）

配额与指派规则完全沿用 #163（条件配额 + 向量化贪心，碰撞按构造成立），只把**小组合批**补齐、
并把计时门改成机制自身的口径；补完 #162/#163 遗留的 `ROUNDING_OFF` 接线、rank-batch 计时、两臂拟合与训练护栏。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157 起，不改）**：`ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **条件配额（沿用 #163，不改）**：第 1 层均匀；第 2 层在每个一级组内均分；第 3 层在每个二级前缀内均分。
4. **指派（本臂唯一改动）**：保留向量化贪心；把第 2 层的逐组 `topk` 改成**把同规模小组合并成一次批量运算**
   （按组行数分桶、桶内 `scatter` 一次完成），第 3 层沿用单行快路径。
5. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003` / `50 sweeps` / centring、残差递推、读出、导出、
   三 token 结构；配额规则、父前缀分组不变。
6. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，逐位一致；**必须真正接到模块常量**）、
   `GEOMETRY_OFF`（`c=0`）、`BOTH_ON`（出厂）。

## 三、验收（派发前，全量导出 + 冻结探针，全部可测）

1. **入口碰撞 ≤ 0.05**：未训练全量导出的 `1 − 不同三元组/商品数`；训练后同规则再测。
2. **指派成本 ≤ 0.5 s**（三层合计，全量导出；机制自身口径），并单列各层。
3. **总耗时 ≤ 1.5 × 基线导出**（同机、同商品集、同批次设置实测基线），两条并列报出。
4. **小组合批正确性**：合批前后的指派结果逐行一致（同一实现两条路径对照）。
5. **贪心质量**：组内贪心总代价对同组精确解相对差 ≤ 1e-2（组行数 ≤ 1024 时逐组比）。
6. **容量恒等式**：每个父前缀下各子码计数等于配额；行和恰 1。
7. **接线**：`ROUNDING_OFF` 与基线逐位一致（含导出）；训练与导出取同一码。
8. **两臂差分学习**：R 改善 ≥ N 的 2 倍（分母为负时 `R ≥ 2·max(N,0)`）。
9. **尺度不变性 / 曲线耦合**：`d` 乘 0.25/4 时两项变化 ≤ 1e-6；`c=0` 与 `c=1` 损失不同（1e-6）。
10. **训练中护栏**：逐层 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`，越界即 FAIL 停止。
11. **rank-batch 指派 ≤ 0.15 s**。
12. **TDD**：先写会失败的测试（配额恒等式、合批与逐组一致、`ROUNDING_OFF` 恒等、c=0 极限、
    训练/导出同码），确认红后再实现。任一门不过即预派发负结果，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 配额指派），Sinkhorn 本体不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：合批只改实现不改结果；若合批后仍超 0.5 s，说明瓶颈在计划（冻结）与编码器（必付），
  此时按"总耗时 ≤ 1.5×基线"判断机制是否可接受，不再改门。

## 五、与 #163 的差异（必须逐条写进规格）

| 项 | #163 | 本臂 |
|---|---|---|
| 计时门 | 导出总耗时 ≤ 2 s（混入前向与冻结计划） | **指派 ≤ 0.5 s** + **总耗时 ≤ 1.5×基线** |
| 第 2 层指派 | 256 组逐组 `topk`（0.72 s） | 按组行数分桶后**合批一次** |
| 遗留项 | `ROUNDING_OFF` 未接、rank-batch 未测、两臂/护栏未跑 | 全部补齐并作为门 |
