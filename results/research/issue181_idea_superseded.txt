## 二、还没试的那一半

`#179` 只把曲率放进**行为对比的距离**；**选码那一步仍是欧氏代价**——于是"决定哪些商品在表示上互为邻居的度量"
与"决定它们落到哪个码字的度量"并不是同一个。主线的要求是让几何地图在**量化过程中**被用上；本臂就是把这同一份度量接到选码侧：

- 对比侧（#179 原样）：`logits = −d_κ/τ`，τ=0.07，权重 0→0.20；
- **选码侧（唯一改动）**：一级 Sinkhorn 的代价矩阵由欧氏 `‖r−c_k‖` 换成**同一个** `d_κ(r, c_k)`；
- Sinkhorn 本体（ε=0.003、50 sweeps、centring）与码本规则**不变**（§19h：机制打分进入均衡分配内部，分配规则仍是基线的）。

## 三、公式（只改一级代价的距离）

```
κ_i     : 冻结 AF3 表 results/research/issue167/kappa.json（均值 1.0、中位 0.9147、max 8.2671；缺失 31 项按 mean_frozen）
proj(u) = tanh(√κ‖u‖)/(√κ‖u‖)·u                        # 零向量取极限 1，保证 κ‖proj‖²<1
d_κ(p,q)= (2/√κ)·asinh( √κ‖p−q‖_ε / √((1−κ‖p‖²)(1−κ‖q‖²)) )
          ‖p−q‖_ε = sqrt(‖p−q‖² + ε_pq),  ε_pq = finfo(dtype).eps·max(‖p‖²,‖q‖²,1)

一级代价：  C_1(i,k) = d_{κ_i}( proj(r_1,i), proj(c_{1,k}) )        # 原为 ‖r_1,i − c_{1,k}‖
对比侧：    logits   = − d_{κ_ij}( proj(u_i), proj(u_j) ) / τ,   κ_ij = sqrt(κ_i κ_j)   # #179 原样
```

- κ 的使用是**同一份表、同一个 `d_κ`、同一个投影**，两处只差"逐商品 κ_i"与"逐对 √(κ_iκ_j)"，因为一边是点对码、一边是点对点。
- 无新增可调常数：τ、权重上限 0.20、升权曲线、码本、预算全部照抄；`d_κ` 与 `proj` 与 #179 逐字相同。
- 训练与导出必须使用同一规则（同一 κ 表、同一 Sinkhorn），否则 SID 不可比。

## 四、开关（存在且接线正确，不训练关闭臂）

- `GEOMETRY_OFF`：两处都退回欧氏（对比用 `cdist`、一级代价用 `‖r−c‖`）→ 必须与 `TIGER_BEHAVIOR_R48` 的损失**逐位一致**。
- `CONTRAST_ONLY`：曲率只在对比侧（= #179 的行为）→ 必须与 #179 的损失逐位一致。
- `BOTH_ON`：出厂。

## 五、验收（派发前，全部可测）

1. **`GEOMETRY_OFF` 逐位一致**：与 R48 损失一致（同 batch 同 seed）。
2. **`CONTRAST_ONLY` 逐位一致**：与 #179 损失一致。
3. **`d_κ` 性质**：`κ=1` 与冻结 `poincare_contract.distance` 一致（rtol 1e-6）；`p=q` 与 `‖p−q‖∈{1e-12,1e-9,1e-6,1e-3}` 梯度有限（gradcheck 双精度）；对称、零距离、抽样三角不等式、`proj` 球内。
4. **选码使用同一度量**：一级代价矩阵与 `d_κ` 的手算逐元素一致；Sinkhorn 本体未被改动（函数 diff 为空）。
5. **训练/导出一致**：同一 κ 表、同一代价规则；导出三级码与训练末轮一致率 1.0。
6. **一 epoch 真实入口冒烟**：`applied_grad_norms` 全有限非零、代价矩阵非恒定、Sinkhorn 不报错、导出 SID 有效。
7. **导出统计**：全量 24587，逐层码数/最大份额（≤10%）、二级前缀、三级碰撞（并列基线 0.162444）、§63 `l3_collision`；`collision < 0.40`。
