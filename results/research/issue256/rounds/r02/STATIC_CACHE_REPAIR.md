# R02 deterministic static-feature cache engineering repair

## Demonstrated fault and limits

`STATIC_CONSUMER_DIAGNOSIS.json` binds the actual standard-launcher four-rank run: identical complete frozen features/topology and learned affine parameters yield different fresh CUDA incoming/outgoing static means. Every layout is fully compared, and the same consumer repeats exactly. This identifies a non-reproducible static-cache component, not a Recall cause or yet a proof that it explains the entire actual-budget discrepancy. The component probe uses default highest dense precision; the actual Trainer uses high. Their token/gate difference magnitudes are not interchangeable.

## Frozen mathematical behavior

For every complete ego and node, cache the arithmetic incoming/outgoing mean of its unchanged six normalized immutable features, or zero on an empty direction. Keep the independent nonempty masks, source-owned dtype/device, all neighbors/edges, bounded chunks and no gradients through static features. No persistent asset is built, copied or changed. Learned projections, GNN activations and attention remain freshly evaluated and differentiable. Formula, original and structural losses, normalization, assignment, cadence, scalar coefficient rule, dimensions, dataset and training/evaluation recipe remain unchanged.

## Targeted repair and proof

Before implementation, execute `python3.9 -m tools.issue256.r02.check_static_cache`: the specified fresh-consumer equality assertion must expose the old production path; crash/import failure does not count. CUDA static cache construction will reuse the existing complete-row `tools.issue253.ego_kernel.row_means` kernel already used by live GNN aggregation. Each row has one owner and a fixed edge reduction order, without cuSPARSE atomic SpMM. CPU fallback stays unchanged. Float32/float64 directed/empty hand answers remain exact. Existing independent full-layout value and gradient references must still pass.

The new backend computes the same mathematical mean but need not reproduce the old nondeterministic floating reduction bit pattern. Never rewrite the historical R01 SID/checkpoint or relabel its old execution source. Re-run current-source actual DDP/module/epoch51/inclusive-performance/machine entry/graph checks; the strict budget tolerance stays2e-6. An improved cache alone is not an admission credential.
