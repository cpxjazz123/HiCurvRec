# 关系级特征增量实验：Graphlet 角色、购买方向、AF3、社区

日期：2026-11-16  
数据：TRAIN 拟合，TEST 评估；所有行为特征只由 TRAIN 行为图构建  
脚本：`incremental.py`、`enrich.py`  
表格：`incremental_tables.md`；数值：`incremental.json`

本实验回答：在“文本上下文 + 度数/流行度/文本相似度控制”之外，逐步加入 **Graphlet 类型 → Graphlet 节点角色 → 购买方向 → AF3 曲率 → 社区关系**，TEST 的下一商品类别 log-loss 是否继续下降。

结论：**前三种（Graphlet 类型、节点角色、购买方向）都有独立增益；AF3 有小而稳定的增益；社区关系的增益很弱，不建议单独作为机制依据。**

---

## 1. 实验设置

### 1.1 任务与样本

- 沿用上一个实验的 6 个高支持商品（乐器线、延迟踏板、3 款琴弦、换弦工具）。
- 每个事件：`predecessor`（前一个商品）→ `target`（当前商品）→ `next`（下一个商品）。
- 预测目标：`next` 的全局文本簇（top 10 + other）。
- 只评估 **TEST 中边存在于 TRAIN 图** 的事件；所有模型使用同一批 TEST 行，避免样本差异。
- TRAIN 拟合，TEST 评估；上下文/结果文本簇不使用行为标签。

### 1.2 模型

- 多项 logistic 回归，L2 正则化，`C=1.0` 固定（不在 TEST 上调参）。
- 数值特征在 TRAIN 上标准化；one-hot 特征不标准化。
- 所有模型都包含同一组控制变量：
  - 文本相似度：`sem_cos`、`title_jaccard`
  - 度数/流行度：`log degree(predecessor)`、`log popularity(predecessor)`、`log degree(target)`、`log popularity(target)`
  - 历史长度
- 文本上下文本身以 20 维 one-hot 进入 A 及之后所有模型。

### 1.3 特征组

| 组 | 特征 |
|---|---|
| `text` | 前一个商品的文本簇 one-hot（20）+ 上述控制变量 |
| `graphlet` | graphlet 模式 one-hot：none / K5 / double_triangle / K4_tail / K2_3 / P5_centre / C5 / P5_hops / K1_4 / T5 / multi |
| `role` | 端点 ORCA role 对 one-hot（21）；`hub_is_pred`（度数较高的一端是否是前一个商品）；`degree_diff`、`core_diff`；`is_bridge` |
| `direction` | `log1p(trans_f)`、`log1p(trans_b)`、`P(target|pred)`、`P(pred|target)`、方向不对称度、方向平衡 |
| `af3` | AF3 数值；`AF3 >= q3`；`AF3 <= q1` |
| `community` | 两端是否同一 Louvain 社区 |

AF3 公式：`AF3(e) = 4 - deg(u) - deg(v) + 3 * m_e`，`m_e` 为包含该边的三角形数；TRAIN 图上 `q1=-293`、`q3=-54`，所有 AF3 ≤ 0。

### 1.4 模型序列

| 模型 | 输入 |
|---|---|
| A | text |
| B | A + graphlet |
| C | B + role |
| D | C + direction |
| E | D + af3 |
| F | E + community |

另外做 **F 的 leave-one-group-out**：从 F 中移除 graphlet / role / direction / af3 / community，观察 log-loss 回升多少。

## 2. 结果

### 2.1 逐步 TEST log-loss

| target | A text | B +graphlet | C +role | D +direction | E +AF3 | F +community |
|---|---:|---:|---:|---:|---:|---:|
| 20159 线材 | 2.2326 | 2.2182 | 2.2132 | 2.2030 | 2.1994 | 2.1980 |
| 22372 延迟踏板 | 2.1165 | 2.1059 | 2.0906 | 2.0783 | 2.0755 | 2.0749 |
| 23516 电吉他弦 | 2.2301 | 2.2143 | 2.2043 | 2.1897 | 2.1880 | 2.1859 |
| 23238 电吉他弦 | 2.2241 | 2.2074 | 2.1962 | 2.1748 | 2.1737 | 2.1719 |
| 23602 原声琴弦 | 2.1473 | 2.1232 | 2.1031 | 2.1021 | 2.0970 | 2.0936 |
| 19314 换弦工具 | 2.1277 | 2.1008 | 2.0903 | 2.0896 | 2.0884 | 2.0855 |
| **加权** | **2.1842** | **2.1670** | **2.1556** | **2.1451** | **2.1424** | **2.1405** |

A→F 加权总增益 **0.0437 nats**（约 2.0% 相对下降）；6/6 个目标都单调下降。绝对水平仍在 2.14–2.20，距离 11 类均匀分布的 log(11)=2.398 只有约 0.20–0.26 nats 的优势，说明这仍是**弱预测任务**。

### 2.2 逐步增益（正 = 后一个模型更好）

加权均值 ± 标准误（按 TEST 行数加权；6 个目标全部为正）：

| 步骤 | 加权增益 | 正目标数 |
|---|---:|---:|
| A text → B +graphlet | **+0.01719 ± 0.00205** | 6/6 |
| B → C +role | **+0.01142 ± 0.00211** | 6/6 |
| C → D +direction | **+0.01057 ± 0.00308** | 6/6 |
| D → E +AF3 | **+0.00266 ± 0.00117** | 6/6 |
| E → F +community | **+0.00190 ± 0.00108** | 6/6 |

- **Graphlet 类型**仍是最大的结构增益（+0.0172）。
- **节点角色**（+0.0114）和**购买方向**（+0.0106）各自都有独立增益，量级接近；这不是“Graphlet 类型换了个名字”。
- **AF3** 有正增益，但只有 +0.0027 nats；6/6 方向一致，量级小。
- **社区关系**只有 +0.0019，接近噪声；6/6 为正但幅度很弱。

### 2.3 Ablation：从 F 中移除一组

| 移除组 | 加权 log-loss 回升 | 正目标数 |
|---|---:|---:|
| -graphlet | **+0.01646 ± 0.00204** | 6/6 |
| -role | **+0.01072 ± 0.00187** | 6/6 |
| -direction | **+0.01033 ± 0.00308** | 6/6 |
| -AF3 | +0.00260 ± 0.00116 | 6/6 |
| -community | +0.00190 ± 0.00108 | 6/6 |

与逐步结果一致：graphlet、role、direction 是主要贡献；AF3、community 是小数。

### 2.4 逐目标差异

- **方向**在 20159/22372/23516/23238 上增益较大（+0.0102～+0.0214）；在 23602/19314 上只有 +0.0010/+0.0007，接近 0。说明方向信息对“配件/踏板”类转移更有用，对琴弦耗材的下一商品预测帮助有限。
- **节点角色**在 6 个目标上都为正（+0.0050～+0.0200），最弱的是线材（+0.0050，SE 0.0027）。
- **AF3** 在 23602 上最大（+0.0051 ±0.0038），在 23238 上最小（+0.0011 ±0.0045），不确定度较大。
- **社区**在 23602 上最大（+0.0034 ±0.0032），在 22372 上最小（+0.0006 ±0.0026）。

### 2.5 准确率（次要指标）

F 的 top-1 accuracy 为 0.219–0.272，A 为 0.208–0.249；大多数目标上升，但 Graphlet/角色步骤偶尔会让 accuracy 略降，而 log-loss 仍下降。**以 log-loss 为主，accuracy 只作参考。**

## 3. 如何读这些结果

### 3.1 节点角色：值得作为一等特征

`role` 组包含：

- 端点 ORCA 角色对（21 种）；
- `hub_is_pred`：度数较高的一端是否是前一个商品（星形中心 vs 外围）；
- `degree_diff`、`core_diff`；
- `is_bridge`。

它在控制度数/流行度/文本相似度之后仍有 +0.0114 的独立增益，说明“**谁在结构中心、谁是外围**”确实携带了文本上下文之外的信息。对 SID 的含义是：

- 中心→外围（主体→配件）更像**跨前缀转移**，T5 应该学；
- 外围→中心（配件→主体）方向相反，是否共享前缀要单独判断；
- 不能只按 graphlet 类型给边分配前缀。

### 3.2 购买方向：独立于 Graphlet 和角色

`direction` 组包含正向/反向计数、条件概率、不对称度和方向平衡。它在 Graphlet + 角色之后仍有 +0.0106 的增益，且在 4/6 个目标上明显。

这说明“**同一条无向边，A→B 和 B→A 不是同一件事**”。对 SID 的含义：

- 无向 graphlet 类型不足以表达购买顺序；
- 方向性强的边更适合保留为序列转移，而不是压进共享前缀；
- 方向性弱的边才更像“同类/同场景”的对称关系。

### 3.3 AF3：有信号，但不足以单独支撑机制

AF3 在控制度数之后仍有 +0.0027 nats 的稳定正增益（6/6 方向一致），但量级只有 role/direction 的 1/4–1/5。它更适合作为**辅助特征**：

- 稠密社区内部 vs 跨社区桥接的区分，AF3 与 graphlet/role 有重叠；
- 若要用曲率，应该与角色/方向组合，而不是单独作为“曲率损失”。

### 3.4 社区关系：弱，低优先级

社区只有 +0.0019 nats，接近噪声；虽然 6/6 为正，但不足以证明独立价值。可能因为 community 已被 graphlet/role/文本上下文部分覆盖。建议不作为优先机制。

### 3.5 与上一个实验的关系

上一个实验用条件频率表 + 置换零分布，发现 graphlet 在文本上下文之外有 +0.020–0.048 nats 的增益；本实验用正则化 logistic，A→B 的 graphlet 增益 +0.0172，量级一致。新增的 role/direction 又各自贡献约 +0.011，说明上一个实验的“结构增量”并不是单一 graphlet 标签的伪影。

## 4. 对下一轮机制的建议

优先级从高到低：

1. **Graphlet 节点角色 + 购买方向**：两者都有独立增益，且语义清楚（中心/外围、正向/反向）。可作为“关系条件化”的主特征。
2. **Graphlet 类型**：作为基础结构标签保留；不要单独使用。
3. **AF3**：作为辅助，不建议单独做曲率机制；若要使用，与角色/方向组合。
4. **社区**：低优先级；可先不做。

对 SID 的具体含义（仍是假设，需 Stage3 验证）：

- **中心→外围 + 强方向性**：保留为跨前缀序列转移，T5 学；不要强制共享前缀。
- **外围→中心 + 弱方向性**：更像同一套设备的维护/耗材，可考虑共享语义前缀。
- **稠密 Graphlet + 同社区**：同场景内部关系，可共享粗粒度 L1，但 L2/L3 仍按功能分叉。
- **桥接 + 负 AF3**：跨场景切换，保持跨前缀，作为 T5 的跨分支转移。

这些规则目前只是由离线下一商品预测支持，**没有经过 RQ-VAE 重训或 Stage3 验证**；下一步如果要改 SID，应做受控实验，而不是直接把特征塞进损失。

## 5. 限制

1. **只有 6 个高支持商品**，全部是乐器配件；没有独立 SD 卡/相机/无人机商品，不能直接外推到用户例子。
2. 文本上下文和结果都是全局 MiniBatchKMeans 簇，不是人工品类；簇可能混合品牌/配件。
3. 只评估 TEST 中边存在于 TRAIN 图的事件（约 92%）；未见的边没有结构/方向/AF3 特征。
4. 模型是固定 `C=1.0` 的多项 logistic；没有在 TEST 上调参，但也没有做嵌套交叉验证或多种子。
5. 增益是“下一商品类别 log-loss”的离线增益，**不是 Stage3 Recall 增益**；不能据此宣称 SID 机制有效。
6. 方向/角色/AF3 都由 TRAIN 构建；TEST 只用于评估。但 TEST 是同一批用户的时间后段，不是用户不相交。
7. 社区/AF3 的增益很小，统计上“6/6 方向一致”不等于实际重要；不要过度解读。
