结论：容量约束本身没问题，**指派算法换成精确求解**即可，双容量只是求解器的可行域。

## 一、主张（一句话）

保留 #168 的双容量（全局每码 `⌊B/K⌋`、父前缀同码 `⌈n_g/K⌉`），把贪心换成**在容量约束下的精确指派**
（min-cost flow / 展开式 Hungarian），代价矩阵用与 #168 相同的 Sinkhorn 形计划或纯代价，导出按块求解且每块各自满足双容量。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **逐商品曲率（沿用 #167）**：`κ_i = (1 − u_i)/mean_frozen(1 − u)`，均值 1。
3. **两重配额（沿用 #168，不改）**：`q_k = ⌊B/K⌋`（余数按码索引）+ `r_g = ⌈n_g/K⌉`。
4. **指派（本臂唯一改动）**：`min_cost_assignment(cost, q, r)`——把容量约束写成 min-cost flow（每行 1 单位、
   每码 `q_k`、每 (父, 码) `r_g`），用确定性求解器求全局最优；实测 1024×1024 训练形状 0.027 s/层，
   导出按 ≤4096 行分块、每块各自双容量（块间不共享容量，如实在报告里写明）。
5. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003`/`50 sweeps`/centring、残差递推、读出、导出、三 token 结构；
   训练目标仍只有 `L_RQ`；开关 `ROUNDING_OFF`/`GEOMETRY_OFF`/`BOTH_ON` 语义不变。
6. **身份**：`ARM_NAME="TIGER_two_sided_exact_rq"`、`ARM_VARIANT="2SEXACT"`、`OUTER_LOOP=False`、
   `AUX_AF3=False`、`CURVATURE=1.0`；树内无绝对路径；`/tmp` 不落产物；checkpoint 绑结构表 SHA 与 κ 表 SHA。

## 三、验收（派发前，全量导出 + 冻结探针 + 200 步试点，全部可测）

1. **三条结构目标同时成立**（沿用 #168 口径）：入口碰撞 ≤ 0.05、二级前缀 ≥ 0.9·B、逐层 256 码且份额 ≤ 1.5×均匀。
2. **代价质量（本臂核心门）**：与同容量精确解**同一求解器**下总代价相对差 ≤ 1e-9（实现同一性），并与
   "无容量约束的 Sinkhorn 计划代价"比值只作诊断（可 >1，因容量改变了可行域）。
3. **双容量恒等式**：每父前缀用每码 ≤ `r_g`、每码总数 ≤ `q_k`、放宽次数 = 0。
4. **运行时间（记录项 + 合理性上限）**：训练形状每层 ≤ 0.05 s；全量导出 ≤ 60 s（含分块）。
5. **200 步试点**：逐层 `codes_used ≥ 240/256`、`max_bucket_share ≤ 5%`、平均前缀距离 ≥ 0.5× 初值。
6. **训练中双侧护栏**：每个评估 epoch 同时检查逐层占用与全局码使用，越界即 FAIL。
7. **接线与一致**：`ROUNDING_OFF` 同模型内逐位一致（含导出）；训练/导出三级一致率 1.0；checkpoint 绑定。
8. **TDD**：先写会失败的测试（精确解与容量恒等式、分块边界、`ROUNDING_OFF` 恒等、`c=0` 极限、训练/导出同码），
   确认红后再实现。
9. 任一门不过：按预派发负结果记录并停止，不改容量规则/κ/λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 容量约束的精确指派）；Sinkhorn 本体（ε、迭代数、centring、代价）不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：精确求解在训练步里可能成为瓶颈（实测 0.027 s/层 × 3 层 ≈ 0.08 s，基线 0.53 s/epoch，
  占比可接受）；导出分块会让块间容量独立，报告必须写明。

## 五、与 #168 的差异（必须逐条写进规格）

| 项 | #168 | 本臂 |
|---|---|---|
| 指派 | 结构化贪心 | **容量约束下的精确求解** |
| 代价质量 | 对精确解 +113% / +1405% | 与精确解差值 ≤1e-9（同一求解器） |
| 结构三门 | 同时成立（实测） | 不变 |
| 导出 | 一次贪心 | 分块精确解（块间容量独立，如实报告） |
