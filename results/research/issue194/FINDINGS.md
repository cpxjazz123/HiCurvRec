# Issue #194 期间的三项实测事实（含一次我自己造成的破坏及其修复）

## 1. 继承树的批量与冻结配方不符（**影响 #181 的全部可比性**）

`TIGER_af3_structdistill_rq`（#181）与从其复制的本树，源码里写的是：

```python
BATCH_SIZE_PER_RANK = 4096       # 每卡 batch, 总 batch = 1024 * 4 = 4096
```

注释声称总 batch 4096，实际是 **4096/卡 × 4 卡 = 16384**，是冻结配方（1024/卡、全局 4096，见 `TIGER_RQ-VAE/train_rqvae.py:72`）的 **4 倍**。
证据：一次一 epoch 对照运行里，本树在修正前的 `lr` 为 **2.333e-05**，冻结基线为 **2.083e-05**——warmup 按步数走，步数不同说明每 epoch 的优化步数不同。

结论：**#181 的 `test_R@10 = 0.054266` 与任何冻结配方下的臂都不可比**，这一条比 #193 查到的两处缺陷更能解释它的读数。本树已改为 `1024`，改后一 epoch 的 `lr` 与基线**完全一致**（2.0833333333333333e-05）。

## 2. `BEHAVIOUR_OFF` 与基线的等价：逐位不可达，步数可达、数值在噪声内

同一 CPU、同一 seed、单进程、各 3 次重复：

| | epoch-1 loss 样本 | 均值 | 相对跨度 |
|---|---|---|---|
| 冻结基线 `TIGER_RQ-VAE` | 0.00048588 / 0.00048566 / 0.00048570 | 0.00048575 | 4.72e-04 |
| 本树 `BEHAVIOUR_OFF` | 0.00048706 / 0.00048657 / 0.00048539 | 0.00048634 | 3.43e-03 |

- **优化步数一致**（`lr` 逐位相同）。
- 均值相对差 **1.23e-03**，落在两棵树各自的重复运行跨度内 ⇒ 无从分辨。
- **"逐位一致"在本 harness 不可达**：基线自己两次运行就差 4.7e-04。这一点必须写明，不能把"没测到逐位相等"写成"已满足"。
- 数值之外还有结构性证据：`BEHAVIOUR_OFF` 时结构项、支撑掩码、曲率核、`codes_of` 全都不可达（`tests/test_sdh_off_state.py` 用会抛异常的打桩证明），且 `_assign_kappa` 返回 `None`（关闭后分配回到欧氏，与基线相同）。

修复后脚本新增**硬保护**：所有输出路径必须落在 `results/research/issue194/` 之内，否则拒绝运行（`Path(...).resolve()` 校验，逐项检查）。

## 4. 结构项的梯度归宿（记录，不是判据）

真实模型 + 真实 batch：结构 KL = 1.9683e-03，`grad_fn` 在位，**8 个参数张量**获得非零梯度，**全部属于编码器**；码本按构造为 0——学生读取 STE 值，码字由 RQ 目标负责。这与 #187/#192 的"两块都要有梯度"不同：那两处是**预算规则**的要求，本机制没有预算规则，公式本身只监督分配。

## 5. 冒烟与入训（验收 6 前半）

`SMOKE_PASS`，`probe lambda_star = 0.00164836`，训练已起（6 进程）。λ 由树内既有的 `struct_distill.calibrate(0.1·‖∇L_RQ‖/‖∇L_SD‖)` 在第一个真实 batch 上测得，**不是调参值**：支撑限制把 `∇L_SD` 变小，于是 λ 比 #191 的 2.3e-05 大约两个数量级，这与"参与求 KL 的对数从 ~64/锚 降到 ~4/锚"的量级关系一致（1/16 ≈ 6%，2.3e-5 → 1.6e-3 是 70 倍，超过 16 倍的部分来自教师值从 T 行改成 A_κ 的幅度差异，无法进一步分解——两项同时改动，不做消融，§19g）。

## 6. 结构项已进入有效窗口（epoch 1501+，实测有限）

前 63 个有效 epoch（1501–1563）：结构 KL **0.004329 / 0.006574 / 0.008716**（min/mean/max），权重 `w` 从 1.14e-06 线性升到 7.19e-05（λ\* = 1.64836e-03 × 时间窗线性）；总 loss 从 0.00032968 到 0.00033208，无 NaN、无发散。支撑限制下每锚约 4 对参与 KL，KL 量级 6e-03 与"只有被 SID 区分错的少数对在起作用"一致。
