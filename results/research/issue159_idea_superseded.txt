Idea：末级用**平衡计划的质量取整**得到硬选码（修正 #158 的贪心不保真）
英文名称：Plan-Based Rounding of the Balanced Assignment (corrected from #158)

#158 把坍缩定位到"离散化那一步"，方向是对的，但实现选错了算法：

| 做法 | 实测 |
|---|---|
| 逐行 `plan.argmax(-1)`（基线） | 计划平衡、硬选码集中（#157：27/256 码、最大码 30.81%） |
| **按代价升序的容量贪心**（#158） | 相对精确解贵 **+31.02%**（5.551271 对 4.236980）与 **+6.95%**（4.531246），保真门 FAIL |

结论：保列和的**约束**没错，错在"用代价排序做贪心"——它把全局最优的平衡计划换成了一个明显更贵的指派。
正确做法是**对平衡计划本身做取整**（计划已是松弛问题的最优解，取整只需保持它的行列质量）。

## 一、主张（一句话）

末级仍由 Sinkhorn 求平衡计划；把它变成硬选码时按**计划质量**取整（每行取质量最大的码、按列容量重分配），
保证每行恰好一个码、每列与计划列和质量偏差 ≤ 1 行；结构监督只塑形计划，不会被离散化抹掉。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157，不改）**：`ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **末级取整（本臂唯一的新机制）**：`index = round_plan(plan)`
   - 列容量 `c_k = round(Σ_i plan_ik)`，用最大余数法补足总和到 batch 行数；
   - 按 `plan_ik` 从大到小遍历，行未分配且列未满则指派；剩余项按容量剩余列的最小代价补齐；
   - 行和恰为 1、每列不超过容量；训练与导出同一函数，导出在完整商品集上确定性执行一次；前两级仍为基线 `argmin`。
4. **保持不变**：代价函数、Sinkhorn 本体与 `SK_EPSILON=0.003` / `SK_ITERS=50` / centring、残差递推、读出、三 token 结构。
5. **开关**：`ROUNDING_OFF`（退回 `argmax`，与基线逐位一致）、`GEOMETRY_OFF`（`c=0`）、`BOTH_ON`（出厂）。

## 三、验收（派发前，冻结 8192 行 TRAIN 探针，全部可测）

1. **占用按构造成立**：末级 `codes_used ≥ 240/256`、最大码份额 ≤ 1.5%、每码行数 ≤ `⌈B/K⌉`。
2. **保真（替掉 #158 的贪心口径）**：每列行数与计划列和偏差 ≤ 1、行和恰为 1；总代价对**计划自身代价**
   的比值 ≤ 1.01（计划是松弛最优，取整只应微增）；与精确求解器的差距只作诊断并列报出。
3. **运行时间**：单次 `1024×256`（每 rank）取整 ≤ 0.05 s（基线实测 0.27 s/epoch，取整不得吃掉 20% 以上）。
4. **两臂差分学习**（沿用协议）：同 seed/数据顺序/固定 200 步/训练器优化器；R 的秩一致性改善 ≥ N 的 2 倍。
5. **尺度不变性**：`d` 同时乘 0.25/4 时 `L_rank`、`L_spread` 变化 ≤ 1e-6。
6. **曲线耦合**：`c=0` 与 `c=1` 损失值不同（欧氏极限 1e-6）。
7. **接线与一致**：`ROUNDING_OFF` 与基线逐位一致（含导出）；同一商品集上训练与导出取同一码。
8. **200 步试跑护栏**：与 #157 相同的占用与平均距离检查，必须通过。
9. **TDD**：先写会失败的测试（行和/列容量、偏差 ≤1、`ROUNDING_OFF` 恒等、c=0 极限、训练/导出同码），
   确认红后再实现。
10. 任一门不过：按预派发负结果记录并停止，不改容量规则、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：本臂显式申请改动末级选码规则（`argmax` → 计划取整），均衡分配本体仍是 Sinkhorn
  （同一 ε、同一迭代数、同一 centring、同一代价）；不把均衡换成普通 `argmin`。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：按计划质量取整仍可能把少数行分到次优码（计划的次大质量接近 1 时）；由"对计划代价 ≤ 1.01"这一门
  兜住；若仍不过，按负结果归档，不改容量规则重跑。

## 五、与 #158 的差异（必须逐条写进规格）

| 项 | #158（不保真） | 本臂 |
|---|---|---|
| 取整依据 | 代价升序贪心 | **计划质量**（松弛最优解的行分布） |
| 代价保真 | 对精确解 +31.02% / +6.95% | 对计划代价 ≤ 1.01（另有精确解对照，仅诊断） |
| 列和偏差 | 未约束 | 与计划列和偏差 ≤ 1 |
| 运行时间 | 未测 | ≤ 0.05 s / rank-batch |
