Idea：配额同时按**父前缀内**与**全局码**两侧约束（修正 #167 的护栏失效）
英文名称：Two-Sided Quotas — per-parent cap × global code capacity (corrected from #167)

#167 是本线路第一次"预派发全过、训练中被自己拦下"的臂：

| 观测 | 数值 |
|---|---|
| 预派发 | 入口碰撞 **0.000000**、结构灵敏度 100%、单一实现 + 开关 1.0/1.0/1.0、checkpoint 绑定、七项 κ 测试全过 |
| 训练中 | epoch 400：末级只剩 **101 码**、最大码份额 **10.02%** → 护栏 FAIL；epoch 300 的崩溃与之同源 |
| 根因 | 条件配额只约束"每个父前缀内部摊开"，**不约束全局码占用**；只有 1 行的父组各自取自己的 `argmax`，全局分布于是跟着计划走，而计划在冻结预算下并不均衡（#160 已测：一级列质量 0–653） |

这是 #161 提出的张力的第三条证据：**碰撞 0 与逐层占用在"只按父前缀配额"的构造下不可同时成立**。
要同时成立，配额必须**两侧都约束**：既限制每个父前缀用某个码的次数，也限制每个码在全 batch 的总用量。

## 一、主张（一句话）

每层做**两重容量**的指派：①全局每码容量 `q_k = ⌊B/K⌋`（余数按码索引）；②每个父前缀用同一个码的上限
`r_g = ⌈n_g/K⌉`；指派按计划质量降序、同时满足两重上限，剩余行在剩余容量内按代价补齐。

这样"父内分散"与"全局均匀"由同一张容量矩阵保证，而不是让每个父组各取 `argmax`。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **逐商品曲率（沿用 #167，不改）**：`κ_i = (1 − u_i)/mean_frozen(1 − u)`，均值 1。
3. **两重配额（本臂唯一改动）**：
   - 第 1 层无父：沿用全局均匀容量 `q_k = ⌊B/K⌋` + 余数；
   - 第 2/3 层：在每层建立 (父前缀 × 码) 容量矩阵，`r_g = ⌈n_g/K⌉` 与 `q_k` 同时生效；
   - 指派：按 `plan_ik` 降序贪心，行放入仍有 **父子双容量** 的最高质量码；剩余行在双容量内按代价最小补齐；
   - 若某个 batch 在双容量下不可行（Hall 条件不满足），按**确定性**顺序把 `r_g` 加 1 直到可行，并把"放宽次数"写入记录（要求 0）。
4. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003`/`50 sweeps`/centring、残差递推、读出、导出、三 token 结构；
   训练目标仍只有 `L_RQ`（秩监督已两次证伪）。
5. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，同模型内逐位一致）、`GEOMETRY_OFF`（`c=0`）、
   `BOTH_ON`（出厂）；只要求实现正确与廉价接线检查。

## 三、验收（派发前，全量导出 + 冻结探针 + 200 步试点，全部可测）

1. **三条同时成立**（此前从未同时达成）：
   - 全局占用：每层 `codes_used ≥ 250/256`、最大码份额 ≤ `⌈B/K⌉/B`（4096 行为 0.39%，允许 1.5×）；
   - 前缀多样性：二级不同前缀 ≥ **0.9·B**；
   - 入口碰撞 ≤ **0.05**（未训练与训练后各测一次）。
2. **双容量恒等式**：每个父前缀用每个码的次数 ≤ `r_g`，每个码总数 ≤ `q_k`；**放宽次数 = 0**。
3. **200 步试点护栏**：逐层 `codes_used ≥ 240/256`、`max_bucket_share ≤ 5%`（比训练护栏更严，提前拦 #167 那种漂移）；
   batch 平均前缀距离 ≥ 0.5× 初始。
4. **训练中护栏（双侧）**：每个评估 epoch 同时检查逐层占用与**全局码使用**，越界即 FAIL 停止。
5. **取整质量**：组内指派总代价对"同容量精确解"相对差 ≤ 1e-2。
6. **接线与一致**：`ROUNDING_OFF` 同模型内逐位一致（含导出）；训练/导出三级一致率 1.0；checkpoint 绑结构表 SHA 与 κ 表 SHA。
7. **时间（记录项）**：全量导出与 rank-batch 耗时写入报告，上限 60 s。
8. **TDD**：先写会失败的测试（双容量恒等式、不可行时的确定性放宽、`ROUNDING_OFF` 恒等、`c=0` 极限、
   训练/导出同码），确认红后再实现。
9. 任一门不过：按预派发负结果记录并停止，不改容量规则、不改 κ 映射、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 双容量指派）；Sinkhorn 本体（ε、迭代数、centring、代价）不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：双容量在某 batch 不可行时会触发放宽；若放宽次数 > 0，说明该 batch 规模下三条不能同时成立，
  按负结果记录（不改 K/B）。

## 五、与 #167 的差异（必须逐条写进规格）

| 项 | #167 | 本臂 |
|---|---|---|
| 配额 | 只按父前缀（`⌊n_g/K⌋`） | **父前缀 × 全局码双容量** |
| 全局码占用 | 不约束（实测训练中塌到 101 码 / 10.02%） | `q_k = ⌊B/K⌋` 强制 |
| 训练中护栏 | 只看逐层 `codes_used`/份额 | 逐层 + **全局码使用** 双侧 |
| 200 步试点 | 占用门（10%/240 码） | **5% 份额 / 240 码**（更早拦漂移） |
