Idea：取整的容量取**均匀配额**，不再取自计划（修正 #160 的计划偏斜）
英文名称：Uniform-Quota Rounding (corrected from #160)

#160 把三层同规则接通并测通，但逐层占用门不过，成因是机械的：

| 观测（4096 行，未训练） | 数值 |
|---|---|
| 逐层计划的列质量 | 一级 0.00–**653.06**、二级 0.00–171.91、三级 1.13–16.41（均匀应为 16） |
| 逐层占用（取整后） | 一级最大码 **15.7%**、`codes_used` 199–228 < 240 |
| 入口碰撞（同一读数） | **0.0898**（4096）/ **0.2963**（全量），均 < 0.40 |

原因：`SK_EPSILON=0.003` / 50 sweeps 下 Sinkhorn 计划远未收敛（与 #150 的列误差 0.740 同源），
而"保列和取整"保的是**计划的**列和——计划里没有的均衡，取整变不出来。

结论：容量不应取自计划。若目标是"每层码本按构造保持均匀"，配额就必须**直接写成均匀的**，
与计划收敛与否无关；计划只用来决定"谁先挑"，不用来决定"每列收几个"。

## 一、主张（一句话）

末三级每层的取整配额取**均匀配额** `q_k = ⌊B/K⌋`（余数按码索引确定性地 +1），不再取自计划的列质量和；
取整仍按计划质量降序指派、剩余行用剩余配额内的最小代价补齐；占用按构造成立，与 Sinkhorn 收敛程度无关。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157 起，不改）**：`ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **分配（本臂唯一改动）**：三层都走 `plan_l = structured_sinkhorn(cost_l, ε=0.003, 50, uniform)`，
   但 `round_plan` 的列容量改为均匀配额：
   - `q_k = ⌊B/K⌋`，前 `B mod K` 个码（按码索引升序）各 +1，保证 `Σ q_k = B`；
   - 按 `plan_ik` 降序为每行指派到仍有配额的码；剩余行在剩余配额内按代价最小补齐；
   - 行和恰为 1、每列恰好 `q_k`；训练与导出同一函数（导出在完整商品集上执行一次）。
4. **保持不变**：代价函数、Sinkhorn 本体与 ε/迭代数/centring、残差递推、读出、导出、三 token 结构；
   不引入桶/掩码/π/层心平移。
5. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，逐位等于基线）、`GEOMETRY_OFF`（`c=0`）、
   `BOTH_ON`（出厂）；只要求实现正确与廉价接线检查，不训练关闭臂（§19g）。

## 三、验收（派发前，冻结探针，全部可测）

1. **逐层占用按构造成立**：三层各自 `codes_used = 256`、最大码份额 = `⌈B/K⌉/B`（4096 行为 0.39%）、
   每列恰好 `q_k`（与计划无关，属恒等式）。
2. **前缀多样性**：冻结探针上二级不同前缀 ≥ `0.5·B`；入口碰撞 ≤ 0.40（未训练与训练后各测一次）。
3. **取整质量（不设绝对容忍，只比两种规则）**：同一 batch 上均匀配额取整的总代价，与**精确求解器在
   同一配额下的最优解**相比相对差 ≤ 1e-2；与计划自身代价的比值只作诊断并列报出（计划不收敛时它必然 >1）。
4. **运行时间**：三次 Sinkhorn + 三次取整 ≤ 0.1 s / rank-batch。
5. **两臂差分学习**（沿用协议）：R 改善 ≥ N 的 2 倍（分母为负时用 `R ≥ 2·max(N,0)`）。
6. **尺度不变性 / 曲线耦合**：`d` 乘 0.25/4 时两项变化 ≤ 1e-6；`c=0` 与 `c=1` 损失不同（1e-6）。
7. **接线与一致**：`ROUNDING_OFF` 与基线逐位一致（含导出）；同一商品集上训练与导出取同一码。
8. **训练中护栏**：每个评估 epoch 逐层 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`，越界即 FAIL 停止。
9. **TDD**：先写会失败的测试（配额恒等式、前缀多样性构造、`ROUNDING_OFF` 恒等、c=0 极限、
   训练/导出同码），确认红后再实现。
10. 任一门不过：按预派发负结果记录并停止，不改配额规则、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：本臂继续显式使用一、二层的均衡分配（`argmin` → 计划 + 均匀配额取整），Sinkhorn 本体不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：均匀配额与"计划想收的行数"不一致，前几轮取整代价会明显高于计划代价；这是有意的取舍
  （用一点码率换码本均匀），由"对精确均匀配额解的差距 ≤1e-2"兜住实现质量，代价膨胀只作诊断。

## 五、与 #160 的差异（必须逐条写进规格）

| 项 | #160 | 本臂 |
|---|---|---|
| 列容量来源 | 计划的列和（未收敛 ⇒ 0–653） | **均匀配额** `⌊B/K⌋` + 余数 |
| 占用 | 一级 15.7%、199–228 码 | 恒等式：每码恰好 `q_k` |
| 与 Sinkhorn 收敛的关系 | 强依赖 | 只用于排序"谁先挑" |
| 质量口径 | 对计划代价 ≤1.01（对不收敛计划无意义） | 对精确均匀配额解 ≤1e-2 |
