# Issue #144 — 结论

**问题**：AF3 能否在 RQ-VAE 训练之外，作为逐层几何配置的选择标准？

**结论：能稳定复现排序，但不能区分优劣；没有唯一选择。**

## 证据

1. **稳定性成立**：在冻结的选择支持（seed=42）与构造后从未用于选择的独立评估支持
   （seed=7，940498 对）上，六个候选的排序相关系数为
   D_AF3 = 1.000、ret@16 = 0.943、Brier = 1.000；两个支持得到**相同的 Pareto 集**。
   因此 AF3 硬 SID 指标不是噪声，外部选择器在排序意义上是可复现的。
2. **区分性不成立**：D_AF3 的全部候选区间只有 0.2848–0.2887（Δ≈0.004），
   而冻结欧氏基线在最关键的三项上都是最好的：ret@16 0.0495（混合臂 0.0451–0.0471）、
   一级码用量 247/256（混合臂 49–87）、L3 碰撞 0.2745（混合臂 0.335–0.461）。
   混合臂只换来 D_AF3 与 Brier 的千分位改善，却在码本健康与邻居保持上系统性变差。
3. **Pareto 集有五个成员**（基线、E、F0、G、L；A 被支配），没有候选在多项指标上占优。
   按 issue 的预注册规则，这只能报告为 **“暂无唯一选择”**，不得临时改权重把某个配置排第一。
4. 由此，AF3 结构保真度**不能**作为替换冻结欧氏基线的理由；它能做的是在候选已经由其他
   理由产生后，稳定地复现它们的结构排序，而不是产生胜者。

## 边界

- 只做外部评估，AF3 未进入任何 forward/loss/采样/梯度路径；未训练新模型。
- 六个候选的 SID 与 checkpoint 全部来自仓库既有产物，SHA 见
  `geometry_selection.json`；不可比项没有被强行纳入（本表全部可用）。
- 评估支持在**看到任何选择结果之前**已按 seed=7 构造并冻结；选择支持 seed=42 的指标在
  本 issue 之前就已被 #140–#143 的报告使用，因此这里只把它当选择集，不当最终证据。
- D_AF3 的降低不等于 Recall 改善；本 issue 不包含 Stage3，也不做推荐效果结论。
