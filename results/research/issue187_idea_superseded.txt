Idea：RAD——半径型结构损失（按一级码分组的双曲半径离散度，非成对、非对比）
英文名称：RAD — Radial-Cluster Dispersion Loss on the Level-1 Code Groups

## 一、已实测全表（修正一条关键前提）

| 臂 | 结构信号如何进入通路 | recall@10 | 对基线 0.056216 |
|---|---|---|---|
| 冻结基线 | — | 0.056216 | — |

**必须写对的两条事实**（`#186` 结论文本 + 源码核对）：

1. `TIGER_struct_mixed_rq/train_rqvae.py` 的 +3.0% 来自 `training_hooks.structure_term`/`structure.structure_loss`
   —— 对**抽样三元组**的 (1/3) 成对项，作用在**量化后的位置**上；它的**分配度规是基线的 `mixed_sq`**，
   所以"把实测 κ_i 放进一级代价"这个说法对它是错的（κ 从未进过它的分配度规）。
2. 该成对三元组项正属于本轮主线**明令禁止**的"行为正负样本/成对学习"（三元组 + target 边距），不得作为方向。
   于是"标量曲率进量化器度规"这一整类**已被测穿**：+0.3% ~ −3.9%，最好的一次是 +0.3%。

## 二、因此下一机制必须换**类**，而不是换标量

未试过、且**不违反**禁止项的一类：**把结构写成"半径"而不是"距离"，写成非成对的分组离散度而不是成对项**。

- 不用正负样本、不用三元组、不用 margin、不用源-目标残差对比；
- 用一级码形成的**组**（这正是主线点名的"组内局部聚类"）；
- 用**双曲半径**（球内到原点的双曲距离，显式曲线量）；
- 组内半径齐性 ⇒ 一级码在球里各自占据一层"壳"，结构决定哪件商品落哪一层。

## 三、主张（一句话）

在训练目标里加一个**无量纲**的分组半径离散度项：每件商品的量化位置到原点的双曲半径，应当接近它所属一级码组的平均半径；
它不改任何分配规则、不构成任何成对比较，却把"组内聚簇"变成几何约束，经编码器 → 一级选码 → SID 同一条通路落地。

## 四、公式（唯一改动）

```
pos_i    = 该商品量化后的位置（E16 欧氏块 + H16 双曲块，与 TIGER_struct_mixed_rq 的 _positions 同口径）
r_i      = d_H(0, pos_i) = 2·atanh(‖pos_i^H‖)                     # 双曲块内在球内的双曲半径
k(i)     = 一级 Sinkhorn 分配（argmax，detach），组 G_k = { i : k(i)=k }
R_k      = mean_{i∈G_k} r_i                                       # 组平均半径（detach）
L_rad    = mean_i ( r_i − R_{k(i)} )²  /  ( mean_i r_i )²          # 无量纲；空码不计
L_total  = L_base + λ·L_rad
λ        = 由仓库既有、已冻结的预算规则算出：λ* = min_over_blocks( ‖g_block^base‖ / ‖g_block^L_rad‖ )（初始化时一次，之后冻死）
```

- **无新增可调常数**：`L_rad` 无量纲（分子分母同量纲），权重 λ 取自既有的预注册预算规则（`calibrate_lambda_block_budget`，不允许 ε、不允许回退）。
- **不是成对项**：不采样任何边/三元组/正负样本；梯度只经 `r_i` 回到编码器与码本。
- **不改分配**：Sinkhorn（ε=0.003、50 sweeps、centring）、码本 K=256、码字与导出全不动。

## 五、开关（存在且接线正确，**不训练关闭臂**）

- `BEHAVIOUR_OFF`：`L_rad ≡ 0` → **必须与冻结基线逐位一致**（损失曲线、每层码分配、导出 SID）。
- `GEOMETRY_OFF`：`r_i` 改用欧氏范数 `‖pos_i‖`（同样的分组离散度，但量不是双曲半径）。
- `BOTH_ON`：出厂（双曲半径 + 分组离散度）。

## 六、验收（派发前，全部可测）

1. **`BEHAVIOUR_OFF` 逐位一致**（对冻结基线：每步 loss、码分配、导出 SID）。
2. **半径恒等式**：`d_H(0,p)=2·atanh(‖p‖)` 与既有双曲实现一致（rtol 1e-6）；`‖p‖→0` 与 `‖p‖→1` 梯度有限；`p=0` 时 `r=0`。
3. **组聚合正确**：手算小例核对 `R_k`、空码剔除、单样本组贡献为 0；`L_rad` 在"组内完全同半径"时为 0。
4. **无量纲**：把全部 `pos` 按同一双曲缩放重参数化时 `L_rad` 的变化符合定义（不随整体尺度漂移）；数量级记录在案。
5. **λ 预算规则**：走既有 `calibrate_lambda_block_budget`，`λ*` 与各 block 的 base/struct 梯度范数一并落盘；装备 `CALIBRATION_DEGENERATE` 时**不训练**。
6. **无成对/对比残留**：代码路径里不出现边采样、三元组、margin、InfoNCE、BCE、源-目标残差（机器可 grep 断言）。
7. **gradcheck**（双精度）与**编码器收到非零梯度**；DDP 下一 epoch 真实入口冒烟：损失有限、`L_rad` 分位数与 `λ` 落盘、导出 SID 有效。
8. **导出统计**：全量 24587，逐层码数/最大份额（≤10%）、二级前缀、三级碰撞（并列 0.162444）、§63 `l3_collision`；`collision < 0.40`。
9. **TDD**：先写会失败的测试（退化逐位一致、半径恒等式、组聚合、无量纲、λ 退化拒绝），确认红后再实现。

## 七、边界与不变项

- 起点：冻结基线 `stage2_RQ-VAE/TIGER_mixed_rq`（只读、逐文件 SHA 记 manifest）→ 新树 `stage2_RQ-VAE/TIGER_rad_rq`
  （`ARM_NAME="TIGER_rad_rq"`、`ARM_VARIANT="RAD"`）。
- 分配规则、码本、预算、导出、E16×H16 装配一律不动；树内无绝对路径；`/tmp` 不落产物。
- 一个候选只跑一次正式训练（§19g）：seed 42、3000 epoch、全局 batch 4096、四卡 50202；不做消融/多种子/扫描。
- 判据唯一：`test_R@10`；参照 0.05622 / 0.057905 / 成功线 0.065。
- 若本臂仍 ≤ 基线：本主线在当前禁止项下的"结构 → 几何 → 选码"通路**已无带正证据的杠杆**，应在 Issue 里记录该结论，而不是再换一个标量。
