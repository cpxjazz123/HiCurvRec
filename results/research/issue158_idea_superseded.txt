Idea：末级选码改用**平衡计划的整数取整**，而不是逐行 argmax（修正 #156/#157 的坍缩）
英文名称：Rounded Balanced Assignment for the Last Level (corrected from #156/#157)

三臂的证据把坍缩定位到同一个位置：**计划是平衡的，逐行 argmax 把它扔掉了。**

| 臂 | 做法 | 实测 |
|---|---|---|
| #150 | π 作末级列边际 | 计划 200/500 sweeps 能追到 1.3e-3 / 8e-11，但 argmax 直方图 234 码 / 1.27% 对均匀 242 / 1.07% |
| #156 | 绝对距离回归 `t=d_ref(1−u)` | Stage2 跑完即坍缩：24587 商品只剩 10 个三码，最大码 99.12% |
| #157 | 尺度无关序目标 + 展布下限 | 距离展布被拉开 48×（8.05e-6 → 3.89e-4），**硬选码反而更集中**：27/256 码、最大码 30.81% |

结论：只要最后一步是"每行各自取 argmin/argmax"，任何把同类商品拉近的潜空间压力都会让它们选中同一个码；
Sinkhorn 的列边际只约束**计划**，约束不了**硬选码**。所以要修的不是目标函数，而是**离散化那一步**。

## 一、主张（一句话）

末级仍由 Sinkhorn 求平衡计划，但把计划变成硬选码时用**保列和的整数取整**（transportation rounding，
每行取一个码、每列最多 `⌈B/K⌉` 个），使码占用按构造成立；结构监督只负责塑形计划，不再被 argmax 抹掉。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157，不改）**：尺度无关 `ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   展布下限 `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **末级离散化（本臂唯一的新机制）**：`index = round_plan(plan)`——按计划列和取整得到每列容量
   （最大余数法，总容量 = batch 行数），再按代价升序做**带容量的贪心指派**（每行恰好一个码、每列不超容量）；
   训练与导出用同一函数，导出在完整商品集上确定性执行一次。前两级仍用基线 `argmin`。
4. **保持不变**：代价函数、Sinkhorn 本体与 `SK_EPSILON=0.003` / `SK_ITERS=50` / centring、残差递推、
   读出、三 token 结构；不引入桶/掩码/π/层心平移；商品级 SID 全局一致。
5. **开关**：`ROUNDING_OFF`（退回逐行 `argmax`，与基线逐位一致）、`GEOMETRY_OFF`（`c=0` 欧氏极限）、
   `BOTH_ON`（出厂）；只要求实现正确与廉价接线检查，不训练关闭臂（§19g）。

## 三、验收（派发前，冻结 8192 行 TRAIN 探针，全部可测）

1. **占用按构造成立**：末级 `codes_used ≥ 240/256`、最大码份额 ≤ 1.5%、每码行数 ≤ `⌈B/K⌉`。
2. **取整保真**：每列行数与计划列和的偏差 ≤ 1 行，行和恰好 1；在同一 batch 上与精确求解器（小规模
   4096×256 用 Hungarian/SCS）比较总代价，相对差 ≤ 1e-3。
3. **两臂差分学习**（沿用协议）：同 seed/数据顺序/固定 200 步/训练器优化器；R 的秩一致性改善 ≥ N 的 2 倍。
4. **尺度不变性**：`d` 同时乘 0.25/4 时 `L_rank`、`L_spread` 变化 ≤ 1e-6。
5. **曲线耦合**：`c=0` 与 `c=1` 的损失值不同（欧氏极限 1e-6）。
6. **接线与一致**：`ROUNDING_OFF` 与基线逐位一致（含导出）；同一商品集上训练与导出取同一码。
7. **200 步试跑护栏**：与 #157 相同的占用与平均距离检查，必须通过（本臂预期按构造成立）。
8. **TDD**：先写会失败的测试（行和/列容量、保真偏差、`ROUNDING_OFF` 恒等、c=0 极限、训练/导出同码），
   确认红后再实现。
9. 任一门不过：按预派发负结果记录并停止，不改容量规则、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：本臂**显式申请**改动末级选码规则（`argmax` → 保列和取整），均衡分配本体仍是 Sinkhorn
  （同一 ε、同一迭代数、同一 centring）；不把均衡换成普通 `argmin`。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：取整让同一 batch 内的商品互相竞争，训练与导出若在不同集合上执行会有分布差 → 由 gate 6 与
  "导出在完整商品集上一次执行"约束；若导出与训练仍不一致，按负结果记录，不改容量规则重跑。

## 五、与前一臂的差异（必须逐条写进规格）

| 项 | #157 | 本臂 |
|---|---|---|
| 末级选码 | `plan.argmax(-1)`（逐行独立） | `round_plan(plan)`（保列和、带容量） |
| 占用 | 靠目标函数间接约束，实测 27/256 码 | 按构造成立（每列 ≤ ⌈B/K⌉） |
| 结构监督 | 尺度无关序目标 + 展布下限 | **不变** |
| 失败模式 | 码字集中 30.8% | 若仍失败，只能是"取整破坏代价或训练/导出不一致" |
