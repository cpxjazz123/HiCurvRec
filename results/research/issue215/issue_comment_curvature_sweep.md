## 第一步：冻结 Checkpoint 上的 L1 曲率扫描 × 六 Role

**先更正前提**：仓库里**没有**此前的"冻结 Checkpoint 曲率敏感性"实验——`issue144/select_geometry.py` 比的是**已训练好的五个几何臂**，
全仓也没有 `c ∈ {0,1,4,16,64,256}` 的扫描脚本或产物。所以我从头实现，并**先做可复现性校验**。

### 1. 校验（必须先过这一关）

编码器输出 `TIGER_z.npy` + 三个冻结码本（各 256×32），L1→残差→L2→残差→L3：
**c = 0 复现已发布 TIGER SID，三层逐位一致 100.00%** ⇒ 管线就是原量化器（用 `TIGER_q` 起算只有 97.8%，归一化后 0.2%）。

### 2. 曲率扫描（L2/L3 仍为欧氏，残差按新 L1 码重算）

| c | 与已发布 SID 一致率 | SID 改变比例 | 碰撞率 |
|---|---|---|---|
| 0 | **1.0000** | 0.0000 | 0.1772 |
| 1 | 0.9993 | 0.0007 | 0.1772 |
| 4 | 0.9993 | 0.0007 | 0.1772 |
| 16 | 0.9993 | 0.0007 | 0.1772 |
| 64 | 0.9993 | 0.0007 | 0.1772 |
| 256 | 0.9997 | 0.0003 | 0.1772 |

逐 Role 的 **P5 / T5 符合率与结构增益在六个曲率下三位小数完全相同**（Role 3：P5 0.577、T5 0.645、增益 0.145；Role 1：0.536 / 0.580 / 0.112）；
逐 Role 的 SID 改变比例最大只有 0.002。

### 3. 为什么没反应：把杠杆量出来

| 量 | 值 |
|---|---|
| L1 码本范数 | 0.102–0.895（均值 0.297，cv 0.562） |
| z 范数 | 均值 0.180，p95 0.348 |
| **L1 决策余量**（次优 vs 最优的相对差） | **中位 0.708**，p10 0.101，**仅 4.5% 商品余量 < 5%** |

（球尺度 × 曲率）网格上最大改变 **0.30%**（尺度 0.9、c=4）；共形因子在各码之间的变异系数 ≤ 0.15。

⇒ **训练出来的欧氏 L1 码本对每个商品都是压倒性选码**（中位余量 71%），任何有界距离重加权都翻不动它。
曲率在这个 checkpoint 上**不是可用杠杆**——不是"六个 Role 反应相同"，而是**这个实验测不到该效应**。

### 4. 结论与下一步

1. **"改 L1 曲率 → 结构符合率变化"在冻结 TIGER（E32 欧氏）上走不通**：c=1→256 只改 0.03–0.07% 商品，
   逐 Role 的 P5/T5/增益/碰撞率不变 ⇒ **无法据此判断"不同 Role 需要不同曲率"**。
2. **要检验该假设，曲率必须参与"码字如何被放置"**：(a) 在双曲几何下**训练** L1 码本（Stage2 单臂，§19g 只允许一次正式训练、不做扫描/消融）；
   或 (b) 用**测地平均**重新放置冻结码本，再在同一 Role 分组上比较结构与 recall。两条路都必须**预先固定曲率值**，不能扫描挑选。
3. **这不是对假设的否定**，而是"在当前 checkpoint 上无法测量"。
