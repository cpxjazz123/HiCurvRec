## 第二个研究问题：每种结构一个距离假设，逐个检验（只跑 TIGER）

你说的两个问题要分开记，我按这个做了：
- **§5.15（已有）**：不同局部结构里的真实行为邻居，是否距离较近？→ 是，前 1/3 张表（0.31–0.34 vs 基线 0.49）。
- **本节（新）**：不同局部结构**内部**的整体距离关系，是否符合其原始连接模式？→ 下表逐条检验。

| 结构 | 假设 | 统计量 |
|---|---|---|
| star4 | 中心→叶 < 叶↔叶 | mean(spoke) − mean(leaf,leaf) < 0 |
| path3 | 相邻 < 两端 | mean(spoke) − d(两端) < 0 |
| cycle4 | 相邻 < 对角 | mean(adjacent) − mean(opposite) < 0 |
| diamond | 唯一缺失对 > 五条边 | d(missing) − mean(edges) > 0 |
| triangle / K4 | 形成紧密群体 | 内部平均距离 − **同度数随机点集** |
| path4 | 一跳 < 两跳 < 三跳 | 三个跳数均值严格递增 |
| triangle_tail | 三角内部 < 尾→核心 | mean(internal) − mean(tail,core) < 0 |

三处方法学修正（来自前两节的教训）：**实例无放回抽样并报去重数量**（K4 在 24,587 个商品里只有 **109 个不同实例**，不是 2,000）、
**并列按 0.5 计并给自助区间**（树的距离只有 4 档，45%–81% 的实例精确并列）、**紧致性用同度数匹配点集作零模型**。

### 结论

1. **你列的六个假设里四个被 `q` 支持**：星形 70.2%、三节点路径 64.5%、四环 68.0%、三角形/Ｋ4 的紧致性 76.9% / 72.5%
   （紧致性效应最大：−0.37 / −0.35 sd）。
2. **菱形假设被拒绝**（41.0%，均值 −0.063 sd）：唯一缺失对**不更远，反而略近**。原因：那对节点虽隔两步，却同处一个稠密四元组
   （共享两个邻居），**簇归属压过跳数**——正是你提醒的"连接模式不保证几何规律"。
3. **"距离随跳数单调增长"被拒绝**：一跳<两跳 73.5%、两跳<三跳只有 56.5%、三段严格递增 44.9%，但平均距离确实随跳上升（+0.258 sd）
   ⇒ **趋势对、严格式不成立**。
4. **树方向一致、强度低一个量级**（0.54–0.59 vs 向量 0.65–0.77），且菱形与 path4 在树上同样被拒绝。
