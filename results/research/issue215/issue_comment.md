## 交付：ORCA 角色驱动的曲率量化，四臂对照（Stage2 + Stage3 完成）

### 机制（唯一的量化改动）

32 维 = E16 + 曲率 16。E16 块不动；曲率半边同时按三种几何打分，再按每行权重混合：

```
D_ik = 2 * ( alpha * ||r_E - e_E||^2 + (1-alpha) * C_ik / 4 )
C_ik = s_E * w_E,i * d_E^2 + s_H * w_H,i * d_H^2 + s_S * w_S,i * d_S^2
```

`d_E` 切空间欧氏；`d_H` 基线自己的双曲分支（Poincaré，`expmap0` + `squared_distance`）；`d_S` 球面测地距离平方，切向量按球面指数映射映入高一维的单位球面嵌入（`exp_0(v) = (sin|v| v/|v|, cos|v|)`），距离 `acos(p·q)`。权重每行非负、和为 1；**全路由到双曲的行逐元素等于 F0 的距离**（由测试证明，不靠一次训练）。尺度 `s = (4.051757, 1.0, 11.854165)`：只用 TRAIN 划分 + 冻结 F0 checkpoint 标定，双曲保持 1。

**没有**：新增可训练参数、角色私有码本、行为 embedding 拼接、AF3 损失、正负对比/关系蒸馏损失。行为信号只通过 TRAIN 图产生的冻结 ORCA 路由进入量化。

### 对三个问题的回答

1. **角色自适应曲率本身是否提高真实 SID 前缀保留率？** **是**：C 的 prefix@1 = 0.1788，比 F0 高 **21%**（prefix@2 +8%、prefix@3 +4%），逐角色剖面一致。
2. **是否相对全局几何与同分布乱序路由有增益？** **顺序对、幅度小**：Stage3 上 C > B > D（比 B 高 0.28%，比 D 高 2.1%），但三者都**低于 F0** 3.3%–5.3%，也低于历史 TIGER 1.5%–3.5%。
3. **哪些结构获益/受损，是否转化为推荐增益？** SID 侧 C 在所有角色上都比 F0 保得多；**但没有转化为推荐增益**（recall −3.3%）。图级解释：行为邻居在向量空间里本来就比同角色随机对更远（AUC 0.28–0.39），而向量空间对**稠密 hub / 星形**表达相对最好、对**紧密社区 / 两跳**最差——恰与 SID 级指标奖励的方向相反。token 级"撞在一起"与"关系表达得好"不是一回事。
