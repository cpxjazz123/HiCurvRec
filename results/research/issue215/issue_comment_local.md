## 局部检验：在三角形的邻域里，真实边排得上去吗

按 owner 的设计做完了：真实行为图只作标准答案，模型只看向量。对每个真实三角形 (a,b,c)：正例是它的三条真实边；难负例是 (a,w)、(b,w)、(c,w)，其中 **w 是 b 的邻居、但不是 a 的邻居**——"一步之遥"的商品，局部模型最容易把它们当成真的。100,000 个真实三角形。

| 预测器 | 边数 > 最难负例 | **随机基线** | 边数 > 全部负例 | 三角形整体恢复 |
|---|---|---|---|---|
| 语义 768 维 | 0.161 | 0.231 | 0.161 | 0.0014 |
| TIGER z / q | 0.182 / 0.193 | 0.231 | 0.182 / 0.193 | 0.0008 / 0.0009 |
| F0 z / q | 0.173 / 0.175 | 0.231 | 0.173 / 0.175 | 0.0023 / 0.0014 |
| B z / q | 0.197 / 0.186 | 0.231 | 0.197 / 0.186 | 0.0022 / 0.0026 |
| C z / q | 0.161 / 0.156 | 0.231 | 0.161 / 0.156 | 0.0017 / 0.0021 |
| D z / q | 0.190 / 0.189 | 0.231 | 0.190 / 0.189 | 0.0016 / 0.0015 |

随机基线 = 每个三角形按实际负例个数算的无信息期望（3/(k+1) = 0.231）。

**三条结论**

1. **局部尺度上模型全部低于随机水平**（0.156–0.197 对 0.231）：面对"一步之遥"的难负例，模型更常把**非边**排在真实边之前。§5.8 的全局 AUC 0.75 主要来自**流行度/度数**结构，而不是"知道哪些商品有关系"——这也解释了 §5.9 的预测图为什么几乎不含真实三角形边（每条三角形的 3 条边只占 0.001–0.002）。
2. **哪些局部结构最难恢复**（"边数 > 最难负例"的取值范围）：**紧密社区 0.106–0.138、两跳/扇出 0.113–0.169** 最难；**稠密 hub 0.157–0.198、星形/链状 0.161–0.207** 最接近随机。这与 §5.7（角色不可预测）、§5.2（逐角色保留度）是同一张图的三种读法：**社区与两跳既是 SID 级指标奖励的地方，也是向量最读不出来的地方** —— 这正是 C 把几何押在这里却没有换来 recall 的原因。
3. **量化在局部尺度上没有一致影响**（B、C 降约 0.01，F0 升 0.002，D 基本不变）⇒ 与全局口径同一结论：量化的代价很小，但这个尺度上分不出臂。

**方法上的两条教训（已写进报告）**：① 从排序建图**不能**用固定 top-k（度数剖面被钉死，11 张图结构一模一样 ⇒ ORCA 对照没有区分力）；② 全局 AUC 与局部排序**必须一起报**：前者 0.75 的信号在局部被流行度反转。
