## 按两轮代码审查修正并按 67 臂重算（issue 已关闭，此处补记）

两轮审查共 10 处问题，全部修正；脚本为 `analysis_sid_recall/analysis.py` 与 `structure_retention.py`。

### 第一轮（局部结构与统计口径）
| 问题 | 修正 |
|---|---|
| K4+尾固定取前三个核心节点 | 实例保存**实际分组**（含挂点位置），打分按实例分组取距离 |
| K2,3 未检查同侧额外边 | 同侧必须是**独立集** |
| T5 未排除尖端与另两个分支的边 | 尖端只接触一个分支 |
| K5 两侧比较规则不同 | 统一为"与每个随机组逐一比较再平均"，零模型对称 =0.5 |
| 跳过实例导致编号错位 | 保留槽位（NaN）+ NaN 感知聚合，并打印不可用零模型数 |
| 各模型用不同 CV 划分 | **固定划分计划**，全模型/去一角色/置换共用 |
| 距离候选未匹配且可能抽到邻居 | 从锚点的**度数×流行度单元**抽取，排除自身与邻居 |

### 第二轮（角色构建）
| 问题 | 修正 |
|---|---|
| `overlap` 在邻居 <2 时填 **1.0（最大值）** | 改为**未定义→用已定义均值 0.0237 填补**；`--overlap-mode old` 仅复现旧表 |
| NMF 标准化后截断负值未说明 | 保留为默认，新增 `--nmf-scaling shift` |
| `argmax(W)` 未处理分量尺度 | 新增 `--normalise-components`，用 ARI 报告差异 |
| 缓存只按节点数判定 | 缓存键改为**指纹**（邻接+orbit 字节+overlap 模式+NMF 设置） |
| 31 个商品无角色 | 输出 `items_without_a_role: 31`（无行为边，不进入统计） |
| 角色解释不准 | 只描述可测的不变量与图式参与率，不再把角色等同于某类结构 |
| 指标被误读 | docstring 明确：这是**每角色行为边的 SID 前缀共享率**，不是逐图式距离判据 |

### 结论
1. **"结构增益预测 recall"成立且稳健**（ρ 0.575–0.681、r 最高 0.861，p ≤0.001）。
2. **"只有一组角色有独立贡献"成立**，仍是 Role 3，且幅度更大（+0.176）。
3. **前缀型指标仍明显更弱**（总体 +0.281），但**逐角色排序改变**（旧 Role 2 最强 → 新 Role 3）。
4. **两条新限制**：角色边界对 `overlap` 填补敏感（ARI 0.264）、对 NMF 分量尺度敏感（ARI 0.436）——但被识别为最有信息的那组在三种口径下都指向同一批商品。
