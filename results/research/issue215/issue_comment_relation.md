## 按 owner 的方法链补做：关系可预测性 → 建图 → ORCA

### 1) 小模型读"关系"，而不是距离

输入两个商品向量的 `[u−v, u⊙v]`（对交换两商品不变，模型不能靠记商品身份取巧），标签是两者在 TRAIN 行为图里是否相连；训练用 80% 的关系，评估用**模型没见过的关系**。负样本两种：随机配对、**度数匹配**配对（随机非边天然远，会让任何模型都显得好）。评估两种切分：关系级、商品级（1/5 商品整体不参与训练）。

| 预测器 | 度数匹配·关系级 AUC | 度数匹配·商品级 | 随机·关系级 | 随机·商品级 |
|---|---|---|---|---|
| 语义 768 维（上限参照） | 0.7670 | 0.5134 | 0.8477 | 0.6477 |
| TIGER z → q | 0.7519 → 0.7479 | 0.6599 → 0.6503 | 0.8024 → 0.7971 | 0.7440 → 0.7315 |
| F0 z → q | 0.7520 → 0.7463 | 0.6816 → 0.6783 | 0.8011 → 0.7909 | 0.7477 → 0.7413 |
| B z → q | 0.7518 → 0.7468 | 0.6791 → 0.6860 | 0.8004 → 0.7917 | 0.7526 → 0.7555 |
| C z → q | 0.7526 → 0.7452 | 0.6780 → 0.6742 | 0.8007 → 0.7903 | 0.7475 → 0.7416 |
| D z → q | 0.7509 → 0.7436 | 0.6688 → 0.6670 | 0.7996 → 0.7888 | 0.7439 → 0.7376 |

- **行为关系确实能从商品向量里恢复**（关系级 AUC ≈ 0.75，度数匹配；随机负样本 0.80）。此前"结构不在向量里"的结论只对**局部结构角色**成立，对**关系**不成立（角色不可预测，见下）。
- **量化要付一点代价，但很小**：AUC 掉 0.004–0.011。
- **五个臂的量化前向量彼此等价**（0.751–0.753）⇒ 臂与臂在"关系可恢复性"上**同样不可分辨**。
- 商品级上 **RQ-VAE 的几何远胜原始语义 embedding**（0.68 对 0.51，语义几乎等于随机）：学到的几何比语义相似更能外推到没见过的商品。

### 2) 用预测的连接建图 → ORCA 描述它

每商品取模型评分最高的 13 个伙伴（= 行为图的每商品平均伙伴数），11 张图各 319,5xx 条边。

**结果要照实说**：11 张图的 ORCA 结构**几乎完全一样**（orbit ρ 0.0008–0.0079，degree ρ ≈ 0.010，逐角色度数重分配完全一致）——因为"每商品固定 13 个伙伴"把度数剖面**钉死**了，这是构造方式的产物，**这个对照没有区分力**。而且这些图只覆盖 64,727 条未见行为边中的 55–66 条（0.08%–0.10%），随机 31.9 万条边大约能覆盖 34 条 ⇒ **模型评分最高的对不是行为邻居，是流行度驱动**。

**结论**：排序是真的（AUC 0.75），但**从排序里建图不能用固定 top-k**；要按概率**阈值**取到与行为图同样的边数（让度数自由），或按预测概率**采样**（保留排序、让度数自己长出来）。这两种做法下 ORCA 的结构对照才有区分力。

### 3) 与此前结论的关系

§5.7：**局部结构角色**无法从向量里读出（角色准确率都在多数类基线 0.5246 上下，轨道回归 R² 全负）；本节：**行为关系**可以读出（AUC 0.75）。两者不矛盾——向量里没有"我是哪种角色"这种标签，但有"我和谁有关系"这种可排序的信号。§5.1 的 Stage3 负结果因此仍然成立：几何按一个向量自己都预测不出的标签去路由，Recall 不可能因此变好。
