## 2. 机制（唯一的量化改动）

32 维 = E16 + 曲率 16。E16 块不变。曲率半边同时按三种几何打分，再按每行权重混合：

```
D_ik = 2 * ( alpha * ||r_E - e_E||^2 + (1-alpha) * C_ik / 4 )
C_ik = s_E * w_E,i * d_E^2 + s_H * w_H,i * d_H^2 + s_S * w_S,i * d_S^2
```

- `d_E`：切空间欧氏距离（曲率块不做 expmap）。
- `d_H`：基线自己的双曲分支（Poincaré 球，`expmap0` + `squared_distance`）。
- `d_S`：球面测地距离的平方；切向量按球面指数映射映入高一维的单位球面嵌入
  （`exp_0(v) = (sin|v| v/|v|, cos|v|)`），距离是 `acos(p·q)`。
- 权重每行非负、和为 1；双曲权重为 1 的行**逐元素等于 F0 的距离**（由测试证明，不是靠一次训练）。
- 尺度 `s = (4.051757, 1.0, 11.854165)`：只用 TRAIN 划分 + 冻结 F0 checkpoint 标定，三分支均值距离对齐；双曲保持 1。

**没有**：新增可训练参数、角色私有码本、行为 embedding 拼接、AF3 损失、正负对比/关系蒸馏损失。
行为信号只通过 TRAIN 图产生的冻结 ORCA 路由进入量化。

### 5.2b 三图实验测的是什么（以及它不测什么）

三图实验问的是"行为图与向量近邻图有多相似"。**行为相连不等于语义相似**：手机与手机壳常有共同购买的行为边，但手机与另一款手机在语义空间里更近。因此"向量没有把行为邻居放近"**不能**推出"这条行为关系丢了"——三图实验衡量的是两张图的相似度，不是结构保留量。真正对应研究目标的是 §5.7 的可预测性实验。

### 5.10 owner 的局部检验：在三角形的邻域里，真实边排得上去吗（100,000 个真实三角形）

真实行为图只作标准答案，模型只看向量。对每个真实三角形 (a,b,c)：正例是它的三条真实边；难负例是 (a,w)、(b,w)、(c,w)，其中 **w 是 b 的邻居、但不是 a 的邻居**——"一步之遥"的商品，局部模型最容易把它们当成真的。指标：三角形的 3 条真实边里，有几条排在**最难的那个负例**之前；以及三角形是否整体恢复。

| B_q | 0.186 | 0.231 | 0.186 | 0.0026 |
| B_z | 0.197 | 0.231 | 0.197 | 0.0022 |
| C_q | 0.156 | 0.231 | 0.156 | 0.0021 |

**结论（三条）**

1. **局部尺度上，模型全部低于随机水平**（0.156–0.197 对 0.231）：面对"一步之遥"的难负例，模型反而更常把**非边**排在真实边之前。§5.8 的全局 AUC 0.75 主要来自**流行度/度数**结构，不是真正的关系判别力——这正是 §5.9 的预测图几乎不含真实三角形边（每条三角形的 3 条边只占 0.001–0.002）的原因。

1. **SID 树不是没有结构信息，而是它表达的关系方向与我们原先假设的相反**：共享前缀越多，**越不可能**是直接行为连接。原因是可解释的——RQ-VAE 的目标是**重建语义**，被放进同一分支的是**可替代**的商品（同类手机），而行为边连接的是**互补**商品（手机与手机壳）。
2. 这与 §5.11/§5.10 并不矛盾，而是同一件事的两面：向量把"语义相近"做成了"距离近"，而行为关系是语义互补的，所以语义近的负样本比语义远的真边还近。
3. **因此下一步不该改几何、也不该立刻改码本目标**：先做两件更小的事——(a) 用**可替代性**而不是 ORCA 角色来做几何路由的对照（角色是结构标签，替代性是树的直接读出）；(b) 若仍要动目标，正确的方向是让码本把**互补**商品放到一起（这属于新机制，需另开 issue）。

| 运行 | `test_recall@10` | `recall@5` | `ndcg@10` |
|---|---|---|---|
| TIGER 规范 SID，登记值 | 0.056216 | — | — |
| TIGER 规范 SID，**本次重跑** | **0.054719** | 0.036230 | 0.029815 |

**同一份 SID、同一套协议，两次运行相差 0.0015（2.7%）**。这把尺子直接决定了本 issue 的可判定范围：

- C − B = 0.000157（0.28%）⇒ **小于同 SID 重跑噪声的 1/9**；
- B − D = 0.000958（1.7%）⇒ 与噪声同量级；
- C − D = 0.001114（2.1%）⇒ 与噪声同量级；
- 三臂相对 F0 的 −3.3% ~ −5.3% ⇒ **大于噪声，但 TIGER 规范 SID 自己的重跑也落在 −2.7%，即"换一个 SID 重跑"能解释掉一半以上的差距**。

所以本 issue 的判定是：**C > B > D 的顺序与假设一致，但每一对之间的差距都在同一协议自身的重跑波动之内；唯一稳健的结论是"三臂都没有超过 F0"。** 要把 C 与 B 的 0.28% 说成机制效应，需要多 seed 复验，本 issue 明确不做这个主张。

（同一份 SID 的另一次历史运行落在 0.040199，那个记录是错的，已删除并在账本标注原因——见 §4b。）

### 5.5 对 issue 三个问题的回答

1. **角色自适应曲率本身是否提高真实 SID 前缀保留率？** **是**。C 的 prefix@1 = 0.1788，比 F0 的 0.1479 高 **21%**，prefix@2 +8%、prefix@3 +4%；逐角色剖面一致，说明这不是"偏向某种结构"的结果，而是整体拟合更好。

3. **哪些结构获益/受损，是否转化为推荐增益？** SID 侧 C 在所有角色上都比 F0 保得多；但**没有转化成推荐增益**（recall −3.3%）。图级解释：行为邻居在向量空间里本来就比同角色随机对**更远**（AUC 0.28–0.39），而向量空间对**稠密 hub / 星形**表达得相对最好、对**紧密社区 / 两跳**最差——恰好与 SID 级指标奖励的方向相反。token 级"撞在一起"与"关系表达得好"不是一回事。

## 5.13 重新设计：结构内部的相对距离模式（owner 2026-11-14 修正）

owner 指出前一批实验问错了问题：判据不是"模型能否预测 A 与 B 之间有行为边"，而是
**对原始行为图里的某一种局部结构，量化后的商品向量与 SID 树能否表达该结构内部多个商品之间的相对距离关系**。
行为图只负责给出"哪些商品构成某个结构、各自处在什么位置"，不负责给出"谁应该更近"的答案。
实验按这个口径重写过一遍（`relative_distance_patterns.py`，只跑 TIGER，owner 2026-11-14：只做 TIGER），
每个结构取 4,000 个实例；六种表示全部换算成**距离**（越小=越近），并按各自的距离尺度标准化：

| 表示 | 定义 |
|---|---|
| `z` | 量化前的向量（目标 A 的参照） |
| `q` | 量化后的向量，欧氏距离 |
| `sid` | SID 树当**接近性**：`d = 1 − lcp/3` |
| `sid_rev` | SID 树当**差异**：`d = lcp/3`（`sid` 的严格补，τ 必然反号） |
| `fused` | 标准化后的 `q + sid` |
| `fused_rev` | 标准化后的 `q + sid_rev` |

### 5.13.1 目标 A：结构内部的相对距离是否被保留（对 `z` 的 Kendall τ）

| 结构 | `q` | `sid` | `fused` | `fused_rev` |
|---|---|---|---|---|
| path3 | **+0.770** | +0.173 | +0.767 | +0.543 |
| triangle | **+0.758** | +0.195 | +0.748 | +0.494 |
| path4 | **+0.778** | +0.253 | +0.776 | +0.593 |
| star4 | **+0.781** | +0.277 | +0.778 | +0.577 |
| cycle4 | **+0.765** | +0.286 | +0.763 | +0.551 |
| triangle_tail | **+0.776** | +0.308 | +0.773 | +0.541 |
| diamond | **+0.755** | +0.327 | +0.751 | +0.504 |
| K4 | **+0.756** | +0.539 | +0.733 | +0.200 |

- **量化保留 ~76% 的相对距离排序**（0.755–0.781，八个结构几乎一致）⇒ 量化不是一个"破坏结构内部顺序"的步骤。
- **SID 树保留得少得多**（0.17–0.54）：`path3` 只有 0.173，`K4` 最高 0.539 ⇒ 树不是向量几何的替代品。
- **融合没有增益**：`fused` 在每个结构上都等于 `q`（差 ≤0.005）⇒ 加进树的接近性不改变内部排序；`fused_rev` 更差（0.20–0.59）。

### 5.13.2 目标 B：各结构自己的签名统计量（单位 = 该表示自身距离分布的标准差；括号内为统计量 > 0 的实例占比）

| 结构 | 统计量 | `q` | `sid` | `fused` |
|---|---|---|---|---|
| path3 | mean(中心→两端) − d(两端) | −0.076sd (66%) | −0.190sd (97%) | −0.164sd (66%) |
| star4 | mean(中心→叶) − mean(叶↔叶) | −0.058sd (70%) | −0.198sd (93%) | −0.157sd (68%) |
| cycle4 | mean(相邻) − mean(相对) | −0.067sd (66%) | −0.076sd (91%) | −0.088sd (67%) |
| triangle_tail | mean(三角内部) − mean(尾→三角) | −0.186sd (51%) | −0.220sd (88%) | −0.250sd (53%) |
| diamond | d(唯一缺失对) − mean(五条边) | +0.053sd (55%) | +0.099sd (31%) | +0.094sd (63%) |

### 5.13.3 结论

1. **结构内部的距离模式主要是"步数"模式，没有额外的结构语义**：所有结构的效应量都在 0.25 sd 以内，方向都是"一跳更近、两跳更远"。
   owner 提出的"四环里相对节点可能更近"**不成立**：`q` 在 66% 的环里把相邻节点放得更近，树在 91% 的环里也如此。
   star 的"叶子彼此更近"同样不成立（叶↔叶比中心→叶更远：`q` −0.058sd / 树 −0.198sd）。
2. **树与向量在方向上一致、在量级上不同**：树的 `path3`/`star4` 效应量更大（−0.19/−0.20 sd vs −0.08/−0.06），但那是因为树的距离只有 4 个离散档（共享前缀即坍缩到 0），
   它的**整体排序一致性只有向量的 1/4**（τ 0.17 vs 0.77）。所以"树的效应量大"不等于"树表达得更好"。
3. **树会打散团块，量化向量会压紧团块**：`K4` 六条边的距离离散度在 `q` 里 0.423、在树里 **1.016**（近乎整个取值范围）⇒ 一个 4-团在树里被切成"
   有共享前缀的"和"没有共享前缀的"两半，在量化向量里则是一团。这与 §5.12 的"树的信号方向相反"一致。
4. **因此"量化是否破坏结构信息"这个问法在本数据上没有对象**：量化保留了 76% 的内部排序，而树本身只保留了 17–54%，两者都没有"另一个结构语义"可被破坏。
5. **被 owner 修正取代的那批实验**（`tree_attention_recoverability.py`，边的二分类准确率）回答的是被放弃的问题，仅作为留档；其中第一版的 `random` 对照是假的
   （`train_variant` 内部按 SID 表重建了 partners，把随机伙伴覆盖了；两个变体数字逐位相同即为证据），已修正为"partners 在 main 里按变体决定"并从命令行选臂。

**边界**：单次采样（seed 42）、单臂（TIGER）、无多个随机种子 ⇒ 上述效应量的符号与量级都只对本次采样成立；
"没有结构语义"这一结论的强度受限于 4,000 实例/结构的统计噪声（效应量 ≤0.25 sd 时，需要更多实例才能排除更小的效应）。

## 5.14 结构距离对齐（owner 2026-11-14 指定的判据，只跑 TIGER）

### 5.14.4 结论

   最强是 diamond（0.793）、triangle（0.760）、star4（0.758），最弱是裸边（0.680）与 K4（0.700）。

   **"行为邻居就是最近邻"这件事在本数据上不发生**；`q` 只是把邻居从随机位置提到 20% 分位，不是提到顶端。
5. owner 的限定成立：本指标只度量**行为邻居的距离对齐**，不等于星形/环/团整体被重建；§5.13 的步数模式与本节一致。
