## 1. 问题与不可回避的对照

历史臂 #181/#209/#210 的负结果都是"全局或逐商品地改曲率代价"。本 issue 只问一个更窄的问题：
**在不加任何图关系损失的前提下，把 ORCA 结构角色接到量化几何上，是否比全局几何、或比同分布的随机路由更好？**

因此四臂只差一个变量——路由：

| 臂 | 树 | 路由 | 训练 |
|---|---|---|---|
| A | `TIGER_mixed_rq_F0` | 冻结 F0（全部双曲） | **不训练**，用已有冻结 SID/Stage3 结果 |
| B | `TIGER_role_geom_global_rq` | 全部商品同一组权重（三分支的人口加权均值） | 3000 epoch，seed 42，global batch 4096 |
| C | `TIGER_role_geom_rq` | 按冻结 ORCA 角色选几何 | 同上 |
| D | `TIGER_role_geom_shuffled_rq` | 与 C 相同，但角色在商品间按 seed=42 置换 | 同上 |

- **C vs B**：局部适配是否优于全局平均。
- **C vs D**：真实结构标签是否优于同分布随机路由。
- **C vs A**：是否实际超过 F0。

## 2. 机制（唯一的量化改动）

32 维 = E16 + 曲率 16。E16 块不变。曲率半边同时按三种几何打分，再按每行权重混合：

```
D_ik = 2 * ( alpha * ||r_E - e_E||^2 + (1-alpha) * C_ik / 4 )
C_ik = s_E * w_E,i * d_E^2 + s_H * w_H,i * d_H^2 + s_S * w_S,i * d_S^2
```

- `d_E`：切空间欧氏距离（曲率块不做 expmap）。
- `d_H`：基线自己的双曲分支（Poincaré 球，`expmap0` + `squared_distance`）。
- `d_S`：球面测地距离的平方；切向量按球面指数映射映入高一维的单位球面嵌入
  （`exp_0(v) = (sin|v| v/|v|, cos|v|)`），距离是 `acos(p·q)`。
- 权重每行非负、和为 1；双曲权重为 1 的行**逐元素等于 F0 的距离**（由测试证明，不是靠一次训练）。
- 尺度 `s = (4.051757, 1.0, 11.854165)`：只用 TRAIN 划分 + 冻结 F0 checkpoint 标定，三分支均值距离对齐；双曲保持 1。

**没有**：新增可训练参数、角色私有码本、行为 embedding 拼接、AF3 损失、正负对比/关系蒸馏损失。
行为信号只通过 TRAIN 图产生的冻结 ORCA 路由进入量化。

### 5.2b 三图实验测的是什么（以及它不测什么）

三图实验问的是"行为图与向量近邻图有多相似"。**行为相连不等于语义相似**：手机与手机壳常有共同购买的行为边，但手机与另一款手机在语义空间里更近。因此"向量没有把行为邻居放近"**不能**推出"这条行为关系丢了"——三图实验衡量的是两张图的相似度，不是结构保留量。真正对应研究目标的是 §5.7 的可预测性实验。

### 5.7 结构角色还能从向量里读出来吗（可预测性实验）

用商品自己的向量预测它在**行为图**里的结构：73 维 ORCA 轨道计数（外加 degree、clustering），以及它的六角色分类。预测器是同一个小 MLP（32→128→128→输出）、同样的 5 折划分（seed 42）、同样的训练量；唯一变化的是喂进去的向量：量化前的 `z`、模型自己的量化读出 `z_q`；768 维语义 embedding 用同样方式拟合，作为**上限参照**。

| 预测器 | orbit ρ | orbit R² | degree ρ | clustering ρ | 角色准确率 | 角色 macro-F1 |
|---|---|---|---|---|---|---|
| 语义 768 维（上限参照） | +0.0259 | −0.389 | +0.018 | +0.035 | 0.5151 | 0.1956 |
| TIGER z → q | +0.0245 → +0.0116 | −0.489 → −0.904 | +0.024 → +0.010 | +0.043 → +0.052 | 0.5245 → 0.5265 | 0.1312 → 0.1386 |
| F0 z → q | +0.0157 → +0.0147 | −0.344 → −0.382 | +0.021 → +0.021 | +0.052 → +0.054 | 0.5230 → 0.5238 | 0.1219 → 0.1222 |
| B z → q | +0.0155 → +0.0243 | −0.557 → −0.508 | +0.026 → +0.031 | +0.049 → +0.063 | 0.5236 → 0.5237 | 0.1265 → 0.1257 |
| C z → q | +0.0272 → +0.0208 | −0.452 → −0.514 | +0.029 → +0.031 | +0.053 → +0.056 | 0.5228 → 0.5228 | 0.1215 → 0.1228 |
| D z → q | +0.0222 → +0.0128 | −0.325 → −0.422 | +0.017 → +0.014 | +0.051 → +0.049 | 0.5237 → 0.5250 | 0.1260 → 0.1287 |

**多数类基线（角色 5 占 12,881/24,556）= 0.5246。**

三条结论：

1. **商品的结构角色基本无法从它自己的向量里读出来**：所有预测器的角色准确率（0.5151–0.5265）都在多数类基线 0.5246 上下，macro-F1 最高也只有 0.196（6 类随机 F1 ≈ 0.167）。**语义 embedding 同样如此**（0.5151）——行为图的局部结构既不在语义里，也不在 RQ-VAE 的向量里。
2. **因此"量化破坏了结构信息"这个说法在这里没有对象**：轨道回归的 R² 全为负（−0.33 ~ −0.90，即比直接预测均值还差），orbit ρ 只有 0.01–0.03。量化前后都没有可恢复的结构信号，所以量化的作用无从测量——**C 的几何按一个向量自己都预测不出的标签路由，Recall 不可能因此变好**，这与 §5.1 的负结果一致。
3. **唯一可分辨的差异是 degree**：路由臂的向量带着略强的度信号（C 0.029/0.031、B 0.026/0.031，对 F0 的 0.021/0.021）——几何确实知道哪些商品是 hub；但量级只有 ρ≈0.03。TIGER 的量化读出最差（R² −0.904）。

### 5.4 TIGER 的规范 SID 重跑，以及这把尺子

归档里那份 TIGER_RQ-VAE 的 SID（sha `53273cb6…`，登记 recall 0.056216）被放进 `results/stage2_RQ-VAE/TIGER_RQ-VAE__canonical/`，用**同一套冻结协议**（150 epoch / NO_EVAL / SEED 42 / BEAM 20 / n_eval 57,439）重跑：

| 运行 | `test_recall@10` | `recall@5` | `ndcg@10` |
|---|---|---|---|
| TIGER 规范 SID，登记值 | 0.056216 | — | — |
| TIGER 规范 SID，**本次重跑** | **0.054719** | 0.036230 | 0.029815 |

**同一份 SID、同一套协议，两次运行相差 0.0015（2.7%）**。这把尺子直接决定了本 issue 的可判定范围：

- C − B = 0.000157（0.28%）⇒ **小于同 SID 重跑噪声的 1/9**；
- B − D = 0.000958（1.7%）⇒ 与噪声同量级；
- C − D = 0.001114（2.1%）⇒ 与噪声同量级；
- 三臂相对 F0 的 −3.3% ~ −5.3% ⇒ **大于噪声，但 TIGER 规范 SID 自己的重跑也落在 −2.7%，即"换一个 SID 重跑"能解释掉一半以上的差距**。

所以本 issue 的判定是：**C > B > D 的顺序与假设一致，但每一对之间的差距都在同一协议自身的重跑波动之内；唯一稳健的结论是"三臂都没有超过 F0"。** 要把 C 与 B 的 0.28% 说成机制效应，需要多 seed 复验，本 issue 明确不做这个主张。

（同一份 SID 的另一次历史运行落在 0.040199，那个记录是错的，已删除并在账本标注原因——见 §4b。）

### 5.5 对 issue 三个问题的回答

1. **角色自适应曲率本身是否提高真实 SID 前缀保留率？** **是**。C 的 prefix@1 = 0.1788，比 F0 的 0.1479 高 **21%**，prefix@2 +8%、prefix@3 +4%；逐角色剖面一致，说明这不是"偏向某种结构"的结果，而是整体拟合更好。
2. **是否相对全局几何与同分布乱序路由有增益？** **顺序对、幅度小**。Stage3：F0 0.05728 > C 0.05538 > B 0.05522 > D 0.05427。C 比 B 高 **0.28%**，比 D 高 **2.1%**；但三者都**低于 F0** 3.3%–5.3%，也低于历史 TIGER 1.5%–3.5%。
3. **哪些结构获益/受损，是否转化为推荐增益？** SID 侧 C 在所有角色上都比 F0 保得多；但**没有转化成推荐增益**（recall −3.3%）。图级解释：行为邻居在向量空间里本来就比同角色随机对**更远**（AUC 0.28–0.39），而向量空间对**稠密 hub / 星形**表达得相对最好、对**紧密社区 / 两跳**最差——恰好与 SID 级指标奖励的方向相反。token 级"撞在一起"与"关系表达得好"不是一回事。

**更正**：本报告早期版本把 C 的 `test_ndcg@5 = 0.025029` 误记为 ndcg@10；C 的 `ndcg@10 = 0.030678`。
