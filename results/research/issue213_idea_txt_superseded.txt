## 1. 目标

用**冻结的 Stage3 协议**对**同一个固定 SID** 重跑一次，量出协议自身的非确定性量级 `Δ_same_sid`，从而判定本线十二个臂的差值（0.2%~1.9%）是否可分辨。

可判定形式：给出一个实数 `Δ_same_sid = |recall_new − recall_ref|`，并与 `F0 − 历史基线 = 0.001062` 比较。

## 2. 假设

- **H**：Stage3 的同一 SID 重跑方差显著小于臂间差值（`Δ_same_sid < 0.0004`，约 0.7%），因此"F0 比历史基线高 1.9%"可分辨，而 ≤0.3% 的差别属噪声。
- **可反驳**：若 `Δ_same_sid ≥ 0.001062`，则本线全部臂间排序不可分辨，F0 的 +1.9% 必须降级为"未超出协议噪声"。

## 3. 参照与起点

```
F0（主参照）  = 0.057278156      # TIGER_mixed_rq_F0；SID sha256 afa89a10b1b197a7b56da4ad322c6ddd96a3c26c04238af326d88747378bb848
历史基线      = 0.056216         # 出处 results/stage3_T5Train/_reference_baseline_deterministic/logs/Amazon_2023_Instruments/Nov-07-2026_15-47-31/test_final.json
禁令族        = 0.064764         # r48k2，未解禁
成功线        = 0.065
差值门槛      = 0.001062         # 0.057278156 − 0.056216
```

- 被测 SID：`results/stage2_RQ-VAE/TIGER_mixed_rq_F0/item_sids.json`（`results/stage2_RQ-VAE/TIGER_mixed_rq/item_sids.json` **不存在**，见 `cca82cf4`）。
- 参照读数：同 SID 的既有运行 `0.057278155956754125`（`.../TIGER_mixed_rq_F0/logs/Amazon_2023_Instruments/Nov-09-2026_08-07-21/test_final.json`）。

## 4. 做法（唯一变量：运行，而非代码）

1. 输入 SID 不变、`SEED=42` 不变、协议常量不变（150 epoch、`EVAL_INTERVAL=5`、`EVAL_START_EPOCH=75`、`EARLY_EVAL_EPOCHS=(25,50,75,100,125)`、`BEAM_SIZE=20`、`NO_EVAL=True`、`SKIP_TEST=False`、端口 50201）；
2. 仅**重新执行**一次，记录 `test_recall@10/@5`、`ndcg@10/@5`；
3. 与参照读数求差得 `Δ_same_sid`；
4. **不改**任何 Stage2/Stage3 源码、不改超参、不产生新 SID、不动历史结果。

## 5. 开关与接线

无机制开关（诊断不引入新代码路径）。仅要求：运行配置与冻结协议**逐项相同**——以 `HG_Rec.log` 第 1 行的 `Configuration:` 与冻结协议常量对照，机器断言一致。

## 6. 预注册（收线/判读，先写下）

```
Δ_same_sid ≥ 0.001062  ⇒ 臂间不可分辨：结案文件须写明"此前排序仅描述性，F0 的 +1.9% 未超出协议噪声"
Δ_same_sid < 0.0004    ⇒ F0 的 +1.9% 可分辨；≤0.3% 的差别属噪声
0.0004 ≤ Δ < 0.001062  ⇒ 部分可分辨：只允许"F0 > 历史基线"这一条结论，其余排序不得主张
```

只跑这一次，不重复、不换 seed、不做多种子扫描。

## 7. 验证要求（交付前必须逐条满足）

1. 输出齐全：`test_final.json`、`HG_Rec.log`、`training_metrics.jsonl`；

4. 报告给出 `Δ_same_sid` 与 `Δ(F0)`／`Δ(历史基线)` 三者的并列表；
5. 若判为不可分辨，**必须**在 `results/research/line_closure/line_closure_2026-11-12.md` 追加"噪声标定"行及影响；

## 8. 预期与反证

- **预期**：`Δ_same_sid` 在 1e-4 量级（AMP/cuDNN/beam 实现差异），即 `Δ < 0.0004`，F0 的 +1.9% 站得住。
