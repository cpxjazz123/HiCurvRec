Idea：双侧配额 + 向量化贪心**直接派发**；代价质量降为诊断，改用"偏好保真度"作门（修正 #169）
英文名称：Two-Sided Quotas, Dispatch with Preference Fidelity (corrected from #169)

#169 把唯一一条"提高代价质量"的路走死了：

| 形状 | `max_flow_min_cost` 实测 | 外推 1024×256 |
|---|---|---|
| 128×32×32 | 0.169 s（5280 边） | — |
| 256×64×64 | 0.970 s（20800 边） | — |
| 512×128×128 | 6.57 s（82560 边） | — |
| 1024×256 | ≈ edges^1.4 外推 | **≈45 s/层 ≈ 900× 超时**；3000 epoch 约 110 小时 |

本机没有 C 级 min-cost flow（ortools / pulp / mip 全部 import 失败，已实测），百万倍加速无望。
所以"精确指派"与"时间预算"在本环境内不可同时满足。

而 #168 已经证明：**双容量 + 向量化贪心**在未训练导出上让三条结构目标同时成立
（碰撞 0.009924、二级前缀 23616、逐层 256/256 码、份额 ≤0.43%），放宽次数 0、200 步试点全过。
缺的只是我发明的"代价质量"门——它比的是与精确解的总代价，而贪心的价值在结构不在总代价。

## 一、主张（一句话）

沿用 #168 的双容量与向量化贪心（不再追精确解），把"代价质量"从派发门降为诊断，
改用**偏好保真度**作门：被指派到"其计划首选码"的行占比 ≥ 0.9——它直接检验"指派是否仍尊重编码器的计划"，
而不是要求贪心在总代价上逼近全局最优。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **逐商品曲率（沿用 #167）**：`κ_i = (1 − u_i)/mean_frozen(1 − u)`，均值 1。
3. **两重配额（沿用 #168）**：`q_k = ⌊B/K⌋`（余数按码索引）+ `r_g = ⌈n_g/K⌉`。
4. **指派（沿用 #168）**：向量化贪心（按计划质量降序 + 双容量 + 剩余行按代价补齐 + 修复步骤），`relaxations` 计数须为 0；
   **导出按块执行、块间容量独立**（#168 实现口径，如实报告）。
5. **代价质量（本臂唯一改动）**：不再要求对精确解 ≤1e-2；改为两条——
   - **偏好保真度**：`|{i : assigned_i = argmax_k plan_ik}| / B ≥ 0.9`（门）；
   - **精确解差距**：仅在 1024 行抽样上用可用求解器测一次，作为诊断写入报告（不设门）。
6. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003`/`50 sweeps`/centring、残差递推、读出、导出、三 token 结构；
   训练目标仍只有 `L_RQ`；开关 `ROUNDING_OFF`/`GEOMETRY_OFF`/`BOTH_ON`。
7. **身份**：`ARM_NAME="TIGER_two_sided_final_rq"`、`ARM_VARIANT="2SFINAL"`、`OUTER_LOOP=False`、
   `AUX_AF3=False`、`CURVATURE=1.0`；树内无绝对路径；`/tmp` 不落产物；checkpoint 绑结构表 SHA 与 κ 表 SHA。

## 三、验收（派发前，全量导出 + 冻结探针 + 200 步试点，全部可测）

1. **三条结构目标同时成立**（#168 已达成，须复测）：入口碰撞 ≤ 0.05、二级前缀 ≥ 0.9·B、逐层 256 码且份额 ≤ 1.5×均匀。
2. **偏好保真度 ≥ 0.9**（新门）；精确解差距（1024 行抽样）与"导出分块数"写入报告作诊断。
3. **双容量恒等式**：每父前缀每码 ≤ `r_g`、每码总数 ≤ `q_k`、放宽次数 = 0。
4. **时间**：全量导出 ≤ 60 s；rank-batch 指派 ≤ 0.15 s（记录 + 上限）。
5. **200 步试点**：逐层 `codes_used ≥ 240/256`、`max_bucket_share ≤ 5%`、平均前缀距离 ≥ 0.5× 初值。
6. **训练中双侧护栏**：每个评估 epoch 同时检查逐层占用与全局码使用，越界即 FAIL 停止。
7. **接线与一致**：`ROUNDING_OFF` 同模型内逐位一致（含导出）；训练/导出三级一致率 1.0；checkpoint 绑定。
8. **TDD**：先写会失败的测试（偏好保真度定义、双容量恒等式、`ROUNDING_OFF` 恒等、`c=0` 极限、训练/导出同码）。
9. 任一门不过：按预派发负结果记录并停止，不改容量规则/κ/λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 双容量指派）；Sinkhorn 本体不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：贪心指派的总代价高于最优，可能让 SID 与编码器意图偏离；**这正是 Stage3 要回答的问题**，
  由其 `test_R@10 > 0.065` 裁决；本臂不再用臆造的质量门替它作答。

## 五、与 #169 的差异（必须逐条写进规格）

| 项 | #169 | 本臂 |
|---|---|---|
| 指派 | 精确求解（900× 超时） | **向量化贪心**（#168 实现） |
| 质量门 | 对精确解 ≤1e-2 | **偏好保真度 ≥0.9**；精确差距只作诊断 |
| 时间 | 每层 ≤0.05 s（不可达） | 导出 ≤60 s、rank-batch ≤0.15 s |
| 结构三门 | 未复测 | 必须复测并同时成立 |
