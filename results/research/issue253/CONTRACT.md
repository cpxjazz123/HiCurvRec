## Local GNN and three-expert attention

Shared learned six-feature input projection and two width32 layers. Each layer is tanh(Wself h+bself+Win Ain h+Wout Aout h), where Ain[target,source]=1/indegree(target), Aout[source,target]=1/outdegree(source); empty rows are zero. Per-ego whole-node means produce two float tokens H[N,2,32] and bool mask[N,2]. Every live parameter participates at current optimizer step.

Q[3,32] independently learned with RNG initialization; shared K,V Linear32→32 and score32→32→1/tanh. Append fixed zero null token, valid exactly when both real tokens are invalid. alpha=masked_softmax_tokens(Q K(H)^T/sqrt32), shape[N,3,3]; real invalid/null-inapplicable slots exactly zero. Context=alpha V(H); w=softmax_experts(score(context)), shape[N,3], ordered curvature(-1,0,+1). No topology roles or expert-specific K/V/score. Empty N returns correctly shaped empty tensors; no valid real token uses only null and finite uniform expert scores. One valid token has alpha1 and may correctly give zero Q-gradient; discrimination tests use two unequal tokens. Permuting real tokens permutes attention, not w. behavior_off gives exactly1/3 on every route without training an ablated arm.
