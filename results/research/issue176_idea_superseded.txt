Idea：尺度稳定的 DUL（DUL-S）——对偶集和项做批归一化，β 由首轮实测量定（修正 #175）
英文名称：Scale-Stable Collision Repulsion (DUL-S, corrected from #175)

结论：**唯一性项的量级失控，且配对集合在中期塌缩**。
`L_unique` 按论文用 `mean over |P|`，于是只要残留 1–3 个高余弦对就能产生 0.016 的项，
而 `L_RQ≈1.5e-4`——唯一性项**主导目标约 100 倍**；同时 batch 内配对从 256 掉到 0，
项在中期既过大又无梯度。碰撞降了 90%，召回却掉到参照的 45%——不是方向被否定，而是权重/归一化不可移植。

## 一、主张（一句话）

保持论文的**逐对边际形式**不变，只修**量级**：把唯一性项从"对配对数取均值"改为"对 batch 商品数取均值"，
并把权重 `β_unique` 由**首轮实测量**定（让两项在起点等量级），从而让 `L_unique` 随碰撞率自然升降、
不再是少数配对主导整个目标。

## 二、公式（唯一改动处）

```
L_unique = (1/B) · Σ_(i,j)∈P relu( cos(z_i, z_j) − m )        # 分母 B = batch 商品数（原为 |P|）
β_unique = mean_epoch1(L_RQ) / mean_epoch1(L_unique)          # 首轮实测量定，之后冻结（无手动常数）
L        = L_RQ + β_unique · L_unique
P        = { i≠j, 同一 batch 内, 三级码序列全同 }；三级码 detach；m = 0.9（沿用）
```

- `m = 0.9` 沿用 #175/论文；方向性矛盾（公式中 m 越大越宽松）继续写进 docstring。
- `β_unique` 在**第一个 epoch** 用滑动均值测量（`L_RQ` 与 `L_unique` 同步累计），epoch 1 结束后固定并写入日志；
  若首轮 `L_unique` 恒为 0（无碰撞对），不静默禁用——记 `BETA_UNMEASURABLE` 并以论文 `β=2.0` 继续并标注。
- 其余一切不变：量化/残差/Sinkhorn（ε=0.003、50 sweeps、centring）/读出/导出、`L_RQ` 组成、3000 epoch、seed 42。

## 三、诊断（必须逐 epoch 记录，用于判定"项是否在起作用"）

`|P|`、`collision(batch 内)`、`cos>m` 的对数占比、`L_unique` 原始值、`β_unique`、`β·L_unique / L_RQ` 比值。
目标比值区间：**0.1–10**（等量级设计）；越界即记录、不调参。

## 四、验收（派发前，全部可测，只判结构正确性）

1. **归一化正确**：给定构造 batch，断言 `L_unique == Σ_P relu(cos−m) / B`（不是 `/|P|`）；`|P|=0` 时项为 0 且不产生 NaN。
2. **β 测量**：用固定数据跑满一个 epoch，断言 `β = mean(L_RQ)/mean(L_unique)` 与手工计算一致，且 epoch 2 起不再变化。
3. **梯度通路**：仅对 `L_unique` 反向，编码器参数收到梯度；argmin 路径不接收。
4. **一 epoch 真实入口冒烟**：损失有限、`|P|`/`β`/比值有记录、导出 SID 技术有效。
5. **TDD**：先写会失败的测试（归一化分母、β 测量与冻结、零对退化、梯度通路），确认红后再实现。
6. 1–4 任一不过：按预派发负结果记录并停止。
