Idea：结构决定**每个商品的曲率**，不再要求它决定前缀分组（换轴，来自 #165/#166 的负面结论）
英文名称：AF3-Conditioned Local Curvature (supersedes the rank-supervision branch)

四臂把秩监督这一支彻底测死，也把冲突钉在构造上：

| 臂 | 构造 | 两臂差分（越正越好） |
|---|---|---|
| #157 / #159 | 一、二层基线 `argmin`，全局秩项 | **+0.0100 / +0.0528** |
| #165 | 三层条件配额（碰撞 0.0），全局秩项 | **−0.0266** |
| #166 | 三层条件配额，组内秩项 | **−0.0426** |

#165 同时证明了另一件事：条件配额把六道门都过了——入口碰撞 **0.000000**、容量恒等式、单一实现、
尺度不变性 0.00e+00、训练护栏、训练/导出三级一致率 1.0/1.0/1.0。

结论：**"碰撞 0"（把同一父前缀下的行摊到不同子码）与"前缀共享式结构监督"在同一构造下互斥**——
配额最大化子码差异，正好抹掉秩项赖以存在的邻域。继续换比较范围没有意义（已测两遍），
必须换轴：让结构决定**度量本身**，而不是决定哪些行共享前缀。

## 一、主张（一句话）

`AF3` 决定每个商品的**局部曲率** `κ_i`：三角丰富（AF3 高）的商品用更接近欧氏（曲率更小）、
树状分支（AF3 低）的商品用更负的曲率；平均曲率保持基线 `c = 1`，配额与指派完全沿用 #165 的构造。

这样结构信号进入同一条连通通路（行为 → 曲率 → 双曲距离 → 计划 → 指派 → SID），
但不再要求"共享前缀"，因此与碰撞 0 的配额构造不冲突。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e = clip((AF3−q05)/(q95−q05), 0, 1)`，
   高/低边集、全高三角形表，SHA `017e47e9…`。
2. **逐商品曲率（本臂唯一改动）**：
   `κ_i = c0 · (1 − u_i) / mean_batch(1 − u)`，`c0 = CURVATURE = 1`；`mean_batch` 在实现里取
   **冻结表的全局均值**（不用 batch 统计，保证商品级 SID 全局一致、导出与训练同值）。
   于是 `mean(κ) = 1`，只改变分布、不改变尺度；`u` 是数据分位映射，无自由常数。
3. **其余沿用 #165**：三层均衡计划（`ε=0.003`、50 sweeps、centring 不变）、条件配额
   （第 1 层均匀；第 2/3 层按父前缀均分）、组内单一向量化贪心、父前缀三层传递、导出同路径、
   `ROUNDING_OFF`/`GEOMETRY_OFF`/`BOTH_ON` 开关。
4. **去掉的东西**：`L_rank`、`L_spread`、`L_tri` 三项**全部移除**（它们在配额构造下已实测为负向或惰性）；
   训练目标回到 `L_RQ` 基线。
5. **保持不变**：代价函数形式（`center_distance`）、残差递推、读出、导出、三 token 结构；
   商品级 SID 全局一致。

## 三、验收（派发前，全量导出 + 冻结探针，全部可测）

1. **入口碰撞 ≤ 0.05**（#165 口径实测 0.0），二级前缀 ≥ 0.5·B。
2. **容量恒等式**：每父组子码计数等于配额；行和恰 1；逐层 `codes_used ≥ 240/256`。
3. **结构灵敏度（取代两臂差分）**：把 `u_i` 随机置换后重新导出，SID 与真实 `u` 的差异 ≥ **10%** 商品；
   并报 `mean|κ_i − 1|`、`κ` 的四分位、以及真实 `u` 与常数曲率下末级距离分布的两条统计。
   这条检验"AF3 确实进入了选码"，不要求它改善任何排序指标。
4. **单一实现 + 接线**：仓库内仅一条指派路径；`ROUNDING_OFF` 同模型内逐位一致（含导出，与基线 `argmin` 一致）；
   `GEOMETRY_OFF`（全体 κ=0）时退化为欧氏；训练与导出三级一致率 1.0。
5. **训练中护栏**：逐层 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`，越界即 FAIL 停止。
6. **checkpoint** 绑结构表 SHA、`q05`、`q95`、κ 表 SHA。
7. **TDD**：先写会失败的测试（κ 的均值恒等式、`u` 单调性、κ 置换后 SID 变化、`ROUNDING_OFF` 恒等、
   `c=0` 欧氏极限、训练/导出同码），确认红后再实现。
8. 任一门不过：按预派发负结果记录并停止，不改 κ 映射、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 条件配额指派）；Sinkhorn 本体（ε、迭代数、centring、代价形式）不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：逐商品曲率只改变"谁离谁近"，不改变"谁与谁共享前缀"；若 Stage3 `test_R@10 ≤ 0.065`，
  说明该轴不产生召回增益，按负结果归档，不再回到秩监督那一支（已两次证伪）。

## 五、与 #166 的差异（必须逐条写进规格）

| 项 | #166 | 本臂 |
|---|---|---|
| 结构作用点 | 距离排序监督（组内） | **逐商品曲率 κ_i** |
| 损失 | `L_RQ + L_rank + L_spread + L_tri` | **仅 `L_RQ`**（基线的重构项） |
| 与配额构造的关系 | 互斥（实测 R 改善 −0.0426） | 正交：配额管占用，κ 管度量 |
| 验收核心 | 两臂差分 ≥2× | **结构灵敏度 ≥10% 商品改码** |
