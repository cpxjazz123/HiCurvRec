Idea：让结构决定**层间位置**，而不是码本容量
英文名称：Frozen Structure Centroids as Inter-Level Residual Shifts (corrected from #150/#151/#152)

这一版不是 #150 路线的修订，而是换轴：前三臂都在"容量/目标分布"这一层动结构信号，全部在
派发前被证伪。本版把结构信号放到**商品在层间的几何位置**上，码本容量与分配规则完全回到基线。

## 一、实证基础（三条前置证伪，均为冻结 8192 行 TRAIN 探针上的实测）

| 臂 | 做法 | 实测 | 结论 |
|---|---|---|---|
| #150 `TIGER_frozen_prior_marginal` | π 作末级 Sinkhorn 的目标列边际 | 计划列误差 0.740；200/500 sweeps 才 1.3e-3 / 8e-11；硬直方图 234 码 / 1.27% / 熵 0.951 对均匀 242 / 1.07% / 0.969 | 冻结迭代预算内 π 不可实现 |
| #151 `TIGER_prior_bias_marginal` | 末级代价加性偏置 `−T·log π_k`，`T = 1.265e-3`（实测中位 top-1/top-2 gap） | 接线正确后直方图几乎不动（熵 0.980161 → 0.980210，最大码 0.7202% 不变）；对 π 相对误差 1.983 对均匀 0.969 | 先验在冻结 ε 的代价尺度上无可动质量 |
| #152 `TIGER_struct_bucket_mask_rq` | 结构层作末级可行性掩码（每层 64 码）+ π 列目标 | π 可实现（2.715% vs 3.0% 量化下界）；硬选码 100% 落桶内；但桶内只用 29–36/64 个码、最大码份额 12.7%–17.7% | 掩码把竞争压进更小的桶并放大塌缩 |

共同结论：在 `SK_EPSILON = 0.003`、50 sweeps 的冻结温度下，硬选码由每行代价决定，
**任何"容量/目标分布"层面的结构先验都无法塑造它**；掩码只会把塌缩集中到桶内。
结构信号必须改变商品在各层竞争时的**位置**，而不是码本的容量账本。

## 二、主张（一句话）

用训练集冻结的**逐结构层层心**，在每个未完成层级之后对残差做一次显式双曲平移，
使同层商品在后续层共享结构方向；分配规则、温度、迭代数、码本容量与列目标全部保持基线。

## 三、设计

1. **结构分层（TRAIN only）**：沿用已验证的三角参与度 `τ` 四分位分层（G = 4），商品→层映射与
   占比 `ρ` 冻结写盘、记 SHA-256（复用 `structure_prior.npz` 的 `item_ids` / `layer` / `rho`）。
2. **层心**：对每个层 `g` 与每个层级 `ℓ ∈ {1,2}`，在冻结探针上取该层商品量化前的残差
   （centred 单位）均值作为层心 `c_{g,ℓ}`；只在 TRAIN 上算一次，写盘并记 SHA-256。
3. **平移**：第 `ℓ` 层量化后，`r ← r ⊕_c (−α_{g,ℓ} · c_{g,ℓ})`（Poincaré 球内 Möbius 加法），
   `α_{g,ℓ} = ‖c_{g,ℓ}‖ / (‖c_{g,ℓ}‖ + median‖r‖_{g,ℓ})` —— 由两个实测量的比值给出，不留可调常数。
4. **其余全部不动**：三层代价、残差递推的其余部分、读出、末级 Sinkhorn（均匀列目标、
   `SK_EPSILON = 0.003`、`SK_ITERS = 50`）、导出、三 token 结构；不引入桶、掩码或 π。
5. **开关**：`SHIFT_OFF`（`α = 0`，逐位等于基线）、`GEOMETRY_OFF`（`c = 0`，平移退化为欧氏平移）、
   `BOTH_ON`（出厂）。开关只要求存在于代码并有廉价接线检查，不训练关闭臂（§19g）。

## 四、验收（派发前，冻结 8192 行 TRAIN 探针，全部可测）

1. **非惰性**：平移使 ≥ 10% 的行改变末级选码（与基线逐行比较）。
2. **不塌缩**：逐层 `codes_used ≥ 0.8 × 基线`、`max_bucket_share ≤ 2 × 基线`（基线在同一探针上实测，
   作为分母）。
3. **层心可用**：四层两两不同（相对差 > 1e-3）、每层 `‖c‖ > 0`、全部 `α ∈ (0,1)`。
4. **极限与接线**：`α = 0` 与基线逐位一致；`c = 0` 时 `d_c²/4` 等于平方欧氏距离（1e-6）；
   训练与导出取同一码；checkpoint 绑层心表 SHA。
5. **TDD**：先写会失败的测试（平移定义域、欧氏极限、α 推导、非惰性、训练/导出同码），再实现。
6. 任一门不过：按**预派发负结果**记录并停止，不调 `α`、不改 `G`/码数、不派发。

## 五、边界与不变项

- 不动代价函数、分配规则、读出、导出、三 token 结构；不引入掩码/桶/π；不用 `argmin` 取代均衡分配（§19h）。
- 3000 epoch、全局 batch 4096、seed 42 冻结；单次正式训练，不做消融/调参/多种子（§19g）。
- 结构信号只来自训练划分；商品级 SID 全局一致；源码无绝对路径；`/tmp` 不落产物。
- 风险：层心方向若与推荐无关，平移会压缩层内差异、抬高碰撞；`codes_used` / `max_bucket_share`
  与 §89 入口门槛会拦截，按负结果记录，事后不改 `G`/`ρ`/`α` 重跑。

## 六、与前三臂的差异

| 项 | #150 / #151 / #152 | 本臂 |
|---|---|---|
| 结构信号的作用对象 | 容量与目标分布（列边际 / 代价偏置 / 可行掩码） | 层间残差位置（Möbius 平移） |
| 分配规则 | 改目标边际 / 改代价 / 改候选集 | 基线均匀 Sinkhorn，完全不改 |
| 常数来源 | T 取中位代价差、掩码常数 | α 由 `‖c‖` 与 `median‖r‖` 的比值推导 |
| 塌缩风险 | 高（#152 实测桶内 29–36/64 码） | 由"非惰性 + 不塌缩"双门在派发前检查 |

## 结构层的移动路线（供下一臂开局）

1. 结构只进"位置"：层心来自 TRAIN，冻结、写盘、记 SHA；不在 run 内重算。
2. 平移只作用于残差，不改代价、不改分配、不改列目标；`α` 必须由实测比值给出，禁止扫描。
3. 派发前必须先证两条：**非惰性**（≥10% 行改码）与**不塌缩**（逐层码使用与最大份额不超基线的
   0.8× / 2×），否则不派发。
4. 逐层记录 `codes_used` / `max_bucket_share` / 归一化熵，并记录被平移改变选码的行占比。
5. 与 #150/#151/#152 的差异（作用对象、分配规则、常数来源、塌缩风险）写进规格与报告。
