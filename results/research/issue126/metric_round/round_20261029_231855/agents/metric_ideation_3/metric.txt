METRIC: hyp_hist_bary_rank_lift_l1
TITLE: Hyperbolic history-barycentre expected-rank lift of the true level-1 SID cell over a size-matched random relabelling.
FORMULA: Items a = 1..N (N = 24587). SID table gives a level-1 digit pi(a) in {0..255}; deeper levels are not read. TRAIN is a set E of ordered pairs (i,j) (query item i, target item j). For each query i let H_i = { j' : (i,j') in E } and let E' = { (i,j) in E : |H_i| >= 2 }. The frozen reference supplies, for every item a, a source vector s_a in R^d, a target vector t_a in R^d, and a temperature tau > 0. Curvature is c = 1. Define exp_0(u) = tanh(||u||/2) * u/||u|| (exp_0(0)=0), r(v) = min( tanh(||v||/(2*tau)), 1 - 1/N ), emb(v) = r(v) * v/||v||, p_a = emb(s_a), q_a = emb(t_a). Mobius addition at c=1: x (+) y = ( (1 + 2<x,y> + ||y||^2) x + (1 - ||x||^2) y ) / ( 1 + 2<x,y> + ||x||^2 ||y||^2 ). Poincare distance: d_H(x,y) = 2 * artanh( ||(-x) (+) y|| ). Riemannian log and exp: log_x(y) = d_H(x,y) * ((-x) (+) y)/||(-x) (+) y|| (0 if x = y); exp_x(v) = x (+) ( tanh(||v||/2) * v/||v|| ), exp_x(0) = x. Frechet (Karcher) barycentre B(S) of a finite set S with uniform weights: b_0 = exp_0( (1/|S|) * sum_{y in S} log_0(y) ); b_{r+1} = exp_{b_r}( (1/|S|) * sum_{y in S} log_{b_r}(y) ), for r = 0..19 (20 iterations, fixed). Cell prototypes: for every level-1 digit k with C_k = { a : pi(a) = k } nonempty, m_k = B({ q_a : a in C_k }); n_1 = number of nonempty level-1 cells. History point for a pair (i,j) in E': h_ij = B({ q_{j'} : j' in H_i, j' != j }). Distances: delta_ij(k) = d_H(h_ij, m_k). Temperature: T = median over (i,j) in E' of delta_ij(pi(j)); if that median is 0, T = 1. Expected rank: rho_ij = sum_{k != pi(j)} sigma( ( delta_ij(pi(j)) - delta_ij(k) ) / T ), with sigma(z) = 1/(1 + e^{-z}). Metric: HBRL = (1/|E'|) * sum_{(i,j) in E'} ln( (n_1 + 1) / ( 2 * (rho_ij + 1) ) ). Conventions: HBRL = 0 if n_1 < 2 or E' is empty. Higher is better; 0 is the value of a partition independent of the reference; the maximum is ln((n_1+1)/2).
INPUTS: the exported SID table (integer code per item per level; only the level-1 digit is read); the frozen Issue #126 reference's per-item source vectors, per-item target vectors and temperature tau; the TRAIN split's (query item, target item) pairs. Nothing else: no validation interaction, no test interaction, no recall, no Stage 2 or Stage 3 run.
GEOMETRY: unit Poincare ball with curvature c = 1, i.e. constant sectional curvature -1. Curvature enters at four explicit points: (i) the data are pushed into the ball by the exponential map exp_0(v/tau), so the radius of every point is the hyperbolic function tanh(||v||/(2 tau)) and not a linear rescaling; (ii) every distance is the Poincare distance built from Mobius addition and 2*artanh, whose argument is not a Euclidean norm; (iii) both barycentre families (the cell prototypes m_k and the history points h_ij) are Frechet/Karcher minimisers of the sum of squared hyperbolic distances, computed with the exp/log fixed-point iteration, and are not arithmetic means; (iv) T is expressed in the same curvature units. Taking c -> 0 removes the artanh and the Mobius correction, makes the barycentres arithmetic means, and changes the number, so this is not a Euclidean distance in disguise.
WHY IT SHOULD TRACK RECALL: Stage-3 recall needs the true target's level-1 token to be among the first tokens the decoder emits for a query, and a table is learnable exactly when that token is a low-entropy function of what the model conditions on. The Karcher barycentre of the query's whole remaining history is the minimum-variance hyperbolic summary of that conditioning set, and it lives on the target channel, which Q_H never uses. The score is not a two-way margin: it is the expected number of the n_1 cell prototypes that the geometry ranks ahead of the correct cell, so rho_ij < 9 means the correct level-1 cell typically sits inside a top-10 cell list, the prefix-level analogue of Recall@10. The null is exact and size-matched: because sigma(z) + sigma(-z) = 1, the expected soft rank of a uniformly random cell under the same distances is exactly rho_0 = (n_1 - 1)/2, so the log-lift cancels the pure size effect and a 2-code table caps at ln 1.5 = 0.405 while a 256-cell table reaches ln 128.5 = 4.856; a collapsed trie therefore cannot win, which is what sank likelihood-style scores. The metric is invariant to relabelling the level-1 digits, since a permutation of the digits permutes the m_k identically, so it scores the partition and not the code values. Over Q_H it adds three things: the query point pools the entire training history instead of one anchor, the contrast is the full level-1 catalogue instead of a mean over ten sampled negatives, and the value is an expected rank rather than a margin, so its scale is a count of competitors.
COMPUTE: O(N*d) for the embeddings; 256 Karcher means over the whole catalogue (N point-visits, 20 iterations); one Karcher mean per evaluated pair over its leave-one-out history, O( sum_i |H_i|^2 * 20 * d ); then |E'| * n_1 Poincare distances, O(|E'| * n_1 * d). At 24587 items, 256 codes, d <= 64 and roughly 2.5e5 training pairs this is about 1e10 flops, a few seconds to about 20 s in vectorised NumPy/BLAS, processed in query blocks of 1024; no N x N matrix and no N x n_1 matrix is ever held, so memory stays under 1 GB.
RISKS: the construction needs the reference's source and target heads to live in one shared metric space, which its contrastive training provides but which must be true or d_H(h_ij, m_k) is meaningless. In a small-tau regime the embedding saturates at the radius cap, all distances grow, T grows with them and rho_ij is compressed toward rho_0 for every table, which loses variance across the 97 tables. Pairs are unweighted, so queries with very long histories contribute many highly stable barycentres and can dominate the mean. Deeper levels are ignored by design, so tables that differ only below level 1 are indistinguishable. If the 97 tables mostly share a level-1 partition the metric has no variance to correlate with. The fixed 20-step Karcher iteration can drift toward the boundary for near-antipodal history sets, and the leave-one-out history point degenerates when the remaining history is a single item.
FAILURE MODE: it must be worst on the table whose level-1 digit is an independent hash of the item index: then pi(j) is exchangeable with every other cell relative to h_ij, rho_ij converges to (n_1 - 1)/2 and HBRL converges to 0 no matter what the reference says. The two degenerate ends are also bad by construction: n_1 = 1 returns 0, and the 2-code, 3-code and 12-code collapsed tables are capped at 0.405, 0.693 and 1.870 respectively, all below a healthy 256-cell table at rho = 5, which scores 3.07. In the other direction it is deliberately blind: a table with a perfect level-1 and a random level-2 scores exactly as high as one with a good level-2, which is the price of not reading the near-identifier prefixes.
END METRIC
