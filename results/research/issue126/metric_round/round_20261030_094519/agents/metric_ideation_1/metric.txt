METRIC: hyp_prefixtree_isometry
TITLE: Rank fidelity of the SID prefix tree, realised as a geodesic tree of hyperbolic Frechet barycentres in the frozen reference Poincare ball, to the reference distances over all training pairs.
FORMULA:
Fix curvature c = 1 (the curvature of the frozen reference ball, as stated by the reference; not fitted). Let x_i be the reference SOURCE representation of item i, already in the unit Poincare ball B_c = {x : sqrt(c)||x|| < 1}.
Mobius addition: u (+) v = ((1 + 2c<u,v> + c||v||^2) u + (1 - c||u||^2) v) / (1 + 2c<u,v> + c^2||u||^2||v||^2).
Poincare distance: d(u,v) = (2/sqrt(c)) * artanh( sqrt(c) * ||(-u)(+)v|| ).
Origin maps: log_0(x) = artanh(sqrt(c)||x||) x / (sqrt(c)||x||); exp_0(w) = tanh(sqrt(c)||w||) w / (sqrt(c)||w||), with exp_0(0)=0.
FRE(S) = hyperbolic Frechet (Karcher) mean of a set S: initialise b = exp_0( mean_{x in S} log_0(x) ), then repeat 60 times: b <- exp_b( (1/2) * mean_{x in S} log_b(x) ), where log_b(y) = log_0( (-b)(+)y ) / (1 - c||b||^2). The step 1/2 and the 60 sweeps are a fixed numerical schedule, not a tuned parameter.
For item i and level l = 1..L: A_l(i) = the level-l prefix cell of i; p_l(i) = FRE({ x_j : A_l(j) = A_l(i) }), one barycentre per cell, reused by all its members.
SID-induced distance: D(i,j) = sum_{l=1}^{L} d( p_l(i), p_l(j) ). D(i,j) = 0 iff i and j agree at every level.
Reference distance: R(i,j) = d( x_i, x_j ).
score = Spearman rank correlation between {D(i,j)} and {R(i,j)} over the pair set P.
P = 200000 distinct unordered pairs (i<j) of training-split items, drawn uniformly by numpy.random.default_rng(0) over the sorted list of training item indices. The seed and the size are a compute budget held fixed for every table, never tuned against a recall.
Return score. It lies in [-1, +1]; higher is better.
INPUTS: (1) the exported SID table, the integer code per item per level; (2) the frozen Issue #126 reference, namely the source representation x_i per item and the training-split item list. Nothing else: no validation interaction, no test interaction, no recall, no Stage-3 run.
GEOMETRY: everything lives in a ball of fixed negative curvature c = 1. The curvature enters in exactly two places and nowhere else. (a) Every cell is summarised by a Frechet barycentre computed with hyperbolic log/exp maps and Poincare distances, so a cell's representative is the least-squares centre in the ball, not a coordinate-wise average. (b) The SID distance is a sum of Poincare distances between those barycentres, i.e. the prefix trie is realised as a geodesic tree inside the ball. This is the right realisation because a prefix hierarchy is a tree and hyperbolic space is the space that embeds trees with bounded distortion at curvature matched to the tree's branching. At c -> 0 the barycentres collapse to Euclidean means, the Poincare distance collapses to half the Euclidean distance, and the score degenerates into a linear-projection score; that degeneration is exactly what the curvature is there to prevent, so the comparison is only meaningful because of the map.
WHY IT SHOULD TRACK RECALL: Recall@10 is a rank question over all pairs, not over one anchor. A table can only retrieve item i with a 10-candidate prefix probe if its cells are the cells of the reference geometry. Q_H scores one canonical prefix contrast; HBAA scores one anchor point against a mean of ten negatives. This metric scores the entire hierarchy against the entire item cloud at once, over roughly two hundred thousand pairs, and it is invariant to which single item is treated as the query: it asks whether the SID table is a low-distortion hyperbolic summary of the reference ball, which is precisely the property an index needs for 10-cell probes to suffice. It also uses the deepest levels without the level-2/3 collapse that sinks Q_H: a level-l cell contributes only the geodesic spread of its own barycentre, which shrinks to zero as that cell becomes a single item, so an over-split finish earns nothing while a semantically coherent deep level still adds resolution. Nothing here is a rearrangement of a single anchor's margin, likelihood or coverage; it is a global isometry score over the full pair structure.
COMPUTE: per-cell barycentres computed once: sum over cells of (n_cell x 60 x 2) log/exp-map evaluations, about 24587 * 60 * 2 is roughly 3e6 map evaluations, plus one L-depth pass to assign p_l(i); then 2e5 pairs x L <= 4 Poincare distances, about 1e6 vectorised operations. Under 10 s on a single core for 24587 items and 256 codes, well inside the one-minute budget.
RISKS: (a) saturation: if the reference's own pair distances are dominated by one large-scale gradient, most plausible tables land in a narrow 0.2-0.4 band and the Spearman against recall is noisy; (b) unbalanced cell sizes: a few huge level-1 cells can dominate the barycentres and make several levels' contributions nearly identical, wasting the ladder; (c) the pair sample is fixed, so its sampling variance is not averaged away across corpora; (d) if the frozen reference representations are nearly rank-1 (collapsed during their own training) the Poincare distances become a monotone rescaling of a scalar and the coherence signal disappears.
FAILURE MODE: worst on a table whose level-1 codes are semantically scrambled while its trie is perfectly balanced, for example codes assigned by an item-id hash: all barycentres then sit near the ball's origin, the Poincare distances between them are small and nearly constant, D is nearly constant and the Spearman falls to 0. It is equally 0 on the pathological table with 24587 distinct level-1 codes (D constant) and on the one-code table (D identically 0, correlation undefined, scored 0), so neither collapse nor total splitting is ever rewarded.
END METRIC
