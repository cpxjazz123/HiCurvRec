METRIC: HYP_VORONOI_MARGIN_L1
TITLE: Mean geodesic margin of the level-1 SID cells as a hyperbolic Voronoi partition of the source ball.
FORMULA:
  Inputs and constants. Let N be the number of items (24587), K = 256 the codebook size, d the reference representation width. Let a_i in {0,...,K-1} be the level-1 integer code of item i in the exported SID table. Let x_i in R^d be the frozen reference SOURCE representation of item i. Let T be the set of item ids that occur as sources in the TRAINING split. All constants are derived, none tuned:
    curvature c = 1 (ball of curvature -1, unit Poincare ball of radius 1);
    scale s = median_{i in T} ||x_i||, with ||.|| the Euclidean norm in R^d; if T is empty use T = all N items.
  Injection (exp map at the origin). For each item:
    p_i = tanh(||x_i|| / s) * x_i / ||x_i||   (p_i = 0 if ||x_i|| = 0).
  Klein coordinates. k_i = 2 p_i / (1 + ||p_i||^2).
  Cell centres (hyperbolic barycentre = Klein-model Einstein midpoint, closed form). For each non-empty code c let C_c = { i : a_i = c }, g_i = 1 / sqrt(1 - ||k_i||^2), and
    kbar_c = ( sum_{i in C_c} g_i k_i ) / ( sum_{i in C_c} g_i ),
    b_c = kbar_c / ( 1 + sqrt(max(0, 1 - ||kbar_c||^2)) ),
  with ||k_i||, ||kbar_c|| clipped to at most 1 - 1e-9 before use.
  Poincare distance. d(u,v) = arcosh( 1 + 2 ||u - v||^2 / ( (1 - ||u||^2)(1 - ||v||^2) ) ), arguments clipped as above so the argument of arcosh is at least 1.
  Per-item margin. d_own(i) = d(p_i, b_{a_i}); d_rival(i) = min over codes c != a_i of d(p_i, b_c).
    m_i = ( d_rival(i) - d_own(i) ) / ( d_rival(i) + d_own(i) )   if |C_{a_i}| >= 2 and the denominator > 0,
    m_i = 0                                                      if |C_{a_i}| = 1 or the denominator = 0.
  METRIC. M = (1/N) * sum_{i=1..N} m_i, in [-1, 1]. If fewer than two distinct level-1 codes are present, M = -1 by definition. Higher is better.
INPUTS:
  (1) the exported Stage-2 SID table, column for level 1 only (one integer code per item, K = 256);
  (2) the frozen Issue #126 behaviour reference, SOURCE representation x_i for each item (target representations are not read);
  (3) the TRAINING split item-id list, used only to compute the single scalar s = median ||x_i||.
  Nothing else: no recall, no Stage-3 output, no validation or test interaction, no model forward pass.
GEOMETRY:
  The curvature enters three times and each time it is load-bearing. (a) The exp map at the origin of the ball of curvature -1, p = tanh(|v|) v/|v| with v = x/s, replaces the reference's flat vector by a point in the ball; this map is a bijection R^d -> open ball and its hyperbolic radial compression is what makes the comparison invariant to the reference's arbitrary output norm (rescaling every x_i rescales s identically, leaving p_i unchanged, whereas a Euclidean nearest-centre margin changes under that rescaling). (b) Cell centres are the exact hyperbolic Frechet barycentres, realised as Klein-model Einstein midpoints with weights g_i = (1 - |k_i|^2)^{-1/2}; the g_i blow up toward the boundary, so an item near the boundary dominates its cell centre far more than it would under a Euclidean mean - a flat centroid is the |k| -> 0 limit of this formula. (c) All comparisons use the Poincare geodesic distance arcosh(1 + 2|u-v|^2/((1-|u|^2)(1-|v|^2))), whose conformal factor 2/(1-|p|^2) is exactly where curvature enters; the margin is a ratio of two of these geodesic lengths, so it is a statement about the curved metric, not about a Euclidean distance in disguise. No free parameter: curvature is fixed at -1 and s is a median of training data.
WHY IT SHOULD TRACK RECALL:
  Stage-3 emits the code autoregressively from the query's source representation, so the first emitted token is a nearest-cell decision in source space: if the correct level-1 code is not the geodesically nearest cell centre to the query, no later token can rescue the item, and if it is nearest only by a hair the first token is a coin flip. M is exactly the average normalised geodesic margin of that decision, taken over the same items whose representations Stage-3 consumes. A SID table whose level-1 cells are semantically coherent AND mutually separated in the ball gives large positive margins; a table that interleaves the source manifold gives margins near or below zero. What it adds over Q_H: Q_H scores the reference's own prefix probability ranking and so saturates when the model is confident about a prefix regardless of whether rival codes are geometrically confusable; M never reads a probability, uses both cohesion and separation (Q_H's known weakness at level 2 is a ranking artefact), and its scale is bounded and comparable across tables with different codebooks. It is also not the collision rate or the same-bucket ratio: a table with 256 perfectly balanced but semantically random cells has the same bucket histogram and the same same-bucket ratio as a good table, yet all its barycentres collapse toward the origin and M falls to about 0.
COMPUTE:
  One pass to build p_i, k_i, g_i: O(N d) = 1.6M-6.3M flops. 256 weighted Klein sums: O(N d). One dense score block of N x K = 6.29M Poincare distances, each about 6d flops, roughly 0.8-4 GFLOP for d = 64-256, plus a min-over-codes reduction. Peak memory 6.29M float32 = 25 MB (or streamed in row blocks to 1 MB). Single-threaded NumPy runs in about 5-30 s on 24587 items and 256 codes; no iteration, no fitting, no training.
RISKS:
  Numerically fragile near the boundary: if median training norm is tiny relative to typical norms, tanh(|x|/s) saturates at 1 and the conformal factor 1/(1-|p|^2) explodes; the 1 - 1e-9 clip keeps arcosh finite but the margin then becomes noise. If the frozen reference's source vectors are near-isotropic with no cluster structure (undertrained or dimension-collapsed), every barycentre sits near the origin, every m_i is near 0, and the metric is flat across tables (near-zero Spearman). Singleton or near-singleton level-1 cells give d_own = 0 and m_i = 1, inflating M; the defined m_i = 0 for |C| = 1 prevents it but a table of 24587 tiny cells still degenerates. Rare-code barycentres from very few items are high-variance. Using all N items' representations means validation/test items' label-free encodings are read (allowed by the contract, but it does mean M is not restricted to the training split). Finally, if Stage-3 actually conditions on target-side representations rather than the query source, the source-side Voronoi argument is misaligned and the sign can invert.
FAILURE MODE:
  Worst on a SID table whose level-1 codes are a uniform random permutation with exactly balanced cell sizes: every cell is a random subset of the item population, so every Einstein midpoint converges to the global midpoint, which lies essentially at the origin, giving d_own ≈ d_rival for all i, so M ≈ 0 with only numerical noise and no ordering across such tables; a single-code or two-code table is defined as M = -1 and is the formal floor. A second bad case is a table clustered on the TARGET representations: if the source and target manifolds are asymmetric, level-1 cells are coherent on the target side but anti-aligned on the source side, margins go negative, and M drops below the random-permutation value.
END METRIC
