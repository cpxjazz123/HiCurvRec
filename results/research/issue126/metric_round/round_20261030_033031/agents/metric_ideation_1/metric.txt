METRIC: hyp_erank_gain
TITLE: Full-history hyperbolic Frechet query against the whole level-1 cell set, scored by a temperatured Plackett-Luce expected rank and normalised by the size-matched prior.
FORMULA:
Let K = 256 level-1 codes. Let I be the items of the TRAINING split, N = |I|. For i in I, b(i) in {1,...,K} is its level-1 code from the exported SID table; x_i (source) and y_i (target) are the frozen reference's representations in the Poincare ball B^d_c of curvature -c, with c = c_ref and tau = tau_ref read from the frozen reference (never fitted). Put Bs = {b : n_b > 0}, n_b = |{i in I : b(i) = b}|, w_b = n_b / N.
Frechet barycentre of a finite set S: m(S) = argmin_z sum_{u in S} d_c(z,u)^2, computed as the Lorentzian centroid by fixed-point iteration (not a Euclidean mean).
Query: q_h = m({x_j : j in history(h)}) for every training history h.
Cell prototype: mu_b = m({y_i : i in I, b(i) = b}) for every b in Bs.
Lorentz lift: L(z) = ( (1 + c||z||^2)/(1 - c||z||^2), 2z/(1 - c||z||^2) ) / sqrt(c); Minkowski product <u,v>_L = -u_0 v_0 + sum_{k=1..d} u_k v_k.
Logit: z_b(h) = <L(q_h), L(mu_b)>_L / tau.
Cell softmax: p_b(h) = exp(z_b(h)) / sum_{b' in Bs} exp(z_{b'}(h)).
Observed expected rank of the true cell b+(h): ER_obs(h) = 1 + sum_{b in Bs, b != b+(h)} p_b(h) / (p_b(h) + p_{b+(h)}(h)).
Size-matched prior expected rank: ER_null(h) = 1 + sum_{b in Bs, b != b+(h)} w_b / (w_b + w_{b+(h)}).
Per-history gain: rho(h) = clip( (ER_null(h) - ER_obs(h)) / (ER_null(h) - 1), 0, 1 ), and rho(h) = 0 if ER_null(h) <= 1 + 1e-12.
METRIC = (1/|H|) sum_{h in H} rho(h), a single scalar in [0,1], higher = better.
INPUTS: the exported SID table (one integer level-1 code per item); the frozen Issue #126 behaviour reference (source x_i, target y_i per item, curvature c_ref, temperature tau_ref); the TRAINING split (histories and their positive next item). Nothing else; no validation interaction and no test interaction, and no recall value.
GEOMETRY: The space is the Poincare ball of fixed negative curvature -c (c = c_ref). Curvature enters three times. (1) q_h and every mu_b are Frechet barycentres under the Poincare geodesic d_c, i.e. exp/log-map means; a Euclidean centroid would move every point. (2) <L(q_h),L(mu_b)>_L = -cosh(sqrt(c) d_c(q_h, mu_b)), so every logit is a geodesic-distance comparison and the softmax bandwidth is fixed by c and tau together, not by a free kernel width. (3) The effective comparison is the tangent-space norm ||log_{q_h}(mu_b)|| = d_c(q_h, mu_b), which is only defined through the hyperbolic exponential map. No step is a Euclidean distance in disguise.
WHY IT SHOULD TRACK RECALL: Stage-3 Recall@10 needs the true item's level-1 cell to be among the cells that the reference-driven retrieval surfaces, because a level-1 prefix mismatch removes the item from the candidate prefix. ER_obs is precisely the temperatured expected rank of the true cell among ALL 256 cell prototypes under the reference's own softmax, conditioned on the entire training history rather than on one item. The denominator ER_null is the expected rank the same true cell would get from its size alone, so rho measures the fraction of the size-prior rank penalty that the reference's hyperbolic geometry actually removes. That adds over Q_H (which scores the prefix by within-prefix ranking and never uses the reference geometry or the query history) and over HBAA (which reduces the negatives to one sampled i- and a pairwise sigmoid, so it is negative-sampling dependent and ignores the other 254 cells): here the full negative distribution is integrated with the reference temperature, and the size-matched null removes the free credit that made the plain path likelihood reward collapse.
COMPUTE: 256 Lorentz barycentres over about N/256 = 96 points each: O(50 * N * d); |H| history barycentres over average history length L: O(50 * |H| * L * d); per history 256 logits and 256 Plackett-Luce terms: O(|H| * K). With N = 24587, K = 256, d <= 128 and |H| <= N this is under 1e8 flops and a few seconds on one CPU; histories are processed in chunks so memory stays O(N). The 50 fixed-point steps are a numerical constant, not a tuned parameter.
RISKS: (a) if tau_ref is on a different scale from the Lorentz inner products, the softmax saturates (ER_obs -> 1 for every table) or flattens (ER_obs -> (B+1)/2), and the metric loses discrimination; (b) the hyperbolic Frechet mean is not robust, so a few boundary-near target outliers can drag mu_b; (c) source and target must live in the same ball, otherwise <L(q_h),L(mu_b)>_L is meaningless; (d) very short histories give a noisy q_h; (e) ER_null grows with the number of nonempty cells, so the ratio only partly removes a residual dependence on B; (f) if Stage 3 gates on full SIDs rather than level-1 prefixes, level-1 rank need not map to recall; (g) for extremely unbalanced cells ER_null can sit near 1, and the epsilon rule sends those histories to 0.
FAILURE MODE: It must be worst on a SID table whose level-1 partition is a balanced random relabelling with all 256 cells nonempty and nearly equal n_b: then every mu_b collapses onto the global target mean, all 256 logits are equal, ER_obs = ER_null = (256+1)/2 = 128.5, the numerator is 0 and METRIC is 0. A one-code table also scores exactly 0 because Bs has one element and the denominator rule applies. It is deliberately not worst on a coarse but geodesically pure table, which is what prevents it from rewarding collapse.
END METRIC
