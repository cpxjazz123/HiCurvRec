METRIC: hyp_xtower_bucket_softrank
TITLE: Cross-tower hyperbolic soft rank of the true level-1 bucket among all codebook buckets
FORMULA: Let N=24587 items, V=256 level-1 codes, c(i) the level-1 code of item i, n_b=#{i: c(i)=b}, V_eff=#{b: n_b>0}. Let x_i (source rep) and y_i (target rep) be the frozen reference arrays. Set s = 0.9 / Q99_i max(||x_i||,||y_i||) and curvature c = 1. For the Poincare ball B_c^d write exp_0^c(v) = tanh(sqrt(c)||v||) v / (sqrt(c)||v||) (exp_0^c(0)=0), log_0^c(z) = (1/sqrt(c)) artanh(sqrt(c)||z||) z/||z|| (log_0^c(0)=0), d_B(z,z') = (2/sqrt(c)) artanh(sqrt(c)||(-z) (+) z'||), with (+) the Mobius sum. Write E(v)=exp_0^c(s v). For a finite set Z in the ball let F(Z)=argmin_m sum_{z in Z} d_B(m,z)^2 be the Frechet (Karcher) barycentre, computed from m0=exp_0^c(mean_{z in Z} log_0^c z) by m <- exp_m^c(mean_{z in Z} log_m^c z) until the step norm < 1e-6 or 50 iterations. For every nonempty bucket b define Z_b={E(y_j): c(j)=b}, m_b=F(Z_b), rho_b=(1/n_b) sum_{j:c(j)=b} d_B(0,E(y_j)), and the radially corrected centroid mtil_b = exp_0^c( (rho_b/d_B(0,m_b)) log_0^c(m_b) ) if m_b != 0, else 0. Let T be the training interactions deduplicated to one per target item (keep its LAST occurrence in the training split), and for t in T let i(t) be the target item and h(t) its training history. Define q_t = exp_0^c( (1/|h(t)|) sum_{j in h(t)} log_0^c(E(x_j)) ). Derive the temperature tau = median_{t in T} d_B(q_t, E(y_{i(t)})). For each t let b_t=c(i(t)), d_+(t)=d_B(q_t, mtil_{b_t}), and d_b(t)=d_B(q_t, mtil_b). Define P_t = (1/(V_eff-1)) sum_{b != b_t, n_b>0} sigma((d_b(t)-d_+(t))/tau), with sigma(z)=1/(1+exp(-z)); if V_eff=1 set P_t=1/2. The metric is H = (1/|T|) sum_{t in T} (2 P_t - 1), a scalar in [-1,+1], higher is better.
INPUTS: (1) the exported Stage-2 SID table, i.e. the integer code per item per level (only the level-1 column is read); (2) the frozen Issue #126 behaviour reference arrays x_i (source) and y_i (target) for i=1..N, learned on training pairs only; (3) the TRAINING split, used only to build T and the histories h(t). Nothing else; no validation or test interaction, no recall, no Stage-3 output.
GEOMETRY: the whole computation lives in the Poincare ball of unit negative curvature c=1 after the reference-derived scale s. Curvature enters in four places: the exp_0/log_0 maps that place the reference vectors and define the history query, the Frechet/Karcher barycentres m_b, the geodesic radial renormalisation mtil_b (which moves the centroid out along its own geodesic ray to the mean member radius), and the hyperbolic distance d_B inside the logistic soft rank. At c -> 0 the same expression collapses to a Euclidean centroid plus Euclidean distance, so the curvature is not decorative; the artanh nonlinearity and the barycentre corrections change which bucket is ranked first.
WHY IT SHOULD TRACK RECALL: Stage-3 recall@10 is decided first at level 1: if the true item's level-1 region is not closer to the history query than the other ~255 regions, no deeper decoding can recover the item. P_t is exactly a soft, temperature-smoothed Recall@1-over-buckets computed with the reference's own geometry, and H is its centred average, so it is a direct proxy for whether the table's coarse routing is aligned with the reference's query-to-candidate metric. Over Q_H it adds the full V-way negative distribution (every other bucket centroid, not a prefix count or a margin against one reference), the target tower (the side a query is actually matched against, while the query is built from the source tower), geodesic barycentres, and a size-unbiased radial correction. Over HBAA it adds a nonlinear soft rank over the whole bucket distribution instead of a linear inner-product margin against a mean of ten negatives: one hard negative cannot be averaged away, and the temperature comes from the reference's own positive query-target distance, so no recall-tuned constant exists. Under a uniformly random relabelling P_t has expectation exactly 1/2 by the symmetry sigma(z)+sigma(-z)=1, and under a one-code table V_eff=1 forces P_t=1/2, so both controls map to 0 and collapse is never rewarded.
COMPUTE: build at most 256 Karcher barycentres over all N=24587 target vectors (O(N d * iterations), ~3e7 scalar ops for d=128); build at most N=24587 history queries with the closed-form tangent mean (O(|T| H d), with H the mean history length); evaluate |T|*V_eff <= 24587*256 = 6.3e6 hyperbolic distances by vectorised matrix operations. The radial corrections and logistic ranks are O(N + |T| V). Total is a few seconds on CPU and well under one minute, with no pairwise N x N matrix.
RISKS: If the reference's target arrays are not the query-side/candidate embeddings but something else, the cross-tower distance is meaningless and P_t sits at 1/2 for every table. If the target vectors are nearly isotropic and low-rank so that all bucket centroids are almost equidistant from every query, P_t is near 1/2 for all 97 tables and the metric cannot discriminate. The radial renormalisation removes the Poincare contraction bias of large buckets but also discards any genuine magnitude/confidence signal, which could lower the correlation. Tables with very few nonempty level-1 codes give a coarse, high-variance P_t; a 2-code but informative split can score high even though it cannot isolate a top-10 item set. Using only the last training occurrence per target item samples a particular query distribution; a different but still training-only deduplication would change the value, though not the form. Near-boundary vectors make artanh and the Karcher iteration stiff; the 0.9 scaling keeps every mapped point strictly inside the ball.
FAILURE MODE: the worst table is a level-1 partition anti-aligned with the reference's target-tower geometry, e.g. codes assigned to maximise target-space dispersion within a bucket or to invert the reference's neighbourhoods; then d_+ is larger than almost every d_b, P_t -> 0 and H -> -1. The degenerate table that must be worst for usefulness, the one-code collapse, gives V_eff=1, hence P_t=1/2 and H=0 (not rewarded rather than punished). A uniformly random or hash-based relabelling gives H approximately 0, and a table whose level-1 buckets are balanced but semantically empty also lands near 0.
END METRIC
