METRIC: hyp_beam10_geo_hit

TITLE: Training-pair hit rate of a curvature −1 beam-10 shortest-geodesic-path reader over the SID trie.

FORMULA: Let N items, L levels, K = 256, and sid_i = (q_{i,1},…,q_{i,L}) be the exported integer code tuple of item i. Let p = (q_1,…,q_ℓ) denote a prefix and P(p) = { i : sid_i[1..ℓ] = p }. Prefix set S_ℓ = { p : |P(p)| > 0 }. Write x^s_i, x^t_i in the unit Poincaré ball B = {x in R^d : ‖x‖<1} for the frozen reference source and target representations z^s_i, z^t_i (temperature tau stored with the reference; tau := 1 if absent), with one scalar scale
  sigma = 1 / Quantile_0.99( ‖tau*z^t_i‖_2 , i = 1..N ),  and  x_i = tanh( sigma*tau*‖z_i‖ ) * z_i/‖z_i‖   (x_i = 0 if z_i = 0).
Both source and target maps use the same sigma and tau. Poincaré metric with c = 1: Möbius addition u⊕v = ((1+2<u,v>+‖v‖²)u + (1−‖u‖²)v) / (1+2<u,v>+‖u‖²‖v‖²), and d(u,v) = 2*artanh( ‖(−u)⊕v‖ ) with (−u)⊕v the Möbius sum. Fréchet barycentre of a prefix, b_p = argmin_{b in B} Σ_{i in P(p)} d(b, x^t_i)², computed by the Karcher fixed point b ← exp_b( (1/|P(p)|) Σ_{i in P(p)} log_b(x^t_i) ), initialised at the member with smallest ‖x^t_i‖, 50 iterations, stopped when ‖mean tangent‖ < 1e-10, where log_b(x) = (2/lambda_b)*artanh(‖(−b)⊕x‖)*((−b)⊕x)/‖(−b)⊕x‖, lambda_b = 2/(1−‖b‖²), and exp_b(w) = b ⊕ ( tanh(lambda_b‖w‖/2) * w/‖w‖ ). If |P(p)| = 1 then b_p = x^t of that member.
Path score of a code path q = (q_1..q_ℓ) for a query source s:
  S(q; s) = d(x^s_s, b_{q_1}) + Σ_{m=2..ℓ} d(b_{q_1..q_{m−1}}, b_{q_1..q_m}).
Beam reader with width B = 10 (B is the recall cutoff k = 10, nothing else): level 1 candidates = S_1 ranked by S, keep the best 10 (ties broken by lexicographically smaller code tuple). For m = 2..L expand each kept prefix by its children in S_m, rank by S, keep the best 10. Since every increment for m >= 2 is independent of s, the best-B children of a parent are exactly its B geodesically nearest children; this pruning is exact by the triangle inequality, so no path that could enter the global top-10 is ever dropped. Reading stops at level L with a set R(s) of at most 10 full code tuples.
For each training pair (s,t) with s != t: hit(s,t) = 1 if sid_t ∈ R(s), else 0. Let Q be the training-pair list in file order, skipped to at most 20000 pairs by taking every ceil(|Q|/20000)-th pair. METRIC = (1/|Q'|) * Σ_{(s,t) in Q'} hit(s,t), a number in [0,1], higher better.

INPUTS: the exported Stage-2 SID table (integer array sid[N, L], values in 0..K−1); the TRAINING split list of (source_item_id, target_item_id) pairs; the frozen Issue #126 reference arrays Zsrc[N, d] and Ztgt[N, d] with its stored scalar temperature. Nothing else — no recall value, no Stage-3 artefact, no validation or test pair.

GEOMETRY: fixed curvature c = 1 (unit negative curvature; no tuned curvature). Curvature enters in three load-bearing places: (1) the exponential map at the origin, x = exp_0(tau*sigma*z) = tanh(‖.‖) * unit vector, so reference vectors become points of a ball of radius < 1 rather than plane vectors; (2) every prefix representative b_p is a Karcher/Fréchet barycentre, i.e. the minimiser of summed squared GEODESIC distance, which in a curved ball sits strictly closer to the origin than the Euclidean mean and is not obtainable by averaging coordinates; (3) the decoder's score is a sum of geodesic lengths, and hyperbolic distance diverges as points approach the boundary, so the level-1 term and the deep increments are weighted by the geometry, not by a linear scale. Consequence: taking c -> 0 changes both the barycentres and the relative size of the increments, hence changes the induced ordering of tables — this is not a Euclidean distance in disguise.

WHY IT SHOULD TRACK RECALL: Stage-3 Recall@10 is literally "did the true SID survive a competition in which at most 10 SID sequences are kept". This metric reproduces that decision with a parameter-free curved reader and reports how often the truth survives. So it measures the headroom the table itself grants: a table with separable, geodesically tight prefixes and non-degenerate deep splits leaves the target's SID among the 10 shortest paths from the source; a table whose prefixes cut across the reference geometry does not, whatever ideal reader is used. What it adds over Q_H: (i) Q_H is a level-1 prefix rank and collapses at level 2 (+0.287) because a near-singleton prefix makes the rank degenerate, whereas here every level contributes a genuine geodesic increment b_parent -> b_child, so all L levels are priced jointly without degeneracy; (ii) it rewards tight hierarchical refinement (small increments) and punishes wasted depth (random deeper codes put a child barycentre far from its parent, inflating every path through that branch, which the beam punishes), the quantity that decides whether the search can travel to depth L without losing the truth; (iii) it carries the aliasing ceiling for free — two items with the same full SID are one candidate, so a target can never be "hit twice", which prefix counts cannot see; (iv) it is aggregated, ordinal and scale-free with a 10-slot competition, i.e. the same regime that made Q_H work, unlike the local per-pair margins that failed.

COMPUTE: barycentres for at most L*N ~ 1e5 prefixes cost sum_p |P(p)| * 50 = 50*L*N ~ 5e6 point updates, vectorised by level, a few seconds; the trie has at most L*N edges so edge geodesic distances number ~1e5 and are computed once; per training pair only the K = 256 level-1 Poincaré distances are computed (2e4 * 256 = 5.1e6), every level-2+ increment being a precomputed lookup, and the beam is at most L*10*10 arithmetic steps per pair. Total 5-15 s single-core on 24587 items and 256 codes.

RISKS: if the reference's target representations are near-degenerate, all prefix barycentres collapse to one point, the level-1 term becomes constant and the metric saturates near 10/N for every table, giving no dynamic range across the 97 pairs; because the pairs are training pairs and the reference was fitted on them, the metric can look uniformly good and compress differences; Karcher iteration can converge slowly for prefixes whose members sit near the boundary (mitigated by the fixed 50-iteration cap and the deterministic initialisation); the surrogate reader is ideal, so it prices sequence length only through geodesic increments and under-penalises a table with perfect coarse alignment plus useless but geometrically cheap deep splits; deterministic tie-breaking must be applied or the value is implementation-dependent.

FAILURE MODE: worst on the semantically blind table sid_i = ( i mod K, floor(i/K) mod K, floor(i/K²) mod K, … ), unique and perfectly balanced: every level-1 bucket is a uniform random sample of the item set, so all 256 barycentres sit on top of the global barycentre, d(x^s_s, b_{q_1}) is identical across candidates up to sampling noise, and every path increment is drawn from one common distribution; the top-10 is then decided by noise and the hit rate tends to about 10 times the largest SID multiplicity over N, i.e. the floor. Correctly it should be near the floor for Stage 3 as well, but any table with a good level-1 and useless deep splits is where it will most over-predict.
