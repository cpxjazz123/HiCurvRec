Idea：条件配额的组内指派改为**向量化贪心**，把导出时间压回预算（修正 #162 的 13.33 s）
英文名称：Conditional Quotas with Greedy In-Group Assignment (corrected from #162)

#162 是本系列第一次把碰撞做到极限：

| 观测（未训练、全量导出 24587） | 数值 |
|---|---|
| 入口碰撞 | **0.000000**（24587 个不同三元组 / 24587 个商品） |
| 二级不同前缀 | **24587**（= 商品数） |
| 逐层占用 | 每层 256 码，最大份额 0.394% / 0.777% / 0.468% |
| 容量恒等式与组内精确解 | 成立（1e-9） |
| **导出耗时** | **13.33 s** > 2 s 门 |

碰撞已经按构造成立（配额驱动），与"组内怎么挑行"无关；13.33 s 全部来自组内**精确指派**
（第 1 层被切成 1024 行块后仍是若干 1024×1024 的匈牙利）。因此本臂只改指派算法，不动配额。

## 一、主张（一句话）

配额继续按父前缀条件化（碰撞由它保证），组内指派改为**向量化贪心**：按计划质量降序把行放进仍有配额的码、
剩余行在剩余配额内按代价补齐；与精确解的代价差以 ≤1e-2 为门，导出时间回到 2 s 以内。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157 起，不改）**：`ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **条件配额（沿用 #162，不改）**：第 1 层均匀配额（`⌊B/256⌋` + 余数）；第 2 层在每个一级组内均分
   到 256 个二级码；第 3 层在每个二级前缀内均分到 256 个三级码。
4. **组内指派（本臂唯一改动）**：把 `linear_sum_assignment` 换成向量化贪心——
   按 `plan_ik` 降序对行做一次全局 `sort`，用"码的剩余配额"做并行计数器（`cummax`/`scatter`），
   同一次遍历内完成指派；未分到码的行在剩余配额内取最小代价补齐（同样向量化）。
   与精确解的代价差以 ≤1e-2 为门（不要求 1e-9）。
5. **保持不变**：代价函数、Sinkhorn 本体与 `ε=0.003` / `50 sweeps` / centring、残差递推、读出、导出、
   三 token 结构；配额规则、父前缀分组、开关语义不变。
6. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，逐位等于基线；**本臂必须真正接到模块常量**，
   #162 未接）、`GEOMETRY_OFF`（`c=0`）、`BOTH_ON`（出厂）。

## 三、验收（派发前，全量导出 + 冻结探针，全部可测）

1. **入口碰撞 ≤ 0.05**：未训练全量导出（24587）的 `1 − 不同三元组/商品数`；训练后同规则再测。
2. **导出时间 ≤ 2 s**（本臂的核心门），并单列各层耗时。
3. **贪心质量**：每组内贪心总代价对同组精确解相对差 ≤ 1e-2（组行数 ≤ 1024 时可比；更大的组按抽样）。
4. **容量恒等式**：每个父前缀下各子码计数等于配额；行和恰 1。
5. **接线**：`ROUNDING_OFF` 与基线逐位一致（含导出，**这次要真接上**）；训练与导出取同一码。
6. **两臂差分学习**：R 改善 ≥ N 的 2 倍（分母为负时 `R ≥ 2·max(N,0)`）。
7. **尺度不变性 / 曲线耦合**：`d` 乘 0.25/4 时两项变化 ≤ 1e-6；`c=0` 与 `c=1` 损失不同（1e-6）。
8. **训练中护栏**：逐层 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`，越界即 FAIL 停止。
9. **rank-batch 耗时 ≤ 0.15 s**（#162 未测）。
10. **TDD**：先写会失败的测试（配额恒等式、贪心与精确解差、`ROUNDING_OFF` 恒等、c=0 极限、
    训练/导出同码），确认红后再实现。任一门不过即预派发负结果，不派发。

## 四、边界与不变项

- §19h：继续使用均衡分配（计划 + 配额指派），Sinkhorn 本体不变。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 取舍写清：放弃 1e-9 的精确性换取时间预算；因为**碰撞由配额保证**，近似指派只影响组内"谁拿哪个码"，
  不影响碰撞、不影响"每个父前缀下子码计数等于配额"这两条。
