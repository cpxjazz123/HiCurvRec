Idea：把平衡取整从末级推广到**三级**（修正 #159 的上游坍缩）
英文名称：Three-Level Balanced Assignment (corrected from #159)

#159 第一次证明"地基层"可以做对，也第一次把坍缩的位置钉死在上游：

| 观测 | 数值 |
|---|---|
| 末级取整的效果 | 最大码份额 **0.378%**、导出用满 **256/256** 码（取整完全做到） |
| 上游一、二级（仍是 `argmin`） | 二级不同前缀 **59**（基线 15860），L1 Hard ER 0.9976（参照 16.14） |
| 同一导出路径、未训练模型 | 入口碰撞 **0.3021**；训练 3000 epoch 后 **0.9510** |

结论：取整规则本身是对的，但它只保护了自己那一层；**训练把一、二级的前缀分布压塌了**，
而一、二级没有任何容量约束。修法不是再改目标函数，而是把同一条规则用到需要它的所有层级。

## 一、主张（一句话）

三级统一由"均衡计划 + 保列和取整"产生硬码：每层都有同一 ε、同一迭代数、同一均匀列目标的
Sinkhorn 计划，再按计划质量取整；码占用在**每一层**按构造成立，前缀坍缩失去通道。

## 二、设计

1. **结构证据（沿用，不重建）**：AF3、`q05/q95`、`u_e`、高/低边集、全高三角形表，SHA `017e47e9…`。
2. **结构监督（沿用 #157/#159，不改）**：`ρ_e = d_e / mean_batch(d)`、`L_rank = softplus(ρ_b − ρ_h)`、
   `L_spread = relu(σ_min − std(ρ))`（`σ_min = 0.48247611144034613`）、ρ 量纲三角项，`λ = 1`。
3. **三级统一分配（本臂唯一改动）**：第 1、2、3 层都走
   `plan_l = structured_sinkhorn(centred_cost_l, ε, 50, uniform)` → `index_l = round_plan(plan_l)`；
   取整规则与 #159 相同（列容量最大余数法 + 按 `plan` 质量降序指派 + 剩余行最小代价补齐）；
   训练与导出同一函数，导出在完整商品集上确定性执行一次。
4. **保持不变**：代价函数、`SK_EPSILON=0.003` / `SK_ITERS=50` / centring、残差递推、读出、导出、
   三 token 结构；不引入桶/掩码/π/层心平移；商品级 SID 全局一致。
5. **开关**：`ROUNDING_OFF`（三层退回基线 `argmin`，逐位等于基线）、`GEOMETRY_OFF`（`c=0`）、
   `BOTH_ON`（出厂）；只要求实现正确与廉价接线检查，不训练关闭臂（§19g）。

## 三、验收（派发前，冻结探针，全部可测）

1. **逐层占用按构造成立**：三层各自 `codes_used ≥ 240/256`、最大码份额 ≤ 1.5%、每码行数 ≤ `⌈B/K⌉`。
2. **前缀多样性（新增，直接针对 #159 的失效）**：冻结探针上构造 SID，二级不同前缀 ≥ `0.5·B`（B 为探针行数；
   基线同探针实测作分母），入口碰撞 ≤ 0.40；未训练模型与训练后同规则各测一次。
3. **逐层保真**：每层取整代价 ≤ 该层计划自身代价 × 1.01；与精确求解器的差距只作诊断。
4. **运行时间**：三次 Sinkhorn + 三次取整 ≤ 0.1 s / rank-batch（基线 0.27 s/epoch，不得超过 40%）。
5. **两臂差分学习**（沿用协议）：同 seed/数据顺序/固定 200 步/训练器优化器；R 改善 ≥ N 的 2 倍
   （分母为负时用良定义形式 `R ≥ 2·max(N,0)`）。
6. **尺度不变性 / 曲线耦合**：`d` 乘 0.25/4 时两项变化 ≤ 1e-6；`c=0` 与 `c=1` 损失不同（1e-6）。
7. **接线与一致**：`ROUNDING_OFF` 与基线逐位一致（含导出）；同一商品集上训练与导出取同一码。
8. **训练中护栏**：每个评估 epoch 逐层检查 `codes_used ≥ 128`、`max_bucket_share ≤ 10%`，
   越界即 FAIL 停止（#159 的坍缩本应在这里被拦下）。
9. **TDD**：先写会失败的测试（逐层行和/列容量、前缀多样性构造、`ROUNDING_OFF` 恒等、c=0 极限、
   训练/导出同码），确认红后再实现。
10. 任一门不过：按预派发负结果记录并停止，不改容量规则、不改 λ/ε/迭代数，不派发。

## 四、边界与不变项

- §19h：本臂**显式申请**把一、二层的选码从 `argmin` 改为"均衡计划 + 取整"（三层同规则）；
  均衡分配本体仍是 Sinkhorn（同一 ε、同一迭代数、同一 centring、同一代价），不是用普通 `argmin` 取代均衡。
- 3000 epoch、全局 batch 4096、seed 42、四卡；单次正式训练；不做消融/调参/多种子（§19g）。
- 结构证据只来自训练划分；源码无绝对路径；`/tmp` 不落产物。
- 风险：三层都平衡会改变基线的缩写行为（前缀多样性可能偏高而语义变差）；这一风险由 Stage3 的
  `test_R@10` 判定，不在派发前用指标替代。

## 五、与 #159 的差异（必须逐条写进规格）

| 项 | #159 | 本臂 |
|---|---|---|
| 分配层级 | 只有末级有均衡计划 + 取整 | **三级同规则** |
| 一、二层 | 基线 `argmin`（无容量约束） | Sinkhorn（均匀列目标）+ 取整 |
| 上游坍缩 | 实测二级前缀 59 | 由逐层占用与前缀多样性两门前置检查 |
| 其余 | 不变 | 不变 |
