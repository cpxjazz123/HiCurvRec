IDEA: gromovcrit-deepest-split
TITLE: A one-sigma prefix-confusion gate over a Gromov-delta cut certificate for behaviour-targeted splits of the deepest RQ-VAE SID level
MOTIVATION: The previous round executed a certificate-valid but coverage-first move set and edited about one third of the catalogue; the deep level of the SID therefore stopped being a stable refinement of the prefix and the validation L1 negative hit rate fell. The real failure mode of a generative recommender is not a badly partitioned catalogue, it is a small set of high-mass prefixes whose top-two deepest codes are statistically indistinguishable, so that the frozen Stage-3 model cannot commit to the correct continuation. Only those prefixes are worth editing, and only if the edit widens a geodesic decision margin.
NOVELTY: Unlike the earlier successor-Frechet codebook updates, per-level curvature control and behaviour-ranked radial assignment, this mechanism never touches the codebook, the curvature, the encoder or the training of Stage 2. It is a post-Stage-2 relabelling that changes only level L, and its new element is an ADMISSION TEST that a move must pass on top of the certificate: the move must touch a critical-confusion pair, defined by a one-Poisson-sigma band on the training-split top-two deepest-code counts for a frozen prefix, together with the condition that the competitor is the geodesically nearest competing code as seen from the prefix behaviour centroid. A move that merely preserves the hyperbolic tree structure is rejected unless it demonstrably sharpens a margin the frozen Stage-3 context actually has to resolve.
CHANGE: Successor transitions from the training split produce a Poincare successor barycentre per item and a prefix-conditional deepest-code confusion table; a critical-confusion set is extracted from that table by a one-sigma counting band; a curved split of the confusable code is proposed on the successor barycentres of only the successor items of critical prefixes; and the split is written into the SID table only if a Gromov-delta cut certificate holds on the split and the Poincare margin of every triggering critical prefix strictly increases.
SPECIFICATION:
Notation. L RQ levels; item i has code (k_1(i),...,k_L(i)) with prefix p(i) = (k_1(i),...,k_{L-1}(i)) frozen and bit-identical throughout. c_k in B^d is the frozen Stage-2 level-L centroid of code k, curvature kappa = -1, Poincare distance d_P, ball radius 1. z_i is the frozen Stage-2 item latent used by the deepest level. All statistics come from the training split only.
1. Successor geodesic barycentre. With directed training counts A_ij, rowsum n_i = sum_j A_ij, training popularity pop_j:
   w_ij = (A_ij / n_i) / sqrt(pop_j), renormalised to sum_j w_ij = 1 over j with A_ij > 0;
   b_i = exp_0( sum_j w_ij * log_0(z_j) ), and b_i = z_i when n_i = 0.
2. Prefix behaviour centroid. For prefix p with item set P_p, b_bar_p = exp_0( sum_{i in P_p} (n_i / sum_{i' in P_p} n_{i'}) * log_0(b_i) ).
3. Prefix confusion table. For every training transition i -> j, increment N(p(i), k_L(j)). n_p = sum_k N(p,k). k1(p) = argmax, k2(p) = second largest in N.
4. Critical set (THE ADDITIONAL PRECISION CONDITION). p is critical iff
   (C1) N(p,k1) - N(p,k2) <= sqrt(N(p,k1))   [one-Poisson-sigma band; derived from the counts, sigma = 1 is the standard one-standard-error rule, not a swept constant]
   (C2) k2 in argmin_{k != k1, N(p,k) > 0} d_P(b_bar_p, c_k)   [nearest competing code under the frozen Stage-2 geometry]
   Base margin M0(p) = d_P(b_bar_p, c_k2) - d_P(b_bar_p, c_k1).
5. Surgical move target. S* = { j : j is a successor under some critical p } intersect { j : k_L(j) = k1 }. Only items in S* may change their code; every other item keeps its code.
6. Curved split proposal for code k1. m = Frechet mean of {b_i : k_L(i)=k1} (Karcher iteration, 5 steps). U = { i in S* : d_P(b_i, b_bar_p) < d_P(b_i, m) }. Seed m_a = Frechet mean of U, m_b = Frechet mean of S*\U; run 3 alternating rounds of assignment by d_P and Frechet-mean update. Split k1 into k1' = the part whose centroid is geodesically nearer b_bar_p and k1'' = the other part, with centroids m' and m''.
7. Certificate, split side (necessary, inherited in spirit from the previous round). With the metric induced by {b_i : i in S*}, Gromov product (x|y)_o = 0.5*(d_P(o,x)+d_P(o,y)-d_P(x,y)), o the ball origin, and cluster defect
   delta_S = 0.5 * max_{x,y,z in S*} max(0, (x|y)_o - min((x|z)_o, (z|y)_o))   (deterministic index-stride sampling of triples when |S*| > 200),
the split is admissible iff
   (S-a) d_P(m', m'') >= 2*max(rad(k1'), rad(k1'')), rad(X) = median_{i in X} d_P(b_i, m_X);
   (S-b) delta_S - delta_{S after split} >= 0.5 * delta_S;
   (S-c) cross-transition mass between the two parts <= median_{i in S*} sum_{j in S*} A_ij.
8. Certificate, merge side. Two level-L codes ka, kb may be merged only if both are members of no critical pair, d_P(m_ka, m_kb) <= min(rad(ka), rad(kb)), the merged cluster defect is <= max(delta_ka, delta_kb), and the directed transition mass between them exceeds the within-median of clause (S-c). Merges exist to keep the level-L vocabulary size from growing and to make the both-off ablations well defined; a merge is executed only when the split budget has been exhausted.
9. Execution rule. A split is written only if clauses (S-a),(S-b),(S-c) hold AND the margin rule M1(p) > M0(p) holds for every critical p that triggered it, with M1(p) = d_P(b_bar_p, m'') - d_P(b_bar_p, m'). Recompute the confusion table from step 3 and repeat, at most 3 rounds, stopping earlier when no move is admitted. Three is a fixed documented default, not a tuned value.
10. Mandatory reporting (recorded, never used as a gate): moved fraction |{i : k_L changed}| / 24556; validation L1 negative hit rate before and after the edit; per-item deepest-code conditional entropy H(K_L | p) computed on training transitions, before and after, reported mass-weighted and for every touched prefix.
COST: Zero added FLOPs per training step in both stages, because Stage 2 is already frozen and Stage 3 consumes the same SID tensor shape with different integers. The one-off edit dominates: at most 3 rounds over at most 24556 successor tokens, and within each round only the clusters S* of critical codes need pairwise Poincare distances (|S*| well under 10^3, so < 10^6 geodesic evaluations per round, < 3*10^6 total, each an O(d) log/exp-map evaluation). That is roughly 7*10^6/72000 = ~97 geodesic evaluations per frozen Stage-2 step amortised over 3000 epochs x 24 steps, i.e. wall clock minutes (2-6 min on one GPU, ~10 min on CPU) against hours for the 3000-epoch four-card Stage-2 run and the 150-epoch Stage 3, so under 1 percent of total wall clock. Memory: one dense successor row set plus the confusion table, O(nnz(A) + n_p * K_L) integers.
HYPOTHESIS: If the deepest-level loss is driven by genuine top-two confusion on high-mass prefixes rather than by noise, then a precision-first edit that touches only the successor items of one-sigma-indistinguishable prefixes will (i) move a small fraction of the catalogue, well below the previous one third, (ii) leave the validation L1 negative hit rate unchanged or better rather than degrading it, (iii) lower the deepest-code conditional entropy of the touched prefixes, and (iv) raise Stage-3 test_recall@10 above 0.065. Observed directly from the outputs of the single frozen Stage-3 run; if the moved fraction is small and recall does not move, the confusion hypothesis is falsified and the negative result is recorded with numbers.
RISKS: The critical set may be empty (over-precision), giving zero moves and a null result; Stage 3 conditions on the full L-level code so an improvement in the level-L margin may not alter its argmax; the successor barycentre is popularity-adjusted only to first order and may still be dominated by head items; Gromov-delta estimation on small S* is noisy and could admit a spurious cut; the training-split confusion ranking may not transfer to the test successor distribution; one seed means seed noise is inside the reported number.
BEHAVIOR SIGNAL: Popularity-adjusted directed item-transition counts from the training split, aggregated into a prefix-conditional deepest-code confusion table, plus the first-order successor geodesic barycentre of every item.
BEHAVIOR COMPUTATION: From the training split interaction sequences only: count every ordered pair (i, j) with j following i inside the same training sequence, giving A_ij; row-normalise and down-weight by 1/sqrt(pop_j) to give w_ij; build b_i by log/exp-map barycentre of successor latents; accumulate N(p(i), k_L(j)) over the same transition set. Validation and test interactions are never read by any of these three computations.
LEAKAGE BOUNDARY: The SID edit reads only A_ij and pop_j from the training split and only parameters of the frozen Stage-2 model, which itself was trained on the training split. The critical set, the certificate and the margin rule are all functions of training counts and frozen centroids, so no validation or test interaction can influence which code an item receives. The validation L1 negative hit rate is computed after the SID table is frozen and is written to the log as a diagnostic only; it is never compared against a threshold inside the mechanism and never reverts a move.
HYPERBOLIC OPERATOR: Poincare ball with fixed negative curvature kappa = -1: exponential and logarithmic maps at the origin, Poincare distance d_P, Karcher/Frechet means, and the Gromov product (x|y)_o with the induced delta-hyperbolicity defect of a cluster.
HYPERBOLIC LOCATION: At quantization/SID-construction time, after the frozen 3000-epoch Stage 2 and before the frozen 150-epoch Stage 3, acting only on the level-L code assignment; also inside the split proposal, where the two-way assignment and the centroid updates are geodesic rather than linear.
COUPLING PATH: training transitions -> popularity-adjusted successor barycentres b_i -> prefix behaviour centroid b_bar_p -> one-sigma critical-confusion set -> surgical target set S* -> geodesic two-means on {b_i : i in S*} -> Gromov-delta cut certificate -> level-L code rewrite. The behaviour signal decides WHICH items may move and the curved operator decides WHETHER the move is structurally sound and margin-improving; removing behaviour empties or randomises S*, removing curvature changes every distance, mean and defect in the same chain, and in both cases the rewritten code table differs.
COUPLING EQUATION: admit(k1 -> k1', k1'') = 1[ N(p,k1) - N(p,k2) <= sqrt(N(p,k1)) ] * 1[ d_P(b_bar_p, c_k2) - d_P(b_bar_p, c_k1) < d_P(b_bar_p, m'') - d_P(b_bar_p, m') ] * 1[ d_P(m',m'') >= 2*max(rad', rad'') ] * 1[ delta_S - delta_{S'} >= delta_S/2 ], where the first factor is the behaviour term, the second and third are the curved margin and separation terms, and the fourth is the curved tree-structure term; all factors are required simultaneously for the rewrite to happen.
OBSERVABLES: moved fraction of the 24556 training items; validation L1 negative hit rate before and after; per-item deepest-code conditional entropy before and after, mass-weighted and per touched prefix; the number of critical pairs found and the number of admitted versus rejected moves in each round; and finally Stage-3 test_recall@10 of the single trained run.
ABLATION BEHAVIOR OFF: b_i := z_i (content only, no successor barycentre), the critical set is computed with N replaced by a uniform count table so that every prefix is either maximally or minimally critical by index order, and S* collapses to the whole k1 cluster; the certificate and the margin rule are unchanged. This switch exists in the code, is unit-tested, and is never trained.
ABLATION GEOMETRY OFF: d_P replaced by the Euclidean norm, exp_0/log_0 replaced by identity, Frechet means by arithmetic means, and the Gromov-defect clauses (S-b) and the merged-defect clause replaced by the always-true predicate. The behaviour signal, the critical set and the margin rule are unchanged, so the only difference is the curve. This switch exists in the code, is unit-tested, and is never trained.
ABLATION BOTH ON: the full mechanism of steps 1-9 with kappa = -1 and the popularity-adjusted successor barycentre, one training run on the frozen budget, no early stopping, the frozen Stage-3 protocol of 150 epochs.
SPEC EQUATIONS:
  d_P(u,v) = arcosh(1 + 2||u-v||^2 / ((1-||u||^2)(1-||v||^2)))
  log_0(x) = arctanh(||x||) * x/||x||,  exp_0(y) = tanh(||y||) * y/||y||
  bary({x_i, a_i}) = exp_0( sum_i a_i log_0(x_i) ),  sum_i a_i = 1
  Karcher: m <- exp_m( sum_i a_i log_m(x_i) ), 5 iterations, step clamped to 0.5
  w_ij = (A_ij/n_i)/sqrt(pop_j) normalised;  b_i = bary({z_j}, {w_ij})
  b_bar_p = bary({b_i : i in P_p}, {n_i / sum n})
  N(p,k) += 1 for each training transition i->j with p(i)=p, k_L(j)=k; n_p = sum_k N(p,k)
  critical(p) = [N(p,k1)-N(p,k2) <= sqrt(N(p,k1))] and [k2 = argmin_{k != k1, N(p,k)>0} d_P(b_bar_p, c_k)]
  M0(p) = d_P(b_bar_p, c_k2) - d_P(b_bar_p, c_k1);  M1(p) = d_P(b_bar_p, m'') - d_P(b_bar_p, m')
  (x|y)_o = 0.5*(d_P(o,x) + d_P(o,y) - d_P(x,y))
  delta_S = 0.5 * max_{x,y,z in S} max(0, (x|y)_o - min((x|z)_o,(z|y)_o))
  rad(X) = median_{i in X} d_P(b_i, m_X)
  pseudocode:
    for round in 1..3:
      N := confusion_table(current level-L codes, A)
      C := [(p,k1,k2,M0) for p if critical(p)]
      if C empty: break
      Sstar := union over C of successors(p) restricted to k_L = k1(p)
      for each k1 in keys(Sstar):
        (m', m'', U) := geodesic_2means({b_i : i in Sstar}, b_bar of triggering p)
        if not (S-a and S-b and S-c): reject, continue
        if not all(M1(p) > M0(p) for triggering p): reject, continue
        commit k_L(j) := k1' for j in U, k1'' for j in Sstar\U
      assert hash(k_1..k_{L-1}) unchanged
    report moved_fraction, val_L1_negative_hit_rate(before, after), H(K_L|p)(before, after)
SPEC INPUTS OUTPUTS: Inputs are the training-split transition counts A_ij, training popularity pop_j, the frozen Stage-2 level-L centroids c_k, the frozen item latents z_i, and the frozen prefixes p(i). Outputs are a rewritten level-L code for a subset of items, an unchanged prefix table (asserted by hash), a per-round move log with admitted and rejected counts, and the three mandatory diagnostics.
SAFEGUARDS: clamp ||x|| <= 1 - 1e-5 before every arcosh and arctanh and add 1e-8 inside the arcosh argument; Karcher step clamped to 0.5 and stopped after 5 iterations; reject any move with |U| < 3 or |S*\U| < 3, or with rad(X) = 0, or with delta_S = 0 (nothing to certify); deterministic tie-breaking by lowest code index everywhere; assert that the multiset of prefixes is bit-identical before and after the edit; cap the number of splits by the number of merge-admissible codes so the level-L vocabulary cannot grow without bound; if the critical set is empty or every move is rejected, write the unchanged table and record a zero-move result rather than relaxing any threshold.
END IDEA
