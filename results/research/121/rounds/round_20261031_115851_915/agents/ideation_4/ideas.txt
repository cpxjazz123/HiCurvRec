IDEA: HORO-TRANSPLANT-L
TITLE: Ideal-boundary horosphere transplant of the deepest RQ code, gated by a constant-free geodesic surprisal test against the frozen Stage-2 child anchors
MOTIVATION: The frozen Stage-2 RQ-VAE assigns the deepest code k_L by residual nearest-neighbour in Euclidean space, so two items a user actually moves between in one session can sit under different deepest tokens while their L-1 prefixes agree. Stage 3 can only exploit a deepest-code improvement if the prefix it is conditioned on still points at that token; the previous round moved a third of the catalogue on a certificate that was necessary but not sufficient, and the validation L1 negative hit rate caught it. This idea repairs only the deepest level, and only where a curved membership test and a curved no-harm test agree, so the move set is small and every move is one the frozen prefix context can support.
NOVELTY: Prior rounds in this programme used (i) successor-weighted Frechet updates of codebook vectors, (ii) a per-level curvature scalar set by prefix-transition hardness, (iii) behaviour-ranked radial Poincare assignment with per-item curvature from context entropy. This mechanism uses none of those objects: it uses the IDEAL BOUNDARY of the Poincare ball (Busemann functions, horoballs), a purely negatively-curved construct with no Euclidean analogue that is neither a radius, nor a curvature scalar, nor a codebook mean; it acts after Stage 2 as a discrete transplant of the deepest code only, leaving levels 1..L-1 bit-identical; and its precision ingredient is a sign test on a geodesic surprisal DIFFERENCE, which contains no tunable constant.
CHANGE: Every item gets one hyperbolic Busemann height coordinate toward each sibling child cell's ideal boundary point; the destination child is chosen by training-split directed successor affinity, the item moves only if it lies inside that child's behaviour-implied horoball AND the move does not raise its geodesic distance to the child's frozen Stage-2 anchor relative to its current one, and only if a two-sided structural certificate holds.
SPECIFICATION: Notation. N=24556 training items; frozen Stage-2 RQ-VAE with L levels and per-level codebook size K (K_L children per parent); z_i the frozen encoder latent; SID(i)=(k_1..k_L); parent p(i)=(k_1..k_{L-1}); S_p={i: p(i)=p}; Ch_p={k_L(i): i in S_p}. Only k_L may change.
Step 0 (behaviour, training split). M[i,j] = number of consecutive training-split pairs (u_t=i, u_{t+1}=j) over all training sessions, deduplicated per user so a repeated pair counts once per user. pop_i = number of training users who interacted with i.
Step 1 (curved embedding, fixed curvature). Deterministic 4096-item training sample S0 (the 4096 smallest training item ids). s = median over ordered pairs of S0 of ||z_i - z_j||_2 / 2. x_i = exp_0(z_i/s) = tanh(||z_i/s||) * (z_i/s)/||z_i/s|| in the Poincare ball of radius 1, constant curvature K=-1; clip ||x_i|| <= 1-1e-3. d_H(x,y) = arcosh(1 + 2||x-y||^2/((1-||x||^2)(1-||y||^2))). s and the clip are derived, not tuned.
Step 2 (child anchors, ideal boundary). For each parent p and k in Ch_p: m_{p,k} = Frechet mean of {x_i : i in S_p, k_L(i)=k} under d_H, by exactly 8 Riemannian gradient steps of size 1/8 from the Riemannian centroid (fixed, deterministic). xi_{p,k} = m_{p,k}/||m_{p,k}||; if ||m_{p,k}|| < 1e-6 fall back to x_j/||x_j|| for the highest-pop member j.
Step 3 (Busemann / horosphere). B_{p,k}(x) = log((1-||x||^2)/(2||x-xi_{p,k}||^2)). Only differences of B are used, so its additive normalisation is irrelevant.
Step 4 (behaviour-implied horosphere height, derived). Wbar[k->j] = (sum_{i in child k} M[i,j])/(pop_k pop_j); R_{p,k} = { j not in S_p : Wbar[k->j] > 0 }; h_{p,k} = median over j in R_{p,k} of B_{p,k}(x_j). Measured, no free constant.
Step 5 (candidate for item i in child a). b(i) = argmax over k in Ch_p, k != a of sum_{j in child k} (M[i,j]+M[j,i])/sqrt(pop_i pop_j), ties by smallest code index. D_i = B_{p,b}(x_i) - h_{p,b} (>=0: inside b's behaviour-implied horoball). Delta_i = d_H(x_i,m_{p,b})^2 - d_H(x_i,m_{p,a})^2 (<=0: geodesic surprisal not increased).
Step 6 (necessary two-sided certificate). Split side: |child a| >= 2 and i is not a cut vertex of the within-cell 1-NN behaviour graph G_a (nodes = members of child a, each node joined to its top-1 behaviour neighbour inside the cell, affinity as above, ties by item id); this keeps each deepest code's behaviour connectivity, which is what the frozen prefix was trained against. Merge side: b(i) already exists in Ch_p (no new code is created) and no child code of p is emptied by the batch.
Step 7 (sufficiency gate, the new precision condition). Accept iff certificate passes AND D_i >= 0 AND Delta_i <= 0. Justification with no tuned constant: m_{p,k} are the frozen Stage-2 level-L code vectors carried into the ball by an isometry, so the frozen quantiser's preference for token k given prefix p is monotone decreasing in d_H(x_i, m_{p,k}); a move with Delta_i > 0 makes the item strictly less reachable by the frozen prefix-to-token map, so any behaviour-coherence gain cannot be realised at generation time. Delta_i <= 0 is the sign of a difference, hence the unique constant-free cut, and it is measured entirely from the training split and the frozen Stage-2 geometry.
Step 8 (application). Exactly one synchronous pass per parent (no iteration: a fixed point is not guaranteed and would need a stopping constant). Accepted moves apply simultaneously; if the batch empties a child code of p, revert the single highest-pop moved-out item so the Stage-3 vocabulary set is unchanged. Report moved fraction, validation L1 negative hit rate before/after, per-item deepest-code conditional entropy before/after.
COST: Essentially zero training cost. Stage 2 unchanged at 3000 epochs (24556 items, 24 steps/epoch, 72000 steps); Stage 3 unchanged at the frozen 150 epochs with unchanged vocabulary size. One offline pass between stages: per parent O(|S_p| * K * d) sibling affinities plus O(|S_p| * |Ch_p|) Busemann evaluations, total about 24556 * 256 * 64 ~= 4.0e8 multiply-adds plus one 1-NN graph, i.e. well under one CPU-minute; peak memory |S_p| * K floats because parents are streamed. Per-step added cost at the frozen scale: 0 flops on any of the 72000 Stage-2 steps and 0 on any Stage-3 step.
HYPOTHESIS: If the deepest code is where behaviour coherence is destroyed while the prefix context is still usable, a horosphere-gated transplant will lower per-item deepest-code conditional entropy for moved items, leave the validation L1 negative hit rate exactly unchanged, and push Stage-3 test_recall@10 above 0.065. Worth keeping if moved fraction is roughly 1-10%, entropy drops for moved items, and Recall@10 improves; refuted if a few percent move and Recall@10 is flat or worse, meaning the deepest level is not where the Stage-3 loss concentrates.
RISKS: The move set may be too small to shift Recall@10 (the deepest token carries only part of the generation loss). The monotone assumption behind Delta (Stage 3's prefix-to-child preference tracks geodesic distance to m_{p,k}) may fail, rejecting the moves that would help. Single-child parents, or parents whose children hold only singletons, contribute nothing. The 1-NN cut-vertex test is noisy on sparse low-popularity behaviour graphs. A pure label transplant with no codebook change can interact badly with an already-overfit Stage-3 last-token head.
BEHAVIOR SIGNAL: Directed item-to-item transition counts from consecutive interactions, popularity-normalised and aggregated to deepest-cell successor flow. Training split only.
BEHAVIOR COMPUTATION: For every training session, take each consecutive pair (u_t, u_{t+1}) with u_t != u_{t+1}, count once per user into M, using only items present in the training split; pop from the same split. Then Wbar[k->j] = sum_{i in child k} M[i,j]/(pop_k pop_j), and the per-item affinity to a sibling cell is sum_{j in child k} (M[i,j]+M[j,i])/sqrt(pop_i pop_j). Only the stage-2 training split file is opened.
LEAKAGE BOUNDARY: M, pop, s, S0, child anchors, horosphere heights and the accept set are functions of the stage-2 training split and of the frozen Stage-2 weights (which saw only that split). Validation interactions are read only after the SID table is frozen, and only to print the L1 negative hit rate before/after; they never enter b(i), D_i, Delta_i or the certificate. Test interactions are never read before the single Stage-3 test evaluation.
HYPERBOLIC OPERATOR: Poincare ball of radius 1, fixed constant negative curvature K=-1; exp_0 injection with data-derived scale s; geodesic distance d_H = arcosh(1 + 2||x-y||^2/((1-||x||^2)(1-||y||^2))); Busemann function B_{p,k}(x) = log((1-||x||^2)/(2||x-xi_{p,k}||^2)) toward the ideal boundary point xi_{p,k}; horoball membership D_i >= 0; Riemannian (Frechet) child anchors by 8 fixed gradient steps.
HYPERBOLIC LOCATION: After Stage-2 training is frozen and before Stage-3 training begins, as a discrete reassignment of the level-L index only; it acts on the SID table, on no weight.
COUPLING PATH: training transitions -> per-parent successor flow -> destination child b(i) and behaviour-implied horosphere height h_{p,b} -> Busemann test D_i = B_{p,b}(x_i) - h_{p,b} -> joint with geodesic surprisal Delta_i against frozen child anchors -> accept/refuse -> new k_L -> Stage-3 labels. Behaviour fixes the destination and the height; curvature fixes the coordinate system and the test; neither half can decide acceptance alone.
COUPLING EQUATION: accept(i) = [|child a| >= 2] AND [i not a cut vertex of G_a] AND [B_{p,b(i)}(x_i) - h_{p,b(i)} >= 0] AND [d_H(x_i,m_{p,b(i)})^2 - d_H(x_i,m_{p,a})^2 <= 0], with b(i) = argmax_k sum_{j in child k} (M[i,j]+M[j,i])/sqrt(pop_i pop_j) and h_{p,k} = median_{j : Wbar[k->j]>0} B_{p,k}(x_j).
OBSERVABLES: (1) moved fraction |moved|/N, expected a few percent; (2) validation L1 negative hit rate, the fraction of (validation positive, fixed-seed validation negative) pairs whose level-1 tokens coincide, before and after - predicted bit-identical because k_1 is untouched, so it is a regression guard proving the earlier failure mode cannot recur; (3) per-item deepest-code conditional entropy H_i = -sum_k q_ik log q_ik over sibling children with q_ik proportional to the behaviour affinity, reported for moved items and for all items, before and after; (4) training-split successor rank of each item's own deepest code, before and after; (5) Stage-3 test_recall@10.
ABLATION BEHAVIOR OFF: M identically zero. Wbar empty, R_{p,k} empty, b(i) has no candidate, the mechanism produces exactly zero moves and the SID table equals the frozen Stage-2 table; the geometry code still runs but every accept test fails at the destination step.
ABLATION GEOMETRY OFF: Replace d_H by the Euclidean norm, xi_{p,k} by the normalised Euclidean mean direction, and B_{p,k}(x) by the linear functional <x, xi_{p,k}>, with h_{p,k} the median of that functional over R_{p,k}. The horoball becomes a flat half-space and Delta_i a squared Euclidean distance difference; the same accept rule then selects a different move set.
ABLATION BOTH ON: The full run above: behaviour affinity picks b(i) and sets h_{p,b}; the Poincare Busemann test and the geodesic surprisal sign test gate the move.
SPEC EQUATIONS: 1) s = median_{ordered pairs in S0} ||z_i - z_j||/2; x_i = tanh(||z_i||/s)*(z_i/||z_i||), clipped to ||x_i|| <= 1-1e-3. 2) d_H(x,y) = arcosh(clamp(1 + 2||x-y||^2/((1-||x||^2)(1-||y||^2)), 1+1e-8, inf)). 3) m_{p,k} = FrechetMean_{d_H}({x_i : i in S_p, k_L(i)=k}) with 8 Riemannian steps of size 1/8. 4) xi_{p,k} = m_{p,k}/||m_{p,k}||. 5) B_{p,k}(x) = log((1-||x||^2)/(2||x-xi_{p,k}||^2)). 6) Wbar[k->j] = sum_{i in child k} M[i,j]/(pop_k pop_j); h_{p,k} = median_{j in R_{p,k}} B_{p,k}(x_j). 7) b(i) = argmax_k sum_{j in child k} (M[i,j]+M[j,i])/sqrt(pop_i pop_j). 8) accept iff certificate(a,i,p) and D_i >= 0 and Delta_i <= 0, with D_i = B_{p,b}(x_i) - h_{p,b} and Delta_i = d_H(x_i,m_{p,b})^2 - d_H(x_i,m_{p,a})^2. 9) new k_L(i) = b(i) if accepted else k_L(i); one synchronous pass; revert the highest-pop mover if a child code of p would be emptied.
SPEC INPUTS OUTPUTS: Inputs: training split sessions; frozen Stage-2 encoder latents z_i for all training items; the frozen SID table (k_1..k_L) and level-L code vectors c_L[k]; the frozen codebook size K. Outputs: a new deepest-code column k_L' for a subset of training items (all other levels bit-identical), plus a report record {moved_fraction, L1_negative_hit_rate_before, L1_negative_hit_rate_after, deepest_code_entropy_before, deepest_code_entropy_after, cut_vertex_refusals, horoball_refusals, surprisal_refusals}.
SAFEGUARDS: clamp ||x_i|| <= 1-1e-3 at injection and after every Frechet step; clamp the arcosh argument to >= 1+1e-8; guard ||m_{p,k}|| < 1e-6 with the highest-pop member direction fallback; guard 1-||x||^2 > 0 in the Busemann logarithm via the clip; skip parents with |Ch_p| < 2 or with fewer than 2 items in every child; empty R_{p,k} leaves h_{p,k} undefined and forces refusal for that child; deterministic tie-breaks (smallest code index, then smallest item id) for bit-reproducibility; assert levels 1..L-1 unchanged for all N items and the Stage-3 vocabulary set size unchanged before running Stage 3; assert no validation or test id appears in M.
END IDEA
