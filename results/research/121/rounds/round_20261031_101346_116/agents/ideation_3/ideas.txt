IDEA: HYP-CERT-LEAFREPAIR
TITLE: Prefix-preserving, certificate-gated hyperbolic repair of the deepest SID code, scored by a behaviour-displaced Poincaré point
MOTIVATION: The measured Stage-3 failure is not a bad prefix tree but a bad local partition: behaviourally coherent items are split across cells while behaviourally disjoint items share a cell, and every previous attempt fixed it by rebuilding prefixes, which the last four rounds falsified. Stage 3 consumes only the item->SID tuple, so the map must move, but it can move in exactly one coordinate: the deepest code. This idea repairs only that coordinate, only where a training-split certificate proves the move cannot add a cross-cell coherent pair or a same-cell disjoint pair, and leaves levels 1..L-1 bit-identical.
NOVELTY: Earlier rounds changed the codebook (Poincaré--Fréchet successor updates), the curvature schedule (CURVCTRL per-level curvature from prefix-transition scores), the radial coordinate of assignment (BRad-RQ context-entropy radius), or re-solved the assignment wholesale. This changes none of those: the codebooks, the encoder, the metric of the quantizer and the prefix partition are frozen; the only mutable object is the last-level token of a certified subset of items, and the decision score is a product of a training-transition agreement term with a Poincaré distance measured from a behaviour-displaced point (a hyperbolic gyromidpoint of the item with its behavioural neighbours), not a Voronoi re-assignment.
CHANGE: After Stage-2 epoch 3000, one deterministic pass re-assigns the last RQ level only, scoring each candidate code by q_behaviour(k') * exp(-d_kappa(v_i, c_k)), where v_i is the curved behaviour-displaced position of item i; a move is taken only if a train-split admissibility certificate (no increase in split coherent neighbours, no increase in same-cell disjoint neighbours) plus a cell-radius geometric guard both pass.
SPECIFICATION: (1) From TRAIN sequences only, count directed consecutive pairs, symmetrise n_ij, form the popularity-adjusted log-ratio LR(i,j)=ln(n_ij*2N_pair/((n_i+1)(n_j+1))). Neighbourhood N(i) = top-M_i by n_ij where M_i is the smallest prefix covering 90% of item i's transition mass, capped at the measured 95th percentile of that M distribution. Weights w_ij=max(0,LR(i,j)), normalised to w_hat. (2) Measure the baseline's TRAIN-split L1 negative-hit rate r0 with the same estimator used as diagnostic, and fix the coherence bound B=ln((1-r0)/r0). (3) Curvature: unit Poincaré ball, kappa=1 (fixed negative curvature, curvature radius 1). For item i, r_i = z_i - mu_{p(i)} (frozen Stage-2 encoder output minus its frozen prefix-centroid), scale s = 7.6 / max_i||r_i|| (derived from artanh(1-1e-3)). Anchor a=phi(mu_{p(i)}); u_i = exp^kappa_a(s*r_i); c_k = exp^kappa_a(s*c^(L)_k); v_i = gyromidpoint of {u_i} U {u_j : j in N(i)} with weights {1} U {w_hat_ij}. (4) Candidates C_i = distinct a_j^L over j in N(i), excluding a_i^L. (5) Accept at most one move per item, processed in decreasing transition-mass order, exactly once, with the certificate of the SPEC EQUATIONS block.
COST: Zero added Stage-2 optimizer steps and zero added Stage-3 cost: 3000 epochs x 24 = 72,000 Stage-2 steps and the frozen 150-epoch Stage-3 protocol are unchanged, same token vocabulary and same sequence lengths. The repair pass is one shot after epoch 3000: graph build O(total train transitions), then 24,556 items x M_i neighbours (M_i typically 50-150) gyromidpoint iterations (10 Ungar steps) plus <= |C_i| <= 256 Poincaré distances: worst case about 5.7e8 scalar ops plus 3.7e6 integer certificate operations, under 2 minutes on one card if the per-item candidate block is vectorised, i.e. under 0.1% of Stage-2 wall clock and an amortised equivalent of about 1.7 ms per Stage-2 step at the frozen scale. Memory: one |I| x M_i index/weight block plus 24,556 x d ball coordinates.
HYPOTHESIS: The recall loss is concentrated in last-token confusion among behaviourally coherent items whose text residuals sit where curvature distorts the comparison; if so, moving them must lower the validation L1 negative-hit rate while leaving every prefix token fixed, and Stage-3 test recall@10 must exceed 0.065 with a measurable fraction of moved items (expected single-digit percent). It is worth keeping only if (a) at least a few hundred moves are certified, (b) validation negRate@L1 falls, and (c) test recall@10 > 0.065; otherwise the no-op / small-move outcome is recorded with its numbers as a negative result.
RISKS: The candidate set C_i is built from neighbours' leaf codes, so items whose behavioural neighbours all live under different prefixes may yield no admissible move and the mechanism degenerates to an exact no-op (recall identical to baseline). The certificate may bind almost everywhere and admit only a handful of moves, giving no measurable effect. The cell-radius guard can veto precisely the boundary items the mechanism targets. Changing the last token for a few items perturbs Stage-3's last-level token statistics, which could cost more than it gains. The disjointness objective may be only weakly correlated with next-item recall. Fixed kappa=1 with data-driven scaling means the geometric term may be nearly Euclidean in effect, making the geometry-off comparison numerically close even though the code path differs.
BEHAVIOR SIGNAL: Popularity-adjusted directed transition association between items, taken as a truncated, weighted behavioural neighbourhood graph per item.
BEHAVIOR COMPUTATION: From TRAIN-split user sequences only: count consecutive directed pairs (i->j), symmetrise n_ij = n_ij^dir + n_ji^dir, marginals n_i, total pair mass 2N_pair, then LR(i,j)=ln(n_ij*2N_pair/((n_i+1)(n_j+1))) with add-one smoothing as a documented default; neighbourhood = smallest top-M_i covering 90% of sum_j n_ij, capped at the measured 95th percentile of M; weights w_ij=max(0,LR(i,j)) normalised per item. The coherence bound B is computed from r0, the baseline's TRAIN-split L1 negative-hit rate.
LEAKAGE BOUNDARY: The graph, the weights, M_i, r0 and therefore B are all computed from TRAIN sequences; the Stage-2 encoder outputs and codebooks used are those fitted on TRAIN text embeddings; the repair never sees validation or test interactions, never sees validation item pairs, and never re-fits anything. Validation is read exactly twice, only to evaluate negRate@L1 before and after the repair, and that number is a reported diagnostic, never a gate, threshold or stopping signal. Test data is untouched until the frozen Stage-3 evaluation.
HYPERBOLIC OPERATOR: Poincaré-ball exponential and logarithmic maps at a prefix anchor, Möbius addition, the Poincaré distance d_kappa(x,y)=(2/sqrt(kappa))*artanh(sqrt(kappa)*||(-x) xor_kappa y||), and the Ungar gyromidpoint, all with fixed negative curvature kappa=1 (unit curvature radius, so the effective curvature is -1/R^2 with R=1) and a scale s derived from the data maximum.
HYPERBOLIC LOCATION: In the quantisation step, after Stage-2 converges and before Stage 3: it defines the geometry in which the deepest-level candidate codes are compared and in which the item's behaviour-displaced position is built. It acts on the discrete assignment produced by the RQ-VAE, not on the encoder or the codebook parameters.
COUPLING PATH: Behaviour weights enter the same scalar that curvature evaluates: the item's position v_i is the hyperbolic gyromidpoint of its own curved residual point with its behavioural neighbours' points (so the coordinate itself is behaviour-conditioned), and the candidate score multiplies the neighbour agreement count by the curvature-distorted distance from that displaced point to the candidate code. Removing behaviour sets v_i:=u_i and q:=uniform, so all candidates differ only by text geometry; removing curvature (kappa->0, phi=id, exp=id, distance=Euclidean, gyromidpoint=weighted mean) changes v_i and every d_kappa, so a different code wins. Either removal changes the accepted move set, hence the emitted SIDs.
COUPLING EQUATION: S_i(k') = q_i(k') * exp( -d_kappa( v_i , c_{k'} ) ), with q_i(k') = sum_{j in N(i)} w_hat_ij * 1[a_j^L = k'] and v_i = gyromid_{kappa}( {u_i} U {u_j}_{j in N(i)} ; {1} U {w_hat_ij} ), u_i = exp^kappa_{phi(mu_p(i))}( s*r_i ), c_{k'} = exp^kappa_{phi(mu_p(i))}( s*c^(L)_{k'} ), subject to the certificate Admit(i,k') = [dSplit_new <= dSplit_old] AND [dMerge_new <= dMerge_old] AND [at least one strict] AND [ ||r_i - c^(L)_{k'}||_2 <= R_{k'} ].
OBSERVABLES: Number and fraction of items whose deepest code changes; 100% identity of tokens 1..L-1 for every item (hard assertion); training-split split-coherent pair count and same-cell disjoint pair count, both non-increasing by construction; validation negRate@L1 before and after (the diagnostic that says whether this is the same failure again); per-item level-L conditional entropy of the next-token distribution under the frozen Stage-3 context, pre/post; final Stage-3 test recall@10 against 0.065. If zero moves are certified, the report says so and the run is a scored negative result, not a silent baseline.
ABLATION BEHAVIOR OFF: Identical code path with the behaviour table replaced by text-embedding cosine similarity in every slot it occupies: w_hat_ij from cosine over the same neighbour sets, q_i from cosine-weighted agreement, LR replaced by cosine for the split/merge certificate, and B replaced by the measured train-split cosine quantile matching r0. This arm exists and must compile and run, but is not trained in this round.
ABLATION GEOMETRY OFF: Identical code path with kappa->0: phi=identity, exp=identity, distance=Euclidean, gyromidpoint replaced by the Euclidean weighted mean, and the candidate score exp(-||v_i-c_k'||^2/(2*sigma^2)) with sigma the measured residual standard deviation. Behaviour signal and certificate unchanged. Not run.
ABLATION BOTH ON: The full mechanism above: behaviour-conditioned gyromidpoint position, Poincare distance with kappa=1, behaviour certificate with B=ln((1-r0)/r0) and the cell-radius guard. This is the single trained run.
SPEC EQUATIONS:
```
INPUTS: train sequences; frozen E, C^(1..L), assignments a_i; frozen prefix centroids mu_p
1  n_ij, n_i, N_pair from TRAIN consecutive pairs (symmetrised)
   LR(i,j)=ln( n_ij*2*N_pair / ((n_i+1)*(n_j+1)) )
   M_i = min( argmin_M{ sum_{top M} n_ij >= 0.9*sum_j n_ij }, P95(M) )
   N(i)=top-M_i(n_ij);  w_ij=max(0,LR(i,j));  w_hat_ij = w_ij / sum_{j in N(i)} w_ij
2  r0 = negRate@L1(TRAIN, baseline SIDs);  B = ln((1-r0)/r0)
3  r_i = z_i - mu_{p(i)}
   s  = 7.6 / max_i ||r_i||            # artanh(1-1e-3)*2, keeps ||exp|| <= 1-1e-3
   u_i = exp^kappa_{phi(mu_{p(i)})}( s*r_i )
   c_k = exp^kappa_{phi(mu_{p(i)})}( s*C^(L)_k )      # prefix-local, k=1..K
   v_i = gyromid_{kappa}( {u_i} U {u_j}_{j in N(i)} ; {1} U {w_hat_ij} )   # 10 Ungar iterations
4  for i in order of decreasing sum_j n_ij  (each item visited once):
     C_i = unique{ a_j^L : j in N(i) } \ { a_i^L }
     for k' in C_i:
        q_i(k') = sum_{j in N(i)} w_hat_ij * 1[a_j^L = k']
        S_i(k') = q_i(k') * exp( -d_kappa(v_i, c_k') )
     k* = argmax_{k' in C_i} S_i(k'); continue if C_i empty
     dSplit(c) = #{ j in N(i) : LR(i,j) >= B  and a_j^L != c }
     dMerge(c) = #{ j in N(i) : LR(i,j) <  B  and a_j^L == c }
     R_{k*} = max_{ j : a_j^L = k* } || r_j - C^(L)_{k*} ||_2       # frozen baseline cell radius
     ok = (dSplit(k*) <= dSplit(a_i^L)) and (dMerge(k*) <= dMerge(a_i^L))
          and (dSplit(k*) < dSplit(a_i^L) or dMerge(k*) < dMerge(a_i^L))
          and (||r_i - C^(L)_{k*}||_2 <= R_{k*})
     if ok: a_i^L <- k*                       # levels 1..L-1 never touched
5  assert forall i: (a_i^1..a_i^{L-1}) unchanged
   report train split/merge counts, val negRate@L1 pre/post, moved count, then hand SIDs to Stage 3
negRate@L1(S) = |{(i,j) consecutive in S : a_i^1 = a_j^1 and LR(i,j) < B}| / |{(i,j) consecutive in S}|
```
SPEC INPUTS OUTPUTS: Input: TRAIN sequences, frozen Stage-2 encoder E, codebooks C^(1..L), frozen assignments a_i, prefix centroids mu_p, and the baseline train-split L1 negative-hit rate r0. Output: a repaired assignment matrix that is identical to the baseline except possibly in column L, the moved-item list, the certificate counts, and the validation negRate@L1 diagnostic; downstream it is the same SID token stream and vocabulary Stage 3 already consumes.
SAFEGUARDS: Clamp all ball coordinates to norm <= 1-1e-3 inside every exp map and every Möbius addition and renormalise after the gyromidpoint iterations; compute artanh in float64 with argument clipped to 1-1e-9; guard s against max_i||r_i||=0 by setting s=1 and skipping the repair (degenerate); skip candidates whose centroid is non-finite or whose cell has zero members (undefined radius R_k); require sum_{j in N(i)} w_ij > 0 or fall back to uniform w_hat over N(i); treat an empty C_i or a failed certificate as an explicit no-op with a logged reason; hard assertion that tokens 1..L-1 are bit-identical after the pass; monotone termination because each item is visited once and only its own pairs change, so total split and merge counts cannot increase; determinism by processing items in the fixed decreasing-mass order with ties broken by item id, so the result is seed-free and reproducible.
END IDEA
