IDEA: ADM-GEO-RQ
TITLE: Admissible geodesic re-assignment: a curved distance budget gated by a measured behaviour-disjoint-pair veto
MOTIVATION: The measured failure is that the RQ-VAE places items in the same prefix even when their training behaviour is disjoint, so the Stage-3 generator spends prefix probability on items the user would never transition to. Earlier rounds attacked this by moving codebook positions (curved Frechet means), by changing the curvature value per level, or by re-scoring radius/assignment to build new prefixes; all rebuilt the partition and all failed. The remaining failure mode is the assignment step itself: it is unconstrained on the negative side. This idea keeps the baseline partition, the codebook positions and the Euclidean training losses, and constrains only individual re-assignment moves with (i) a hard behaviour veto that can never increase same-prefix behaviour-disjoint pairs and (ii) a hyperbolic travel budget that says how far an item may move to join a behaviour-coherent cell.
NOVELTY: Not a codebook update (rejects poincare-frechet-successor-codebook), not a curvature schedule (rejects CURVCTRL-SID), not a radius/entropy assignment score (rejects BRad-RQ), not a new-prefix rebuild (rejects the whole last four rounds). It is a monotone admissibility operator on the discrete assignment: the curved metric appears only as the permitted travel budget inside an inequality, and the behaviour graph appears only as the negative-side count inside the same inequality, so neither can act without the other. The bound tau is self-calibrated from the baseline's own measured negative-hit rate, so no constant is tuned.
CHANGE: At each RQ level, instead of taking the nearest code outright, item i may move from its current code a to a candidate code b only if (1) the number of behaviour-disjoint items already in b (with the same shorter prefix) does not exceed the number in a, and (2) the Poincare distance increase from a to b is at most a behaviour-derived allowance scaled by a measured code-to-code Poincare scale. Otherwise the item stays where it is.
SPECIFICATION: Let D be the RQ depth (e.g. 3), K the codebook size per level, d the residual dimension. Epoch 0 is the ordinary text-embedding RQ-VAE with no behaviour term and yields the initial assignment A0(i,l) = Euclidean argmin code at level l.
Step 1 (train-only behaviour graph). From TRAIN sequences count consecutive in-session directed transitions N_ij and symmetrise A_ij = N_ij + N_ji. Popularity-adjusted score s_ij = log( (A_ij + 1) / (deg_i deg_j / (2M) + 1) ), where deg is the symmetrised weighted degree and M the number of undirected edges (Laplace +1 is a documented default, not a tuned value). Behaviour-disjoint means s_ij <= 0. Keep for each item its top-64 neighbours by s as the sparse support of the veto (cap equal to the baseline context length, not tuned).
Step 2 (derived constants, all from TRAIN at epoch 0). h0 = fraction of same-L1-cell item pairs with s_ij <= 0 (the baseline negative hit rate, TRAIN only). Pos = { s_ij : s_ij > 0 and i,j share the L1 cell at epoch 0 }. tau = Quantile over Pos at probability q = h0, so a worse baseline demands stronger coherence; no tuning. rho_l = RMS norm of the epoch-0 level-l code vectors (measured, sets the exp-map scale so residuals do not saturate the ball). lambda_l = median pairwise Euclidean distance among epoch-0 level-l code vectors (measured, scales the allowance). Curvature K = 1, fixed, documented default; the Gromov delta of the TRAIN transition metric is recorded as a diagnostic only and never sets K.
Step 3 (curved images). phi_l(x) = exp^K_0(x / rho_l). For item i, u_i = phi_l(residual_l(i)); for code c, v_c = phi_l(c_l). dP(u,v) = arcosh(1 + 2K||u-v||^2 / ((1-K||u||^2)(1-K||v||^2))) / sqrt(K).
Step 4 (admission). For item i at level l with a = A(i,l), order all K codes by dP ascending and take the first m = D candidates (m equals the RQ depth, not tuned). For each candidate b != a compute created = number of j in Supp_i with s_ij <= 0, A(j,l) = b and prefix_{<l}(j) = prefix_{<l}(i); removed = same count for a; dX = created - removed; sbar_i(b) = mean of s_ij over the items j already in cell b sharing the shorter prefix (tau if cell b is empty); allowance = lambda_l * max(0, sbar_i(b) - tau); gap = dP(u_i, v_b) - dP(u_i, v_a). Admit iff dX <= 0 AND gap <= allowance; among admitted candidates take the smallest gap; apply with straight-through. Codebook positions, reconstruction loss and commitment loss stay exactly as in the baseline.
Step 5: nothing else changes. Decoder, Stage-2 schedule, Stage-3 protocol, seed: frozen.
COST: Per step (batch 1024, D=3, K=256, d=32): the K-code distance evaluations already exist in the baseline argmin, now in the curved metric; add 1024*3*3 = 9216 Poincare distances (~30 flops each) and 1024*3*3*20 = 184320 sparse neighbour lookups for the veto against a precomputed boolean disjoint-edge matrix. About 3e5 flops per step, 2-4 ms batched on GPU, under 3 percent of a step whose transformer decoder forward dominates; overhead over 72000 steps (24 steps x 3000 epochs) is a few GPU minutes. One-off CPU: build the top-64 graph and the boolean veto matrix (24556 items, ~1.5e6 entries, 2-5 min), measure h0, tau, rho_l, lambda_l once at epoch 0 (~1 min). No new parameters; extra memory is the sparse veto matrix (~6 MB int32).
HYPOTHESIS: If the failure really is same-prefix/disjoint-behaviour, the veto plus the curved budget rejects a few high-damage baseline moves and admits a few behaviour-coherent ones: SID churn stays between 3 and 15 percent (partition nearly the baseline), the validation L1 negative hit rate falls clearly below its epoch-0 value, and Stage-3 test_recall@10 exceeds 0.065 because the generator no longer spends prefix mass on disjoint items. If churn is ~0 the mechanism is inert on this pathway; if churn is large and the negative hit rate does not fall it is the same failure again and is recorded as such.
RISKS: (1) The dX <= 0 veto can be satisfied trivially by staying put, making the operator inert and Stage 3 bit-identical to baseline - visible in the admitted-move counters. (2) h0 near 1 makes tau strict and leaves only zero-allowance moves, again near-inert. (3) For small residual norms the exp map is nearly linear, so geometry-off and both-on coincide; the mean dP / mean L2 ratio is reported, and a ratio within 1 percent means the result must be recorded as a geometry failure, not a behaviour failure. (4) The straight-through gradient stays Euclidean, so the encoder can drift and later reassign the same pairs; the veto is re-evaluated each step, so this shows up as oscillation, bounded but not eliminated by the no-move-unless-admitted rule. (5) A frozen 150-epoch Stage 3 may be insensitive to a small SID change, so a true effect may be unobservable in one run.
BEHAVIOR SIGNAL: Popularity-adjusted directed item-transition log-ratio s_ij over consecutive in-session item pairs, symmetrised, used both as the disjointness predicate (s_ij <= 0) and as the coherence margin (sbar_i(b) - tau).
BEHAVIOR COMPUTATION: From the TRAIN split only: for every user session in train, for every adjacent pair (x_t, x_{t+1}) add 1 to N_{x_t,x_{t+1}}; A = N + N^T; deg_i = sum_j A_ij; M = sum_{i<j} A_ij; s_ij = log((A_ij + 1)/(deg_i deg_j/(2M) + 1)). Store the top-64 neighbours by s per item; h0, tau, rho_l, lambda_l are computed once at epoch 0 from the same TRAIN matrix and the behaviour-free epoch-0 assignment.
LEAKAGE BOUNDARY: Everything that enters the SID construction (A, s, the boolean disjoint matrix, h0, tau, rho_l, lambda_l) comes from TRAIN interactions and from the epoch-0 encoder and codebooks, which were trained on TRAIN text features and TRAIN reconstruction targets only. No validation or test interaction, prefix or recall value is ever read into an assignment decision, and no derived constant is re-estimated after epoch 0. The validation L1 negative hit rate is computed only after training, as a post-hoc diagnostic, and is never fed back into the partition, into tau, or into a switch. There is no per-user adaptation at inference: the mask depends only on the TRAIN graph and the batch.
HYPERBOLIC OPERATOR: Poincare-ball distance dP at fixed negative curvature K = 1, composed with the exponential map at the origin exp^K_0 scaled by the measured rho_l; used as the assignment metric and as the travel budget in the admission inequality.
HYPERBOLIC LOCATION: Inside the RQ-VAE discrete assignment step at every level of every Stage-2 training step, i.e. inside the quantizer that produces the SIDs; never in a standalone loss and never in Stage 3.
COUPLING PATH: item text residual -> exp map -> Poincare distance to candidate codes -> gap -> compared with lambda_l * max(0, sbar_i(b) - tau) -> compared again with dX (the behaviour-disjoint count) -> admit or stay -> straight-through into decoder and codebook update. The behaviour graph supplies s hence dX, sbar and tau; the geometry supplies gap and lambda_l; the admission is one boolean that is false if either the behaviour count or the curved margin is violated, so deleting the graph zeroes both the veto and the allowance (moves become pure curved nearest-code and the disjoint-pair leakage reappears) and deleting the curvature turns gap into a Euclidean gap (the budget no longer reflects prefix depth).
COUPLING EQUATION: admit(i: a->b, l) = [ dX_behaviour(i,b,a,l) <= 0 ] AND [ dP(u_i, v_b) - dP(u_i, v_a) <= lambda_l * max(0, sbar_i^behaviour(b) - tau) ], with dX_behaviour = sum_{j in Supp_i, s_ij<=0} ( 1[cell_l(j)=b] - 1[cell_l(j)=a] ).
OBSERVABLES: (1) admitted-move count per level and the fraction of items whose SID tuple changes (churn), which must be small but nonzero; (2) validation L1 negative hit rate, the diagnostic that decides whether this is the same failure again, reported against its epoch-0 baseline value; (3) mean dP / mean L2 ratio, showing the curved term is operative rather than numerically Euclidean; (4) measured Gromov delta of the TRAIN transition metric as a context number, recorded and never used; (5) Stage-3 masked-prefix accuracy at L1 and full-SID predictability on validation; (6) Stage-3 test_recall@10 against 0.065.
ABLATION BEHAVIOR OFF: use_behaviour=False: the boolean disjoint matrix is zeroed, sbar is set to tau everywhere and tau to 0, so dX == 0 and allowance == 0 for every candidate; the rule collapses to taking the curved nearest code that does not increase Poincare distance, i.e. the same curved operator with no behaviour information. The code path exists and is exercised by a unit test on a toy batch; no arm is trained.
ABLATION GEOMETRY OFF: use_curvature=False: phi becomes identity, dP becomes Euclidean L2, lambda_l becomes the median Euclidean code distance; dX, sbar, tau and the whole veto are unchanged from the both-on run. The code path exists and is unit-tested; no arm is trained.
ABLATION BOTH ON: the single formal run: use_behaviour=True, use_curvature=True, one candidate, 3000 Stage-2 epochs on four cards, frozen Stage 3 for 150 epochs, no early stopping, no seed repetition, no tuning of any constant.
SPEC EQUATIONS:
 h0 = |{(i,j): i<j, cell0(i)=cell0(j), s_ij <= 0}| / |{(i,j): i<j, cell0(i)=cell0(j)}|
 tau = Quantile_{q=h0}( { s_ij : s_ij > 0, cell0(i)=cell0(j) } )
 rho_l = sqrt(mean_c ||c_l^c||^2) ;  lambda_l = median_{p!=q} ||c_l^p - c_l^q||
 phi_l(x) = tanh(||x||/rho_l) * x/||x||   (K = 1, exponential map at the origin)
 dP(u,v) = arcosh( 1 + 2||u-v||^2 / ((1-||u||^2)(1-||v||^2)) )
 per step, per level l ascending, per item i in batch:
   a = A(i,l); cand = argsort_k dP(phi_l(r_i^l), phi_l(c_l^k))[:D]; best = a; best_gap = 0
   for b in cand, b != a:
     created = sum_{j in Supp_i, s_ij<=0} 1[A(j,l)=b and prefix_{<l}(j)=prefix_{<l}(i)]
     removed = sum_{j in Supp_i, s_ij<=0} 1[A(j,l)=a and prefix_{<l}(j)=prefix_{<l}(i)]
     dX = created - removed
     sbar = mean_{j in cell b, prefix match} s_ij   (tau if the cell is empty)
     gap  = dP(phi_l(r_i^l), phi_l(c_l^b)) - dP(phi_l(r_i^l), phi_l(c_l^a))
     if dX <= 0 and gap <= lambda_l * max(0, sbar - tau) and gap < best_gap: best, best_gap = b, gap
   A(i,l) = best ;  z_l = c_l^best + stopgrad(r_i^l - c_l^best)  (straight-through, losses unchanged)
SPEC INPUTS OUTPUTS: Inputs: level-l encoder residual r_i^l (d-dim), level-l codebook c_l (K x d), current assignment A(:,l) with its shorter prefixes, the item's sparse behaviour support {(j, s_ij)} (<=64 entries), and the four derived quantities (h0, tau, rho_l, lambda_l). Outputs: the updated integer code A(i,l) for every item in the batch, hence the SID tuple, plus per-step counters (admitted moves, dX histogram, mean gap, mean dP / L2 ratio) written to the run log. No new parameters; the decoder interface is unchanged.
SAFEGUARDS: clamp ||u||^2 and ||v||^2 to at most 1 - 1e-6 before arcosh; evaluate arcosh as log(1 + x + sqrt(x^2 + 2x)) with x = 2||u-v||^2/((1-||u||^2)(1-||v||^2)), add 1e-12 inside the log, and return 0 when the argument is at or below 1 + 1e-12. Guard rho_l with max(rho_l, 1e-6) and ||x|| with max(||x||, 1e-12). Items with empty support have created = removed = 0 and sbar = tau, so only distance-non-increasing moves pass, deterministically. Items without a level-l assignment at step 0 fall back to the baseline argmin. tau is clipped to max(tau, 0). If no positive same-cell pair exists, tau is set to the maximum observed s over all pairs, the run logs a degenerate-behaviour warning, and the mechanism is recorded as undefined rather than silently inert. If the veto matrix is empty the code takes the behaviour-off branch automatically and logs it, so a silent inert run is impossible. Assignment is applied level-ascending within a step so prefix_{<l} is always current, and the level-l counters are recomputed from the live A, never cached across steps.
END IDEA
