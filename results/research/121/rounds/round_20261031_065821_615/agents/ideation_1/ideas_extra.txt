IDEA: CGREP-4L-RQ
TITLE: Contrast-weighted geodesic repulsion on quantised codewords with a fourth RQ level
MOTIVATION: Both negative rounds lost recall by MERGING deep prefixes (round two kept 1298 L3 prefixes at 0.05165, round one kept 2201 at 0.05439). The behaviour signal has so far only been used as an attractive force (move points toward a successor hub), which is exactly the operation that destroys depth. Separately, text-nearest items that are behaviourally unrelated keep sharing a prefix, and the 3x256 quantiser has no room left at level three. This idea reverses the sign of the behaviour force and adds the one architectural change the brief declares legal (a fourth level), so the partition can only become finer at depth.
NOVELTY: Not attraction to a popularity-adjusted successor barycentre (round two), not successor-weighted Frechet codebook updates, not per-level curvature control from prefix-transition scores, not radial position from context entropy, not Gromov-delta or ancestor-depth weighting, not a standalone hyperbolic auxiliary loss. It is the only repulsive, hinge-bounded, margin-terminated operator here, it acts on the QUANTISED code vectors rather than on the input points (so it can split a cluster but not create one), and it is paired with extra deep capacity instead of being asked to fit into the saturated three-level codebook.
CHANGE: Take the behaviourally most-contrasting text-nearest neighbours of each item inside the same level-2 prefix and push their quantised code vectors apart along the Poincare metric, with a hinge that switches off as soon as the pair is separated by the median initial geodesic distance; simultaneously widen the SID to four levels of 256 codewords so the newly created separation can be committed to tokens.
SPECIFICATION: For each item i, q_i = exp_0^c( sum_{l=1..4} e_{l,k_l(i)} ). Static precompute: p_i = add-one-smoothed directed training-transition distribution; contrast c_ij = 1 - cos(p_i,p_j); impostor set P = for each i the 4 text-kNN neighbours (frozen text embedding) with the largest c_ij. Margin m = median over P of d_P at initialisation. Loss L = L_RQVAE + lambda * mean_{(i,j) in batch, pi2(i)=pi2(j)} c_ij * [m - d_P(q_i,q_j)]_+^2, with STE so grad reaches e_{l,k_l(i)}; lambda = L_quant^(0)/L_push^(0) measured at step 0.
COST: +8192 parameters (one extra 256 x 32 codebook). Per step: at most 4096 x 4 = 16384 Poincare distance evaluations, roughly 0.1-0.4 ms on top of the ~6.3 ms step (24 steps/epoch, 0.15 s/epoch), so about +3-8 percent, i.e. 0.155-0.17 s/epoch and still ~8 minutes for 3000 epochs plus one ~1 minute GPU precompute of the impostor lists. Stage 3 pays one extra token per item.
HYPOTHESIS: If separation created by behaviour contrast is what the recall metric was reading (behaviour-contrast rho = +0.7104 in the 107-pair table) and prefix capacity was the binding constraint, then distinct L3 prefixes must rise above the 1298/2201 range, L4 must not collapse to a handful of codes, and Stage3 test_recall@10 must exceed 0.065. Observed through: distinct prefix counts per level, mean Poincare radius, L4 codebook perplexity, and test_recall@10 from the single frozen run.
RISKS: The outward drift can over-separate and starve the deep codebooks (all items far from every codeword) - the hinge margin limits this but L4 perplexity is the failure meter. The push can destroy text semantics that Stage 3 relies on for cold prefixes, in which case recall falls while prefix counts look healthy. A fourth token lengthens every Stage 3 sequence and may interact badly with the frozen protocol's context. Behaviour-contrast is measured only for items with outgoing transitions, so sparse items contribute nothing and the effect may be unevenly distributed. Seed noise is unmeasured because there is one run.
BEHAVIOR SIGNAL: Directed item-to-item transition contrast, i.e. the dissimilarity of two items' row-normalised successor distributions, used with a reversed (repulsive) sign.
BEHAVIOR COMPUTATION: From the TRAINING split sequences only, over 24556 items: A_ij = count of consecutive pairs (item_t = i, item_{t+1} = j); p_i = (A_i. + 1)/(sum_j A_ij + V) with V = 24556 (add-one, no tuned smoothing); c_ij = 1 - cos(p_i, p_j) clipped to [0,1]; items with no outgoing transition get c = 0 and are excluded from P. The impostor list is materialised once before Stage 2 and frozen for the whole run.
LEAKAGE BOUNDARY: A_ij is built only from training-split sequences; the text embedding used for text-kNN is item metadata that is not fitted on any validation or test interaction; the margin m is a median over the same frozen training pair list. No validation or test user, sequence, transition or metric ever enters the pair construction, the margin, or the codebook.
HYPERBOLIC OPERATOR: Fixed negative curvature c = 1 (ball radius 1) Poincare ball; exp_0^c tangent-to-ball map for the quantised vector and Poincare geodesic distance d_P with Mobius addition. Curvature is deliberately not trained and not per-cell, because curvature is a gauge; the only geometric content used is the metric's radial distortion, which makes the same hinge push much harder near the boundary than near the origin.
HYPERBOLIC LOCATION: In the RQ-VAE training loss at the deepest quantisation levels (all four codebooks through the straight-through path, with the parent mask fixed at level two), and consequently in the geometric layout of the level-3 and level-4 codebooks.
COUPLING PATH: Behaviour contrast c_ij selects and weights the pair; only that pair's quantised code vectors are compared under d_P; the gradient of that single term updates e_{3,k} and e_{4,k} directly, which changes the residual assignment of the next step and therefore the emitted tokens. Removing c_ij removes the per-pair variation of the force; replacing d_P by Euclidean distance removes the radial grading; either change alters the same scalar that produces the codebook gradient, so it is one pathway and not two losses added together.
COUPLING EQUATION: L_push = (1/|B_P|) * sum_{(i,j) in B_P, pi2(i)=pi2(j)} c_ij * [ m - (2/sqrt(c)) artanh( sqrt(c) || (-q_i) (+)_c q_j || ) ]_+^2 , with q_i = exp_0^c( sum_{l=1..4} e_{l,k_l(i)} ).
OBSERVABLES: A rise in distinct level-3 prefixes above 2201 and in distinct level-4 prefixes (target well above 3000); a modest rise in mean hyperbolic radius; a fall in mean cosine similarity between quantised vectors of text-kNN pairs; higher L4 codebook perplexity than the level-3 baseline; behaviour-conditioned prefix transition predictability recorded as a diagnostic; and Stage3 test_recall@10 against the 0.065 gate, with distinct-prefix counts as the mechanism-level reading.
ABLATION BEHAVIOR OFF: Same four-level architecture, same Poincare operator, same impostor pairs and margin, but c_ij set to 1 for every pair, so the push becomes behaviour-blind and acts like a plain curved diversity hinge. Implemented as a single flag that overwrites the contrast matrix with ones; wired but not trained.
ABLATION GEOMETRY OFF: Same four-level architecture, same contrast weights c_ij and same margin (recomputed as the median initial Euclidean distance so the scale matches), but d_P replaced by the Euclidean distance between the same quantised vectors and the exp map replaced by the identity. Implemented as one flag swapping the metric call; wired but not trained.
ABLATION BOTH ON: The full run described here: four 256-codeword levels, contrast-weighted Poincare hinge on the quantised code vectors, margin from the initial median geodesic distance, lambda from the initial loss ratio.
SPEC EQUATIONS: 
c = 1; V = 24556; d = latent/embedding dim; L levels = 4; K = 256.
Precompute (once, CPU/GPU, training split only):
  A[i,j] = #{t : seq_t = i, seq_{t+1} = j, seq in D_train}
  p_i = (A[i,:] + 1) / (A[i,:].sum() + V)
  c_ij = clip(1 - dot(p_i,p_j)/(||p_i|| ||p_j|| + 1e-8), 0, 1)
  NB(i) = 8 nearest items by cosine in frozen text embedding
  P = { (i,j) : j in NB(i), rank by c_ij desc, keep top 4, c_ij >= median_{i,j in NB} c_ij }
Forward:
  u_i = sum_{l=1..4} e_{l, k_l(i)}
  q_i = exp_0^c(u_i) = tanh(||u_i||) * u_i / ||u_i||   (c = 1; u_i = 0 -> 0)
  q_j likewise; b = (-q_i) (+)_1 q_j = ((-q_i) + q_j)/(1 - <q_i,q_j>)   [note (-q_i)(+)q_j uses <q_i,q_j> in the denominator for c = 1]
  d_P(i,j) = 2 * artanh( min(||b||, 1 - 1e-6) )
  push_ij = c_ij * max(0, m - d_P(q_i,q_j))^2
  L_push = mean over batch pairs with pi2(i) == pi2(j) (pi2 detached); if no such pair, L_push = 0
  L = L_RQVAE + lambda * L_push,  lambda = stop_grad(L_quant at step 0) / stop_grad(L_push at step 0)
Backward: STE so dL/du_i flows into e_{1..4, k_l(i)}; k_l(i) from the current hard assignment (no gradient).
Post-step safety: if mean |q| > 0.95, multiply all codebooks by 0.95/mean|q|.
SPEC INPUTS OUTPUTS: Inputs: frozen item text embeddings, training-only transition counts A, the four codebooks e_{l,k} in the tangent at the origin, the batch of item indices with their current hard assignments k_1..k_4. Outputs: the per-step scalar L_push and its gradient into the level-1..4 codebooks, and after training a 4-token SID (k1,k2,k3,k4) per item plus the updated encoder and codebooks.
SAFEGUARDS: clamp the artanh argument to 1 - 1e-6 and add 1e-8 in every norm denominator; the exp map keeps |q| < 1 by construction so no ball projection is needed inside the distance; c_ij = 0 for items with no outgoing transition so they contribute no gradient; the hinge is bounded below at 0 with zero gradient once d_P >= m, so the objective has no minimum at the origin and cannot reproduce the round-one collapse (checked explicitly against that failure mode); the level-2 mask is detached so it cannot be gamed by moving an item across parent cells; skip the push for any step whose pair set is empty or whose value is non-finite (logged, never silently zeroed for the whole run); radial rescale at the 0.95 boundary fraction to stop outward drift; dead-code watch on level 4 (perplexity < 2 recorded as a failure signature, not as a gate).
END IDEA
