IDEA: BEHDIR-L4
TITLE: Behaviour-steered geodesic fourth SID level: a train-only successor direction walks each item off its level-3 prefix inside the Poincare ball to mint a new deep token
MOTIVATION: Both trained rounds lost recall for one reason - their mechanisms edited the existing three-level partition and merged prefixes (2201 -> 1298 distinct L3 prefixes traced the 0.0544 -> 0.0517 drop). The frozen RQ-VAE's level three is already near saturation for 24556 items, so text geometry alone has no room left, and items that differ only in what users do next are forced onto the same deep token. This mechanism attacks the one place where room demonstrably exists - an ADDITIONAL level - and uses training-only successor behaviour to choose the direction of that refinement, so items a user will treat differently stop sharing a SID while the surviving 2201-prefix capacity is provably untouched.
NOVELTY: Every mechanism here so far (round-one curved residual chain, round-two concentration-scaled step to the popularity-adjusted successor barycentre, poincare-frechet-successor-codebook, succboost-geoshift, BRad-RQ radial entropy assignment, CURVCTRL-SID, LORENTZ-SUCCPROFILE-SMOOTH-RQ, behcone-prefix-rq, TSG-SID, BRANCHCURV-MOEB-RQ, MIXCURV-FIBRE-RQ, SUCC-GEO-CBTAB, BFRQ-KARCHER-MASS) re-positions points or codewords of the EXISTING partition, i.e. it spends existing capacity. This idea is additive: levels 1-3 are frozen bit-identical, and behaviour is neither a hub attraction nor a radius rescaling in the existing ball - it is a DIRECTION for a new fourth token. There is no Frechet/successor barycentre anywhere (behaviour enters as a rank-32 SVD coordinate of the item's own successor distribution, not as an averaged successor position) and no entropy-driven radial scaling (no item's radius is changed).
CHANGE: After the third RQ level each item is moved a fixed, learnable geodesic distance s away from its level-3 prefix point along a direction that mixes (a) the Poincare log of its level-3 text residual, metric-normalised by the prefix conformal factor, with (b) a fixed orthonormal projection of its training-only successor profile; the nearest of 64 ball-embedded codewords to the arrival point becomes its fourth SID token.
SPECIFICATION: Ball curvature c=1, lambda(x)=2/(1-|x|^2), Mobius addition (+), d_P(p,x)=2*artanh(|(-p)(+)x|), exp_p(v)=p(+)(tanh(|v|/2)*v/|v|), log_p(x)=2*artanh(|(-p)(+)x|)*((-p)(+)x)/|(-p)(+)x|.
 1. Levels 1-3 unchanged: item i gets prefix p_i = last level-3 codeword and level-3 input point x_i in the ball.
 2. t_i = log_{p_i}(x_i); v_i = t_i / lambda(p_i); vhat_i = v_i/max(|v_i|,1e-8), zero if |v_i|<1e-8.
 3. b_i in R^32, |b_i|=1 (train-only, see BEHAVIOR COMPUTATION). P in R^{d x 32} fixed: orthonormal columns from seeded QR (seed 0), never trained. h_i = P b_i, |h_i|=1.
 4. Gate g_i = 1 + tanh(W b_i) in (0,2)^d, W in R^{d x 32} initialised to 0 so the first step is geometry-only.
 5. u_i = (g_i (.) vhat_i + h_i)/max(|g_i (.) vhat_i + h_i|, 1e-8); equal a-priori weight because both summands are unit-norm.
 6. q_i = exp_{p_i}(s u_i), s = s0 * exp(clamp(psi,-1,+1)); psi learnable init 0, s0 = mean_i d_P(x_i,p_i) measured once on the training split with the epoch-0 encoder then frozen.
 7. a4(i) = argmin_k d_P(q_i, c4_k), c4 in the ball, K4 = 64.
 8. SID(i) = (a1,a2,a3,a4). Loss: the baseline RQ-VAE objective only; the fourth level contributes the same commitment/usage term with the same coefficient. No new loss term, therefore no coupling weight to tune.
 9. c4 initialisation: 20 Poincare k-means iterations (Frechet mean by iterative log/exp) on q_i of a fixed 8192-item seed-0 training subsample at epoch 0, then a normal trainable parameter.
 10. K4=64 is derived, not chosen: the largest power of two keeping the per-item distance-count increase under 10% (768 -> 832, +8.3%) at the frozen budget.
COST: +8.3% per-item distance evaluations (768 -> 832), one extra log-map and exp-map per item, one 64 x d codebook, one d x 32 gate matrix, one fixed d x 32 projection. Expected 0.15 -> approx 0.165 s per epoch (24556 training items, 24 steps, global batch 4096, four cards, 3000 epochs): about +10% wall clock, +64 distances and 2 transcendental maps per item per step. One-off: PPMI + rank-32 truncated SVD of the training transition matrix (< 1 min on one card) and the epoch-0 k-means (20 x 8192 x 64 distances, seconds).
HYPOTHESIS: Items sharing a level-3 prefix but differing in successor profile currently share all tokens; separating them along a curvature-normalised geodesic should raise distinct deep SIDs without lowering the 2201 distinct L3 prefixes, and give Stage-3 a deep token that already distinguishes future-different items. Worth keeping if Stage-3 test_recall@10 exceeds 0.065 while L1/L2/L3 prefix counts stay 251/1769/2201 and the L4 distinct count rises well above the L3 count.
RISKS: (i) the behaviour term dominates u_i so level four degenerates into a 64-way behaviour-cluster id shared across prefixes and text residual is lost - visible as near-uniform a4 across prefixes and a small level-4 reconstruction share; (ii) learnable s hits the lower clamp, level four becomes a no-op (bounded, not destructive); (iii) fixed random P lands the successor profile in directions already dominant in the text residual, so the mix adds nothing; (iv) Stage-3 pays one extra sequence position at the same epoch budget.
BEHAVIOR SIGNAL: Directed training-only item transitions aggregated into each item's own successor profile (a rank-32 positive-PMI embedding of one row of the transition matrix), used as a unit tangent direction at the level-3 prefix.
BEHAVIOR COMPUTATION: From Stage-3 TRAIN session sequences only. Build sparse T (V x V, V=24556) over consecutive in-session pairs (i followed by j); symmetrise S=(T+T^T)/2 and form PPMI M_ij = max(0, log( (S_ij * sum(S)) / (row_i * col_j) )); truncated SVD rank 32; b_i = normalise(U_32[i,:] * S_32^{1/2}). Items with zero transitions get b_i = 0, so that item deterministically takes the behaviour-off path. Computed once before Stage 2, never recomputed.
LEAKAGE BOUNDARY: T is built only from train-split sessions; validation and test sequences are never read, counted, or used to fit the SVD, P, s0 or the epoch-0 k-means. The only epoch-0 quantities come from the encoder's own output on training items. The signal is a property of each item's training successor distribution, not of any evaluation event, so no validation or test interaction can enter the SID construction; the SID is a deterministic function of the frozen train split plus training-time parameters.
HYPERBOLIC OPERATOR: Fixed negative curvature c=1 Poincare ball: log map at the level-3 prefix t_i = log_{p_i}(x_i), conformal-factor normalisation v_i = t_i/lambda(p_i), exponential map q_i = exp_{p_i}(s u_i), and geodesic distance d_P for level-4 assignment and codebook Frechet means.
HYPERBOLIC LOCATION: In the quantizer, at the newly added fourth RQ level - curvature defines the level-4 query point (log then exp at the prefix) and the level-4 assignment metric, and shapes the epoch-0 codebook through Poincare k-means.
COUPLING PATH: b_i -> h_i = P b_i and -> g_i = 1+tanh(W b_i) -> u_i = normalise(g_i (.) vhat_i + h_i) -> q_i = exp_{p_i}(s u_i) -> a4 = argmin_k d_P(q_i,c4_k) -> fourth SID token -> Stage-3 vocabulary and generation target. Behaviour changes the geodesic direction, hence the arrival point and the token; curvature changes the residual normalisation, the arrival point and the metric in which the token is chosen. Setting h_i=0 and g_i=1 leaves the plain curved level-4 residual; replacing log/exp/1-over-lambda and Euclidean distance leaves a Euclidean level 4. Both ablations change the emitted token, so the pathway is single and both inputs are load-bearing.
COUPLING EQUATION: a4(i) = argmin_{k<=64} d_P( exp_{p_i}( s * normalise( (1+tanh(W b_i)) (.) vhat_i + P b_i ) ), c4_k ), with vhat_i = normalise( log_{p_i}(x_i) / lambda(p_i) ), lambda(p) = 2/(1-|p|^2), b_i the train-only successor profile - behaviour terms b_i, P, W and curved terms log_{p_i}, exp_{p_i}, lambda(p_i), d_P in one expression.
OBSERVABLES: (a) distinct L4 token count and distinct four-token SID count versus 2201 L3 prefixes (should rise; 251/1769/2201 should not move); (b) share of the level-4 reconstruction term in total reconstruction error (should stay non-trivial, i.e. level 4 still carries text geometry); (c) MI between an item's a4 and the a4 of its next training item versus MI against random items (deep token behaviour-informative); (d) measured s and |W| trajectories (s away from clamps, W unsaturated); (e) Stage-3 test_recall@10, recall@5, ndcg@10.
ABLATION BEHAVIOR OFF: code path BEH_DIR=0: h_i forced to 0 and g_i forced to 1, so u_i = vhat_i and the fourth level is the plain curvature-normalised geodesic step off the level-3 prefix. Token stream, loss and every other hyperparameter identical. Not trained this round; wired and unit-tested.
ABLATION GEOMETRY OFF: code path GEO=0: lambda(p)=1, log_{p_i} replaced by x_i - p_i, exp_{p_i} by p_i + s u_i, d_P by Euclidean distance, Poincare k-means by Euclidean k-means; behaviour terms unchanged. Not trained this round; wired and unit-tested.
ABLATION BOTH ON: the full specified run: BEH_DIR=1 and GEO=1, behaviour direction and gates live, log/exp/lambda/d_P live, K4=64, s0 measured once at epoch 0, W initialised to 0, 3000 Stage-2 epochs on four cards, then the frozen 150-epoch Stage-3 protocol. The only arm trained.
SPEC EQUATIONS:
 lambda(x) = 2/(1 - |x|^2)
 (-p)(+)x = ( (1-|p|^2) x - (1-|x|^2) p ) / ( 1 - 2<p,x> + |p|^2|x|^2 )
 d_P(p,x) = 2 * artanh( min(|(-p)(+)x|, 1-1e-7) )
 log_p(x) = d_P(p,x) * ((-p)(+)x) / max(|(-p)(+)x|, 1e-12)
 exp_p(v) = p (+) ( tanh(|v|/2) * v / max(|v|,1e-12) )
 v_i = log_{p_i}(x_i) / lambda(p_i);  vhat_i = v_i / max(|v_i|, 1e-8)
 g_i = 1 + tanh(W b_i);  h_i = P b_i
 u_i = ( g_i (.) vhat_i + h_i ) / max(| g_i (.) vhat_i + h_i |, 1e-8)
 s = s0 * exp( clamp(psi, -1, +1) );  q_i = exp_{p_i}( s u_i )
 a4_i = argmin_{k=1..64} d_P(q_i, c4_k)
 pseudocode per step:
   x = ball_encode(batch)                      # baseline 3-level path unchanged -> a1,a2,a3,p_i,x_i
   t = poincare_log(p_i, x_i); v = t / conformal(p_i); vh = unit(v)
   h = prof[batch] @ P.T ; g = 1 + tanh(prof[batch] @ W.T)   # BEH_DIR=0: h=0, g=1
   u = unit(g * vh + h); q = poincare_exp(p_i, s * u)        # GEO=0: q = p_i + s*u, lambda=1
   a4 = argmin(-poincare_dist(q[:,None,:], c4[None,:,:]))    # GEO=0: Euclidean
   loss = baseline_rqvae_loss + commit(q, c4[a4])            # same coefficient as levels 1-3
   straight-through: backprop into encoder, c4, W, psi (P frozen)
SPEC INPUTS OUTPUTS: Inputs: the item's level-3 input point x_i in the unit Poincare ball, its level-3 prefix codeword p_i, its 32-d unit successor profile b_i, frozen projection P (d x 32), gate matrix W (d x 32, init 0), level-4 codebook c4 (64 x d in the ball), scalar s (init s0, clamped). Outputs: the fourth SID token a4_i in 1..64, the level-4 query point q_i (used by the commitment term and decoder path), and gradients with respect to encoder parameters, c4, W and psi.
SAFEGUARDS: (1) every ball point is clamp-projected to radius <= 1-1e-5 before any log map; (2) arcosh/artanh arguments clamped to [1+1e-9, 1-1e-7] so no NaN at coincident or boundary points; (3) |v_i| < 1e-8 falls back to vhat_i = 0 so the direction is behaviour-only rather than undefined; (4) s clamped to [0.37 s0, 2.72 s0] so the fourth level can neither vanish nor jump to the boundary, with s0 measured at epoch 0 so no scale is hand-chosen; (5) the gate is 1+tanh, bounded in (0,2), so it can never zero the residual; (6) no objective term has its minimum at the ball origin - q_i sits at geodesic distance s from p_i and s is clamped away from 0 - so the round-one origin-collapse failure mode is structurally excluded, and s and |W| are logged every epoch anyway; (7) level-4 codebook usage is logged per epoch (distinct a4 per prefix and globally) so dead-codebook failure is visible in-run; (8) W and psi use the baseline optimiser and learning rate, no new hyperparameter; (9) the level-4 commitment coefficient equals the levels 1-3 coefficient so no weight is introduced; (10) the behaviour profile is precomputed and cached, and zero-transition items deterministically reduce to the behaviour-off path.
END IDEA
