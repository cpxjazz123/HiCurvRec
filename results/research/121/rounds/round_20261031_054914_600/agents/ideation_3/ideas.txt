IDEA: holonomy-frame-sid
TITLE: Behavioural-drift holonomy rotates the per-prefix code frame of the hyperbolic RQ-VAE, so where a prefix's successors drift decides which codewords its items receive.
MOTIVATION: Round one showed where the problem is flat. Level 1 already uses essentially all 256 codewords, while levels 2 and 3 produce only 1,769 and 2,201 distinct prefixes over 24,556 items (about 11 items per deepest triple). The ranking cannot move unless the PREFIX STRUCTURE moves, i.e. unless items sharing an (L1,L2,L3) triple stop sharing it. At the same time issue 126 says the radial coordinate is only group compactness and that permuting radii destroys the correlation, while Gromov-delta and ancestor-depth weighting actively hurt. So the usable behaviour signal is a CONTRAST/direction signal, and the usable geometric object is not a radius but a frame. This idea takes the one curvature-specific quantity with no Euclidean analogue - the holonomy, the rotation a tangent vector picks up when parallel-transported around a closed geodesic loop - and uses it to orient the residual codebook of every prefix, driven by where that prefix's training-only successors actually go.
NOVELTY: Not a weighted assignment, not a Frechet codebook update, not a per-level curvature, not an entropy-ranked radius, not Gromov-delta weighting. Curvature is FIXED at c = 1 (gauge-fixed, exactly as issue 126(b) requires) and nothing about curvature is learned; what is measured is the AREA of a geodesic triangle (origin, prefix text anchor, prefix successor anchor), and that area becomes a holonomy rotation of the code frame in the 2-plane spanned by the two anchors' disagreement. The mechanism is provably inert (identical to the baseline assignment) when behaviour adds no directional information, and it is also inert in the Euclidean limit, so it cannot be a behaviour suffix on an unchanged quantizer. No earlier round used holonomy or a frame rotation.
CHANGE: For every prefix p we build a successor anchor b_p by propagating the frozen text embeddings through the row-normalised training transition matrix, and a text anchor a_p from the prefix's own items; the hyperbolic area of (origin, a_p, b_p) sets an angle theta_p, and the level's shared 256-codeword codebook is rotated by theta_p about a_p before nearest-neighbour assignment inside p. Prefixes whose items lead where they already are get theta_p = 0 and keep their baseline codes; prefixes whose successors drift away get a distinct, area-determined frame, which de-aliases the deep triples.
SPECIFICATION:
Notation: z_i in R^32 is the frozen Stage-1 text embedding (identical to the baseline, no trainable encoder - the variant of round one that did not collapse). Ball map psi(z) = tanh(||z||/s) * z/||z|| with s = mean_i ||z_i|| over the 24,556 items (a derived, scale-relative constant), c = 1, ball radius 1.
(1) Behaviour matrix from the Stage-2 training split only: T[a,b] = number of consecutive pairs a->b in training histories. P(b|a) = T[a,b] / sum_b T[a,b] (zero-mass rows dropped).
(2) For prefix p with item set S_p: a_p = psi(mean_{i in S_p} z_i); v_p(b) = (1/|S_p|) sum_{i in S_p} P(b|i); b_p = psi(sum_b v_p(b) z_b). b_p lives in the SAME frozen text ball, so no cross-space projection is needed; behaviour enters only through v_p.
(3) Poincare distance d(u,v) = arcosh(1 + 2||u-v||^2 / ((1-||u||^2)(1-||v||^2))). Sides: A = d(o,b_p) (opposite the angle at a_p), B = d(o,a_p), C = d(a_p,b_p).
(4) Angles by the hyperbolic law of cosines: cos(alpha) = (cosh B cosh C - cosh A)/(sinh B sinh C), cyclically. Area Delta_p = max(0, pi - (alpha+beta+gamma)). Holonomy theta_p = wrap_to_(-pi,pi](-Delta_p) (Gauss-Bonnet, K = -1).
(5) Frame at a_p: e1 = log_{a_p}(b_p)/||log_{a_p}(b_p)|| (if ||log|| < 1e-8 then theta_p := 0); u_text = top principal direction of {log_{a_p}(z_i) : i in S_p}; e2 = orthonormalise(u_text - <u_text,e1> e1). R_p is the identity except on span(e1,e2), where it is the 2x2 rotation by theta_p.
(6) Rotated codebook for prefix p at level l: c'_{p,k} = exp_{a_p}( R_p log_{a_p}(c^l_k) ), k = 1..256. Assignment k_i = argmin_k d(z_i^l, c'_{p(i),k})^2 (ties to smallest k); residual z_i^{l+1} = log_{c'_{p,k_i}}(z_i^l) as in the baseline RQ. Level 1 uses p = root (a_p = origin), so its frame is untouched and all 256 codewords stay in play.
(7) Stage 2 then trains the frozen recipe on reconstruction of the frozen text geometry; only decoder/residual parameters move. Frames are computed once at epoch 0 and re-checked every 100 epochs for prefix-set drift.
Pseudocode: build T; psi all z; for l in 1..3: for each active prefix p: compute a_p, v_p, b_p, Delta_p, theta_p, R_p; build c'_{p,.}; assign all items in p; update prefix sets. Then run RQ-VAE training with these fixed per-prefix codebooks.
COST: Static pass at epoch 0 plus refresh every 100 epochs: 256 active prefixes x 3 levels, each O(32-d log/exp + a 32x32 rotation), so about 1e6 flops per pass, i.e. milliseconds. Per step the extra work is rotating the codebooks of the prefixes present in a 4096-item batch (at most ~32 prefixes x 256 codes x 32 dims = 2.6e5 flops) plus one Poincare distance matrix instead of a Euclidean one (4096 x 256 x 32 = 3.4e7 flops): expected +5 to +10% on the 0.145 s/epoch baseline, so ~0.152-0.160 s/epoch and 585-605 s for the 3000-epoch, 24-step, 4-GPU Stage 2. Stage 3 is untouched (frozen 150-epoch protocol).
HYPOTHESIS: If deep-prefix aliasing is the binding capacity problem and behaviour adds directional information only where a prefix's successors drift, then rotating just the drifting prefixes' frames should raise the number of distinct L3 triples above 2,201 and thin the items-per-triple tail, and lift Stage 3 test_recall@10 above 0.065 by giving the generator finer distinctions among the frequently queried items. Observable in distinct L3 triples, the 95th percentile of items-per-triple, per-prefix conditional entropy of the L3 code, and finally test_recall@10 / recall@5 / ndcg@10 on the frozen 57,439-query protocol.
RISKS: (a) A rigid per-prefix rotation can act like a relabelling: if the level-3 codebook is near rotationally symmetric the partition barely changes and triples shift without gaining information. (b) If successor drift is dominated by global popularity, v_p is nearly identical for every prefix, all theta_p cluster near one value, and the mechanism degenerates to a single global relabelling. (c) Large areas give large rotations that scatter codes arbitrarily and can hurt. (d) The 100-epoch refresh makes frames piecewise constant, so late prefix drift is only partly tracked. (e) Single run: the +/-0.003 seed noise on recall cannot be separated from a real gain.
BEHAVIOR SIGNAL: Prefix-conditioned successor displacement - the training-only distribution over next items given each item, aggregated over the items of a prefix, compared with the prefix's own text position.
BEHAVIOR COMPUTATION: Directed consecutive-pair counts T[a,b] from Stage-2 training user histories only, row-normalised to P(b|a); prefix successor weight v_p(b) = mean over i in S_p of P(b|i); b_p = psi(sum_b v_p(b) z_b). Nothing else is read, and T is built once before training starts.
LEAKAGE BOUNDARY: T, v_p, a_p and b_p use only Stage-2 training histories and the frozen Stage-1 text embeddings; the prefix sets S_p come from the model's own training-time assignment. Validation and test sequences are never touched: the frames are a deterministic function of (training transitions, frozen text vectors), so no item's SID can depend on a held-out interaction and no test query can alter theta_p or c'_{p,k}.
HYPERBOLIC OPERATOR: Poincare ball with FIXED curvature c = 1 (gauge-fixed, no learned curvature), using the Poincare distance, the log/exp maps at a_p, and the geodesic-triangle area via Gauss-Bonnet, whose holonomy is -Area. The rotation R_p is itself a hyperbolic isometry about a_p.
HYPERBOLIC LOCATION: Inside quantization, at every RQ level, immediately before the nearest-codeword assignment and inside the decode of the assigned code: the shared codebook of a prefix is expressed in that prefix's own holonomy-rotated frame.
COUPLING PATH: transition counts -> successor anchor b_p -> hyperbolic triangle (origin, a_p, b_p) -> area -> holonomy angle theta_p -> rotation R_p of the level-l codebook -> assignment k_i -> SID token -> Stage 3. Removing behaviour sets b_p := a_p, the triangle degenerates, Delta_p = 0, theta_p = 0 and every prefix keeps the baseline codes; removing geometry sets Delta_p := 0 (Euclidean holonomy is trivial) and the assignment becomes the Euclidean baseline. Neither term survives alone.
COUPLING EQUATION: c'_{p,k} = exp^{c=1}_{a_p}( R_{e1,e2}(theta_p) log^{c=1}_{a_p}(c_k) ), with theta_p = -Area_c( o, a_p(w_behaviour), b_p(w_behaviour) ) and b_p = psi(sum_b v_p(b) z_b), v_p(b) proportional to sum_{i in S_p} P_train(b|i).
OBSERVABLES: distinct L3 prefixes (baseline 2,201), distinct L2 prefixes (baseline 1,769), the items-per-triple distribution and its 95th percentile, per-prefix conditional entropy of the L3 code, the fraction of prefixes with |theta_p| > 1e-3, per-epoch reconstruction loss, SID coverage (all 24,556 items, 251 L1 codewords), and Stage 3 test_recall@10 (target > 0.065; baseline 0.0679; round-one 0.05439), recall@5 and ndcg@10.
ABLATION BEHAVIOR OFF: use_behaviour_anchor = False: set v_p(b) uniform over S_p (equivalently b_p := a_p), so Delta_p = 0, theta_p = 0, all R_p = I and the assignment is exactly the baseline; wired in code, never trained.
ABLATION GEOMETRY OFF: use_hyperbolic = False: set theta_p := 0 and use the Euclidean distance and Euclidean exp/log, so the holonomy channel is provably zero and the quantizer reduces to the Euclidean RQ-VAE; wired in code, never trained.
ABLATION BOTH ON: the full run above, the only arm actually trained: 3000 Stage-2 epochs on four GPUs at global batch 4096, then the frozen 150-epoch Stage 3.
SPEC EQUATIONS: see steps (1)-(7); d(u,v) = arcosh(1 + 2||u-v||^2/((1-||u||^2)(1-||v||^2))); exp_a(v) = tanh(||v||)(v/||v||), log_a its inverse, both in the c = 1 ball; cos(alpha) = (cosh B cosh C - cosh A)/(sinh B sinh C); Delta = pi - (alpha+beta+gamma); theta = -Delta; c'_{p,k} = exp_{a_p}(R_p log_{a_p}(c_k)); k_i = argmin_k d(z_i^l, c'_{p(i),k})^2.
SPEC INPUTS OUTPUTS: Inputs: frozen text embeddings z_i in R^32 for 24,556 items, training transition counts T, the baseline 3 x 256 codebook, and the current prefix assignment. Outputs: for each active prefix and level a 256 x 32 rotated codebook c'_{p,.}, a per-prefix angle table theta (256 x 3), the SID matrix (24,556 x 3), and the prefix sets consumed by the next level.
SAFEGUARDS: map every vector with psi and clip ball norms to 1 - 1e-3; clamp every cosh argument to [0, 30] and every cos(alpha) to [-1 + 1e-7, 1 - 1e-7] before arccos; clip Delta_p to [0, pi] and set theta_p := 0 whenever any side is below 1e-8, any value is non-finite, or |theta_p| < 1e-6; wrap theta to (-pi, pi]; orthonormalise (e1,e2) by Gram-Schmidt and fall back to theta_p = 0 if ||e2|| < 1e-6; verify R_p orthogonality to 1e-5; assert the angle table is finite and log the fraction of prefixes with nonzero theta; break assignment ties on the smallest code index. Because the rotation is an isometry about a_p it cannot shrink the codebook toward the origin and cannot reproduce the round-one zero-residual collapse, and because the text geometry is frozen the trainable-encoder collapse path is unreachable.
