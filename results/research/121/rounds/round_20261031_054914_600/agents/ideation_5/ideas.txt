IDEA: GEO-RAY-CONTRAST-RQ
TITLE: Behaviour-contrast geodesic-ray prefix tree with fixed-radius exp-map codewords and behaviour-weighted Lorentzian Sinkhorn assignment
MOTIVATION: Round one produced SIDs whose prefixes were behaviourally uninformative: level 1 spread over all 256 codewords but levels 2-3 collapsed to 1769 and 2201 distinct prefixes (~14 items per deepest prefix), and the curved residual chain either collapsed to 1-2 prefixes or, when frozen, could not reach the tokens. The recommender then scored 0.05439 recall@10. The problem is that the token path is chosen by an unweighted nearest-residual rule whose minimum is the zero residual, so nothing forces the deepest prefixes to separate items that users actually distinguish.
NOVELTY: The token tree is generated as geodesic rays of FIXED radius from each parent (radius = the measured median residual norm at that node), so a codeword can never be the parent itself and the zero-residual attractor does not exist; the 256 branch directions at each node are the behaviour-CONTRAST tangent directions of that node's items; assignment is a balanced Lorentzian Sinkhorn solve whose cost is multiplied by the item-to-parent behaviour contrast. This differs from successor-Frechet codebook updates (no barycentre update), per-level curvature control (curvature is fixed at c=1 and is not the mechanism), behaviour cones (no cone constraint, the direction set is unconstrained and trained), and behaviour-ranked radial assignment (radius is fixed per node and identical for all children; behaviour acts on direction and on assignment weight, never on radius).
CHANGE: Replace the RQ-VAE nearest-residual quantizer with a three-level hyperbolic prefix tree: level-l codeword k is exp_{c_parent}(eta_l * u_{l,k}) with ||u_{l,k}||=1 and eta_l the node's median log-map residual norm; items are assigned to children by a Sinkhorn plan on the cost (1 + b_i) * d_Lorentz(x_i, c_{l,k}); the residual passed to level l+1 is the log map of the item at its assigned child. Stage 2 trains only the direction matrices U_l (256x32 per level) under the Sinkhorn cross-entropy, with the frozen Stage-1 text geometry as input.
SPECIFICATION: Inputs: frozen Stage-1 text embeddings e_i (D dims) for the 24,556 training items; training-only directed transition counts T_ij. Precompute: fixed PCA to D'=32 fit on training item text (frozen after Stage 1), z_i = PCA(e_i), clipped to ||z_i|| <= 1-1e-6; x_i = exp_0^c(z_i) in the Poincare ball, c=1, equivalently Lorentz coordinates (sqrt(1+c||z_i||^2)/sqrt(c), z_i). Behaviour: p_ij = log((T_ij + 1) / ((out_i * in_j)/M + 1)) clipped at 0, sym-max b_ij = max(p_ij, p_ji); b_i(S) = mean_{j in S, j != i} b_ij (0 if S has one item). Tree build (offline, <60 s): for node with item set S_p and parent point c_p, compute r_i = log_{c_p}(x_i), rhat_i = r_i/||r_i||, weights w_i = 1 + b_i(S_p); run 10 iterations of weighted spherical k-means with K=256 (deterministic seeded init) to get means m_k; set u_k = normalize(m_k + rho * W_k) with rho = 1/sqrt(D') = 0.1768 and W a fixed seeded Gaussian frame (tie-break, a priori); eta = median_i ||r_i||, clipped to [1e-3, 0.99*artanh(sqrt(0.95))]; c_{l,k} = exp_{c_p}(eta * u_k). Assignment: C_ik = (1 + b_i(S_p)) * d_Lorentz(x_i, c_{l,k}); S = Sinkhorn(-C/eps) with eps = median(C)/2, 5 log-domain iterations, row marginals 1 and column marginals |S_p|/256; token k_i = argmax_k S_ik. Residual: x_i <- exp^{-1}_{c_{l,k_i}}(x_i) (a tangent vector at the child, re-injected as the next level's input point by exp_{c_{l,k_i}} of the projected vector, so the child is the new origin of its own tangent chart). Stage 2 loss: L = -sum_i sum_k S_ik * log softmax_k( <rhat_i, u_k> / tau ) with tau = 1/sqrt(D'), plus the standard RQ-VAE reconstruction term on the frozen z_i through a linear decoder. Trained parameters: U_1,U_2,U_3 (3 x 256 x 32 = 24,576 scalars) only; everything else frozen. SID of item i = (k_i^1, k_i^2, k_i^3).
COST: Precompute (PCA, PMI, offline tree) is O(N*K*D') = 24,556*256*32 ~ 2.0e8 MACs per level, seconds on one GPU, once. Per Stage-2 step (global batch 4096, 1024 per card): three cost matrices 1024x256 plus 5 Sinkhorn iterations and one log-map per level, about 25M MACs forward and 50M with backward, ~6-10 ms/step on four cards versus ~6 ms/step baseline; per epoch 24 steps ~0.15-0.25 s versus the measured 0.145 s/epoch, so 450-750 s for 3000 epochs versus 571 s measured. Memory adds one 1024x256 cost/plan buffer per level (<3 MB), no change to Stage 3.
HYPOTHESIS: If behaviour contrast is what makes adjacent prefixes predictable (the issue-126 finding that contrast metrics, not curvature magnitude or depth, track recall), then forcing the deepest prefixes to be behaviour-contrast directions at a fixed geodesic radius should raise the number of distinct L3 prefixes well above 2,201 and make the Stage-3 prefix transitions more predictable, which should show up as test_recall@10 above 0.065. Observed as: L2/L3 distinct-prefix counts, prefix-transition accuracy, and the single frozen Stage-3 recall. If recall does not move, the hypothesis that the collapse was a prefix-structure problem is falsified for this dataset.
RISKS: (1) Behaviour contrast b_ij is sparse and noisy at 24,556 items, so the direction estimates may be near-random at deep nodes where S_p is small; mitigated by the frame tie-break but not eliminated. (2) The frozen text geometry may not contain the behaviour-contrast directions, so the best achievable branch directions could be weak. (3) Sinkhorn balancing forces uniform usage and could manufacture prefixes that are geometrically arbitrary in low-density regions. (4) The fixed radius eta set to the median residual may be too large for deep nodes, pushing codewords off the item manifold. (5) Only 24,576 trainable scalars is a very small capacity; if Stage 3 gains need more, this underfits.
BEHAVIOR SIGNAL: Popularity-adjusted, symmetrised directed-transition contrast (a PMI over consecutive-item transitions), aggregated as b_i(S), the mean contrast of item i to the other items of its current prefix node.
BEHAVIOR COMPUTATION: From the Stage-2 training split only: count directed pairs (u_t -> u_{t+1}) within each training sequence into T_ij; compute p_ij = max(0, log((T_ij+1)/((out_i*in_j)/M + 1))) with M the total pair count and out_i, in_j the marginal counts; b_ij = max(p_ij, p_ji); b_i(S) = mean over j in S, j != i. Recomputed once before Stage 2 and held fixed; the per-node aggregation b_i(S_p) is read from the same fixed matrix at every epoch.
LEAKAGE BOUNDARY: T is built only from Stage-2 training sequences; no validation or test interaction is read, and Stage-3 queries are never touched. The Stage-1 text encoder, the PCA basis and the offline tree are fit on training items only, and the SIDs are frozen before Stage 3 starts; Stage 3 consumes only the resulting integer triples. No statistic of the validation or test split enters any direction, radius, weight or threshold.
HYPERBOLIC OPERATOR: Poincare/Lorentz exponential and logarithmic maps, Lorentzian distance d_Lorentz(x,y) = arcosh(-<x,y>_L) with the Minkowski inner product, and the exp-map codeword construction exp_{c_p}(eta*u); trainable negative curvature is not used, curvature is fixed at c = 1 and is treated as the gauge it is.
HYPERBOLIC LOCATION: Inside the quantizer, both in codeword generation (exp map from the parent at a fixed geodesic radius) and in assignment (Lorentzian distance inside the Sinkhorn cost); the log map produces the residual that feeds the next level, so the geometry is in the gradient path of every token.
COUPLING PATH: behaviour contrast -> per-node branch directions u_{l,k} and per-item weight (1 + b_i) -> geodesic-ray codeword c_{l,k} = exp_{c_p}(eta_l u_{l,k}) and cost C_ik -> Sinkhorn plan -> token k_i^l -> log-map residual -> next level -> SID -> Stage 3. Removing behaviour zeroes b_i, which changes both the k-means directions and the cost weights, hence a different plan, different tokens and a different prefix tree; removing geometry replaces exp/log and d_Lorentz by addition and L2, which changes the codeword positions and the nearest-child ranking at the same coordinates. Neither removal leaves the other's computation intact.
COUPLING EQUATION: C_ik = (1 + b_i(S_p)) * d_Lorentz( x_i , exp_{c_p}( eta_l * u_{l,k} ) ), followed by S = Sinkhorn(-C/eps), where b_i(S_p) is the behaviour term, exp_{c_p}(eta_l u_{l,k}) is the curved codeword and d_Lorentz is the curved distance.
OBSERVABLES: level-2 and level-3 distinct prefix counts (must rise above 1,769 / 2,201), items per deepest prefix (down from ~14), prefix-transition accuracy on held-out training prefixes, codebook usage entropy per level, and finally Stage-3 test_recall@10 on 57,439 queries; the SID assignment itself is the primary observable of the coupling.
ABLATION BEHAVIOR OFF: b_ij := 0 everywhere, so w_i = 1 in the spherical k-means, C_ik = d_Lorentz(...) unweighted, and the Sinkhorn plan is the pure geometric balanced assignment; geometry and the fixed-radius construction are unchanged. Code exists behind a single flag; not trained in this round.
ABLATION GEOMETRY OFF: replace exp_{c_p}(eta u_k) by c_p + eta u_k, replace d_Lorentz by ||x_i - c_{l,k}||_2, and replace the log-map residual by plain subtraction; behaviour weights and Sinkhorn are unchanged. This is the c -> 0 limit and is a different computation, not a relabelling. Code exists behind a single flag; not trained in this round.
ABLATION BOTH ON: the full pathway above, behaviour contrast in the directions and in the cost, curved codewords and Lorentzian distance, fixed-radius tree, Sinkhorn; this is the only arm trained (one seed, 3000 epochs, frozen Stage-3).
SPEC EQUATIONS:
p_ij = max(0, log((T_ij + 1) / ((out_i in_j)/M + 1))); b_ij = max(p_ij, p_ji); b_i(S) = mean_{j in S, j != i} b_ij.
z_i = PCA_32(e_i), z_i <- z_i * min(1, (1-1e-6)/||z_i||); x_i = (sqrt(1+||z_i||^2), z_i) in Lorentz R^{1+32}.
r_i = log_{c_p}(x_i) = arcosh(alpha) * (x_i - alpha c_p)/||x_i - alpha c_p||, alpha = <c_p,x_i>_L; rhat_i = r_i/||r_i||.
u_k = normalize(m_k + (1/sqrt(32)) W_k), W fixed seeded 256x32, m_k = weighted spherical k-means mean with weights 1 + b_i(S_p), 10 iters.
eta = clip(median_i ||r_i||, 1e-3, 0.99*artanh(sqrt(0.95))); c_{l,k} = cosh(eta) c_p + sinh(eta) u_k (Lorentz form of exp_{c_p}(eta u_k)), renormalised to <c,c>_L = -1.
C_ik = (1 + b_i(S_p)) * arcosh(-<x_i,c_{l,k}>_L).
Sinkhorn in log domain, 5 iterations: K_ik = exp(-C_ik/eps), eps = median(C)/2; alternate row normalisation to 1 and column normalisation to |S_p|/256.
k_i^l = argmax_k S_ik; x_i <- exp^{-1}_{c_{l,k_i}}(x_i), then re-anchor to the child for level l+1.
L = -sum_i sum_k S_ik log softmax_k(<rhat_i,u_k> * sqrt(32)) + lambda_rec * ||z_i - Dec(sum_l E_l[k_i^l])||^2 with lambda_rec = 1 (RQ-VAE default, unchanged).
SPEC INPUTS OUTPUTS: Input: frozen 768-dim (or Stage-1 dim) text embeddings of 24,556 training items, training-only directed transition counts, K=256, L=3, D'=32, c=1. Output: an integer SID triple per item, three direction matrices U_l (the trained parameters), the per-node radius table eta_l, and the log-map residual stream used by the next level.
SAFEGUARDS: clip ||z_i|| at 1-1e-6 and keep c=1 so the ball never leaves the manifold; use the Lorentz form with renormalisation <c,c>_L = -1 after every exp map; arcosh argument clipped to [1+1e-7, inf); log map uses ||x_i - alpha c_p|| with eps 1e-7; eta clipped to [1e-3, 0.99*artanh(sqrt(0.95))] and per-node median prevents a zero step; the seeded frame term with rho = 1/sqrt(D') prevents duplicate directions and is a tie-break, not a tuned constant; Sinkhorn in log domain with 5 fixed iterations and a max-shift to avoid overflow; enforce a deterministic tie-break on argmax by codeword index; assert 100% item coverage and no empty child; no parameter is chosen by trying values - eps is the measured median cost, tau and rho are the chance-scale 1/sqrt(D'), lambda_rec is inherited from the RQ-VAE.
END IDEA
