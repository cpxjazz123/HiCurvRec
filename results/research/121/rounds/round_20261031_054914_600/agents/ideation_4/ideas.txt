IDEA: HSPT-RQ
TITLE: Hyperbolic successor parallel-transport residual quantizer: the parent prefix's geodesic distance transports each child codebook along the item's directed-transition direction
MOTIVATION: In a generative recommender the SID is consumed as a token sequence, so what matters is whether a parent prefix (L1, L2) leaves the true next item's child prefix predictable. Round one's SID was healthy but ranking-useless: level 1 saturated 251 of 256 codewords while levels 2 and 3 collapsed to 1769 and 2201 distinct prefixes, i.e. about fourteen items share every deepest prefix and the children carry almost no discriminative information about what a user actually does next. A Euclidean RQ assigns a child codeword as if every parent prefix lived at the same place, so the child partition is blind to how far out in the hierarchy the parent already sits and to where the user's behaviour is heading from that item.
NOVELTY: The codebook is made parent-dependent by GEODESIC PARALLEL TRANSPORT, not by radial reweighting, not by Fréchet centroid updates, not by per-level curvature control, not by Gromov-delta or ancestor-depth weights, and not by cone constraints. Curvature enters as the Levi-Civita connection of the Lorentz model (transport is the identity in the flat limit), behaviour enters only as the transport DIRECTION, and they meet in a single line: the level-l codebook seen by item i is PT over the geodesic o -> P_{l-1} of C_l with direction b_i. Because transport is an isometry it cannot shrink codes toward the origin, which is the exact collapse mode that killed round one's curved residual objective.
CHANGE: Replace the level-l Euclidean nearest-codebook lookup by a lookup against a codebook that has been parallel-transported from the origin to the item's current parent prefix point, along the geodesic whose direction is the item's behaviour successor direction; the same transported vector is used for the straight-through residual, so the behaviour-and-curvature shaped partition is exactly the one the tokens encode.
SPECIFICATION:
Curvature fixed at K = -1 (the gauge result of issue 126 says |K| is not identifiable, so it is fixed, never tuned).
Lorentz point of tangent u in R^32: L(u) = (sqrt(1+||u||^2), u).
exp_o(u) = L(u); log_o((x0,x)) = x.
Transport of a spatial code vector w along the geodesic o -> P with unit spatial direction b and length rho:
  w_par = <w,b>_E ; w_perp = w - w_par*b
  PT(w; rho, b) = (w_par*sinh(rho), w_par*cosh(rho)*b + w_perp) in (time, space) tangent coordinates at P.
This is an isometry: <PT(w),PT(w)>_L = ||w||^2.
Per item i with encoder output z (clipped, ||z||<=5) and precomputed behaviour direction b_i:
  u <- 0 ; codes <- []
  for l = 1..3:
      rho <- ||u|| ; P <- L(u)
      for k in 1..256: Q_k <- exp_{P}( PT(C_l[k]; rho, b_i) )
      k* <- argmin_k d_L( L(z), Q_k ),  d_L((x0,x),(y0,y)) = arccosh(max(1, x0*y0 - <x,y>))
      codes.append(k*) ; u <- u + C_l[k*]                       (straight-through: gradient copies dB/dz)
  reconstruction loss on z_hat from the sum of C_l[k*]; commitment loss unchanged from the frozen baseline.
COST: Behaviour directions are precomputed once from the training split (sparse top-20 rows), so they add zero per-step cost. The extra per step is, per level, a 4096 x 256 x 33 transport plus a 4096 x 256 Lorentz distance, chunked at 512 items: about 1.0e8 elementwise ops and about 70 MB of transient memory per step at the frozen scale. Estimated 0.145 s/epoch -> 0.20-0.25 s/epoch, i.e. the 571 s Stage2 run becomes roughly 780-1050 s on the same four cards; Stage3 is untouched.
HYPOTHESIS: If parent distance and behaviour direction genuinely shape the child partition, then the number of distinct L2 and L3 prefixes must rise materially above 1769 and 2201 while level-1 usage stays broad, the measured mean transport magnitude cosh(rho) must be clearly above 1 at L3, and Stage3 test_recall@10 must exceed the frozen 0.0679 baseline and the 0.065 gate from the single frozen run. If recall stays at 0.054 while the prefix counts rise, the mechanism is producing a finer but meaningless partition and is not worth keeping.
RISKS: The per-item effective codebook may become so item-specific that assignment turns arbitrary, which would raise prefix counts but destroy prefix semantics and drop recall below 0.054; deep prefixes (rho up to 5) give cosh(rho) up to 74 and can amplify the along-behaviour component until the transported codebook is dominated by b_i, so rho must be clamped and monitored; the behaviour direction derived from frozen text geometry may be too noisy for rare items (row mass below the pruning threshold), where the mechanism degenerates to identity transport.
BEHAVIOR SIGNAL: Directed item-to-item transitions of the training sequences, converted into a per-item successor direction in the tangent space at the origin, used as the parallel-transport direction.
BEHAVIOR COMPUTATION: From the Stage-2 TRAINING split only: build the directed count matrix T_ij from consecutive (item, next item) pairs in every training sequence with a repeat-suppression window of 3; row-normalise, keep the top 20 successors by count per item, and drop any successor with mass below 1/20 of the row mass (2 fixed, derived defaults: the pruning threshold is the reciprocal of the retained support size, no sweep). With the frozen Stage-1 text embedding z^text of the baseline, define d_i = sum_j P_ij (z^text_j - z^text_i) and b_i = d_i / ||d_i||, with b_i = 0 when ||d_i|| < 1e-8.
LEAKAGE BOUNDARY: T and b are computed only from the Stage-2 training sequences and the frozen Stage-1 text embedding, which itself never saw validation or test interactions; validation is used only for logging and Stage3 test queries are never read during Stage2, so no validation or test interaction can reach the transport directions, the codebooks or the encoder.
HYPERBOLIC OPERATOR: The Levi-Civita parallel transport of the Lorentz hyperboloid of constant curvature K = -1 (fixed, not trainable), with closed form PT(w; rho, b) = (w_par sinh rho, w_par cosh rho b + w_perp), plus the Lorentz geodesic distance used for the assignment.
HYPERBOLIC LOCATION: Inside the residual quantizer's per-level assignment and straight-through residual, at levels 2 and 3 where the parent prefix has rho > 0; it shapes which child codeword an item receives and therefore the L2/L3 prefix structure itself.
COUPLING PATH: encoder output -> accumulated tangent u -> parent point P = exp_o(u) with distance rho -> behaviour direction b_i selects the geodesic -> PT moves every child codebook along that geodesic by rho -> Lorentz distance picks the child code -> straight-through gradient updates the encoder and codebooks -> the emitted L2/L3 token is the transported choice. Setting b_i = 0 makes the transport exactly the identity and the L2/L3 assignment Euclidean-in-tangent regardless of rho; replacing the connection with the trivial one makes transport the identity regardless of b_i, so each switch alone destroys the pathway.
COUPLING EQUATION: k*_l(i) = argmin_k arccosh( max(1, <L(z), exp_{L(u)}( PT(C_{l,k}; ||u||, b_i) )>_L ) ), with b_i = normalise( sum_j P_ij (z^text_j - z^text_i) ) the behaviour term and PT / arccosh / exp the curved terms.
OBSERVABLES: distinct L2 prefix count (baseline 1769), distinct L3 prefix count (baseline 2201), L1 codeword usage (baseline 251/256), the per-level mean and 95th percentile of cosh(rho) and of the transport's along-behaviour fraction |w_par|/||w||, the frozen prefix-transition probe's accuracy at predicting the empirical next-item prefix from the parent prefix, the train reconstruction loss trajectory, and Stage3 test_recall@10 / @5 / ndcg@10.
ABLATION BEHAVIOR OFF: b_i := 0 for all items, so PT(w; rho, 0) = (0, w) = identity transport; the quantizer keeps the Lorentz distance but the child codebook no longer depends on where the parent sits or where behaviour points.
ABLATION GEOMETRY OFF: replace exp, log, arccosh and the connection by their flat counterparts, i.e. PT = identity for every rho and b; the mechanism reduces exactly to the baseline RQ-VAE in R^32 with behaviour reading out to nothing.
ABLATION BOTH ON: the full coupled run, one training run, 3000 epochs, four cards, frozen recipe, no arm trained with the switches off.
SPEC EQUATIONS:
  L(u) = ( sqrt(1+||u||^2), u )
  exp_P(v) = cosh(||v||) P + sinh(||v||) v/||v||,  P = L(u), v = PT(C_{l,k}; ||u||, b_i)
  PT(w; rho, b): wpar = dot(w,b); wperp = w - wpar*b; return (wpar*sinh(rho), wpar*cosh(rho)*b + wperp)
  d_L(X,Y) = arccosh( clamp(X0*Y0 - dot(Xs,Ys), min=1.0) )
  assignment per level then u <- u + C_l[k*], straight-through dB/dz = I
SPEC INPUTS OUTPUTS: Inputs: encoder output z in R^32, the three codebooks C_1..C_3 in R^{256x32}, the precomputed unit behaviour directions b in R^{24556x32} restricted to the batch, and the frozen baseline losses. Outputs: the three code indices (c1,c2,c3) per item, the quantized tangent sum u used by the decoder, and per-level diagnostics (rho, cosh(rho), along-behaviour fraction).
SAFEGUARDS: fixed curvature K = -1 (gauge, never trained); ||z|| clipped to 5 and rho clipped to [0, 5] so cosh(rho) <= 74; Lorentz arccosh argument clamped to >= 1 with an epsilon inside the sqrt; codebook rows re-normalised to unit Euclidean norm after every optimiser step so their scale cannot drift; b_i zeroed when ||d_i|| < 1e-8 and for items with an empty successor row; assignment chunked at 512 items to bound transient memory; a NaN/Inf guard that falls back to identity transport for the affected step; the along-behaviour fraction is logged every epoch so a transport that has been swamped by b_i is visible rather than silent.
END IDEA
