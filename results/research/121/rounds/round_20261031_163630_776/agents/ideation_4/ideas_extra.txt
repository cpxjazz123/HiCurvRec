IDEA: SID-GW-DELTA
TITLE: Gromov-delta-calibrated Poincare distance-matrix alignment of the RQ-VAE code space to the training behaviour graph.
MOTIVATION: RQ-VAE Semantic IDs are trained to reconstruct item content, so code-space neighbourhoods reflect content similarity rather than co-consumption. Two items that users actually move between land far apart in code space, and the stage-3 generator has to memorise the transition instead of reading it off the SID prefix. The frozen probe exposes exactly this (Spearman 0.0402, top-10 overlap 0.0124 for the plain Euclidean RQ-VAE).
NOVELTY: The previous mechanisms act per item or per level: behaviour-ranked radial assignment (BRad-RQ), per-level curvature scheduled by a hard prefix-transition score (CURVCTRL-SID), Frechet successor-weighted codebook updates. This one never touches the assignment weights, the codebook update rule or the per-level curvature schedule. It adds a single batch-level term that aligns the entire pairwise distance structure of the code space to the behaviour distance, and it *measures* how hyperbolic the behaviour graph actually is, then fixes the curvature from that measurement instead of scheduling or tuning it.
CHANGE: Stage-2 loss gains one term, L_GW, the discrepancy between normalised pairwise Poincare distances among the batch's decoded code vectors and normalised pairwise behaviour distances among the same items; gradients flow through the straight-through quantizer into both the encoder and the codebooks. The Poincare curvature is a single frozen constant kappa = -1/delta^2, where delta is the estimated 4-point hyperbolicity of a tree built on training transitions.
SPECIFICATION: (1) Build the training-only behaviour distance d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)), symmetrised as min(d_beh(i,j), d_beh(j,i)), from training-split directed transitions only. (2) Build a single-linkage (or neighbour-joining) tree T over the 24556 items from d_beh, estimate delta by sampling 2000 deterministic quadruples and taking max over quadruples of (largest two of the three pairwise sums minus the third)/2; clip delta to [0.01*diam(T), diam(T)]; set kappa = -1/delta^2. (3) At each step, form a batch of 128 anchors, each with its 8 strongest training behaviour neighbours, plus 128 uniform random items: B = 1152. (4) Decode code vectors z_i from the straight-through SID embedding, map to the Poincare ball with exp_0 and clamp radius to 1-1e-5. (5) Compute D_P(i,j) = (2/sqrt|kappa|) artanh(sqrt|kappa| * ||(-z_i) xor z_j||) for pairs present in the batch; compute d_beh for the same pairs from the sparse precomputed table (pairs without an observed transition fall back to their 2-hop shortest path in the transition graph, and are dropped if still absent). (6) Normalise both matrices by their batch medians; L_GW = mean over pairs of (Dhat_P - dhat_beh)^2. Total loss = L_RQVAE + 1.0 * L_GW.
COST: One-off CPU precompute of the sparse behaviour kNN and the delta estimate (a few minutes, outside the 3000-epoch budget). Per step only ~9-10k pairs are evaluated, so the extra cost is vectorised Poincare distance plus a sparse lookup: roughly +3-5% wall clock, about +0.3 to +0.6 h over 72k steps (3000 epochs x 24 steps) on four cards. No extra parameters, no extra forward pass.
HYPOTHESIS: If behaviour adjacency is close to tree-like (small delta), a single constant-curvature embedding can realise it with low distortion, and forcing code distances to match it puts transition information into the SID prefixes. Observable as probe Spearman rising above 0.0402 and top-10 behaviour-neighbour overlap above 0.0124, with a matching rise in Stage-3 test_recall@10 above 0.065; a single run, so ~0.013 of recall noise is part of the reading.
RISKS: The behaviour graph may be far from tree-like, giving a small |kappa| and an almost Euclidean term; the median normalisation can be dominated by the uniform random items and flatten the gradient; sampled neighbour pairs may be too few per batch to move the codebook; the probe may improve while Stage 3 does not, because matching distances is not the same as making prefixes predictive.
BEHAVIOR SIGNAL: Popularity-adjusted, symmetrised directed item-transition distance over training-split transitions, used both as the alignment target and as the kNN that constructs each batch.
BEHAVIOR COMPUTATION: From the training split only, count directed transitions n_ij, item popularity pop_i (training interactions), form the sparse matrix d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)), symmetrise by elementwise min, keep the top-32 neighbours per item, and materialise the 2-hop fallback for pairs inside a sampled batch.
LEAKAGE BOUNDARY: The transition counts, popularity, kNN table, the tree T and delta are all computed before Stage-2 starts from the training split only. Validation and test interactions are never read by the SID construction, the batch sampler, the curvature estimate or the loss; the probe itself is computed after training and never feeds back.
HYPERBOLIC OPERATOR: Poincare ball distance with fixed negative curvature kappa = -1/delta^2, delta measured from the behaviour tree and clipped relative to the tree diameter; no trainable curvature.
HYPERBOLIC LOCATION: Inside the Stage-2 training objective, on the pairwise distance matrix between decoded code vectors; it therefore shapes the encoder and the RQ codebooks, not a post-hoc metric.
COUPLING PATH: d_beh -> tree T -> delta -> kappa -> Poincare distance D_P(kappa) -> normalised GW discrepancy against d_beh -> gradient into encoder and codebooks -> SID assignment. Removing the behaviour signal removes the target and the neighbour-anchored batches, so L_GW vanishes and Stage 2 is the plain RQ-VAE. Removing the curvature sends kappa to 0, D_P to the Euclidean distance, and changes every gradient in the term.
COUPLING EQUATION: L_GW = mean_{(i,j) in P} [ D_P(z_i, z_j ; kappa = -1/delta^2) / med(D_P)  -  d_beh(i,j) / med(d_beh) ]^2, with the neighbour set P drawn from the behaviour kNN and delta measured on the behaviour tree.
OBSERVABLES: Probe Spearman between code-space distance and training behaviour distance (baseline 0.0402); top-10 behaviour-neighbour overlap (baseline 0.0124); per-level prefix behaviour predictability (accuracy of predicting the true next item's level-l code from the context prefix, l = 1..4); codebook usage entropy; Stage-3 test_recall@10 against the 0.065 target.
ABLATION BEHAVIOR OFF: A switch `use_behaviour` set to False; d_beh is replaced by a constant matrix, the batch is uniformly sampled, L_GW reduces to a variance penalty on D_P and the run is the plain Euclidean/curved RQ-VAE. Implemented and correct, not trained in this round.
ABLATION GEOMETRY OFF: A switch `curvature_mode="euclidean"`; kappa is set to 0, D_P becomes ||z_i - z_j||, everything else including the behaviour target and the batches is unchanged. Implemented and correct, not trained in this round.
ABLATION BOTH ON: `use_behaviour=True` and `curvature_mode="poincare"` with kappa = -1/delta^2 from the measured delta; this is the single trained arm.
SPEC EQUATIONS: 
  d_beh(i,j) = -log((n_ij + 1) / (sqrt(pop_i * pop_j) + 1));  d_beh <- min(d_beh, d_beh^T)
  T = single_linkage(d_beh);  delta = max_Q [ (s1 + s2 - s3)/2 ] over sampled quadruples Q, s1>=s2>=s3 the three pairwise tree sums
  delta <- clip(delta, 0.01*diam(T), diam(T));  kappa = -1/delta^2
  z_i = decode(sid_i) via straight-through;  u_i = exp_0(z_i), ||u_i|| <- min(||u_i||, 1-1e-5)
  D_P(i,j) = (2/sqrt|kappa|) * atanh( sqrt|kappa| * || (-u_i) xor u_j || )
  Dhat_P = D_P / median(D_P);  dhat = d_beh / median(d_beh)
  L = L_RQVAE + mean_{(i,j) in P} (Dhat_P(i,j) - dhat(i,j))^2
SPEC INPUTS OUTPUTS: Inputs: training transition counts n_ij, training popularity pop_i, the batch's decoded code vectors z_i (B x d), the precomputed sparse d_beh table, the scalar delta and kappa. Outputs: a scalar L_GW and its gradient with respect to z_i (hence to the encoder weights and codebook entries); the batch sampler also returns the neighbour-anchored index set.
SAFEGUARDS: Clamp the Poincare radius to 1-1e-5 before artanh; add 1e-8 inside artanh and inside the log; clip delta to a diameter-relative interval so kappa stays finite and bounded; guard medians with 1e-6; drop pairs with no observed or 2-hop behaviour path instead of imputing a large distance; skip L_GW for a step if fewer than 512 valid pairs remain; keep the straight-through gradient magnitude clipped to the RQ-VAE's existing gradient clip.
END IDEA
