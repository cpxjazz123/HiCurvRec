IDEA: LORBARY-RECON-TARGET
TITLE: Behaviour-weighted Lorentzian Karcher barycentre as the Stage-2 reconstruction target, scored by geodesic distance
MOTIVATION: The RQ-VAE latent stays organised by text-embedding similarity because Stage-2's dominant term asks item i to reconstruct item i's own text embedding; every behaviour term can only fight that gradient. That is why six mechanisms which edited codebook vectors, per-level curvature, radial position or assignment all left the probe at 0.0402 Spearman / 0.0124 top-10 overlap. The recommender symptom is that two items a user actually jumps between receive unrelated SIDs, so the generator has nothing learnable to copy at the transition.
NOVELTY: All earlier mechanisms perturbed the quantizer (successor-weighted Fréchet codebook updates, prefix-transition curvature per level, entropy-ranked radial assignment, cone/successor smoothing). This one changes the label side of Stage-2: the target each item must reconstruct is a behaviour-weighted Karcher barycentre in the Lorentz model, and the loss is a geodesic distance to that barycentre. Encoder, decoder, RQ levels and the codebook update rule are unchanged; no new loss weight, no new architecture, no new parameter count.
CHANGE: Replace the per-item reconstruction target (the item's own text embedding) with a precomputed behaviour-weighted Lorentzian Karcher barycentre over the item's top-10 training-transition neighbours, and replace MSE on the decoder output with the squared geodesic distance between the decoded hyperboloid point and that barycentre.
SPECIFICATION: (1) From training-split transitions only compute n_ij and pop_i and set d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)), the probe's own statistic; (2) N_i = the 10 smallest-d_beh neighbours with n_ij >= 1; (3) weights w_ii = 1 and w_ij = exp(-(d_beh(i,j)-d_i^min)/tau_i) with tau_i the mean centred gap, both derived from measured quantities; (4) lift every text embedding to the hyperboloid with fixed c = 1 and run 8 damped Karcher iterations on the weighted squared geodesics to obtain m_i; (5) in Stage-2 the decoder output h_i is lifted by exp_0 and the reconstruction term becomes arcosh(-c<exp_0(h_i), m_i>_L)^2/c, with commitment loss, codebook k-means, 3000 epochs and the Stage-3 protocol untouched. Targets are static, so the frozen budget is not exceeded.
COST: One precompute before epoch 1: about 24,556 items x 11 points x 8 iterations x 768 dims, roughly 1e9 flops, seconds on one GPU or 1-2 minutes single-threaded CPU; it stores one 24556x768 fp32 target tensor (75 MB) plus 24556x10 int32 index and weight tensors (2 MB). Per-step cost at the frozen scale (24 steps/epoch x 3000 epochs = 72,000 steps): one extra inner product and one arcosh per batch element, O(B*D), below 0.5% of a step, so total wall clock stays within about +1% of the baseline.
HYPOTHESIS: If the target is the behaviour barycentre, the encoder must place behaviour-adjacent items at geodesically close latents, so the probe must move in the same computation: Spearman(code-space distance, d_beh) above the measured baseline 0.0402 and top-10 behaviour-neighbour overlap above the measured baseline 0.0124, with Stage-3 test_recall@10 above 0.065. Observation is the pre-Stage-3 probe on the single trained candidate plus the single Stage-3 run; a single run carries roughly 0.013 of recall noise, so support requires a probe gain clearly beyond seed-level wobble together with recall at or above 0.065.
RISKS: Over-smoothing: if the neighbourhood dominates the target, distinct items share codes, which can raise overlap while destroying item-level discriminability and Stage-3 recall. The arcosh loss is stiff near the origin and can destabilise 3000 epochs if the tangent clip is loose. Popularity-adjusted d_beh can concentrate weight on hubs, so a few high-degree items pull many targets. Precomputed targets freeze the behaviour structure, so the objective cannot refine neighbourhoods as the encoder improves.
BEHAVIOR SIGNAL: Popularity-adjusted symmetrised directed transition distance d_beh(i,j), the resulting transition neighbourhood N_i, and per-item training popularity pop_i.
BEHAVIOR COMPUTATION: From the training split only: for every user's training-split item sequence, count each consecutive ordered pair u_t -> u_{t+1}; n_ij = n_{i->j} + n_{j->i}; pop_i = number of training-split interactions of item i; d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)); N_i = 10 argmin over j != i with n_ij >= 1. Items with no counted transition get N_i empty and use the self-only target.
LEAKAGE BOUNDARY: Only training-split sequences, training-split item popularity and frozen item text metadata enter the precompute. No validation or test interaction is read, no per-user validation prefix is used, no Stage-3 feedback is fed back. The target tensor is frozen before epoch 1 and never refreshed from any evaluation split, so SID construction is a function of the training split alone; a load-time assertion checks that no validation or test item id appears in any neighbour list.
HYPERBOLIC OPERATOR: Fixed negative curvature c = 1 in the Lorentz model L^D_1 = {x : <x,x>_L = -1, x_0 > 0} with <x,y>_L = -x_0*y_0 + x.y; operators are the exponential and logarithm maps at the origin and at the running barycentre, the Karcher objective sum_j w_ij*d_L(x,x_j)^2, and the geodesic distance d_L(x,y) = arcosh(-c<x,y>_L)/sqrt(c) used as the training loss.
HYPERBOLIC LOCATION: Two linked places, one computation: the precompute that defines the Stage-2 target (weighted Karcher barycentre) and the Stage-2 objective itself (the reconstruction loss is a geodesic distance between the decoded hyperboloid point and that barycentre). The quantizer remains in the tangent space at the origin, so the SID structure (three levels, same codebook sizes, same straight-through path) is unchanged.
COUPLING PATH: training transitions -> d_beh -> weights w_ij -> a single argmin sum_j w_ij*d_L(x,x_j)^2 -> target m_i -> geodesic reconstruction loss -> gradient into the encoder and the RQ codebooks -> SIDs -> Stage 3. Removing the behaviour term leaves one point in the argmin and the target becomes the item's own lift; removing the curvature leaves a Euclidean weighted mean and an MSE. Either deletion changes the same tensor that Stage-2 differentiates, so neither is decorative.
COUPLING EQUATION: m_i = argmin_{x in L^D_c} sum_{j in N_i union {i}} w_ij^beh * d_L(x, x_j)^2 ; L_rec = (1/c) * arccosh( -c * < exp_0^c(h_i), m_i >_L )^2
OBSERVABLES: Pre-Stage-3 probe before the mechanism (plain Euclidean RQ-VAE, same probe, d_beh over training transitions only): Spearman(code-space distance, d_beh) = 0.0402 and top-10 behaviour-neighbour overlap = 0.0124. After the single coupled run the same two numbers must both rise; secondary observables are the mean geodesic reconstruction error to the barycentre, the fraction of each item's 10 nearest codes that are behaviour neighbours, and the training-split transition probability of SID prefixes shared by two items (prefix behaviour predictability). Final judgement is Stage-3 test_recall@10 against the 0.065 target, with the caveat that one run carries about 0.013 of noise.
ABLATION BEHAVIOR OFF: use_behaviour=False: N_i becomes empty and w_ii = 1, so m_i = x_i and the run is a plain hyperbolic RQ-VAE learning its own lifted text embedding. The Karcher code path and the geodesic loss still execute unchanged; only the behaviour term is deleted. This arm exists and is correct in the code but is not trained in this round.
ABLATION GEOMETRY OFF: use_hyperbolic=False: x_j is replaced by the raw text embedding e_j, so m_i = (sum_j w_ij*e_j)/(sum_j w_ij) with identical behaviour weights, and the loss becomes ||h_i - m_i||^2. The behaviour signal is untouched; only curvature is removed. This arm exists and is correct in the code but is not trained in this round.
ABLATION BOTH ON: use_behaviour=True and use_hyperbolic=True, i.e. the single candidate this round trains once on the frozen 3000-epoch Stage-2 budget and the frozen 150-epoch Stage-3 protocol, with no early stopping, no sweep and no seed repetition.
SPEC EQUATIONS: c = 1; <x,y>_L = -x_0*y_0 + x.y; exp_0(v) = (cosh(||v||), sinh(||v||)*v/||v||); log_0(x) = arccosh(x_0)*x_{1:}/||x_{1:}||; Pi(z) = z/sqrt(-<z,z>_L) projects an ambient vector with <z,z>_L < 0 onto L.
d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)); N_i = top10_{j != i, n_ij >= 1} ascending d_beh(i,j).
d_i^min = min_{j in N_i} d_beh(i,j); tau_i = max( mean_{j in N_i}( d_beh(i,j) - d_i^min ), 1e-6 ); w_ij = exp( -(d_beh(i,j) - d_i^min)/tau_i ); w_ii = 1; W_i = w_ii + sum_{j in N_i} w_ij.
alpha is fixed once from measured scales so that mean_i ||log_0(m_i)|| = mean_i ||e_i||, which keeps the reconstruction-loss magnitude at its baseline scale so the frozen commitment weight needs no change; v_i = alpha*e_i; x_i = exp_0(v_i).
m^(0) = Pi( sum_j w_ij*x_j / W_i ); for t = 1..8: u = ( sum_j w_ij * log_{m^(t-1)}(x_j) ) / W_i; if ||u|| < 1e-6 break; m^(t) = exp_{m^(t-1)}( u * min(1, (0.25*Rmax)/||u||) ); store m_i = m^(t) and t_i = log_0(m_i).
Stage-2: h_i = decoder(quantized_i); L_rec = (1/c) * arccosh( clamp( -c*<exp_0(h_i), m_i>_L, 1+1e-6, 1e6 ) )^2; total loss = L_rec + existing commitment loss with all existing weights and schedules unchanged; 3000 epochs, 24 steps per epoch, no early stopping.
SPEC INPUTS OUTPUTS: Inputs are the frozen 768-d item text embeddings for 24556 training items, the training-split transition counts and the training-split popularity. Outputs are the per-item Lorentz barycentre m_i and tangent target t_i as a 24556x769 fp32 tensor plus neighbour index and weight tensors, and a modified Stage-2 reconstruction loss. The downstream artefact is still one RQ-VAE SID triple per item, structurally identical to the baseline.
SAFEGUARDS: Clamp the arccosh argument from below to 1+1e-6 and evaluate (-c<.,.>_L - 1) in float64, since arccosh(z) ~ sqrt(2(z-1)) near 1 and float32 cancellation otherwise destroys the gradient. Clip the decoded tangent norm to the radius bound arctanh(0.9) before exp_0 so no point touches the ball boundary. Clamp each Karcher step to 0.25 of that radius bound and stop at ||u|| < 1e-6, with at most 8 iterations so worst-case precompute cost is bounded. If tau_i <= 1e-6 set all w_ij = 1 instead of dividing by zero. Require <z,z>_L < 0 before projecting and otherwise fall back to x_i. Items with empty N_i use w_ii = 1. Assert at load that no validation or test item id occurs in any neighbour list, and log the probe numbers exactly as the tools-side probe computes them.
END IDEA
