IDEA: GDELTA-SUCC-PULL-RQ
TITLE: Behaviour-local Gromov-delta curvature steering a successor-residual pull inside the RQ-VAE code assignment
MOTIVATION: Text-only RQ-VAE SIDs cluster by surface semantics, so items that users actually transition between receive unrelated code prefixes (probe Spearman 0.0402, top-10 behaviour-neighbour overlap 0.0124). The recommender therefore has to learn transition structure from SID tokens that were never organised for it. Previous fixes changed the codebook update, a per-level scalar, a radius or a post-hoc score; none changed which code wins at quantization time. This idea changes the assignment decision itself, using the training transition graph and a curved metric, so behaviourally related items are forced into nearby codes during Stage-2.
NOVELTY: (1) the curvature of the quantization metric is an ITEM-level quantity derived from the local Gromov delta of the training transition metric, not a global constant, a per-level value, or an entropy-derived radius; (2) the behaviour signal enters the per-level argmin as a second geodesic term pointing at the curvature-matched centroid of the item's successors' stored residuals, not as a codebook update, a relabelling, or a suffix on an unchanged quantizer; (3) the two distance terms are unit-scaled by detached batch medians, so the coupling weight is derived (=1) and no sweep is needed. No successor-weighted Frechet update, no prefix cone, no successor-profile smoothing, no radial re-ranking, no metric swap on frozen code vectors.
CHANGE: Each residual level assigns the code minimising a two-term curved score d_{K_i}(x_i^l, e_{l,k})/s1 + d_{K_i}(e_{l,k}, g_i^l)/s2 instead of the plain nearest-code distance, where g_i^l is the w_ij-weighted mean of the stored residuals of i's top training successors and K_i is the item curvature from the local Gromov delta of the training transition metric. The chosen indices are the SIDs; the residual recursion, reconstruction and commitment losses are unchanged.
SPECIFICATION: Precompute once, before Stage-2, from training-split sessions only: n_ij = directed transition counts, pop_i = sum_j n_ij + sum_j n_ji, d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)); N_i = 4 successors with n_ij>0 and smallest d_beh; w_ij = softmax_j(-d_beh(i,j)) over N_i. Symmetrise l_ij = (d_beh(i,j)+d_beh(j,i))/2; S_i = {i} union N_i union 4 predecessors with largest n_ji (|S_i| <= 9). On the induced subgraph of S_i take shortest-path closure of l (a genuine metric); if disconnected set delta_i = delta_ref. delta_i = max over quadruples (a,b,c,p) in S_i of (largest - second largest)/2 of the three sums d(a,b)+d(c,p), d(a,c)+d(b,p), d(a,p)+d(b,c). delta_ref = median_i delta_i; K_i = clip(delta_ref/(delta_ref+delta_i), 0.1, 2); c0 = 1 is the documented unit-curvature default. During Stage-2, for batch B and level l = 1..L: u_i^1 = Enc(text_i); x_i^l = exp_0(u_i^l) (reference curvature 1), clamp ||x|| <= 0.7; g_i^l = sum_{j in N_i} w_ij * bank[j][l] (stop-grad); s1 = median_i min_k d_{K_i}(x_i^l,e_{l,k}), s2 = median_i min_k d_{K_i}(e_{l,k},g_i^l), both detached and floored at 1e-6; k_i^l = argmin_k [d_{K_i}(x_i^l,e_{l,k})/s1 + d_{K_i}(e_{l,k},g_i^l)/s2]; e_{l,k} = exp_0(v_{l,k}); u_i^{l+1} = log_0(x_i^l) - v_{l,k_i^l}; bank[i][l] <- detach(x_i^l); L = ||Dec(sum_l v_{l,k_i^l}) - text_i||^2 + beta * sum_l ||sg(log_0(x_i^l)) - v_{l,k_i^l}||^2, exactly the baseline losses.
COST: 3000 epochs x 24 steps = 72000 steps. Per step the extra work is the second distance term B*K*L = 1023*256*3 ~ 786k Poincare distances (~8 MFLOP) plus two detached medians, roughly 1-3% of a baseline step (encoder/decoder over ~1023 items dominates); no extra backward graph beyond the existing straight-through path. One-off precompute is 24556 items x C(9,4)=126 quadruples (~3.1M small operations, seconds to a minute vectorised) plus one forward pass over 24556 items to fill the residual banks, ~1 epoch-equivalent = 0.03% of the 72000-step budget. Bank memory 24556*3*64*4 B ~ 18.9 MB.
HYPOTHESIS: If transition structure is the missing organising signal, the assignment-level pull must raise the probe above the Euclidean gate, expected Spearman >= 0.10 and top-10 behaviour-neighbour overlap >= 0.04 versus 0.0402 / 0.0124, because successors' residuals share codes at every level and therefore share prefixes. Stage-3 test_recall@10 should then exceed 0.065; it is reported as a single run with the explicit ~0.013 noise caveat. If the probe moves but Stage-3 does not, the generative decoder cannot exploit behaviour-organised prefixes, which is itself the informative result.
RISKS: The successor pull can concentrate level-1 codes and starve the codebook (monitor per-level usage entropy; the equally unit-scaled text term is the only counterweight). Local delta estimates are noisy for low-degree or disconnected items (fallback delta_ref). Per-item curvature makes the distance a family of Poincare metrics rather than one global manifold. Behaviour smoothing may overwrite fine text distinctions needed for cold or long-tail items, and Stage-3 may lose the SID diversity beam search needs. One run cannot separate these effects from seed noise.
BEHAVIOR SIGNAL: Directed training-split item transitions (i followed by j in a training session), with popularity adjustment.
BEHAVIOR COMPUTATION: Count n_ij and pop_i over the Stage-2 training split only; d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)); N_i = top-4 successors by smallest d_beh; w_ij = softmax(-d_beh) over N_i; local Gromov delta delta_i from the symmetrised, shortest-path-closed transition metric on S_i; delta_ref = median delta_i. All computed once before Stage-2 training, never recomputed from validation or test interactions.
LEAKAGE BOUNDARY: The transition counts, neighbour lists, local metric and curvature are built exclusively from the Stage-2 training split before the run starts; validation and test sessions are never read by the SID builder, the banks are filled only from training items, and Stage-3 consumes the frozen SIDs with no interaction feature at inference. No per-epoch statistics from held-out data enter the SID construction.
HYPERBOLIC OPERATOR: Poincare ball distance with item-conditioned negative curvature K_i, in closed arcosh form d_K(u,v) = (1/sqrt(K)) * arcosh(1 + 2K||u-v||^2 / ((1-K||u||^2)(1-K||v||^2))), with K_i in [0.1,2] and all points clamped to norm <= 0.7.
HYPERBOLIC LOCATION: Inside the residual quantizer's per-level assignment decision (the argmin that emits each SID digit) and in the behaviour term of that same score, during Stage-2 training only; it does not act on the codebook update rule, the decoder, or Stage-3.
COUPLING PATH: Training transitions -> n_ij, pop_i -> d_beh -> (w_ij, N_i, delta_i) -> (g_i^l, K_i) -> curved assignment score at every RQ level -> chosen code indices -> SID tuple -> frozen Stage-3 vocabulary. Removing the behaviour term zeroes g_i and fixes K_i = c0, so the argmin reverts to plain nearest code; removing the curved operator replaces d_K by Euclidean in both terms.
COUPLING EQUATION: score_l(i,k) = d_{K_i}(x_i^l, e_{l,k})/s1 + d_{K_i}(e_{l,k}, g_i^l)/s2, where g_i^l = sum_{j in N_i} w_ij * bank[j][l] (behaviour term, w_ij = softmax_j(-d_beh(i,j))), K_i = clip(delta_ref/(delta_ref+delta_i), 0.1, 2) (behaviour-derived curvature), d_K is the Poincare distance (curved term), s1 and s2 are detached batch medians.
OBSERVABLES: Probe after Stage-2 exactly as in the tools-side probe (Spearman between code-space distance and d_beh, top-10 behaviour-neighbour overlap) with before numbers 0.0402 / 0.0124 and after numbers recorded; per-level code usage entropy and the K_i distribution (collapse check); prefix behaviour predictability as conditional entropy H(k_l | k_<l) over training items and held-out teacher-forced prefix accuracy; Stage-3 test_recall@10 with the single-run ~0.013 caveat.
ABLATION BEHAVIOR OFF: BEHAVIOUR_OFF flag in the same code: second term weight 0, so k_i^l = argmin_k d_{K_i}(x_i^l, e_{l,k}) with K_i = c0 = 1 fixed (hyperbolic quantizer, text only, no transitions). Not trained this round; switch implemented and unit-checked.
ABLATION GEOMETRY OFF: GEOMETRY_OFF flag: replace every d_{K_i} by Euclidean distance in both terms (delta_i and K_i still computed and logged, not used), so score = ||x_i^l - e_{l,k}||/s1 + ||e_{l,k} - g_i^l||/s2. Not trained this round; switch implemented and unit-checked.
ABLATION BOTH ON: The single trained candidate: behaviour pull with w_ij, N_i and K_i from the training transition metric, and curved Poincare distances in both terms, all inside the per-level argmin. This is the only arm executed, 3000 Stage-2 epochs on four cards plus the frozen 150-epoch Stage-3 protocol.
SPEC EQUATIONS: d_K(u,v) = (1/sqrt(K)) * arcosh(1 + 2*K*||u-v||^2 / ((1-K*||u||^2)*(1-K*||v||^2))). d_beh(i,j) = -log((n_ij+1)/(sqrt(pop_i*pop_j)+1)); l_ij = (d_beh(i,j)+d_beh(j,i))/2; D = shortest_path(l) on S_i. delta_i = max_{a,b,c,p in S_i} 0.5*(max(S1,S2,S3) - mid(S1,S2,S3)), S1 = D(a,b)+D(c,p), S2 = D(a,c)+D(b,p), S3 = D(a,p)+D(b,c). delta_ref = median_i delta_i; K_i = clip(delta_ref/(delta_ref+delta_i), 0.1, 2). w_ij = exp(-d_beh(i,j)) / sum_{j' in N_i} exp(-d_beh(i,j')); g_i^l = sum_j w_ij * bank[j][l]. score_l(i,k) = d_{K_i}(x_i^l,e_{l,k})/s1 + d_{K_i}(e_{l,k},g_i^l)/s2; k_i^l = argmin_k score_l(i,k). e_{l,k} = exp_0(v_{l,k}) = tanh(||v_{l,k}||/2) * v_{l,k}/||v_{l,k}|| (reference curvature 1); log_0(x) = 2*artanh(||x||) * x/||x||. u_i^1 = Enc(text_i); x_i^l = clamp(exp_0(u_i^l), 0.7); u_i^{l+1} = log_0(x_i^l) - v_{l,k_i^l}. L = ||Dec(sum_l v_{l,k_i^l}) - text_i||^2 + beta * sum_l ||sg(log_0(x_i^l)) - v_{l,k_i^l}||^2, beta the baseline value unchanged. Straight-through: hard index, the gradient to the encoder passes through the identity path as in the baseline.
SPEC INPUTS OUTPUTS: Inputs: item text embeddings (24556 x d), training-split transition counts, baseline codebook size K and levels L, baseline encoder/decoder. Outputs: a K^L SID vocabulary, one SID tuple per item, the per-item K_i array, per-level code usage counts, the two probe numbers, and the Stage-3 recall. Internal operator: given residuals x_i^l (ball coordinates), code points e_{l,k}, bank rows and (w_ij, K_i, s1, s2), it returns the hard code indices for all levels and the refreshed residual bank.
SAFEGUARDS: Clamp every ball coordinate to norm 0.7 = 0.999/sqrt(K_max) with K_max = 2 so 1-K||u||^2 >= 1e-3; clamp the arcosh argument to >= 1+1e-7 with a stable arcosh; clamp K_i to [0.1,2]; floor s1, s2 and delta_ref at 1e-6; detach s1, s2, w_ij, delta_i, K_i and the bank so the behaviour target never back-propagates through the precompute; empty N_i or disconnected S_i gives g_i^l = x_i^l (stop-grad) and delta_i = delta_ref; replace non-finite distances by the batch maximum finite distance before the argmin; keep the baseline codebook-usage reset and beta unchanged; assert that no validation or test item id appears in the startup transition table.
END IDEA
