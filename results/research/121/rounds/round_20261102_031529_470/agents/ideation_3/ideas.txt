IDEA: CURVALLOC-LORENTZ-RQ
TITLE: Mean-zero allocation of per-level Lorentz curvature and code radius from the null-standardised Ollivier curvature of the training behaviour quotient graph
MOTIVATION: The measured evidence says the recall-relevant geometric object is the level-wise profile of the behaviour quotient graph's standardised Ollivier curvature (L3 +0.26, L1 -0.16, L1-L3 -0.20, p=0.0095), and that the largest non-geometric driver is how many level-3 codes actually get used (+0.42, collisions -0.39). Existing SIDs differ only in whether their prefix geometry happens to fit the level-wise clustering of the behaviour graph. No quantizer currently builds that fit: the partition comes from one Euclidean nearest-code rule with a single curvature shared by all three levels.
NOVELTY: Not a per-level learning rate from a hard prefix-transition score (CURVCTRL-SID), not entropy-ranked radial assignment (BRad-RQ), not Frechet codebook updates, and not a fixed mixed-curvature product chosen by hand. The signal is a runtime-measured, permutation-null-standardised Ollivier curvature of the behaviour quotient graph induced by the CURRENT prefix assignment, spent as a mean-zero allocation of two geometric quantities (per-level negative curvature c_l and per-level radial budget rho_l) that enter the distance the quantizer itself minimises. No extra loss term is added, no recall label is used, and the assignment feeds back into the measurement, so behaviour and geometry form a closed loop rather than two parallel objectives.
CHANGE: Each RQ level l lives on its own Lorentz hyperboloid of curvature -c_l with code radius rho_l, both set from that level's standardised behaviour-quotient curvature, c_l = c0*exp(-delta_l) and rho_l = rho0*exp(delta_l/2) with delta_l = kappa_hat_l - mean_l(kappa_hat_l). Nearest-code assignment, residual subtraction and codebook parameterisation all pass through the exp/log maps of that level's hyperboloid, so changing delta_l changes which code each item receives.
SPECIFICATION: (1) Build W once from the training split: W_ij = number of training sessions in which j occurs after i within the same window H used by the sequential Stage-2 encoder, symmetrised W <- (W+W^T)/2; N_tr = 24556. (2) Every T = 200 epochs (15 refreshes over 3000 epochs) take the current hard prefixes p_l(i) = (k_1..k_l) and form the quotient graph Q_l: nodes = occupied level-l prefixes, A_l(a,b) = sum_{i in a, j in b} W_ij (sparse S_l^T W S_l, self-loops kept); d_Q = unweighted hop distance. (3) Lazy walk P = 0.5(I + D^{-1}A) with D = diag(A1); curvature kappa(a,b) = 1 - W1(m_a, m_b)/d_Q(a,b) with m_a = 0.5*delta_a + 0.5*A_a./deg(a). (4) Standardise against a member-shuffling null: R = 8 relabellings of items into prefixes with group sizes preserved, kappa_hat_l = (kappa_bar_l - mu_null,l)/sigma_null,l, the same edge sample size used in both. (5) Form delta_l with the mean-zero constraint, clip to [-1,+1], EMA with 0.5. (6) All distances, residuals and codebooks use the level's own hyperboloid. STOP-GRADIENT on kappa_hat: it is a schedule, not a loss.
COST: Per step the extra work is three Lorentz distance tensors of shape B x K x (D+1) plus three exp/log maps of shape B x D per item and per code: about 1.2e6 extra flops at B=256, K=256, D=64, under 2% of a step, with no backward pass through the measurement. The 15 curvature refreshes cost one sparse S_l^T W S_l per level (3 x nnz(W) ~ 3e6 adds), 8 null relabellings, and 3 levels x 256 sampled edges x 30 Sinkhorn iterations on supports of at most 9+9 cells (~1.5e7 flops per refresh, a few seconds each), so roughly 30-60 s of the whole 72000-step run: under 1% wall clock and no extra memory beyond one 24556 x 3 assignment cache.
HYPOTHESIS: If level-wise clustering of the training behaviour graph is a real constraint on a good prefix code, then letting the more clustered sub-quotient (typically level 3) own a flatter, wider hyperboloid while the more branching level (typically level 1) owns a sharper, tighter one must (a) keep level-3 code usage at or above baseline, (b) not collapse level-1 usage, (c) make the run's measured standardised profile monotone in depth, and (d) push Stage3 test Recall@10 above 0.065. Observed from the run's own logs: per-level used-code counts, the 15 recorded kappa_hat triples, and test_recall@10 against 0.065; if the profile is not monotone or level-1 usage falls below about 8 codes the hypothesis is falsified.
RISKS: The sign of the curvature-to-geometry map may be wrong for this data (flatter may need to follow LOW curvature), and one run cannot correct it; the +-1 clip keeps the worst case a bounded factor-e perturbation of one level instead of a collapse. The assignment<->curvature loop can oscillate, damped by the T=200 cadence, EMA 0.5 and the mean-zero constraint. Sinkhorn W1 on sparse quotient graphs is noisy and biased upward; the identical estimator is applied to the null so standardisation cancels the bias but amplifies variance when sigma_null is small, hence the sigma floor. The tangent-space residual chain is less faithful than the Euclidean one and can degrade reconstruction; the measured radial normalisation makes the tanh squash near-identity for typical items.
BEHAVIOR SIGNAL: Sequential co-consumption / directed item transitions of the training split, aggregated to prefix-group level as a weighted quotient graph, plus the current model's training-item prefix assignment.
BEHAVIOR COMPUTATION: From the training split only: for every consecutive pair (i -> j) in a training session inside window H, increment W_ij; symmetrise. At each refresh multiply W by the current item->prefix indicator per level to get A_l, then build the lazy random walk and the per-edge Ollivier curvature with a Sinkhorn-W1 over each sampled edge's neighbour support. No validation or test interaction, user or item is read.
LEAKAGE BOUNDARY: W, the quotient graphs, the null draws and sigma are computed exclusively from training-split sessions of the frozen Stage-2 split; validation and test interactions are never read while the SID is constructed, and the mechanism has no validation-based selection, no early stopping and no test-time statistic. The 0.065 target and the forensic correlations fix the mechanism's direction before the run only; no recall label of any model enters kappa_hat.
HYPERBOLIC OPERATOR: Measured (not tuned) negative curvature per level, c_l = c0*exp(-delta_l) with c0 = 1, realised in the Lorentz hyperboloid model of curvature -c_l: d_{L,c}(x,y) = (1/sqrt(c))*arcosh(-c*<x,y>_L), exp_o^c(v) = (cosh(sqrt(c)||v||)/sqrt(c), sinh(sqrt(c)||v||)/(sqrt(c)||v||)*v), log_o^c its inverse, Euclidean branch as the c->0 limit.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer: codebook parameterisation (each code is exp_o^{c_l} of a radius-squashed free tangent vector), encoder-side residual mapping exp_o^{c_l}, the nearest-code rule argmin d_{L,c_l}, and residual subtraction in the tangent space log_o^{c_l}. It therefore acts on the assignment and on every gradient reaching encoder and codebooks.
COUPLING PATH: training behaviour graph W -> quotient graph Q_l of the current prefixes -> standardised curvature kappa_hat_l -> delta_l -> (c_l, rho_l) -> Lorentz distance d_{L,c_l}(exp_o^{c_l}(squash(r_{l,i})), e_{l,k}) -> argmin / straight-through -> new prefixes -> next refresh of Q_l. Behaviour off collapses kappa_hat to 0 and forces every level to unit curvature and the median radius; geometry off (c_l -> 0 with rho_l kept) leaves a Euclidean quantizer with the same behaviour-set radius. Both change the argmin, hence the SID.
COUPLING EQUATION: p_l(k|i) = softmax_k( -d_{L,c_l}( exp_o^{c_l}( rho_l*tanh(||r_{l,i}||/rho_l)*rhat_{l,i} ), exp_o^{c_l}( rho_l*tanh(||w_{l,k}||/rho_l)*what_{l,k} ) ) ), with c_l = c0*exp(-delta_l), rho_l = rho0*exp(delta_l/2), delta_l = clip(kappa_hat_l - mean_m kappa_hat_m, -1, +1), kappa_hat_l = (kappa_bar_l(A_l(W_train, p_l)) - mu_null,l)/sigma_null,l, and rho0 = median_i ||z_i - mean(z)|| measured on training items at epoch 0.
OBSERVABLES: per-level used-code counts over training (level 3 expected at or above baseline, level 1 expected not to collapse); the 15 logged kappa_hat triples and their depth profile; the final SID table's collision rate; the recorded behaviour-prefix transfer predictability (diagnostic only, never a gate); final Stage3 test_recall@10 against 0.065.
ABLATION BEHAVIOR OFF: delta_l = 0 for all levels, i.e. W is not read, c_l = c0 and rho_l = rho0; everything else identical (still Lorentzian, unit curvature, median radius).
ABLATION GEOMETRY OFF: c_l replaced by the flat limit c -> 0 (Euclidean squared distance, no arcosh, no exp/log) while delta_l and rho_l keep their behaviour-driven values, i.e. a Euclidean quantizer with behaviour-set radius.
ABLATION BOTH ON: the full loop above, kappa_hat measured from the training quotient graph and spent on both c_l and rho_l. Only this arm is trained this round; the other two exist behind switches, are correct, and are not run.
SPEC EQUATIONS:
  # once, from the training split only
  W = sym(cooccurrence(train_sessions, window=H)); N = 24556
  rho0 = median_i ||z_i - mean(z)||          # measured at epoch 0
  c0 = 1.0; delta = zeros(3)
  for epoch in 1..3000:
      for step in 1..24:
          for l in 1..3:
              c_l = c0*exp(-delta[l]); rho_l = rho0*exp(delta[l]/2)
              x   = exp_o(c_l, rho_l*tanh(||r_l||/rho_l)*rhat_l)          # item side
              E   = exp_o(c_l, rho_l*tanh(||w_l||/rho_l)*what_l)          # codes, free tangents w_l
              logits = -d_L(c_l, x[:,None,:], E[None,:,:])
              k_l = argmin(logits, -1)                                    # straight-through
              u_l = log_o(c_l, E[k_l])                                    # tangent code
              r_{l+1} = r_l - u_l
          z_hat = LayerNorm(sum_l u_l); loss = recon + commit + baseline usage term
          adam_step(encoder, {w_l})                                       # c_l, rho_l stop-grad
      if epoch % 200 == 0:
          for l in 1..3:
              A_l = S_l(p_l)^T @ W @ S_l(p_l)                              # quotient graph
              d_Q = hopdist(A_l); P = 0.5*(I + D^{-1}A_l)
              kappa_bar_l = mean over 256 weight-sampled edges of (1 - sinkhornW1(m_a,m_b,d_Q)/d_Q(a,b))
              for r in 1..8:
                  p_l^null = shuffle_members(p_l)                          # group sizes preserved
                  recompute kappa_bar_l^null identically
              mu, sigma = mean/std(kappa_bar_l^null)
              kappa_hat_l = (kappa_bar_l - mu)/max(sigma, 1e-6)
          delta = 0.5*delta + 0.5*clip(kappa_hat - mean(kappa_hat), -1, +1)
SPEC INPUTS OUTPUTS: Inputs: training-split co-occurrence W, item representations z_i and residuals r_{l,i}, current hard prefixes, free codebook tangents w_{l,k}, measured rho0. Outputs: per-level (c_l, rho_l) refreshed every 200 epochs, per-item codes k_1..k_3 (the SID), the tangent code vectors u_l for the decoder, and the reconstruction consumed by the standard RQ-VAE loss.
SAFEGUARDS: arcosh argument clamped to >= 1+1e-7, evaluated in float32 after subtracting the time component, with the c <= 1e-4 branch replaced by the Euclidean formula; every code and residual squashed by rho_l*tanh(.) so sqrt(c_l)||v|| <= sqrt(c_l)*rho_l stays O(1) and exp_o cannot overflow; delta clipped to +-1 (one standardised sigma maps to a factor e) and EMA-smoothed 0.5 so a noisy null cannot jump the geometry; kappa_hat set to 0 whenever a level has fewer than 8 occupied prefixes or sigma_null < 1e-6, which falls back to unit curvature (also the behaviour-off arm); mean-zero constraint on delta so the total curvature budget is conserved and code usage cannot be globally inflated or deflated; rho0 measured from training items so the squash is near-identity for typical residuals; the standard usage/entropy term and the codebook size are untouched, so nothing forces prefix merging and the Issue #127 coarse-partition collapse cannot be reproduced by construction.
END IDEA
