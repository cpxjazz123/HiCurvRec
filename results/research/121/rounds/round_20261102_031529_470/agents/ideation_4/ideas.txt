IDEA: ORC-CELLCHART
TITLE: Behaviour-curvature cell charts: per-code standardised Ollivier curvature sets each RQ codeword's own Poincare chart curvature used in assignment
MOTIVATION: The SID's prefix geometry is fixed and Euclidean for every codeword, so a codeword sitting on a tree-like (branching) behavioural neighbourhood and one sitting inside a cohesive cluster are forced to discriminate residuals identically. The forensics show the standardised level profile, not the raw curvature, is what tracks recall, and that level-3 code usage and collisions dominate. What is missing is a mechanism that gives each codeword a geometry matched to its own behavioural quotient neighbourhood, at the level's own resolution, without ever coarsening the partition.
NOVELTY: Earlier rounds set a per-LEVEL curvature from a scalar (hard prefix-transition score) or a per-code radius from context entropy. This sets a per-CODE curvature MAGNITUDE from the standardised Ollivier-Ricci curvature of that code's node in the level's behaviour quotient, expressed as a deviation from a resolution-matched behaviour reference partition (exactly K_l cells), and makes that number the curvature of that code's Poincare chart inside the nearest-code rule. The curvature is not a loss, a schedule or a radius: it is the metric in which the residual-to-codeword distance is measured, per code, per level.
CHANGE: The RQ-VAE distance at level l becomes d_{k_{l,c}}(z,e_c) with a per-code curvature magnitude k_{l,c} obtained from the code's standardised quotient curvature; the field is refreshed every 5 epochs from training transitions and enters the assignment logits directly, so both the partition and the codebook gradients move.
SPECIFICATION: (1) Build W (24556x24556, symmetrised directed transition counts) from training sequences only. (2) One-off: truncated SVD rank 128 of the row-normalised W gives behaviour coordinates b_i; k-means with exactly K_l clusters gives reference partition P*_l. (3) For any partition a, quotient Q(a) has edge weight w_ab=sum_{i in a,j in b} W_ij; lazy random walk mu_a=0.5 delta_a+0.5 sum_b (w_ab/d_a) delta_b; Ollivier curvature kappa(a,b)=1-W1(mu_a,mu_b)/d_Q(a,b) with d_Q the hop metric; node value kappa_a is the w-weighted mean over neighbours; standardise against S nulls that permute the item-to-cell map while keeping cell sizes: kappa_hat_a=(kappa_a-mean_null)/sd_null. (4) Phi_{l,c}=(kappa_hat_{l,c}-mu*_l)/sd*_l winsorised at +-3 (mu*,sd* from P*_l at the same K_l). (5) k_{l,c}=clip(k0*exp(-Phi_{l,c}), k0/4, 4*k0), k0=min_l ((1-1e-3)/q99(||z_{i,l}||))^2 measured once at init. (6) Assign p(c|i,l) ∝ exp(-d_{k_{l,c}}(z_{i,l},e_{l,c})/tau_l); rest of RQ-VAE unchanged.
COST: 72,000 optimizer steps (3000x24), batch 1023. Per-step assignment over 3x256x64 is ~50M mul-adds; the Mobius/artanh path adds ~10 elementwise passes over 0.8M values, under 1 ms/step and under 1% of a model step. Six hundred refreshes (every 5 epochs) cost one 4096-item forward (4 step-equivalents, 2400 step-equivalents total = 3.3%) plus 20 null shuffles x 3 levels x ~5k edges x 4 Sinkhorn iterations, roughly 0.1-1 s each, 1-10 min total. One-off reference SVD+k-means under 15 min. Expected +4-8% wall clock, no extra forward/backward in the 72k steps.
HYPOTHESIS: If per-cell geometry matched to the cell's own quotient curvature is what the generative prefixes need, the produced SID should use more level-3 codes and collide less at fixed K, its standardised curvature profile should move toward the resolution-matched reference profile, and Stage3 test_recall@10 should exceed 0.065 in the single run.
RISKS: Per-pair curvature is not a global metric, so cells need not be convex and a code can become over-attractive; node curvature on small cells is noisy and can flip sign between refreshes; if the reference partition is itself strongly aligned with W, Phi may saturate the +-3 clip and the field becomes binary; added curvature could interact badly with the straight-through gradient at level 1 and shrink early code usage, which is exactly the Issue #127 failure mode.
BEHAVIOR SIGNAL: Directed item transitions (sequential co-consumption) in the training split, aggregated into the level's prefix quotient graph.
BEHAVIOR COMPUTATION: From each training sequence, consecutive pairs (i_t -> i_{t+1}); W_ij counts them, W <- W+W^T. At a refresh, the 4096-item fixed sample's induced subgraph is contracted by the current hard level-l assignment a_l to give w_ab; degrees, lazy walk, W1 transport on neighbour supports, node curvature, then the 20-shuffle size-preserving null. Reference mu*_l, sd*_l come from the same estimator applied to P*_l built from W.
LEAKAGE BOUNDARY: W is built only from training-split sequences; the reference SVD/k-means, k0 (from training residual norms) and every refresh use only training items and the current model. No validation or test item, sequence, co-occurrence or metric is read at any point; the SID table is frozen before Stage 3 and Stage 3 never writes back.
HYPERBOLIC OPERATOR: Poincare ball distance with per-code curvature magnitude k_{l,c} (curvature -k_{l,c}), d_k(x,y)=(2/sqrt(k)) artanh(sqrt(k)||(-x) (+)k y||), with Mobius addition (+)k; k0 is data-derived and the field lives in [k0/4, 4k0].
HYPERBOLIC LOCATION: Inside the RQ-VAE nearest-code rule at each of the three levels, i.e., in the E-step of quantization and in the gradient that reaches the encoder and the codebook through the assignment probabilities.
COUPLING PATH: W_train -> level-l quotient Q(a_l) -> standardised node curvature kappa_hat_{l,c} -> deviation from the K_l-cell behaviour reference -> per-code chart curvature k_{l,c} -> the distance used to assign every residual at that level -> new a_l and new codebook gradients -> next refresh. Behaviour sets the curvature, the curvature is the metric, the metric sets the assignment; neither can be removed without changing the same tensor that the loss differentiates.
COUPLING EQUATION: p(c|i,l) ∝ exp( -(2/sqrt(k_{l,c})) artanh(sqrt(k_{l,c}) ||(-z_{i,l}) (+)_{k_{l,c}} e_{l,c}||) / tau_l ), with k_{l,c}=clip(k0*exp(-(kappa_hat^{ORC}_{l,c}(W_train,a_l)-mu*_l)/sd*_l), k0/4, 4k0).
OBSERVABLES: Per-level code usage histogram and dead-code count (level 3 should rise); SID triple collision rate (should fall); the produced SID's standardised curvature profile per level versus the reference profile (should move toward it, i.e., flatten where the reference is flat); conditional entropy H(prefix_{l+1}|prefix_l) on held-out training sequences (recorded, not gating); Stage3 test_recall@10.
ABLATION BEHAVIOR OFF: Same code path, flag use_behaviour_curvature=False: Phi set to 0 for every level and code, so k_{l,c}=k0 everywhere and the curved quantizer runs with a single uniform curvature. Nothing else changes.
ABLATION GEOMETRY OFF: Flag use_curvature_metric=False: the field is still computed and logged but the assignment uses the Euclidean squared distance ||z-e||^2 and the curvature never enters the logits.
ABLATION BOTH ON: Full path above, one training run, 3000 Stage 2 epochs on four cards, frozen Stage 3 protocol, no early stopping.
SPEC EQUATIONS: W_ij=#{t: i_t=i, i_{t+1}=j}; w_ab=sum_{i in a,j in b}W_ij; d_a=sum_b w_ab; mu_a=0.5 delta_a+0.5 sum_b (w_ab/d_a) delta_b; kappa(a,b)=1-W1(mu_a,mu_b)/d_Q(a,b); kappa_a=sum_b (w_ab/d_a) kappa(a,b); kappa_hat_a=(kappa_a-E_null[kappa_a])/sd_null[kappa_a]; Phi_{l,c}=clip((kappa_hat_{l,c}-mu*_l)/sd*_l,-3,3)*n_c/(n_c+nbar_l); k_{l,c}=clip(k0 exp(-Phi_{l,c}),k0/4,4k0); field<-0.9 field+0.1 target; k0=min_l((1-1e-3)/q99(||z_{i,l}||))^2. If usage_c<1/(2K_l) then k_{l,c}=k0/4 until the next refresh. Pseudocode: init W,B,P*_l,(mu*_l,sd*_l),k0, field=k0; for epoch in 1..3000: for step in 1..24: z=encoder(batch); for l: d=poincare(z_l,E_l,field_l); logits=-d/tau_l; baseline RQ loss; end; if epoch%5==0: a=argmax on the fixed 4096-item sample; for l: kappa_hat=standardise(Q(a_l),W_sample,20 shuffles); target=clip(k0 exp(-shrink((kappa_hat-mu*_l)/sd*_l)),k0/4,4k0); field_l=0.9 field_l+0.1 target; revive dead codes; end.
SPEC INPUTS OUTPUTS: Inputs: training transition counts W, current level assignments a_l, codebooks E_l, residuals z, reference statistics mu*_l/sd*_l, k0. Outputs: per-code curvature magnitudes k_{l,c} (K_l floats per level) and the assignment logits / probabilities p(c|i,l) used by the RQ-VAE.
SAFEGUARDS: clamp sqrt(k)||x|| to 1-1e-6 before artanh and clamp squared norms to (1-1e-3)^2/k; keep k in [k0/4,4k0] so no code can approach the ball boundary; winsorise Phi at +-3; shrink Phi by n_c/(n_c+nbar_l) so small cells cannot dominate; EMA 0.9 on the field and refresh only every 5 epochs to damp the assignment-curvature loop; dead-code revival at k0/4 guarantees at least half the codebook is reachable, so the Issue #127 collapse to a handful of level-1 codes is structurally blocked and K_l is never reduced; if a refresh finds the assignment entropy below ln(K_l/2) the field update is skipped for that level; all curvature arithmetic in float64 on the graph side.
END IDEA
