IDEA: CURVQUOTA-SWAP-SID
TITLE: Curvature-biased, quota-exact 2-swap code assignment for a Poincare-ball RQ-VAE
MOTIVATION: The baseline TIGER RQ-VAE gives every training item the code triple nearest to it in an isotropic Euclidean residual space, so a SID carries no information about where the item sits in the training transition graph, and two items users actually consume in sequence frequently get different prefixes. Round 1 spent the measured behaviour-graph curvature on the space's radius and destroyed the codebook (170 -> 56 distinct triples, Stage3 recall 0.041888). Round 2 put behaviour in as a multiplicative per-pair weight: margins moved, not one argmin did. What is missing is a behaviour term that provably changes which code an item receives, plus a resolution guarantee that survives any curved metric, however aggressive.
NOVELTY: The assignment is constrained to be a PERMUTATION of the Euclidean nearest-neighbour assignment of the same batch shard: a sequence of transpositions. The per-level usage multiset is therefore invariant by construction (every code keeps exactly the count the baseline quantizer gave it, so collision rate and exposure are unchanged), while WHICH item holds which code is re-decided by an additive curved-plus-curvature cost. No Sinkhorn plan, no marginal argmax, no rescaling of distances, no radius, temperature or usage-weight parameter, no codebook renormalisation. The behaviour-graph curvature is spent as an additive per-pair cost term and never as a scale.
CHANGE: (1) Encoder outputs and code vectors are mapped into the unit Poincare ball, the quantization distance becomes d_P at fixed curvature c=1, and the codebook EMA is carried in the tangent space at the origin. (2) Inside each level and each rank-local batch shard, the code of item i is chosen by a cost that adds a curvature-weighted successor-mass bias to the normalised curved distance, and that cost is minimised by exact 2-swaps starting from the Euclidean nearest assignment, so the multiset can never move.
SPECIFICATION: Offline, once, on CPU before Stage 2 (no collectives, one artifact memory-mapped by all ranks):
  1. w_ij = directed transition counts over TRAIN-split sequences only, i,j in the 24556 training items.
  2. pi_l(i) = level-l prefix of training item i under the FROZEN baseline RQ-VAE (train items only).
  3. Quotient graph per level: W_l(a,b) = sum over i with pi_l(i)=a and j with pi_l(j)=b of w_ij.
  4. Per edge (a,b) with W_l>0, Ollivier curvature with the alpha=0.5 lazy random walk:
     kappa_l(a,b) = 1 - W1(a,b)/d(a,b), W1 = sum_{u,v} mu_a(u) mu_b(v) d(u,v),
     mu_a(u) = alpha*1[u=a] + (1-alpha)*W_l(a,u)/deg_l(a), d = unweighted shortest path on the quotient.
  5. Null: S=32 size-preserving member shuffles; each shuffle reassigns items to prefixes drawn without replacement from the list in which each prefix appears n_a times, so the prefix-size multiset is preserved; kappa is recomputed on a FIXED sample of 2000 edges per level per shuffle and all values are pooled into mu_l, sigma_l.
  6. kappa_hat_l(a,b) = clip((kappa_l(a,b) - mu_l)/sigma_l, -4, +4); kappa_bar_l = mean over quotient edges;
     delta_l = kappa_bar_l - mean_l'(kappa_bar_l'); eta_l = delta_l / std_l'(delta_l').
  7. Artifact acceptance check: |kappa_bar_l - [-2.32,-1.80,-0.86]_l| <= 0.15 for all three levels, otherwise abort.
  Training loop, per step, per level l=1..3, per rank's local shard (no cross-rank call anywhere):
      x_i = phi(h_i), e_k = phi(theta_k), phi(z) = z/(1+||z||) so ||x||<1
      D[i,k] = d_P(x_i, e_k)
      a0[i] = argmin_k ||x_i - e_k||          # Euclidean nearest: quota reference (baseline quantizer's own choice)
      q[k] = |{i : a0[i] = k}|                # the protected multiset, exactly
      Bias[i,k] = eta_l * kappa_hat_l(a0[i], k) * w_i(k)/w_i, on item i's successor-code support, zero elsewhere
      C[i,k] = D[i,k]/m_l + Bias[i,k]
      a <- a0; for round = 1..12 (documented default):
          M[i,k] = C[i,k] - C[i,a[i]]                       # regret of moving i to k
          A[p,r] = min over {i : a[i]=p} of M[i,r]          # scatter-amin, O(B*K)
          G[p,r] = A[p,r] + A[r,p]                          # best 2-swap gain between codes p and r
          (p*,r*) = argmin G; if G[p*,r*] < 0, swap the two argmin items, else leave
      commit a[i]; residual r_i <- r_i - e_{a[i]}; proceed to level l+1
  Loss: curved commitment d_P(x,e)^2 with stop-gradient on the code, plus the reconstruction term unchanged.
  Codebook: t_k <- (1-gamma) t_k + gamma * mean_{i assigned to k} log_0(x_i); e_k = exp_0(t_k), gamma = 0.99 baseline default.
COST: Per step at the frozen scale (24556 training items, 24 steps per epoch, 3000 epochs = 72000 steps): 3 levels x 1024 x 256 = 786k Poincare distance evaluations, about 16 MFLOP, plus 3 x 12 rounds x (B*K + K*K) roughly 12 MFLOP, plus three host synchronisations to read the fixed-round result, so about 3-6 ms per step on an A100-class card, roughly 5-10% over the baseline step, about 6 minutes of added wall clock over the whole run. Memory: artifact 20-30 MB, memory-mapped, no per-rank copy. Offline build: one CPU pass over training sequences plus 32 shuffles x 3 levels x 2000 sampled edges, 25-45 minutes once, outside the four-card Stage 2 budget.
HYPOTHESIS: That the standardised behaviour-graph curvature of a level identifies which successor codes a code should be allowed to reach, so reallocating items between codes under that additive bias places co-transitioning items in shared prefixes more often without moving a single usage count. If true: the per-level swap rate is non-zero at levels 1 and 3 and near zero at level 2; prefix-bigram top-1 accuracy of level 2 given level 1 and of level 3 given levels 1-2 rises against the same model with the bias off; distinct prefix counts stay near 247/7414/20223 and the collision rate stays near 0.177 because the multiset is invariant; and Stage 3 test_recall@10 exceeds 0.065 against the 0.055537 baseline. If the swap rate is below about 1% at every level, the hypothesis is already false at the assignment and the recall result is interpretable without further experiments.
RISKS: eta_2 is small (-0.24), so the middle level may barely move and a third of the mechanism may be inert; the quotient is built on the frozen baseline's prefixes and is therefore a static prior that can drift from the codebook being trained; the 12-round budget may bind and leave the descent far from its local optimum; the Poincare metric concentrates distances near the boundary and, although the quota forbids collapse, it may still push unrelated items into rare codes and hurt prefix predictability; the bias magnitude (eta * kappa_hat * successor mass, typically 0.1-0.4 against a normalised distance spread near 1) may be too small to move enough items, in which case the measured swap rate is exactly the diagnostic that says so.
BEHAVIOR SIGNAL: Training-only directed item transitions, aggregated into a per-item successor distribution over level-l codes and entered as the successor mass w_i(k)/w_i at each of the three levels.
BEHAVIOR COMPUTATION: From the TRAIN split only. For every consecutive pair (i -> j) inside a training sequence, w_ij += 1. Then w_i(k) = sum over j with pi_l(j)=k of w_ij and w_i = sum over j of w_ij, with pi_l the level-l prefix map of the frozen baseline. Stored offline as a CSR over the 24556 training items for the three levels, then frozen.
LEAKAGE BOUNDARY: Both inputs to the artifact are train-only: transition counts come from training sequences, and pi_l comes from the frozen baseline evaluated on the 24556 training items. Validation and test sequences are never referenced by the artifact script, the artifact is frozen before Stage 2 starts, and no per-epoch statistic enters it, so no validation or test interaction can reach the SID construction.
HYPERBOLIC OPERATOR: Poincare-ball distance d_P(x,y) = 2 artanh(||(-x) xor y||) with fixed curvature c = 1, together with the exponential and logarithmic maps exp_0/log_0 used for the codebook update and the parameter-free ball map phi(z) = z/(1+||z||).
HYPERBOLIC LOCATION: In the RQ-VAE quantizer at Stage 2: the assignment cost of all three levels, the straight-through commitment loss, and the EMA codebook update (tangent-space barycentre at the origin). It does not act inside Stage 3.
COUPLING PATH: successor mass w_i(k)/w_i (behaviour) times standardised behaviour-graph curvature kappa_hat_l(a0_i,k) times the level deviation eta_l gives an additive term; that term enters C[i,k]; C drives the quota-preserving swaps; the swaps decide the item's code triple, which is the token sequence Stage 3 trains on. Setting eta_l = 0 removes the term and the descent from a0 makes only the moves the curved metric alone justifies, so the emitted SIDs change; replacing d_P by the Euclidean distance changes a0, the protected multiset, the normalised distances and therefore every swap decision. Neither can be dropped without changing the SIDs.
COUPLING EQUATION: C[i,k] = d_P(x_i, e_k) / m_l  +  eta_l * clip(kappa_hat_l(a0_i, k), -4, +4) * (w_i(k) / w_i)
OBSERVABLES: (i) per-level swap rate s_l = |{i : a[i] != a0[i]}| / B at epochs 1, 500, 1500, 3000, which is exactly 0 when the bias is off and the metric perturbation is absent; (ii) the usage-multiset difference sorted(a)-sorted(a0), which must be exactly 0 at every logged step; (iii) distinct prefix counts per level against 247/7414/20223, and the collision rate against 0.177; (iv) prefix-bigram top-1 predictability on held-out training tails; (v) the fraction of items with no training successor; (vi) the number of binding swap rounds out of 12; (vii) Stage 3 test_recall@10 against 0.055537.
ABLATION BEHAVIOR OFF: eta_l <- 0 for all l, so Bias is identically zero and C reduces to the normalised curved distance. The switch exists as one config flag read at every level and is correct in the code; it is exercised only in no-grad inference passes over the finished model and never as a trained arm, so no second training run is spent.
ABLATION GEOMETRY OFF: d_P replaced by the Euclidean norm and the tangent-space codebook EMA replaced by a plain mean, with phi kept as a fixed squashing map so everything else in the code path is identical. Also exercised only in inference passes on the single trained model.
ABLATION BOTH ON: The trained arm: Poincare distance, tangent-space codebook EMA, and eta_l * kappa_hat_l(a0_i,k) * successor mass, minimised by the quota-exact 12-round 2-swap descent. One run, 3000 Stage 2 epochs on four cards, the frozen Stage 3 protocol, no early stopping, no sweep, no multi-seed.
SPEC EQUATIONS: d_P(x,y) = 2 artanh(||(-x) xor y||), c = 1; phi(z) = z/(1+||z||); e_k = phi(theta_k); a0 = argmin_k ||x_i - e_k||; q[k] = |{i : a0[i]=k}|; Bias[i,k] = eta_l * clip(kappa_hat_l(a0[i],k),-4,4) * w_i(k)/w_i; C[i,k] = d_P(x_i,e_k)/m_l + Bias[i,k]; M[i,k] = C[i,k] - C[i,a[i]]; A[p,r] = min_{i:a[i]=p} M[i,r]; G[p,r] = A[p,r] + A[r,p]; a <- swap(argmin_{p,r} G) while min G < 0, at most 12 rounds; invariant sorted(a) == sorted(a0); kappa_hat_l(a,b) = clip((kappa_l(a,b)-mu_l)/sigma_l,-4,4); eta_l = delta_l/std(delta); t_k <- (1-gamma) t_k + gamma * mean_{i in k} log_0(x_i), gamma = 0.99; e_k = exp_0(t_k).
SPEC INPUTS OUTPUTS: Inputs are the batch encoder outputs h (B x d), the current three codebooks, and the frozen train-only artifact (kappa_hat key-value arrays per level, CSR successor masses, eta_l, m_l seeds). Output is, for every item, a triple of code indices, i.e. its SID, plus per-level swap counts and the multiset assertion result. The Stage 3 recommender consumes the triples unchanged; only Stage 2 changes.
SAFEGUARDS: artanh via 0.5*log((1+r)/(1-r)) with r pre-clamped to 1-1e-6; ||x|| and ||e|| clamped to 1-1e-3 before every Poincare operation; Mobius denominator clamped at 1e-9; kappa_hat hard-clipped at four null standard deviations; items with no outgoing training transition get Bias = 0 and keep a0, and their coverage fraction is logged; m_l is the median of the previous epoch's per-batch median curved distance, a measured quantity refreshed once per epoch and never selected; sum_k q[k] == B and sorted(a) == sorted(a0) are asserted device-side every step on every rank, a violation raises; no torch.distributed call exists in the offline script or in the assignment path, and the artifact is read through a memory map so each rank touches only its own rows; the descent is run with a fixed round count so no data-dependent host branch is taken inside the loop.
END IDEA
