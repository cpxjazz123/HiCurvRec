IDEA: BCGR-LORENTZ
TITLE: Behaviour-contrast geodesic re-anchoring of the RQ-VAE residual chain in the Lorentz model
MOTIVATION: Evidence in this repository says the useful SID metric family is behaviour *contrast*, and that its Euclidean control matches the hyperbolic form, while the radial coordinate is only group compactness and the four-point/tree premise is unavailable. That leaves one unexamined place for geometry to do real work: the quantization residual. In a Euclidean RQ chain the residual z - q mixes radial error (which the evidence says is uninformative) with directional error (which carries behaviour identity), so levels 2 and 3 spend their codebook capacity re-encoding radius. BCGR makes the residual an angular, behaviour-oriented quantity: it measures the correction from a point displaced along the item's train-only behavioural flow, in a chart where pure radius changes are cheap and direction changes are expensive.
NOVELTY: Prior mechanisms here changed the codebook update rule (successor-weighted Frechet means), the per-level curvature (CURVCTRL), or the item radius (BRad). BCGR changes none of those: the codebook, the number of levels and the loss terms are untouched. It changes *where the log map is taken from* - the residual anchor is displaced by a behaviour-contrast term - and it therefore changes what levels >= 2 are asked to encode (behaviour-orthogonal direction instead of radius). No cone, no prefix-transition score, no Gromov-delta weight, no radial ranking.
CHANGE: At every RQ level the residual is taken at a displaced anchor q~ = exp_q(delta_i * u_i) instead of at the codeword q, where delta_i is the item's train-only forward/backward transition asymmetry times the codeword's own hyperbolic radius and u_i is the parallel transport to q of the successor-centroid direction; the next-level input is the parallel transport of log_{q~}(z) back to the origin and every assignment uses the Lorentz distance.
SPECIFICATION: Fix the gauge at curvature c = 1 (documented choice; re-scaling by sqrt(c) reproduces any other curvature exactly). Work on the hyperboloid H^d = {x in R^{d+1}: <x,x>_L = -1}, <u,v>_L = -u0 v0 + u.v, lift L(z) = (sqrt(1+||z||^2), z), d_H(x,y) = arcosh(clamp(-<x,y>_L, 1+1e-7, inf)).
Train-only statistics per item i: n_ij = number of times item j directly follows item i in training sessions; p_i(j) = n_ij / sum_j n_ij, p~_i(j) = n_ji / sum_j n_ji; alpha_i = 0.5 * sum_j |p_i(j) - p~_i(j)| in [0,1]; s_i = sum_j p_i(j) * e_j with e_j the frozen side/text embedding of item j; v_i = P s_i / max(||P s_i||, 1e-8) with P a learned d_in x d linear map; u_i = PT_{O->q}(v_i) with O = (1,0,...,0).
Per level l with codeword q_l: delta_i = alpha_i * d_H(O, q_l) (automatically <= d_H(O,q_l), clipped at 0.5 * d_H(O,q_l) for safety); q~_l = exp_{q_l}(delta_i * u_i); residual tangent r_l = PT_{q~_l -> O}( log_{q~_l}( L(z_l) ) ); next input z_{l+1} = exp_O(r_l); assignment a_{l+1} = argmin_k d_H(L(z_{l+1}), q_{l+1,k}). Commitment term uses ||r_l||^2 in place of ||z_l - q_l||^2; reconstruction loss unchanged. alpha_i = 0 -> delta = 0 -> exact baseline anchor.
COST: One-time pass over training sessions to build sparse n_ij and s_i (O(#train transitions), minutes, CPU, cached). Per step nothing changes in the transformer; the added work is 4096 items x 3 levels x (one log, one exp, two parallel transports, ~4 d-dimensional ops) plus a 4096 x 3 x 257 Lorentz-dot assignment in R^(d+1), about 1.1e8 FLOPs forward per step against a transformer step of order 1e12, i.e. well under 1% per step. Per epoch at the frozen scale (24556 items, 24 steps, 3000 epochs) the re-anchoring is ~1.2e9 FLOPs per epoch, no extra codebook entries and one extra d_in x d matrix; measured wall-clock expectation +1% to +2% on the four-card Stage 2 run, negligible on Stage 3 because Stage 3 consumes the emitted SIDs only.
HYPOTHESIS: If the radial coordinate is the uninformative part of the code space (evidence 3) and behaviour contrast is the informative part, then removing radius from the residual should make levels 2 and 3 encode behaviour-distinguishing direction, so the train-split conditional entropy H(next | 2-level prefix) and H(next | 3-level prefix) at fixed first token should fall relative to the frozen baseline, level-2/3 code usage should spread rather than concentrate on a few radial codes, and Stage 3 test_recall@10 should exceed 0.065 in the single frozen run. If the residual re-anchoring is neutral (delta too small to matter because most codewords sit near the origin) the diagnostics will show unchanged level-2 entropy and unchanged recall, which is the falsification.
RISKS: (1) Early in training P and the codebook are unaligned, so u_i points somewhere unhelpful and the displacement injects noise into levels 2-3; 3000 epochs may not be enough to recover. (2) If codewords cluster near the origin, d_H(O,q) ~ 0 and delta ~ 0, making the mechanism a no-op - this is detectable in the diagnostics but leaves the run uninformative. (3) Behaviour contrast may already be fully exploited by the level-1 assignment, so the residual change is redundant. (4) The learned P has a single gradient pathway and could collapse to a constant direction, in which case alpha only rescales a fixed displacement (harmless but weak).
BEHAVIOR SIGNAL: Per-item forward/backward transition asymmetry of the sequential training graph, alpha_i in [0,1], together with the successor-averaged side-embedding direction s_i.
BEHAVIOR COMPUTATION: From the training split only: scan each training session, insert directed edges (item at position t -> item at position t+1) into a sparse counter to obtain n_ij; normalise rows to p_i and columns to p~_i; alpha_i = 0.5 * L1 distance between the two distributions; s_i = sum_j p_i(j) e_j with e_j the frozen side embedding already fed to the RQ-VAE. Everything is recomputed once before Stage 2 and cached; items with no in- or out-edges get alpha_i = 0, s_i = 0 and reduce exactly to the baseline.
LEAKAGE BOUNDARY: n_ij, alpha_i and s_i are built exclusively from the sequential training interactions, the same split that trains the RQ-VAE and Stage 3; validation and test sessions are never read by the statistics pass, so no validation or test interaction can enter the SID construction. The side embeddings e_j are the model's frozen item features, not interaction-derived, so they carry no split leakage. The statistics are constants w.r.t. the Stage 2 graph, so no validation signal can be laundered through them.
HYPERBOLIC OPERATOR: Curvature -1 fixed by the documented gauge on the Lorentz hyperboloid: exponential map exp_x(v) = cosh(||v||) x + sinh(||v||) v/||v||, logarithmic map log_x(y) = arcosh(alpha)/sqrt(alpha^2-1) * (y - alpha x) with alpha = -<x,y>_L, parallel transport PT_{x->y}(v) = v + (<y,v>_L / (1 - <x,y>_L)) (x + y), and geodesic distance d_H = arcosh(-<x,y>_L). No trainable curvature: it is a gauge, and the mechanism does not claim to identify it.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer, at every level l >= 1, in the forward assignment path - the anchor of the log map, the transport of the residual, and the nearest-codeword scoring. It does not act on the loss scaling, on Stage 3, or on any standalone regulariser.
COUPLING PATH: The behaviour term and the curved term produce the same object: q~_l = exp_{q_l}( alpha_i * d_H(O,q_l) * PT_{O->q_l}(P s_i / ||P s_i||) ). That object is simultaneously the anchor whose log map defines the residual handed to level l+1 and the point against which level l+1's Lorentz assignment is effectively scored, so setting alpha_i = 0 removes the behaviour and reverting exp/PT/d_H to their Euclidean forms removes the curve; either change alters the residual vector and therefore the SID token produced at level l+1.
COUPLING EQUATION: q~_{i,l} = exp_{q_l}( alpha_i * d_H(O, q_l) * u_{i,l} ), r_{i,l} = PT_{q~_{i,l} -> O}( log_{q~_{i,l}}( z_{i,l} ) ), a_{i,l+1} = argmin_k d_H( exp_O(r_{i,l}), q_{l+1,k} ), where alpha_i is the behaviour term and d_H/exp/log/PT are the curved terms.
OBSERVABLES: (i) SID assignment: level-2 and level-3 code usage entropy and the number of distinct level-2 codes used per level-1 prefix should increase; the fraction of items whose full SID changes relative to a stored baseline SID table should be substantial (recorded, not gated). (ii) Prefix behaviour predictability on the training split: H(next | 2-token prefix) and H(next | 3-token prefix) at fixed first token should decrease. (iii) Behaviour contrast diagnostics (HBAA contrast, adjacency, transfer predictability) recorded, never used as a gate. (iv) Stage 3 test_recall@10 from the single frozen Stage 3 run.
ABLATION BEHAVIOR OFF: alpha_i forced to 0 for every item and s_i forced to 0 (so u_i = 0), leaving exp/log/PT/d_H exactly as specified; the anchor collapses to q_l and the run is a pure Lorentz residual chain. Not trained in this round, but wired and unit-checked to reproduce baseline residuals bit-for-bit within tolerance.
ABLATION GEOMETRY OFF: every exp/log/PT replaced by its linear/Euclidean counterpart (q~ = q + delta_i * v_i with delta_i = alpha_i * ||q_l||, r = z - q~, assignment by L2), behaviour left on; the same alpha_i and s_i enter a flat residual chain. Not trained in this round.
ABLATION BOTH ON: the full coupled mechanism exactly as specified - alpha_i from train-only transition asymmetry, delta_i = alpha_i * d_H(O,q_l), Lorentz log/exp/PT and Lorentz nearest-codeword scoring. This is the single arm that is trained and the only arm judged.
SPEC EQUATIONS: precompute (CPU, once): n_ij from train sessions; p_i(j) = n_ij / sum_j n_ij; p~_i(j) = n_ji / sum_j n_ji; alpha_i = 0.5 * sum_j |p_i(j) - p~_i(j)|; s_i = sum_j p_i(j) e_j. Init P ~ N(0, 1/d_in).
forward(item i, latent z): x_1 = L(z); for l in 1..L: q = q_l[a_l]; if alpha_i == 0 or ||s_i|| == 0: r = PT_{q->O}(log_q(x_l)) else: v = P s_i; v = v / max(||v||, 1e-8); u = PT_{O->q}(v); delta = min(alpha_i * d_H(O,q), 0.5 * d_H(O,q)); qt = exp_q(delta * u); r = PT_{qt->O}(log_{qt}(x_l)); x_{l+1} = exp_O(r); logits_k = -d_H(x_{l+1}, q_{l+1,k}); a_{l+1} = argmax_k logits_k; store r for the commitment term. Return the token tuple (a_1..a_L). Loss = baseline reconstruction + ||r_l||^2 (straight-through on x_{l+1} as in the frozen recipe).
SPEC INPUTS OUTPUTS: Inputs: the frozen side embeddings e_j (R^{d_in}), the sparse train transition counts, the current batch latents z (R^d), the per-level Lorentz codebooks Q_l (R^{(d+1) x K}), the linear map P. Outputs: per item a discrete SID token tuple and the per-level residual tangents r_l used by the commitment term; a cached alpha_i, s_i table is emitted to disk for audit.
SAFEGUARDS: (1) clamp the arcosh argument to >= 1 + 1e-7 and the Lorentz inner product to <= -1 - 1e-7 before the distance; (2) clamp every point back onto the hyperboloid after exp (renormalise so <x,x>_L = -1) to stop float drift off the manifold; (3) guard ||v|| and ||log|| with 1e-8 floors and use the series limit for alpha near 1; (4) cap delta at 0.5 * d_H(O,q) so the anchor can never cross the origin or leave the region where the log map is well conditioned; (5) clamp the transported residual norm to the 99.9th percentile of the batch per level (a measured, per-batch quantile, not a tuned constant) so a single outlier cannot dominate the commitment term; (6) items with alpha_i = 0 take the exact baseline branch, so no degenerate direction can enter; (7) keep the Lorentz chart throughout (the Poincare chart saturates above c ~ 2 and is never used); (8) fix the gauge at c = 1 and apply any curvature change only as the sqrt(c) rescaling, never as a fitted parameter.
END IDEA
