IDEA: CONFORMAL-SUCC-RQ
TITLE: A behaviour-conditioned conformal factor deforms the Lorentz-chart distance used by the RQ-VAE residual assignment, so successor-concentrated items get finer code resolution.
MOTIVATION: The evidence says SID quality is predicted by behaviour contrast, not by hierarchy: HBAA-style distance contrast tracks recall (+0.71) while Gromov-delta and ancestor-depth weighting hurt. Degree-matched rewiring is as tree-like as the real graph, so "the data is a tree" is unavailable. What is still unused is the graph's own local concentration: some items have highly predictable next items (successor mass concentrated on few neighbours), others disperse it. A quantizer that spends its finite code resolution uniformly ignores exactly that contrast. This idea makes the behaviour contrast enter the metric tensor of the code space, so the quantizer resolves predictable regions more finely and dispersive regions more coarsely, which is where prefix transfer is already easy.
NOVELTY: Earlier attempts either weighted the assignment/outer product by transitions (Sinkhorn or behaviour-weighted assignment), set per-level or per-prefix curvature from transition statistics (CURVCTRL-SID, BRad-RQ put it in the radial coordinate, SUCC-GEO-CBTAB and Poincare-Frechet put it in the update rule). None changes the METRIC ITSELF as a function of the item's successor concentration: here the behaviour scalar is a conformal factor multiplying a fixed-curvature Lorentz distance, so the behaviour term appears inside the distance and the distance carries curvature in one expression. Curvature is held at c=1 and never estimated, respecting the gauge result (any estimated c is a radial rescale). No Frechet/Karcher codebook update, no curvature prediction from prefixes, no radial term.
CHANGE: Compute a per-item degree-corrected successor-concentration score b_i from train-only directed transitions; map it to a per-code conformal weight g_{l,k} (stop-gradient responsibility-weighted mean of g_i = exp(b_i/4)); use g_{l,k} * d_Lorentz(x_i^l, y_{l,k}) as the assignment distance at every RQ level instead of the plain distance, with the codebook update unchanged.
SPECIFICATION:
1. Train-only transitions: from the Stage-2 training split only, for each user session in timestamp order add a unit edge i -> j between consecutive distinct items; accumulate C_ij. d_i = sum_j C_ij, P_ij = C_ij / d_i.
2. Behaviour scalar: q_i = sum_j P_ij^2 (successor concentration). Degree-matched null q_i^0 = 1/d_i. u_i = log(q_i * d_i) for d_i >= 2, else u_i = 0. b_i = clip((u_i - mean(u)) / std(u), -2, +2) over the 24556 training items (mean/std computed once on the training split, frozen).
3. Conformal weight: g_i = exp(b_i / 4) in [e^-0.5, e^+0.5] = [0.607, 1.649].
4. Hyperbolic lift (fixed c = 1, Lorentz chart): for tangent vector t, x = (sqrt(1+||t||^2), t), with radial clamp ||t|| <= tanh^{-1}(0.99).
5. Code lift: y_{l,k} = (sqrt(1+||e_{l,k}||^2), e_{l,k}).
6. Assignment logits: s_ik = - ( g_{l,k} * arccosh(-<x_i^l, y_{l,k}>_L) )^2 / tau_l, tau_l = mean_k ||e_{l,k}||^2, softmax over k, straight-through hard code for the SID.
7. g_{l,k} = sum_i w_ik g_i / (sum_i w_ik + 1e-8), with w_ik the previous-epoch hard assignment indicator of item i to code (l,k); stop-gradient, recomputed once per epoch.
8. Decoder input is the tangent image log_0(y_{l,k}) = e_{l,k} of the selected code (unchanged from baseline), so the generative model and Stage 3 see only integer SIDs.
COST: One extra O(N_items * L * K) pass per epoch for the responsibility-weighted g (24556 * 3 * 256 = 18.9M adds), plus an arccosh and a Lorentz dot replacing the squared Euclidean per pair: about 18.9M arccosh per epoch, i.e. 786k per step over 24 steps, well under 1% of a transformer step at global batch 4096; no extra parameters beyond the frozen 24556-float b vector; roughly +2-4% wall clock on Stage 2, unchanged Stage 3.
HYPOTHESIS: If the conformal stretch aligns code resolution with successor concentration, then the behaviour-weighted level-1 and level-2 quantization error should fall for high-b items at unchanged code usage, prefix transition entropy should drop for the high-b item subset, and Stage 3 test_recall@10 should exceed 0.065. It is worth keeping if that recall is above 0.065 and the behaviour-weighted quantization error falls; it is not worth keeping if g_{l,k} is nearly constant (signal washed out) or if high-b and low-b item recall move together with no prefix change.
RISKS: b_i may mostly encode popularity (mitigated by the degree-matched null, not guaranteed); the conformal factor may act as noise and shift code assignment without changing prefix predictability; soft responsibility may be dominated by a few hub codes so g_{l,k} collapses to 1; if high-b items are already saturated in Stage 3 the recall gain is nil; arccosh gradients blow up near the light cone if the clamp is wrong.
BEHAVIOR SIGNAL: Degree-corrected successor concentration b_i of each training item, from directed item-to-item transitions in the Stage-2 training interactions.
BEHAVIOR COMPUTATION: From the training split only: iterate each user's sessions in timestamp order, add unit edge i->j for consecutive items, accumulate C_ij; d_i = sum_j C_ij; P_ij = C_ij/d_i; q_i = sum_j P_ij^2; u_i = log(q_i d_i); b_i = clip(z-score(u), -2, 2), frozen before training. No validation or test interactions are ever read.
LEAKAGE BOUNDARY: C_ij, d_i, and the mean/std of u are computed at preprocessing time from the training interaction file only, written to a read-only 24556-vector, and never recomputed during validation or test; Stage 3 consumes only integer SIDs produced in Stage 2, so no validation or test user-item pair can influence b_i, g_{l,k}, or the codebook.
HYPERBOLIC OPERATOR: Lorentz (hyperboloid) geodesic distance d_L(x,y) = arccosh(-<x,y>_L) at fixed curvature c = 1, multiplied by a conformal factor g; tangent lift x = (sqrt(1+||t||^2), t) is the exp map at the origin.
HYPERBOLIC LOCATION: Inside the RQ-VAE residual assignment at every quantization level, i.e. the code-entry selection step that produces each SID digit; the codebook update rule and the decoder are unchanged.
COUPLING PATH: b_i -> g_i -> g_{l,k} -> distance g_{l,k} * d_Lorentz(x_i, y_{l,k}) -> assignment logits -> hard code index -> level-l SID digit -> prefix -> Stage-3 recall. Removing behaviour sets b_i = 0 hence g = 1 and the distance is the plain Lorentz distance; removing geometry replaces d_Lorentz by the Euclidean tangent distance and the product becomes a behaviour-weighted Euclidean distance. Either removal changes the core assignment computation, not a side loss.
COUPLING EQUATION: s_ik = - ( g_{l,k}(b) * arccosh(-<exp_0(t_i^l), exp_0(e_{l,k})>_L) )^2 / tau_l , with g_{l,k}(b) = sum_i w_ik exp(b_i/4) / sum_i w_ik.
OBSERVABLES: per-level code usage histogram and perplexity; g_{l,k} distribution (must stay non-degenerate); behaviour-weighted quantization error split by b_i tercile; level-1 and level-2 prefix transition entropy on the training split; SID collision count; Stage 3 test_recall@10.
ABLATION BEHAVIOR OFF: b_i := 0 for all items, so g_i = 1 and g_{l,k} = 1; the same Lorentz distance and the same tau are used and everything else is identical.
ABLATION GEOMETRY OFF: d_Lorentz replaced by the Euclidean tangent distance ||t_i^l - e_{l,k}||_2 inside the same product, with tau_l = mean_k ||e_{l,k}||^2 unchanged; b and g unchanged.
ABLATION BOTH ON: the full coupled run, g = exp(b/4) multiplying the c = 1 Lorentz arccosh distance; the only arm trained.
SPEC EQUATIONS:
u_i = log( (sum_j (C_ij/d_i)^2) * d_i ),  b_i = clip((u_i - mu_u)/sigma_u, -2, 2),  g_i = exp(b_i/4)
x_i^l = ( sqrt(1+||t_i^l||^2), t_i^l ),  y_{l,k} = ( sqrt(1+||e_{l,k}||^2), e_{l,k} )
<s,t>_L = -s_0 t_0 + s_1 t_1 + ... + s_d t_d
d_L = arccosh( clamp(-<x,y>_L, 1+1e-7, +inf) )
s_ik = - ( g_{l,k} * d_L )^2 / tau_l,  p_ik = softmax_k(s_ik)
k_i^l = argmax_k p_ik (straight-through),  SID(i) = (k_i^1, k_i^2, k_i^3)
g_{l,k} = sum_i w_ik g_i / (sum_i w_ik + 1e-8),  w_ik = 1[k_i^l = k], stop-gradient
codebook update: unchanged baseline EMA/VQ update on the tangent vectors e_{l,k}
SPEC INPUTS OUTPUTS: Inputs: train-only transition counts C (24556 x 24556 sparse, ~1e7 edges), frozen b (24556,), per-level codebooks e_{l,k} (L x 256 x d), residual tangents t_i^l (batch x d). Outputs: g_{l,k} (L x 256), assignment logits s (batch x 256 per level), hard codes and hence SID tuples, plus the diagnostic tensors above.
SAFEGUARDS: clamp the arccosh argument at 1+1e-7 (double precision for the inner product, then cast); radial clamp ||t|| <= tanh^{-1}(0.99) and ||e|| likewise so the lift never reaches the light cone; tau_l floored at 1e-6 to avoid division by zero when a level collapses; g_i predefined in [0.607, 1.649] and g_{l,k} additionally clipped to the same interval; codes with sum_i w_ik < 2 inherit g_{l,k} = 1 (no behaviour estimate); stop-gradient on g_{l,k} so the behaviour term cannot be gamed by the encoder; items with d_i < 2 get b_i = 0; if the code usage perplexity of a level falls below 1.2 the run is reported as collapsed (diagnostic, not a gate).
END IDEA
