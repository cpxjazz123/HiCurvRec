IDEA: GYROFRAME-RQ
TITLE: Behaviour-conditioned moving frame (Mobius gyro-translation by a positive-PMI transition direction) for the RQ-VAE residual recursion in a fixed-curvature Poincare ball
MOTIVATION: RQ-VAE semantic IDs are built by subtracting codebook vectors from a residual, so every deeper level re-encodes the item's absolute position rather than what distinguishes it from the items it is actually confused with at recommendation time. The repository evidence shows that what predicts Stage3 recall is behaviour contrast (HBAA +0.7104) and not hierarchy, curvature estimation or radial compactness, yet the quantizer recursion has no notion of where an item's behaviour is heading; its levels 2..L are spent on global geometry instead of behaviour-relevant deviation.
NOVELTY: Earlier rounds changed the codebook (Poincare-Frechet successor centroids), the per-level curvature (CURVCTRL-SID), the radial slot (BRad-RQ), the prefix cone (behcone-prefix-rq), successor profile smoothing (LORENTZ-SUCCPROFILE-SMOOTH-RQ), successor boosting (succboost-geoshift), MoE branching (BRANCHCURV-MOEB-RQ) and multi-curvature fibres (MIXCURV-FIBRE-RQ). None of them touches the residual recursion operator itself. GYROFRAME-RQ changes p_{l+1} from "p_l minus code" to "p_l minus code, re-expressed in a per-item frame that is gyro-translated by the item's behaviour contrast direction". The displacement is directional only (constant hyperbolic radius), so it is not a radial or depth ranking, and curvature is never estimated (fixed c=1, explicitly a gauge choice).
CHANGE: At each level the residual point is moved into the item's behaviour frame by the Poincare isometry tau_{m_i}, the chosen code is subtracted there by Mobius addition, and the result is logged back to the tangent space to become the next residual, so the codes chosen at levels 2..L are determined jointly by the behaviour direction and by the curved frame change.
SPECIFICATION: k_l = argmin_k d_P(E_sigma(r_l), E_sigma(e_k)); p_{l+1} = (-E_sigma(e_{k_l})) (+) ((-m_i) (+) E_sigma(r_l)); r_{l+1} = L_sigma(p_{l+1}); m_i = tanh(rho) u_i, where u_i is the positive-PMI transition contrast direction and rho, sigma are measured once and frozen. Full equations under SPEC EQUATIONS.
COST: Precompute once, offline, before training: the sparse train-transition PMI weights plus one sparse-times-dense product (~10^6 edges x 768 dims ~ 0.8 GFLOP), and the 24556 x 768 anchor table (75 MB float32); a few seconds to one minute, zero per-step cost afterwards. Per training step (global batch 4096, L levels, d = 768): L x 4096 x 768 x ~10 flops ~ 1.3e8 FLOPs = 0.13 GFLOP plus ~4 extra 4096 x 768 activations (~55 MB); that is under 1-2% of a transformer step. At the frozen scale 24 steps/epoch x 3000 epochs = 72,000 steps, total extra ~9.4 TFLOP, wall-clock overhead about 1%. No new trainable parameters; the anchor table is a non-trainable buffer.
HYPOTHESIS: For the idea to be worth keeping, the behaviour frame must move deep-level capacity away from global position and toward transition-relevant deviation, so that a 3-token prefix becomes more predictive of the training successor set and the frozen Stage3 beam puts the true item in the top 10 more often than 0.065. Observable: at the final checkpoint, evaluating the same weights with m_i forced to 0 (forward pass only, no retraining) must change a large fraction of level>=2 codes and worsen the train-split prefix successor rank; if the both-on run's Stage3 test_recall@10 exceeds 0.065 while the geometry-off switch on the same checkpoint yields different level>=2 codes, the coupling is doing work.
RISKS: The frame offset may be noise for items whose PMI direction is dominated by popularity artefacts (reduced but not removed by the PMI normalisation). The discrete argmin passes gradient to the curved chain only through the straight-through cost, so the codebook may adapt weakly and the frame may act as a fixed perturbation. If latents crowd the ball boundary, artanh saturation makes the frame change enormous. The constant-radius anchor may be too weak or may dominate. Stage3 may simply ignore the changed tokens, in which case one run cannot tell which sub-part failed.
BEHAVIOR SIGNAL: Directional positive-PMI transition contrast per item (popularity-adjusted directed transitions), not a co-occurrence count and not a hierarchy statistic.
BEHAVIOR COMPUTATION: From the sequential TRAINING interactions only, unit edges, no truncation, using the same builder as the evidence graph: A_ij = number of training-split transitions i -> j; o_i = sum_j A_ij; iota_j = sum_i A_ij; T = sum_ij A_ij. Contrast weight w_ij = max(0, ln(A_ij * T / (o_i * iota_j))) for A_ij >= 1, else 0. With x_i^txt the frozen Stage 2 item text embedding, c_i = sum_j w_ij (x_j^txt - x_i^txt) and u_i = c_i / ||c_i|| (u_i = 0 when o_i = 0 or ||c_i|| < 1e-12). The tables {u_i} and {m_i} are computed once before the run and frozen.
LEAKAGE BOUNDARY: A is built from training-split sequences only; validation and test interactions never enter A, w, u, m, rho or sigma. rho is measured from the first training forward pass and sigma from the training text embeddings. No validation or test statistic selects any constant, so the SID construction is a pure function of (training transitions, training text embeddings, frozen constants) and nothing from the evaluation splits can reach the codebook or the tokens.
HYPERBOLIC OPERATOR: Fixed negative curvature c = 1 (unit Poincare ball), used through three explicit curved operations: exp_0 / log_0 at a frozen tangent scale sigma (tanh and artanh), the Mobius addition (+)_c with its inverse (-x)(+)_c y, and the Poincare distance d_P(x,y) = acosh(1 + 2c||x-y||^2 / ((1-c||x||^2)(1-c||y||^2)))/sqrt(c). Curvature is never estimated or tuned; c=1 is a documented gauge choice consistent with the repo finding that c only rescales tangent vectors.
HYPERBOLIC LOCATION: Inside the residual quantizer recursion at every level l >= 1 of RQ-VAE training: in the assignment cost and in the residual update that feeds level l+1, and in the codebook commitment through the curved residual.
COUPLING PATH: u_i (behaviour) -> m_i = tanh(rho) u_i (a point in the ball) -> Mobius gyro-translation of the level-l residual point -> curved subtraction of the chosen code -> r_{l+1} -> level-(l+1) assignment. Setting m_i = 0 collapses the translation to the identity and changes every level>=2 code; setting c = 0 turns the translation into a plain offset and changes the codes. Neither factor can be deleted without changing which codes are chosen, so they are one pathway rather than two losses.
COUPLING EQUATION: p_{l+1} = (-E_sigma(e_{k_l})) (+)_c ( (-m_i) (+)_c E_sigma(r_l) ), with k_l = argmin_k d_P^c(E_sigma(r_l), E_sigma(e_k)) and m_i = tanh(rho) * u_i from the positive-PMI behaviour contrast direction; equivalently r_{l+1} = L_sigma(p_{l+1}).
OBSERVABLES: (1) SID assignment: per-level code usage histograms and the fraction of items whose level>=2 tokens differ between the trained weights evaluated with m_i and with m_i = 0 (one forward pass each, no retraining). (2) Per-level mean tangent norm ||r_l||, which should stop growing with l if the frame absorbs position. (3) Train-split prefix successor predictability: mean rank and hit rate of the true successor given the level-l prefix, for l = 1..L. (4) Frozen Stage3 test_recall@10, the only judgement.
ABLATION BEHAVIOR OFF: m_i := 0 for all i (the u table and anchor buffer zeroed), so the recursion becomes p_{l+1} = (-q_{k_l}) (+) p_l, i.e. pure hyperbolic RQ with no behaviour frame. Wired as a config flag; not trained in this round.
ABLATION GEOMETRY OFF: c := 0 path, where (+) becomes +, E_sigma and L_sigma become identity and d_P becomes squared Euclidean, so the recursion becomes r_{l+1} = r_l - e_{k_l} - m_i, i.e. behaviour enters only as a constant per-item offset. Same flag structure; not trained in this round.
ABLATION BOTH ON: The trained arm: c = 1 with the Mobius recursion and m_i = tanh(rho) u_i active. This is the single formal run (3000 Stage 2 epochs, four-GPU DDP, batch 4096, frozen recipe) followed by the frozen Stage 3 protocol.
SPEC EQUATIONS: Constants fixed before the run: c = 1; sigma = 1/R with R = the 95th percentile of ||z_i|| over training items at the end of epoch 0 (measured, then frozen); rho = median_i ||r_{i,1}|| over training items at the end of epoch 0 (measured, then frozen). Ball maps: E_sigma(r) = tanh(sigma||r||)/(sigma||r||) * r; L_sigma(p) = artanh(||p||)/(sigma||p||) * p, with ||p|| clamped to 1-1e-5, and E_sigma(0) = L_sigma(0) = 0. Mobius (c = 1): x (+) y = ((1 + 2<x,y> + ||y||^2) x + (1 - ||x||^2) y) / (1 + 2<x,y> + ||x||^2 ||y||^2). Forward for item i with encoder latent z_i: r_1 = z_i; for l = 1..L: p_l = E_sigma(r_l); q_k = E_sigma(e_k); cost_l(k) = acosh(1 + 2||p_l - q_k||^2 / ((1-||p_l||^2)(1-||q_k||^2))); k_l = argmin_k cost_l(k); code contribution e_{k_l} taken straight-through; p_next = (-q_{k_l}) (+) ((-m_i) (+) p_l); r_{l+1} = L_sigma(p_next). SID_i = (k_1,...,k_L). Reconstruction x_hat_i = Dec(sum_l e_{k_l}); loss = ||x_hat_i - x_i^txt||^2 + beta||z_i - sg(sum_l e_{k_l})||^2 + lambda_cb||sum_l e_{k_l} - sg(z_i)||^2 with the frozen baseline beta and lambda_cb unchanged. Offline: A, w, u, m exactly as in BEHAVIOR COMPUTATION.
SPEC INPUTS OUTPUTS: Inputs are the training-split transition matrix A (sparse, N x N), the frozen item text embeddings X in R^{N x d}, the encoder latent z_i, and the codebook E in R^{K x d}. Outputs are the precomputed anchor table m in R^{N x d}, the per-level code indices (k_1..k_L) per item, the curved residual chain r_1..r_{L+1} used for assignment and for the commitment term, and gradients to the encoder, codebook and decoder.
SAFEGUARDS: (a) clamp every ball point to norm <= 1-1e-5 before Mobius addition and before acosh; (b) clamp the acosh argument to >= 1+1e-7 and (1-||x||^2) to >= 1e-5; (c) use artanh(t) = 0.5*log((1+t)/(1-t)) with t clamped to 1-1e-6 and a zero-norm guard returning 0; (d) floor the Mobius denominator at 1e-8 and fall back to the Euclidean update on the affected rows, counting and logging them; (e) u_i = 0 for o_i = 0 or ||c_i|| < 1e-12, so out-degree-zero items keep m_i = 0; (f) PMI defined only on A_ij >= 1, so no log(0); (g) float32 forward with a float64 Mobius-identity check on 16 random rows once per epoch; (h) curvature is a compile-time constant c = 1, so no curvature drift; (i) sigma and rho are frozen after epoch 0 so the frame cannot co-adapt into a scale search.
END IDEA
