IDEA: GEO-MIX-PREFIX-RQ
TITLE: Geodesic-midpoint mixup gives co-consumed items a shared coarse Poincare prefix
MOTIVATION: Content-only SIDs give co-consumed items unrelated coarse prefixes, so the generator cannot use the history token to anticipate the successor.
NOVELTY: It changes no assignment, codebook, residual or prefix scorer. Unlike cocond-markov-poincare-ot, poincare-frechet-successor-codebook, SUCC-TAN-RQ, KAPPA_BRANCH and the issue126 proxy, it acts on the quantizer's TRAINING DISTRIBUTION: one curvature-defined virtual target at the exact geodesic midpoint.
CHANGE: From training-only co-consumption counts, add one virtual reconstruction target per connected item at the c=-1 Poincare geodesic midpoint of that item and a count-sampled neighbour; train the otherwise unchanged RQ-VAE on the 2N-point union.
SPECIFICATION: Build a row-normalised sparse co-consumption matrix P from train sessions (window 5). Map embeddings into the unit Poincare ball (R=0.9, M=max train norm). For each item with non-empty row sample j~P[i,:], set m_i=exp_{p_i}(0.5 log_{p_i}(p_j)), invert the chart, append as virtual target. Unchanged loss/encoder/codebook; SIDs inferred from real embeddings only.
COST: Preprocess: seconds (24556 midpoints, d~64). Train: 24 steps/epoch over 2N=49112 points, ~2046/step vs 1023, so ~2x encoder-decoder FLOPs/step and 1.6-2.0x Stage-2 wall clock over 3000 epochs. +~6.3 MB, no new params, no inference cost.
HYPOTHESIS: Origin-ward midpoints make level-1 cells behaviour-coherent: co-consumed pairs share first tokens more, successor first-token entropy falls, Stage3 test R@10 > 0.065. Only the hyperbolic midpoint bows toward the origin, so the Euclidean arm should lose this.
RISKS: A virtual-point code may appear without pulling real items together; smoothing may blur fine content; the graph is popularity-dominated; rare items may under-fit.
BEHAVIOR SIGNAL: Windowed sequential co-consumption counts over training sessions.
BEHAVIOR COMPUTATION: For each train session and ordered pair (u,v) with 1<=pos(v)-pos(u)<=5, C[u,v]+=1; A=C+C^T; A_ii=0; P[i,:]=A[i,:]/sum. One neighbour per item drawn once with the run seed, cached.
LEAKAGE BOUNDARY: Graph, M, midpoints and neighbours come from train sequences/embeddings only; val/test never read; SIDs from real embeddings.
HYPERBOLIC OPERATOR: Unit-curvature Poincare ball, c=-1, metric 4/(1-||x||^2)^2 I; Mobius addition, exp/log, geodesic midpoint.
HYPERBOLIC LOCATION: Preprocessing and RQ-VAE reconstruction targets; it shapes the learned cells, not the assignment logits.
COUPLING PATH: graph -> pair -> geodesic -> curved midpoint -> virtual target -> reconstruction gradient -> level-1 codebook/encoder -> SID(i). No behaviour: no pair. Euclidean: different target. Either removal changes the computation.
COUPLING EQUATION: v_i=chart^{-1}(m_i), m_i=exp_{p_i}(0.5*log_{p_i}(p_{j(i)})), j(i)~P[i,:].
OBSERVABLES: mean level-1 centroid distance over co-consumed pairs (down); successor first-token entropy (down); fraction of first tokens changed; Stage3 test R@10. Diagnostics recorded, never gated.
ABLATION BEHAVIOR OFF: graph disabled, D'=D, same seed/epochs/RQ-VAE.
ABLATION GEOMETRY OFF: same pairs and 2N set, m_i=(e_i+e_j)/2 raw, no ball maps.
ABLATION BOTH ON: full graph + c=-1 midpoint + 2N targets.
SPEC EQUATIONS: M=max||e_i||; p_i=0.9 e_i/M. x(+)y=((1+2<x,y>+||y||^2)x+(1-||x||^2)y)/(1+2<x,y>+||x||^2||y||^2). log_x(y)=2 artanh(||(-x)(+)y||)((-x)(+)y)/||(-x)(+)y||. exp_x(v)=x(+)(tanh(||v||/2)v/||v||). m_i=exp_{p_i}(0.5 log_{p_i}(p_j)); v_i=M m_i/0.9. Loss unchanged over real and virtual x.
SPEC INPUTS OUTPUTS: in: E (N x d), train sequences, W=5, R=0.9, c=-1, seed; out: X' (2N x d), row 2i=e_i, row 2i+1=v_i or e_i if no neighbour, plus index map.
SAFEGUARDS: clamp ||p||<=0.9-1e-6; denom max(.,1e-12); artanh arg min(.,1-1e-6); A_ii=0; skip zero-mass rows; handle ||e_i||=0; assert finite and ||v_i||<=max(||e_i||,||e_j||)+1e-6.
END IDEA
