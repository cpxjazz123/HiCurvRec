IDEA: TSG-SID
TITLE: Curvature-transported successor gradients through the RQ-VAE straight-through path
MOTIVATION: In a VQ/RQ-VAE the straight-through estimator hands the encoder a pure reconstruction gradient, so the training transition structure (which item a user actually takes next) never reaches the encoder or the codebook geometry: SID assignment is blind to behavioural reachability. Curved space has so far been used only to re-weight losses, assignments or codebook means, never to shape the gradient that actually moves the latent.
NOVELTY: Unlike the per-level curvature controllers, Poincare Sinkhorn/mass transport, curved Frechet codebook updates and prefix-cone proposals, this changes neither the assignment rule nor a loss value: it changes the vector that backpropagates through the quantizer. The successor distribution is log-mapped at the assigned codeword and parallel-transported to the latent, in the same Poincare ball that defines the quantizer commit and the decoder chart.
CHANGE: Each level carries a curvature c_l derived from the measured latent scale; the latent is injected into that ball through exp_0, quantized by geodesic distance, and the STE gradient is augmented by the tangent vector of its training successors, parallel-transported from the codeword to the latent and gated by the current commit distance.
SPECIFICATION: For level l, measure s_l = max over the 24556 training latents of |z_l| (one pass at epoch 0, refreshed every 100 epochs), set c_l = 1/(4 s_l^2). Map x = exp_0^{c_l}(z/s_l). Assign k = argmin_k d_{c_l}(x, e_{l,k}). Build the training-only successor distribution p(j|i) (top-M=16, renormalized). v_b = sum_j p(j|i) log_{e_{l,k}}^{c_l}(e_{l,k'(j)}), where k'(j) is j's current level-l codeword (stop-grad). Scale lambda_l = delta_l / mean|v_b| measured at epoch 0, delta_l = median commit distance at epoch 0; apply the curvature-tied soft bound r_l tanh(|lambda_l v_b|/r_l) with r_l = 0.5/sqrt(c_l). Gradient to encoder: g = sg[x - e_{l,k}] + kappa * PT_{e_{l,k}->x}^{c_l}(v_b_soft), kappa = d_c(x,e_{l,k})/(d_c(x,e_{l,k})+delta_l). Commitment loss is the squared geodesic distance d_{c_l}(x,e_{l,k})^2, so the codebook update is also curved. Autograd differentiates exp_0. Three switches: USE_BEHAV (v_b=0 when off) and USE_HYPER (c_l=0, Euclidean branch when off); the single run has both on.
COST: Transition table is built once from the training split (24556 x 16 ints, ~0.4M entries). Per step at the frozen scale (batch ~1023, L=4 levels, M=16 successors) there are about 65k log-map + transport evaluations of dimension d (d=32-64), roughly 4-8 MFLOP, plus one Mobius add per item per level; expected overhead 3-8% of step time over 72,000 steps (24 x 3000), no extra forward passes and no extra epochs. The s_l and delta_l measurements are one pass over 24556 latents.
HYPOTHESIS: If SID quality is limited by the encoder not knowing which items are behaviourally reachable from which, then transporting successor tangents into the quantizer gradient should pull high-branch items toward their successor region, raising training prefix top-1 transition accuracy and Stage3 test Recall@10 above the no-transport baseline. Observed as a nonzero SID assignment flip rate (target >2% of items versus epoch 0), a monotone rise in prefix transition predictability, and a Recall@10 improvement with both switches on.
RISKS: Transport is noisy under sparse transitions; the successor codeword map k'(j) is stale within an epoch; curvature from s_l drifts as the encoder rescales; the added tangent could dominate reconstruction and collapse codebook usage; the effect may be below seed noise in a single run.
BEHAVIOR SIGNAL: Directed item-to-item transitions from training sequences, aggregated into a sparse row-stochastic successor distribution p(j|i) per item, top-M truncated and renormalized.
BEHAVIOR COMPUTATION: One pass over the training split only, counting consecutive (i_t, i_{t+1}) pairs, keeping the top-M=16 successors per item and dividing by the row count; the table is frozen at epoch 0 and rebuilt only from training data. No popularity correction is applied (documented default), so nothing is tuned.
LEAKAGE BOUNDARY: Counts, s_l, delta_l and the successor-to-codeword map are computed exclusively from the training split and from the current training codebook; validation and test sequences are never read, and no evaluation statistic enters any constant.
HYPERBOLIC OPERATOR: Poincare ball of trainable-free curvature -c_l with c_l = 1/(4 s_l^2) (so the ball radius is 2 s_l, twice the measured latent scale), exponential map exp_0, logarithmic map log_x, geodesic distance d_c, and parallel transport PT_{x->y}; all in closed form.
HYPERBOLIC LOCATION: At quantization time (latent injection, assignment, commitment) and in the backward pass, where the transported tangent is added to the straight-through gradient. It is not a side loss.
COUPLING PATH: p(j|i) selects and weights successor codewords; the log map at the assigned codeword and the parallel transport to the latent are defined only by the curvature c_l; their output is the gradient the encoder receives. Setting p=0 zeroes the term, and setting c=0 replaces log/transport by Euclidean differences, so both factors are load-bearing in one path.
COUPLING EQUATION: g_i,l = sg[x - e_{l,k}] + [ d_{c_l}(x,e_{l,k}) / (d_{c_l}(x,e_{l,k}) + delta_l) ] * PT_{e_{l,k}->x}^{c_l}( sum_{j in Succ(i)} p(j|i) * log_{e_{l,k}}^{c_l}( e_{l,k'(j)} ) ), with x = exp_0^{c_l}(z_{i,l}/s_l) and c_l = 1/(4 s_l^2).
OBSERVABLES: SID assignment flip rate relative to epoch 0; per-level prefix top-1 transition accuracy on training transitions; codebook usage entropy per level; geodesic commit distance distribution; Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: p(j|i) := 0, so v_b = 0 and g = sg[x - e_{l,k}]; the curved chart, geodesic assignment and geodesic commitment remain, isolating the behavioural tangent.
ABLATION GEOMETRY OFF: c_l := 0 with an explicit Euclidean code path, so exp_0 = log_x = PT = identity, d_c = Euclidean distance, and the same p-weighted successor difference e_{l,k'(j)} - e_{l,k} enters the gradient; the behaviour term remains, isolating the curvature.
ABLATION BOTH ON: the single trained run, with p(j|i) from the training split and c_l = 1/(4 s_l^2), the transported gated tangent active.
SPEC EQUATIONS: exp_0^c(v) = tanh(sqrt(c)|v|) * v/(sqrt(c)|v|); log_x^c(y) = (2/(sqrt(c) lambda_x)) * artanh(sqrt(c)|(-x)+_c y|) * ((-x)+_c y)/|(-x)+_c y|; d_c(x,y) = (2/sqrt(c)) artanh(sqrt(c)|(-x)+_c y|); lambda_x = 2/(1-c|x|^2); PT_{x->y}^c(v) = (lambda_x/lambda_y) * gyr[y,-x] v; c_l = 1/(4 s_l^2); z_hat = z/s_l; x = exp_0^{c_l}(z_hat); k = argmin_k d_{c_l}(x,e_{l,k}); v_b = sum_j p(j|i) log_{e_{l,k}}^{c_l}(e_{l,k'(j)}); v_soft = r_l tanh(|lambda_l v_b|/r_l) * lambda_l v_b/|lambda_l v_b|, r_l = 0.5/sqrt(c_l); kappa = u/(u+delta_l), u = d_{c_l}(x,e_{l,k}); g = sg[x-e_{l,k}] + kappa * PT_{e_{l,k}->x}^{c_l}(v_soft); L_commit = u^2.
SPEC INPUTS OUTPUTS: Inputs: per-level latent z_{i,l}, current codebook {e_{l,k}}, training successor table p(j|i), measured s_l, delta_l, lambda_l, and the switch flags. Output: the encoder-side gradient g_{i,l}, the assigned codeword index k, the scalar geodesic commitment loss, and the updated codebook (through the same distance).
SAFEGUARDS: Use c_l = 1/(4 s_l^2) so |x| < 2 s_l for every |z| <= s_l, which keeps x strictly inside the ball by construction, with no protective cap on the curvature; clamp the Mobius argument |(-x)+_c y| <= (1-1e-6)/sqrt(c); artanh uses the log form for small arguments and clamps at 1-1e-6; norms divided by max(|.|, 1e-12); lambda_l floored at 1e-6 and the soft bound r_l tanh(|.|/r_l) is injective over the observed range, so it never freezes the behaviour term; the successor map is stop-grad and recomputed once per epoch; delta_l > 0 by construction from a median over 24556 items.
END IDEA
