IDEA: branch_curvature_encoder
TITLE: Let transition branching set the encoder's local hyperbolic curvature
MOTIVATION: Items with many behaviorally distinct continuations should be represented in a space that can expand those branches, while predictable transitions need less radial expansion; a single global encoder geometry cannot express that difference.
NOVELTY: Unlike the measured curved assignment-score approaches, this changes the encoder representation before quantization: training-only transition branching controls the curvature of a Lorentz manifold map, and the resulting mapped vector changes the ordinary RQ-VAE input and its gradients. It does not reweight codeword selection distances.
CHANGE: Precompute each item's smoothed outgoing-transition entropy from training sequences and use it to select item-conditioned negative curvature in the encoder's Lorentz exp-map/log-map path. Quantize the resulting tangent vector with the existing Euclidean RQ-VAE, so behaviour and curvature jointly alter the vectors, residuals, assignments, and encoder updates.
SPECIFICATION: For training item i, compute b_i=H(p(.|i))/log(max(2,d_i)), with p(j|i) proportional to c_ij+alpha over observed outgoing neighbors and c_ij counts of adjacent item pairs in train only; set b_i=0 when d_i=0. Set k_i=softplus(a_0+a_1*b_i)+k_min, curvature K_i=-k_i (initialize a_1>0; clamp k_i to [0.05,5]). Given encoder output u_i in R^d, map v_i=Exp^K_i_o([0,u_i]) onto the Lorentz hyperboloid, then z_i=Log^K_i_o(v_i) in the origin tangent space; feed z_i to the unchanged Euclidean residual quantizer and decoder. Optimize ordinary reconstruction/VQ losses end-to-end, including gradients through b_i-independent learnable curvature parameters (b_i is fixed). Use the same transformation in get_indices. Costs: precompute O(E_train) once and store one scalar per item; each epoch minibatch adds O(Bd) map operations, no pairwise item matrix. At 24 steps/epoch for 3000 epochs this is 72,000 minibatch passes; additional work is 72,000 Lorentz map evaluations per batch (linear in its item count and d), with no extra graph pass or Stage3 cost. The extra map may add a modest encoder-side overhead; measure wall-clock against baseline.
COST: Precomputation O(E_train), storage O(24556), plus O(Bd) Lorentz exp/log maps per optimizer step, no additional codebook-distance or graph computation. At the frozen scale this is 24*3000=72,000 training steps; total added arithmetic is O(72,000*B*d) map work (B is the existing step's item batch size), expected modest relative to the MLP and quantizer. Stage3 inference adds the same per-item map used for SID generation only, not recommender inference.
HYPOTHESIS: The mapping can distribute high-branching items into encoder representations with useful hierarchy/volume while retaining predictable-item compactness; keep only if fixed-seed Stage3 test Recall@10 exceeds 0.065 and beats the matched Euclidean and behaviour-off runs. Inspect per-item curvature, gradient norms, and SID changes only as diagnostics, not acceptance criteria.
RISKS: Entropy may mostly encode item popularity or sparse-count noise; item-conditioned curvature can become a shortcut or destabilize maps; the origin log-map can partly cancel curvature's benefit; Stage3 may prefer semantic reconstruction over transition branching. Tune alpha and curvature bounds on training behavior only, and use identical seeds/training budget for ablations.
BEHAVIOR SIGNAL: Per-item outgoing sequential-transition branching entropy, normalized to [0,1].
BEHAVIOR COMPUTATION: From train split only, count directed adjacent pairs c_ij across each user's chronologically ordered training interactions. For each source i, smooth its observed outgoing-neighbor distribution with alpha=0.1 pseudocount per observed neighbor, calculate Shannon entropy H_i, and normalize by log(max(2,d_i)); set zero for no observed successors. Compute once before RQ-VAE training; do not include validation/test histories or edges.
LEAKAGE BOUNDARY: Build the transition counts exclusively from the training split's interactions and freeze b_i before model fitting. Validation/test are used only for downstream evaluation and never for entropy computation, curvature input, parameter selection, SID assignment, or codebook initialization.
HYPERBOLIC OPERATOR: Lorentz-model exponential map and origin logarithmic map on constant negative curvature K_i=-k_i, where k_i=clip(softplus(a_0+a_1*b_i)+k_min,0.05,5.0). The operator is a genuine curved manifold map, not a named Euclidean distance.
HYPERBOLIC LOCATION: In the item encoder output path immediately before the first RQ quantization level; the transformed tangent representation becomes the input to all residual quantization levels and reconstruction loss.
COUPLING PATH: Training transition entropy b_i determines item-specific negative curvature k_i; k_i determines the Lorentz exp/log transformation of the encoder output; that transformed vector determines residuals, selected codes, quantization/reconstruction gradients, and ultimately the item's SID. Removing b_i fixes curvature; removing the curved map removes the behaviour-conditioned representation change.
COUPLING EQUATION: b_i=H_train(next|i)/log(max(2,d_i)); k_i=clip(softplus(a_0+a_1*b_i)+k_min,0.05,5); z_i=Log_o^{K_i}(Exp_o^{K_i}([0,f_theta(x_i)])); SID_i=RQ_Euclidean(z_i). The coupling is the explicit b_i -> K_i -> Log/Exp-mapped z_i path (the quantizer's Euclidean assignment distance itself is unchanged).
OBSERVABLES: On/off coupling should change encoder gradients and item latent vectors, and consequently potentially SID assignments; quantify changed-code fraction and transition-predictability from prefixes as diagnostics. Primary observable is Stage3 test Recall@10; require >0.065 and report its matched ablations.
ABLATION BEHAVIOR OFF: Keep Lorentz maps but set b_i=0 for every item, making curvature constant across items; train and evaluate with the same seed/budget.
ABLATION GEOMETRY OFF: Keep the same computed b_i and curvature head, but replace Lorentz Exp/Log with identity z_i=f_theta(x_i) (flat/Euclidean path); retain parameter-count controls if feasible.
ABLATION BOTH ON: Use train-only b_i, learned bounded k_i, and the Lorentz Exp/Log encoder path; train RQ-VAE, emit SIDs, then run the fixed Stage3 protocol and report test Recall@10.
SPEC EQUATIONS: For x_i, let u_i=f_theta(x_i). Compute (in float32) r_i=||u_i||, q_i=sqrt(k_i)*r_i, and Lorentz point v_i=(cosh(q_i)/sqrt(k_i), sinh(q_i)*u_i/(sqrt(k_i)*max(r_i,eps))) under signature (-,+,...,+). Compute tangent log vector z_i=(asinh(sqrt(k_i)*||v_i_spatial||)/(sqrt(k_i)*max(||v_i_spatial||,eps)))*v_i_spatial; feed z_i into the unchanged RQ-VAE. For numerical safety constrain q_i<=10 (scale u_i down before the map when needed), and use series limits near zero; alternatively implement standard tested Lorentz Exp/Log routines. Train with L=L_recon+L_RQ, backpropagating through maps and a_0,a_1; initialize a_1=0.1 and k near 1. At SID export, use the identical frozen encoder/map and deterministic argmin quantization.
SPEC INPUTS OUTPUTS: Inputs are the existing item embedding x_i, frozen train-only scalar b_i, encoder parameters theta, and trainable curvature scalars a_0,a_1. Output z_i in R^d, which is consumed by the existing RQ-VAE and yields the usual integer SID; no changes to Stage3 vocabulary format are required.
SAFEGUARDS: Compute maps and norms in float32 even under mixed precision; clamp k to [0.05,5], q to at most 10, use eps=1e-6 and stable small-radius Taylor limits (sinh(q)/q and asinh(q)/q); reject non-finite z_i and log curvature/clamp rates. Set b_i=0 for zero-degree items, avoid validation/test edges, and verify the K->0 identity limit in a unit test.
END IDEA
