IDEA: transition_tangent_warp
TITLE: Train a behaviour-conditioned hyperbolic tangent warp before residual quantization
MOTIVATION: Semantic embedding neighborhoods may not preserve which items are likely to follow one another; a recommender benefits when training successor relationships influence the geometry of the encoded items before the unchanged RQ assignment.
NOVELTY: This puts the behaviour-geometry coupling in the encoder's latent map, not in codeword distance, assignment weighting, prefix occupancy matching, or a separate behavioural loss. The same training transition-derived vector controls an exp/log-map warp that changes the latent vector presented to the ordinary Euclidean RQ-VAE.
CHANGE: Build a sparse directed transition profile for each training item, project it through a small learned map into a bounded tangent displacement, and combine that displacement with the encoder output by a Poincare exp-map/log-map round trip before ordinary residual quantization; train the map through the standard reconstruction-plus-quantization objective.
SPECIFICATION: Let c_ij be the count of consecutive training-only transitions i->j. For each i, form sparse normalized outgoing and incoming profiles a_i[j]=c_ij/(sum_l c_il+eps) and b_i[j]=c_ji/(sum_l c_li+eps), concatenate them, and apply a fixed-seed sparse random projection P to dimension d_b followed by a learned linear map W: u_i = rho*tanh(W P[a_i;b_i]), where rho bounds tangent norm. Given base encoder vector z_i in R^d, map z_i to the Poincare ball at curvature -c using x_i=exp_0^c(z_i); form y_i=MobiusAdd_c(x_i, exp_0^c(u_i)); return z'_i=log_0^c(y_i) to the unchanged Euclidean residual quantizer and decoder. Optimize ordinary reconstruction and VQ losses only; gradients through z'_i update encoder and W. Set u_i=0 for missing/unknown profiles.
COST: Precompute sparse transition profiles once in O(E_train) time and O(E_train) sparse storage; project per batch with sparse matrix multiplies. At 24 steps/epoch x 3000 epochs over 24556 items (about 1024 items/step), added batch work is O(nnz_batch*d_b + B*d_b*d + B*d) for profile projection, learned projection and Poincare maps, plus O(B*d) temporary vectors; no B-by-codebook curved distances and no extra user/item pair sampling. Expect a modest encoder-side overhead; measure actual epoch wall time against matched ablations.
HYPOTHESIS: Directed predecessor/successor context supplies an item-specific tangent correction that makes semantically similar but behaviorally distinct items more separable in the latent codes, while grouping items with compatible continuation context; this improves Stage3 test Recall@10 if the learned warp preserves useful semantic reconstruction. Observe latent displacement norms, SID changes conditioned on transition-profile similarity, and Stage3 test Recall@10; retain only if both-on exceeds 0.065 and both controls.
RISKS: The profile projection can encode popularity or sparse noise rather than transferable continuation structure; the encoder may cancel the warp, or reconstruction loss may overemphasize behaviour at the expense of content. Tune rho and regularize W using train-only diagnostics, not test feedback; include a profile-shuffling diagnostic if feasible.
BEHAVIOR SIGNAL: Per-item sparse directed predecessor and successor co-consumption profiles, representing which items users consume immediately before and after the item in training sequences.
BEHAVIOR COMPUTATION: Within train split only, group events by user, sort by timestamp, count adjacent ordered item pairs (i,j). Normalize each item's outgoing counts into a successor distribution and its incoming counts into a predecessor distribution; create a sparse concatenated row per item. Do not bridge split boundaries or count non-adjacent events.
LEAKAGE BOUNDARY: Derive profiles only from training interactions and freeze them before Stage2 SID construction. Validation/test events are not read for the profile, projection, map training, or code export; unseen IDs map to the zero profile, and Stage3 evaluation uses frozen SIDs/model.
HYPERBOLIC OPERATOR: Poincare-ball exp_0^c and log_0^c maps plus Mobius addition at fixed positive curvature magnitude c (sectional curvature -c).
HYPERBOLIC LOCATION: Between encoder output and the existing Euclidean RQ-VAE quantizer, where the training-profile-driven tangent vector is composed with the encoded point on the negatively curved ball and mapped back to tangent coordinates.
COUPLING PATH: Training-only directed counts -> sparse item profile -> learned tangent displacement u_i -> Poincare exp-map and Mobius addition with encoded point -> log-map latent z'_i -> ordinary RQ assignments and reconstruction/VQ gradients -> exported SIDs.
COUPLING EQUATION: z'_i = log_0^c(exp_0^c(z_i) ⊕_c exp_0^c( rho*tanh(WP[a_i;b_i]) )); the training behaviour profile determines the tangent displacement and the curved Mobius/exp-log operations determine how that displacement changes the encoder latent used for SIDs.
OBSERVABLES: Compare latent vectors, SID sequences, quantization/reconstruction gradients, and Stage3 test Recall@10; the coupled run should produce profile-dependent latent/SID changes and improve test_R@10 above 0.065 versus each control.
ABLATION BEHAVIOR OFF: Set all profiles and u_i to zero while retaining the Poincare maps and identical encoder, RQ-VAE, seeds and training budget; this isolates the contribution of training behaviour.
ABLATION GEOMETRY OFF: Keep the same training profiles and learned W, but replace exp/log/Mobius composition with Euclidean z'_i=z_i+u_i; retain all other settings to isolate curvature.
ABLATION BOTH ON: Use training-only profiles, learned bounded tangent displacement, and Poincare exp-map/Mobius-add/log-map composition; export the resulting SIDs and evaluate unchanged Stage3 test_R@10.
SPEC EQUATIONS: c_ij=sum_{u,t}1[i_t=i,i_{t+1}=j] over training sequences only. a_i[j]=c_ij/(sum_l c_il+eps), b_i[j]=c_ji/(sum_l c_li+eps). v_i=P[a_i;b_i], u_i=rho*tanh(Wv_i), z_i=Encoder(e_i). For curvature -c, lambda_x=2/(1-c||x||^2); exp_0^c(v)=tanh(sqrt(c)||v||)*v/(sqrt(c)||v||), log_0^c(x)=atanh(sqrt(c)||x||)*x/(sqrt(c)||x||), and x⊕_c y=((1+2c<x,y>+c||y||²)x+(1-c||x||²)y)/(1+2c<x,y>+c²||x||²||y||²). Then z'_i=log_0^c(exp_0^c(z_i)⊕_c exp_0^c(u_i)); apply existing Euclidean RQ-VAE to z'_i.
SPEC INPUTS OUTPUTS: Inputs are item embedding e_i, item ID, frozen sparse train-profile table, sparse projection P, learned W, rho and curvature c. Outputs are transformed latent z'_i for the existing RQ-VAE, which returns quantized vector, losses and SID tokens.
SAFEGUARDS: Use c>0 fixed and small (e.g. 0.1), clamp ball norms to (1-eps)/sqrt(c), clamp atanh arguments to [-1+eps,1-eps], use stable small-norm limits for exp/log, compute geometry in float32, bound u norm by rho (e.g. rho<=0.25), normalize count rows with eps, use deterministic sparse projection and zero profiles for unseen items, and monitor finite values, latent norms and reconstruction loss. Keep train/validation/test separation and identical seeds/configuration across ablations.
END IDEA
