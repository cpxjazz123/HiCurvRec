IDEA: prefix_successor_ball
TITLE: Prefix-conditioned successor barycentres for curved residual assignment
MOTIVATION: At the third token, items sharing the first two codes may still have competing next-item futures. A single global successor signal misses this local branching; the residual code should identify an item by its successor distribution conditional on its already-assigned prefix.
NOVELTY: Unlike first-level cohort anchoring or ordering an extension token by successor rank, this constructs training-only successor prototypes inside each (T1,T2) residual cell and uses their hyperbolic distance directly to select T2/T3 codes. The curve changes emitted residual codes, not just a side loss or code order.
CHANGE: Keep baseline Euclidean L1 quantization cheap. At L2/L3, assign each item's residual jointly against a candidate code using a Poincare distance to a learned successor-distribution prototype indexed by the current prefix and candidate residual code; blend that with residual reconstruction distance.
SPECIFICATION: Precompute sparse train-only transition distributions p_j(k)=(N_{jk}+alpha*pi(k))/(N_j+alpha), with pi the train item frequency distribution. During each hard-quantization refresh, form q_i=log(p_i+eps) projected to d dimensions by a fixed seeded sparse projection. For candidate code c at level l in {2,3}, use prefix a_l=(c1) for L2 and a_l=(c1,c2) for L3, and maintain prototype u_{a_l,l,c}=normalized EMA mean of q_j for training items j with prefix_l(j)=a_l and code_l(j)=c; shrink to the global level prototype with weight n/(n+tau). Cost for item i: J_l(i,c)=||r_i-e_{l,c}||^2 + lambda_l*s_i*d^2_{P,-1}(Exp_0^c(Aq_i),Exp_0^c(u_{a_l,l,c})); assign argmin over the existing codebook. Implement actual curvature -c_curv (initial c_curv=1, fixed); do not alter code counts or L1. Use current-epoch assignments, then EMA prototypes, for the next refresh.
COST: One sparse train transition pass O(E_train), one fixed projection per item, and refresh-time prototype accumulation O(24556*d); per optimizer step only O(B*K*d) for L2/L3 candidate distances (K=256, d small) if refreshed, or none between refreshes. Batch-vectorized Poincare distance should keep one-epoch smoke near 0.13 s/epoch; refresh at e.g. every 10 epochs amortizes overhead, and 3000 epochs means 300 refreshes. No Stage3 cost.
HYPOTHESIS: Within each fixed (T1,T2) cell, successor profiles have a small number of stable modes that correlate with the gold third code. Keep only if both-on lifts teacher-forced T3 top-1 materially above 0.53 toward 0.7, does not sacrifice T4 top-1, and Stage3 test_R@10 exceeds 0.065 under the frozen protocol.
RISKS: Prefix cells may be sparse, noisy, or have multimodal futures too numerous for 256 codes; EMA prototype lag can oscillate assignments. Transition profiles may encode popularity rather than useful conditional intent; this can reduce L1 Hard ER or overfit train histories.
BEHAVIOR SIGNAL: Directed item successor distributions, conditioned by the currently assigned prefix.
BEHAVIOR COMPUTATION: Count adjacent (i,j) pairs in training histories only, directionally; apply additive smoothing toward train-only item popularity, then take log probabilities and fixed-project. Prefix-specific prototype means aggregate these vectors over items assigned the matching T1/T2 and residual code.
LEAKAGE BOUNDARY: Build transition counts only from Stage2 training histories; validation/test histories and their interactions are never loaded by the SID builder. Prefix prototypes and assignments are fitted only on the 24,556 training items; validation/test are transformed using frozen codebooks and prototypes.
HYPERBOLIC OPERATOR: Poincare-ball exponential map at origin and squared geodesic distance d^2_{-c}(x,y)=4/c*atanh^2(sqrt(c)||(-x)⊕y||), fixed negative curvature -c, c=1.
HYPERBOLIC LOCATION: In the L2 and L3 hard residual assignment cost, comparing each item's embedded successor profile to candidate prototypes for its current prefix; not at L1 or L4.
COUPLING PATH: Train successor counts -> smoothed profile -> prefix/candidate prototype -> Poincare distance inside L2/L3 argmin -> emitted residual code. Disabling counts or replacing the ball distance changes that argmin and SID.
COUPLING EQUATION: c*_l(i)=argmin_c [||r_i-e_{l,c}||²+lambda_l*s_i*d²_{P,-1}(Exp^1_0(A log(p_i+eps)),Exp^1_0(u_{a_l,l,c}))], l=2,3; a_2=(c1), a_3=(c1,c2), s_i=min(1,log(1+N_i)/s0).
OBSERVABLES: Record L1 Hard ER on the canonical 52,855 pairs with ten fixed negatives (predicted flat or slightly improved); gold-prefix survival at depths 1-4 (L1 near baseline, L2/L3 higher, L4 maintained); teacher-forced top-1 T3 (target >0.53, ideally 0.7-0.8) and T4 (maintained); Stage 3 test_R@10 target >0.065. Compare all three arms with same seed/protocol.
ABLATION BEHAVIOR OFF: Set lambda_l=0, retaining the identical Euclidean residual reconstruction assignment and codebooks; measure all required observables.
ABLATION GEOMETRY OFF: Keep the same train successor profiles, prefix prototypes, shrinkage and lambda, but replace d^2_{P,-1}(Exp_0(x),Exp_0(y)) with ||x-y||^2 in the same projected tangent vectors; measure all required observables.
ABLATION BOTH ON: Use train-only successor profiles, prefix-conditioned prototypes and the stated Poincare assignment at both L2 and L3; retain baseline L1 and deterministic L4; measure all required observables.
SPEC EQUATIONS: N_ij=count_train(i followed by j); p_i(j)=(N_ij+alpha*pi_j)/(sum_k N_ik+alpha); z_i=A log(p_i+eps); u_{a_l,l,c}=EMA(shrink(mean{z_j: prefix_l(j)=a_l, code_l(j)=c}, global_u_l,c, tau)); x_i=Exp^c_0(z_i), v=Exp^c_0(u); d_P=2/sqrt(c)*atanh(sqrt(c)||(-x)⊕_c v||); J_l(i,c)=||r_i-e_l,c||²+lambda_l*s_i*d_P²; assign c=argmin J. Recompute residual from the existing RQ-VAE update rule after each selected code.
SPEC INPUTS OUTPUTS: Inputs are training-only directed counts, train item popularity, item embeddings/residuals, hard L1/L2 prefix assignments, existing 256-entry L2/L3 codebooks, projection A and smoothing/shrinkage hyperparameters. Outputs are updated prefix-conditioned prototypes, hard L2/L3 assignments, and four-token SIDs with existing deterministic collision extension.
SAFEGUARDS: Clamp p>=1e-8; use sparse top-M successors plus a residual tail bucket; normalize projection scale; cap ||x|| at (1-1e-5)/sqrt(c); clamp atanh argument to 1-1e-6; use float32 distances, prototype count threshold plus global shrinkage, stop-gradient through hard argmin, and fixed seeded A. Freeze curvature and lambda before Stage3; no test-time tuning.
END IDEA

IDEA: successor_hyperbolic_margin
TITLE: Curved triplet margins on level-3 residual codes
MOTIVATION: A level-3 code should separate items whose training successors diverge even when their first two semantic tokens match; the failure is not merely assigning semantic labels but placing the right residual code boundary between future-behaviour neighborhoods.
NOVELTY: Rather than successor prototype attraction or a geodesically warped residual update, this directly trains level-3 codeword locations with a prefix-local, directed successor triplet margin evaluated in hyperbolic geometry. The triplet determines hard assignment through the updated codebook and thus changes the emitted T3 SID.
CHANGE: Within each fixed (T1,T2) cell, sample positive item pairs with similar train-only successor distributions and negatives with dissimilar distributions. Optimize a Poincare triplet ranking loss on the L3 residual and codeword representations, then perform ordinary hard nearest-code assignment using Poincare distance at both L2 and L3 so the learned curved locations govern actual residual code selection.
SPECIFICATION: For each training item i compute sparse p_i over its next items from directed train counts. In each batch, sample positive j from the same current (T1,T2) cell with JS(p_i,p_j)<a and negative k in that cell with JS(p_i,p_k)>b (fallback to nearest valid global pair if cell too small). Map normalized residual vectors h_i=Proj_l(r_i) and L2/L3 codewords e_l,c via Exp_0 into Poincare ball curvature -1. Minimize L_trip=softplus(dP(h_i,h_j)-dP(h_i,h_k)+m) weighted by confidence w_i=min(1,log(1+outcount_i)/s0); backpropagate to projection/codewords alongside baseline commitment/reconstruction losses. At L2 and L3 hard assignment choose argmin_c ||r_i-e_l,c||² + gamma_l*dP(Exp_0(Proj_l(r_i)),Exp_0(Proj_l(e_l,c)))²; choose gamma_l>0 and hold fixed. L1 remains baseline.
COST: Precompute sparse successor top-M and sampled positive/negative pair lists once in O(E_train); per step add B triplets and at most 2*B*256 vectorized Poincare distances for L2/L3 assignment. Expected incremental cost <10% of baseline (under 0.13 s/epoch target) with d<=64 and pair sampling cached; no full all-pairs distance matrix. Across 24 steps/epoch and 3000 epochs, fixed pair sampling and batched codeword distances avoid epoch-scale graph traversal.
HYPOTHESIS: Items sharing a prefix but having distinct likely futures need geometrically separable T3 residual regions; the coupled ranking and curved assignment should raise T3 top-1 above 0.53 toward 0.7 while retaining T4 predictability and yield Stage3 test_R@10>0.065. Keep only if geometry-off and behavior-off fail to match both-on.
RISKS: Current prefix partition may not provide enough positive/negative triplets; noisy/sparse successor distributions create false supervision. Contrastive codebook updates may damage reconstruction, increase L1 Hard ER, or create code collapse; the geometric ranking may add no value over the Euclidean triplet.
BEHAVIOR SIGNAL: Directed successor-distribution similarity for item pairs, computed only from training histories.
BEHAVIOR COMPUTATION: Count ordered adjacent transitions in training histories; smooth each item's next-item distribution with train-only popularity. For sampled candidates in the same current (T1,T2) cell calculate Jensen-Shannon divergence between the sparse distributions; low divergence defines positive, high divergence defines negative.
LEAKAGE BOUNDARY: All transition distributions, item frequencies, triplets, and codebook updates derive exclusively from Stage2 training histories/items. No validation/test interactions or labels enter pair construction, assignment, or SID export; those splits are touched only by the frozen Stage3 evaluation.
HYPERBOLIC OPERATOR: Poincare Exp map and geodesic distance at fixed curvature -1, used in a triplet margin and directly in residual hard assignment.
HYPERBOLIC LOCATION: Trainable L3 residual codebook geometry via triplet gradients; actual hard nearest-code assignment uses the same curved distance at L2 and L3. L1 is unchanged and L4 remains deterministic collision extension.
COUPLING PATH: Train transition counts -> JS-based positive/negative triplet choice -> Poincare triplet gradient updates residual codewords -> Poincare L2/L3 assignment -> emitted SID. Without behaviour, pair selection is random; without geometry, both triplet distances and assignment metric become Euclidean, changing codeword updates and assignments.
COUPLING EQUATION: L_trip=w_i*softplus(d_{P,-1}(h_i,h_j)-d_{P,-1}(h_i,h_k)+m); (c2*,c3*)=argmin_{c2,c3} sum_{l=2,3}[||r_i-e_l,c||²+gamma_l*d²_{P,-1}(Exp_0(Proj_l(r_i)),Exp_0(Proj_l(e_l,c)))], where (j,k) are selected by train-only JS successor similarity.
OBSERVABLES: Report canonical L1 Hard ER on 52,855 fixed-negative pairs (predict near baseline; flag degradation), gold-prefix survival at depths 1-4 (expect gains chiefly at depths 2-3 without hurting depth 4), teacher-forced top-1 T3 (target >0.53 toward 0.7-0.8) and T4 (maintained), and Stage 3 test_R@10 target >0.065. Compare behavior-off, geometry-off and both-on.
ABLATION BEHAVIOR OFF: Keep curved losses/assignment but sample matched-prefix positive and negative items randomly, independent of successor distributions; same training schedule and metrics.
ABLATION GEOMETRY OFF: Keep exactly the successor-selected triplets but replace Poincare distances in triplet loss and L2/L3 assignment with Euclidean distances; same schedule and metrics.
ABLATION BOTH ON: Select triplets from train-only successor JS divergence and use curvature -1 Poincare triplet and assignment at L2/L3; baseline L1, deterministic L4; same frozen Stage3 evaluation.
SPEC EQUATIONS: Build p_i from train transitions; positive j: JS(p_i,p_j)<a and same prefix; negative k: JS(p_i,p_k)>b and same prefix. h=Exp^1_0(Proj(r)), q=Exp^1_0(Proj(e)); L=baseline_RQVAE + eta*w_i*softplus(dP(h_i,h_j)-dP(h_i,h_k)+m). Hard assignment per l=2,3: c*=argmin_c ||r_i-e_l,c||²+gamma_l*dP(Exp(Proj(r_i)),Exp(Proj(e_l,c)))². T3 code remains a normal residual code, not an added token.
SPEC INPUTS OUTPUTS: Inputs are train-only directed transition counts, train popularity, current prefix assignments, residual embeddings and the existing L2/L3 codebooks. Outputs are cached behavior-labelled triplets, updated codebook/projection parameters, hard residual assignments and fixed-width SIDs.
SAFEGUARDS: Sparse top-M distributions with tail mass; smooth with alpha>=1e-3; skip items with too few outgoing counts; impose a minimum triplet cell population and deterministic seeded fallback; clip gradients and keep baseline commitment loss; project ball vectors to norm <=1-1e-5, clamp atanh argument, use stable float32 distances; monitor code occupancy and reject if T3 collapse worsens. Hyperparameters fixed before Stage3, no validation/test tuning.
END IDEA
