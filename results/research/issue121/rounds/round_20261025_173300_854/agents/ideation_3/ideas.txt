IDEA: interest_transport_hyp
TITLE: Transport user-interest mixtures into hyperbolic prefix assignments
MOTIVATION: An item's single content vector can erase the fact that distinct training users consume it from different interest contexts; a useful SID prefix should group items that serve similar mixtures of user interests, not merely items with similar embeddings.
NOVELTY: This uses user-level interest mixtures as a per-item soft assignment prior and combines that prior multiplicatively with hyperbolic code likelihoods in a balanced entropic assignment. It does not move each latent by its transition neighbors, match prefix occupancy to continuation mass, or use a behavior-only suffix.
CHANGE: From training-only user histories, infer a small fixed set of user-interest components and represent each item by its smoothed distribution over those components. At each RQ level, use that distribution to modulate the hyperbolic soft code assignment before a minibatch Sinkhorn normalization; the resulting responsibilities drive codebook updates and straight-through hard SID choices.
SPECIFICATION: Let q_u be the normalized counts of user's items in K-means clusters fit to training-user history vectors (history vector is the mean of frozen item embeddings); freeze those clusters. Define b_ik=normalized sum over training events (u,i) of q_uk, with Dirichlet smoothing. For latent z_i and code c_lj, compute p_ij ∝ exp(-d_{-c}(exp_o(z_i),exp_o(c_lj))²/τ + γ log(ε + Σ_k b_ik A_ljk)), where A_ljk is a learned soft compatibility from interest component k to code j, row-softmaxed. Sinkhorn-normalize p over the minibatch to uniform code capacity, use p for the soft quantization/commitment update, and retain argmin of the same combined log-score for exported digits. Initialize A near uniform and γ small; train with the baseline reconstruction and VQ losses.
COST: One train-history clustering pass O(U*d*Iters) and event-to-mixture accumulation O(E_train*K) once; per tokenizer step adds O(B*K*C + B*C*iterations) for interest-code compatibility and Sinkhorn, alongside existing hyperbolic distance work (B items, C codes at the active level). At 24,556 items, 24 steps/epoch, 3,000 epochs, the added compatibility work is about 1,768,032,000* K*C multiply-adds if recomputed for every item; cache b_i and A, and minibatch-only cost is 72,000 Sinkhorn calls of O(B*C*iterations), likely 5–20% wall-clock depending on B,C. No Stage3 inference cost is required after hard SIDs are frozen.
HYPOTHESIS: The item-interest mixture contains stable multi-user context information that content reconstruction misses; both-on should alter early-level SID groupings by matching items with similar interest mixtures, improve next-item separability and produce Stage3 test Recall@10 above 0.065. Keep only if it beats frozen baseline and both controls under the same validation selection and seeds.
RISKS: User clusters may reflect popularity or noisy short histories; smoothing may wash out niche interests; minibatch balancing may impose artificial uniform capacity; compatibility parameters can collapse to a dominant component; Stage3 users may not share the training interest mixture distribution.
BEHAVIOR SIGNAL: Per-item soft mixture over latent user-interest components, computed only from which items training-split users consumed.
BEHAVIOR COMPUTATION: For each training user, average the frozen embeddings of that user's training interactions (deduplicate or cap repeats); fit K-means with K=16 on these history vectors using training users only. Assign each user to a soft distribution q_u by softmax of negative squared distance to the fitted centroids with temperature τ_u. For each item i, b_ik ∝ ε + Σ_{training events (u,i)} q_uk; normalize b_i to sum to one. No chronological adjacency is used.
LEAKAGE BOUNDARY: Build user histories, centroids, soft assignments, b_i and compatibility initialization exclusively from the training interaction split; freeze centroids and b_i before SID fitting. Validation/test interactions do not contribute to user clusters, code assignments, optimization, or SID export; unseen items use the smoothed uniform b_i.
HYPERBOLIC OPERATOR: Lorentz hyperboloid exponential map at the origin and geodesic distance d_{-c}(X,Y)=acosh(max(1,-c<X,Y>_L))/sqrt(c), fixed curvature -c with c=0.5.
HYPERBOLIC LOCATION: Inside each RQ level's soft assignment logits and consequent Sinkhorn responsibilities during Stage2 training, before choosing the code digit and updating the residual.
COUPLING PATH: Training user-interest mixtures b_i and learned compatibility A determine a per-item prior over code choices; its log prior is added to Lorentz distance logits, changing the balanced responsibilities, codebook gradients and hard prefix digits. Removing b_i or replacing Lorentz distance changes this same assignment computation.
COUPLING EQUATION: s_{ij}= -d_{-c}(exp_o(z_i^l),exp_o(c_j^l))^2/τ + γ log(ε + b_i^T A_l[:,j]); P_l=Sinkhorn(exp(s)); z_i^l^2_{Lorentz} and b_i^T A_l[:,j] jointly determine P_l and the code update.
OBSERVABLES: Measure per-level responsibility and hard-digit shifts, change in codebook/encoder gradients, similarity between items sharing prefixes versus b_i similarity, train-only held-out transition predictability by prefix, and Stage3 test Recall@10; report the behavior-off, geometry-off and both-on runs.
ABLATION BEHAVIOR OFF: Replace every b_i by the uniform K-vector while retaining Lorentz distances, compatibility parameterization, Sinkhorn, model size and training schedule; alternatively fix A contribution to zero log-prior. This tests whether user-interest information changes assignments.
ABLATION GEOMETRY OFF: Keep b_i, A and Sinkhorn exactly unchanged but replace exp_o and Lorentz geodesic squared distance with matched-dimensional Euclidean squared distance; retain the same temperature, logits, losses and seeds.
ABLATION BOTH ON: Use training-only soft user-interest mixtures, learned interest-code compatibility, Lorentz distances and identical minibatch Sinkhorn normalization; export hard RQ digits and evaluate the unchanged Stage3 protocol.
SPEC EQUATIONS: History h_u=mean_{i in train(u)} e_i; fit centroids μ_k on {h_u}; q_uk=softmax_k(-||h_u-μ_k||²/τ_u). b_ik=(ε+Σ_{(u,i) in train}q_uk)/(Kε+n_i), then normalize. For level l, X_i=exp_o^{-c}(r_i^l), C_j=exp_o^{-c}(c_lj), A_l[:,j]=softmax_k(a_lkj). s_ij=-d_{-c}(X_i,C_j)^2/τ+γ log(ε+b_i^T A_l[:,j]); P=Sinkhorn(exp(s/τ_s)) with uniform row and column marginals. Quantized residual is Σ_j P_ij c_lj for training gradient; forward SID digit is argmax_j s_ij, followed by the baseline residual update. Keep γ modest (e.g. 0.1), K=16, Sinkhorn iterations=5; use the baseline reconstruction/commitment objective and straight-through path.
SPEC INPUTS OUTPUTS: Inputs: training user-item events, frozen item embeddings, Stage2 encoder residuals and codebooks, c, τ, τ_s, γ, and K=16. Outputs: frozen per-item interest mixtures b_i, trainable compatibility matrices A_l, differentiable level-wise responsibilities, updated codebooks/encoder, and hard SID digits.
SAFEGUARDS: Use float32/64 for maps and Sinkhorn; project Lorentz points back to the hyperboloid after updates; clamp acosh arguments to at least 1+ε and tangent norms before exp maps; stabilize log(b_i^T A) with ε; smooth rare items with a uniform Dirichlet prior; cap γ and logits, subtract row maxima before exponentiating, clamp Sinkhorn kernel, and fall back to row-softmax if nonfinite. Keep deterministic clustering and tie-breaking, monitor assignment entropy, code usage and gradient norms; ensure all clustering inputs are train-only.
END IDEA
