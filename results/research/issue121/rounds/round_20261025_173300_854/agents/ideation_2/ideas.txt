IDEA: transition_branch_hyperbolic_prototypes
TITLE: Allocate shared SID prefixes by hyperbolic transition-branch prototypes
MOTIVATION: The Stage 2 reconstruction objective can preserve item vectors without organizing items into groups that are useful as next-item candidates. Items reached from the same predecessor often belong to distinct user-interest branches; encoding these branches into early SID assignments may make the generative recommender's prefix tokens more predictive.
NOVELTY: This changes the first-level grouping objective using predecessor-conditioned transition distributions and hyperbolic prototype geometry. It is not a shell-calibrated per-item Poincare assignment, Busemann gate, or tangent-space warp: behavior changes which examples attract a prototype, and curved geometry is inside that same assignment score.
CHANGE: Before RQ-VAE training, compute each training item’s sparse distribution over its most frequent training-only successor items. During the first residual-quantizer stage, combine ordinary item-to-code distance with a hyperbolic distance from the item's transition-distribution embedding to a trainable prototype for each first-level code; use the resulting joint score for hard code assignment and reconstruction gradients.
SPECIFICATION: Let X be the items and T_ij be counts of adjacent (i,j) events in training sequences only. Row-normalize with additive smoothing over observed outgoing neighbors to obtain p_i(j). Map each successor item j to a trainable Lorentz-hyperboloid point y_j and each first-level code k to prototype c_k, both on curvature -κ (κ=1 initially). For each item form q_i = normalize(Σ_j p_i(j) log_o(y_j)), map q_i to the hyperboloid by exp_o, and set s_ik = ||z_i-e_k||² + λ d_L(exp_o(q_i), c_k)². Assign a_i=argmin_k s_ik; train encoder, Euclidean code vectors, y_j and c_k with the usual RQ-VAE reconstruction/commitment terms plus λ times selected hyperbolic term, using straight-through assignments. Normalize Lorentz points after updates and keep them within a bounded radius. At inference/export only the resulting standard discrete RQ-VAE codes are used.
COST: Precompute sparse transition rows once in O(E_train); cache the q_i vectors. Per training step at the frozen scale of 24,556 items and 24 steps/epoch, score the current minibatch against K first-level prototypes, adding O(B*K*d) Lorentz distance arithmetic (typically a small constant-factor overhead over the first-stage assignment), with no all-pairs item calculation; 72,000 optimizer steps total over 3,000 epochs. Expect roughly 10–30% Stage 2 wall-clock overhead depending on batch size and K, plus one-time sparse preprocessing.
HYPOTHESIS: For items whose outgoing training transitions split into coherent successor branches, the joint score will place items with similar next-item opportunities under shared early SID prefixes while keeping semantic reconstruction adequate. Keep only if behavior-and-geometry-on improves Stage 3 test Recall@10 over the frozen 0.063354 baseline and both ablations, with the target exceeding 0.065; inspect first-level prefix transition predictability as a diagnostic, not as the admission criterion.
RISKS: Sparse or noisy outgoing histories may make q_i unreliable; popularity-dominated successors can collapse branches; the hyperbolic term can dominate reconstruction or Lorentz optimization can become unstable. Tune λ on training-only diagnostics or fixed predeclared values, never test Recall.
BEHAVIOR SIGNAL: Directed item-to-next-item transition distributions, representing each item's observed successor branches.
BEHAVIOR COMPUTATION: From the Stage 2 training split only, count adjacent item pairs in each user's temporally ordered training sequence, optionally weighting each pair by inverse square root of its predecessor frequency; retain the top 32 successors per source, add ε=1e-4 smoothing to retained edges, and row-normalize. Do not form edges across split boundaries.
LEAKAGE BOUNDARY: Build and freeze T and p_i strictly from training interactions before SID training. Validation/test events are not read by preprocessing, prototype fitting, checkpoint selection, or code assignment; validation/test is used only by the separate Stage 3 evaluation protocol.
HYPERBOLIC OPERATOR: Lorentz-model squared geodesic distance d_L²(u,v)=κ⁻¹ arcosh²(-κ⟨u,v⟩_L), with trainable curvature fixed at κ=1 (negative sectional curvature -1); exp_o and log_o are the Lorentz/hyperbolic maps at the origin.
HYPERBOLIC LOCATION: In first-level RQ-VAE code assignment and its selected-code training loss, where successor-distribution embeddings and code prototypes are compared before the SID prefix is emitted.
COUPLING PATH: Training transitions define p_i and hence curved item coordinate h_i=exp_o(Σ_j p_i(j)log_o(y_j)); that coordinate is compared to each hyperbolic code prototype to change first-level assignment and update both prototypes and successor embeddings. Removing transitions makes h_i item-independent/uninformative; replacing Lorentz distance/maps with Euclidean ones removes the curved allocation geometry.
COUPLING EQUATION: h_i = exp_o(Σ_j p_i(j) log_o(y_j)); a_i = argmin_k [||z_i-e_k||² + λ d_L(h_i,c_k)²], where p_i is the behavior term and d_L is the curved term; L = L_RQ + λ d_L(h_i,c_{a_i})².
OBSERVABLES: The first SID token assignments and their member-item successor distributions should change; prefix-conditioned next-item predictability should rise on held-out training interactions, and the decisive observable is Stage 3 test Recall@10 relative to 0.063354 and the ablations.
ABLATION BEHAVIOR OFF: Set p_i(j) to the same fixed prior distribution for every item (equivalently disable transition-derived q_i), retaining Lorentz prototype distances and identical training budget; this isolates the contribution of user behavior.
ABLATION GEOMETRY OFF: Keep p_i and the identical coupling path, but replace exp/log/Lorentz geodesic distance with Euclidean q_i and ||q_i-c_k||²; this isolates curved geometry.
ABLATION BOTH ON: Use training-only p_i, hyperbolic maps, Lorentz distance, joint assignment score, and the same RQ-VAE schedule; evaluate Stage 3 Recall@10 and compare all runs under the frozen protocol.
SPEC EQUATIONS: Given sparse T, p_ij=(T_ij+ε)/(Σ_{r∈Top32(i)}T_ir+32ε) for j in Top32(i). Compute v_i=Σ_j p_ij log_o(y_j), h_i=exp_o(v_i). For first quantizer output z_i and codes e_k,c_k, score s_ik=||z_i-e_k||²+λ d_L(h_i,c_k)²; choose a_i=argmin_k s_ik, use straight-through one-hot(a_i), and optimize baseline RQ-VAE loss + λ mean_i d_L(h_i,c_{a_i})². Update y,c by backprop; export ordinary quantizer indices as SID prefix.
SPEC INPUTS OUTPUTS: Inputs are ordered training-only user item sequences, Stage 2 item embeddings z_i, first-level Euclidean code vectors e_k, trainable Lorentz successor vectors y_j and code prototypes c_k, and λ. Outputs are first-level discrete assignments a_i, gradients for RQ-VAE and hyperbolic parameters, and ultimately standard multi-level SIDs.
SAFEGUARDS: Compute Lorentz products in float32 or higher; clamp -κ⟨u,v⟩_L to at least 1+1e-6 before arcosh; clamp tangent norms before exp/log; project points onto the hyperboloid after each update and clip their spatial norm/radius; use ε-smoothed sparse rows and a zero/prior fallback for items with no outgoing training edge; normalize loss terms and cap λ (e.g. start at 0.01); check finite loss/gradients and fall back to Euclidean-only assignment for invalid rows.
END IDEA
