IDEA: MIXCURV-FIBRE-RQ
TITLE: Behaviour-gated mixed-curvature product codebook: each item is quantized under a Poincare factor or a spherical factor according to how tree-like its training transition neighbourhood is
MOTIVATION: A single negative-curvature SID model assumes the item transition graph is a tree: one radial "is-a / sequel-of" depth plus an angular sector. Real consumption is a mixture. Sequel and attribute chains are tree-like, but repeat consumption, substitutes and mutually linked co-consumption form short cycles, and a Poincare ball can only represent a cycle by spending radial depth, which pushes cyclically consumed items onto the boundary where the metric is numerically hostile and where their prefixes collide with unrelated leaf items. The result is SIDs whose first tokens mix two incompatible kinds of neighbourhood, so the Stage 3 generator sees a prefix whose next-token distribution is a superposition of a hierarchy move and a lateral move, which is exactly the regime where prefix prediction degrades. The proposal gives each item its own curvature mixture, measured from its own training transitions, so the partition can be hierarchical where the behaviour is hierarchical and lateral where the behaviour is lateral.
NOVELTY: Earlier mechanisms here either weight/diffuse the assignment mass (cocond-markov-poincare-ot), place a hierarchy in one negative-curvature latent (BRANCHCURV-SID, KAPPA_BRANCH, GEO-SHELL-RQ, CURVCELL-SID, SUCCFAN-CURV-RQ), transport successor directions in the tangent space (fork-angle-transport, fork-angular-barycenter, SUCC-TAN-RQ), use geodesic charts/anchors, or use a Lorentz cone. None uses a positive-curvature factor at all, none uses a product of two manifolds of opposite curvature, and none makes a measured per-item behaviour statistic choose the metric an item is quantized under. Here the behaviour statistic is not a weight on a distance and not a target shift: it is the mixing coordinate between a hyperbolic and a spherical metric, so removing it collapses to an unweighted product metric and removing curvature collapses to a plain weighted Euclidean quantizer.
CHANGE: The RQ-VAE codebook stops being a set of vectors in one Euclidean (or one Poincare) space and becomes a set of product-manifold points (a ball point, a sphere point) per level, with each item's assignment distance being a behaviour-weighted combination of the Poincare distance in the first factor and the spherical geodesic distance in the second. The same behaviour weight also enters the Frechet/Karcher codebook estimator, so the per-item tree-likeness statistic changes both which code an item gets and where the code sits.
SPECIFICATION: Precompute once on the Stage-2 training sequences only. Add a directed edge u_t -> u_{t+1} for every consecutive pair inside every training sequence. For item i let N_i be its out-neighbour set, k_i = |N_i|, and c_i the number of ordered pairs (a,b) in N_i x N_i with a != b and an edge a -> b; C_i = c_i / (k_i (k_i - 1)) if k_i >= 2 else 0 (this is the directed local clustering coefficient, i.e. how much i's successors feed each other = how cyclic/lateral rather than tree-like i's consumption role is). Define the tree-likeness weight g_i = clip(1 - C_i, 0.1, 0.9); if k_i < 5 set g_i = 0.5. The 0.1/0.9 clip and the 0.5 low-degree prior are fixed documented defaults, not tuned. At every RQ level l in 1..3 the encoder output z in R^d is split into z_H in R^{d_H} (d_H = ceil(d/2)) and z_S in R^{d_S} (d_S = d - d_H); the running reconstruction zhat starts at 0; p = exp0^{k_H}(zhat_H) is a Poincare ball point and q = R_S * zhat_S/||zhat_S|| is a point on the sphere of radius R_S = 1/sqrt(k_S); codebook entry k of level l is (A_lk, B_lk) with ||B_lk|| = R_S; the assignment uses D_ik = sqrt( g_i * dtil_H(p, A_lk)^2 + (1 - g_i) * dtil_S(q, B_lk)^2 ) with both factor distances normalised by their own derived maximum so that g_i is a genuine mixing coordinate; the straight-through code is the baseline's, with the baseline temperature reused unchanged; after choosing k*, zhat_H += log0^{k_H}(A_lk*) and zhat_S += B_lk* - q_base where q_base is the unnormalised zhat_S, i.e. the spherical factor advances by the chord to the chosen sphere point while the hyperbolic factor advances by the tangent image of the chosen ball point; the decoder and the commitment loss see zhat exactly as in the baseline. k_H and k_S are trainable via k = softplus(k_raw) + 1e-3, initialised at k_H = k_S = 1.0 (unit curvature, documented default). Codebook entries are updated by one Karcher/Frechet step per level with the same g_i: A_lk <- exp0^{k_H}( sum_i s_ik g_i log0^{k_H}(p_i) / sum_i s_ik g_i ), B_lk <- R_S * normalise( sum_i s_ik (1 - g_i) q_i ), where s_ik is the soft assignment mass of item i to code k.
COST: No new parameters of consequence (3 x 256 x d product codebook points, plus the 24556-vector g). One-time graph pass over the training transitions, O(E) with E = number of consecutive pairs (order 10^6), a few seconds and a 24556-element output. Per step at the frozen scale only 24556/24 ~= 1023 items are quantized against 3 x 256 codes, i.e. ~7.9e5 product distances per step, each costing one arcosh plus one arccos over d-dimension inner products; this is roughly 3-5x the baseline Euclidean squared-distance kernel, which is itself a sub-millisecond, launch-bound slice of a Stage-2 step, so the expected per-step overhead is well under 1% of a Stage-2 step and under 2-3% of total wall clock over 3000 x 24 = 72000 steps. Memory overhead is negligible. No sweep, no extra seed, no extra arm: one training run.
HYPOTHESIS: If per-item behaviour tree-likeness is a real signal, then items whose training transitions are strongly cyclic are currently being forced into a hierarchy their behaviour does not have, and giving them a spherical fibre should (a) reduce prefix collisions between behaviourally distinct items in the tail, (b) lower the Stage 3 generator's cross-entropy on tokens 2 and 3 relative to token 1, and (c) raise Stage 3 test recall@10 above 0.065 in the single run. It is worth keeping if and only if the run both beats 0.065 and shows level-1 token usage that tracks the behaviour communities rather than collapsing onto a few radial shells.
RISKS: C_i is noisy for low-degree items, which are the majority of the long tail, so g_i may be near its 0.5 prior for most items and the mechanism may act only on the head; the spherical factor may simply add an uninformative rotational degree of freedom that the decoder ignores, in which case tokens 2-3 get noisier; the two curvature scales interact with the straight-through temperature, and although the temperature is inherited unchanged, a badly conditioned initial ball radius can make the arcosh term dominate early; and a gain could come from the extra geometry with zero contribution from behaviour, which the diagnostics must expose rather than the run hiding.
BEHAVIOR SIGNAL: Directed item transitions from the Stage-2 training sequences only, reduced to a per-item directed local clustering coefficient (cycle/lateral mass among an item's own successors).
BEHAVIOR COMPUTATION: From every Stage-2 training sequence, count edges u_t -> u_{t+1}; for each item i collect its out-neighbour set N_i and count edges among N_i; C_i = c_i/(k_i(k_i-1)); g_i = clip(1 - C_i, 0.1, 0.9), with g_i = 0.5 when k_i < 5. Computed once before Stage 2 starts and frozen for all 3000 epochs.
LEAKAGE BOUNDARY: The graph is built only from the training split sequences that the RQ-VAE is fitted on; validation and test sequences are never read, and no Stage-3 statistics (no prefix counts, no token frequencies, no popularity from the evaluation period) enter g_i, the codebooks or the curvature. g_i is a deterministic function of training transitions frozen before the first gradient step, so no validation or test interaction can influence an SID.
HYPERBOLIC OPERATOR: A trainable mixed-curvature product: Poincare ball of curvature k_H < 0 (initialised at -1) with the arcosh distance and exp0/log0 maps, multiplied with a sphere of curvature k_S > 0 (initialised at +1) with the arccos geodesic distance; both factor distances are renormalised by their own derived maximum.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer, simultaneously in (i) the per-level nearest-code assignment metric and (ii) the Frechet/Karcher update of every codebook entry, i.e. in the core of Stage 2, not in an auxiliary loss.
COUPLING PATH: g_i is computed from training transitions, then multiplies the squared normalised Poincare distance and its complement multiplies the squared normalised spherical distance, and the same g_i reappears as the weight of the Karcher step that moves each codebook point; therefore the behaviour statistic decides the metric an item is measured in and the geometry decides where the codes it is measured against end up. Setting g_i = 0.5 removes the behaviour term from both the assignment and the codebook estimator; setting k_H, k_S -> 0 replaces both curved distances and both exp/log maps by their Euclidean limits, which changes the same assignment and the same codebook update.
COUPLING EQUATION: D_ik = sqrt( g_i * (d_H^{k_H}(p_i, A_lk) / D_Hmax)^2 + (1 - g_i) * (d_S^{k_S}(q_i, B_lk) / D_Smax)^2 ), with g_i = clip(1 - C_i(N_i^{train}), 0.1, 0.9), d_H = (1/sqrt(k_H)) arcosh(1 + 2 k_H ||p-a||^2 / ((1 - k_H||p||^2)(1 - k_H||a||^2))), d_S = R_S arccos(clip(<q,b>/R_S^2, -1+1e-6, 1-1e-6)), and the codebook step A_lk <- exp0^{k_H}( sum_i s_ik g_i log0^{k_H}(p_i) / sum_i s_ik g_i ).
OBSERVABLES: (1) SID assignment: adjusted mutual information between the level-1 token index and a held-out-free behaviour community labelling of the transition graph, plus the distribution of Poincare radii of level-1 codes (should stop pushing cyclic items to the boundary). (2) Gradient/parameter: the learned k_H and k_S should move away from their 1.0 initialisation and their ratio should correlate with the mean g_i of the items assigned to each level-1 code. (3) Prefix behaviour predictability: Stage 3 per-token accuracy and cross-entropy at token 1 vs tokens 2-3, and the number of distinct next-items sharing a 2-token prefix. (4) Stage 3 test recall@10, the judgement, against the recorded baseline and the 0.065 target.
ABLATION BEHAVIOR OFF: g_i is replaced by the constant 0.5 for every item, so the metric is the unweighted normalised product distance and the Karcher step is unweighted; the code still exists and is exercised by one config flag, but no such run is trained this round.
ABLATION GEOMETRY OFF: k_H and k_S are driven to 0, so exp0/log0 become the identity, p = zhat_H, q = zhat_S, A and B are unbounded Euclidean points, and D_ik = sqrt(g_i * (||p - A||/D_Hmax)^2 + (1-g_i) * (||q - B||/D_Smax)^2); this is the plain behaviour-weighted Euclidean RQ-VAE and is not trained this round.
ABLATION BOTH ON: the full mechanism above: behaviour-gated mixed-curvature assignment plus behaviour-gated Karcher codebook, trained once on the frozen 3000-epoch Stage-2 budget and evaluated with the frozen Stage-3 protocol, with no early stopping, no sweep and no seed repetition.
SPEC EQUATIONS: 1) g_i = clip(1 - C_i, 0.1, 0.9), C_i = c_i / (k_i (k_i - 1)), g_i = 0.5 if k_i < 5. 2) p = exp0^{k_H}(zhat_H) = tanh(sqrt(k_H)||zhat_H||) * zhat_H / (sqrt(k_H)||zhat_H||), q = R_S zhat_S / max(||zhat_S||, 1e-8), R_S = 1/sqrt(k_S). 3) d_H and d_S as in COUPLING EQUATION, with D_Hmax = (1/sqrt(k_H)) arcosh(1 + 2 rho^2/((1-rho^2)^2)) at rho = 1 - 1e-3 and D_Smax = pi R_S. 4) s_ik = softmax_k(-D_ik^2 / tau) with the baseline tau; hard = onehot(argmin_k D_ik); st_ik = hard + s_ik - s_ik.detach(). 5) zhat_H += sum_k st_ik log0^{k_H}(A_lk), zhat_S += sum_k st_ik (B_lk - q); loss as baseline on Dec(zhat) plus the baseline commitment term. 6) A_lk <- exp0^{k_H}( (sum_i s_ik g_i log0^{k_H}(p_i)) / max(sum_i s_ik g_i, 1e-8) ), B_lk <- R_S normalise( sum_i s_ik (1-g_i) q_i ); one Karcher iteration per step. 7) At inference the SID of an item is the triple of argmin indices, one per level, exactly as the baseline.
SPEC INPUTS OUTPUTS: Inputs: encoder output z (d dims) per item, the frozen per-item behaviour weight vector g (24556 floats), the product codebooks {(A_l, B_l)}_{l=1..3}, trainable k_H_raw, k_S_raw, the baseline temperature tau. Outputs: for every item a 3-tuple of codebook indices (its SID), the straight-through product quantization zhat fed to the decoder, the commitment/decoder losses, and the gradient with respect to the encoder, the product codebooks and both curvatures.
SAFEGUARDS: clamp the ball radius ||p||, ||A|| to (1 - 1e-3)/sqrt(k_H) before every arcosh so the argument is >= 1 + 1e-7; clamp the arccos argument to [-1 + 1e-6, 1 - 1e-6]; guard ||zhat_S|| with max(., 1e-8) and skip the spherical term (g_i -> 1) when the norm is degenerate; parametrise k = softplus(k_raw) + 1e-3 and clamp k <= 1e3 so the Euclidean limit is reachable without division by zero; freeze g_i (no gradient) and assert it is finite and in [0.1, 0.9]; fall back to the Euclidean mean for any Karcher step whose denominator is below 1e-8 or whose result is non-finite; keep D_Hmax/D_Smax recomputed from the current curvature each step so the normalisers cannot go stale; reuse the baseline temperature, clip bounds and learning rate unchanged so no new constant requires tuning; assert one-hot/argmin consistency once per epoch and abort the level rather than emit NaN SIDs.
END IDEA
