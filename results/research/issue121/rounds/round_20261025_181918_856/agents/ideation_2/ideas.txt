IDEA: cooccur_curved_balancer
TITLE: Popularity-corrected co-consumption transport for hyperbolic prefix allocation
MOTIVATION: Content-near items can have very different collaborative audiences; a tokenizer that groups only by content can collapse items consumed by distinct user cohorts into shared prefixes, weakening next-item prediction.
NOVELTY: Rather than transition-direction scoring, branch-conditioned curvature, or a separate pairwise behavior loss, this uses popularity-corrected train-only user co-consumption to define a small set of behavior anchors and performs batch-balanced hyperbolic transport directly into first-level codewords. The transport assignment itself changes prefix membership.
CHANGE: Form K frozen behavior anchors by clustering item vectors built from train-only, popularity-corrected user co-consumption profiles. For each training item, add its Poincare distance to each anchor (weighted by its soft profile membership) to the latent-to-codeword cost, then use a minibatch Sinkhorn assignment on that combined curved cost so code capacity is allocated across distinct cohorts rather than dominated by frequent items.
SPECIFICATION: From training users only, create binary user-item matrix X and item co-consumption C=X^T X; set A_ij=log((C_ij+alpha)*U/((df_i+alpha)*(df_j+alpha))) for i!=j, where U is train user count and df_i train-user frequency. Retain each row's top m positive neighbors and L2-normalize to profile p_i. Fit K-means to p_i using train items only to get anchor memberships r_ik (softmax of negative squared profile distances / tau); map each anchor's frozen mean item embedding through exp_0^c to Poincare point a_k. For minibatch encoder z_i and train-only co-consumption profile membership r_i, map z_i and codewords e_j to ball points x_i,e_j; define T_ij=d_c(x_i,e_j)^2 + lambda * sum_k r_ik*d_c(e_j,a_k)^2. Compute entropy-regularized balanced assignment Q=Sinkhorn(exp(-T/eps), row sums 1 and column sums B/K), use argmax_j Q_ij for emitted first code, and train with Q-weighted codebook/commitment loss plus standard reconstruction. Use the same learned codebook at inference; behavior profiles are not required at Stage3.
COST: One-time sparse co-consumption construction O(sum_u |I_u|^2) on train user-item sets, top-m sparsification and O(N*m) storage; anchor clustering O(iter*N*m*K) once. Training adds O(B*Kcode*D) curved distances plus Sinkhorn O(S*B*Kcode) per minibatch, where S=5-10 iterations; current nearest-code assignment is O(B*Kcode*D). At frozen scale there are 24*3000=72,000 minibatches and 73,668,000 item presentations; added work is 72,000 Sinkhorn runs, each O(S*B*Kcode), with per-run distance cost O(B*Kcode*D). Profile and membership lookups are cached. Report measured epoch time; expected moderate constant-factor overhead, no extra Stage3 cost.
HYPOTHESIS: Popularity-corrected co-consumption cohorts contain complementary next-item evidence not present in text embeddings. Pre-score train-only probe: on a user-stratified held-out subset of TRAIN interactions, measure whether items assigned to the same first-prefix via this transport yield higher cohort-conditioned next-item Recall@10 than content-only prefixes at comparable prefix occupancy; expect an increase, especially among items with similar content but low profile cosine. Keep only if both-on beats both controls and Stage3 test Recall@10 exceeds 0.065.
RISKS: Co-consumption can reflect exposure/popularity rather than preference; profile sparsity and cohort count K can make anchors unstable. Balanced minibatch marginals may over-regularize genuinely skewed code use, and anchor term can compete with reconstruction. Sinkhorn temperature and lambda require train-only calibration; minibatch composition may add variance.
BEHAVIOR SIGNAL: Popularity-adjusted within-user sequential-window co-consumption profile for each item.
BEHAVIOR COMPUTATION: Using TRAIN split only, for each user collect distinct interacted items and accumulate pair counts C_ij (optionally within a fixed session/window); subtract marginal popularity with the stated log association score, retain top m positive neighbors, normalize, and derive soft memberships to K profile clusters. Compute/freeze profiles, anchors, and memberships before RQ-VAE fitting. No validation/test rows are inputs.
LEAKAGE BOUNDARY: User-item sets, item frequencies, profile matrix, anchor clustering, and all cached memberships come only from training interactions plus the frozen item inventory/embeddings. Validation/test are evaluation-only; no their interaction, co-consumption, marginal, or assignment contributes to profiles, anchors, Sinkhorn targets, or SID construction.
HYPERBOLIC OPERATOR: Poincare exponential map and negative-curvature (-c, c>0) geodesic distance d_c, used in a behavior-conditioned transport cost; c is one fixed, predeclared curvature (e.g. c=1) for all points.
HYPERBOLIC LOCATION: First-level quantization cost matrix before balanced Sinkhorn assignment; its output Q selects the first SID token and affects the codebook/encoder quantization gradients.
COUPLING PATH: Train-only co-consumption -> item profile membership r_ik -> anchor-distance term d_c(e_j,a_k)^2 inside the same curved item/code cost as d_c(x_i,e_j)^2 -> Sinkhorn Q -> first-level assignments, gradients, and SID prefixes. Removing either profile term or curved costs changes this cost matrix and its resulting assignments.
COUPLING EQUATION: x_i=exp_0^c(z_i), e_j=exp_0^c(code_j), a_k=exp_0^c(anchor_k); T_ij=d_c(x_i,e_j)^2 + lambda*sum_k r_ik*d_c(e_j,a_k)^2; Q=Sinkhorn(exp(-T/eps), row=1, col=B/Kcode). Here r_ik is the behavior term and d_c is the curved term in one assignment pathway.
OBSERVABLES: Measure first-code assignment changes versus baseline, code occupancy/cohort mixing, and the pre-score train-held-out within-prefix next-item Recall@10 (expected to rise for low-content-similarity/high-co-consumption-affinity pairs). Primary outcome is Stage3 test Recall@10; require >0.065 and compare all matched arms.
ABLATION BEHAVIOR OFF: Set lambda=0 and omit profile anchors while retaining identical Poincare costs, Sinkhorn marginals, initialization, and schedule; this isolates geometry plus balancing without behavior.
ABLATION GEOMETRY OFF: Retain the exact train-only profile memberships, anchors, lambda, and Sinkhorn procedure, but replace all Poincare exp maps and distances with identity maps and squared Euclidean distances; keep occupancy targets unchanged.
ABLATION BOTH ON: Use the frozen co-consumption profiles and anchor term inside the negative-curvature Poincare cost matrix, then run the specified Sinkhorn assignment and train the RQ-VAE; evaluate the resulting SIDs under the unchanged Stage3 protocol.
SPEC EQUATIONS: X_ui=1 if train user u interacted with item i; df_i=sum_u X_ui; C=X^T X; A_ij=log((C_ij+alpha)U/((df_i+alpha)(df_j+alpha))) for i!=j. p_i=normalize(top_m_positive(A_i)); r_i=softmax(-dist_sq(p_i,mu_k)/tau). T_ij=d_c(exp_0^c(z_i),exp_0^c(code_j))^2 + lambda*sum_k r_ik*d_c(exp_0^c(code_j),exp_0^c(anchor_k))^2. Q=diag(u) exp(-T/eps) diag(v), with u,v iteratively scaled to row target 1 and column target B/Kcode. Quantization loss is sum_ij Q_ij ||z_i-code_j||^2 (straight-through output uses argmax Q); reconstruction remains unchanged.
SPEC INPUTS OUTPUTS: Inputs: TRAIN user-item interactions, frozen item embeddings/IDs, encoder outputs z_i, first-level codebook, fixed c, alpha,m,K,lambda,eps; outputs: cached sparse p_i and r_i, anchor points, per-batch Q, selected first-level indices, quantized vectors, and final SIDs.
SAFEGUARDS: Exclude diagonal C_ii; require positive df and smooth counts; clip A and retain only top-m positive entries; L2-normalize with epsilon and assign empty profiles to a train-only global fallback membership. Use float32 geometry, project ball norms to at most (1-1e-5)/sqrt(c), clamp atanh inputs below 1-1e-5, and clamp cost logits before exponentiation. Sinkhorn log-domain iterations, epsilon floor, finite checks, gradient clipping, and a fallback to row-wise softmax if marginal scaling fails. Freeze anchors and profile memberships; fix seeds and batch sampling across ablations. Calibrate lambda/eps and report train-only assignment cost and marginal error.
END IDEA
