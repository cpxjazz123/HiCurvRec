IDEA: coconsume_karcher_assignment
TITLE: Co-consumption Karcher anchors for curved residual assignments
MOTIVATION: Content-near items can serve different user cohorts and should not be forced into the same early SID prefix; training-only co-consumption supplies a collaborative neighborhood signal that can adjust grouping.
NOVELTY: Unlike directed-transition gates, branch-radius biases, or transition-mass prefix losses, this builds a sparse item-item co-consumption graph and uses its hyperbolic Fréchet (Karcher) anchor directly as an additional candidate in the first residual code assignment. Behavior changes the location being quantized, not just a distance weight or auxiliary loss.
CHANGE: For each item, compute a sparse weighted mean of its train co-consumers in the Poincare ball, and blend that anchor into the encoded vector in tangent coordinates before first-level code selection; later residual levels remain unchanged.
SPECIFICATION: Let e_i be the encoder output mapped by exp_0^c to x_i. Build normalized sparse weights A_ij from train-only user co-consumption. Compute a one-step Karcher approximation m_i=exp_{x_i}^c(eta * sum_j A_ij log_{x_i}^c(x_j)); set x'_i=exp_{x_i}^c(lambda_i log_{x_i}^c(m_i)). Select first-level code argmin_k d_c(x'_i,c_k)^2, then continue ordinary residual quantization. lambda_i=lambda0*n_i/(n_i+kappa), where n_i is co-consumer support, preventing unsupported items from moving.
COST: Precompute co-consumption graph once from train interactions; retain top 32 neighbors/item. At 24,556 items and 24 steps/epoch, first-level anchor calculation costs at most 24,556*32 curved log-map neighbor operations per epoch (about 0.59M neighbor terms), amortized/precomputed if encoder is frozen only; with changing embeddings recompute once per epoch, not each of 24 batches. Adds about 1.8B neighbor terms over 3000 epochs in the conservative online version, plus negligible top-32 sparse storage; expected wall-clock overhead is concentrated in this per-epoch preprocessing and should be benchmarked. Compared with brute all-pairs, sparse construction is essential.
HYPOTHESIS: Among items with similar content embeddings, those co-consumed by the same train users should share first-level codes more often, while unrelated cohort items split; the train statistic is the co-consumer edge-versus-nonedge first-level prefix agreement gap, expected to increase. Retain only if Stage3 test Recall@10 exceeds 0.065 and beats both ablations.
RISKS: Popular items may dominate co-consumption; approximate Karcher means may oversmooth useful content distinctions; anchor directions can be noisy for low-support items; recomputing 32 curved maps/item/epoch may cost too much.
BEHAVIOR SIGNAL: Symmetric user co-consumption, adjusted for global item popularity.
BEHAVIOR COMPUTATION: On the Stage2 training split only, for each user deduplicate their interacted item set S_u. Accumulate C_ij += 1/|S_u| for distinct i,j in S_u. Define A_ij proportional to C_ij/sqrt((d_i+eps)(d_j+eps)), remove self-edges, retain top 32 neighbors per row, and row-normalize. No validation or test records are read.
LEAKAGE BOUNDARY: Construct C and A solely from training user histories/interactions. Freeze the graph before fitting/exporting SIDs; validation/test are only used downstream for evaluation and cannot enter graph weights, support counts, anchors, or model selection of individual assignments.
HYPERBOLIC OPERATOR: Poincare-ball exp/log maps and distance with fixed curvature c=1 (ball radius (1-eps)/sqrt(c)); the Karcher tangent average is a curved operation.
HYPERBOLIC LOCATION: First residual quantizer input, immediately before the first codebook nearest-neighbor assignment; applies while training and when exporting item SIDs using the frozen train graph.
COUPLING PATH: Train co-consumption weights select neighboring item points; their Poincare log-map average displaces the current item along a curved tangent, which changes its first-level nearest code and hence its SID prefix.
COUPLING EQUATION: x_i=exp_0^c(e_i); m_i=exp_{x_i}^c(eta sum_j A_ij log_{x_i}^c(x_j)); x'_i=exp_{x_i}^c(lambda_i log_{x_i}^c(m_i)); q_i=argmin_k d_c(x'_i,c_k)^2. Both A_ij (behavior) and log/exp/d_c (curvature) are required for this assignment pathway.
OBSERVABLES: Measure first-level SID agreement for train co-consumption edges versus degree/popularity-matched nonedges, the fraction of items whose first-level code changes versus content-only baseline, and Stage3 Recall@10. Expected edge/nonedge agreement gap rises without collapsing code usage; goal is test Recall@10 > 0.065.
ABLATION BEHAVIOR OFF: Set A_ij=0 and lambda_i=0, recovering the unshifted baseline input and ordinary first-level assignment with the same curved quantizer.
ABLATION GEOMETRY OFF: Use Euclidean vectors, Euclidean neighbor mean m_i=x_i+eta sum_j A_ij(x_j-x_i), blend x'_i=(1-lambda_i)x_i+lambda_i m_i, and squared Euclidean code distance; keep graph and all other settings fixed.
ABLATION BOTH ON: Use train-only A_ij, Poincare Karcher anchor/blend, and hyperbolic nearest-code assignment as specified; compare same seeds, training schedule, and Stage3 protocol.
SPEC EQUATIONS: Normalize e_i to x_i=exp_0^c(e_i). For sparse neighbor set N(i), m_i=exp_{x_i}^c(eta sum_{j in N(i)} A_ij log_{x_i}^c(x_j)); x'_i=exp_{x_i}^c(lambda_i log_{x_i}^c(m_i)); q_i=argmin_k d_c(x'_i,c_k)^2. Quantization residual is x'_i minus selected code in log/code tangent coordinates, mapped back consistently; subsequent levels use the repository's normal residual path. Use straight-through gradients through q_i as in baseline.
SPEC INPUTS OUTPUTS: Inputs are item encoder vectors e_i, train-only sparse normalized neighbor rows A_i, support n_i, first-level codebook {c_k}, curvature c, eta, lambda0, kappa. Output is first-level code index q_i and curved residual passed to later levels; inference/export requires only item ID, frozen encoder, and frozen train graph row.
SAFEGUARDS: Project every ball point to norm <=(1-eps)/sqrt(c), clamp acosh/atanh arguments and conformal factors, accumulate neighbor weights in float32, exclude self edges, normalize nonempty rows, set lambda_i=0 when n_i=0, cap eta and lambda_i to [0,1], and fall back to x_i if any map is nonfinite. Clip gradient norms and test c->0 Euclidean-limit behavior.
END IDEA
