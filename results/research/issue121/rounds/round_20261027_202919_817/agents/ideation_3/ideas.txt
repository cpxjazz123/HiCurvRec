IDEA: cofrechet_rank
TITLE: Co-occurrence Frechet context enters rank-sum code assignment
MOTIVATION: Items used across the same training histories often share next-item roles even when their text embeddings are not nearest; assignment should respect this local collaborative neighborhood without letting popularity alone dictate the code.
NOVELTY: The behavior context is recomputed from current pre-quantization item representations, and hyperbolic distance to it ranks the very same candidate codes used by reconstruction. Unlike a post-hoc behavior loss or codebook-derived context, both signals alter each item's selected code.
CHANGE: Before each assignment, map current encoder outputs to a fixed-curvature Poincare ball and compute each item's co-occurrence-weighted intrinsic Frechet barycentre. For each residual quantizer layer, select the code minimizing the sum of its reconstruction-error rank and its hyperbolic-distance-to-context rank.
SPECIFICATION: Let A_ij be the number of unordered pairs (i,j) appearing together in a user's longest Stage-2 training sequence, symmetrized, with A_ii=0; freeze q_ij=A_ij/||A_i:||_2. With curvature -c (c=1), prequantization vectors h_j are mapped to x_j=proj(exp_0(s h_j)), where s=1/sqrt(d) is a documented scale normalization. Context m_i=argmin_{y in B_c} sum_j q_ij d_c(y,x_j)^2, solved by a fixed small inner iteration of Riemannian gradient descent initialized at the weighted tangent mean exp_0(sum_j q_ij log_0(x_j)); stop-gradient through m_i to avoid second-order inner-solver gradients. At layer l, residual r_i^l and code vectors e_k^l give E_ik=||r_i^l-e_k^l||²; B_ik=d_c(exp_0(s h_i),m_i). Define ascending average ranks R_E,R_B (ties get average occupied rank); choose argmin_k R_Eik+R_Bik, smallest code index breaks exact total ties. Apply the existing straight-through quantized residual update.
COST: One Stage-2 training run only: 3000 epochs x 24 steps x four cards. Sparse context aggregation costs O(nnz(A_batch)d), with nnz bounded by the batch items' frozen neighbor lists; per layer add O(batch_size * code_count * d) hyperbolic distance and rank work, alongside baseline Euclidean code distances of the same order. Frechet iterations add O(iterations * nnz(A_batch)d); cache/reuse contexts within a step. This is an assignment-side overhead, not a second model or run.
HYPOTHESIS: If co-occurring items occupy semantically related roles, codes jointly preferred by reconstruction and neighborhood context give more predictable prefixes and improve frozen Stage-3 test_recall@10 over 0.065. Record Recall@10 as judgement and co-occurrence prefix coherence, adjacency and transfer predictability as diagnostics only.
RISKS: Intrinsic means may be costly or poorly conditioned for diffuse neighborhoods; co-consumption may reflect broad popularity rather than predictive relations; rank discards score margins, and one-run seed noise is substantial.
BEHAVIOR SIGNAL: Symmetric within-sequence item co-occurrence counts, row-L2-normalized.
BEHAVIOR COMPUTATION: From each user's longest Stage-2 training sequence only, count every distinct item pair once, symmetrize, zero diagonal, then L2-normalize each row; freeze sparse rows before Stage 2. No validation or test sequences are read.
LEAKAGE BOUNDARY: A is constructed solely from the Stage-2 training split before fitting; contexts use only frozen A and current encoder outputs for training catalog items. SID generation and Stage 3 evaluation never use validation/test interactions to construct or update A or contexts.
HYPERBOLIC OPERATOR: Poincare ball exp/log maps, fixed-curvature (-1) distance, and intrinsic squared-distance Frechet barycentre.
HYPERBOLIC LOCATION: Current pre-quantization encoder outputs are mapped to the ball for neighbor barycentres; the same context and item point enter every layer's code-assignment distance ranking.
COUPLING PATH: Frozen q_ij selects current encoder neighbor points -> their curved Frechet barycentre m_i -> curved distances from the item's representation to m_i rank candidate codes -> rank sum selects the residual code. Removing q or replacing the curved operations changes the chosen code path.
COUPLING EQUATION: m_i=argmin_y Σ_j q_ij d_{-1}(y,exp_0(h_j/√d))²; k_i=argmin_k [rank_k ||r_i-e_k||² + rank_k d_{-1}(exp_0(h_i/√d),m_i)].
OBSERVABLES: Log the fraction of items whose assigned code differs from reconstruction-only assignment and the rank components; record SID/prefix behavior diagnostics and frozen Stage-3 test_recall@10. No diagnostic is an admission gate.
ABLATION BEHAVIOR OFF: Define q rows as zero and use m_i=exp_0(h_i/√d), making the behavior rank identical across codes (average tie rank); do not train this arm.
ABLATION GEOMETRY OFF: Replace exp/log, Frechet barycentre and d_-1 with Euclidean weighted mean and Euclidean distance; keep the same q and rank sum; do not train this arm.
ABLATION BOTH ON: Use frozen nonzero q, current-encoder intrinsic Poincare Frechet context, hyperbolic context-distance rank plus Euclidean reconstruction rank; this is the sole candidate training run.
SPEC EQUATIONS: For c=1, project P_c(x)=x*min(1-eps/sqrt(c), sqrt(c)||x||)/(||x||+eps). exp_0(v)=tanh(sqrt(c)||v||)v/(sqrt(c)||v||+eps); log_0(x)=atanh(sqrt(c)||x||)x/(sqrt(c)||x||+eps). d_c(x,y)=2/sqrt(c) atanh(sqrt(c)||(-x)⊕_c y||), with Mobius addition and norm clamped below 1/sqrt(c). Use q sparse row weights in a deterministic fixed iteration Frechet solver; detach barycentre result. For rank ties use average rank (1-based), then stable code-index tie break for argmin. Empty-neighbor rows use m_i=x_i, so all behavior ranks tie. The behavior-off, geometry-off, and both-on switches are implemented, correctness-tested on toy inputs, and never used as trained comparison arms.
SPEC INPUTS OUTPUTS: Inputs: frozen sparse q rows, current batch item IDs, current encoder vectors h, layer residuals r, initialized Euclidean code vectors e. Output: chosen code index per item/layer, quantized code vector and optional detached context/rank diagnostics.
SAFEGUARDS: Project ball points strictly inside radius 1-eps; clamp atanh arguments and denominators; use float32 or float64 for manifold calculations and finite-value checks; self-context for empty rows; skip zero-weight neighbors; deterministic stable tie handling; initialize codebooks through baseline initialization before first assignment; gradient flows through selected code via existing straight-through path, not through iterative barycentre.
END IDEA

IDEA: cotangent_rank
TITLE: Origin-tangent co-occurrence barycentre with geodesic candidate ranking
MOTIVATION: Sparse co-consumption neighborhoods can be noisy and costly to average intrinsically; a stable origin-tangent aggregation can provide a behavior-aware local direction while preserving curved candidate comparison.
NOVELTY: Unlike codebook-context or behavior-loss designs, this uses the training co-occurrence row to aggregate current pre-quantization neighbor representations in the hyperbolic tangent space, then uses the resulting point's hyperbolic distance as an explicit candidate-code rank in assignment. It is distinct from an intrinsic Frechet solver: the aggregation is a closed-form tangent-space weighted mean.
CHANGE: Each step, map current encoder outputs into a fixed-curvature Poincare ball, average each item's neighbor log-map vectors using frozen row-normalized co-occurrence weights, and map that mean back to form context. Rank candidate residual codes by Euclidean reconstruction error and curved distance of their decoded candidate point to this context, then add ranks equally.
SPECIFICATION: Construct frozen A and q exactly from each user's longest Stage-2 training sequence: each pair once, symmetric, diagonal zero, row L2 normalization. Set x_i=exp_0(h_i/√d), c_i=exp_0(Σ_j q_ij log_0(x_j)), with c_i=x_i when q_i is empty. For layer l and candidate k, form decoded candidate z_ik=Σ_{t<l} e_{i,t}+e_k^l (the partial reconstruction in the original encoder coordinate system), map u_ik=exp_0(z_ik/√d), and compute D_ik=d_-1(u_ik,c_i). Select k_i=argmin_k(rank_k ||r_i^l-e_k^l||² + rank_k D_ik); average ranks for ties and stable lowest-index tie break. Use existing straight-through residual quantization after hard selection.
COST: One run, 3000 epochs, 24 steps/epoch, four cards. Context requires O(nnz(A_batch)d) log/weighted-sum/exp work per step; candidate geodesic ranking adds O(batch_size * code_count * d) per layer, same asymptotic candidate count as baseline distances. No extra optimizer, model parameters, or trained ablation arms.
HYPOTHESIS: The tangent mean captures a useful local direction for co-consumed items, while the curved distance makes candidate placement respond to that collaborative context. Evidence is changed assignment/ranks and improved frozen Stage-3 test_recall@10 above 0.065; record prefix coherence, adjacency, and transfer predictability only as diagnostics.
RISKS: Origin-tangent aggregation can distort widely separated neighborhoods; decoded candidate/context scales may differ; rank fusion can override a small but meaningful reconstruction advantage. The fixed single run retains seed uncertainty.
BEHAVIOR SIGNAL: Symmetric, per-row L2-normalized within-training-sequence co-occurrence.
BEHAVIOR COMPUTATION: For each user, use only their longest Stage-2 training sequence; add one to each unordered pair's count; symmetrize and normalize rows; freeze before training. No held-out interaction contributes.
LEAKAGE BOUNDARY: The frozen q matrix is derived only from Stage-2 training histories. Neighbor vectors are current model outputs for training catalog items, and held-out histories are excluded from context computation and SID construction.
HYPERBOLIC OPERATOR: Fixed negative curvature -1 Poincare exp_0/log_0 maps and geodesic distance d_-1.
HYPERBOLIC LOCATION: Neighbor aggregation occurs in the origin tangent space and is mapped back to the ball; the geodesic distance from each candidate reconstruction to that behavior context participates in candidate ranking.
COUPLING PATH: q chooses current neighbor representations -> log_0 maps and q-weighted tangent mean produce c_i -> each candidate reconstruction is mapped and geodesically compared to c_i -> that distance rank combines with reconstruction rank to choose the code.
COUPLING EQUATION: c_i=exp_0(Σ_j q_ij log_0(exp_0(h_j/√d))); k_i=argmin_k [rank_k ||r_i-e_k||² + rank_k d_-1(exp_0(z_ik/√d),c_i)].
OBSERVABLES: Measure assignment changes relative to reconstruction-only choice and record the two rank contributions, prefix/co-occurrence diagnostics, and Stage-3 test_recall@10. Only the frozen Stage-3 test_recall@10 judges success.
ABLATION BEHAVIOR OFF: Zero q and set c_i=x_i; the resulting context distance is constant across candidate codes, yielding tied behavior ranks. Defined and tested only as a wiring switch, not trained.
ABLATION GEOMETRY OFF: Replace maps and geodesic distance with Euclidean neighbor weighted mean and Euclidean candidate-context distance, leaving the behavior row and rank combination intact. Defined but not trained.
ABLATION BOTH ON: Use nonempty frozen q where available, current encoder neighbor vectors, tangent-space Poincare aggregation and curved candidate distance rank; train only this full mechanism once.
SPEC EQUATIONS: c=1; x=exp_0(h/√d), v_i=Σ_j q_ij log_0(x_j), c_i=exp_0(v_i), or c_i=x_i for no neighbors. For each code k, z_ik is the partial reconstruction with layer-l candidate, D_ik=(2)atanh(||(-u_ik)⊕c_i||), u_ik=exp_0(z_ik/√d). Minimize average-tie rank(E_ik)+average-tie rank(D_ik), with stable index tie break. Project all ball points to radius <=1-eps; clamp norms and atanh inputs; use safe float precision.
SPEC INPUTS OUTPUTS: Inputs are frozen sparse co-occurrence rows q, item IDs, current pre-quantization vectors, residual vectors, and initialized codebooks. Outputs are hard selected code indices and the resulting straight-through quantized vectors; contexts and rank counts may be logged detached.
SAFEGUARDS: Strict ball projection with epsilon margin, clamped Mobius/atanh operations, fp32+ finite checks, zero-neighbor self-context, skip zero weights, deterministic average-rank tie policy and code-index final tie break. Keep baseline codebook initialization valid before first assignment. Do not backpropagate through context aggregation; selected-code gradients use the baseline straight-through estimator. The three switches are implemented and wiring-tested, not used for comparison training.
END IDEA
