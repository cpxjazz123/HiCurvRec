IDEA: cofreq_frechet_rank
TITLE: Co-occurrence Frechet context in rank-sum code assignment
MOTIVATION: Items co-consumed across a user's training history can share a semantic code neighborhood even when their encoder reconstruction errors alone separate them; the context is computed from current item representations, so it is not a stale codebook prior.
NOVELTY: Unlike existing codebook-context or post-assignment behaviour mechanisms, the training-sequence co-occurrence Frechet barycentre contributes a hyperbolic rank on the very same candidate-code decision as reconstruction.
CHANGE: Freeze symmetric, per-user-longest-training-sequence co-occurrence rows, then at each assignment form a curvature -1 Frechet barycentre of the item's represented neighbours. Add the candidate's reconstruction-error rank and its hyperbolic distance-to-context rank; choose the lowest total, with stable code-index tie break.
SPECIFICATION: For each item i, let N_i,w_ij be nonzero entries of its L2-normalized symmetric co-occurrence row. Let z_j=f_theta(j), and b_i=argmin_{b in B} sum_j w_ij d_B(b,z_j)^2, where B is the curvature -1 Poincare ball. For current residual input x_i and code c_k, e_ik=||x_i-c_k||_2^2 and h_ik=d_B(phi(x_i),b_i). Let r^e_ik=1+#{l:e_il<e_ik}+0.5*#{l!=k:e_il=e_ik}; define r^h analogously. k*=argmin_k(r^e_ik+r^h_ik), ties by lower code index. The rank coefficients are fixed at one; this is not a tuned coupling weight. Empty N_i uses behaviour rank zero for every k (equivalently omit its contribution), leaving the baseline reconstruction argmin.
COST: Baseline budget is 24,556 items x 24 steps/epoch x 3,000 epochs = 1,768,032,000 item-step assignments across four cards. Co-occurrence preprocessing is one sparse training-only pass. For a batch of B items, K codes, dimension d, and retained neighbour count q, computing the live weighted contexts costs O(Bqd) plus fixed-iteration Frechet updates; distances and ranks cost O(BKd), same asymptotic order as baseline code distances. Memory O(nnz(co-occurrence)); no extra model or training run. Four-card wall time should be measured against the frozen baseline; no claim of zero overhead.
HYPOTHESIS: Behavioural neighbors that have similar recommendation roles will pull assignments toward codes near a common current-representation context, improving prefix predictability and ultimately Stage3 test_recall@10; retain only if frozen Stage3 test Recall@10 exceeds 0.065. Record co-occurrence-neighbor SID agreement, prefix counts, and transfer predictability as diagnostics, never gates.
RISKS: Broad/long histories can make contexts generic; sparse or empty rows fall back to reconstruction; Frechet iterations add cost; rank discontinuities give no gradient through the hard assignment (the existing straight-through reconstruction path remains responsible for updates); behaviour and reconstruction ranks may conflict.
BEHAVIOR SIGNAL: Symmetric within-sequence item co-occurrence.
BEHAVIOR COMPUTATION: On each user's longest Stage2 training sequence, count every unordered pair of distinct items once; symmetrize counts, then L2-normalize each item row. Freeze sparse neighbors and weights before Stage2. No validation/test sequences and no sequence beyond the designated training split.
LEAKAGE BOUNDARY: Construct the graph solely from Stage2 training sequences before training; prohibit validation/test loaders and future interactions from the preprocessing and context paths. Encoder representations are current learned representations of those training-graph neighbor item IDs only.
HYPERBOLIC OPERATOR: Curvature -1 Poincare distance d_B(u,v)=acosh(1+2||u-v||^2/((1-||u||^2)(1-||v||^2))) and weighted squared-distance Frechet barycentre.
HYPERBOLIC LOCATION: Context is recomputed from pre-quantization encoder outputs immediately before each batch assignment; the Poincare distance from mapped item representation to that context ranks all codes. The codebook is initialized by the existing valid initialization before any assignment; context never reads codebook vectors.
COUPLING PATH: Frozen neighbours and weights -> current neighbor encoder outputs -> hyperbolic Frechet context -> per-code hyperbolic distance ranks -> rank-sum with each code's Euclidean reconstruction-error rank -> selected code and existing straight-through training update. Behaviour-off removes the context rank; geometry-off replaces barycentre/distance with Euclidean weighted mean/distance.
COUPLING EQUATION: b_i=FrechetMean_{K=-1}({z_j,w_ij}); S_ik=rank_k(||x_i-c_k||^2)+rank_k(d_{K=-1}(phi(x_i),b_i)); k*=argmin_k S_ik. Both rank terms count once, without a tunable coefficient.
OBSERVABLES: With the mechanism on, assignments can change relative to reconstruction-only assignment; record changed-assignment fraction, neighbor agreement, prefix counts, transfer predictability, training loss/update stability, and frozen Stage3 test_recall@10. The decision metric is Stage3 test_recall@10, target above 0.065.
ABLATION BEHAVIOR OFF: Wiring-only switch: set the behaviour rank to zero for every code, leaving the Euclidean reconstruction assignment. Do not train this arm.
ABLATION GEOMETRY OFF: Wiring-only switch: use Euclidean weighted mean of the same live neighbor encoder outputs and Euclidean distance for the context rank (retain the reconstruction rank). Do not train this arm.
ABLATION BOTH ON: The sole trained candidate uses training co-occurrence weights, curvature -1 Frechet contexts and hyperbolic-distance ranks, summed with Euclidean reconstruction ranks. No off-arm is trained.
SPEC EQUATIONS: Project mapped encoder vectors to norm <=1-epsilon, with epsilon derived from machine precision (e.g. sqrt(dtype epsilon)); use stable acosh/log1p forms and clamp distance denominator factors to epsilon. Compute Frechet mean by a fixed small number of weighted Riemannian gradient steps from the highest-weight neighbor, using log/exp maps and project after each step; normalize weights after dropping missing IDs. Tie rank is average rank; final score tie resolves by code index. Empty-neighbor row contributes zero behaviour rank. Context gradients flow through neighbor representations and selected-code straight-through path; sparse graph weights are constants. Verify on toy graph that changing an edge changes assignment, geometry switch changes curved score, and a real batch has nonzero context and gradient reaching selected code.
SPEC INPUTS OUTPUTS: Inputs: Stage2 batch encoder residuals x, current pre-quantization item embeddings z, valid initialized code vectors c, frozen sparse co-occurrence rows, curvature K=-1. Output: selected code index per item and the normal baseline quantized output/straight-through update.
SAFEGUARDS: Float32/float64 stable distance calculations; ball projection after every map/update; clamp norms and denominator away from boundary; finite-value checks with fallback to reconstruction-only for invalid/empty context; deterministic average ranks for ties and code-index final tie-break; bounded fixed Frechet iterations; never materialize dense item-item adjacency.
END IDEA

IDEA: cofreq_tangent_rank
TITLE: Tangent-space co-occurrence barycentre for hyperbolic assignment ranking
MOTIVATION: The same training-only co-consumption signal can indicate a local semantic neighborhood, while a shared tangent space avoids averaging Poincare coordinates in a way that can bias contexts toward the ball origin.
NOVELTY: Uses a log-map weighted tangent barycentre at the item's own representation, then exp-maps it back before the hyperbolic candidate-distance rank; unlike codebook-derived contexts or an auxiliary behaviour loss, it changes the assignment itself and adapts as encoder outputs move.
CHANGE: For each item, map its live co-occurrence neighbors into the tangent space at that item's mapped representation, take their co-occurrence-weighted tangent mean, and exp-map the result to a curved context. Rank candidate codes by hyperbolic distance to that context and add that rank to the Euclidean reconstruction rank.
SPECIFICATION: Compute the same frozen normalized symmetric training co-occurrence W as in IDEA cofreq_frechet_rank. Let p_i=phi(z_i), p_j=phi(z_j), all in curvature -1 Poincare ball. Set v_i= sum_{j in N_i} w_ij Log_{p_i}(p_j), b_i=Exp_{p_i}(v_i). For each code k compute e_ik=||x_i-c_k||^2 and h_ik=d_{-1}(p_i,b_i); use average ranks (1-based) for each list and k*=argmin_k(rank(e_i,k)+rank(h_i,k)), lower code index on final tie. Empty N_i assigns a zero behaviour rank to every candidate. Unit rank coefficients are fixed by design.
COST: Same frozen scale: 24,556 items x 24 steps x 3,000 epochs = 1,768,032,000 item-step assignments over four cards. One sparse graph construction pass; per batch cost O(Bqd) for log/weighted-mean/exp operations plus O(BKd) for candidate distances and ranks, comparable asymptotically to baseline assignment, with higher constants. Sparse memory O(nnz W); no sweep, repeat, or ablation training.
HYPOTHESIS: Centering the co-occurrence aggregate in each item's tangent space may preserve item-specific local directions rather than collapse diverse neighbors into an origin-biased average; observe changed SID assignments and recorded neighbor/prefix/transfer diagnostics, then judge solely by frozen Stage3 test_recall@10 > 0.065.
RISKS: If p_i is near the boundary, tangent maps can amplify noise; one-hop context can be noisy for popular hubs; hard ranks are discontinuous and may not provide a direct rank gradient. Safeguards and baseline straight-through updates are therefore essential.
BEHAVIOR SIGNAL: Symmetric co-occurrence of items within each user's longest training sequence, each unordered pair counted once.
BEHAVIOR COMPUTATION: Build item-pair counts only from Stage2 training sequences, symmetrize and L2-normalize per-item rows, freeze sparse neighbors/weights before Stage2. No validation or test data enters.
LEAKAGE BOUNDARY: Graph and weights are materialized from the training split only; contexts query only those frozen IDs' current Stage2 encoder outputs. Validation/test interactions are inaccessible to graph construction and SID assignment.
HYPERBOLIC OPERATOR: Curvature -1 Poincare Log_p and Exp_p tangent maps and Poincare geodesic distance.
HYPERBOLIC LOCATION: At assignment time, Log maps current pre-quantization neighbor representations to the tangent plane at current item representation; the weighted tangent aggregate is Exp-mapped to a hyperbolic context; candidate context distances generate the behaviour rank. Existing codebook is validly initialized before first assignment and is not used to initialize context.
COUPLING PATH: Co-occurrence IDs/weights select the live encoder outputs -> curvature-dependent tangent aggregation and exp-map -> per-candidate hyperbolic context rank -> rank sum with candidate reconstruction rank -> code assignment.
COUPLING EQUATION: b_i=Exp^{(-1)}_{p_i}(sum_j w_ij Log^{(-1)}_{p_i}(p_j)); S_ik=rank_k(||x_i-c_k||^2)+rank_k(d_{-1}(p_i,b_i)); k*=argmin_k S_ik.
OBSERVABLES: Measure assignment changes against reconstruction-only on wiring checks; record neighbor SID agreement, prefix counts, transfer predictability and training stability; after the single trained run report frozen Stage3 test_recall@10 as the judgment, not the diagnostics.
ABLATION BEHAVIOR OFF: Wiring-only switch sets all behaviour ranks to zero and leaves Euclidean reconstruction argmin; not trained.
ABLATION GEOMETRY OFF: Wiring-only switch uses ordinary Euclidean neighbor mean and Euclidean distance to it for the behaviour rank, still added to reconstruction rank; not trained.
ABLATION BOTH ON: Sole trained run enables the training-only co-occurrence row, curvature -1 tangent/exp context and hyperbolic distance rank together with Euclidean reconstruction rank.
SPEC EQUATIONS: p_i=Proj_B(phi(z_i)); v_i=Σ_j w_ij Log_{p_i}(p_j); b_i=Proj_B(Exp_{p_i}(v_i)); h_ik=d_{-1}(p_i,b_i); k*=argmin_k[avgRank_k(e_ik)+avgRank_k(h_ik)]. Use average rank for exact ties and code-index deterministic final tie. Normalize weights over present neighbors. Boundary projection uses 1-epsilon with epsilon=sqrt(machine epsilon); stable log/exp and acosh implementations, finite checks, and empty-row fallback. Cheap wiring tests: toy-edge perturbation changes assignments, geometry switch changes score, live batch contexts are nonzero and gradients reach selected code.
SPEC INPUTS OUTPUTS: Inputs: batch residuals x_i, current item and neighbor encoder outputs z_i,z_j, frozen sparse W, initialized RQ-VAE codebook, K=-1. Outputs: per-item selected code index, quantized vectors and unchanged baseline straight-through training interface.
SAFEGUARDS: Project to radius <=1-epsilon after maps; use stable Mobius/log/exp formulas and clamp arguments/denominators; compute curved operations in at least float32; skip absent neighbors and fall back to reconstruction-only on invalid context; average-rank ties and deterministic index tie-break; sparse neighbor gathers and bounded degree; check finite values and gradient reach in wiring tests.
END IDEA
