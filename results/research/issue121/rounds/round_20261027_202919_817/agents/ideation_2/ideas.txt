IDEA: co_rank_coarse
TITLE: Co-occurrence-geodesic rank fusion at the coarse RQ level
MOTIVATION: The first SID token defines a broad semantic region; letting training-sequence co-consumption choose among equally plausible coarse codes may make that prefix more useful for next-item prediction without forcing uniform code use.
NOVELTY: Unlike existing successor-context and behaviour-cohesion mechanisms, the frozen symmetric co-occurrence context participates in the actual first-layer argmin through a rank fusion with reconstruction, not a separate loss or post-hoc SID feature.
CHANGE: At the first residual quantizer only, select the code by summing its reconstruction-error rank and its Poincare-distance-to-cooccurrence-context rank; later RQ levels retain baseline Euclidean residual assignments. This is the single candidate’s design, not an ablation plan.
SPECIFICATION: For item i with encoder vector z_i, let N(i),w_ij be its frozen L2-normalized co-occurrence row. Let b_i be the curvature-c=-1 Poincare Frechet barycentre of {proj(exp_0(z_j)):j in N(i)}, computed by a fixed-point Karcher iteration. For each first-level code k, let q_ik=||z_i-e_k||² and h_ik=d_P(proj(exp_0(e_k)),b_i). Set r_q(i,k)=1+#{l:q_il<q_ik}+0.5#{l!=k:q_il=q_ik}; define r_h analogously, and k*=argmin_k(r_q+r_h), ties by lowest code index. (The candidate-dependent distance is essential: d_P(z_i,b_i) alone is constant over k and cannot rank codes.)
COST: At frozen scale, 24 steps/epoch × 3000 epochs = 72,000 steps, 24,556 training items total. For batch size B and K first-level codes, baseline first-level B×K reconstruction work is augmented by B×K curved distances and rank operations; context costs O(sum_i |N(i)|d) per step with sparse neighbor rows, and is recomputed for current encoder outputs. No extra model or Stage 2 run; likely a modest first-layer assignment overhead, implementation should chunk B×K to bound memory.
HYPOTHESIS: Worth keeping if coarse assignments shift toward codes geometrically close to observed co-consumers while retaining reconstruction fit and Stage3 test_recall@10 exceeds 0.065. Record prefix predictability, co-occurrence adjacency/coherence and SID diagnostics alongside, but do not gate on them; one frozen-protocol Stage3 evaluation decides.
RISKS: Co-occurrence may reflect popularity or within-user noise; rank fusion can sacrifice important reconstruction distinctions, barycentres can blur multi-interest neighbourhoods, and a single run has seed uncertainty.
BEHAVIOR SIGNAL: Symmetric item co-occurrence from each user's longest training sequence.
BEHAVIOR COMPUTATION: Before Stage 2, for every user’s longest training sequence count each unordered pair of distinct items once (symmetric row updates); L2-normalize each nonzero per-item row. Freeze sparse neighbour IDs and weights. Use training split only.
LEAKAGE BOUNDARY: Construct rows only from the training split before Stage 2; validation/test interactions are never loaded by this operator. Encoder neighbour vectors are current representations of training items only.
HYPERBOLIC OPERATOR: Fixed-curvature Poincare ball with c=-1; exp_0 maps tangent encoder/code vectors into the ball, projected weighted Karcher mean computes the barycentre, and Poincare distance ranks candidate codes.
HYPERBOLIC LOCATION: First-level code assignment; subsequent residual levels use the unchanged baseline Euclidean assignments.
COUPLING PATH: Frozen neighbours and their weights select current encoder outputs for b_i; b_i and each candidate code’s curved image jointly determine h_ik; h_ik’s rank is added to the reconstruction rank that chooses the first SID code.
COUPLING EQUATION: b_i=KarcherMean_{P,-1}({exp_0(z_j):j∈N(i)},w_ij); k*=argmin_k [rank_k(||z_i-e_k||²)+rank_k(d_{P,-1}(exp_0(e_k),b_i))].
OBSERVABLES: First-level assignments and their gradients/selected-code updates change when the training graph or curvature switch changes; record code frequencies, prefix behaviour predictability, adjacency/coherence, and Stage3 test_recall@10. Judgement is test_recall@10 > 0.065, not a diagnostic threshold.
ABLATION BEHAVIOR OFF: Wiring check only: set N(i)=empty, define h_ik=0 and assign by reconstruction rank; do not train this arm.
ABLATION GEOMETRY OFF: Wiring check only: use Euclidean weighted mean of neighbour z_j and Euclidean distance from e_k to that mean; keep the same rank fusion; do not train this arm.
ABLATION BOTH ON: The single proposed candidate: frozen training co-occurrence, curved barycentre, candidate-to-context Poincare rank plus reconstruction rank. Train once for exactly 3000 Stage 2 epochs on four cards; no ablation, sweep, seed repetition, or early stopping.
SPEC EQUATIONS: Clamp/project ball points to norm ≤(1-1e-5)/sqrt(c_abs). Karcher iteration: initialize b=exp_0(sum_j w_ij log_0(x_j)); repeat a documented fixed 5 iterations b←exp_b(sum_j w_ij log_b(x_j)); project after each update. For empty rows, set context term to tied zero ranks and use reconstruction rank only. Compute pairwise ranks by stable comparisons, assigning exact ties their average rank. Detach discrete argmin/ranks; use selected code in standard RQ-VAE straight-through/reconstruction and codebook losses. Avoid dense all-item graph materialization; cache sparse training neighbours.
SPEC INPUTS OUTPUTS: Inputs: batch item IDs, current encoder vectors for batch and their training neighbours, first-layer codebook vectors, frozen sparse co-occurrence rows, fixed c=-1. Output: first-layer code index per item and selected quantized vectors; later residual indices are baseline outputs.
SAFEGUARDS: Float32 geometry/ranks even under mixed precision; clamp norms before log/exp and denominators away from zero; project every ball operation; skip empty/zero-weight rows; average exact ties and deterministic lowest-index final tie; chunk candidate distances; reject NaN/Inf with baseline-safe reconstruction-only fallback for affected items.
END IDEA

IDEA: co_rank_all_levels
TITLE: Recompute co-occurrence-geodesic rank fusion at every residual level
MOTIVATION: Fine-grained SID suffixes may encode collaborative distinctions that a coarse-only prefix cannot express; training co-consumption can guide each residual decision while reconstruction continues to constrain the complete code tuple.
NOVELTY: This places the same behaviour-curved rank competition inside every sequential RQ assignment, rather than applying behaviour to only the initial region or adding an independent behaviour objective.
CHANGE: At each RQ level ℓ, form the current residual r_iℓ, compute the item’s context from the current pre-quantization encoder representations of its frozen co-occurrence neighbours, and choose among that level’s codes using reconstruction-error rank plus candidate-to-context Poincare-distance rank. Residual update and codebook training otherwise follow baseline.
SPECIFICATION: Maintain the baseline residual r_i1=z_i and candidate reconstruction errors q_iℓk=||r_iℓ-e_ℓk||². For all levels use the same frozen N(i),w_ij and current neighbour encoder vectors to obtain b_i as the c=-1 Poincare Karcher mean. Let h_iℓk=d_P(exp_0(e_ℓk),b_i); select k_iℓ=argmin_k(rank(q_iℓk)+rank(h_iℓk)) with average ranks for ties and code-index final tie-break, then r_i,ℓ+1=r_iℓ-e_ℓ,k_iℓ. The context is not built from codebook vectors or residuals.
COST: At 24,556 items, 24 steps/epoch and 3000 epochs (72,000 steps), each level adds B×K curved distances and rank computation plus sparse neighbour-context aggregation; for L levels this is about L times the per-level candidate scoring overhead, with context aggregation shared across levels within a step. Chunk candidate scoring; no extra run or data pass beyond sparse neighbour gathers.
HYPOTHESIS: Worth keeping if behavioural information improves suffix allocation without overwhelming residual reconstruction, seen in changed multi-level assignments and, decisively, Stage3 test_recall@10 > 0.065. Record prefix predictability, adjacency/coherence, and collision/code-use summaries; diagnostics are descriptive only.
RISKS: Repeated rank fusion may over-steer later residuals, where reconstruction errors are small; identical context at every level may over-count the same signal, increase compute, or destabilize residual code usage.
BEHAVIOR SIGNAL: Symmetric co-occurrence in training sequences only.
BEHAVIOR COMPUTATION: For each user’s longest training sequence, increment each unordered distinct item pair once in both directions; L2-normalize each item’s co-occurrence row, store sparse neighbours/weights frozen before Stage 2.
LEAKAGE BOUNDARY: Co-occurrence graph is built exclusively from training split sequences. Validation/test data and their item transitions are inaccessible to SID assignment; neighbour representations are obtained only for those training graph neighbours.
HYPERBOLIC OPERATOR: Fixed negative curvature c=-1 Poincare exp/log maps, weighted Karcher barycentre, and Poincare distance.
HYPERBOLIC LOCATION: Candidate scoring in every RQ level’s quantization assignment; baseline residual arithmetic and losses remain unchanged.
COUPLING PATH: Each training item’s frozen co-consumption row gathers current neighbour encoder representations into a curved context; each level’s candidate codes are ranked by curved distance to that context, and those ranks directly alter the argmin that emits that level’s SID token.
COUPLING EQUATION: b_i=KarcherMean_{P,-1}(exp_0(z_j);w_ij); k_iℓ=argmin_k{rank_k(||r_iℓ-e_ℓk||²)+rank_k[d_{P,-1}(exp_0(e_ℓk),b_i)]}.
OBSERVABLES: Every level’s selected assignment and selected-code update can change; log per-level assignment differences in wiring tests, then record behaviour diagnostics and Stage3 test_recall@10. Success criterion is the frozen Stage3 test_recall@10 > 0.065.
ABLATION BEHAVIOR OFF: Wiring check only: empty neighbour rows remove the context rank and each level becomes reconstruction-rank assignment; never train this arm.
ABLATION GEOMETRY OFF: Wiring check only: replace Poincare Karcher mean/distance with Euclidean weighted neighbour mean and Euclidean candidate distance; retain rank sum; never train this arm.
ABLATION BOTH ON: The sole trained candidate has both frozen co-occurrence context and c=-1 curved candidate scoring at every level; run 3000 Stage 2 epochs on four cards, frozen Stage 3, no early stopping/ablation/sweep/seeds.
SPEC EQUATIONS: For each item and level, use average rank 1+count(strictly smaller)+half count(other exact equals); minimize rank sum. Curved barycentre uses b0=exp_0(sum w log_0(x)); five fixed Karcher updates b←exp_b(sum w log_b(x)), projecting each step. Empty row means behaviour rank is a constant tie; equivalent to reconstruction-only assignment. Maintain standard residual update and STE. Complexity O(BLKd) candidate score plus sparse O(B deg d) context; chunk codes.
SPEC INPUTS OUTPUTS: Inputs: batch item IDs, their current encoder vectors, current encoder vectors for frozen graph neighbours, residual at each level, each level codebook, sparse weights, c=-1. Outputs: one chosen code per item per level and standard baseline quantized residual reconstruction.
SAFEGUARDS: Project to radius (1-1e-5)/sqrt(c_abs); clamp all denominators and atanh arguments; float32 for geometry; handle isolated items by reconstruction-only; average ties and deterministic index tie-break; finite-value fallback; sparse gather and chunked B×K×L computation.
END IDEA

IDEA: co_rank_residual_context
TITLE: Residual-conditioned co-occurrence context for late SID tokens
MOTIVATION: An item’s broad co-consumption neighbourhood can be ambiguous across interests; late residual codes should respond to the part of that behavioural context not yet represented by earlier SID tokens.
NOVELTY: Unlike prior successor-residual or behaviour-cohesion mechanisms, the context is the curved barycentre of neighbours’ pre-quantization encoder outputs, while the current residual code candidate is ranked against a residual-conditioned curved displacement of that context on the same assignment path.
CHANGE: At each residual level, map the current residual and behaviour barycentre into the tangent space at the origin, subtract the already reconstructed prefix from the barycentre tangent vector, map that remainder into the Poincare ball, then rank candidate codes by Poincare distance to this residual context alongside Euclidean residual reconstruction rank. No learned scale or tuned weight is introduced.
SPECIFICATION: Compute b_i=KarcherMean_{P,-1}(exp_0(z_j),w_ij); let p_iℓ=sum_{m<ℓ} e_m,k_im be baseline prefix reconstruction and define u_iℓ=log_0(b_i)-p_iℓ, g_iℓ=exp_0(u_iℓ). For candidate k at level ℓ, q_iℓk=||r_iℓ-e_ℓk||² and h_iℓk=d_{P,-1}(exp_0(e_ℓk),g_iℓ); choose argmin_k(rank(q)+rank(h)). The subtraction occurs in the tangent chart; prefix p uses the actual selected code vectors. This creates a context for the behaviour not yet explained by the emitted prefix.
COST: Frozen scale is 24 steps/epoch × 3000 epochs = 72,000 steps and 24,556 items. Per batch, sparse neighbour aggregation and one barycentre per item are shared; each of L levels adds B×K Poincare distances/ranks and O(Bd) tangent residual-context work. This is higher than baseline code assignment but no extra training run; chunk scoring and cache neighbour IDs, not representations.
HYPOTHESIS: Worth keeping if late SID tokens encode residual behavioural structure rather than repeat coarse co-consumption, changing suffix assignments and yielding frozen Stage3 test_recall@10 > 0.065. Record prefix predictability, adjacency/coherence and per-level usage only as diagnostics; Stage3 test recall is the judgement.
RISKS: Tangent subtraction is chart-dependent and may push g toward the ball boundary; prefix subtraction may over-correct or cancel valid context; neighbourhood mixtures can be multi-modal and rank-only trade-offs may hurt reconstruction.
BEHAVIOR SIGNAL: Symmetric co-occurrence of items in users’ longest training sequences.
BEHAVIOR COMPUTATION: Count each unordered pair of distinct items once in each user’s longest training sequence, symmetrize and L2-normalize per-item rows, freeze sparse neighbours and weights before Stage 2.
LEAKAGE BOUNDARY: Only training sequences construct the graph. No validation/test interactions, future items, or their representations enter neighbour rows or barycentres used for SID generation.
HYPERBOLIC OPERATOR: Fixed c=-1 Poincare exp_0/log_0, weighted Karcher barycentre, and Poincare distance; tangent-chart residualization is followed by exp_0 back to the curved ball.
HYPERBOLIC LOCATION: At every residual-level assignment, both forming the behaviour barycentre and converting the prefix-residualized context into the candidate distance target.
COUPLING PATH: Training co-occurrence weights select current neighbour encoder vectors; their hyperbolic barycentre is residualized using the emitted code prefix in the tangent chart; the resulting curved target supplies candidate distance ranks that alter the same RQ argmin as reconstruction.
COUPLING EQUATION: b_i=KarcherMean_{P,-1}(exp_0(z_j),w_ij); g_iℓ=exp_0(log_0(b_i)-p_iℓ); k_iℓ=argmin_k[rank_k(||r_iℓ-e_ℓk||²)+rank_k(d_{P,-1}(exp_0(e_ℓk),g_iℓ))].
OBSERVABLES: Changing a toy training co-occurrence graph must alter context and potentially assignment; curvature must affect candidate distance ranks; real batch context must be nonzero and assignment must update selected code parameters through standard quantizer losses. Record all behavioural diagnostics and judge solely by frozen Stage3 test_recall@10 > 0.065.
ABLATION BEHAVIOR OFF: Wiring check only: empty graph sets behaviour context rank to tied constant ranks; reconstruction rank selects codes. Not a trained arm.
ABLATION GEOMETRY OFF: Wiring check only: weighted Euclidean mean of neighbour encoder vectors, Euclidean prefix subtraction, and Euclidean candidate distance replace all curved operations; rank combination unchanged. Not trained.
ABLATION BOTH ON: Train only the full training-co-occurrence / curved-barycentre / tangent-residual-context / candidate-distance-rank system for 3000 epochs on four cards and evaluate once with frozen Stage3; no ablation, tuning, seed repeat, or early stop.
SPEC EQUATIONS: Compute barycentre with five fixed Karcher updates, project every iterate; p_iℓ is cumulative already-selected code reconstruction; r_iℓ is baseline residual. Rank ties get average rank (strictly smaller + half equal others), final ties lowest index. Empty neighbours bypass context and use reconstruction rank. Standard RQ residual update after selection.
SPEC INPUTS OUTPUTS: Inputs: item batch IDs, current encoder z for items and their sparse training co-occurrence neighbours, prior selected code vectors p, current residual, level codebook, fixed c=-1. Outputs: per-level code assignment and reconstructed quantized vector.
SAFEGUARDS: Project ball norms below (1-1e-5)/sqrt(c_abs); clamp log/exp denominators and inverse-tanh inputs; compute geometry in float32; if tangent residual exceeds ball-safe tangent radius, scale it by the largest radial factor that projects it just inside the ball (scale derived from boundary, not tuned); empty rows use no behaviour term; exact ties average ranks and final tie breaks by code index; finite fallback to reconstruction-only and chunk candidate distances.
END IDEA
