IDEA: fork-angle-transport
TITLE: Successor-fork angular transport in the quantizer's Poincare tangent space
MOTIVATION: Items reached from the same training prefix often serve a shared user-interest branch; vanilla reconstruction can place those alternatives in unrelated directions, making their codes weakly useful for next-item generation.
NOVELTY: Rather than adding a separate behaviour loss to the encoder, train-only successor overlap supplies the target tangent direction used by a Poincare-geodesic assignment cost. This is a local, branch-conditioned transport of the representation the quantizer actually reads, not a Euclidean suffix or a hyperbolic-only regularizer.
CHANGE: Precompute a sparse successor-overlap vector for each item. At each quantization layer, add that vector (scaled by the item's branch ambiguity) to the current tangent residual, map the result into a fixed-curvature Poincare ball, and select the code by Poincare distance; reconstruction/commitment gradients pass through this same transformed point.
SPECIFICATION: For training interactions only, let N(i) be distinct next items after anchor i. Define S_ij=|N(i)∩N(j)|/(|N(i)∪N(j)|+eps), retain top-k nonzero neighbours per i (k derived as min(8, degree), no sweep), and let b_i=sum_j S_ij log(1+|N(j)|). For layer l with residual tangent vector r_i^l and learned linear map W_l, u_i^l=r_i^l+ (b_i/(1+b_i)) W_l [sum_j S_ij e_j/(sum_j S_ij+eps)]. Let x_i^l=Exp_0^c(u_i^l), and q_i^l=argmin_k d_c(x_i^l, Exp_0^c(c_k^l))^2. Use ordinary RQ residual update from the selected code in tangent coordinates. behavior_on=False sets S,b to zero; geometry_on=False replaces Exp/d_c with identity/L2. Both-on is the specified path. Fixed c=1, with standard projection to norm < (1-1e-5)/sqrt(c); no tuned constants. The shared-successor signal and curved distance jointly determine assignment and its gradients.
COST: Precompute sparse top-k overlap once from 24,556 training items; memory O(E_k), where E_k is retained directed neighbour count. Per step, B=4096 item lookups plus sparse gather O(BkD), then B×K Poincare distances per layer, the same asymptotic assignment cost as the baseline and a modest distance/map overhead; 24 steps/epoch × 3000 epochs = 72,000 steps, no extra training pass or run.
HYPOTHESIS: If alternatives sharing observed successor context should have nearby usable codes, the coupled tangent shift will change assignments and encoder/codebook gradients toward branch-consistent codes, yielding Stage3 test Recall@10 > 0.065. Record assignment changes, successor-neighbour retrieval and test Recall; behaviour diagnostics are descriptive only.
RISKS: Sparse Jaccard overlap may be noisy for rare items; the tangent shift can overwhelm reconstruction despite its bounded coefficient; ambiguity may correlate with popularity rather than true branching; fixed curvature may add cost without useful geometry.
BEHAVIOR SIGNAL: Directed successor-set overlap, weighted by successor branching.
BEHAVIOR COMPUTATION: From the training split only, form N(i) from observed directed anchor→next-item pairs; compute top-k Jaccard overlaps S_ij and b_i as specified. Do not use valid/test sequences, labels, or co-occurrence statistics.
LEAKAGE BOUNDARY: Build and freeze the sparse S table exclusively from Stage2 training interactions before optimization. Every item receives a deterministic global SID; validation/test interactions are unavailable to the constructor and are used only by the frozen Stage3 evaluation protocol.
HYPERBOLIC OPERATOR: Poincare exponential map Exp_0^c and Poincare distance d_c at fixed negative curvature -c, c=1.
HYPERBOLIC LOCATION: In each residual-quantization layer, immediately before nearest-code assignment, where the adjusted representation, code locations and assignment gradient are computed.
COUPLING PATH: The train-only successor-overlap aggregate shifts the representation before Exp_0^c; the resulting Poincare distance selects the code and supplies the quantization gradient. Removing behaviour removes the shift; replacing curved maps/distance changes that assignment computation.
COUPLING EQUATION: q_i^l=argmin_k d_c(Exp_0^c(r_i^l+g_i^l), Exp_0^c(c_k^l))^2, where g_i^l=(b_i/(1+b_i))W_l[Σ_j S_ij e_j/(Σ_j S_ij+eps)]; S,b are training behaviour and d_c,Exp are curved operations.
OBSERVABLES: Changed SID assignments and codebook/encoder update directions for high-overlap branches; changed predictability of held-out training prefixes from SID prefixes; final Stage3 test Recall@10 is the judgement.
ABLATION BEHAVIOR OFF: In code only, behavior_on=False sets S_ij=b_i=0, so g_i^l=0 while retaining Poincare assignment. Do not train this arm.
ABLATION GEOMETRY OFF: In code only, geometry_on=False uses identity mapping and squared Euclidean assignment distance on the same behavior-shifted vector. Do not train this arm.
ABLATION BOTH ON: The single formal candidate uses training-derived S,b and Poincare Exp/distance together as in the coupling equation. Train only this arm once under the frozen recipe.
SPEC EQUATIONS: (1) From train edges: N(i)={j:(i,j) observed}; S_ij=Jaccard(N(i),N(j)), retain top min(8,degree(i)); b_i=Σ_j S_ij log(1+|N(j)|). (2) m_i=Σ_j S_ij e_j/(Σ_j S_ij+eps); g_i^l=b_i/(1+b_i) W_l m_i. (3) x_i^l=Exp_0^1(r_i^l+g_i^l); q_i^l=argmin_k d_{-1}(x_i^l,Exp_0^1(c_k^l))². Apply standard residual update and commitment/codebook terms through this assignment path. Switches are explicit booleans as above, tested by checking numerical pathway differences, not by training ablations.
SPEC INPUTS OUTPUTS: Inputs: training-only directed edges, item embeddings, per-layer residuals/code vectors and codebook. Output: per-layer code indices, quantized residuals and differentiable assignment/commitment values.
SAFEGUARDS: Add eps=machine epsilon for empty sets/normalization; empty neighbourhood means g=0. Clip tangent norms only to the analytic ball-domain limit (1-1e-5)/sqrt(c) before Exp; project code points to same open ball; clamp acosh arguments to >=1+machine epsilon; compute distances in float32 under AMP; skip non-finite overlap rows and log counts. No validation-derived statistics or tuned clipping/temperature.
END IDEA

IDEA: fork-radial-curvature-calibration
TITLE: Branching-calibrated radial targets with geodesic successor attraction
MOTIVATION: A branching prefix represents uncertainty over many next items while items with similar successor contexts should occupy compatible semantic regions; a flat latent space does not express both broad branching and shared directional structure in a single quantizer-facing representation.
NOVELTY: It couples successor branching to a per-item radial target and successor co-context to a geodesic attraction term on the encoder output before RQ-VAE quantization. Unlike earlier behaviour-fork proposals, the mechanism is a calibrated radial coordinate plus sparse geodesic graph smoothing, not a branch-conditioned Euclidean supervision target or a residual/assignment reweighting.
CHANGE: Map the encoder output into the Lorentz hyperboloid, constrain its geodesic radius toward a radius derived from log successor count, and attract items sharing successor contexts by Lorentz geodesic distance. The resulting constrained Lorentz point is then mapped to the tangent representation consumed by the unchanged residual codebook; the graph attraction and radial constraint share the same point and encoder gradient path.
SPECIFICATION: Use train-only successor sets N(i). Let h_i=log(1+|N(i)|), and let rho_i=log(1+h_i) (nonnegative, naturally scale bounded); for each item define neighbours j with positive Jaccard overlap S_ij, truncated to top min(8,degree), with normalized a_ij=S_ij/(Σ_j S_ij+eps). For encoder z_i, v_i=Exp_0^c(z_i) in the Poincare ball and its radius r_i=2/sqrt(c) atanh(sqrt(c)||v_i||). Set v'_i=Exp_0^c((rho_i/(r_i+eps)) Log_0^c(v_i)); this radial projection is differentiable and maps to target radius rho_i. Minimize L_graph=Σ_iΣ_j a_ij d_c(v'_i,v'_j)^2, then quantize y_i=Log_0^c(v'_i) using baseline Euclidean RQ assignments/decoder. To ensure geometry is necessary to the coupled pathway, define behaviour_on=False as rho_i=median_train(rho) and a_ij=0; geometry_on=False uses Euclidean norm/radial scaling and Euclidean pair distance on z. Both-on uses the above single curved point and graph loss. The radial target is derived from observed branch counts, no coupling weight: add graph loss as a mean per-item squared distance divided by its detached batch mean squared latent norm (dimensionless normalization).
COST: Train-only sparse graph construction O(E_k) and memory O(E_k). Per step, encoder mapping/log-exp plus O(Bk) Lorentz distances and one detached scalar normalization; extra O(BkD) arithmetic at B=4096, 24 steps/epoch × 3000 = 72,000 steps. No additional model pass or training run.
HYPOTHESIS: Branch count should encode uncertainty radially while shared-successor items receive a coherent geodesic neighborhood; if this structure is useful to next-item generation, SIDs and encoder gradients will change and the single Stage3 run will exceed test Recall@10 0.065. Record radial/count association, graph-neighbour SID predictability and Recall without using diagnostics as gates.
RISKS: Hard radial projection could erase useful encoder norm information; train graph overlap can be sparse/noisy; geodesic attraction may oversmooth popular branches; the normalization may still make the graph term too influential; Euclidean RQ over log-mapped points may fail to preserve curved neighbourhoods.
BEHAVIOR SIGNAL: Per-item directed successor branching and shared-successor overlap.
BEHAVIOR COMPUTATION: From Stage2 training interactions only, form N(i) as the distinct next-item set after i; branch count is |N(i)| and neighbour overlap is Jaccard(N(i),N(j)) for retained top-k positive neighbours. No validation/test interactions contribute.
LEAKAGE BOUNDARY: Freeze the successor sets, counts and sparse weights from the training split before training. The SID function is item-global and deterministic; Stage3 validation/test are only consumed by its fixed evaluation, never by graph/radius construction or optimization.
HYPERBOLIC OPERATOR: Poincare Exp_0^c/Log_0^c radial projection and Poincare geodesic distance at fixed negative curvature -c (c=1).
HYPERBOLIC LOCATION: Encoder-to-quantizer interface: project each encoded item to its behaviour-derived radius in the ball, compute graph geodesic attraction there, then Log-map the same point into the representation read by RQ-VAE.
COUPLING PATH: The training-derived count sets the radius of each curved point, while training-derived overlap pairs are scored by geodesic distance between those same projected points; their gradients update the encoder representation that the quantizer consumes. Either count/graph or curved operations removed changes the projected points/loss and their gradients.
COUPLING EQUATION: v'_i=Exp_0^c((rho_i/(||Log_0^c(v_i)||+eps))Log_0^c(v_i)); L_graph=Σ_ij a_ij d_c(v'_i,v'_j)^2 / stopgrad(mean_batch||Log_0^c(v')||²+eps), where rho_i=log(1+log(1+|N(i)|)) and a_ij is normalized training successor Jaccard overlap.
OBSERVABLES: Encoder radial coordinate tracks training successor branching; graph neighbours become closer under curved metric and more predictable from SID prefixes; assignment distribution and gradients change. Decide solely by frozen Stage3 test Recall@10 > 0.065.
ABLATION BEHAVIOR OFF: In code only, behavior_on=False replaces rho with the training median radius and zeros a_ij, leaving the curved mapping active. Do not train this arm.
ABLATION GEOMETRY OFF: In code only, geometry_on=False replaces maps, radial projection and distance by Euclidean norm scaling and squared Euclidean distance, while retaining branch-derived radii and overlap pairs. Do not train this arm.
ABLATION BOTH ON: The one formal run uses branch-derived rho and overlap weights with Poincare radial projection/geodesic distance. Train once only.
SPEC EQUATIONS: Define train-only N(i), h_i=log(1+|N(i)|), rho_i=log(1+h_i), and a_ij=Jaccard(N(i),N(j))/Σ_j Jaccard for top min(8,degree(i)) positive neighbours. v_i=Exp_0^1(z_i); t_i=Log_0^1(v_i); v'_i=Exp_0^1(rho_i t_i/(||t_i||+eps)); y_i=Log_0^1(v'_i). L_graph=[Σ_ij a_ij d_{-1}(v'_i,v'_j)^2]/stopgrad(mean_batch||y||²+eps). Optimize baseline reconstruction+RQ-VAE terms plus L_graph; the normalized graph term is dimensionless and has coefficient 1 by construction, not tuned. Quantize y_i with baseline RQ.
SPEC INPUTS OUTPUTS: Inputs: training-only edge-derived counts/overlaps, encoder outputs z_i, RQ-VAE codebooks. Outputs: quantizer inputs y_i, graph loss and standard SID indices.
SAFEGUARDS: c=1 fixed; clamp input norms to (1-1e-5)/sqrt(c), guard zero norms with machine epsilon; clamp acosh argument above 1; compute Lorentz/Poincare operations in float32; exclude empty-neighbour graph rows; detach only the loss-scale denominator; assert finite radii and gradients. rho is a count-derived nonnegative target, not swept or validation-calibrated.
END IDEA
