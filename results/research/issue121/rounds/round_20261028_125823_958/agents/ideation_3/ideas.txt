IDEA: fork-radius-geodesic
TITLE: Successor-branch radial supervision by Poincare geodesic distance
MOTIVATION: An item with many distinct next-item outcomes represents a broad behavioral fork, while a low-branching item has a more predictable continuation; semantic IDs should expose this difference in their coarse latent representation.
NOVELTY: It replaces pairwise successor clustering with a scalar, item-specific radial target computed from continuation uncertainty. Unlike unchanged Euclidean RQ-VAE plus a behavior suffix, the target is a Poincare radius of the exact encoder representation consumed by quantization; unlike generic hyperbolic RQ-VAE, the radius is set by observed training-only branching.
CHANGE: From training-only outgoing transition entropy, map each item's normalized branch entropy to a target Poincare radius and penalize the squared geodesic distance between that radial target and the encoded item. Apply the penalty to the pre-quantization latent after exp-map, alongside the unchanged canonical reconstruction/RQ-VAE objective.
SPECIFICATION: Count directed adjacent item pairs in training user sequences only: n_ij. Define p(j|i)=n_ij/sum_j n_ij and h_i=-sum_j p(j|i)log p(j|i), with h_i=0 for no outgoing edges. Set q_i=h_i/log(max(2,d_i)), where d_i is the number of distinct successors (and q_i=0 when d_i<2). On a training-only item set, let q05 and q95 be empirical 5th/95th percentiles; set t_i=clip((q_i-q05)/(q95-q05+eps),0,1). With fixed c=1 negative curvature, radial target y_i=exp_o^c((t_i R)u_i), where u_i=z_i/(||z_i||+eps), R is the empirical 95th percentile of ||z|| over the current training minibatch, detached from gradients. Minimize L=L_RQVAE+mean_i d_B^2(exp_o^c(z_i),y_i); unit coefficient after each term is divided by its detached minibatch mean (clamped below by eps). This defines scale without a sweep.
COST: One training-only transition count pass, O(E_train) once. At each of 24 steps/epoch (about 1,023 items/step; 24556 items total), add one exp-map, norm, and pointwise Poincare distance per item: O(BD), no codebook pair expansion. At 3000 epochs the extra work is 24*3000*B pointwise distances; expected small relative to encoder and codebook assignment, with no additional training run.
HYPOTHESIS: Worth keeping only if training-only branching predicts useful next-item uncertainty and the radial gradients move encoder latents in a way that survives quantization; observe changed latent radii/SID assignments and, decisively, frozen Stage3 test Recall@10 > 0.065. Diagnostics are descriptive only.
RISKS: Branch entropy may be a popularity or data-frequency proxy rather than stable user intent; the quantizer may erase the radial signal; small/no-outdegree items have weak supervision; per-batch radius calibration can be noisy.
BEHAVIOR SIGNAL: Per-item normalized entropy of directed next-item outcomes (successor branching).
BEHAVIOR COMPUTATION: From training split user sequences, count each adjacent pair (i,j), form each source's empirical successor distribution and normalized entropy; no validation/test sequences or held-out interactions are read.
LEAKAGE BOUNDARY: The transition table and entropy targets are computed once from the training split only; validation/test data are unavailable to target construction, normalization, or model updates. Stage3 uses the resulting frozen SIDs under the prescribed protocol.
HYPERBOLIC OPERATOR: Poincare-ball exp map at the origin and squared geodesic distance d_B^2 for curvature -c, c=1.
HYPERBOLIC LOCATION: Auxiliary supervision on the encoder output immediately before RQ-VAE quantization; its gradients update that same encoder representation read by the quantizer.
COUPLING PATH: Training successor entropy determines a target radius, and the distance from the exp-mapped encoder latent to that target generates gradients on the pre-quantization latent; removing entropy removes item-specific targets, while replacing the geodesic with Euclidean distance removes the curved radial geometry.
COUPLING EQUATION: L_fork=mean_i [ w_i d_B^2(exp_o^c(z_i), exp_o^c(t_i R u_i)) ], where w_i=1 and t_i is the training-only normalized successor-entropy target.
OBSERVABLES: With the full mechanism, radial latent norms and resulting SID assignments should become associated with training-only branching, while Stage3 test Recall@10 is the sole keep/reject outcome; target >0.065.
ABLATION BEHAVIOR OFF: Set all t_i to the training-set median target, retaining the identical curved distance and pathway; this removes item-specific behavior supervision. This switch exists for comparison but is not trained in this round.
ABLATION GEOMETRY OFF: Replace both exp maps and d_B by their tangent-space Euclidean counterparts, retaining t_i, R, and the same normalized objective. This switch exists for comparison but is not trained in this round.
ABLATION BOTH ON: Use the per-item training successor-entropy target and curvature -1 Poincare exp maps/distance as specified. Train exactly this single candidate once; no ablation arm is run.
SPEC EQUATIONS: For item i, n_ij=count_train(i->j), p_ij=n_ij/(sum_j n_ij+eps), h_i=-sum_j p_ij log(p_ij+eps), q_i=h_i/log(max(2,d_i)) if d_i>=2 else 0. Normalize q_i by training-item q05,q95 to t_i in [0,1]. z_i=Encoder(x_i); u_i=z_i/(||z_i||+eps); R=stopgrad(percentile95_batch(||z||)); y_i=exp_o^c(t_i R u_i); v_i=exp_o^c(z_i). Optimize canonical L_RQVAE plus scale-normalized mean d_B(v_i,y_i)^2. Use the existing training split and canonical 3000-epoch schedule.
SPEC INPUTS OUTPUTS: Inputs are training content embedding x_i, training-only transition count table, and encoder latent z_i; output is scalar auxiliary loss and its gradients into z_i/encoder. It does not change the RQ-VAE codebook interface or Stage3 input format.
SAFEGUARDS: Float32 geometry; clamp tangent norms below (1-eps)/sqrt(c) before exp-map; clamp Poincare distance denominators and acosh/atanh arguments; eps=machine-safe 1e-6; skip/zero-target no-outdegree items; if q95<=q05 set all t_i to 0; detach R and loss-scale estimates; assert finite losses/gradients. Curvature c=1 is a documented fixed default, not tuned.
END IDEA

IDEA: fork-angular-barycenter
TITLE: Shared-successor angular attraction with branch-calibrated hyperbolic geodesics
MOTIVATION: Items that lead into the same downstream item can represent alternative entry points into a common continuation; their SIDs should retain that behavioral substitutability without collapsing every item with broad branching into one cluster.
NOVELTY: The mechanism supervises a curved, directed predecessor-to-successor barycentric relation, rather than assigning behavior-weighted codewords, running behavior Sinkhorn, or applying an independent behavior loss to an unrelated representation. It couples the successor structure to a Poincare geodesic midpoint target on the quantizer's own latent.
CHANGE: For each training item, form a weighted Fréchet-style barycenter of its successors' Poincare points and pull its encoded point toward the geodesic midpoint between its current point and that continuation barycenter. Weight this pull by the source's normalized branching uncertainty, so branching controls how strongly the item is placed between its own semantic location and its behavioral continuation.
SPECIFICATION: Build train-only directed counts n_ij and successor probabilities p_ij as in the first idea. For each minibatch source i with at least one observed successor represented in the minibatch, map current successor latents z_j to Poincare points x_j=exp_o^c(z_j), then compute a tangent-space barycenter b_i=exp_o^c(sum_j p_ij log_o^c(x_j)) using only observed successors (renormalize p over included successors). Define m_i as the Poincare geodesic midpoint between x_i=exp_o^c(z_i) and b_i, computed m_i=exp_{x_i}(0.5 log_{x_i}(b_i)). Let a_i be normalized successor entropy in [0,1] using training-set q05/q95. Minimize L=L_RQVAE+mean_i a_i*d_B^2(x_i,m_i), with the auxiliary term divided by its detached minibatch mean when positive. No-successor or absent-successor items contribute zero. This supplies a unit-free scale and uses fixed c=1.
COST: Precompute sparse directed counts once in O(E_train). Per step on about 1,023 of 24,556 items, gather sparse successor edges and perform exp/log maps and one barycenter plus midpoint per eligible source: O(E_B D), where E_B is the number of sampled observed outgoing edges, bounded by the training graph's sparse minibatch edges; no all-pairs item matrix. 24 steps/epoch for 3000 epochs; added edge-wise geometry may be noticeable but remains sparse, with no extra run.
HYPOTHESIS: Worth keeping if shared continuations identify behaviorally interchangeable items and the entropy-weighted curved midpoint regularizes their latent organization without blurring content distinctions; observe training-only successor alignment and changed assignments, but decide only by Stage3 test Recall@10 > 0.065.
RISKS: A midpoint toward popular successors can over-associate unrelated sources; minibatches may omit most successors and produce noisy barycenters; high-entropy sources may receive a diffuse, unhelpful target; curvature may add cost or unstable gradients.
BEHAVIOR SIGNAL: Directed next-item transition distribution and its normalized successor entropy.
BEHAVIOR COMPUTATION: From adjacent item pairs in training user sequences only, count n_ij, normalize each source row to p(j|i), and calculate entropy normalized by log distinct outdegree; minibatch barycenters renormalize only over included training successors.
LEAKAGE BOUNDARY: Both transition rows and entropy scaling quantiles are built exclusively from training interactions; the per-step barycenter accesses only training item IDs and current model latents. Validation/test interactions are never loaded into SID construction or optimization.
HYPERBOLIC OPERATOR: Poincare exp/log maps and the geodesic midpoint obtained by exp_x(0.5 log_x(y)) under fixed curvature -1; distance is Poincare geodesic distance.
HYPERBOLIC LOCATION: The auxiliary target construction and loss on the encoder's pre-quantization latents; gradients feed directly into the latent representations consumed by the baseline quantizer.
COUPLING PATH: Training transition probabilities construct a successor barycenter in the Poincare ball; branching entropy gates the geodesic-midpoint pull on the same encoded point. Without the transition signal there is no barycenter, and with Euclidean geometry the barycenter/midpoint computation and distance are replaced, changing that same gradient path.
COUPLING EQUATION: L_cont=mean_i [a_i d_B^2(x_i, exp_{x_i}(0.5 log_{x_i}( exp_o(sum_j p_ij log_o(x_j)) )))], where x_k=exp_o(z_k) and a_i is normalized training successor entropy.
OBSERVABLES: The on-mechanism should alter encoder gradients and SIDs in proportion to directed continuation barycenters; record latent/assignment and successor-alignment diagnostics, never as admission gates. Stage3 test Recall@10 must exceed 0.065 to retain.
ABLATION BEHAVIOR OFF: Set a_i=0 and replace p_ij barycenter with no behavioral target, yielding zero auxiliary loss while preserving baseline RQ-VAE. This switch exists in code but is not trained this round.
ABLATION GEOMETRY OFF: Use Euclidean weighted successor barycenter, Euclidean midpoint (x_i+b_i)/2 and squared Euclidean distance, with all same edges and a_i. This switch exists in code but is not trained this round.
ABLATION BOTH ON: Use training-only directed probabilities and entropy weights with Poincare barycenters, geodesic midpoint, and Poincare distance. This is the sole candidate trained once; no ablation arm is run.
SPEC EQUATIONS: p_ij=n_ij/(sum_k n_ik+eps); h_i=-sum_j p_ij log(p_ij+eps); q_i=h_i/log(max(2,d_i)); scale q to a_i in [0,1] by train-item 5th/95th quantiles. For included successors J_i, p'_ij=p_ij/(sum_{k in J_i}p_ik+eps), x_k=exp_o^c(z_k), b_i=exp_o^c(sum_{j in J_i}p'_ij log_o^c(x_j)), m_i=exp_{x_i}^c(0.5 log_{x_i}^c(b_i)); optimize L_RQVAE plus normalized mean a_i d_B^2(x_i,m_i). Fixed c=1; no constant sweep.
SPEC INPUTS OUTPUTS: Inputs are current minibatch encoder latents, sparse training-only directed transition rows, and train-derived entropy quantiles. Output is scalar auxiliary loss and gradients to all included source/successor latents; quantizer and downstream SID interface remain unchanged.
SAFEGUARDS: Float32 manifold arithmetic; project ball points to radius (1-eps)/sqrt(c); clamp norms and log/atanh/acosh arguments; eps=1e-6; renormalize minibatch successor weights safely; skip empty rows; stop-gradient the auxiliary-loss scale; cap each source's included edge list at its observed sparse row length (no dense expansion); assert finite values. Use c=1 documented default.
END IDEA
