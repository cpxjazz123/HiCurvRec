IDEA: fork_metric_quantizer
TITLE: Couple successor-fork structure to hyperbolic residual quantization
MOTIVATION: Items that lead to many distinct next items need coarse, reusable prefixes, while items with narrow continuation sets can occupy more specific regions; an ordinary Euclidean residual codebook has no direct training signal for this branching structure.
NOVELTY: Rather than supervising ball-coordinate radius/angular targets or adding a behavior-derived latent warp, use training-only successor-fork relations to define which *residual code assignments* are metrically compatible, and compute that compatibility with the Poincare distance used in the quantizer itself.
CHANGE: Compute a fixed branching rank and shared-successor relation from training sequences. At each quantizer level, select residual codewords by minimizing a single score that combines Poincare residual distance with a fork-conditioned geodesic codeword cost; the selected codeword and residual update then feed the next level.
SPECIFICATION: For each item i, let b_i=log(1+|{j:n_ij>0}|), where n_ij counts adjacent training transitions i→j. Let s_ik=1 if items i,k have at least one common training successor, otherwise 0. At level l with residual r_il and codeword q_lc, represent q_lc and the residual in the tangent ball via x=exp_0^c(r_il), y=exp_0^c(q_lc). Score D_ilc=d_P,c(x,y)^2 + alpha_l (b_i-b_c)^2 + beta_l (1-s_i,c), where b_c and s_i,c are fixed training-only means for items assigned to code c by the preceding frozen baseline SID (level 1 uses global mean b_c and s=0). To avoid circular reassignment, derive code statistics once from baseline train-only SIDs before candidate training and freeze them. Pick argmin; update r_i,l+1=r_il-q_lc in tangent coordinates, with standard RQ-VAE reconstruction/VQ objective. Derive alpha_l=median(training d_P²)/median(nonzero (b_i-b_c)²), beta_l=median(training d_P²), computed once on the frozen baseline initialization; no tuning.
COST: One-time train-only counts, sparse shared-successor lookup and scale statistics O(E_train+nnz); per item/level, map residual and codewords to the ball and compute Poincare distances, O(B K d) (K is existing codebook size), plus O(BK) cached fork terms. At frozen scale B≈24556/24≈1024 per step, 24 steps/epoch × 3000 epochs; replaces existing Euclidean assignment distance rather than adding a second pass, so expected modest map/distance overhead, no extra learned network or sampling.
HYPOTHESIS: If continuation branching is useful to next-item prediction beyond content reconstruction, fork-compatible items will more often share coarse assignments while narrow-fork items retain useful fine distinctions, and the coupled candidate's single frozen Stage3 test Recall@10 will exceed 0.065. Record assignment changes by branching rank and training-only prefix continuation predictability as diagnostics only; neither is an admission gate.
RISKS: The frozen baseline codeword fork statistics may be noisy or circularly reinforce baseline partitions; branch count may mostly measure item exposure; Poincare assignment may reduce to Euclidean behavior or distort residual magnitude. The baseline itself is below target, so no result is assumed.
BEHAVIOR SIGNAL: Per-item successor branching rank and shared-successor relation.
BEHAVIOR COMPUTATION: On training split only, sort each user's training events by timestamp and count adjacent ordered pairs n_ij. Set b_i=log(1+number of distinct j with n_ij>0); s_ik=1 iff their nonempty successor sets intersect. No cross-split adjacency.
LEAKAGE BOUNDARY: Counts, successor sets, baseline SIDs and code-conditioned fork statistics use only training interactions and the frozen baseline Stage2 artifact; freeze all before candidate Stage2. No validation/test interactions or outcomes enter preprocessing, scale derivation, code statistics, or SID construction; Stage3 evaluates frozen candidate SIDs under the unchanged protocol.
HYPERBOLIC OPERATOR: Poincare-ball distance d_P,c at fixed curvature -c, with exp_0^c mapping residuals and codewords into the ball.
HYPERBOLIC LOCATION: Every residual-code assignment at every RQ level; the actual argmin uses squared Poincare geodesic distance, not a detached auxiliary loss.
COUPLING PATH: Training successor branching and shared-successor data set each candidate codeword's fork compatibility; that term is added directly to the Poincare assignment score, changing argmin, residual trajectory, reconstruction/VQ gradients, and exported SIDs.
COUPLING EQUATION: a_ilc=d_P,c(exp_0^c(r_il),exp_0^c(q_lc))² + alpha_l(b_i-b_c)² + beta_l(1-s_i,c); c_il=argmin_c a_ilc. The behavior terms alter the choice made by the curved metric assignment.
OBSERVABLES: SID and residual-code assignment changes stratified by b_i and shared-successor status; train-only prefix continuation predictability as a diagnostic; final criterion is Stage3 test Recall@10 >0.065. Also compare measured per-step assignment/runtime with baseline.
ABLATION BEHAVIOR OFF: Define the code path by setting alpha_l=beta_l=0; assignment becomes pure Poincare residual quantization, preserving curvature and all other settings. This is a design switch only; do not train this arm.
ABLATION GEOMETRY OFF: Replace d_P,c(exp_0^c(r),exp_0^c(q))² with ||r-q||², leaving the same fork terms, scale constants and assignment procedure. This is a design switch only; do not train this arm.
ABLATION BOTH ON: Use training-only fork statistics and the Poincare score above for the sole candidate run; train once for exactly 3000 Stage2 epochs on four cards and evaluate with the frozen Stage3 protocol, no early stopping.
SPEC EQUATIONS: n_ij=Σ_{u,t in train}1[x_ut=i,x_u,t+1=j]; F_i={j:n_ij>0}; b_i=log(1+|F_i|); s_ik=1[F_i∩F_k≠∅]. Initialize frozen code statistics from baseline train SIDs: b_lc=mean{b_i:c_il^base=c}, s_l(i,c)=mean_{k:c_lk^base=c}s_ik (level 1 may use same global formula). Let x=exp_0^c(r_il), y_c=exp_0^c(q_lc), d_P,c(x,y)=2/sqrt(c) atanh(sqrt(c)||(-x)⊕_c y||). Compute alpha_l=median_i,c(d_P²)/median_{i,c:|b_i-b_lc|>0}(b_i-b_lc)², beta_l=median_i,c(d_P²), all from one fixed baseline initialization; define alpha=0 if denominator is zero. Assign c_il=argmin_c[d_P²+alpha_l(b_i-b_lc)²+beta_l(1-s_l(i,c))]; update residual by existing baseline convention, and use ordinary reconstruction/VQ optimization.
SPEC INPUTS OUTPUTS: Inputs: training adjacency counts, frozen baseline SIDs, encoder residuals, learned codewords, fixed curvature c, and derived scale statistics. Output: candidate SID token per item and quantized residual/reconstruction inputs at each RQ level.
SAFEGUARDS: Use float32 geometry; clamp ball norms to (1-eps)/sqrt(c), clamp atanh argument to 1-eps, use stable zero-norm limits and Poincare Möbius subtraction; normalize/fallback empty successor sets to b=0,s=0; define median of an empty set as zero and skip its term. Compute code statistics once, frozen; ensure codeword and residual coordinates use the same declared tangent convention. Deterministic tie-break by smallest code index. Log finite values and term scales, not tune from diagnostics.
END IDEA

IDEA: fork_geodesic_margin
TITLE: Train encoder separation by a successor-fork geodesic margin
MOTIVATION: Content reconstruction can place behaviorally incompatible items close together even when their likely next-item branches differ, making generative SID prefixes ambiguous for next-item decoding.
NOVELTY: This uses a fixed training-only pair sampler and a Poincare triplet margin on encoder outputs, rather than radial/angular target supervision, a behavior-conditioned transform, or behavior-weighted code assignment. The behavior-derived pair controls which items enter the curved geometric comparison, and its gradient flows into the exact pre-quantizer representation used to make SIDs.
CHANGE: Form anchor-positive pairs from items with shared successors and anchor-negative pairs from high-exposure items with disjoint successors; apply a scale-normalized Poincare geodesic ranking loss to their encoder embeddings before RQ quantization, added to the existing objective with a coefficient derived from baseline reconstruction-loss scale.
SPECIFICATION: From train-only transitions define F_i and degree m_i=Σ_j n_ij. For each anchor i, positive p is the shared-successor item maximizing |F_i∩F_p|/(|F_i∪F_p|+eps); negative n is among items with F_i∩F_n=∅ and m_n≥median(m), chosen as nearest baseline Euclidean embedding to avoid trivial negatives. Define Lfork=mean[max(0, d_P,c(z_i,z_p)-d_P,c(z_i,z_n)+mu)] with mu=median training Poincare distance at baseline initialization. Let gamma=median per-item baseline reconstruction loss / median per-item nonzero triplet hinge at initialization (or zero if no valid triplets). Optimize Lbase+gamma Lfork, with deterministic one positive/negative per valid anchor per epoch from fixed train graph. Existing hard quantization and decoder unchanged.
COST: Precompute sparse F_i, degrees, valid pairs and baseline nearest eligible negatives once: O(E_train) storage and graph work; one triplet distance and hinge per valid anchor per step, O(Bd) extra, B≈1024 at 24556 items/24 steps. Over 24 steps/epoch × 3000 epochs, adds at most 3 Poincare distances/item/step in the encoder batch, negligible versus codebook assignment; no second model or additional run.
HYPOTHESIS: If shared successor branches are predictive beyond content, the geodesic margin will reshape encoder gradients so shared-fork items become closer than high-exposure branch-incompatible items while preserving reconstruction, yielding Stage3 test Recall@10 >0.065 in the sole frozen run. Monitor the actual margin distribution, SID co-prefix rates for sampled train pairs, and fork-stratified prefix predictability as diagnostics, never as admission gates.
RISKS: Hard negatives may encode popularity rather than genuine incompatibility; selecting nearest baseline embeddings can create false negatives; sparse successor sets yield few valid triplets; the loss may compete with reconstruction or be absorbed by the quantizer. Geometry could add no benefit over Euclidean distances.
BEHAVIOR SIGNAL: Training-only shared-successor positive pairs and popularity-gated disjoint-successor negatives.
BEHAVIOR COMPUTATION: From adjacent timestamp-ordered events within each training user sequence only, build F_i and m_i. For each i, choose p by maximum successor-set Jaccard overlap; choose n with empty intersection and m_n at least the train-item median, nearest to i under frozen baseline Euclidean embeddings. Freeze this deterministic pair table.
LEAKAGE BOUNDARY: Pair mining and all medians use training transitions and the already frozen baseline Stage2 embeddings only. Validation/test interactions, labels and scores are never read during pair construction, loss computation, or SID export; Stage3 evaluation consumes the frozen candidate SIDs.
HYPERBOLIC OPERATOR: Squared-curvature Poincare geodesic distance d_P,c with fixed negative sectional curvature -c, used in an explicit triplet ranking hinge.
HYPERBOLIC LOCATION: Auxiliary gradient term on the encoder's pre-quantization latent z_i; this same z_i enters the unchanged RQ quantizer, so the curved gradient changes the learned representation and resulting SID assignments.
COUPLING PATH: Training-only fork pairs select anchor-positive-negative triples; the Poincare distance differences determine the hinge and encoder gradients; the gradients change pre-quantizer embeddings, code assignments and exported SIDs.
COUPLING EQUATION: Lfork=E_[i,p,n](max(0,d_P,c(z_i,z_p)-d_P,c(z_i,z_n)+mu)); L=L_RQVAE+gamma Lfork, where the fork-derived triples determine the arguments of both curved distances.
OBSERVABLES: Margin satisfaction, encoder gradient norms, SID assignments/prefixes for sampled fork pairs, and train-only fork predictability are recorded; only frozen Stage3 test Recall@10 >0.065 judges the candidate.
ABLATION BEHAVIOR OFF: Keep Poincare distance and margin but replace training-derived triples with a deterministic label-free identity/no-pair set, making Lfork=0; this is a specification switch, not a trained arm.
ABLATION GEOMETRY OFF: Keep the exact frozen triples, pair sampler, mu and gamma but replace d_P,c(z_i,z_j) with Euclidean ||z_i-z_j||₂; this is a specification switch, not a trained arm.
ABLATION BOTH ON: Use the frozen training-derived fork triples and Poincare geodesic triplet loss for the one candidate, with exactly 3000 Stage2 epochs on four cards, frozen Stage3 protocol and no early stopping.
SPEC EQUATIONS: F_i={j:Σ_{u,t in train}1[x_ut=i,x_u,t+1=j]>0}, m_i=Σ_j n_ij. p_i=argmax_{p≠i}|F_i∩F_p|/(|F_i∪F_p|+eps), requiring nonempty intersection. n_i=argmin_{n:F_i∩F_n=∅,m_n≥median(m)}||z_i^base-z_n^base||₂. mu=median_{valid i}[d_P,c(z_i^base,z_p^base),d_P,c(z_i^base,z_n^base)] (pooled distances). h_i=max(0,d_P,c(z_i,z_p)-d_P,c(z_i,z_n)+mu). gamma=median_i Lrec_i^base / median_{valid i,h_i^base>0}h_i^base, with gamma=0 if denominator/valid set empty. Train L=L_RQVAE+gamma mean_i h_i. Re-sample nothing: fixed triples for every epoch.
SPEC INPUTS OUTPUTS: Inputs: training-only event sequences, frozen baseline encoder embeddings and per-item reconstruction losses, candidate encoder latent z_i, and curvature c. Output: fork loss and gradients to encoder; the existing quantizer returns the final SID sequence.
SAFEGUARDS: Exclude empty successor sets and self-pairs; require positive overlap/disjointness exactly as specified; use fixed candidate set and deterministic tie-breaking. Clamp Poincare norms to (1-eps)/sqrt(c), atanh inputs to 1-eps; compute maps/distances and loss scaling in float32 with stable small-norm limits. If no valid pairs, set gamma=0 and log that condition (mechanism has no signal). Derive mu and gamma once from baseline initialization; do not retune or use validation/test outcomes.
END IDEA
