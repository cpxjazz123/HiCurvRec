IDEA: l1-geosuccdrift-rq
TITLE: Level-1-only geodesic successor drift of the RQ-VAE codebook, with levels >= 2 left bit-identical to the Euclidean baseline.
MOTIVATION: The three rejected curvature arms all perturbed the deep residual chain and each destroyed deep dispersion (l3_collision 0.549 / 0.943 / 0.960 against a 0.35 ceiling) while level-1 separation stayed mediocre (valid_l1_hard_er 3.885 / 2.488 / 2.755, hit rate 0.122 / 0.263 / 0.182). The problem is separable: level 1 needs more behaviour-driven separation, levels 2..L must be left alone. SIDs are consumed as prefixes, so the first token must encode "what tends to follow" while later tokens stay as dispersed as the baseline.
NOVELTY: Not a per-codeword capacity radius (GEOCAP), not a per-occupant curvature field (OCCURV-FIELD), not per-layer curvature + successor-code centroids + global Sinkhorn balance (strataot). Behaviour never touches the assignment: it moves the LEVEL-1 CODEWORD POSITIONS along geodesics of a fixed Poincare ball using the training-only directed successor centroid of each codeword's occupants, at a step scale equal to the frozen optimizer lr and capped by the measured level-1 code spacing. No Sinkhorn, no balancing, no per-layer curvature strength, no cross-graph transport; the deep chain is literally baseline code.
CHANGE: After every optimizer step each level-1 codeword is transported by an exponential map half-way (Riemannian) toward the mean tangent direction of its occupants' successor centroids in a Poincare ball whose curvature is fixed from the measured encoder scale; the displacement cap is derived from the current median codeword spacing; levels 2..L untouched.
SPECIFICATION:
 1. c = 1/r_s^2 with r_s = median(||z0||) measured on the first epoch (frozen). phi(z) = tanh(sqrt(c)||z||)/(sqrt(c)||z||) z. d_P(u,v) = (1/sqrt(c)) arcosh(1 + 2c||u-v||^2/((1-c||u||^2)(1-c||v||^2))).
 2. Succ(i) = directed next items of i in Stage-2 training sequences (window 1). mu_i = mean_{j in Succ(i)} E[j], E a stop-gradient EMA table (E[j] <- 0.99E[j] + 0.01 z_j, training-batch items only).
 3. s_i = phi(mu_i), stop-gradient.
 4. After the optimizer step: S_c = {i in batch : c1(i) = c} (detached); m_c = mean_{i in S_c} log_{e_c}(s_i).
 5. rho_c = sqrt(c) lambda_{e_c} ||m_c||, lambda_e = 2/(1-c||e||^2); kappa_c = min(1, 0.25 d_nn / rho_c), d_nn = median level-1 codeword pair distance, recomputed once per epoch.
 6. e_c <- exp_{e_c}( eta_t kappa_c m_c ), eta_t = the step's optimizer lr. Switched off for level 1 only per ablation flag; levels 2..L never see c, phi, d_P, log or exp.
 7. Level-1 assignment = argmin_c d_P(phi(z), e_c) with straight-through; levels 2..L argmin_c ||r_l - e_{l,c}||^2 exactly as baseline; r2 = z0 - e_{c1} (baseline Euclidean subtraction with the drifted e_{c1}).
 8. At the end of Stage 2 the codebook is frozen and the SID table committed by the same deterministic forward (drift is an update rule, not a forward rule).
COST: one EMA row update per batch item, 8 successor lookups per item from a static CSR row, per step 1024 log/exp map pairs plus one per-item log at the level-1 codeword (~1.3k transcendentals), and one 1024x1024 Poincare pair-distance median per epoch. ~+3-6% on the quantization block, ~+1-2% total step time; at the frozen scale (24556 training items, 24 steps/epoch, 3000 epochs

= 72000 steps) roughly +3-8 minutes wall clock on four cards, no extra forward pass or epoch.
HYPOTHESIS: If level-1 crowding limits prefix predictability, the drift must lower valid_l1_hard_er from 6.468 to <= 4 and raise the level-1 positive hit rate to >= 0.12 while keeping l3_collision <= 0.35 and level2_distinct_prefixes at the ~7414 baseline scale; worth keeping only if the recorded diagnostics move exactly so and Stage3 test_recall@10 exceeds 0.065 in the single run.
RISKS: drift pulls codewords off occupants and raises ER; the cap makes it a no-op; successor centroids are popularity-dominated; EMA staleness; hub items saturate the ball boundary and destabilise log/exp; level-1 and level-2 codebooks drift apart; the committed drift-free forward may not reflect the trained geometry.
BEHAVIOR SIGNAL: Directed item transitions aggregated per level-1 codeword: the successor centroid of the items assigned to that codeword.
BEHAVIOR COMPUTATION: Counted from the Stage-2 training split only as directed pairs (u_t -> u_{t+1}) within training sessions; static CSR successor list per training item; mu_i = mean EMA embedding of 8 sampled successors per item per step; used only through the codeword-drift update.
LEAKAGE BOUNDARY: the transition graph is built only from the training sequences used to fit the RQ-VAE; validation and test sessions are never scanned, so no validation or test interaction can enter a SID. The EMA table is updated only from training-batch items, the drift is not applied when the SID table is committed, and the committed table is frozen before Stage 3.
HYPERBOLIC OPERATOR: fixed negative curvature c = 1/r_s^2 (r_s measured, not tuned) in the Poincare ball; d_P plus the Riemannian log/exp map at the level-1 codeword, used to take a capped geodesic step.
HYPERBOLIC LOCATION: only the level-1 codebook update and the level-1 assignment distance; levels 2..L keep the Euclidean residual recursion, Euclidean distance and argmin verbatim.
COUPLING PATH: successor pairs -> EMA successor centroid mu_i -> s_i = phi(mu_i) -> Riemannian log at e_c -> capped geodesic step -> drifted e_{c1} -> the same codeword that forms r2 = z0 - e_{c1}. Behaviour sets the direction, curvature sets the path and step length; removing either removes the update.
COUPLING EQUATION: e_c <- exp_{e_c}( eta_t kappa_c mean_{i in S_c} log_{e_c}( phi( mean_{j in Succ(i)} E[j] ) ) ), kappa_c = min(1, 0.25 d_nn / (sqrt(c) lambda_{e_c} ||m_c||)).
OBSERVABLES: valid_l1_hard_er (<= 4), level-1 hit rate (>= 0.12), l3_collision (<= 0.35), level2_distinct_prefixes (~7414), geodesic drift magnitude and moved-codeword fraction, level-1 prefix transfer predictability, Stage3 test_recall@10 (> 0.065, the only judgement).
ABLATION BEHAVIOR OFF: m_c = 0 for every codeword (level-1 codewords shaped by the reconstruction gradient alone); curvature, ball map and level-1 Poincare assignment unchanged.
ABLATION GEOMETRY OFF: c -> 0, phi = identity, Euclidean difference step and Euclidean distance: e_c <- e_c + eta_t kappa^E_c mean_{i in S_c}(mu_i - e_c), kappa^E_c = min(1, 0.25 d^E_nn / ||mean(mu_i - e_c)||); behaviour term unchanged.
ABLATION BOTH ON: the full coupled run above, c = 1/r_s^2, training-only successor centroids, levels 2..L on the baseline Euclidean recursion.
SPEC EQUATIONS: as in items 1-6 plus mu_i = mean_{j in Succ(i)} E[j], m_c = mean_{i in S_c} log_{e_c}(phi(mu_i)), e_c <- exp_{e_c}(eta_t min(1, 0.25 d_nn / |||m_c|||_{e_c}) m_c). Per step: encoder -> z0; r

1 = phi(z0); c1 = argmin_c d_P(r1, e_c); r2 = z0 - e_{c1}; levels 2..L baseline; loss; backward; optimizer.step(); if epoch > 0: update E, recompute S_c, m_c, cap, exp-map update of level-1 codewords only.
SPEC INPUTS OUTPUTS: in: level-1 codewords in the ball, batch z0, detached c1, CSR successor lists, EMA table E, frozen lr eta_t, measured r_s, per-epoch d_nn. out: updated level-1 codewords (same count, same ball, index->position bijection) plus diagnostics (kappa_c, drift magnitude, moved count); nothing else in the model changes.
SAFEGUARDS: clamp radii to (1 - 1e-3)/sqrt(c) after each exp map; clamp artanh argument to 1 - 1e-7, arcosh argument >= 1; zero the step if ||m_c|| or d_nn is non-finite/zero; skip drift during epoch 0 while r_s and d_nn are measured; skip |S_c| = 0; detach m_c; apply only after optimizer.step(); cap displacement at 0.25 d_nn and at eta_t; assert no NaN and no collapse within 1e-3 d_nn; no tuned constants (r_s measured, c derived, eta_t frozen, 0.25 and the Riemannian midpoint documented defaults).
END IDEA
