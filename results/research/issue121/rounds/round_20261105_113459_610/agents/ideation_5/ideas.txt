IDEA: shalcurv-cont-anchor-rq
TITLE: Shallow-only Poincare curvature with a behaviour continuation anchor: hyperbolic level-0/1 assignment and log-map hand-off, deep levels byte-identical baseline
MOTIVATION: The three rejected arms (GEOCAP, OCCURV-FIELD, strataot) all bought shallow separation at the price of deep collapse (l3_collision 0.549/0.943/0.960 vs baseline 0.2745; level2_distinct_prefixes 4236/784/720 vs 7414). Separately, RQ-VAE SIDs describe an item's content but not where the sequence goes, so Stage 3 must learn next-SID prediction from prefixes that carry no behavioural information. This idea isolates curvature in the shallow chart, keeps levels 2-3 literally the baseline recursion, and makes the level-1 code continuation-aware so an item's prefix already encodes its likely continuations.
NOVELTY: Not per-codeword capacity radii from behaviour demand (GEOCAP), not reach-as-curvature occupancy cells (OCCURV), not per-layer curvature with successor code centroids plus Sinkhorn (strataot), not cross-graph dual-segment transport. New here: (a) a popularity-adjusted, Dice-normalised directed successor distribution, compressed per item into a measured concentration alpha_x, forms a hyperbolic continuation anchor b_x; (b) one convex score S(k) mixes the geodesic residual distance with the geodesic anchor distance, evaluated on a geometric shortlist of M=8 codewords, so behaviour can only reorder inside the geometric neighbourhood rather than move codes across the space; (c) the shallow residual is handed to the deep levels through a log-map plus parallel-transport pair anchored at the chosen level-0 code, so the shared deep codebooks see residual vectors in one common origin frame; (d) curvature is exactly zero for level>=2, with Euclidean argmin and the unmodified baseline residual recursion; no Sinkhorn anywhere.
CHANGE: Levels 0 and 1 are quantised with Poincare geodesic distances and exp/log/parallel transport on a ball of fixed curvature -kappa (kappa derived from the measured RMS scale of training encoder outputs), and level 1 is selected by a single score that adds a behaviour continuation-anchor term to the geodesic residual term; levels 2 and 3 keep the baseline Euclidean argmin and residual recursion unchanged and receive only the transported shallow residual.
SPECIFICATION: sigma = RMS of ||z|| over epoch 1 (detached, frozen); kappa = 1/sigma^2, ball radius sigma. u0 = exp_0(z); k0 = argmin_k d_P(u0,e_{0,k})^2; v1 = log_{e_{0,k0}}(u0)/(1-kappa*||e_{0,k0}||^2) = PT_{e_k0->0}; u1 = exp_0(v1); C = the M=8 codewords with smallest d_P(u1,e_{1,k}); p_x, alpha_x, b_x from the frozen train transition table; S(k) = (1-alpha_x)*d_P(u1,e_{1,k})^2 + alpha_x*d_P(e_{1,k},b_x)^2; k1 = argmin_{k in C} S(k). Then s1 = v1 - e_{1,k1} and for l=2,3: k_l = argmin_k ||s_{l-1}-e_{l,k}||^2, s_l = s_{l-1}-e_{l,k_l} (baseline, untouched). Reconstruction u0_hat = exp_{e_{0,k0}}((1-kappa*||e_{0,k0}||^2)*(e_{1,k1}+e_{2,k2}+e_{3,k3})), z_hat = log_0(u0_hat), loss = ||z-z_hat||^2 with code indices detached (straight-through); assignment and reconstruction use the same codeword positions at every level.
COST: Stage-2 step at the frozen scale (B=1024, D=32, K=256): baseline three argmins ~2.5e7 MACs; added level-0/level-1 Poincare distances ~1.7e8 MACs, exp/log/PT O(B*D), shortlist O(B*8): under 3% of Stage-2 step time and ~0% at Stage 3. Behaviour tables rebuilt once per epoch (24 steps), O(E) with E the train transition count: negligible across 3000 epochs = 72000 steps. No extra forward pass, no extra loss, no new parameters beyond the same four codebooks.
HYPOTHESIS: If shallow curvature plus behaviour-only shortlist reordering preserves deep dispersion, the single run should show valid_l1_hard_er <= 4 and positive hit rate >= 0.12 together with l3_collision <= 0.35 and level2_distinct_prefixes in the 7414 range, and Stage3 test Recall@10 above 0.065; observable as (i) a materially non-zero fraction of items whose coupled level-1 argmin differs from the geometric argmin while p95 of ||v1||/sigma stays bounded, and (ii) train-only prefix->next-prefix predictability of the level-1 code rising relative to the geometric assignment.
RISKS: The predictive pull inflates the shallow residual, deep residual norms grow and l3_collision climbs past 0.35 - the exact failure mode of OCCURV and strataot; the M=8 shortlist and the concentration-derived alpha are the only limits.; Successor distributions may be diffuse, so alpha_x is small for most items, the SIDs barely move, and the run reproduces baseline 0.0555 instead of beating 0.065.; Hub items with concentrated successors get pulled hard, many of their level-1 codes collapse onto one anchor, which can lower level2_distinct_prefixes and imbalance the level-1 codebook.; Poincare operators near the ball boundary go non-finite in fp32 if kappa is overestimated from a noisy first epoch.; The anchor table depends on the previous epoch's frozen level-1 codes, so an early code collapse can lock in a bad table.; With one run and no ablation arms, a result landing between the arms cannot attribute the effect to the coupling.
BEHAVIOR SIGNAL: Popularity-adjusted directed successor distribution of each training item over level-1 codewords, together with its normalised-entropy concentration.
BEHAVIOR COMPUTATION: From the TRAIN split only: count consecutive pairs c(i->j) inside each user history; Dice-normalise w(i->j) = c(i->j)/(deg(i)+deg(j)) so hub successors are downweighted; map successors to codewords with the frozen, detached previous-epoch level-1 assignment l1 and set p_i[k] = sum_{j:l1(j)=k} w(i->j) / sum_j w(i->j); alpha_i = clip(1 - H(p_i)/log K1, 0, 1) with H the Shannon entropy; alpha_i = 0 for items with no outgoing train transition. Tables are rebuilt at each epoch boundary from train data only and are never differentiated.
LEAKAGE BOUNDARY: The transition table, the kappa scale and the frozen l1 map are functions of Stage-2 training sequences and of encoder outputs on training items only; validation and test sequences are never read during SID construction, and the test split is touched only by the frozen Stage-3 protocol after SIDs are fixed. Items without train transitions get alpha = 0, so no validation or test interaction can alter a code.
HYPERBOLIC OPERATOR: Poincare ball of fixed negative curvature -kappa with kappa = 1/sigma^2 derived from the measured RMS scale sigma of training encoder outputs (ball radius sigma, metric factor 4 convention): Moebius addition, geodesic distance d_P(x,y) = (2/sqrt(kappa))*artanh(sqrt(kappa)*||(-x)(+)y||), exp_0 and log_0, parallel transport PT_{e->0}(v) = v/(1-kappa*||e||^2) and its inverse (1-kappa*||e||^2)*v, and the tangent-space hyperbolic mean exp_0(sum_k p_k log_0(e_k)).
HYPERBOLIC LOCATION: In the quantizer and in training: the level-0 and level-1 codebook assignment (geodesic distance) and the shallow residual hand-off v1 delivered to the deep codebooks (log map plus parallel transport). Levels 2 and 3 run with kappa = 0, i.e. plain Euclidean argmin and the baseline residual recursion.
COUPLING PATH: Behaviour builds p_x, alpha_x and b_x; those enter the single level-1 score S(k) that also contains the geodesic distance d_P; the argmin of S fixes k1, which fixes the transported shallow residual v1 - e_{1,k1}, the deep codes and the reconstruction. Removing behaviour (alpha = 0, b unused) reduces the score to the pure geodesic argmin; removing curvature reduces d_P, exp/log and PT to their kappa->0 limits and the quantizer to baseline RQ. Neither half can be deleted without changing the chosen code.
COUPLING EQUATION: S(k|x) = (1 - alpha_x)*d_P(u1, e_{1,k})^2 + alpha_x*d_P(e_{1,k}, b_x)^2, with b_x = exp_0( sum_k p_x[k]*log_0(e_{1,k}) ) and alpha_x = clip(1 - H(p_x)/log K1, 0, 1).
OBSERVABLES: valid_l1_hard_er (bar <= 4, expect 2.5-4), positive hit rate (bar >= 0.12), l3_collision (bar <= 0.35), level2_distinct_prefixes (not below the 7414 order of magnitude), p50/p95 of ||v1||/sigma and ||s1||/sigma, the fraction of items whose coupled level-1 argmin differs from the geometric argmin, train-only prefix->next-prefix predictability of the level-1 code, and Stage3 test Recall@10 (target > 0.065 against baseline 0.0555).
ABLATION BEHAVIOR OFF: alpha_x set to 0 and b_x unused, so the level-1 code is the pure geodesic argmin over the ball and only the curved shallow chart plus the log-map hand-off remain; isolates the behaviour contribution.
ABLATION GEOMETRY OFF: kappa -> 0 exact limits: d_P becomes squared Euclidean distance, log becomes subtraction, PT becomes identity, the hyperbolic mean becomes the weighted Euclidean mean and exp_0 becomes identity, with the behaviour terms still switched on; isolates curvature.
ABLATION BOTH ON: The full coupled run in specification - the only arm actually trained (one run, frozen 3000-epoch Stage-2 budget on four cards, frozen Stage-3 protocol, no early stopping, no sweep over any constant, no seed repetition).
SPEC EQUATIONS: sigma = rms(||z||) over epoch 1, frozen; kappa = 1/sigma^2. exp_0(v) = tanh(sqrt(kappa)*||v||/2)*v/(sqrt(kappa)*||v||); log_0(u) = (2/sqrt(kappa))*artanh(sqrt(kappa)*||u||)*u/||u||. x(+)y = ((1+2k<x,y>+k||y||^2)x + (1-k||x||^2)y)/(1+2k<x,y>+k^2||x||^2||y||^2), k = kappa. d_P(x,y) = (2/sqrt(kappa))*artanh(sqrt(kappa)*||(-x)(+)y||). u0 = exp_0(z); k0 = argmin_k d_P(u0,e_{0,k})^2; v1 = log_{e_{0,k0}}(u0)/(1-kappa*||e_{0,k0}||^2); u1 = exp_0(v1); C = shortlist_M8(u1); S(k) = (1-alpha_x)*d_P(u1,e_{1,k})^2 + alpha_x*d_P(e_{1,k},b_x)^2; k1 = argmin_{k in C} S(k); s1 = v1 - e_{1,k1}; k_l = argmin_k ||s_{l-1}-e_{l,k}||^2, s_l = s_{l-1}-e_{l,k_l} for l = 2,3; u0_hat = exp_{e_{0,k0}}((1-kappa*||e_{0,k0}||^2)*(e_{1,k1}+e_{2,k2}+e_{3,k3})); z_hat = log_0(u0_hat); L = ||z-z_hat||^2 (plus the baseline commitment term if present). Backward: indices detached (straight-through), shallow exp/log/PT differentiated exactly in z and in e_{0,*}, e_{1,*}.
SPEC INPUTS OUTPUTS: Inputs: encoder output z in R^32 per training item, four codebooks, the train-only transition table and frozen level-1 map, and fixed hyperparameters (K=256 per level, M=8, kappa from sigma). Outputs: codes (k0,k1,k2,k3) at fixed codeword positions, reconstruction z_hat and the RQ-VAE loss; per-item side outputs p_x (sparse), alpha_x, b_x, ||v1|| and the coupled-vs-geometric disagreement flag.
SAFEGUARDS: Clip every codebook row to ||e|| <= 0.9*sigma after each optimiser step; clamp artanh arguments to <= 1-1e-7 and arcosh arguments to >= 1+1e-7; floor kappa at 1e-6 and never recompute sigma after epoch 1; normalise p_x with epsilon 1e-12 and clip alpha_x to [0,1]; if any shallow operator returns a non-finite value for a batch, fall back to the Euclidean branch for that batch and log it (no tuning); M=8 is fixed a priori from the 3-bit level-1 shortlist width and is never searched; record p50/p95 residual norms every 100 steps; no extra loss terms, warm-ups, sweeps, ablation arms or seed repetitions.
END IDEA
