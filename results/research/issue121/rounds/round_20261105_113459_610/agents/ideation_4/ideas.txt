IDEA: brancurv-l1-rq
TITLE: Branching-adaptive shallow curvature: behaviour-set radial coordinates turn the level-1 Poincare metric into per-item angular resolution, deep levels left exactly Euclidean.
MOTIVATION: The measured failure of every curvature arm so far is depth-localised: level-1 separation improves (ER 6.47 -> 2.5-3.9) but level-2 distinct prefixes collapse from 7414 to 720-4236 and l3_collision goes 0.27 -> 0.55-0.96, so Stage3 recall never passes 0.065. The likely cause is that curved arms also moved the reconstruction vectors that the untouched deep codebooks quantize, shrinking the radial variance of the residual cloud. Separately, baseline level-1 hard ER 6.468 says the first token is decided by a magnitude-dominated Euclidean metric that cannot separate fine topics. The idea fixes both in one place: curvature acts only on which level-1 cell an item falls into, and only through the metric, while the residual handed to the baseline deep levels keeps its full radial range.
NOVELTY: Differs from GEOCAP (per-codeword geodesic capacity radii), OCCURV-FIELD (per-occupant curvature field on the residual at all levels), strataot (per-layer curvature + successor-code centroids + full-field Sinkhorn) and from the falsified transport/ladder/taper shapes on three axes: (a) the behaviour signal is the popularity-adjusted directed out-degree of each item (a rarity-filtered graph-neighbour count), not demand, reach or successor centroids; (b) curvature is a single measured constant, with no per-code or per-layer curvature magnitude anywhere; (c) the level-1 codebook parameter stays Euclidean and is used verbatim as the residual subtraction vector, so the deep recursion is literally the baseline code path. New device: the item's behaviour branching is used as a hyperbolic radial coordinate, so negative curvature converts it into local angular resolution.
CHANGE: Before level-1 assignment only, the encoder output is lifted to a Poincare ball of radius R (fixed from catalogue size and measured mean branching): the item direction comes from the encoder, its ball radius from its popularity-adjusted out-degree, and the level-1 code's ball radius from its own Euclidean norm. The level-1 code is the argmin of the Poincare distance; the chosen Euclidean code vector is then subtracted exactly as in the baseline and every deeper level runs the unmodified Euclidean RQ recursion.
SPECIFICATION: Precompute once from the TRAINING split: directed pair counts n_ij, item counts n_i, M = sum n_ij; adjusted successor set S_i = { j : n_ij > n_i n_j / M }; s_i = |S_i|; b_bar = mean_i s_i; T_i = log(1+s_i); T_bar = mean_i T_i; R = max(1, log(N_items)/log(1+max(b_bar,1.1))); kappa = -1/R^2; T_max = 2 R atanh(0.95). Cache T_i (float32) and a USE_BEHAV flag (T_i or T_bar). Per training step, level 1 only: zhat = z/max(||z||,eps); r_i = R tanh(T_i/(2R)); u_i = r_i zhat; rho_k = R tanh(||e_k||/(2R)); c_k = rho_k e_k/max(||e_k||,eps); d_k = arcosh(1 + 2 R^2 ||u_i - c_k||^2 / ((R^2-||u_i||^2)(R^2-||c_k||^2))); k1 = argmin_k d_k. Then z_q1 = e_{k1}; residual res = z - z_q1 (unchanged baseline formula, straight-through unchanged); levels 2..L run the baseline Euclidean argmin over their own codebooks with no curvature and no Sinkhorn. Loss: baseline RQ-VAE loss (reconstruction + codebook + commit) unchanged; no extra loss term, no extra hyperparameter, no temperature, no clip bound, no Sinkhorn.
COST: One extra B x 256 x d elementwise pass per step (B = batch, d = encoder width, 256 = level-1 codebook): ~2M flops, well under 1% of a transformer step; expected +2 to 4% wall clock over 72,000 steps (3000 epochs x 24 steps) on four cards. One offline graph pass over the Stage-2 training sequence file (O(nnz log N), minutes, once) plus 24556 float32 radii (~100 KB). No extra parameters, no extra codebook, no extra forward pass at inference (radii are static per item).
HYPOTHESIS: Worth keeping iff the level-1 slot can be made a vocabulary of (topic direction, behaviour branching) while leaving magnitude to the deep levels: then level-1 usage becomes direction-driven and more uniform (valid_l1_hard_er <= 4, first-token positive hit >= 0.12), the residual keeps its radial variance so level2_distinct_prefixes stays ~7414 and l3_collision <= 0.35, and Stage3 test Recall@10 exceeds 0.065. Observed through the frozen diagnostic tool (level-1 ER, first-token hit, level-2 distinct prefixes, l3_collision) plus the single Stage3 run.
RISKS: Level-1 assignment ignoring ||z|| could push residual norms above the deep codebooks' trained range early in training and slow deep convergence.; Hub items (large r_i, near the ball boundary) may occupy very few level-1 codes because the stretched metric concentrates them on the few codes whose radial coordinate matches, re-concentrating usage.; Behaviour-graph sparsity: rare items with s_i = 0 sit at the ball centre and get a near-degenerate coarse assignment.; A single run cannot separate 'curvature helped' from seed noise.; The measured R may be small enough that the ball saturates and the metric behaves like a hard angular partition.
BEHAVIOR SIGNAL: Popularity-adjusted directed transition out-degree per item (a behaviour-conditioned graph-neighbour count), one scalar per item.
BEHAVIOR COMPUTATION: From the Stage-2 TRAINING split sequences only. Count directed item pairs n_ij within training sequences of training users and item marginal counts n_i, M = total counted transitions. Item j is an adjusted neighbour of i iff n_ij > n_i * n_j / M (co-consumption above the popularity-only expectation). s_i = number of such j; T_i = log(1+s_i); T_bar = catalogue mean; both frozen before the first training step.
LEAKAGE BOUNDARY: The graph is built exclusively from training-split sequences of training users; validation and test interactions are never read, no evaluation metric feeds back, and the radii are computed once and frozen, so no validation or test interaction can influence the level-1 assignment, the codebook, or any SID. The catalogue size and the encoder both come from training data; the SIDs are produced by one pass over the catalogue with frozen radii.
HYPERBOLIC OPERATOR: Poincare-ball distance with a single fixed negative curvature kappa = -1/R^2, R = log(N_items)/log(1+b_bar) measured from the training graph (R ~ 4-5 at 24556 items for b_bar ~ 8-12, kappa ~ -0.05); items enter via the hyperbolic exp map exp_0^kappa(T_i * zhat) = R tanh(T_i/(2R)) zhat and codes via exp_0^kappa(||e_k|| * ehat_k).
HYPERBOLIC LOCATION: Level-1 assignment only (the argmin that picks the first SID token). Levels >= 2 use no curvature: the residual recursion, the per-level codebooks, the Euclidean argmin and the codebook updates are the baseline code path, and no Sinkhorn or balancing exists anywhere.
COUPLING PATH: One argmin: the behaviour signal fixes the item's radial coordinate in the ball, the curvature fixes the metric in which that radius implies an angular sensitivity, and the resulting distance decides the level-1 code that is then subtracted from the residual. Removing behaviour makes all radii equal (curvature then acts uniformly and the assignment loses its per-item resolution); removing curvature makes the same quantities Euclidean and the assignment becomes a radial-offset comparison. Either removal changes the same numbers that produce the level-1 token.
COUPLING EQUATION: k1(i) = argmin_k d_kappa( R tanh(T_i/(2R)) * z_i/||z_i|| , R tanh(||e_k||/(2R)) * e_k/||e_k|| ), with T_i = log(1 + s_i) the behaviour term, kappa = -1/R^2 the curved term, and levels >= 2 unchanged: k_l = argmin_k ||res_{l-1} - e^{(l)}_k||_2, res_l = res_{l-1} - e^{(l)}_{k_l}.
OBSERVABLES: Level-1 usage entropy and valid_l1_hard_er should fall from 6.468 toward <= 4; first-token positive hit rate should rise from baseline (comparison point: GEOCAP 0.1222, OCCURV 0.2629); items per level-1 code should become more uniform; level2_distinct_prefixes should stay at baseline scale (~7414, not 720-4236) and l3_collision should stay <= 0.35 because the residual keeps its radial variance; Stage3 test Recall@10 is the judgement (target > 0.065 against baseline 0.0555 / best 0.0638).
ABLATION BEHAVIOR OFF: USE_BEHAV=False: every item gets T_i = T_bar (the measured catalogue mean), so all items sit at one ball radius and the assignment reduces to a curvature-only angular metric with no per-item branching resolution; same code, one flag, not trained in this round.
ABLATION GEOMETRY OFF: USE_CURV=False: the kappa -> 0 limit is used, i.e. u_i = T_i zhat_i, c_k = ||e_k|| ehat_k and d_k = ||u_i - c_k||_2 (plain Euclidean), so behaviour still sets a radial offset but there is no stretched metric; same code, one flag, not trained in this round.
ABLATION BOTH ON: USE_BEHAV=True and USE_CURV=True: the full coupled level-1 Poincare assignment with behaviour-derived item radii and Euclidean reconstruction; this is the single arm that is trained (3000 Stage-2 epochs, four cards, frozen Stage-3 protocol, no early stopping, no tuning, no multi-seed).
SPEC EQUATIONS: (1) S_i = { j : n_ij > n_i n_j / M }, s_i = |S_i|, T_i = log(1+s_i), b_bar = mean s_i, R = max(1, log(N_items)/log(1+max(b_bar,1.1))), kappa = -1/R^2, T_max = 2R atanh(0.95). (2) r_i = R tanh(min(T_i,T_max)/(2R)), u_i = r_i z_i/max(||z_i||,eps). (3) rho_k = R tanh(||e_k||/(2R)), c_k = rho_k e_k/max(||e_k||,eps). (4) d_ik = arcosh(1 + 2R^2||u_i-c_k||^2 / max((R^2-||u_i||^2)(R^2-||c_k||^2), 1e-6 R^4)). (5) k1 = argmin_k d_ik; z_q1 = e_{k1}; res_1 = z - z_q1. (6) for l >= 2 exactly baseline: k_l = argmin_k ||res_{l-1}-e^{(l)}_k||_2, res_l = res_{l-1}-e^{(l)}_{k_l}. (7) loss = baseline RQ-VAE loss, unmodified; gradients reach z only through res_1 (standard straight-through), the argmin carries no gradient. Pseudocode: radii table once -> per step: z = encoder(batch); r = radius[item_id]; u = r * normalize(z); level 1 only compute d (B x 256) by (4); k1 = argmin; res = z - E1[k1]; levels 2..L baseline quantize(res); decoder loss; backward.
SPEC INPUTS OUTPUTS: Inputs: encoder output z (B x d), level-1 codebook E1 (256 x d, Euclidean, unchanged), frozen per-item radii r (24556 float32), fixed R and kappa. Outputs: level-1 code index k1 (B,) and the Euclidean code vector e_{k1} used for the straight-through reconstruction and for the residual handed to the baseline deep levels; no change to the interface of any deeper level, to the decoder, or to the Stage-3 input format.
SAFEGUARDS: ||z|| and ||e_k|| floored at 1e-6; radii clipped so r <= 0.95R via T_max so both ball denominators stay positive; the two-ball denominator floored at 1e-6 R^4 before arcosh; arcosh argument floored at 1+1e-7; kappa implemented as the pair (R, sign) so the Euclidean arm is the exact kappa->0 limit rather than a separate code path; b_bar floored at 1.1 so R stays finite and >= 1; items with s_i = 0 get T_i = 0 (ball centre) by definition, not by a magic constant; a NaN guard that raises instead of silently returning a zero distance; no constant in the mechanism is chosen by trial - R, T_i and T_bar are measured, 0.95 and 1.1 are documented boundary defaults, and the only free quantities (codebook size, loss weights) are inherited from the baseline.
END IDEA
