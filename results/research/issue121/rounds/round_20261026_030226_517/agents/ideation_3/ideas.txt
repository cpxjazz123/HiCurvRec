IDEA: branch_gate_curved_prefix
TITLE: Branch-conditioned Lorentz prefix routing with a decisive third code
MOTIVATION: Items reached through many distinct next-item contexts need a stable, coarse first token, while the third token should resolve the remaining ambiguity using the actual train-only successor branch.
NOVELTY: Instead of adding successor distance as an independent loss or applying it to a residual, use per-item successor-branch entropy to set the curvature of a single Lorentz nearest-code assignment at level 3; the selected level-3 code is then constrained through its three-token prefix representative. Keep collision extension as a separate deterministic post-assignment operation.
CHANGE: Compute normalized branching entropy per item from training transitions, convert it to a bounded item curvature, and assign level-3 residuals by Lorentz distance under that curvature. Optimize the three-token representatives (levels 1-3 only) with a margin continuation penalty; afterward order items sharing a three-token prefix by training successor popularity to allocate the small fourth-token extension alphabet.
SPECIFICATION: Let b_i be normalized outgoing-successor entropy and p_i be log(1+training successor count), both computed by make_train_behavior(train_split). For level 3 use k_i=clip(k0*exp(alpha*(b_i-mean(b))), kmin,kmax), kmin,kmax>0. Map level-3 residual z_i to Lorentz space with exp_o^{k_i}; choose c*=argmin_c d_L,k_i(exp_o^{k_i}(z_i),c)^2. The prefix penalty uses only representative vectors q123 (composed from levels 1,2,3): for each training transition i->j with same first two assigned codes, penalize max(0,m+d_L(q123_i,q123_j) - d_L(q123_i,q123_n)), where n is a sampled non-successor with same first-two prefix. Train the four-level RQ-VAE reconstruction/commitment objective plus lambda times this penalty. Within each exact first-three-code bucket, sort by (-p_i,item_id), assign extension ranks in fixed chunks of size K=32 (fourth token 0..31); never include level 4 in prefix-penalty averages.
COST: Behavior statistics are one preprocessing pass over train transitions, O(E_train); curvature and distance require O(N*256) level-3 code comparisons per assignment step and one sampled prefix triplet per transition minibatch. Relative to baseline: modest (about one extra level-3 distance evaluation and sampled penalty; expected 5-15% step time, measure). Frozen scale: 24 steps/epoch * 3000 = 72,000 steps; add at most 72,000 level-3 batched distance calls and 72,000 sampled triplet-penalty calls, each on the existing minibatch (no all-pairs matrix); 4 cards data-parallel.
HYPOTHESIS: High-branching items benefit from greater negative curvature's hierarchy separation, making third codes more branch-informative; same-prefix continuation margin makes T3 predictable, and popularity ranks make T4 nearly deterministic. Keep only if both-on improves gold-prefix survival at depths 3 and 4 and teacher-forced T3/T4 accuracy, with Stage 3 test_R@10 >0.065; report L1 Hard ER on the canonical 52,855 pairs and ten fixed negatives as a guard against pathological collapse.
RISKS: Curvature heterogeneity may destabilize shared codebooks; entropy is noisy for rare items; sampled negatives may produce false continuation structure; a 32-slot extension bucket can be exceeded; a coarse L1 gain can be lost to code usage imbalance. ER may rise or fall, so it is diagnostic, not the selection rule.
BEHAVIOR SIGNAL: Per-item normalized entropy of the directed training-only next-item distribution, plus the same training-only outgoing count for extension ordering.
BEHAVIOR COMPUTATION: make_train_behavior(train_split) returns tensors b[N] and p[N]. Count directed adjacent item pairs only inside each user's training sequence; b_i=-sum_j P(j|i)log(P(j|i)+eps)/log(max(2,degree_i)); p_i=log(1+sum_j count(i,j)). No validation/test sequences are read.
LEAKAGE BOUNDARY: The function accepts only the train split and returns item-indexed tensors; SID fitting, curvature, penalty sampling, and extension ordering consume only those tensors and training embeddings. Freeze resulting SID mapping before Stage 3 evaluation; validation/test interactions are inaccessible to construction.
HYPERBOLIC OPERATOR: Lorentz-model distance d_L,k with trainable/fixed negative curvature -k, and Lorentz exponential map exp_o^k; k is bounded to [0.05,2.0].
HYPERBOLIC LOCATION: Level-3 code assignment and the level-3 three-token-prefix continuation penalty during Stage 2 quantizer training.
COUPLING PATH: Training outgoing entropy b_i sets k_i, which changes exp_o and Lorentz distances to level-3 codewords, changing the chosen third code; that changed code defines q123 for the continuation margin. Popularity p_i separately determines only deterministic fourth-token order after the prefix is frozen.
COUPLING EQUATION: c3(i)=argmin_c d_L,k_i(exp_o^k_i(z3_i),c)^2; k_i=clip(k0 exp(alpha*(b_i-mean(b))),kmin,kmax); L=L_RQVAE+lambda*max(0,m+d_L,k0(q123_i,q123_j)-d_L,k0(q123_i,q123_n)).
OBSERVABLES: Compare L1 Hard ER on the fixed canonical 52,855-pair/10-negative set; gold-prefix survival depths 1,2,3,4; teacher-forced top-1 T3 and T4; Stage 3 test_R@10. Predicted T3 rises materially above the measured 0.338 coarse-geodesic arm, T4 approaches the resample 0.977, depth-3/4 survival and test recall rise, while L1 ER may change but should not exhibit total collapse. Include explicit behavior-off, Euclidean geometry-off, and both-on runs.
ABLATION BEHAVIOR OFF: Set b_i=mean(b) and p_i=mean(p) for every item, retaining the same Lorentz implementation, continuation margin, K, and compute. This removes item-conditioned behavior from curvature and extension ordering; expect lower T3/T4 and prefix survival than both-on.
ABLATION GEOMETRY OFF: Replace exp_o^k and d_L,k in assignment and continuation penalty with matched Euclidean z3 and squared Euclidean distance, retaining actual b_i-dependent scale in the assignment score only as a matched scalar temperature is not allowed: instead map k_i to a Euclidean anisotropic metric M_i=diag(exp(k_i),exp(-k_i),1...) and use (z-c)^T M_i(z-c), so behavior remains coupled but curvature is absent. This isolates geometry; expect worse T3/prefix survival than both-on.
ABLATION BOTH ON: Use actual b_i-conditioned Lorentz map/distance and actual p_i popularity ordering, with the three-level-only continuation margin; evaluate all listed observables and fixed Stage 3 protocol.
SPEC EQUATIONS: For each batch: compute u_i=exp_o^{k_i}(z3_i); a_i=argmin_c d_L,k_i(u_i,c)^2; q123_i=compose(q1_i,q2_i,c[a_i]); sample transition (i,j) and matched-prefix non-successor n; Lcont=relu(m+d_L,k0(q123_i,q123_j)-d_L,k0(q123_i,q123_n)); update model/codebooks on L_RQVAE+lambda Lcont. After training, per prefix sort by (-p_i,item_id), set t4=floor(rank/32) clipped to available extension codes; output fixed four-token SID. Prefix quantities never include t4.
SPEC INPUTS OUTPUTS: Inputs: train split sequences, item embeddings, four-level RQ-VAE codebooks, train transitions, hyperparameters k0/alpha/kmin/kmax/lambda/m and K=32. Outputs: trained codebooks, item SID tensor [N,4], b[N], p[N], and logged L1 ER/prefix survival/T3-T4 accuracies. The behavior function must return real, mean-filled, and zero-filled controls for independent coupling checks.
SAFEGUARDS: Clamp probabilities before log; define entropy as zero for outdegree<2; bound k away from zero and cap Lorentz coordinates/norm before exp map; stable acosh(max(1+eps, Lorentz inner product)); normalize tangent vectors; gradient-clip; deterministic item-id tie-break; extension code count fixed and explicitly fail/log overflow rather than silently reusing rank; sample non-successor only among train items; assert continuation tensors are q123 only.
END IDEA

IDEA: transition_balanced_curved_residual
TITLE: Successor-balanced geodesic residual transport for three-token prefixes
MOTIVATION: A transition's next item should receive a third code that is both useful for reconstructing item semantics and geometrically aligned with its training successor context; the observed coarse-first-level solution otherwise leaves level 3 too weak to disambiguate continuation.
NOVELTY: Couple behavior and geometry in a minibatch transport assignment: training transition counts define row demand weights and Lorentz geodesic costs jointly determine which level-3 residual codes receive items. This is not a successor-geodesic auxiliary loss; behavior changes the constrained assignment itself. The fourth token remains deterministic popularity-ranked extension, not a fourth interchangeable quantizer level.
CHANGE: At level 3, use a small entropic transport solve over item-to-code assignments with behavior-derived item demand and geodesic item-to-code cost. Add a three-token-prefix balance hinge that explicitly pushes every overloaded prefix's represented successor mass to a sibling prefix by a margin; then sort members of each final three-token prefix by training successor popularity for extension tokens.
SPECIFICATION: make_train_behavior(train_split) returns s_i=log(1+incoming train transition count) and a sparse directed transition matrix A_ij (counts, row normalized). At each minibatch, form Lorentz points u_i=exp_o^k(z3_i), codewords v_c, C_ic=d_L,k(u_i,v_c)^2. Set row mass r_i=(1+gamma*s_i)/sum_i(1+gamma*s_i), column capacity h_c=1/256. Compute entropy-regularized Sinkhorn T=argmin_{T>=0} <T,C>+tau sum T(log T-1), T1=r, T^T1=h; use T as soft assignment for level-3 commitment/reconstruction gradients and hard argmax_c T_ic for emitted codes. For each three-code prefix g=(c1,c2,c3), define successor mass M_g=sum_{i in g} sum_j A_ij * 1[j's first-two prefix differs from g's first-two prefix]. For sibling prefixes sharing first two codes, train Lbal=sum_(g,h) relu(m+M_g-M_h)^2 for ordered pairs where M_g> M_h; compute only g,h from levels 1-3. After training, within each g rank items by (-log(1+sum_j A_ij), item_id) and allocate fixed 32-item extension slots.
COST: Sparse transition aggregation is O(E_train); each Sinkhorn minibatch is O(B*256*I) for I=8-12 iterations, plus Lorentz costs O(B*256), and prefix balance is O(number of occupied prefixes squared within matched first-two groups), implement with top sibling pairs to bound it. At frozen scale, 72,000 optimizer steps; with B equal to baseline minibatch, 8-12 small Sinkhorn iterations per step; expect roughly 10-25% Stage 2 wall-clock overhead, record actual step time. No full 24,556^2 matrix or extra epoch.
HYPOTHESIS: Behavior-weighted capacity prevents transition-important items from being stranded in overloaded level-3 codes, while the curved cost assigns semantically and behaviorally compatible residuals. T3 top-1 should rise toward 0.7, the level-3 prefix margin should increase depth-3/4 survival, and popularity-ranked extension should make T4 highly accurate with a small alphabet. Worth keeping only if fixed-protocol Stage 3 test_R@10 exceeds 0.065 and both-on wins over the two matched ablations; L1 Hard ER is reported on canonical 52,855 pairs with ten fixed negatives to ensure the coarse level did not merely collapse.
RISKS: Sinkhorn may be too costly or underflow with sharply varying costs; weighted capacities can overconcentrate high-degree items; minibatch transport may not match global code capacities; successor mass is sparse for rare items; the balance hinge could trade away reconstruction quality. Fixed extension capacity may overflow dense prefixes.
BEHAVIOR SIGNAL: Training-only incoming popularity mass s_i and directed row-normalized item transition graph A_ij.
BEHAVIOR COMPUTATION: make_train_behavior(train_split) returns sparse A[N,N] and s[N]. Extract consecutive (item_t,item_t+1) pairs within each user's train sequence, count edges, row-normalize nonempty rows, and set s_i=log(1+incoming count). Use no non-training split.
LEAKAGE BOUNDARY: The named function's sole input is train_split; its outputs are persisted with the Stage 2 run and are the only interaction-derived tensors used in transport, prefix balance, and extension ranking. Validation/test data never enter preprocessing, assignment, tuning, or SID ordering.
HYPERBOLIC OPERATOR: Lorentz exponential map and Lorentz geodesic distance with fixed negative curvature -k (k=1 initially); no Euclidean distance in both-on transport.
HYPERBOLIC LOCATION: Cost matrix for level-3 soft/hard code assignment during Stage 2; same assignment flows into three-token prefix representatives and behavior successor-mass balancing.
COUPLING PATH: s_i sets transport row mass, A_ij contributes prefix successor mass, and Lorentz C_ic determines where that weighted mass is transported; T changes level-3 hard codes and therefore q123 prefix membership, which changes the balance hinge and emitted SIDs.
COUPLING EQUATION: T=Sinkhorn(r(s),h, C_ic=d_L,k(exp_o^k(z3_i),v_c)^2); c3_i=argmax_c T_ic; L=L_RQVAE(T)+lambda*sum_(g,h)relu(m+M_g(A)-M_h(A))^2.
OBSERVABLES: Report canonical L1 Hard ER (52,855 pairs, same ten fixed negatives), gold-prefix survival at each depth 1-4, teacher-forced top-1 T3/T4, and Stage 3 test_R@10. Predicted depth-3 survival and T3 increase versus the measured coarse-geodesic arm; depth-4 survival/T4 increase versus it through compact popularity-ranked extension; target recall >0.065. L1 ER could rise modestly from balancing but not collapse. Compare behavior-off, Euclidean geometry-off, and both-on.
ABLATION BEHAVIOR OFF: Set s_i to its train-item mean, replace A with uniform outgoing probabilities over train items, and use uniform r_i; keep Lorentz costs, Sinkhorn, prefix balance structure, and extension algorithm (mean popularity ties resolved by item ID). Expect reduced T3/T4, survival, and recall if behavior is useful.
ABLATION GEOMETRY OFF: Use Euclidean C_ic=||z3_i-v_c||^2 and Euclidean prefix representative distances in the hinge, with the exact same actual s_i/A, row masses, capacities, temperature, and Sinkhorn iterations. This is a matched Euclidean assignment preserving behavior; expect worse T3 and depth-3/4 survival than both-on if curvature adds value.
ABLATION BOTH ON: Use train-derived s_i/A in row masses and prefix successor mass, Lorentz C_ic and Lorentz prefix hinge, then deterministic popularity extension; evaluate under frozen Stage 3 protocol.
SPEC EQUATIONS: Form C_ic from level-3 residual and Lorentz codeword. r_i=(1+gamma*s_i)/sum_i(1+gamma*s_i); h_c=1/256. Run fixed-I log-domain Sinkhorn on K_ic=-C_ic/tau with marginals r,h; use soft T in quantizer gradients, hard argmax for four-token SID. For each prefix g from first three codes only, M_g=sum_{i:c123_i=g} sum_j A_ij*1[c12_j!=c12_i]. For paired occupied siblings g,h with same c12, add relu(m+M_g-M_h)^2 whenever M_g>M_h; this is a balance hinge, not an average over level 4. Rank each g by outgoing successor count, assign extension rank blocks of 32; no prefix operation sees fourth tokens.
SPEC INPUTS OUTPUTS: Inputs: train sequences, item embeddings, RQ-VAE codebooks, minibatch transitions, k, gamma, tau, Sinkhorn iteration count, margin m, and extension block K=32. Outputs: updated codebooks/encoder, item SIDs [N,4], sparse A and s tensors, and metrics (ER, survival, T3/T4 accuracy). make_train_behavior(train_split) must also support checker-provided actual, mean, and zero signals.
SAFEGUARDS: Log-domain Sinkhorn; clamp costs and logits; ensure positive marginals and renormalize r/h; use deterministic bounded iterations; for empty outgoing rows set A row zero; define prefix balance only for occupied siblings and cap pair sampling; stop gradients through discrete prefix membership but keep soft transport gradients; report row/column marginal error; stable Lorentz acosh clamp and bounded coordinates; deterministic tie-break by item ID; log extension overflow explicitly; assert all prefix balance terms reference exactly levels 1-3.
END IDEA
