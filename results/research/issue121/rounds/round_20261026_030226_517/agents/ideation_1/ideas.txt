IDEA: beh_ranked_hyp_tail
TITLE: Behaviour-ranked collision extension with a hyperbolic decisive third code
MOTIVATION: Make the third code carry a train-only successor-community choice and make collisions under the first three codes resolve in a reproducible, recommendation-relevant order rather than an arbitrary fourth-token choice.
NOVELTY: Unlike existing successor-geodesic coarse assignment or tangent successor residuals, use one scalar train-only successor statistic to condition the actual Poincare assignment at level 3, then use that same statistic only to order collisions after the three-token prefix is frozen. The extension is explicitly not a fourth quantizer level and is excluded from every prefix-consistency loss.
CHANGE: Let level 1 retain 32 effective groups, level 2 retain the baseline 256 codes, and perform a behaviour-conditioned Poincare nearest-code assignment at level 3. For items sharing (z1,z2,z3), sort by smoothed training successor popularity and assign deterministic ranks 0..9 (bucket larger groups into ten rank bins); append that rank as token 4.
SPECIFICATION: Construct b_i with train_successor_signal(train_split): count each adjacent training-only transition i->j, compute s_i=sum_j C[i,j]/(1+sum_j C[i,j]), then standardize log1p(outdegree_i) across items to mean zero/unit variance (zero for absent items); return an item-indexed float tensor. On level 3 compute q_i=expmap0(r_i,c3), where r_i is the current Euclidean residual; candidate anchors a_k=expmap0(e_3k,c3). Set d_ik=d_P(q_i,a_k;c3) - alpha*tanh(b_i)*h_k, where h_k is a learned scalar per code constrained to [-1,1], then choose argmin_k d_ik. This gives a genuine behaviour-conditioned curved assignment. After training, group by exactly z1,z2,z3; sort each group by (-log1p(outdegree_i), item_id) and set z4=min(9,floor(10*rank/group_size)); use deterministic item_id tie break. No penalty averages over z4. Tail balance is enforced on the training tensors: for each parent p=(z1,z2), let n_pc be number of training items assigned to child c=z3; minimize L_tail=sum_p max(0, max_c n_pc - (min_c n_pc + 2))^2 after restricting to occupied children (margin=2 counts; intended inequality max_c n_pc <= min_c n_pc+2). This is measured from the same z1,z2,z3 assignment tensors used by training, with stop-gradient counts and a straight-through assignment gradient to level-3 logits.
COST: Precompute signal in O(number of train transitions), O(number of items) memory. Per assignment adds one scalar-code bias and level-3 Poincare distances, O(B*K3) scalar work beyond baseline geometry. At frozen scale, 24 full-item steps/epoch means 589,344 item assignments/epoch and 1,768,032,000 over 3000 epochs; added work is 589,344*K3 scalar bias operations per epoch (K3=256: about 151M), plus small segment reductions for occupied (z1,z2) groups. Four-card wall time expected +5-15%, dominated by assignment and group-count reductions.
HYPOTHESIS: If successor popularity orders collision sets and b_i predicts meaningful successor neighborhoods, T3 top-1 should rise materially over 0.338 (target >=0.65), T4 top-1 exceed 0.90 with NLL <0.3, and Stage3 test_R@10 exceed 0.065. On canonical 52,855-pair / ten-fixed-negative evaluation predict L1 Hard ER stays near baseline or slightly improves (not the optimization target); gold-prefix survival at depth 1 is near coarse-arm 0.989, depth 2 roughly >=0.34, depth 3 and 4 rise over resample's .091/.088 because decisive T3/T4 preserve continuation. Keep only if both T3/T4 and Stage3 improve without collapsing L1 ER.
RISKS: A global outgoing-popularity scalar may not distinguish competing interests; small collision groups produce ties; balance penalty can create artificial child occupancy and hurt semantic fit; overly strong alpha can reorder items by popularity rather than transitions.
BEHAVIOR SIGNAL: Per-item training-only outgoing transition popularity b_i, as returned by train_successor_signal(train_split).
BEHAVIOR COMPUTATION: train_successor_signal takes only the Stage 2 training split and item count; count adjacent i->j edges, derive outdegree_i=sum_j C[i,j], return standardized log1p(outdegree_i) (zero for unobserved items). No validation/test sequences or frequencies are passed.
LEAKAGE BOUNDARY: The function receives only train split; the tensor is fixed before Stage 2 fitting. Validation/test interactions, metrics, and item counts cannot enter b_i, assignment, tail loss, or collision ordering. Stage 3 test is evaluation only.
HYPERBOLIC OPERATOR: Poincare distance d_P at fixed negative curvature -c3 (c3=0.5), with expmap0 of residuals and code anchors.
HYPERBOLIC LOCATION: Level-3 hard code assignment during all 3000 Stage 2 epochs; used again only in the assignment logits, not for post-hoc relabeling.
COUPLING PATH: train-only b_i modulates a code-specific bias inside the level-3 Poincare-distance argmin; changing b_i changes the selected anchor, and replacing d_P changes the same argmin. The ensuing (z1,z2,z3) groups determine the ranked extension token.
COUPLING EQUATION: z3_i=argmin_k[d_P(expmap0(r_i,c3),expmap0(e_3k,c3);c3)-alpha*tanh(b_i)h_k]; therefore behaviour and curved distance jointly determine the three-token prefix whose collision group is ranked.
OBSERVABLES: Compare L1 Hard ER on 52,855 canonical pairs with ten fixed negatives; gold-prefix survival at depths 1/2/3/4; teacher-forced T3/T4 top-1 and T4 NLL; Stage3 test_R@10. Expected L1 ER approximately flat/slightly up, depth-1 survival high, depth-3/4 survival and T3/T4 accuracy up, and recall >0.065.
ABLATION BEHAVIOR OFF: Set b_i=0 and alpha=0 in the coupled assignment; retain identical negative curvature, level sizes, tail margin, and train-only collision rank protocol (rank key falls back to item id). This tests whether behaviour contributes.
ABLATION GEOMETRY OFF: Replace d_P and exp/log maps with matched squared Euclidean distance ||r_i-e_3k||^2, but keep the same real b_i bias, h_k, tail margin, data/order and compute budget. This tests geometry, not a disabled behaviour branch.
ABLATION BOTH ON: Use real train_successor_signal, Poincare assignment at c3=0.5, tail inequality margin 2, and popularity-ranked extension for the full 3000 epochs.
SPEC EQUATIONS: C_ij=count_train(i->j); b_i=(log(1+sum_j C_ij)-mean_train)/max(std_train,1e-6). d_ik=d_P(exp_0(r_i),exp_0(e_k);c3)-alpha*tanh(b_i)h_k; z3_i=argmin_k d_ik. L=L_RQVAE+lambda_tail sum_p relu(max_c n_pc-min_c n_pc-2)^2, p=(z1,z2), counts over items and z3 only. After fitting, for each exact triple group sort (-outdegree_i,item_id), assign z4=min(9,floor(10*rank/m)). Four-token fixed width; no fourth-level continuation penalty.
SPEC INPUTS OUTPUTS: Input item embeddings/residuals, existing z1/z2 assignments, level-3 codebook, train split, item IDs; output level-3 hard assignments, RQ-VAE plus tail loss, and deterministic four-token SID. train_successor_signal(train_split) returns shape [24556] float tensor.
SAFEGUARDS: Clamp std to 1e-6, tanh behaviour and code biases, clamp Poincare norms to (1-1e-5)/sqrt(c3), compute artanh arguments in [-1+1e-6,1-1e-6], normalize counts only among occupied children, skip p with fewer than two occupied children, use fixed item-ID ties, log assignment histograms and NaN/Inf checks. Checker can substitute real b, its mean (constant behavior), and zeros through the same function output pathway.
END IDEA

IDEA: beh_curvature_prefix_margin
TITLE: Successor-conditioned curvature with a three-token continuation margin
MOTIVATION: Prevent the third token from behaving like an independent 256-way residual choice: items expected to continue to related successors should form stable three-token prefix representatives, while the first level remains broad enough to preserve prefix coverage.
NOVELTY: This places behaviour in the curvature parameter of a level-3 Poincare quantizer and couples it to an explicit prefix-representative continuation objective. It is not a successor entropy penalty or a standalone hyperbolic regularizer; behaviour sets local curvature, which changes geodesic assignment and the loss geometry on the exact same tensors.
CHANGE: Keep four fixed SID positions and make a two-step user-history successor-consensus graph from training sequences. Use its per-item concentration to select level-3 curvature in a bounded negative-curvature interval, then apply a margin loss to the three-token representatives only: same-prefix items with overlapping train-successor neighborhoods must be closer than non-overlapping controls by margin m. Generate token 4 deterministically by ordering items within exact three-token prefix by training successor popularity.
SPECIFICATION: Define train_successor_signal(train_split) returning two per-item tensors: b_i=outgoing transition entropy normalized to [0,1] and vector sparse neighbor rows P_i. Count adjacent transitions per training sequence; P_ij=(C_ij+1e-3)/(outdegree_i+1e-3*|N_i|) over observed outgoing neighbors. Set c_i=clip(c_min+(c_max-c_min)*b_i, c_min,c_max), with c_min=.25,c_max=1.0; hence concentrated successor profiles get lower curvature. Use d_P(exp_0(r_i,c_i), exp_0(e_k,c_i);c_i) for level-3 assignment. For batch item pairs i,j sharing the current (z1,z2) parent, define overlap o_ij=sum_k min(P_ik,P_jk); sample a positive if o_ij>=.25 and a negative if o_ij<=.05. Let v_i=log_0(exp_0(r_i,c_i),c_i), a differentiable tangent representative of the current third-level residual. L_pref=sum_(+,−) relu(m+d_P(v_i,v_j;cbar)-d_P(v_i,v_−;cbar)) with cbar=sqrt(c_i*c_j), computed only over z1,z2,z3 representations (never z4). Also tail-balance counts on the same z1,z2,z3 assignment tensors enforce max_c n_pc <= min_c n_pc+2 for occupied children, via squared hinge. Sort exact triple collisions by decreasing outdegree then item ID and map rank to at most ten extension values.
COST: Signal preprocessing O(train transitions + E) once; sparse overlap pairs are sampled (e.g. 2 positives and 2 negatives per item batch), O(B*4*average_degree) sparse work plus O(B*K3) curved assignment. Frozen scale: 589,344 item assignments/epoch, 1,768,032,000 over 3000 epochs; pairwise margin adds four geodesic pair distances/item, approximately 2.36M pair distances/epoch (about 7.1B over training), and curvature adds one scalar per item. Expected four-card wall time +10-25%, depending on sparse graph degree and pair kernel.
HYPOTHESIS: If successor-profile concentration predicts reusable continuation structure, the prefix margin should make T3 predictable while curvature prevents over-merging. Expect L1 Hard ER on 52,855 pairs / ten fixed negatives roughly maintained or improved modestly; gold-prefix survival depth 1 stays >=.90 and depths 2/3/4 improve over .829/.156/.086 l1_only and toward .497/.122/.091/.088 resample's deep survival; T3 top-1 rises above .34 toward .65, T4 above .90 with low NLL, and Stage3 test_R@10 exceeds .065. Retain only when the gains appear in both-prefix survival and Stage3, not merely training margin.
RISKS: Entropy can be noisy for low-degree items; high overlap positives may encode repeated popularity rather than genuine continuation; pair sampling and curvature may destabilize optimization; occupied-child balance may conflict with coherent prefixes.
BEHAVIOR SIGNAL: Train-only directed successor profile P_i and normalized outgoing entropy b_i, emitted by train_successor_signal(train_split).
BEHAVIOR COMPUTATION: The named function accepts the training split only, counts each within-sequence adjacent directed pair, returns a sparse row-normalized outgoing transition matrix and per-item entropy H(P_i)/log(max(2,degree_i)); no held-out sequence is used. Unobserved rows are zero entropy with empty sparse rows.
LEAKAGE BOUNDARY: The train split is the sole input to signal construction and is materialized once before Stage 2; no validation/test graph, frequency, transition, or popularity enters training, collision rank, or SID export. Validation may assess the fixed run but cannot alter its signal or codes.
HYPERBOLIC OPERATOR: Item-conditioned Poincare geodesic distance and exp_0/log_0 maps at negative curvature -c_i, c_i in [0.25,1.0].
HYPERBOLIC LOCATION: Level-3 assignment and the three-token-prefix pairwise continuation margin during Stage 2; level 4 remains a deterministic post-fit extension, not a curved quantizer.
COUPLING PATH: The same training successor profile sets c_i in the level-3 geodesic argmin and supplies positive/negative prefix pairs; changing behavior changes curvature and pair membership, while Euclidean replacement changes both assignment and margin distances. The resulting first-three-token representatives are exactly the objects constrained and subsequently extended.
COUPLING EQUATION: c_i=.25+.75*b_i; z3_i=argmin_k d_P(exp_0(r_i,c_i),exp_0(e_k,c_i);c_i); L_pref=relu(m+d_P(v_i,v_j;cbar)-d_P(v_i,v_n;cbar)) for P_i/P_j overlap >=.25 and P_i/P_n overlap <=.05, all conditioned on the same z1,z2 prefix.
OBSERVABLES: Log L1 Hard ER over 52,855 canonical pairs/ten fixed negatives, gold-prefix survival at each depth 1-4, teacher-forced T3/T4 accuracy and T4 NLL, Stage3 test_R@10. Predict modest L1 ER improvement/neutrality, depth-3 survival and T3 accuracy increase, depth-4 survival/T4 accuracy increase from popularity-ranked extension, and Stage3 >0.065.
ABLATION BEHAVIOR OFF: Replace P_i with empty rows, b_i with its global train mean (constant curvature), and sample matched random positives/negatives; retain identical Poincare operations, loss weights, and tail balance. This removes behavior-dependent curvature and pairs.
ABLATION GEOMETRY OFF: Use squared Euclidean distances for level-3 assignments and continuation margin, fixed matched curvature-independent scale, but retain actual train-derived P_i, b_i, pair selection, margin, tail balance, and extension sorting. This is a matched Euclidean assignment, not a behavior-disabled branch.
ABLATION BOTH ON: Use actual training P_i and b_i, item-conditioned Poincare distance at c_i, graph-overlap pair margin on three-token representatives, margin m=0.5, count-balance margin 2, and deterministic ranked extension.
SPEC EQUATIONS: C_ij=train adjacent transition counts; P_ij=(C_ij+1e-3)/(sum_k C_ik+1e-3*d_i) for observed neighbors; b_i=H(P_i)/log(max(2,d_i)); c_i=.25+.75b_i. z3=argmin_k d_P(exp_0(r_i,c_i),exp_0(e_k,c_i);c_i). For p=(z1,z2), sample triples (i,j,n) with overlap(P_i,P_j)>=.25 and overlap(P_i,P_n)<=.05; L_pref=mean relu(.5+d_P(v_i,v_j;cbar)-d_P(v_i,v_n;cbar)); L_bal=sum_p relu(max_c n_pc-min_c n_pc-2)^2, with n_pc counts only z3 children and occupied c. L_total=L_RQVAE+lambda_pref L_pref+lambda_bal L_bal. Exact (z1,z2,z3) collision rank sorted by (-outdegree,item_id), z4=min(9,floor(10*rank/group_size)).
SPEC INPUTS OUTPUTS: Input train split, 24,556 item embedding/residual tensor, current z1/z2 codes, level-3 anchors, sampled batch item IDs; return sparse P, b, level-3 assignments, prefix-margin and balance losses, and fixed four-token IDs.
SAFEGUARDS: Clip b and curvature to bounds; add 1e-3 smoothing only across observed neighbors; skip pairs with empty profiles; stop-gradient pair selection and count tensors while differentiating geodesic distances; use stable log1p and entropy clamp; project ball points below radius (1-1e-5)/sqrt(c); clamp artanh inputs; use fixed-seed pair sampler and item-ID tie breaks. Tail inequality is evaluated directly from the exact z1,z2,z3 tensors used for the loss, never over z4. Checker can feed real signal, its mean/zero tensors; assert that mean/zero controls alter the same computation as expected.
END IDEA
