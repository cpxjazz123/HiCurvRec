IDEA: cohrank-curvature-sinkhorn-v1
TITLE: Behaviour-graph closure rank as a per-code curvature centre inside the balanced Sinkhorn cost, so coarse Semantic-ID prefixes group items homogeneous in local behaviour curvature.
MOTIVATION: An L1 token that mixes flat (hub-like) and tight (clique-like) behaviour neighbourhoods forces the generator to model two incompatible transition regimes under one prefix, and L2/L3 refinement then spends capacity separating them; grouping items by a behaviour-curvature rank makes the coarse prefix a behavioural summary, so prefix-conditioned prediction sharpens and Stage3 test Recall@10 should exceed 0.065. Reconstruction target and codebook sizes are untouched.
NOVELTY: Not transition-count weighting of a curved assignment, not a standalone hyperbolic loss beside a behaviour loss, not an unquantised behaviour hierarchy: the item's train-only triangle-closure rank and a per-code learned curvature centre meet INSIDE the baseline's balanced Sinkhorn cost as a bounded offset, and a scale-free curvature-homogeneity penalty on the same balanced soft plan trains those centres, so behaviour and geometry share one gradient loop.
CHANGE: Level-l cost becomes curved Poincare code distance minus a curvature-match bump between item closure rank and the code's learned curvature centre; a normalised within-code curvature-variance penalty on the balanced plan trains the centres.
SPECIFICATION: (A) Frozen train-only behaviour vector: 24556-node undirected co-occurrence graph (edge weight log1p co-occurrence count, symmetric union of directed transitions, A = 1[w>0]); t_ij = (A*A)_ij = |N(i) ∩ N(j)| sparse; coh_i = mean_{j in N(i)} log1p(t_ij); heavy-tailed so rank-uniformise rho_i = (avgrank(coh_i) - 0.5)/n, rho in (0,1), median 0.5, MAD 0.25, degree-0 -> 0.5. (B) Measured geometry: c = 1/median_i ||u_i^(1)||_2^2 (floor 1e-8), R_c = 1/sqrt(c), x_i = exp_0^c(u_i), p_k = exp_0^c(q_k), d_c(x,y) = (2/sqrt(c)) artanh(sqrt(c)||(-x)(+)y||). (C) Coupling at every level: m_k = sigmoid(mu_k) in (0,1), g_ik = exp(-(rho_i - m_k)^2/(2 s^2)) with s = 0.25, beta_l = 1.0 * median_i min_k d_c(x_i,p_k) measured once no-grad at init, C_ik = d_c(x_i,p_k) - beta_l g_ik, and the baseline Sinkhorn solver/eps/marginals kept verbatim with hard level index k_i = argmax_k P_ik (never argmin of a score), so balancing still governs codebook usage. (D) L = L_recon + beta_commit L_commit + 1.0 * L_curv with L_curv = sum_l [sum_{i,k} P_ik (rho_i - m_k^(l))^2 / (sum_{i,k} P_ik Var_batch(rho) + 1e-8)]; STE, 3 levels, dimension, codebook 256, optimiser, epochs, batch, seed unchanged; reconstruction and residuals use un-hyperbolised codes.
COST: B ~ 1023 per step; 3 x 1023 x 256 = 785,664 curved cost entries per step (one tangent difference, one tanh/norm, one artanh each, same exp count as the baseline kernel) plus 786k multiply-adds for L_curv; +3% to +5% step wall clock (~+0.1 to +0.2 s/step on four cards, ~+2 to +3 h over 3000 epochs), no extra epochs; one-time sparse A*A build (seconds to a minute), rank sort O(n log n), 18.9M-evaluation no-grad beta/c calibration (seconds); Stage3 cost identical; 768 extra scalars.
HYPOTHESIS: The balanced plan becomes curvature-sorted (mean |rho_i - rho_j| over L1-sharing pairs <= 0.5 x the random-pair value) while L1 usage stays in the reference order (~241 of 256 codes used, not 42) and L3 collision stays near 0.065, not 0.703; if that appears and Stage

3 test Recall@10 > 0.065 in the single frozen run the coarse prefix is a behaviourally meaningful condition. If no L1 stratification appears, Sinkhorn balance has erased the offset and the mechanism is dead regardless of recall.
RISKS: Near-uniform column marginals allow only reordering, and too large a beta_l degenerates the plan into a curvature quantile partition that hurts reconstruction and recall; rank-uniformisation discards magnitude and can flatten a two-scale closure pattern; degree-1 items give a one-edge noisier rank; hubs can dominate coh before ranking; single run means seed noise sits inside the interval; c from initial embedding scale may misestimate curvature later.
BEHAVIOR SIGNAL: Training-only item-level local curvature of the co-consumption/transition graph (triangle closure of each item's neighbourhood) as the bounded curvature rank rho_i.
BEHAVIOR COMPUTATION: Training split only, before Stage2: log1p co-occurrence edges inside the baseline window, binary sparse A, t_ij = (A*A)_ij, coh_i = mean_j log1p(t_ij) over N(i), rank-uniformised rho_i over the 24556 items, frozen float32 with a hash of the training-file list; never recomputed during training or for Stage3.
LEAKAGE BOUNDARY: rho, the graph, c and beta_l come from the training split at init and are frozen; no validation or test interaction, episode or metric touches them, so no evaluation signal can shape SID construction; Stage3 consumes only the trained codebook and the centres are training-time quantiser parameters never tuned on an eval split; no test-time graph update.
HYPERBOLIC OPERATOR: Fixed negative curvature kappa = -c with measured c = 1/median_i ||u_i||_2^2 (floor 1e-8); Poincare distance d_c(x,y) = (2/sqrt(c)) artanh(sqrt(c)||(-x)(+)y||) with exp_0^c(v) = tanh(sqrt(c)||v||) v/(sqrt(c)||v||), ball radius R_c = 1/sqrt(c).
HYPERBOLIC LOCATION: In the quantiser's assignment step of all three levels - the cost matrix of the baseline balanced Sinkhorn solver - and, through the differentiable plan P, in the curvature-homogeneity penalty that trains the code centres; not in reconstruction, commitment or residual recursion.
COUPLING PATH: graph -> coh -> rho -> g_ik(rho_i,m_k) -> offset in C_ik together with d_c(x_i,p_k) -> balanced Sinkhorn plan P -> (a) baseline plan-argmax level index and (b) L_curv = E_P[(rho_i - m_k)^2]/Var(rho) -> gradient into mu -> m_k -> g -> C. Behaviour off cuts the loop (g == 1, L_curv == 0, plain curved distance); geometry off (c = 0) makes the distance Euclidean while g and L_curv remain.
COUPLING EQUATION: C^(l)_ik = d_c(x_i^(l), p_k^(l)) - beta_l * exp(-(rho_i - sigmoid(mu_k^(l)))^2/(2 s^2)), s = 0.25, beta_l = 1.0 * median_i min_k d_c(x_i^(l), p_k^(l)) at init; L_curv^(l) = sum_{i,k} P_ik (rho_i - m_k^(l))^2 / (sum_{i,k} P_ik Var(rho) + 1e-8), P the baseline Sinkhorn plan of exp(-C^(l)/eps).
OBSERVABLES: L1 hard ER, L2 distinct-prefix count, L3 collision rate, L3 refinement gain with L1 usage in the reference order; mean |rho_i - rho_j| over L1-sharing pairs versus random pairs (target ratio <= 0.5) and the fraction of same-prefix pairs within s; spread of sigmoid(mu) across codes; Stage3 test Recall@10 > 0.065 (coherence/adjacency/transfer-predictability recorded, never gated).
ABLATION BEHAVIOR OFF: rho constant 0.5, g_ik = 1, offset 0, L_curv 0, mu unused with zero gradient; curved d_c and the baseline balanced Sinkhorn retained. Switch exists in code, no arm trained this round.
ABLATION GEOMETRY OFF: c = 0, d_c -> Eu

clidean, rho/g/beta_l/L_curv retained; this same-capacity Euclidean control is a separate sibling-round arm whose directory and identical stratified table plus Stage3 numbers are cited in the mechanism arm's report; not run as an ablation here.
ABLATION BOTH ON: measured c > 0, curved d_c plus rank-curvature offset beta_l g_ik inside the baseline balanced Sinkhorn cost at all three levels, L_curv training mu; one run, no early stopping.
SPEC EQUATIONS: w_ij = log1p(count); A = 1[w_ij > 0]; T = A @ A; coh_i = mean_{j in N(i)} log1p(T_ij); rho_i = (avgrank(coh_i) - 0.5)/n; c = max(1/median_i||u_i^(1)||_2^2, 1e-8); s = 0.25; beta_l = median_i min_k d_c(exp_0^c(u_i^(l)), exp_0^c(q_k^(l))); d_c = (2/sqrt(c)) artanh(clamp(sqrt(c)||(-x)(+)y||, 0, 1-1e-6)); m_k = sigmoid(clamp(mu_k, -20, 20)); g_ik = exp(-(rho_i - m_k)^2/(2 s^2)); C_ik = d_c(x_i,p_k) - beta_l g_ik; K = exp(-C/eps); [u,v] = sinkhorn_iters(K, 1/B, 1/256); P = diag(u) K diag(v); k_i = argmax_k P_ik; L_curv = sum_l [sum_{i,k} P_ik (rho_i - m_k^(l))^2 / (sum_{i,k} P_ik Var_batch(rho) + 1e-8)]; L = L_recon(STE, un-hyperbolised) + beta_commit L_commit + 1.0 L_curv; gradients dP/dC via differentiable Sinkhorn, dC/dmu via g_ik, dP/dmu through the same chain.
SPEC INPUTS OUTPUTS: In - frozen train-only graph and rho (24556), level-l u^(l) and q^(l), mu^(l) in R^256, measured c, s, alpha, calibrated beta_l. Out - cost C in R^{B x 256}, baseline plan P and plan-argmax indices k_i, scalar L_curv and its gradients into mu^(l) (and via C into u^(l), q^(l)), per-code centres m_k for reporting.
SAFEGUARDS: artanh argument clamped to [0, 1-1e-6], ball points clamped to R_c(1-1e-5); c floored 1e-8; beta_l clamped to [1e-3, 1e2] x its measured median; sigmoid logits clamped +/-20 so m_k in (0,1) and g_ik in (e^-8,1]; Var_batch(rho) floored 1e-8 and the L_curv denominator guarded against zero column mass; neutral rho = 0.5 for degree-0 items, empty neighbourhoods skipped; Sinkhorn solver, marginals and plan-argmax rounding untouched so the balanced assignment can never become an argmin and the codebook cannot collapse; c and beta_l no_grad and detached; NaN/Inf guard skips and logs a step; rho, c, beta_l hashed into the run manifest for train-only provenance.
END IDEA
