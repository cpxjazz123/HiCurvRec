IDEA: incoming_ball_sink
TITLE: Incoming-context hyperbolic Sinkhorn assignment
MOTIVATION: An item's own content vector misses the fact that the same target can be reached from concentrated predecessor regions; assigning it using its incoming contexts may make early SID prefixes predictive of what follows.
NOVELTY: Replace independent nearest-code assignment with a sparse, behaviour-conditioned balanced assignment whose costs are curved distances to incoming-context prototypes. The data pathway is target-specific predecessor context, not a post-hoc loss on frozen codes or a transition-pair resampling objective.
CHANGE: At each quantizer level, form a target context point from the current soft assignments of its training predecessors, and use that point to tilt the item's Poincare-distance assignment logits before a small sparse Sinkhorn normalization. This changes the actual discrete code selection while preserving the existing four-token alphabet.
SPECIFICATION: For train-only directed co-consumption edges p->i, let a_p be p's soft assignment to the current level's K codewords c_k in the Poincare ball. For target i, compute q_i=Proj(sum_{p in P(i)} w_pi sum_k a_pk c_k / sum_p w_pi); weights w_pi are normalized inverse-popularity-weighted training edge counts. For its encoded latent z_i map x_i=exp_0(z_i). Set C_ik=(1-lambda_i)d_c(x_i,c_k)^2 + lambda_i d_c(q_i,c_k)^2, with lambda_i=lambda0*min(1, log(1+|P(i)|)/log(1+P95)). Run 3 row/column Sinkhorn iterations only on the 32 closest codewords per row, with codeword marginals equal to baseline usage; hard argmin of C gives the token. No extension codes are created.
COST: One-time sparse edge aggregation O(E_train); per step for batch B, K codewords and top-32 mask, O(B*32*d + B*32*3) distances/normalization, versus dense O(B*K*d); expected <5% step overhead after edge gather/cache. At frozen scale 24,556 items x 24 steps x 3,000 epochs = 72,000 steps, about 1.77 billion sparse assignment-distance evaluations at B~items/24, plus the baseline RQ-VAE cost.
HYPOTHESIS: Items with several distinct incoming contexts are the difficult targets; the adaptive curved context term should reduce their cross-region assignment dispersion and improve held-out discrimination, raising Stage3 test_R@10 above 0.065. Keep only if L1 Hard ER and the held-out positive-minus-hard-negative gap improve without reducing gold-prefix survival.
RISKS: Early soft assignments may make q_i noisy; popular predecessors may dominate despite weighting; Sinkhorn marginals can fight content reconstruction, and sparse top-32 support can exclude the useful code. Test several fixed lambda0 values selected without validation/test interactions.
BEHAVIOR SIGNAL: Training-only directed sequential co-consumption predecessor-to-target edges and the target's incoming predecessor-region mixture.
BEHAVIOR COMPUTATION: From the frozen training split only, count adjacent item transitions p->i, deduplicate per user-session, downweight predecessor p by 1/sqrt(1+training_item_frequency(p)); build P(i) and cache sparse edges once. No re-sampling or split mixing.
LEAKAGE BOUNDARY: Only training interactions produce P(i), weights, and marginals. Validation/test events are not read by preprocessing, assignment, hyperparameter selection, or export; at inference no user context is consumed.
HYPERBOLIC OPERATOR: Squared Poincare geodesic distance d_c^2 at fixed negative curvature -c, c=1, with exp_0 and ball projection for latent/prototype vectors.
HYPERBOLIC LOCATION: Inside each level's code assignment cost and sparse Sinkhorn logits; it determines the assignments, not a penalty added after quantization.
COUPLING PATH: Training predecessor edges -> soft predecessor code mixture -> projected curved context q_i -> curved context-plus-content assignment cost -> Sinkhorn/hard token. Removing edges eliminates q_i; replacing d_c with Euclidean distance changes both context and content assignment geometry.
COUPLING EQUATION: A_i=SparseSinkhorn(exp(-[(1-lambda_i)d_c(x_i,c_k)^2 + lambda_i d_c(q_i,c_k)^2]/tau)); q_i=Proj(sum_{p->i}w_pi sum_k a_pk c_k/sum_{p->i}w_pi). The behaviour term q_i and curved term d_c jointly set A_i.
OBSERVABLES: Compare SID assignments and incoming-region dispersion, L1 Hard ER, cooccur_overlap_L3, adjacency_L3, canonical positive-minus-negative gap (10 co-occurrence-similar hard negatives), gold-prefix survival at depths 1-4, extension alphabet size (must remain baseline-sized), and frozen Stage 3 test_R@10. Expected gains are larger gap and higher Recall, not necessarily higher raw positive similarity.
ABLATION BEHAVIOR OFF: Shuffle the item-to-row association of the cached incoming-context signal before training, keeping edge weights, codebook, Sinkhorn, and all hyperparameters unchanged.
ABLATION GEOMETRY OFF: Replace every d_c^2 in assignment cost by squared Euclidean distance and exp/projection by identity, with same behavior, weights, temperature, and sparse Sinkhorn.
ABLATION BOTH ON: Use correctly aligned training-only incoming-context signal and Poincare distances in the assignment pathway.
SPEC EQUATIONS: For each target i and level l: a_pk=softmax over current sparse assignments; q_i=Proj(sum_p w_pi sum_k a_pk c_k / max(eps,sum_p w_pi)); lambda_i=lambda0 min(1,log(1+n_i)/log(1+P95)); C_ik=(1-lambda_i)d_c(exp_0(z_i),c_k)^2+lambda_i d_c(q_i,c_k)^2; A=Sinkhorn_3(exp(-C/tau) masked to nearest 32); token_i=argmax_k A_ik. Detach q_i's predecessor assignments within an epoch to keep gradients sparse and stable; update codebook through selected assignment/reconstruction path.
SPEC INPUTS OUTPUTS: Inputs are current batch latents, level codebook points, cached training predecessor CSR (predecessor IDs and weights), predecessor soft assignments, and baseline codebook marginals. Outputs are sparse assignment probabilities and one token per item/level; four-token SID serialization and extension alphabet remain unchanged.
SAFEGUARDS: Use float32 distance/Sinkhorn, clamp ball norm to (1-1e-5)/sqrt(c), clamp acosh argument to >=1+1e-7, denominator >=1e-8, remove targets with no predecessor by lambda_i=0, cap edge weights and lambda0, add 1e-8 to Sinkhorn marginals, and fall back to nearest content code if row normalization is non-finite. Cache only train CSR and stop gradient through cached predecessor assignments.
END IDEA

IDEA: curved_follow_gap
TITLE: Hyperbolic follow-versus-hard-negative codebook contrast
MOTIVATION: Similarity to co-consumed items alone is insufficient: successful SIDs need to place actual next items closer than co-occurrence-similar items that do not follow, while allowing a target's incoming contexts to shape the region representation.
NOVELTY: Use the RQ-VAE's current prefix code as a hyperbolic query point and update its codebook through a per-batch positive-versus-hard-negative ranking contrast. Unlike a separate behaviour loss beside unchanged quantization, the same curved scores re-rank candidate codewords and feed a straight-through assignment, so the contrast changes SID tokens.
CHANGE: For each sampled training transition, construct one positive target and a small set of high-cosine co-consumption hard negatives; use the current source-prefix code's Poincare tangent/log-map representation to score all candidates against the target code choices, then apply the resulting contrast gradient to the codebook and assignment logits. Incoming-context weights emphasize targets reached from multiple distinct prefix regions.
SPECIFICATION: Freeze train co-consumption cosine matrix S from training-only user-item rows. For target i choose positive j from observed train next-item edges and M=8 negatives n with high S(i,n), excluding any observed train successor of source u. Let h_i be incoming predecessor-prefix entropy normalized to [0,1]. For source prefix point r_u=Proj(sum_{l<3} c_{u_l}), define query q_u=Log_0(r_u), map each candidate item latent z_v to y_v=exp_0(z_v), and score s(u,v)=-d_c(r_u,y_v)^2. Loss per transition is (1+eta*h_i)*softplus((m - s(u,j) + logsumexp_n(s(u,n)))/tau). Combine with reconstruction; its normalized coefficient is alpha=0.1*stopgrad(recon_ema/(loss_ema+eps)), so its initial scale is approximately 1e-5 to 1e-4. Straight-through reassign the target's final-level token to the codeword minimizing d_c(y_i,c_k)^2 - gamma*(s(u,i)-mean_n s(u,n)) differentiable score contribution.
COST: One-time S and incoming prefix statistics via sparse train co-consumption; per step sample 8 negatives per transition, compute 9 Poincare distances and gradients for the sampled rows, O(9*B*d), plus one sparse candidate-token update; <8% overhead expected. At 24,556 items, 24 steps/epoch, 3,000 epochs (72,000 steps), about 648,000 scored candidates per full-item epoch-equivalent? Precisely 72,000*B*9 distances; with B about 1,023 this is ~663 million distances, versus dense all-item scoring which is explicitly avoided.
HYPOTHESIS: If hyperbolic discrimination captures the measured negative-side signal and incoming-context entropy weights the ambiguous targets, the gap against fixed hard negatives and gold-prefix survival should rise, yielding Stage3 test_R@10 >0.065. Retain only if both positive-minus-negative gap and test Recall beat the matched controls without alphabet expansion.
RISKS: Hard negatives may be false negatives; score can overfit sparse transitions; the auto-scaled loss may become too weak/strong, and prefix-code sums may be poorly calibrated early in training. Keep negatives training-only, cap h_i and alpha, and report per-epoch scales.
BEHAVIOR SIGNAL: Train-only sequential co-consumption transitions, training-item co-consumption cosine for hard negatives, and incoming prefix diversity for target weighting.
BEHAVIOR COMPUTATION: Build item co-consumption rows from users/interactions in the training split only; cosine-normalize rows. Count directed adjacent transitions in each training user's sequence. For target i compute distinct source-prefix count by dividing unique depth-3 prefixes among its training predecessors by max(1, distinct predecessors); transform to h_i and freeze. For each transition select the 8 non-successor items with largest row cosine to its positive target, with deterministic item-ID tie breaking.
LEAKAGE BOUNDARY: All item rows, transitions, prefix counts, negative pools and chosen negatives are computed from training interactions only and frozen before Stage2. Validation/test histories cannot change positives, negatives, weights, code assignments or stopping; no user signal is used at prediction time.
HYPERBOLIC OPERATOR: Fixed-curvature (-1) Poincare exp_0, Log_0 and geodesic distance d_c; scores use squared geodesic distance in the candidate contrast and assignment correction.
HYPERBOLIC LOCATION: The candidate discrimination logits and the final-level code assignment itself; not an auxiliary geometry regularizer on already finalized SIDs.
COUPLING PATH: Train transitions choose positive and co-occurrence-hard negatives; incoming prefix diversity sets their weight; Poincare distances from the current prefix point score those candidates; the resulting contrast gradient modifies the same codebook and final assignment logits used to emit tokens.
COUPLING EQUATION: L(u,i)= (1+eta*h_i) softplus((m + d_c(r_u,y_i)^2 - tau*logsumexp_{n in N(i)}[-d_c(r_u,y_n)^2/tau])/tau); A_ik=softmax_k(-d_c(y_i,c_k)^2 + gamma*[d_c(r_u,y_i)^2 - mean_n d_c(r_u,y_n)^2]_{ST}). Here N(i) is selected by training co-consumption and h_i is incoming-context diversity; the behaviour-derived contrast is computed in curved geometry and alters assignment.
OBSERVABLES: Log SID token changes and assignment gradients; report L1 Hard ER, cooccur_overlap_L3, adjacency_L3, positive-minus-negative gap on canonical fixed pairs, gold-prefix survival at depths 1-4, extension alphabet (must not grow), and Stage3 test_R@10. Success means gap improves and Stage3 Recall crosses 0.065 with the same frozen protocol.
ABLATION BEHAVIOR OFF: Independently permute the item-to-row association for co-consumption vectors, transition targets and incoming-diversity values while retaining counts/pool sizes; recompute positives/negatives from the permuted mapping and train with identical curvature and weights.
ABLATION GEOMETRY OFF: In the exact score and assignment positions replace Poincare d_c and exp/log maps by squared Euclidean distances and identity maps, retaining identical positive/negative samples, loss scale, and gamma.
ABLATION BOTH ON: Correctly aligned train-only transitions, hard negatives, incoming-prefix diversity and fixed-curvature Poincare scores jointly update final code assignments.
SPEC EQUATIONS: For each sampled train transition u->i, N_i=Top8_{v: v not observed successor(u)} cos(S_i,S_v); h_i=clip(unique_train_prefix3(predecessors(i))/max(1,unique_predecessors(i)),0,1); r_u=Proj(sum_{l<3}c_{u_l}); y_v=exp_0(z_v); s(u,v)=-d_1(r_u,y_v)^2; ell=(1+eta*h_i)softplus((m-s(u,i)+tau*logsumexp_{v in N_i}(s(u,v)/tau))/tau). Add alpha*mean(ell) to baseline reconstruction/commitment. Final assignment logits are -d_1(y_i,c_k)^2 + gamma*stop-gradient normalized contrast advantage, then argmax; use straight-through gradients on selected token.
SPEC INPUTS OUTPUTS: Inputs are frozen train transition tuples, item co-consumption sparse rows, incoming predecessor-prefix counts, current prefix code vectors, current item latents, and final-level codebook. Outputs are sampled candidate ranking loss, sparse codebook/encoder gradients, and unchanged-length four-token SIDs.
SAFEGUARDS: Fixed deterministic hard-negative pools; exclude all observed training successors of the source; cap at 8 negatives and cap h_i/eta; float32 maps and distances; project norms below (1-1e-5); clamp squared distances and logits to finite ranges; use eps=1e-8 in cosine/normalization; maintain EMA loss scale with alpha clipped [0.01,1]; skip transitions with no valid negative and ensure empty predecessor contexts get h_i=0. Do not permit validation/test-derived negative mining.
END IDEA
