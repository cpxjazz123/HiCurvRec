IDEA: geo_hardpair
TITLE: Incoming-transition geodesic margin quantization
MOTIVATION: Co-consumption-close but non-following items are the informative confounders; the first SID token should place true next items closer to a source item's assigned region than those hard negatives.
NOVELTY: Unlike a behaviour loss appended to an unchanged quantizer, this uses train-only contrastive evidence to alter the actual hyperbolic coarse-code assignment logits. It is not a residual transition warp or global balanced Sinkhorn assignment.
CHANGE: For each training transition source s -> positive p, compare p against a fixed small set of items similar to p's co-consumption profile but absent as successors of s; compute these comparisons using Poincare distance to candidate first-level code vectors and add the margin to the assignment logits before argmin/soft assignment.
SPECIFICATION: Freeze a sparse train-only item co-consumption matrix C and directed successor counts N. For each s sample one positive p~N[s,*] and K negatives n with high cosine(C[p],C[n]) but N[s,n]=0. Let z_i=exp_0^c(x_i), q_k be first-level code points, a(i)=argmin_k d_c(z_i,q_k)^2. Define logits L(i,k)=d_c(z_i,q_k)^2 + eta * 1[k=a(s)] * [m + d_c(z_p,q_k)-d_c(z_n,q_k)]_+ averaged over sampled negatives; use resulting logits for the actual coarse assignment. To keep gradients useful, replace indicator with soft source-assignment probability softmax(-d_c(z_s,q)/tau). Train with baseline reconstruction plus the assignment cross-entropy/commitment term already used by quantizer.
COST: Precompute sparse C and N once, O(nnz(C)+nnz(N)); per sampled transition cost O(K*d + (K+2)*M*d) naively for M first-level codes, or O((K+2)*d) after ordinary assignment distances are cached. At frozen scale sample B=1024 transitions per step: K=4, M=256, d=64 means roughly 0.54G additional distance-coordinate operations per step if recomputing all candidate distances, avoidable by caching the distance table; otherwise about 1.3M pair-coordinate operations. 24 steps/epoch x 3000 epochs = 72k steps, so sparse minibatch sampling rather than all graph edges is mandatory.
HYPOTHESIS: True successors will acquire assignment regions that are geodesically closer to their source region than co-consumption-hard non-successors, improving gold-prefix survival and Stage3 test_R@10; keep only if both the held-out positive-minus-negative gap and test_R@10 rise versus controls, targeting >0.065.
RISKS: Co-consumption-hard negatives may include plausible but unobserved successors; high eta may distort reconstruction or collapse assignments. Frozen negatives may be stale as codes change; sample from a seeded precomputed shortlist and cap margins.
BEHAVIOR SIGNAL: Directed train co-consumption transitions plus profile-similar non-successors.
BEHAVIOR COMPUTATION: From train split only, count directed adjacent item pairs from each observed training history followed by its training target; compute sparse row-normalized co-consumption profiles from co-occurrence in those same training sequences. For each source-positive pair, retrieve top profile-cosine items absent from that source's observed successor set; no validation/test rows.
LEAKAGE BOUNDARY: Construct C, N, positive/negative triples once exclusively from the training split, freeze them, and never read validation/test interactions during SID training or export; use validation only under the predeclared Stage3 selection protocol, not to tune SID construction.
HYPERBOLIC OPERATOR: Squared Poincare-ball distance d_c(u,v)=2/sqrt(c)*atanh(sqrt(c)*||(-u)⊕_c v||), with fixed c=1 and ball radius 1/sqrt(c).
HYPERBOLIC LOCATION: Candidate first-level quantization logits before the coarse token is selected at every training quantization call.
COUPLING PATH: The transition-derived positive/hard-negative margin changes the geodesic-distance logits that select the codeword, so shuffling behavior removes the margin and replacing hyperbolic distance changes the assignment computation itself.
COUPLING EQUATION: L(i,k)=d_c(z_i,q_k)^2 + eta*pi_sk*[m+d_c(z_p,q_k)-d_c(z_n,q_k)]_+, where pi_sk=softmax_k(-d_c(z_s,q_k)^2/tau); behavior term is the sampled train transition (s,p,n), and curved term is d_c.
OBSERVABLES: Measure changed L1 assignment distribution/SIDs, source-conditioned geodesic positive-minus-hard-negative gap, gold-prefix survival depths 1-4, L1 Hard ER, cooccur_overlap_L3, adjacency_L3, extension alphabet, and frozen Stage3 test_R@10.
ABLATION BEHAVIOR OFF: Permute item-to-row associations of frozen C/N features and transition triples while preserving their marginals, then use the same curved logits, batch schedule, eta and seeds.
ABLATION GEOMETRY OFF: Replace every d_c in logits and pi with Euclidean distance in the same code assignment position; keep train triples, negative sampler, eta and all other settings fixed.
ABLATION BOTH ON: Use correctly associated train-only transitions/hard negatives and Poincare distances in the same coarse assignment logits.
SPEC EQUATIONS: u⊕_c v=((1+2c<u,v>+c||v||²)u+(1-c||u||²)v)/(1+2c<u,v>+c²||u||²||v||²). Project z,q to norm <=(1-eps)/sqrt(c). Compute D_ik=d_c(z_i,q_k)^2; pi_s=softmax(-D_s/tau); H_k=mean_n relu(m+sqrt(D_pk)-sqrt(D_nk)); L_ik=D_ik+eta*pi_sk*H_k; token_i=argmin_k L_ik (or existing soft assignment on L during training). Add no extension tokens; use the frozen four-level collision rule unchanged.
SPEC INPUTS OUTPUTS: Inputs: current item embeddings, train-only sampled (s,p,n) minibatch, first-level codebook, c,tau,m,eta. Outputs: modified coarse assignment logits and existing coarse token/gradient; other residual levels remain baseline.
SAFEGUARDS: Clamp norms to (1-eps)/sqrt(c), clamp atanh argument to 1-eps, denominator to >=eps, compute distances in float32, mask positives/negatives with missing IDs, cap H at a fixed value, stop-gradient through hard-negative retrieval, and normalize added loss to reconstruction scale (~1e-4) using a coefficient fixed before runs. Skip malformed triples and preserve baseline assignment for items without train transitions.
END IDEA

IDEA: incoming_barycenter_sink
TITLE: Incoming-context hyperbolic barycenter prior for code assignment
MOTIVATION: Items reached from several predecessor regions are difficult targets; their SID assignment should inherit a compact incoming context instead of relying only on their own content embedding.
NOVELTY: This moves incoming-context information into each item's quantization cost via a per-item hyperbolic barycenter of predecessor code points. It differs from global Sinkhorn balancing, branch-shell geometry and post-hoc graph regularization because the curved barycenter directly participates in per-item assignment.
CHANGE: Build a sparse train-only predecessor distribution for each item and compute a leave-one-edge-out Poincare Fréchet barycenter of the predecessors' current coarse code vectors. Add the distance from each candidate codeword to this barycenter to that item's quantizer assignment cost, weighted inversely by incoming context concentration, so context-diverse targets are pulled more strongly into their predecessors' region.
SPECIFICATION: For item i, P_i={j:N[j,i]>0}, with normalized weights w_ji=N[j,i]/sum_r N[r,i]. Map predecessors' coarse code points q_{a(j)} into the ball. Approximate their Frechet mean b_i by 3 fixed-point steps: v=log_{b}(q); b <- exp_b(sum_j w_ji v), initialized at most frequent predecessor's codepoint. Define concentration h_i=sum_j w_ji^2 and beta_i=beta0*(1-h_i). Per-item candidate cost A_ik=d_c(z_i,q_k)^2 + beta_i*d_c(q_k,b_i)^2. Quantize with argmin_k A_ik. For a small target minibatch, enumerate only its incoming sparse lists; sample at most 16 predecessors/item with deterministic weights when indegree is higher.
COST: Precompute train predecessor lists in O(nnz(N)); per step for B=1024 target items and cap 16 predecessors, three barycenter updates cost O(B*16*d), then assignment context cost O(B*M*d). At d=64,M=256 this is about 16.8M additional coordinate ops per step (one distance per item/code), or 1.21T over 72k steps; avoid the full matrix by ranking baseline top-8 candidates then apply curved context term only to them, reducing added cost to ~0.52M coordinate ops/step and ~37.7B total. No additional parameters or extension alphabet.
HYPOTHESIS: High incoming-context concentration after assignment will reduce the penalty for context-diverse targets and cluster their target regions with observed predecessors, improving the positive-minus-negative gap, prefix survival and Stage3 test_R@10; keep only if test_R@10 improves and exceeds 0.065 without growing extensions.
RISKS: Current hard predecessor assignments make b_i noisy and early assignments unstable; use EMA code vectors and barycenter stop-gradient for first 100 epochs, then ramp beta0. Repeated training prefixes can overweight frequent sequences; row-normalize and degree-cap predecessor samples. Approximate barycenters may be biased near ball boundary.
BEHAVIOR SIGNAL: Directed incoming train co-consumption predecessor counts N[j,i].
BEHAVIOR COMPUTATION: Count j->i when j immediately precedes i in a training history/target sequence reconstructed solely from train split. For every target i, normalize its incoming predecessor counts to w_ji; compute h_i=sum_j w_ji^2, and cap the sampled predecessor set to 16 with a fixed seed.
LEAKAGE BOUNDARY: The N graph, per-item incoming distributions and sampling lists are constructed once from training only and frozen. Validation/test interactions are never read for barycenters, assignment updates or SID export; no user context is used at prediction time.
HYPERBOLIC OPERATOR: Poincare exp/log maps and approximate Frechet barycenter under fixed negative curvature -c=-1; candidate scoring uses Poincare distance.
HYPERBOLIC LOCATION: In the actual first-level codeword assignment cost, where each candidate codepoint is scored relative to the incoming-context barycenter.
COUPLING PATH: Incoming predecessor counts determine b_i and beta_i; the Poincare barycenter and distance contribute directly to A_ik, which determines the SID coarse token. Removing either the counts or curved operations changes A_ik and assignment.
COUPLING EQUATION: A_ik=d_c(z_i,q_k)^2 + beta0*(1-sum_j w_ji^2)*d_c(q_k, FrechetMean_c({q_{a(j)};w_ji}))^2; the behavior term is w_ji from N[j,i], and the curved term is the curvature-c FrechetMean_c and d_c.
OBSERVABLES: Record assignment changes by incoming-context concentration quartile, gold-prefix survival at depths 1-4, L1 Hard ER, cooccur_overlap_L3, adjacency_L3, positive-minus-hard-negative gap, extension alphabet and frozen Stage3 test_R@10.
ABLATION BEHAVIOR OFF: Randomly permute the item-to-row association of N/w/h and the predecessor lists, preserving per-item count/concentration marginals as closely as possible; keep curved barycenters and beta schedule.
ABLATION GEOMETRY OFF: Compute the weighted predecessor arithmetic mean in Euclidean code space and replace d_c with squared Euclidean distance in the same A_ik position; preserve behavior weights and candidate shortlist.
ABLATION BOTH ON: Correct train-only incoming predecessor lists, hyperbolic Frechet barycenter and Poincare assignment cost, with all coefficients fixed before the run.
SPEC EQUATIONS: Poincare exp_x(v)=x⊕_c(tanh(sqrt(c)*lambda_x||v||/2)*v/(sqrt(c)||v||)); log_x(y)=2/(sqrt(c)*lambda_x)*atanh(sqrt(c)||(-x)⊕_c y||)*((-x)⊕_c y)/||(-x)⊕_c y||; lambda_x=2/(1-c||x||²). Iterate b^(t+1)=exp_{b^t}(sum_j w_ji log_{b^t}(q_{a(j)})) for t=0..2. For baseline top-8 candidate set K_i, A_ik=d_c(z_i,q_k)^2+beta0*(1-h_i)*d_c(q_k,b_i)^2; choose argmin over K_i. Keep existing residual levels and collision handling unchanged.
SPEC INPUTS OUTPUTS: Inputs: z_i, current coarse codebook q, frozen train predecessor sparse lists/counts, curvature c=1, beta0, baseline top-8 candidate IDs. Outputs: modified candidate costs and first-level token; no new tokens or test-time features.
SAFEGUARDS: Project all ball points to norm <=(1-eps)/sqrt(c); clamp log/atanh arguments and exp map tangent norms; epsilon-protect zero tangent norms and Frechet denominators; do barycenter updates in float32; stop-gradient through predecessor assignments and b_i to avoid unstable graph-wide gradient paths; use uniform fallback when indegree is zero and beta_i=0 in that case. Set beta0 so median added assignment cost matches a fixed fraction of baseline reconstruction scale (~1e-4); do not tune on test.
END IDEA
