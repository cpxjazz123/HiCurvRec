IDEA: geoflow-metric-rq
TITLE: Behaviour-direction anisotropic assignment metric gated by each codeword's own Poincare conformal weight (single chart, single codebook)
MOTIVATION: RQ-VAE semantic IDs are chosen by plain Euclidean nearest-neighbour, so each item's quantisation error is spread isotropically and the prefix the generative recommender must predict carries no information about where the item's behaviour actually leads. The previous round showed that fixing this by transporting residuals or codewords between charts destroys the consistency between assignment and reconstruction and collapses every level to one prefix. This idea keeps one Euclidean chart and instead makes the residual-space metric itself direction-aware: an error component along the item's measured training transition direction is expensive at codewords deep in the ball and cheap at codewords near the hyperbolic boundary, so the winning codeword is the one whose quantisation error sits where next-step prediction does not need it.
NOVELTY: Not transport, not holonomy, not radial volume/capacity allocation, not prefix ranking, not Sinkhorn. Curvature appears only as the Poincare conformal factor of each individual codeword's own radial position inside its level's own ball (a per-code geometric scalar), and behaviour appears only as a per-(item,code) directional term <r - c_k, u_i>^2 built from directed training transitions. Assignment, residual subtraction, reconstruction and the SID dump all read the identical codeword positions; nothing is moved, mapped into another manifold or re-embedded.
CHANGE: Every RQ level's argmin becomes argmin_k [ ||r - c_k||^2 + lambda_k * <r - c_k, uhat_i>^2 ] with uhat_i the unit mean latent displacement toward the item's training next-items and lambda_k = 1 - min((||c_k||/max_j||c_j||)^2, 1 - 1/K); z_q and the decoder keep using the same c_k, so assignment and reconstruction cannot disagree.
SPECIFICATION: Per epoch, from the training split only, build row-normalised directed transition weights w_ij = n_ij / sum_j n_ij; with detached item embeddings e_i set u_i = sum_j w_ij (e_j - e_i), uhat_i = u_i / max(||u_i||, 1e-8), and uhat_i = 0 for items with no outgoing training transition. For each level l: z_k = ||c_{l,k}|| / max_j ||c_{l,j}||, s_k = 1 - min(z_k^2, 1 - 1/K) (bounded in [1/K, 1], derived only from codeword radii and K), then a_i = <r_i, uhat_i>, b_ik = (C_l uhat_i)_k, d_ik = ||r_i - c_{l,k}||^2 + s_k (a_i - b_ik)^2, k*_i = argmin_k d_ik, r_i <- r_i - c_{l,k*_i}. z_q = sum over the three levels of c_{l,k*}; codebook updates, commitment loss, decoder, collision-extension token and Stage 3 protocol are untouched.
COST: One extra K x d matvec per (item, level) in the quantiser: about 3 * 1023 * K * d MACs per step at the frozen scale (24556 training items / 24 steps = ~1023 latents per step), the same order as the distance matmul already computed, i.e. roughly +2-5 percent per step with no extra epoch. The epoch-level uhat refresh costs ~(number of training transitions) * d MACs (~3e7), negligible. Total wall clock about 1.0-1.05x the baseline 3000-epoch Stage 2 run; extra memory is one B x K temporary and one d-vector per item.
HYPOTHESIS: If a prefix should encode the item's behavioural future, then distorting the assignment metric along the measured transition direction must change which codeword wins for a substantial fraction of items and must lift Stage3 test_recall@10 above the 0.0555 baseline toward 0.065. Required observables in the same single run: a clearly non-zero (expected 5-30 percent) fraction of level-1 assignments that differ from the Euclidean argmin computed on the same residual and codebook; a rise in the training-only prefix-transition lift P(prefix1(j)=prefix1(i) | i->j) over the prefix prior; and level-wise distinct prefix counts staying above 1 with l3_collision well below 1.0 and refinement gain bits above 0.
RISKS: The anisotropy can vanish if neighbour latents are nearly identical (u_i ~ 0) or if most items are cold, reducing the run to the Euclidean baseline.; The direction estimate from the embedding table can be dominated by popularity and rotate u_i toward a global mean direction, making the metric a weak rank-1 shrinkage.; Boundary codewords could attract too many items and re-collapse prefixes; this is monitored in the diagnostics but, per policy, never tuned against.; With one run and no seed repetition the measured recall gain may be inseparable from seed noise, so the effect has to exceed the historical spread around 0.0555.
BEHAVIOR SIGNAL: Directed first-order item-to-item transitions (sequential co-consumption), entering per (item, codeword) as a direction in latent space.
BEHAVIOR COMPUTATION: From the Stage-2 training interaction split only, count n_ij = number of times item j occurs as the next item after item i in a training sequence; row-normalise to w_ij; with the current (detached) item embedding table E compute u_i = sum_j w_ij (e_j - e_i); L2-normalise to uhat_i; set uhat_i = 0 for items with no outgoing training transition. Recomputed once at the start of every epoch from frozen transition counts, cached, detached, never back-propagated.
LEAKAGE BOUNDARY: Transition counts come only from training-split sequences; validation and test interactions are never read when uhat is built, and uhat is frozen before any evaluation or SID dump. No validation statistic (recall, entropy, collision, usage share) enters lambda_k, uhat, the cap 1/K or the codebook, so the SID construction is a pure function of training interactions and training-time parameters.
HYPERBOLIC OPERATOR: Poincare-ball conformal factor with fixed negative curvature -kappa (kappa = 1 after normalising each level by its own maximum codeword radius): gamma(c_k) proportional to 1/(1 - z_k^2), z_k = ||c_k|| / max_j ||c_j||; the induced per-codeword weight s_k = 1 - min(z_k^2, 1 - 1/K) is the curvature-dependent metric scale at that codeword.
HYPERBOLIC LOCATION: Inside the RQ assignment step of every level, as the per-codeword multiplier of the directional quantisation error; it acts during training and is reused when SIDs are dumped, so the same geometry decides both.
COUPLING PATH: The single argmin that selects codeword k* for item i at level l. Setting uhat_i = 0 zeroes the directional term and recovers plain Euclidean k-means; setting s_k = 1 removes the per-codeword curvature gate and leaves behaviour-only flat weighting that cannot spread codewords radially. Both factors multiply the same scalar inside the same distance, so neither is decorative.
COUPLING EQUATION: d_{i,l,k} = ||r_{i,l} - c_{l,k}||^2 + s_k * <r_{i,l} - c_{l,k}, uhat_i>^2, with s_k = 1 - min((||c_{l,k}|| / max_j ||c_{l,j}||)^2, 1 - 1/K) the Poincare conformal (curvature) term and <., uhat_i> the directed-transition (behaviour) term; k* = argmin_k d_{i,l,k}.
OBSERVABLES: (1) Stage3 test_recall@10 (target > 0.065 against the 0.0555 baseline); (2) fraction of level-1 assignments that differ from the Euclidean argmin on the same residual and codebook; (3) per-level distinct prefix counts, l3_collision and l3_refinement_gain_bits, which must stay away from the previous round's collapse values (1, 1.0, 0); (4) training-only prefix-transition lift P(prefix1(j)=prefix1(i) | i->j) relative to the prefix prior; (5) distribution of s_k-weighted winning codeword radii, to see whether items actually spread radially.
ABLATION BEHAVIOR OFF: uhat_i set to the zero vector for all items (behaviour term inactive) while s_k keeps its computed values; the metric then reduces exactly to Euclidean squared distance. Present as a switch in the code, not trained in this round.
ABLATION GEOMETRY OFF: s_k forced to 1 for all codewords (Euclidean, curvature-free direction weighting) while uhat_i is kept; behaviour-weighted but flat, with no per-codeword radial gate. Present as a switch in the code, not trained in this round.
ABLATION BOTH ON: The full coupled metric d = ||r - c_k||^2 + s_k * <r - c_k, uhat_i>^2, the only arm that the single scheduled 3000-epoch Stage 2 run and the frozen Stage 3 protocol actually train.
SPEC EQUATIONS: Per level l: codebook C_l in R^{K x d}, residuals r_i in R^d, directions uhat_i in R^d (unit or zero).   z_k = ||c_{l,k}||_2 / max_j ||c_{l,j}||_2   s_k = 1 - min(z_k^2, 1 - 1/K)   a_i = <r_i, uhat_i>   b_ik = <c_{l,k}, uhat_i> = (C_l uhat_i)_k   d_ik = ||r_i - c_{l,k}||^2 + s_k * (a_i - b_ik)^2   k*_i = argmin_k d_ik   (ties: lowest index)   r_i <- r_i - c_{l,k*_i}   z_q,i = sum_{l=1..3} c_{l,k*_{i,l}}, then the unchanged collision-extension token and decoder. Behaviour: w_ij = n_ij / sum_j n_ij ; u_i = sum_j w_ij (e_j - e_i) ; uhat_i = u_i / max(||u_i||, eps), or 0 if deg_out(i) = 0. Switches: BEH_OFF -> uhat_i := 0 ; GEO_OFF -> s_k := 1 ; BOTH_ON -> as above.
SPEC INPUTS OUTPUTS: Input: the level's codeword matrix C_l (K x d, trainable), residuals r_i (d), per-item unit behaviour direction uhat_i (d, detached, cached per epoch), curvature fixed at kappa = 1 and the derived cap 1/K. Output: integer codeword index k* per item per level, used both to build z_q for the decoder and to define the SID prefix, plus per-codeword weights s_k and per-pair directional errors (a_i - b_ik)^2 for logging. Nothing else in the quantiser, codebook update, loss or collision handling changes.
SAFEGUARDS: uhat_i is L2-normalised with a 1e-8 floor and set to exactly zero for items without training transitions, so cold items fall back to Euclidean quantisation; z_k is clamped to <= 1 - 1/K so s_k stays in [1/K, 1] and can never be zero or negative; the max-norm denominator uses a 1e-12 floor for an all-zero codebook; equal codeword norms make all s_k equal, which is exactly the geometry-off behaviour; neighbour displacements are recomputed under no_grad from detach()ed embeddings so behaviour cannot back-propagate or enlarge the graph; the directional term is a square, so the sign of uhat is irrelevant and no cosine division by a small residual norm is taken, so the previous round's 3.7e13 blow-up cannot recur; assignment ties are broken by lowest index for deterministic SID dumps; K and its cap 1/K are structural (number of codewords), not tuned constants; diagnostics (distinct prefixes, collision, usage share) are logged per epoch for monitoring only and never abort or alter training.
END IDEA
