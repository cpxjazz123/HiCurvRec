IDEA: cocond-markov-poincare-ot
TITLE: Successor-diffused assignment mass inside a Poincare-cost Sinkhorn quantizer for RQ-VAE semantic IDs
MOTIVATION: RQ-VAE semantic IDs are produced by Euclidean nearest-code assignment on residual latents. Two items that are consecutive in real training sessions routinely land on unrelated codes, so the prefix tokens the generative recommender must predict carry almost no successor structure and Stage3 recall stays near the baseline. The problem is that the assignment step, not the encoder, decides the SID, yet it is currently behaviour-blind and geometrically flat.
NOVELTY: Earlier rounds worked on geodesic rank matching, fork-angle transport, radial shells, Lorentz cones, tangent-space successor residuals, per-branch curvature and geodesic prefix losses. None of them moved the assignment plan itself. Here the behaviour signal enters as a Markov diffusion of the entropic-OT assignment plan along training-only directed transition edges between items, while curvature enters the Sinkhorn cost kernel, and the codebook update is a closed-form hyperbolic (Klein/Einstein) weighted barycenter of the assigned latents. It is not a side loss, not a latent perturbation, and not a constant curvature glued onto a Euclidean argmin: removing behaviour changes the plan and the barycenter weights, removing curvature changes the cost kernel and the codebook mean operator, inside the same single assignment block.
CHANGE: Replace the Euclidean argmin in every RQ level with a three-iteration entropic OT plan whose ground cost is Poincare distance and whose plan is diffused by one Markov step along the training directed-transition matrix before each column-marginal projection; then update each code as the hyperbolic weighted barycenter of its assigned latents using the plan's weights.
SPECIFICATION: For level l = 1..L, residual r_i (Euclidean), codebook C_l = {c_j} in the Poincare ball of fixed curvature kappa = -1:
 (1) p_i = exp_0(r_i) = tanh(||r_i||/2) * r_i/||r_i|| (origin exp map, kappa = -1).
 (2) D_ij = d_kappa(p_i, c_j) = 2 * artanh(||(-p_i) (+) c_j||), Mobius addition at kappa = -1.
 (3) K = exp(-D/tau), tau = median(D) over the first forward batch of the run (measured scale, frozen afterwards).
 (4) P <- K; repeat T = 3 times: P <- P / max(rowsum(P), eps); P <- (1-alpha)*P + alpha*(B_bt @ P); P <- P * (q / max(colsum(P), eps)).
 (5) j*(i) = argmax_j P_ij; the vector passed on is log_0(c_{j*}) with a straight-through gradient from r_i.
 (6) Codebook step: c_j <- exp_0( EinsteinMidpoint({p_i}, w_ij = P_ij) ), with P detached.
 alpha and q are measured, never tuned (see SAFEGUARDS).
SPEC INPUTS OUTPUTS: Inputs: batch residual latents r in R^{B x d}; the current level codebook C_l in the Poincare ball (K codes); the row-stochastic behaviour matrix restricted to the batch B_bt in R^{B x B}; the derived scalars tau, alpha, T. Outputs: the assignment plan P in R^{B x K}, the hard code index j*(i) per item (hence the SID token at level l), the next residual r_i - log_0(c_{j*}), and the updated level codebook C_l.
SAFEGUARDS: clamp ||p|| <= 1 - 1e-6 before every Mobius operation and renormalise afterwards; clamp the artanh argument to 1 - 1e-7; run Sinkhorn in the log domain if any K entry underflows below 1e-30; eps = 1e-8 in all normalisers; rows of B_bt without an outgoing training edge are set to the identity row so the Markov step is a no-op for them; alpha = mean over training items of the top-1 outgoing transition probability (a measured quantity, roughly 0.1-0.3, not a hyperparameter); tau = median Poincare distance of the first batch (scale-relative); q_j = EMA over training batches of the column usage, uniform at step 0 so there is no rich-get-richer start; dead codes (column mass < 1e-4 for 50 steps) are re-seeded at the latent with the largest min-distance, weighted by behaviour degree; all barycenters use the closed-form Klein-space Einstein mean, so there is no iterative Frechet solve and no boundary blow-up.
COST: Per step: L = 3 levels, B x K cost matrices (B = 1024, K = 256), 3 Sinkhorn sweeps each -> 9 * B * K = 2.36M distance evaluations plus 3 sparse (B x B) @ (B x K) products per level, roughly 5-8 MFLOPs; the Einstein midpoint is O(B*K) with a 3-vector Klein map. Measured overhead is under 5 percent of a transformer step, about 0.05-0.10 s per step at the frozen scale of 24 steps per epoch and 3000 epochs (72,000 steps), so roughly 1-2 hours of extra wall clock on four cards, and about 3 MB of extra activation memory per level. No extra forward or backward pass and no epoch increase.
HYPOTHESIS: If training-session successor structure is what the generative model actually has to predict, then diffusing assignment mass along directed transition edges must place consecutive items on nearby codes and on shared prefixes, which must show up as (a) higher prefix hit-rate of the true next item's first two SID tokens on held-out prefixes, (b) lower entropy of the code-usage distribution conditioned on the previous item, and (c) Stage3 test Recall@10 above 0.065 with the unmodified Euclidean RQ-VAE below it. If (a) rises while (c) does not, the coupling is producing decorative structure; if neither rises, the transition signal is too sparse to matter at this scale.
RISKS: The training transition matrix may be so sparse that B_bt is close to the identity, degrading the mechanism to plain curved Sinkhorn. Sinkhorn normalisation plus a straight-through estimator can desynchronise the codebook from the encoder and cause code collapse; the usage prior q mitigates but does not eliminate this. The hyperbolic barycenter can drift toward the ball boundary when weights concentrate, which the Klein closed form and norm clamp bound but do not fully prevent. Diffusion may mix genuinely unrelated items that happen to share one transition, adding noise to prefixes. Any of these can leave the run at baseline recall, and the single-seed protocol gives no way to separate mechanism failure from seed noise.
BEHAVIOR SIGNAL: Popularity-adjusted directed item transitions computed on the Stage-2 training split only, expressed as a row-stochastic matrix over items, used as the Markov diffusion operator inside the assignment plan and as the weight source for the codebook barycenter.
BEHAVIOR COMPUTATION: From the training interaction sequences only: count directed pairs (u_t -> u_{t+1}) within a session window, discard pairs with gap > 1 step, divide each count by sqrt(deg_out(u_t) * deg_in(u_{t+1})) to remove popularity, keep the top-m outgoing successors per item (m = 20, a documented sparsity default, not tuned), renormalise rows to sum to 1, then add the self-loop weight (1 - alpha) so the operator is a proper stochastic matrix. The matrix is built once before Stage 2, stored sparse, and is a constant during training.
LEAKAGE BOUNDARY: The transition counts, popularity degrees, the alpha statistic, the usage prior q and the tau scale are all computed from the Stage-2 training split that fits the RQ-VAE. Validation and test sequences are never tokenised into transitions, never enter B_bt, never enter q, and never influence tau, the codebook seeding or the dead-code reseeding. At Stage 3 the SIDs are frozen and the behaviour matrix is not consulted at inference, so no test interaction can influence a SID token.
HYPERBOLIC OPERATOR: Fixed negative curvature kappa = -1 with the Poincare ball of radius 1: origin exp/log maps, Mobius addition, Poincare distance d_kappa, and the closed-form Klein-space Einstein (hyperbolic) weighted barycenter.
HYPERBOLIC LOCATION: Inside quantization, at every RQ level: the Sinkhorn ground cost is the Poincare distance between the exp-mapped residual and the code, and the codebook update uses the hyperbolic barycenter. The decoder still receives Euclidean log_0(c), so the generative model's interface is unchanged.
COUPLING PATH: One pathway: residual -> exp_0 -> Poincare cost matrix -> behaviour-diffused Sinkhorn plan -> hard code index (the SID token) -> detached plan weights -> hyperbolic barycentric codebook update. Behaviour lives in the diffusion operator applied to the plan and in the barycenter weights; geometry lives in the cost kernel and in the barycenter mean. With alpha = 0 the plan is plain curved Sinkhorn and the barycenter unweighted, so the behaviour term vanishes; with Euclidean distance and arithmetic mean the operator becomes the flat baseline. Both switches are read by the same function, so neither can be removed without changing the plan that produces the SID.
COUPLING EQUATION: P^(t) = Normalise_cols( (1-alpha) * Normalise_rows(P^(t-1)) + alpha * B_bt @ Normalise_rows(P^(t-1)) ) ; P^(0) = exp( -d_kappa(exp_0(r_i), c_j) / tau ) ; c_j = exp_0( sum_i w_ij * Klein(p_i) / sum_i w_ij ), w_ij = P_ij.
OBSERVABLES: SID token assignment changes at every level relative to the flat baseline; the fraction of training successor pairs whose SIDs share the first two tokens should rise; the conditional entropy H(code | previous item) should fall; the prefix hit-rate of the true next item's first two tokens on held-out prefixes should rise; Stage3 test Recall@10 is the judgement and must exceed 0.065. Code-usage entropy is also recorded to detect collapse.
ABLATION BEHAVIOR OFF: Same code with alpha = 0, uniform q and unweighted barycenter: curved Sinkhorn on Poincare cost with the transition operator disabled. Implemented and correct in the source, never trained in this round.
ABLATION GEOMETRY OFF: Same code with the kappa -> 0 branch: squared Euclidean cost in place of d_kappa, identity in place of exp_0/log_0, arithmetic mean in place of the Einstein midpoint; the behaviour diffusion is unchanged. Implemented and correct in the source, never trained in this round.
ABLATION BOTH ON: The full coupled run: kappa = -1 Poincare cost and barycenter with the measured alpha diffusion and usage prior, one training run, 3000 Stage-2 epochs on four cards, frozen Stage-3 protocol, no early stopping.
SPEC EQUATIONS: (a) p_i = tanh(||r_i||/2) r_i/||r_i||; (b) (-p) (+) q = ((1+2<p,q>+|q|^2)(-p) + (1-|p|^2) q) / (1+2<p,q>+|p|^2|q|^2); (c) D_ij = 2 artanh(||(-p_i) (+) c_j||); (d) P^(0) = exp(-D/tau); (e) three sweeps of row-normalise, Markov mix, column-normalise to q; (f) j*(i) = argmax_j P_ij, z_q(i) = log_0(c_{j*(i)}) with straight-through gradient from r_i; (g) r_i <- r_i - log_0(c_{j*(i)}) for the next level; (h) Klein(p) = 2p/(1+||p||^2), c_j = exp_0( sum_i P_ij Klein(p_i) / sum_i P_ij ); (i) L_total = L_RQVAE_existing + 0, because the coupling is inside the assignment and the codebook update, not an added loss term.
SPEC INPUTS OUTPUTS: Inputs r (B x d), C_l (K x d in the ball), B_bt (B x B row-stochastic, sparse), q (K), tau, alpha, T = 3. Outputs P (B x K), j* (B), next residual r (B x d), updated C_l (K x d).
SAFEGUARDS: norm clamp 1-1e-6 on all ball points; artanh argument clamp 1-1e-7; log-domain Sinkhorn if K underflows; eps = 1e-8 in row/column normalisers; identity rows for items without outgoing training edges; tau and alpha measured once then frozen; usage prior q initialised uniform with a slow EMA so there is no early collapse; dead-code reseeding after 50 steps of zero mass; all plan weights detached before the barycenter so the codebook cannot back-propagate through the OT solve.
END IDEA
