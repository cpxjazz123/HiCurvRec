IDEA: CURVCELL-SID
TITLE: Co-evolving per-code behavioural curvature field that sizes each RQ-VAE cell by the measured branching of its own successor set.
MOTIVATION: RQ-VAE cells are sized by content density, not by how far user behaviour fans out of them. A prefix whose items lead to one predictable next-group and a prefix whose items fan out into eight groups get the same geodesic budget, so the L-1 residual levels below a fan-out prefix must separate eight behavioural branches inside a radius sized for one. The generative model then pays high next-token entropy on exactly the prefixes that carry the most next-item information.
NOVELTY: Earlier rounds used a global/static curvature from branch counts, radial calibration, shells/volume allocation, geodesic-rank matching, fork-angle transport and cone/margin objectives. This proposal has no pair-rank, no transport, no margin and no shell. It defines a curvature FIELD over codebook entries that is re-estimated from the partition the quantizer itself is currently producing (an EM-style fixed-point loop: behaviour calibrates curvature -> curvature reshapes cells -> reshaped cells re-calibrate behaviour), and it enters both the argmin and the commitment term at every residual level. Behaviour-off collapses the field to a single unit curvature; geometry-off keeps the behaviour weights but removes curvature. No earlier proposal is self-consistent in this sense.
CHANGE: Each code k at level l carries its own negative curvature -kappa[l][k], derived in closed form from the effective number of distinct successor code-groups B[l][k] measured on training transitions under the current SIDs; the level-l assignment and commitment use the curvature-rescaled Poincare distance d_B(eps,c)/sqrt(kappa), so behaviour literally sets the size of the cell each code can claim.
SPECIFICATION: Unit Poincare ball B^d (curvature -1), Mobius add oplus, d_B(u,v)=2*atanh(||(-u) oplus v||). RQ-VAE with L levels x K codes, latent z_i = tanh(E(x_i))*(1-1e-6). State: s[l][k] = sqrt(kappa[l][k]) > 0. Refresh at epochs t in {1,2,4,...,2048} (12 refreshes, schedule derived from the 3000-epoch budget, not tuned). Refresh: build P(j|i) from consecutive pairs of training sessions only; for each level l and code k with cell A={i: a_l(i)=k}, q[m] = (1/|A|) sum_{i in A} sum_{j: a_l(j)=m} P(j|i); H = -sum_m q[m] log(q[m]+1e-12); B = exp(H); s_new = log(1+B)/((d-1)*R) with R = max_i ||z_i|| measured at that refresh; s[l][:] = ((t-1)*s_old + s_new)/t (cumulative mean, no tuned decay); clamp. Forward: eps=z_i; for l=1..L: k_l = argmin_k d_B(eps, c[l][k])/s[l][k]; eps = (-c[l][k_l]) oplus eps. Loss: reconstruction ||x_i - D(z_i)||^2 + beta * sum_l ( d_B(eps_{l-1}, sg(c[l][k_l])) / s[l][k_l] )^2, beta inherited unchanged from the baseline config. No gradient flows into s.
COST: Negligible. Per step at the frozen scale (batch = ceil(24556/24) = 1023 items, K=256, L=4): 1023*256*4 = 1,047,552 (item,code) pairs, i.e. one extra multiply per pair to divide by s -> about +1.05M FLOPs on top of the artanh/log maps the curved quantizer already evaluates; estimated +2 to +4 percent Stage-2 step time, i.e. roughly +2 to +4 percent of the 3000-epoch budget. Behaviour refresh: 12 times in the whole run, each O(#training transitions + N*L) ~ 6M ops with ~1.5M session transitions, under 1-2 s each, under 0.1 percent of wall clock. No extra parameters, no extra memory beyond L*K scalars (1024 floats).
HYPOTHESIS: If prefix entropy is limited by curvature budget rather than by encoder capacity, then with the coupling on the per-code cell sizes will become ordered by measured branching (Spearman |A_k| vs B_k clearly positive), the level-1 conditional entropy H(next code | level-0 code) will fall, and Stage-3 test Recall@10 will exceed 0.065 in the single run. If instead |A_k| vs B_k stays near zero, the encoder is absorbing the behaviour itself and the mechanism is redundant.
RISKS: The encoder is free to move latents, so it may cancel the curvature rescaling (the argmin only shifts when cell boundaries actually move); the self-consistency loop can drift toward a few very-low-curvature huge cells or oscillate at refresh epochs; curvature-rescaled distances are not a metric, so a code's cell may become non-convex or empty; early refreshes run on noisy SIDs before the partition stabilises; if Stage-3 generators already learn prefix frequency, extra prefix coherence may not convert into recall.
BEHAVIOR SIGNAL: Directed item-to-item transitions inside training sessions, aggregated into the effective number of distinct successor code-groups B[l][k] of each current SID cell (a branching, not a popularity, statistic).
BEHAVIOR COMPUTATION: From the Stage-2 training split only: for every consecutive pair (i -> j) in a training session increment n(i,j), row-normalise to P(j|i) = n(i,j)/sum_j' n(i,j'). At a refresh, read the current assignment a_l(i) for all training items, accumulate for each cell k the K-vector q[m] = mean over i in cell of the transition mass their successors send to level-l code m, take H = -sum q log q and B = exp(H). Computed 12 times, outside the training step, in one vectorised pass over the transition list.
LEAKAGE BOUNDARY: The transition counts, the cell statistics and R are built exclusively from the Stage-2 training split; validation and test interactions are never read by the SID builder, and the refresh only queries the training transition table plus the current training-item assignments. Stage-3 data, the Stage-3 generator and any held-out recall computation never enter the curvature field, so no validation or test interaction can influence SID construction; no constant in the mechanism is chosen by trying values, so no data-dependent selection path exists either.
HYPERBOLIC OPERATOR: Fixed negative curvature per codebook entry, kappa[l][k] = (log(1+B[l][k])/((d-1)*R))^2, applied through the curvature-rescaled Poincare distance D = 2*atanh(||(-eps) oplus c||)/sqrt(kappa) and the Mobius residual eps <- (-c) oplus eps; curvature is derived from data, not trained, and is bounded by kappa*R^2 < 1.
HYPERBOLIC LOCATION: Inside the quantizer, at every level of the residual chain: the nearest-code search, the commitment term, and the residual that is handed to the next level. It does not sit in a separate loss.
COUPLING PATH: training transitions -> per-cell successor entropy B[l][k] -> per-code curvature kappa[l][k] -> rescaled distance used in argmin and commitment -> which items share a cell -> SID -> the next refresh re-measures B. Removing the behaviour term freezes kappa at 1 and the argmin becomes the plain fixed-curvature Poincare nearest code; removing curvature turns the same expression into a behaviour-weighted Euclidean nearest code. Either removal changes which codes are assigned, hence the SIDs.
COUPLING EQUATION: k_l(i) = argmin_k [ d_B(eps_{l-1}(i), c[l][k]) / sqrt( kappa[l][k] ) ] with sqrt(kappa[l][k]) = log(1 + exp(H_l[k])) / ((d-1)*R), H_l[k] = -sum_m q_l[k][m] log q_l[k][m], q_l[k][m] = (1/|A_l[k]|) sum_{i in A_l[k]} sum_{j in code m} P(j|i).
OBSERVABLES: (1) SID assignment: rank correlation between cell size |A_l[k]| and B_l[k], and the distribution of sqrt(kappa) across level-0 codes; (2) prefix behaviour predictability: H(next level-l code | level-l code) recorded at each refresh, and SID churn per refresh; (3) Stage-3 test Recall@10 against 0.065; (4) code usage histogram and collision/ER diagnostics recorded only as diagnostics, never as a gate.
ABLATION BEHAVIOR OFF: use_behaviour_curvature=False -> s[l][k] = 1 for every level and code, refresh loop skipped, so the quantizer is the fixed unit-curvature Poincare RQ-VAE with everything else identical; one training run, no tuning.
ABLATION GEOMETRY OFF: use_poincare=False -> D_l(k,eps) = ||eps - c[l][k]|| / s[l][k] with the identical behaviour-derived s, giving a behaviour-weighted Euclidean quantizer; this isolates curvature from the behaviour weighting.
ABLATION BOTH ON: use_behaviour_curvature=True and use_poincare=True -> D_l(k,eps) = d_B(eps, c[l][k])/s[l][k] with s from the refresh loop; this is the single trained candidate of the round.
SPEC EQUATIONS:
d_B(u,v) = 2*atanh(clamp(||(-u) oplus v||, 0, 1-1e-7)), with standard Mobius subtraction in ball coordinates.
Behaviour refresh at t in {1,2,4,...,2048}:
for l in 1..L:
  for k in 1..K:
    A = {i : a_l(i) == k}
    if |A| == 0: s_new[l][k] = mean over non-empty cells of s_new[l][:]; continue
    q[m] = (1/|A|) * sum_{i in A} sum_{j : a_l(j)==m} P(j|i)      m = 1..K, training transitions only
    H = -sum_m q[m]*log(q[m] + 1e-12)
    B = exp(H)                                                     B >= 1 by construction
    s_new[l][k] = log(1 + B) / ((d-1) * R)                         R = max_i ||z_i|| measured now
  s[l][:] = ((t-1)*s[l][:] + s_new[l][:]) / t                      cumulative mean
  s[l][:] = clamp(s[l][:], log(2)/((d-1)*R), (1-1e-6)/R)
Forward, every step:
eps = z_i
for l in 1..L:
  dist[k] = poincare ? d_B(eps, c[l][k]) / s[l][k] : norm(eps - c[l][k]) / s[l][k]
  k_l = argmin_k dist[k]
  eps = (-c[l][k_l]) oplus eps
SID(i) = (k_1, ..., k_L)
Objective:
loss = ||x_i - D(z_i)||^2 + beta * sum_l ( d_B(eps_{l-1}, stopgrad(c[l][k_l])) / s[l][k_l] )^2
s is a detached buffer; no gradient into the entropy and the refresh never runs inside the autograd graph.
SPEC INPUTS OUTPUTS: Inputs: the training-session transition table, the current per-item SID assignment, the current latent radius R, the per-level codebooks c[l][k]; at forward time the latent eps and the codebook. Outputs: a per-level, per-code curvature buffer s[l][k] (L*K floats) refreshed 12 times, and per step the discrete SID (k_1..k_L) plus the rescaled commitment term used in the loss. The operator is a drop-in replacement for the nearest-code search and commitment term of the existing RQ-VAE.
SAFEGUARDS: artanh argument clamped to 1-1e-7 and ||eps|| clamped to 1-1e-6 by the tanh-scaled encoder head so no latent leaves the ball; log(1+B) is always >= log 2 because B >= 1, so no division by zero; empty cells inherit the level-mean curvature; s clamped to [log(2)/((d-1)R), (1-1e-6)/R] so kappa*R^2 < 1 and the rescaled chart never degenerates; cumulative averaging with weight 1/t damps oscillation across refreshes without any tuned decay constant; cells with no observed transition fall back to the level mean; curvature is a detached buffer with no gradient so the entropy can never backprop into the encoder; ties are broken by lowest code index so SID construction is reproducible.
END IDEA
