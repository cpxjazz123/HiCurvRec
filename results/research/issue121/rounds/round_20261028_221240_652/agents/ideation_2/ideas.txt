IDEA: SUCCFAN-CURV-RQ
TITLE: Successor-fanout curvature field that rescales the RQ residual chain through the Poincare conformal factor
MOTIVATION: RQ-VAE spends the same quantization resolution everywhere. In real sequences most items have one or two plausible successors (their SID should stay coarse and stable), while a minority of "hub" items branch into dozens of successors (their SID needs fine resolution or the next item is unreachable by prefix extension). A flat metric cannot express that; a single global curvature cannot either.
NOVELTY: Earlier work here moved successor information into the quantizer as ranks, transported tangent directions, cones, shells or barycentres. This idea never moves the item: it makes curvature a per-prefix-node quantity measured from successor fanout and lets that local curvature rescale the RQ residual chain via the Poincare conformal factor lambda_p(x) = 2/(1 - c_p ||x||^2). The curvature field is derived, not trained, and it multiplies the residual instead of adding a loss.
CHANGE: Each SID prefix node p carries a negative curvature c_p computed from the training-only popularity-adjusted successor fanout of the items currently assigned to p; the level-l residual is amplified by lambda_p at encode and divided by lambda_p at decode, so high-branching regions of the code tree get geometrically more resolution.
SPECIFICATION: See SPEC EQUATIONS. Three switches exist in code: USE_BEHAVIOUR (fanout -> c_p) and USE_HYPERBOLIC (lambda != 1). Behaviour off sets all c_p = 1 (fixed unit curvature). Geometry off takes the c -> 0 limit (lambda == 1, plain RQ sum). Both on is the shipped candidate.
COST: Same order as baseline. Per step (batch ~1023 items, 3 levels, 256 codes/level): codebook lambda precomputation 3x256 scalars, per item per level two scalar multiplies in encode and two in decode, ~6k extra scalar ops per step and no extra matmuls; <1% of a step. Once per epoch, one pass over 24556 items and their training successors to refresh f_i and the per-node means (~0.5 ms). Over 3000 epochs x 24 steps = 72000 steps the added wall clock is roughly 1-3% of Stage 2.
HYPOTHESIS: If the flat-resolution hypothesis is the bottleneck, then giving hub prefixes a larger conformal factor must make their level-2/level-3 codes separate successors that currently collide, which must show up as (i) higher per-level code entropy concentrated in the top fanout quartile and (ii) higher training prefix-conditional next-code accuracy for those items, and finally Stage 3 test_recall@10 above 0.065 in the single run.
RISKS: The fanout field may be nearly constant after normalisation, collapsing to fixed curvature (mechanism idle). Amplified residuals for hubs may starve the other prefixes of codebook capacity. Successor fanout is noisy for rare items. The generator may not exploit finer hub codes, so Recall stays flat even if assignment does change. Deeper levels could become numerically stiff where lambda is large.
BEHAVIOR SIGNAL: Popularity-adjusted directed successor fanout of each training item, aggregated to the SID prefix node that item currently occupies.
BEHAVIOR COMPUTATION: From training-split sequences only: n_ij = directed transition counts, succ(i) = {j : n_ij > 0}, indeg(j) = number of training items with n_.j > 0. f_i = log(1 + sum_{j in succ(i)} n_ij / sqrt(1 + indeg(j))). For level-l prefix node p with member set M_p = {i : codes_{1..l}(i) = p}, raw_p = mean_{i in M_p} f_i; g_p = clip((raw_p - mu_l)/(sigma_l + 1e-6), -4, 4) where mu_l, sigma_l are the mean and std of raw over non-empty level-l nodes. c_p = clip(exp(g_p), 0.1, 10.0). Recomputed once per epoch from the current assignments with stop-grad; never from validation or test interactions.
LEAKAGE BOUNDARY: f_i, indeg and all n_ij come exclusively from the training interaction file; the statistics are a frozen array indexed by training item id. Validation and test sequences are never read by the SID builder, by the curvature field, or by the assignment step. At inference the curvature field is a lookup over the frozen codebook prefixes, so no per-user or per-session test interaction can influence a SID.
HYPERBOLIC OPERATOR: Trainable-free negative curvature per prefix node, c_p = -kappa_p in (0.1, 10.0), entering through the Poincare conformal factor lambda_p(x) = 2/(1 - c_p ||x||^2) and, for the assignment score, the conformal approximation of the Poincare distance d_{c_p}(a,b) ~ sqrt(lambda_p(a) lambda_p(b)) ||a - b||.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer, in both the code assignment score and the residual recursion (encode) / residual recomposition (decode), at every level l = 1..3, using the curvature of the parent prefix.
COUPLING PATH: fanout f_i -> node statistic g_p -> curvature c_p -> conformal factor lambda_p -> level-l assignment score and residual scaling -> residual handed to level l+1 -> SID tokens. Removing the behaviour term freezes c_p = 1 and the residual chain becomes fixed-curvature RQ; removing the curved term sets lambda = 1 and the chain collapses to the Euclidean RQ sum. Both changes alter the assignment, so the pathway is the mechanism.
COUPLING EQUATION: q_l(i) = argmin_k [ sqrt(lambda_{p}(x_i^l)) * lambda_p(e_k)^{1/2} * ||x_i^l - e_k|| ],  x_i^{l+1} = lambda_{c_p}(e_{q_l(i)}) * (x_i^l - e_{q_l(i)}), with c_p = exp(clip((mean_{i in M_p} f_i - mu_l)/(sigma_l+eps), -4, 4)).
OBSERVABLES: (1) SID assignment changes: per-level code usage entropy, and the gap in entropy between the top and bottom fanout quartile, must widen relative to a flat-metric quantizer. (2) Gradient/parameter update: lambda_p enters the residual so the codebook gradients for hub-prefix codes are scaled by lambda_p; the level-2/3 codebooks must drift more for hub prefixes. (3) Prefix behaviour predictability: training prefix-conditional next-code accuracy at levels 1-3 for hub items. (4) Stage 3 test_recall@10 in the single run, judged against 0.065.
ABLATION BEHAVIOR OFF: USE_BEHAVIOUR = False: f_i replaced by its global mean so g_p = 0 and c_p = 1 for every prefix node; lambda_p is still computed and applied with unit curvature, so the residual chain is curved but blind to behaviour.
ABLATION GEOMETRY OFF: USE_HYPERBOLIC = False: the c -> 0 limit, lambda_p(x) := 1 everywhere, assignment is plain Euclidean nearest code and x^{l+1} = x^l - e_{q_l}; the behaviour field is still computed and logged but multiplies nothing, so this is exactly standard RQ-VAE.
ABLATION BOTH ON: the shipped candidate, c_p from fanout and lambda_p applied in both assignment and residual chain; no arm of the three is trained this round, all three are reachable by config flags.
SPEC EQUATIONS: 
  Encode, item i with latent z_i:
    x^1 = z_i ; p_1 = root
    for l = 1..L (L = 3):
      c = CURV[p_l]                                  # scalar, from behaviour field
      for each code e_k in codebook C^l: lam_k = 2 / max(1 - c*||e_k||^2, 1e-3)
      lam_i = 2 / max(1 - c*||x^l||^2, 1e-3)
      q_l = argmin_k  sqrt(clip(lam_i, 0.05, 20) * clip(lam_k, 0.05, 20)) * ||x^l - e_k||
      r_l = clip(lam_{q_l}, 0.05, 20) * (x^l - e_{q_l})       # hyperbolic metric step
      x^{l+1} = r_l ;  p_{l+1} = (q_1..q_l)  (stop-grad)
  Decode, exact inverse of the chain:
    acc = e_{q_L}
    for l = L-1 down to 1: acc = e_{q_l} + acc / clip(lam_{q_l}, 0.05, 20)
    zhat_i = acc    # equals sum_l e_{q_l} when c = 0
  Loss: unchanged RQ-VAE loss ||z_i - zhat_i||^2 + ||sg[zhat_i] - z_i||^2 (or the baseline commitment term), with x^l and e_{q_l} in place of the Euclidean residual targets. lambda is a stop-grad reweighting; no extra loss term and no extra parameter.
  Curvature refresh, end of each epoch: recompute M_p from current argmin assignments, recompute f_i from the frozen training transition table, set CURR[p] = c_p as above; empty nodes inherit mu_l (g_p = 0, c_p = 1).
SPEC INPUTS OUTPUTS: Inputs: encoder latent z_i (batch, d); three codebooks C^1..C^3 of size K=256 each; per-item training fanout f_i (24556 floats); the previous epoch's prefix partition. Outputs: SID tokens (q_1,q_2,q_3) per item, the curved residual chain x^1..x^{L+1}, the reconstruction zhat_i used by the loss, and the refreshed curvature table CURR over all non-empty prefixes.
SAFEGUARDS: clamp 1 - c||x||^2 to at least 1e-3 before the reciprocal; clamp lambda to [0.05, 20]; clamp g_p to [-4,4] so c_p in [0.018, 54] before the final [0.1,10] clip; clamp c_p to [0.1,10]; guard sigma_l < 1e-6 by using g_p = 0 for that level; empty or singleton prefixes use g_p = 0 (c_p = 1); detach f_i, M_p and the curvature table from the graph; initialise CURR[all] = 1.0 so epoch 1 is exactly fixed-curvature and the field only turns on once the first real partition exists; accumulate the decode chain in float32; assert that the c = 0 limit reproduces the baseline residual sum to 1e-5 in a unit check.
END IDEA
