IDEA: KAPPA_BRANCH
TITLE: Training-branching sets a per-item curvature field that drives the RQ-VAE assignment metric.
MOTIVATION: A content-only RQ-VAE gives every item the same geometric room. Items with many behaviourally distinct successors (broad-appeal hubs) get coarse prefixes that cannot separate those successors, while leaf items waste capacity. In a negatively curved space volume grows exponentially with radius, so the place where the training transition graph branches is exactly where more negative curvature buys separation per bit; where it does not branch, extra curvature only adds distortion.
NOVELTY: Curvature is neither a global hyperparameter nor a trainable scalar. It is a per-item field computed from the training-only transition graph and injected into the pair distance used for nearest-code search, codebook gradient and hence SID assignment. Existing behaviour-aware quantizers reweight the data term of a Euclidean quantizer; here behaviour changes the metric itself, and the metric changes the codes.
CHANGE: Each item gets kappa_i from its normalised successor branch entropy; the RQ-VAE assigns and commits with a symmetrised Poincare distance whose curvature is the harmonic mean of the two endpoints' curvatures, so codebook gradients, code occupancy and the final SID all move with the training graph.
SPECIFICATION: successor distribution p_ij = n_ij / sum_j n_ij with add-one smoothing on the training pair counts n_ij; branch entropy H_i = -sum_j p_ij log p_ij; h_i = H_i / log(|S_i| + 1) clipped to [0,1]; kappa_i = kappa0 * (1 + h_i) with kappa0 = 1 (unit ball, no free constant, no sweep); pairwise curvature kbar_ik = 2 kappa_i kappa_k / (kappa_i + kappa_k) in [1,2]. Points are tangent vectors mapped by p_kappa(w) = tanh(sqrt(kappa)||w||)/(sqrt(kappa)||w||) * w. Distance d_kappa(u,v) = (1/sqrt(kappa)) arcosh(1 + 2 kappa ||u-v||^2 / ((1 - kappa||u||^2)(1 - kappa||v||^2))). Level assignment k* = argmin_k d_kbar(p(z_i), p(c_k)); residual r <- r - c_{k*}; commitment L_c = beta * d_kbar(p(r), p(c_{k*}))^2 with beta = 0.25 (the documented baseline default, not searched); reconstruction loss unchanged, codebooks still trained by straight-through gradients, only now those gradients flow through the curved commitment.
COST: ~786k Poincare distances per step (batch 1024 x 256 codes x 3 levels) replacing dot products, two arcosh/hyperbolic evaluations on that tensor; estimate +3 to +5 ms per step, i.e. ~4-6 minutes over 72,000 steps on four cards, under 5% of Stage-2 wall clock. One pre-pass over the training pairs (order 10^5-10^6 edges) to build n_ij and h_i, a few seconds and ~1 MB for the per-item curvature table.
HYPOTHESIS: If hub items really need more separated coarse prefixes, then with curvature on, high-branch items should spread over more distinct level-1 codes than low-branch items (a measurable occupancy/entropy gap), the Stage-3 generator's first-token entropy on hub contexts should drop, and test Recall@10 should exceed the frozen baseline; for the idea to be worth keeping the occupancy gap and the recall gain must both appear in the single run.
RISKS: The harmonic-mean pair curvature is not a true metric, so assignment may oscillate between epochs; if branch entropy is dominated by a few very high-degree items the field is nearly constant and the mechanism degenerates; if the Stage-3 generator is insensitive to fine prefix differences the extra separation buys nothing.
BEHAVIOR SIGNAL: Directed item transition counts and the resulting per-item successor branch entropy.
BEHAVIOR COMPUTATION: From the training split only, count consecutive pairs (u -> i) over all training sequences, deduplicate repeated (user, item) transitions so one power user cannot dominate, add-one smooth, normalise to p_ij, compute H_i and h_i, store a 24556-vector of kappa_i once before Stage 2 starts.
LEAKAGE BOUNDARY: The transition graph is built exclusively from training-split sequences that Stage 2 already consumes; no validation or test interaction, no Stage-3 label and no future-item information enters kappa. SIDs are frozen when Stage 2 ends, so nothing from validation or test can propagate back into the IDs.
HYPERBOLIC OPERATOR: Poincare ball distance with per-pair negative curvature kbar_ik in [1,2] plus the curvature-scaled tangent-to-ball map tanh(sqrt(kappa) r)/(sqrt(kappa) r).
HYPERBOLIC LOCATION: Inside quantization, at every residual level: the nearest-code rule and the commitment term of the Stage-2 RQ-VAE, which is where codebook gradients and SID assignment are decided.
COUPLING PATH: training pairs -> per-item branch entropy -> kappa_i -> kbar_ik -> nearest-code decision and commitment gradient -> codebook entries -> SID assignment of every item. Removing behaviour collapses kappa_i to 1 and the whole path to unit-curvature RQ; removing geometry collapses the decision to Euclidean nearest neighbour.
COUPLING EQUATION: k*(i) = argmin_k (1/sqrt(kbar_ik)) arcosh(1 + 2 kbar_ik ||p(z_i)-p(c_k)||^2 / ((1-kbar_ik||p(z_i)||^2)(1-kbar_ik||p(c_k)||^2))), with kbar_ik = 2 kappa_i kappa_k/(kappa_i+kappa_k) and kappa_i = 1 + H_i/log(|S_i|+1).
OBSERVABLES: per-item curvature table; level-1 code occupancy entropy split by high/low branch items; fraction of items whose level-1 code differs from the Euclidean baseline; prefix-to-successor predictability on training prefixes; Stage-3 test_recall@10.
ABLATION BEHAVIOR OFF: kappa_i forced to kappa0 for all i, i.e. every item lives in the same unit-curvature ball; the curved distance code path still executes. No arm is trained.
ABLATION GEOMETRY OFF: kbar distance replaced by the Euclidean ||p(z_i)-p(c_k)||^2 on the same vectors with the same commitment weight; the entropy table is still computed and still logged. No arm is trained.
ABLATION BOTH ON: the full run described above, one training run, 3000 Stage-2 epochs, frozen Stage-3 protocol, no early stopping.
SPEC EQUATIONS: as in SPECIFICATION plus pseudocode: build n_ij, h_i, kappa_i once; per step encode z=E(x); for l in 1..3: pz=ball(z); for all k compute d_kbar; k*=argmin; e=c[l][k*]; r=r-e; acc+=e; L = ||x - D(acc)||^2 + 0.25 * sum_l d_kbar(p(r_l), p(e_l))^2 + straight-through codebook update.
SPEC INPUTS OUTPUTS: inputs are the item content embeddings x_i, the frozen kappa table and the codebooks; outputs are the three-level SID per item, the trained codebooks and the standard Stage-2 checkpoints.
SAFEGUARDS: clamp all ball norms to 1 - 1e-5 before arcosh; clamp the arcosh argument to at least 1 + 1e-7; fall back to the Euclidean distance for any pair whose clamped distance is non-finite; floor |S_i| at 1 and h_i at 0 so items with no observed successor sit at kappa0; freeze kappa after the pre-pass so it cannot co-adapt with the codebooks; assert that the SID assignment is a pure function of the frozen table and the epoch's codebooks.
END IDEA

IDEA: ANCHOR_TANGENT
TITLE: Quantize each item in the tangent space at the hyperbolic Frechet mean of its training successors.
MOTIVATION: Content-based SIDs put an item next to items that look like it, but the generator has to predict it from what a user just consumed. When an item's true predecessors/successors sit far away in content space, the prefix that the generator can actually infer points at the wrong code, and the model spends capacity learning a mapping that the ID layout contradicts.
NOVELTY: The curved operation is not a distance and not a loss weight: it is the choice of chart. Every item is re-expressed as a tangent vector at its own behaviour centroid, so the SID records how the item deviates from where its training successors say it should be, and the decoder walks back out through exp at that same anchor. Behaviour-dependent centres plus Mobius exp/log make the coordinate system itself a function of the training graph.
CHANGE: Compute a per-item anchor as the Poincare Frechet mean of the item's training successors; log-map the encoder output into the tangent space at that anchor; run the ordinary residual quantizer there; decode the summed residual back to the ball through exp at the anchor before the decoder.
SPECIFICATION: w_i = tanh(||z_i||) z_i/||z_i|| in the unit ball (fixed kappa = -1). Successor weights w_ij = n_ij / sum_j n_ij over S_i. Anchor by K = 3 fixed-point iterations: m_i^(0) = w_i, m_i^(t+1) = exp_{m_i^(t)}( sum_j w_ij log_{m_i^(t)}(w_j) ). With Mobius addition a (+) b = ((1 + 2<a,b> + ||a||^2) b + (1 - ||b||^2) a) / (1 + 2<a,b> + ||a||^2||b||^2), exp_m(v) = m (+) tanh(||v||/2) v/||v|| and log_m(w) = 2 artanh(||(-m)(+)w||) ((-m)(+)w)/||(-m)(+)w||. Then t_i = log_{m_i}(w_i); residual chain r_0 = t_i, for l = 1..3: k_l = argmin_k ||r_{l-1} - c_lk||^2, r_l = r_{l-1} - c_lk, s_i += c_lk; dequantised point w_hat_i = exp_{m_i}(s_i); decoder input log_0(w_hat_i) rescaled to the baseline decoder's expected norm; loss = ||x_i - D(log_0(w_hat_i))||^2 + 0.25 ||sg(s_i) - t_i||^2 + 0.25 ||s_i - sg(t_i)||^2, the standard commitment form applied to the tangent vector.
COST: Anchors computed once before Stage 2: |E| edges x d x K = 3 Mobius evaluations, order 10^8 flops, under 5 s and 24556 x d floats of storage (~6 MB at d = 64). Per step: one batch log at the anchors and one batch exp, 1024 points each, plus two Mobius adds, well under 1 ms on GPU; total overhead below 1% of the 72,000-step Stage-2 run. No extra parameters.
HYPOTHESIS: If the generator's difficulty is that prefixes disagree with transitions, then anchoring should make the first code of an item predictable from the codes of its training predecessors much more often than in the unanchored quantizer, and Stage-3 test_recall@10 should rise; the claim is worth keeping only if prefix-predictability and recall move together in the single run.
RISKS: Frechet means of popular hubs can be close to their own point, so t_i is near zero for hubs and the quantizer spends few bits on exactly the items that matter; successor sets are sparse for the long tail, so most anchors collapse to the origin and the mechanism degenerates to baseline; the decoder input distribution shifts, which can slow the 3000-epoch fit.
BEHAVIOR SIGNAL: Directed training transitions aggregated per item into a successor distribution.
BEHAVIOR COMPUTATION: From training sequences only, count (u -> i) over adjacent pairs, deduplicate per (user, item), keep the successor multiset S_i with counts n_ij, normalise to w_ij, and build the anchor table once; items with empty S_i get m_i = 0.
LEAKAGE BOUNDARY: S_i comes only from training-split adjacency that Stage 2 is already allowed to see; the anchor table is frozen before the first Stage-2 step and before any validation pass; validation and test sequences are never read when building S_i, so no future interaction can shape an anchor or an ID.
HYPERBOLIC OPERATOR: Mobius exp/log maps and the Poincare Frechet mean in the unit ball, curvature kappa = -1 fixed.
HYPERBOLIC LOCATION: In Stage-2 quantization, at the coordinate change between the encoder's content space and the residual quantizer, and in the dequantisation that feeds the decoder.
COUPLING PATH: training pairs -> successor distribution -> Frechet-mean anchor m_i -> log_m(w_i) -> residual codes -> SID -> exp_m(sum of codes) -> decoder reconstruction and codebook gradient. Removing behaviour sets m_i = 0 and the path is ordinary RQ; removing geometry makes the anchor an arithmetic mean and the residual a linear difference.
COUPLING EQUATION: t_i = log_{m_i}(exp_0(z_i)) with m_i = argmin_m sum_{j in S_i} w_ij d_P(m, w_j)^2, and w_hat_i = exp_{m_i}(sum_{l=1..3} c_{l,k_l}).
OBSERVABLES: mean ||t_i|| versus mean ||z_i|| (how much of the item is explained by its behaviour anchor); anchor-hit rate, i.e. share of items whose level-1 code equals the code its anchor falls in; prefix-to-successor predictability on training prefixes; fraction of items whose SID changes relative to unanchored RQ; Stage-3 test_recall@10.
ABLATION BEHAVIOR OFF: m_i = 0 for every item, so the mechanism is plain unit-ball RQ with the same loss and the same codebooks path; the anchor table is still built and logged. No arm is trained.
ABLATION GEOMETRY OFF: m_i becomes the arithmetic mean of the successor content embeddings, t_i = z_i - m_i, reconstruction adds s_i linearly, no exp/log anywhere; the behaviour table is unchanged. No arm is trained.
ABLATION BOTH ON: the full coupled run, one training run on the frozen budget, frozen Stage-3 protocol.
SPEC EQUATIONS: as above plus pseudocode: precompute n_ij, w_ij, m_i by 3 Frechet iterations; per step w=tanh(||z||) z/||z||; t=log_m(w) (fall back to 0 when ||(-m)(+)w|| < 1e-8); standard RQ on t; w_hat=exp_m(acc); L=||x-D(log_0(w_hat))||^2 + 0.25||sg(acc)-t||^2 + 0.25||acc-sg(t)||^2.
SPEC INPUTS OUTPUTS: inputs are item content embeddings, the frozen anchor table and the successor weights; outputs are the three-level SID, the trained codebooks, the anchor table and the reconstruction checkpoints.
SAFEGUARDS: clamp every ball point to norm 1 - 1e-5; clamp artanh arguments to 1 - 1e-7; return the origin when the Mobius inverse is numerically zero; detect non-finite exp/log and fall back to the Euclidean residual for that batch; rescale log_0(w_hat) to the baseline decoder input norm so the decoder is not re-tuned; keep the anchor table on CPU and move it per batch to avoid a 6 MB per-step copy.
END IDEA

IDEA: GEO_REPAIR
TITLE: Behaviour-directed geodesic reassignment of colliding semantic IDs so the generator's reachable item set stops depending on arbitrary tie-breaks.
MOTIVATION: The quantizer maps many items onto the same three-token SID; the generator can only emit one item per SID, so the rest become effectively unreachable and recall is capped by an arbitrary content tie-break that has nothing to do with what users actually do next. Adding codes or a fourth level changes the vocabulary and the Stage-3 protocol; nothing has to change if the ambiguous tail of the assignment is decided by behaviour instead.
NOVELTY: The curved operation acts on the decision rule for already-ambiguous items only, not on the encoder, the loss or a global assignment. The behaviour centroid is the reference point, the Poincare distance to the candidate codes is the criterion, and the representative of each collision class is chosen by training in-degree, so the SID the generator already emits stays fixed and only the unreachable duplicates are moved to where their successors say they belong.
CHANGE: After the epoch's assignment, group items by full SID; the highest training in-degree item keeps the ID, and every other member is re-assigned at the last level (or the second level if the parent prefix has no free code) to the code geodesically closest to its training successor centroid.
SPECIFICATION: Group G_s = {i : SID(i) = s}. Representative r(s) = argmax_i indeg_train(i). For i in G_s, i != r(s): m_i = Poincare Frechet mean (K = 3) of its successor points w_j, j in S_i; candidate set K_i = codes at level 3 inside the current level-2 prefix with free capacity, else all level-3 codes inside the prefix, else the level-2 codes; z* = argmin_{c in K_i} d_P(m_i, c) with d_P(u,v) = arcosh(1 + 2||u-v||^2/((1-||u||^2)(1-||v||^2))) on the unit ball; set SID(i) = (prefix, z*) and update the code's membership. Repair is applied every epoch after the optimizer step, on the assignment only, with the codebooks untouched.
COST: One hash-grouping and sort over 24,556 SIDs per epoch, O(N log N) with N = 24556, plus re-assignment of the colliding tail (order 2k-6k items) against at most 256 candidate codes each, i.e. under 1.5M distances per epoch vectorised in one batched kernel, ~1-2 ms per epoch on GPU, 1.4-2.0 s over 3000 epochs, well under 1% of total wall clock; no extra parameters and no extra forward passes.
HYPOTHESIS: If unreachable duplicates are a real recall cap, then the on-run should show a rise in the number of distinct SIDs, a rise in the share of decoded SIDs whose item has above-median training in-degree, higher prefix-to-successor predictability on training prefixes, and a Stage-3 test_recall@10 gain; one run has to show the assignment shift and the recall gain together.
RISKS: Re-assignment can put an item into a code whose content neighbours are unrelated, so the generator's content prior works against it; the repaired assignment is discontinuous across epochs and may make the codebook usage noisy; if collisions are concentrated in a few huge content clusters the free-code search degenerates to level 2 and the mechanism mostly relabels.
BEHAVIOR SIGNAL: Training in-degree per item plus the successor distribution used for the centroid.
BEHAVIOR COMPUTATION: From training sequences only: in-degree = number of distinct users whose training sequence contains the item; successor sets and counts from adjacent training pairs, deduplicated per (user, item); both built once and frozen.
LEAKAGE BOUNDARY: Both statistics are functions of the training split only and are frozen before Stage 3; the repair reads the epoch's codebooks and the frozen table, never a validation or test sequence, and never a Stage-3 prediction, so no held-out interaction can move an ID.
HYPERBOLIC OPERATOR: Poincare distance on the unit ball, curvature kappa = -1 fixed, applied from a behaviour centroid to candidate codes.
HYPERBOLIC LOCATION: In Stage-2 post-processing, on the quantizer's decision rule for the colliding tail of the assignment.
COUPLING PATH: training pairs -> successor centroid m_i and in-degree -> representative selection -> geodesic nearest-candidate rule -> repaired SID for the ambiguous items. Removing behaviour makes m_i = z_i and the rule an arbitrary content tie-break; removing geometry replaces d_P by the Euclidean distance from an arithmetic centroid.
COUPLING EQUATION: SID(i) = (prefix(i), argmin_{c in K_i} d_P(m_i, c)) for i in G_s \ {r(s)}, with r(s) = argmax_i indeg_train(i) and m_i = FrechetMean({w_j : j in S_i}).
OBSERVABLES: number of distinct full SIDs per epoch; share of the repair set that actually moves; mean in-degree of the emitted items; distribution of decoded SIDs over test-time generation; prefix-to-successor predictability on training prefixes; Stage-3 test_recall@10.
ABLATION BEHAVIOR OFF: the repair still runs but with m_i = z_i (item point instead of successor centroid) and the representative chosen by content distance rather than in-degree; geometry untouched. No arm is trained.
ABLATION GEOMETRY OFF: the repair uses the Euclidean distance between an arithmetic successor mean and the code vectors, with the same grouping and the same in-degree representative rule. No arm is trained.
ABLATION BOTH ON: the full run as specified, one training run, frozen Stage-2 and Stage-3 protocols.
SPEC EQUATIONS: as above plus pseudocode: after each epoch compute SID(i) for all i; group by SID; for each group sort by indeg_train descending; keep the first; for the rest build m_i by three Frechet iterations; collect free level-3 codes in the parent prefix; assign argmin d_P(m_i, c); log group sizes and moves; write the repaired assignment for the next epoch's use.
SPEC INPUTS OUTPUTS: inputs are the epoch's SID assignment, the codebooks, the frozen in-degree and successor tables; outputs are the repaired SID assignment used for the checkpoint and by Stage 3, plus the collision and movement logs.
SAFEGUARDS: never move the representative so the generator's learned emission target is stable; cap the number of repairs per epoch at a measured value (the size of the collision tail at epoch 1) so a degenerate first epoch cannot rewrite the whole vocabulary; skip an item when all candidate codes are occupied by their own representatives; clamp ball norms to 1 - 1e-5 and artanh arguments to 1 - 1e-7; if a repair produces a non-finite distance, leave the original SID unchanged and count it in the log.
END IDEA
