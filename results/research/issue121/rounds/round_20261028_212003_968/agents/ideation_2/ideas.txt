IDEA: BRANCHCURV-SID
TITLE: Behaviour-branching curvature field on the RQ-VAE codebook metric
MOTIVATION: Items differ in how predictable their training successors are. Items in a high-fan-out region need coarse cells with fine boundaries, while items on a narrow chain need sharp cells. One global curvature forces the same resolution everywhere, so prefix tokens smear across fan-out regimes and Stage 3 cannot separate "many possible next items" from "one likely next item".
NOVELTY: The curvature is neither a global constant nor a separate loss. Every codebook vector carries its own negative curvature computed from the measured successor-branching entropy of the training items currently assigned to that code, and that curvature enters the quantizer distance itself. Nothing in the repository ties per-code curvature to measured behaviour.
CHANGE: Replace d(z_i,e_k) in the RQ-VAE assignment with a code-specific hyperbolic distance d_{kappa_k}(u_i,e_k), where kappa_k is a deterministic, scale-relative function of the branching entropy H_k of code k, refreshed by EMA from training-only transitions. The decoder and reconstruction target are otherwise unchanged.
SPECIFICATION: u_i = exp_0^{k0}(z_i), k0 = -1 / median_i ||z_i||^2 (derived from encoder scale, not tuned). For every code k, p_kj = (sum_{i:a_i=k} T_ij + alpha) / (sum_j' (sum_{i:a_i=k} T_ij' + alpha)), alpha = 1, H_k = -sum_j p_kj log p_kj / log M, Hbar = mean_k H_k. kappa_k = k0 * exp(H_k - Hbar) clamped to [0.25*k0, 4*k0] (documented clamp, no sweep). Assignment logits l_ik = -d_{kappa_k}(u_i,e_k)^2 / tau with tau = median_{i,k} d_{kappa_k}(u_i,e_k)^2 computed once at epoch 0 and frozen. q_i = softmax(l_i). Loss = baseline RQ-VAE reconstruction + commitment; only assignment distances and code usage change. At each epoch end recompute hard a_i, accumulate T_ij from the training transition table restricted to items with a_i = k, and update H_k <- 0.9 H_k + 0.1 H_k^new; initialise H_k at global entropy. Freeze kappa_k after epoch 500 (documented warm-up, no tuning).
COST: One pass over the sparse training transition table per epoch: <= 24556 rows, ~O(10) stored successors each, < 0.5 s CPU per epoch, < 25 min over 3000 epochs, done once. Per step: same 1024 x 256 distance count plus one arcosh and one exp per logit, about 1.3x the quantizer cost and < 5% total step time.
HYPOTHESIS: If successor fan-out is heterogeneous and global curvature is a real bottleneck, codes in high-branching regions should acquire flatter effective metrics, per-code successor entropy of the top-1 next token should drop, and Stage 3 test Recall@10 should exceed 0.065 with no ablation arm trained. Observable in the per-code curvature histogram and Stage 3 prefix hit-rate.
RISKS: Entropy feedback can oscillate or collapse items into a few codes; the clamp and post-epoch-500 freeze are the guards. Per-code curvature makes dissimilarity asymmetric, so nearest-code search is no longer a metric nearest-neighbour problem; acceptable because codes are only compared as candidates. If branching entropy is nearly uniform, kappa_k is nearly constant and the mechanism reduces to baseline: safe failure but no gain.
BEHAVIOR SIGNAL: Directed item transitions in training sequences, aggregated into a row-normalised successor distribution per item, from which per-code successor-branching entropy is measured.
BEHAVIOR COMPUTATION: One pass over the training split only: for every adjacent pair (item_t, item_{t+1}) increment T[item_t,item_{t+1}]; keep counts and row-normalise at use time. Each epoch, H_k uses T rows of items whose current hard code is k. No validation or test sequence is read.
LEAKAGE BOUNDARY: T is built once from the training split before Stage 2 starts; validation and test sequences never enter T; hard assignments used for H_k come only from Stage 2 training batches; Stage 3 is trained and evaluated after SIDs are frozen. No validation/test interaction can change a SID.
HYPERBOLIC OPERATOR: Poincare-ball exponential and logarithmic maps plus the Poincare distance with trainable-free negative curvature kappa_k < 0 per code, kappa_k in [0.25*k0, 4*k0], k0 derived from encoder scale.
HYPERBOLIC LOCATION: Inside the RQ-VAE quantizer, in nearest-code distance and soft assignment, during Stage 2 only; it does not act in Stage 3.
COUPLING PATH: Behaviour counts -> per-code branching entropy H_k -> per-code curvature kappa_k -> hyperbolic distance d_{kappa_k}(u_i,e_k) -> assignment q_i -> reconstructed SID -> new hard assignments -> updated H_k. Removing behaviour makes kappa_k constant; removing curvature makes the distance Euclidean; both change the same logits.
COUPLING EQUATION: l_ik = -d_{kappa_k}(u_i,e_k)^2 / tau, with kappa_k = kappa_0 * exp(H_k(T) - Hbar(T)), where H_k(T) is the behaviour term and d_{kappa} is the curved term.
OBSERVABLES: Per-code curvature histogram; per-code successor entropy of the first SID token; code-usage entropy; Stage 3 test Recall@10; prefix hit-rate at each prefix length.
ABLATION BEHAVIOR OFF: Set H_k = Hbar for all k, so kappa_k = kappa_0 and T is unused; everything else identical.
ABLATION GEOMETRY OFF: Replace d_{kappa_k} by Euclidean ||u_i - e_k||, keep the same H_k-driven code statistics; kappa_k is logged but unused.
ABLATION BOTH ON: The full coupled run described above.
SPEC EQUATIONS: z_i = encoder(x_i); u_i = exp_0^{k0}(z_i); T_ij from training transitions; p_kj = (sum_{i:a_i=k} T_ij + 1) / (sum_j (sum_{i:a_i=k} T_ij + 1)); H_k = -sum_j p_kj log p_kj / log M; Hbar = mean_k H_k; kappa_k = clip(k0 * exp(H_k - Hbar), 0.25*k0, 4*k0); d_k(u,e) = (1/sqrt(|k|)) arcosh(1 + 2|k| ||u-e||^2 / ((1-|k||u|^2)(1-|k||e|^2))); l_ik = -d_{kappa_k}(u_i,e_k)^2 / tau; q_i = softmax(l_i); L = L_RQVAE + L_commit; a_i = argmax_k q_ik at epoch end; H_k <- 0.9 H_k + 0.1 H_k^new.
SPEC INPUTS OUTPUTS: Inputs: encoder outputs z_i (batch 1023/1024), codebook E in the Poincare ball, training transition table T, previous H_k. Outputs: soft assignment q_i over 256 codes, hard SIDs, updated H_k, and the usual reconstruction loss.
SAFEGUARDS: Clamp ||u|| and ||e|| to (1-1e-5)/sqrt(|k|); clamp the arcosh argument to >= 1+1e-7; compute logits in float64; detach T and hard assignments when forming H_k; clamp kappa_k as stated; freeze kappa after epoch 500; carry the previous H_k for codes with zero assigned items.
END IDEA

IDEA: SUCC-TAN-RQ
TITLE: Successor-directed tangent base shift for hyperbolic residual quantization
MOTIVATION: In residual quantization the second and third tokens encode whatever the first code failed to capture, in a direction unrelated to where users actually go next. When training transitions are directionally predictable, that predictability is spent on arbitrary residual bits instead of on a prefix a generative recommender can use.
NOVELTY: The residual chain is not reweighted and embeddings are not graph-smoothed. The quantizer's base point is transported along the measured mean successor-displacement tangent before the first code is chosen, and every later residual is taken in the tangent space of the chosen code; curvature controls the transport. This is a curved, behaviour-directed residual, distinct from behaviour-weighted distances or graph-regularised embeddings.
CHANGE: Before level 1, shift the item point along its measured successor direction in the tangent space at the origin: s_i = exp_0^k(log_0^k(u_i) + eta * t_i). Then quantize s_i with a hyperbolic residual quantizer whose level-l base is exp_{e_{c_l}}^k(xi_l) and whose codes are chosen by d_k(base, e_k). The reconstruction target remains the unshifted u_i, but the code chain is chosen to reconstruct s_i.
SPECIFICATION: t_i = (1/|S_i|) sum_{j in S_i} (log_0^k(u_j) - log_0^k(u_i)), S_i the training successors of i (out-degree capped at 32, most frequent). eta = d_code / (median_i ||t_i|| + 1e-8), d_code = median_{k != k'} d_k(e_k,e_k') measured at epoch 0; a typical successor shift then equals one code spacing, so eta is derived, not tuned. b_i^1 = s_i; c_1 = argmin_k d_k(b_i^1,e_k); xi_1 = log_{e_{c_1}}^k(b_i^1) - log_{e_{c_1}}^k(e_{c_1}); b_i^2 = exp_{e_{c_1}}^k(xi_1); c_2 = argmin_k d_k(b_i^2,e_k); and so on for L = 3 levels. u_hat_i = exp_0^k(sum_l log_0^k(e_{c_l})). L = d_k(u_i,u_hat_i)^2 + d_k(s_i,u_hat_i)^2 + commitment. The second term is the behaviour term, the first keeps item fidelity; both share u_hat, so behaviour changes the code chain that produces u_hat.
COST: One extra exp/log per item per level and one successor-mean precomputation pass over training (~24556 items x <=32 successors) done once. Per step: 3 x 1024 x 256 distances with log/exp maps (~2x baseline quantizer arithmetic) plus two reconstruction terms; roughly 1.5x-2x baseline Stage 2 step time, no extra epochs or passes.
HYPOTHESIS: If transitions carry directional information that residuals currently destroy, shifting the base along the successor tangent should make true successor pairs share longer SID prefixes and raise Stage 3 test Recall@10 above 0.065 in the single frozen run. Observable as a rise in mean longest-common-prefix of held-out successor pairs and in Stage 3 recall at prefix lengths 1-3.
RISKS: The successor mean is noisy for tail items and can point uninformatively; the median-based eta keeps the shift at one code spacing but tail items may still be displaced too much. The shifted target can fight the reconstruction term and degrade item fidelity; sharing u_hat limits but does not remove this. Hyperbolic residual chains are numerically fragile near the ball boundary.
BEHAVIOR SIGNAL: Mean successor displacement in tangent space, computed from directed item transitions in the training split.
BEHAVIOR COMPUTATION: For each training item i, collect the multiset of its immediate next items in training sequences, keep the 32 most frequent successors, map each successor through log_0^k, average the differences from log_0^k(u_i), and L2-normalise only if ||t_i|| < 1e-8; all from training split.
LEAKAGE BOUNDARY: The successor table and eta scale are computed once from training sequences before Stage 2 and frozen; no validation or test sequence contributes a transition, and no Stage 3 feedback changes them.
HYPERBOLIC OPERATOR: Poincare-ball exp/log maps and distance with fixed negative curvature k = k0 = -1/median_i||z_i||^2, used for the base shift and every residual step.
HYPERBOLIC LOCATION: Inside the RQ-VAE residual quantizer during Stage 2: it defines the level-1 base point and the tangent frame of every later level.
COUPLING PATH: Training transitions -> successor tangent t_i -> shifted base s_i -> level-1 nearest code and residual -> levels 2-3 codes -> reconstructed u_hat -> SID and loss. Removing behaviour sets eta = 0 and s_i = u_i; removing geometry replaces exp/log and d_k by Euclidean addition and distance; both alter the same code chain.
COUPLING EQUATION: s_i = exp_0^k(log_0^k(u_i) + eta * t_i) and c_l = argmin_k d_k(b_i^l, e_k), where t_i (behaviour) is transported by the curved exp map and scored by the curved distance.
OBSERVABLES: Mean successor LCP of SIDs; SID prefix entropy per level; reconstruction distance under the unshifted target; Stage 3 test Recall@10.
ABLATION BEHAVIOR OFF: eta = 0, so s_i = u_i and the chain is a plain hyperbolic residual quantizer; the transition table is still built but unused.
ABLATION GEOMETRY OFF: Replace exp_0, log_0, exp_{e}, log_{e} and d_k by Euclidean counterparts (vector addition and L2 distance), keep eta and t_i identical.
ABLATION BOTH ON: The full coupled run with the successor shift and the hyperbolic residual chain.
SPEC EQUATIONS: u_i = exp_0^{k0}(z_i); t_i = mean_{j in S_i}(log_0^{k0}(u_j) - log_0^{k0}(u_i)); d_code = median_{k != k'} d_{k0}(e_k,e_k'); eta = d_code / (median_i ||t_i|| + 1e-8); s_i = exp_0^{k0}(log_0^{k0}(u_i) + eta t_i); b_i^1 = s_i; for l = 1..L: c_l = argmin_k d_{k0}(b_i^l,e_k); xi_l = log_{e_{c_l}}^{k0}(b_i^l) - log_{e_{c_l}}^{k0}(e_{c_l}); b_i^{l+1} = exp_{e_{c_l}}^{k0}(xi_l); u_hat_i = exp_0^{k0}(sum_l log_0^{k0}(e_{c_l})); L = d_{k0}(u_i,u_hat_i)^2 + d_{k0}(s_i,u_hat_i)^2 + ||sg[u_i]-u_hat_i||^2.
SPEC INPUTS OUTPUTS: Inputs: z_i batch, codebook E, successor tangent table t_i, eta, L = 3. Outputs: code indices c_1..c_L (the SID), reconstructed u_hat_i, loss.
SAFEGUARDS: Clamp all ball norms to (1-1e-5)/sqrt(|k0|); clamp arcosh argument to >= 1+1e-7; log-domain softmax over codes; cap successor out-degree at 32 and drop zero-count entries; if ||t_i|| = 0 use s_i = u_i; compute eta once and freeze it; float64 for exp/log in the first 100 steps.
END IDEA

IDEA: GEOPFX-SID
TITLE: Transition-pair geodesic alignment of hyperbolic prefix anchors
MOTIVATION: A generative recommender emits SID prefixes, so what matters is not only that related items are close but that the shared prefix lies "between" them along a path. Euclidean prefix codes have no betweenness: the shared prefix of two successor items can sit far off the line joining them, making the prefix a poor intermediate state for beam search.
NOVELTY: Behaviour does not weight the distance and is not a second loss. Each observed training transition selects a geodesic segment between two item SIDs, and the corresponding prefix anchor is pulled onto that segment in the Poincare ball. Curvature and behaviour meet inside one geometric residual, unlike a transition loss plus an unrelated hyperbolic regulariser.
CHANGE: Add one term per sampled training transition (i -> j): the squared hyperbolic distance from shared prefix anchor g_ij to the geodesic segment gamma(u_i,u_j), normalised by the pair's squared hyperbolic distance. The anchor is the exp-map of the sum of the shared prefix code logs.
SPECIFICATION: LCP_ij = number of leading SID tokens equal for i and j. g_ij = exp_0^k(sum_{m <= LCP_ij} log_0^k(e_{c_m(i)})); if LCP = 0 the pair is skipped (documented default: no shared prefix to align). gamma(u_i,u_j)(s) = exp_{u_i}^k(s * Pi_{u_i}(log_{u_i}^k(u_j))), s in [0,1]. delta(g,gamma) = min_s d_k(g,gamma(s)) via 12 golden-section steps on [0,1]. L_geo = (1/|E_b|) sum_{(i,j) in E_b} w_ij * delta^2 / (d_k(u_i,u_j)^2 + eps), w_ij = transition count, eps = 1e-6, term weight fixed at 1 (documented default). E_b is a uniform sample of at most 2048 training transitions per step. Total loss = baseline RQ-VAE loss + L_geo. No other change to the quantizer.
COST: 2048 pairs x 12 golden-section evaluations x one Poincare distance each per step, about 24.5k extra distances versus 1024 x 256 = 262k quantizer distances, so ~+10% quantizer work and well under +10% total step time. Transition list precomputed once; sampling O(2048) per step; 72,000 steps total.
HYPOTHESIS: If prefix tokens are intermediate beam states in Stage 3, moving the shared anchor onto the geometric path between successor items should make true successors share prefixes more often and make those prefixes more predictive. Observable as an increase in area under the prefix hit-rate curve and Stage 3 test Recall@10 above 0.065 in the single run.
RISKS: At the start no two items share a prefix, so LCP = 0 for almost all pairs and the term is inert until codes agree; warm-up and a minimum-LCP filter help but may make the term arrive late. The geodesic minimum can be flat when g is already close to the segment, giving weak gradients. Optimising this term can distort item-level reconstruction if weight 1 is too strong relative to the baseline loss.
BEHAVIOR SIGNAL: Directed training transitions (i -> j) with their counts.
BEHAVIOR COMPUTATION: One pass over the training split counting adjacent pairs (item_t, item_{t+1}); store as a sparse list of (i, j, count). At each step sample up to 2048 entries uniformly from this list.
LEAKAGE BOUNDARY: The transition list is built once from the training split before Stage 2 and frozen. Validation and test sequences are never read, and no validation/test metric selects the term weight, LCP threshold or golden-section count; those are documented defaults fixed before training.
HYPERBOLIC OPERATOR: Poincare exp/log maps, geodesic segment, and Poincare distance with fixed negative curvature k = k0 = -1/median_i||z_i||^2.
HYPERBOLIC LOCATION: In the Stage 2 training loss on the codebook and encoder, applied to prefix anchors built from codebook vectors; it shapes the SID prefix geometry that Stage 3 consumes.
COUPLING PATH: Training transitions define edge pairs -> shared prefix tokens define anchor g_ij -> hyperbolic geodesic between the two item SIDs and curved point-to-segment distance -> gradient on the codebook -> next epoch's SIDs and prefixes. Removing behaviour removes the edges; removing geometry replaces the geodesic segment and Poincare distance by a Euclidean segment and L2 distance; both change the same scalar residual.
COUPLING EQUATION: L_geo = (1/|E_b|) sum_{(i,j)} w_ij * dist_{k0}( exp_0^{k0}(sum_{m<=LCP_ij} log_0^{k0}(e_{c_m(i)})), gamma_{k0}(u_i,u_j) )^2 / d_{k0}(u_i,u_j)^2, where w_ij and LCP_ij are the behaviour terms and gamma, dist and d are the curved terms.
OBSERVABLES: Mean LCP of true successor pairs; prefix hit-rate curve at lengths 1-3; codebook norm distribution; Stage 3 test Recall@10.
ABLATION BEHAVIOR OFF: Remove L_geo (equivalently empty edge set / weight 0); all other losses identical.
ABLATION GEOMETRY OFF: Keep the same sampled transition pairs and prefix anchors, but compute the anchor, segment and residual with Euclidean operations: line segment between u_i and u_j, Euclidean point-to-segment distance, no exp/log.
ABLATION BOTH ON: The full coupled run with training transitions and hyperbolic geodesic alignment.
SPEC EQUATIONS: c(i) = (c_1(i),...,c_L(i)); LCP_ij = max m such that c_{1:m}(i) = c_{1:m}(j); g_ij = exp_0^k0(sum_{m<=LCP_ij} log_0^k0(e_{c_m(i)})); v = log_{u_i}^k0(u_j); gamma(s) = exp_{u_i}^k0(s * v); delta_ij = min_{s in [0,1]} d_k0(g_ij, gamma(s)) via 12 golden-section iterations; L = L_RQVAE + (1/|E_b|) sum_{(i,j) in E_b, LCP_ij >= 1} w_ij * delta_ij^2 / (d_k0(u_i,u_j)^2 + 1e-6).
SPEC INPUTS OUTPUTS: Inputs: current SIDs for the batch, codebook E in the ball, sampled transition list with counts, k0. Outputs: scalar L_geo and gradients w.r.t. the codebook (and encoder through code selection, using the straight-through assignment already in the RQ-VAE).
SAFEGUARDS: Skip pairs with LCP = 0 and pairs whose items occupy the same batch position; clamp ball norms to (1-1e-5)/sqrt(|k0|); clamp arcosh argument to >= 1+1e-7; float64 for golden-section distance; detach sampled edge indices; cap at 2048 pairs per step; if all pairs are skipped return zero; warm up the term from epoch 1 (documented) rather than thresholding by a tuned LCP value.
END IDEA
