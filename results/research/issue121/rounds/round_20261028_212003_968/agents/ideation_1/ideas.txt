IDEA: behaviour_anchored_geodesic_charts
TITLE: RQ-VAE residual quantization performed in per-item Poincare charts whose origin is the hyperbolic Frechet mean of the item's training-only successor neighbourhood
MOTIVATION: Content-only SIDs are assigned in one global flat coordinate system, so two items that users actually move between can receive unrelated code prefixes, and the residual chain is a straight Euclidean line that has no reason to follow a behavioural neighbourhood. A generative recommender then wastes prefix capacity on content similarity that does not predict the next item.
NOVELTY: The behaviour signal is not a loss weight, a graph regulariser, a Sinkhorn marginal or a hierarchy constraint. It selects the BASE POINT (gauge) of the curved coordinate system in which every residual is measured and every codeword is decoded, and the residual chain itself advances by geodesic exp maps. The same code tuple therefore means "this geodesic displacement from my own behavioural anchor", which is a different coupling position from behaviour-weighted assignment, curved hierarchy and transition-residual losses: here behaviour enters through log_a / exp_a, i.e. inside the geometric primitive that produces the code.
CHANGE: Replace the Euclidean residual quantizer of the RQ-VAE by a chart-relative geodesic residual quantizer. Each item's target point p_i is written as log_{a_i}(p_i) at a behaviour-derived anchor a_i, each quantized level moves the reconstruction along a geodesic exp_{p-hat}(q_l), and the next residual is taken at the new point; anchors are refreshed every epoch from a stop-gradient encoder snapshot and the training transition graph.
SPECIFICATION: Poincare ball with fixed curvature c = 1 (radius 1). Encoder z_i in R^d, scale s = median over training items of ||z_i|| measured at Stage-2 epoch 0 and frozen, p_i = exp_0(s * tanh(z_i / s)). Training-only directed successor counts c_ij from Stage-2 sequences give top-K (K = 8) neighbours and weights w_ij proportional to c_ij. Anchor a_i = two-step Karcher mean of {p_j : j in N(i)} under d_Poincare, detached, EMA-smoothed, clamped to radius 0.5 s; a_i = 0 if N(i) is empty. Quantization with L = 3 levels and codebooks C_l of 256 vectors in the tangent frame: r_1 = log_{a_i}(p_i); q_l = argmin_{c in C_l} ||r_l - c||^2; p-hat_0 = a_i; p-hat_l = exp_{p-hat_{l-1}}(q_l); r_{l+1} = log_{p-hat_l}(p_i); SID(i) = (k_1, k_2, k_3). Loss = d_Poincare(p-hat_L, p_i)^2 / s^2 + sum_l ||sg(r_l) - q_l||^2 + 0.25 * sum_l ||r_l - sg(q_l)||^2, with the baseline content decoder fed log_0(p-hat_L). Cost: at the frozen scale (24556 items, 24 steps/epoch, 1023 items/step) each step performs about 1023 * 3 * 3 = 9.2k exp/log calls, roughly 2 MFLOP, plus an anchor refresh of 24556 * 8 * 2 * 2 = 0.8M map calls once per epoch (about 0.1-0.2 s), so total wall clock is at most about 1.05x baseline and memory grows by 24556 * d floats for anchors plus the cached sparse successor graph (tens of MB).
COST: <=1.05x baseline wall clock and <=1.1x peak memory; per step at the frozen scale: ~9.2k Poincare exp/log evaluations (~2 MFLOP, vectorised over 1023 items per step), ~0.05 s/step amortised anchor cost (0.1-0.2 s per epoch for all 24556 anchors over 3000 epochs). No extra forward or backward pass through the encoder.
HYPOTHESIS: If behavioural adjacency is better captured by "equal geodesic displacement from a shared anchor" than by "equal absolute position", transition-neighbour items will share first-level codes and longer prefixes more often than in the behaviour-off and geometry-off configurations, the generative model will emit valid prefixes longer, and Stage-3 test_recall@10 will exceed 0.065 with the diagnostics moving in the same direction. Observed by: (i) first-level code agreement rate over training transition pairs, (ii) mean shared prefix length over the same pairs, (iii) code-tuple Jaccard against the both-off reference, (iv) Stage-3 test_recall@10.
RISKS: (1) The encoder may collapse all p_i near the origin, making anchors and the origin indistinguishable and degenerating the mechanism into the behaviour-off arm; the EMA plus the 0.5 s clamp does not prevent collapse, only mitigates drift. (2) For long-tail items the successor set is tiny or empty, so their anchors are noisy or zero and their codes behave like the behaviour-off arm. (3) Codebooks shared across heterogeneous tangent frames may mix incomparable directions and hurt more than the anchoring helps. (4) With a geodesic residual the first level already absorbs most of the displacement, so levels 2 and 3 can die, which shortens effective prefixes and can lower recall. (5) A per-epoch anchor refresh creates a moving quantization target that can oscillate.
BEHAVIOR SIGNAL: Popularity-debiased directed item transitions within the Stage-2 training sequences (successor distributions), reduced to a top-8 weighted successor neighbourhood per item with weights proportional to raw directed counts.
BEHAVIOR COMPUTATION: One pass over the Stage-2 TRAIN split sequences only. For each ordered pair (i, j) appearing with j inside a forward window of 5 positions after i in the same sequence, increment c_ij; drop pairs where either item has fewer than 5 occurrences in train; keep the top 8 successors per item by c_ij and set w_ij = c_ij / sum_j' c_ij'. Cache as CSR arrays (row pointer, column index, weight). Refit never; recompute anchors from this fixed graph and the current encoder snapshot at each epoch boundary.
LEAKAGE BOUNDARY: SID construction reads only Stage-2 training sequences, the training item table and training graph statistics; valid/test interactions are never touched, no validation statistic enters any constant, and the anchor/neighbour cache is built before any Stage-2 step and never updated from validation or test. The only measured constant, s = median ||z_i||, is a training-item median. The Stage-3 protocol is untouched.
HYPERBOLIC OPERATOR: Poincare ball of fixed negative curvature c = 1 with Mobius addition, exponential map exp_x(v) = x (+) (tanh(||v||/2) v / ||v||), logarithmic map log_x(y) = 2 artanh(||(-x)(+)y||) ((-x)(+)y) / ||(-x)(+)y||, and d(x,y) = 2 artanh(||(-x)(+)y||); both maps are used at the anchor, at every intermediate reconstruction, and in the reconstruction loss.
HYPERBOLIC LOCATION: Inside the quantizer of the RQ-VAE, at every level: the target is mapped with log at the item's anchor, the codebook step is taken with exp at the running reconstruction, the next residual is recomputed with log at the new point, and the reconstruction loss is a squared Poincare distance. It also acts in the per-epoch anchor construction (Karcher mean under d_Poincare).
COUPLING PATH: successor graph -> top-8 weighted neighbour set of item i -> Frechet/Karcher mean a_i in the ball -> log_{a_i}(p_i) -> codebook argmin at level 1 -> exp_{a_i}(q_1) -> log at the new point -> level 2 and 3 codes. The behaviour signal is the only source of the base point and the base point is the only thing that makes the curved log/exp non-trivial; delete either and the numeric code tuple changes at the first argument of the argmin. There is no second loss, no auxiliary head and no post-hoc correction.
COUPLING EQUATION: r_1(i) = log_{a_i(w_ij, c_ij)}(p_i), a_i = KarcherMean_{d_Poincare}({p_j : w_ij > 0}); k_1 = argmin_k ||log_{a_i}(p_i) - c_{1,k}||^2; k_{l+1} = argmin_k ||log_{exp_{p-hat_l}(c_{l,k})}(p_i) - c_{l+1,k}||^2.
OBSERVABLES: (i) first-level code agreement rate over training transition pairs, expected to rise; (ii) mean shared prefix length over the same pairs, expected to rise; (iii) anchor displacement ||log_0(a_i)|| distribution, expected to be non-degenerate (not piled at 0); (iv) code-usage entropy per level, expected not to collapse; (v) code-tuple Jaccard versus the both-off configuration, expected to be far from 1 (the mechanism really reassigns SIDs); (vi) Stage-3 test_recall@10 as the sole judgement, target > 0.065.
ABLATION BEHAVIOR OFF: config flag behaviour_anchor=False sets a_i = 0 for all items (single chart at the ball origin) while keeping exp/log residuals, curvature c = 1 and the reconstruction loss unchanged; the switch exists and is correct, but this arm is not trained in this round.
ABLATION GEOMETRY OFF: config flag curved=False keeps the behaviour anchors but replaces them by the weighted Euclidean mean of the neighbour embeddings, replaces log/exp by vector subtraction/addition, and replaces d_Poincare by squared Euclidean distance; the successor graph, K, weights and codebook sizes are identical; switch exists, arm not trained.
ABLATION BOTH ON: the full mechanism exactly as specified: behaviour-derived Karcher anchors and geodesic log/exp residuals simultaneously; this is the single trained candidate of the round.
SPEC EQUATIONS: inputs: item content embeddings x_i (d = 64), Stage-2 train successor CSR graph (K = 8), curvature c = 1, L = 3, |C_l| = 256, beta = 0.25, anchor EMA 0.8, clamp radius 0.5 s, radial clip R = 4 s, eps = 1e-8.
  1. z_i = Encoder(x_i); s = median_i ||z_i|| at epoch 0 (frozen); p_i = exp_0(s * tanh(z_i / s)).
  2. every epoch start, with p_i detached:
     m_i = p_{argmax_j w_ij}; repeat 2 times: m_i <- exp_{m_i}(sum_j w_ij * log_{m_i}(p_j) / sum_j w_ij);
     u_i <- 0.8 * u_i_prev + 0.2 * log_0(m_i); if ||u_i|| > 0.5 s: u_i <- u_i * 0.5 s / ||u_i||; a_i = exp_0(u_i); a_i = 0 if N(i) empty.
  3. forward for item i: r = log_{a_i}(p_i); if ||r|| > 4 s: r <- r * 4 s / ||r||; p-hat = a_i; codes = [];
     for l = 1..3: k_l = argmin_k ||r - c_{l,k}||^2; codes.append(k_l); p-hat = exp_{p-hat}(c_{l,k_l}); r = log_{p-hat}(p_i).
  4. loss = d(p-hat, p_i)^2 / s^2 + sum_l ||sg(r_l) - c_{l,k_l}||^2 + 0.25 * sum_l ||r_l - sg(c_{l,k_l})||^2 (+ baseline content reconstruction from log_0(p-hat)).
  5. SID(i) = (k_1, k_2, k_3).
SPEC INPUTS OUTPUTS: takes x_i, the frozen successor CSR graph, the anchor cache and tangent-frame codebooks; returns the code tuple (k_1..k_3) per item, the reconstruction point p-hat, per-level tangent residuals r_l, and the scalar loss. Anchors are a non-differentiable cached buffer; gradients flow to the encoder and codebooks only.
SAFEGUARDS: artanh argument clamped to 1 - 1e-7 and all norms floored at 1e-8; points clamped to radius 1 - 1e-5 before every Mobius operation; r_1 radially clipped to 4 s (s is measured, not tuned); anchors clipped to 0.5 s and EMA-smoothed against per-epoch drift; empty or single-neighbour sets fall back to a_i = 0 or a_i = p_j; Karcher iteration guarded against divergence with a step-norm clip of 1.0 and a finite-value check that falls back to the previous anchor; dead codebooks follow the baseline re-initialisation policy only, with no extra hyperparameter; a NaN/Inf in any map aborts that step's quantizer update and keeps the previous codebooks.
END IDEA
