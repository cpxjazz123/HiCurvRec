IDEA: transition_busemann_gate
TITLE: Successor-direction Busemann gating of curved residual assignments
MOTIVATION: Items with the same content embedding can have different next-item roles; ordinary reconstruction quantization has no reason to allocate a code that preserves which successor direction a user's training history tends to follow.
NOVELTY: This does not set a branch-dependent radius, interpolate an item toward a transition-neighborhood Frechet prototype, or append a behavior suffix. It makes the ranking of actual residual codewords depend on a train-only directed successor direction through a hyperbolic Busemann potential, a directional rather than radial/geodesic-target coupling.
CHANGE: At each item, form a stable tangent-space successor direction from its observed training-only outgoing transitions, map that direction to a Poincare-ball boundary anchor, then add the direction's Busemann potential to the curved distance used for first-stage code assignment. The chosen codeword and straight-through quantized latent therefore change as a function of both the transition signal and curvature.
SPECIFICATION: Let frozen item embedding be e_i and training sequences define counts n_ij of adjacent i->j events. Compute q_ij=(n_ij+alpha*pi_j)/(sum_l n_il+alpha), where pi is training-only item frequency normalized; cache h_i=sum_j q_ij*(e_j-e_i), normalized to unit length with norm floor, and confidence a_i=min(1, log(1+sum_j n_ij)/log(1+n95)), where n95 is the 95th percentile training outgoing count. For encoder output z_i and first-stage codeword c_k, map x_i=exp^(-c)_0(z_i), y_k=exp^(-c)_0(c_k), project to radius <=0.9/sqrt(c). Set u_i=normalize(h_i), and boundary anchor b_i=(1-epsilon)u_i/sqrt(c). Score S_ik=d_c(x_i,y_k)^2 + lambda*a_i*B_c(y_k;b_i), assign argmin_k S_ik. Here B_c(y;b)=log((1-c||b||^2)||y-b||^2 / ((1-c||y||^2)||b-y||^2)) is numerically singular as written at b=y; implement the equivalent stable Poisson-kernel potential B_c(y;u)=log((1-c||y||^2)/(c||y-u/sqrt(c)||^2+epsilon)) with unit direction u and boundary anchor, clipping its input to [epsilon,1/epsilon], and subtract its codebook mean so the additive offset is immaterial. Use fixed curvature -c, c=0.5; lambda is selected once on training-only assignment/reconstruction diagnostics and frozen before Stage3. (Sign convention: minimize distance minus lambda*a_i*B, so codes in the successor-facing direction are favored.) Residual stages after stage 0 remain baseline Euclidean RQ to limit disruption.
COST: One preprocessing pass over training transitions O(T) plus O(N*K*D) cached direction-score work per epoch step for the first-stage quantizer; asymptotic assignment cost is unchanged and the Busemann term adds about one scalar/vector operation per item-codeword pair alongside Poincare distance. At frozen scale, 24,556 training items x 3,000 epochs = 73,668,000 item presentations total (24 batches/steps per epoch, about 1,023 items per step). Correction: the frozen total is 24*3000=72,000 optimizer steps; for a full epoch pass of 24 batches each, 73,668,000 item presentations total across all epochs. Added Busemann evaluation is one O(D) term per compared codeword, i.e. approximately 73,668,000*K*D scalar-coordinate contributions across the full run; cached h_i makes no sequence traversal occur in training. Expect modest constant-factor overhead over the first-stage hyperbolic distance, no extra model parameters.
HYPOTHESIS: For items with sufficient outgoing evidence, successor direction is predictive of useful next-item prefixes and the hyperbolic boundary potential separates multiple continuation modes without sacrificing content reconstruction. Keep only if coupled run improves Stage3 test Recall@10 versus both controlled ablations, targeting >0.065; confirm it changes first-stage code assignments and improves train-prefix successor predictability without relying on validation/test interactions.
RISKS: Sparse or noisy outgoing transitions make h_i unreliable; popularity smoothing may erase meaningful personalization; the shared direction averages genuinely multimodal successors; Busemann scores near the boundary can dominate reconstruction; downstream Stage3 may not exploit directional code organization. Confidence shrinkage, bounded scores, and a small lambda are essential.
BEHAVIOR SIGNAL: Directed item-to-next-item transition distribution for each source item, pooled over training user sequences.
BEHAVIOR COMPUTATION: From training split only, count adjacent pairs n_ij; use smoothed transition probabilities q_ij=(n_ij+alpha*pi_j)/(n_i+alpha) and expected frozen embedding displacement h_i=sum_j q_ij(e_j-e_i). Confidence a_i shrinks low-count sources; unseen sources use h_i=0 and a_i=0.
LEAKAGE BOUNDARY: Construct n_ij, pi, q, h_i and confidence using only the training sequence file; freeze and hash this cache before generating SIDs. Never read validation/test events or their ordering during preprocessing, fitting, tuning, or SID assignment; select lambda by training-only diagnostics, and reserve validation/test solely for the prescribed downstream evaluation.
HYPERBOLIC OPERATOR: Poincare exponential map and squared geodesic distance at fixed negative curvature -0.5, combined with a boundary Busemann/Poisson-kernel potential on the same Poincare ball.
HYPERBOLIC LOCATION: First residual quantizer's hard codeword assignment score; subsequent residual quantizers retain baseline behavior.
COUPLING PATH: Training transition counts create a source-item direction and confidence; those values parameterize a hyperbolic boundary potential evaluated for each candidate codeword, which is added to its Poincare distance score and directly selects the emitted first SID token. Turning off transitions nulls the potential; flattening geometry replaces the Poincare distance and boundary potential with Euclidean distance and matched linear directional score.
COUPLING EQUATION: k_i=argmin_k { d_c(x_i,y_k)^2 - lambda*a_i*B_c(y_k;u_i) }, with u_i=normalize(sum_j q_ij(e_j-e_i)), x_i=exp^(-c)_0(z_i), y_k=exp^(-c)_0(c_k), c=0.5, and B_c the bounded Poincare boundary Busemann potential.
OBSERVABLES: First-stage SID assignments change preferentially for high-confidence source items; nearest-code successor predictability on held-out training transitions and Stage3 test Recall@10 should rise. Log assignment flip fraction by confidence bin, transition-prefix hit rate, reconstruction loss, gradient norms, and test Recall@10.
ABLATION BEHAVIOR OFF: Set a_i=0 for every item, preserving the same Poincare distance, codebook, optimizer and schedule; this is curved distance-only quantization.
ABLATION GEOMETRY OFF: Keep the identical cached q_ij, h_i and a_i, but use Euclidean latent/codeword distances and a bounded linear directional score -lambda*a_i*dot(y_k,u_i), with scale matched on training batches; no Poincare map or boundary potential is used.
ABLATION BOTH ON: Use cached training-only transition direction and confidence in the stated fixed-curvature Poincare distance plus boundary Busemann assignment at residual stage zero; all other settings match baseline.
SPEC EQUATIONS: For each training sequence s=(i_1,...,i_m), n_ij += count(t: i_t=i and i_{t+1}=j); pi_j=(freq_j+alpha)/(sum_l freq_l+alpha*V). q_ij=(n_ij+alpha*pi_j)/(n_i+alpha). h_i=sum_j q_ij(e_j-e_i), u_i=h_i/max(||h_i||,1e-8), a_i=min(1,log(1+n_i)/log(1+n95)). For each candidate code y, x=Proj(exp_0^{-c}(z)), y=Proj(exp_0^{-c}(c_k)), t= c||y-u/sqrt(c)||^2+epsilon, B=clip(log((1-c||y||^2+epsilon)/t),-Bmax,Bmax); S=d_c(x,y)^2-lambda*a_i*(B-mean_k B); k=argmin S. Apply normal straight-through quantization update from chosen y; use standard baseline residual update thereafter.
SPEC INPUTS OUTPUTS: Inputs are training-only user-ordered item sequences, frozen item embeddings e_i, encoder latent z_i, first-stage codebook {c_k}, fixed c and alpha/lambda. Outputs are frozen per-item (u_i,a_i), first-stage assignment indices, quantized vectors and final RQ-VAE SIDs.
SAFEGUARDS: Use float32 geometry even under mixed precision; clamp Poincare norms to (1-epsilon)/sqrt(c), epsilon=1e-6; normalize directions with a 1e-8 floor and zero out directions below that floor; clip Busemann potential to [-10,10], use log1p counts, cap alpha and confidence inputs, and use fallback a_i=0 for no transition evidence. Verify finite distances/gradients and nonzero assignment changes in smoke tests. Match Euclidean control score scale using training-only statistics and keep all preprocessing deterministic.
END IDEA
