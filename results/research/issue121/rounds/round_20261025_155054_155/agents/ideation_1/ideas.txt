IDEA: transition_geodesic_residual
TITLE: Transition-directed geodesic residual quantization
MOTIVATION: Ordinary residual quantization optimizes item reconstruction independently, so a code chosen for an item may not preserve which items users actually move to next. Make each item's quantization residual account for its observed outgoing next-item neighborhood, while representing the hierarchy of frequent and increasingly specific transitions in a negatively curved latent space.
NOVELTY: The repository's RQ-VAE uses Euclidean residual VQ and has a bootstrap-consensus assignment regularizer; this instead changes the residual itself using directed training transitions, and quantizes that behavior-conditioned residual by Poincare geodesic distance. It is not a separate behavior loss on top of unchanged assignments.
CHANGE: Precompute a smoothed outgoing-transition target vector per training item. At each RQ level, map the current residual and candidate code vectors into a fixed-curvature Poincare ball, shift the residual along the log-map direction toward its transition target, and select the code with minimum geodesic distance to that shifted point; subtract the selected code in the tangent space for the next residual.
SPECIFICATION: Let E_i be the frozen item embedding and D_train the training interaction sequences only. Count directed adjacent pairs C_ij in each user's time-ordered training sequence; define p_i(j)=(C_ij+alpha*pi(j))/(sum_k C_ik+alpha), where pi is the normalized training-only target-item frequency. Form t_i=normalize(sum_j p_i(j) A E_j), where A is a learned linear projection shared with the encoder. For item i and level l, let r_i^0=z_i and c_lk be Euclidean code vectors; use exp_0^c to map vectors to ball B_c and log_0^c to return to tangent space. Set u_i^l=log_0^c(exp_0^c(r_i^l)); v_i=log_0^c(exp_0^c(t_i)); h_i^l=u_i^l+lambda_l v_i, y_i^l=exp_0^c(h_i^l), and k*=argmin_k d_c(y_i^l,exp_0^c(c_lk)); set q_i^l=c_lk* and r_i^(l+1)=r_i^l-q_i^l. Train reconstruction plus ordinary VQ commitment/codebook losses, with the assignment and residual recurrence above defining the coupled path. Set lambda_l lower at fine levels (e.g. lambda_l=lambda_0*rho^l, 0<rho<1).
COST: Precompute transition counts/targets once in O(M+T_train) sparse operations and memory proportional to observed unique transitions, for M=24,556 training items and T_train training-only events. Per RQ-VAE step (one minibatch of B items, d=code dimension, K_l codes at each level L), added target lookup is O(Bd) and stable Poincare distance/map and assignment work is O(B*d*sum_l K_l), same asymptotic order as baseline code assignment but with a larger constant; no graph traversal or full-catalog pass per step. At the frozen scale of 24 steps/epoch × 3,000 epochs = 72,000 optimizer steps, run the extra O(B*d*sum_l K_l) computation each step; transition preprocessing is amortized once. Report measured wall-clock overhead against the same batch and hardware.
HYPOTHESIS: Directed next-item neighborhoods have a hierarchy (broad destinations plus specific branches) that the negative-curvature geometry can represent with less distortion than flat Euclidean residual codes. Worth keeping only if the both-on run improves Stage3 test Recall@10, targeting >0.065, over both controlled ablations; also inspect whether assignments of items with similar outgoing distributions become closer at coarse levels without collapsing distinct destinations.
RISKS: Sparse or low-count histories yield noisy targets; popularity smoothing may overemphasize head items. A single expected-neighbor vector can blur multimodal branches. Curved-distance scaling and lambda can swamp reconstruction, while tangent residual subtraction is an approximation to fully intrinsic residual quantization. Stage3 may not benefit even if the transition structure is represented better.
BEHAVIOR SIGNAL: Directed sequential co-consumption / next-item transitions: a user's immediately consecutive training items provide an ordered source→destination signal.
BEHAVIOR COMPUTATION: From training split only, sort each user's training interactions by timestamp (stable tie-break by event row ID), count each adjacent item pair C_ij, and normalize outgoing counts with alpha-smoothed training-only destination popularity pi(j). Construct each t_i as the weighted mean of projected frozen destination embeddings. Drop self-pairs; items with no outgoing training edge use the smoothed pi-weighted mean. Cache sparse counts and t_i; do not use validation or test sequences.
LEAKAGE BOUNDARY: Build C, pi, and t exclusively from the training interaction file and training item IDs; freeze/cache them before fitting the tokenizer. Do not read validation/test interactions or their timestamps, targets, or derived graph statistics. Validation/test are used only by the established downstream evaluation after SID export.
HYPERBOLIC OPERATOR: Poincare-ball exponential/logarithmic maps at the origin and geodesic distance with fixed negative curvature -c, c>0. Use d_c(x,y)=(2/sqrt(c))*atanh(sqrt(c)*||(-x)⊕_c y||), with Mobius addition ⊕_c, evaluated only inside the open ball.
HYPERBOLIC LOCATION: In each residual quantizer level's assignment calculation, after behavior-conditioned tangent shift and before code selection; tangent residual is carried to the next level. Thus curvature affects actual SID assignments and subsequent residuals, not only an auxiliary penalty.
COUPLING PATH: Training-only transition counts produce destination target t_i; t_i is log-mapped and shifts the current residual before exp-mapping; the resulting point is compared to codewords using Poincare geodesic distance, selecting the code and changing the next residual/SID. Removing behavior removes the shift; removing curvature changes maps and distance to their Euclidean counterparts.
COUPLING EQUATION: k_i^l=argmin_k d_{-c}( exp_0^{-c}( log_0^{-c}(r_i^l)+lambda_l*log_0^{-c}(t_i) ), exp_0^{-c}(c_lk) ); r_i^(l+1)=r_i^l-c_lk_i^l, where t_i is computed from training-only directed behavior and d_{-c}, exp_0^{-c}, log_0^{-c} are the curved operators at curvature -c.
OBSERVABLES: Compare per-item level assignments and code usage, outgoing-transition predictability from coarse SID prefixes, the gradient/update change in encoder and codebooks, and ultimately Stage3 test Recall@10. The decision metric is Stage3 test Recall@10 versus the three named conditions, with >0.065 as the target; assignment/prefix metrics are diagnostics, not admission criteria.
ABLATION BEHAVIOR OFF: Set lambda_l=0 for all levels while retaining the same Poincare maps, geodesic code assignment, initialization, and training budget; this isolates the contribution of training transitions.
ABLATION GEOMETRY OFF: Replace exp/log maps and d_{-c} assignment with identity maps and squared Euclidean distance, retaining the same t_i, lambda schedule, residual recurrence, optimizer, and budget; this isolates curvature.
ABLATION BOTH ON: Use training-only t_i, nonzero decaying lambda_l, curvature -c Poincare maps and geodesic assignments at every level as specified; evaluate final-epoch exported SIDs in Stage3.
SPEC EQUATIONS: For curvature c>0, exp_0^{-c}(u)=tanh(sqrt(c)||u||)*u/(sqrt(c)||u||), with zero limit at ||u||=0; log_0^{-c}(x)=atanh(sqrt(c)||x||)*x/(sqrt(c)||x||). Project each mapped point/code to norm <= (1-eps)/sqrt(c). For l=0,...,L-1: u=log(r_l); v=log(t_i); y=exp(u+lambda_0*rho^l*v); k=argmin_k d_{-c}(y,exp(c_lk)); q_l=c_lk; r_(l+1)=r_l-q_l. Use straight-through assignment for gradients and the existing codebook/commitment objective. Use stable atanh clamp and norm floors; optionally learn c only with positive parameterization and clamp it to a configured safe interval, but primary comparison fixes c (e.g. c=1).
SPEC INPUTS OUTPUTS: Inputs are current item latent z_i, its training-only target t_i, level-l residual r_i^l, codebook {c_lk}, fixed c, lambda_l, and rho. Outputs are integer code k_i^l, selected code vector q_i^l, and next residual r_i^(l+1); concatenated k_i^l across levels is the raw SID.
SAFEGUARDS: Compute maps/distance in FP32 or FP64; clamp sqrt(c)||x|| to at most 1-eps (eps=1e-5), clamp atanh arguments to [-1+eps,1-eps], and floor norm denominators at 1e-8. Reject nonfinite transitions/targets, normalize with denominator floor, use alpha>0 smoothing, cap ||t_i|| and lambda_l, and monitor maximum ball norm plus finite losses/gradients. Empty outgoing rows use pi-smoothed fallback. Do not allow zero-degree items or padding IDs to create NaNs.
END IDEA
