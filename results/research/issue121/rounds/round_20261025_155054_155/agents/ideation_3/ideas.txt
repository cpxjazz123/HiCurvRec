IDEA: branch_curvature_gate
TITLE: Let training-only next-item branching set local hyperbolic assignment curvature
MOTIVATION: Items that lead to many distinct next items represent branching interests and may need a broader, more discriminative hierarchy than predictable one-successor items; a single global curvature cannot adapt the SID assignment geometry to that difference.
NOVELTY: Instead of adding a behaviour regularizer or matching behaviour to prefix occupancy, compute an item-specific curvature from its training next-item branching entropy and use that curvature inside each item's actual Lorentz code-distance calculation. Behaviour therefore changes the metric used to assign SIDs.
CHANGE: Precompute a smoothed branching score for each item using training transitions, map it to bounded negative curvature, and use that item-specific curvature in the Lorentz distance from the item's current residual to each code vector at every RQ level.
SPECIFICATION: From train.parquet only, count directed consecutive pairs c_ij; let p(j|i)=(c_ij+alpha)/(sum_j c_ij+alpha*N_i), over observed outgoing successors (N_i), and H_i=-sum_j p(j|i)log p(j|i)/log(max(2,N_i)). Set h_i=0 for N_i<2, otherwise clamp H_i to [0,1]. Define kappa_i=exp(log(kappa_min)+(log(kappa_max)-log(kappa_min))*h_i), e.g. [0.25, 4]. For latent residual r_i and code c_k, Lorentz-lift each tangent vector at origin at curvature -kappa_i: spatial(v)=tanh(sqrt(kappa_i)||v||)v/(sqrt(kappa_i)||v||), time(v)=sqrt(1/kappa_i+||spatial(v)||^2); d_i,k=acosh(max(1+eps, kappa_i*(time(r_i)time(c_k)-spatial(r_i)·spatial(c_k))))/sqrt(kappa_i). Assign argmin_k d_i,k^2, then subtract the selected code in the existing residual path; optionally use softmax(-d_i,k^2/tau) as the training assignment probabilities, with the same distance in straight-through quantization. The geometry-off control substitutes ||r_i-c_k||^2 and ignores h_i.
COST: Precompute transition counts/entropy once, O(E_train) time and O(I) storage; negligible relative to 3000 epochs. Per training step at the frozen scale (24 steps/epoch, 3000 epochs, 24556 items; roughly 1024 items/step), the extra work is one curvature lookup per item and a variable-curvature Lorentz lift/distance for each existing item-code comparison: O(B*K*D) arithmetic and O(B*K) distance memory, with no extra model pass or pairwise item graph. Expect a modest constant-factor increase over the baseline hyperbolic distance; exact wall-clock should be measured against geometry-off and fixed-curvature runs.
HYPOTHESIS: High-branching items benefit from a different effective radial/angular tradeoff during quantization, making their prefixes more useful for next-item generation without damaging predictable items. Keep only if both-on improves Stage3 test Recall@10 over both controls and behaviour/geometry interventions measurably change assignments or codebook/encoder gradients.
RISKS: Entropy estimates for rare items are noisy; train transitions may not represent test-time branching; per-item varying curvature can distort a globally shared codebook's geometry, destabilize assignments, or cause rare high-entropy items to overfit. Test smoothing, bounded curvature and warm-up; do not tune using validation/test interactions.
BEHAVIOR SIGNAL: Per-item normalized entropy of the directed training next-item distribution (next-item branching).
BEHAVIOR COMPUTATION: Group train.parquet by user, order each user's training interactions by timestamp, count each consecutive directed pair (item_t,item_{t+1}); aggregate counts by source item, apply additive smoothing over its observed successor set, then normalize Shannon entropy by log successor count. Cache only the resulting training-item scalar h_i.
LEAKAGE BOUNDARY: Construct the transition table exclusively from the training split before Stage2; validation/test rows are never loaded by the precomputation. Unseen items receive h_i=0 and the fixed low-curvature default; freeze the lookup for Stage2 SID export and Stage3.
HYPERBOLIC OPERATOR: Lorentz-model distance on the hyperboloid of constant sectional curvature -kappa_i, using exp-at-origin tangent lifts and the Lorentz inner product/acosh distance; kappa_i is bounded and item dependent.
HYPERBOLIC LOCATION: In each residual-quantization level's code assignment logits/argmin, replacing the current Euclidean or fixed-curvature distance before selecting the code and forming the residual.
COUPLING PATH: Training transition counts -> normalized branching entropy h_i -> curvature kappa_i -> Lorentz lift and distance between residual r_i and each code -> assignment probabilities/code choice -> residual and encoder/codebook gradients -> exported SID.
COUPLING EQUATION: q_i=argmin_k d_{-kappa(h_i)}(r_i,c_k)^2, where h_i=H(next_item|item_i, train) and d_{-kappa} is the Lorentz distance at negative curvature -kappa; thus changing either h_i or the curved distance changes q_i and its training gradient.
OBSERVABLES: Measure per-item SID changes stratified by training branching entropy, assignment probabilities/codebook gradients, and Stage3 test Recall@10; predict larger useful assignment changes among high-entropy items and improved generated continuation ranking.
ABLATION BEHAVIOR OFF: Replace every h_i with the training-set mean (one common kappa), retaining the same Lorentz operator and parameterization; compare assignments, gradients and Stage3 test Recall@10.
ABLATION GEOMETRY OFF: Keep the training-derived h_i table and all other settings, but replace Lorentz distance with squared Euclidean residual-code distance (no curvature-dependent lift); compare the same outputs and Stage3 test Recall@10.
ABLATION BOTH ON: Use each item's train-only h_i to set bounded kappa_i and use the corresponding Lorentz distance in every RQ level; export these SIDs and evaluate the unchanged Stage3 protocol on test_R@10.
SPEC EQUATIONS: For source item i, successors S_i and smoothed probabilities p_ij=(c_ij+alpha)/(C_i+alpha|S_i|), h_i=0 if |S_i|<2 else clip(-sum_j p_ij log p_ij/log|S_i|,0,1). kappa_i=exp((1-h_i)log kappa_min+h_i log kappa_max). For v, s=sqrt(kappa_i), u=||v||, x=tanh(su)v/max(su,eps), t=sqrt(max(1/kappa_i+||x||^2,eps)); then d(r,c)=acosh(max(1+eps,kappa_i*(t_r*t_c-x_r·x_c)))/s. At each level compute logits=-d^2/tau, softmax or argmin as in baseline, and update residual with the selected/soft code using the existing RQ rule. Use curvature -kappa_i (positive kappa_i denotes magnitude).
SPEC INPUTS OUTPUTS: Inputs are frozen item embedding/residual r [B,D], current level codebook c [K,D], integer item IDs [B], frozen train-derived h lookup [I], bounds kappa_min/max, and temperature tau. Output per-item-code distances [B,K], assignment probabilities or indices, and the selected quantized vectors/tokens consumed by the unchanged residual stack.
SAFEGUARDS: Clamp kappa to [0.25,4] and curvature magnitude away from zero; compute norm with epsilon, use stable acosh argument clamp >=1+1e-6, clamp h to [0,1], use alpha (e.g. 1) and h=0 for fewer than two distinct successors, handle unknown IDs with h=0, run distance arithmetic in float32 under mixed precision, and log finite-distance/gradient checks. Match codebook initialization, seed, training budget and all non-geometry settings across ablations.
END IDEA
