IDEA: predecessor_contrast_offset
TITLE: Predecessor-region contrast offset on the item latent
MOTIVATION: An item's own content latent should remain decisive for SID identity, while training transitions provide a directional cue about which first-level code region is useful for next-item prediction. A hard co-consumption negative supplies a local contrast rather than allowing generic popularity to dominate.
NOVELTY: Unlike context-decides-code mechanisms (which bottleneck distinct outcomes to the number of contexts), the contextual signal perturbs each item's own differentiable latent before the ordinary first-level nearest-code decision. Unlike an auxiliary transition loss, behaviour and curvature jointly change the actual assignment input.
CHANGE: Once per epoch compute fixed-curvature Poincare Frechet barycentres of current first-level codepoints for each item's observed training predecessors and its hardest eligible training co-consumption negative. Shift x_i a small, concentration-gated fraction toward the predecessor barycentre and away from the negative barycentre; select the first code by squared Euclidean distance from the shifted latent, then retain baseline residual quantisation at later levels.
SPECIFICATION: Freeze train-only predecessor sets P(i) and user-item sets U(i). Let n(i)=argmax_{j: J(i,j)>0, j not in P(i)} J(i,j), with deterministic item-ID tie-break, where J(i,j)=|U(i)∩U(j)|/|U(i)∪U(j)|. At each epoch compute b_i=FrechetMean_{Poincare(c=1)}{v_{a_1(j)}:j∈P(i)} and r_i analogously for n(i)'s predecessor set (empty set maps to 0). Let q_i(k) be the training predecessor mass assigned to first-level region k; gamma_i=0 if P(i) empty, else 1-H(q_i)/log(max(2,K)). Set d_i=(b_i-x_i)-0.5(r_i-x_i), z_i=x_i+w*gamma_i*d_i (w=0.1, bounded as specified below), and a_1(i)=argmin_k ||z_i-v_k||². Use z_i only for selecting a_1; baseline reconstruction and residual levels remain unchanged. Recompute barycentres after each epoch's codebook update. Distributed codebook access must use the unwrapped model/module at four-rank DDP.
COST: One-time training-split graph construction costs sparse user-set intersections for co-consumption candidates; cache predecessor/negative lists. Per epoch, barycentre accumulation is O(E_pred*d + N*d) plus O(N*K*d) nearest-code work already comparable to baseline; use cached predecessor-region aggregates to avoid edge-wise recomputation. At frozen scale N=24,556, 24 steps/epoch, 3,000 epochs: one barycentre refresh per epoch and 24,556 small shifts/assignments per epoch, targeting near-baseline ~0.15 s/epoch on four cards; profile because Frechet iterations may exceed budget.
HYPOTHESIS: Directed predecessor regions contain predictive structure beyond item content, and repelling each item from its strongest non-predecessor co-consumption neighbour reduces context-induced aliasing without collapsing item-level outcomes. Keep only if both-on improves Stage3 test Recall@10 toward/above 0.065 versus baseline and behavior-off, with no unacceptable reconstruction-loss or runtime increase.
RISKS: Sparse or noisy predecessor sets, unstable hard negatives, zero/near-zero entropy denominators, codebook movement making barycentres stale within an epoch, and the bounded shift still distorting reconstruction can erase gains. Jaccard candidate construction can be costly unless sparse and cached. Poincare barycentre iteration may break the epoch-time target.
BEHAVIOR SIGNAL: Directed training-only predecessor relation plus training-only co-consumption Jaccard for a hard negative.
BEHAVIOR COMPUTATION: From the training split only, add edge j→i when j is an observed immediate predecessor of i in a training sequence. For each item pair co-consumption J is the Jaccard overlap of the sets of training users interacting with each item. Select the maximum-J item not in i's observed predecessor set; freeze all lists and weights before Stage2.
LEAKAGE BOUNDARY: Construct user sets, transitions, candidate negatives, and predecessor-region masses exclusively from training interactions. Do not read validation/test interactions or future sequence positions. These frozen structures are the only behaviour inputs to Stage2; Stage3 validation/test is used only for the frozen evaluation protocol.
HYPERBOLIC OPERATOR: Fixed-curvature (c=1) Poincare Frechet barycentre, minimizing the sum of squared Poincare distances to the assigned codepoints.
HYPERBOLIC LOCATION: First-level context construction, once per epoch from current first-level codepoints; its barycentres form the offset before first-level item-to-code assignment.
COUPLING PATH: Training predecessor assignments and the hard-negative predecessor assignments select codepoints; their c=1 Poincare Frechet barycentres define d_i; gamma_i gates d_i; d_i shifts the still item-specific x_i; that shifted latent determines the first-level code and ensuing residual SID.
COUPLING EQUATION: d_i=(b_i^{Poincare(c=1)}-x_i)-0.5(r_i^{Poincare(c=1)}-x_i); z_i=x_i+w*gamma_i*d_i; a_1(i)=argmin_k ||z_i-v_k||². Here b_i and r_i depend on the training behavior signal, and the Poincare operator is inside that same assignment pathway.
OBSERVABLES: Measure first-level SID assignments and their epoch-to-epoch stability, training-transition predictability from prefixes, calibration cooccur_overlap_L3, reconstruction loss, runtime, and ultimately frozen Stage3 test Recall@10. Both-on should differ from each control in assignments and, if useful, improve Recall@10; do not treat SID quality metrics alone as admission.
ABLATION BEHAVIOR OFF: Set gamma_i=0 for all i and bypass b_i/r_i; assignment cost is exactly plain squared Euclidean ||x_i-v_k||² with x_i differentiable and not detached. Keep all other Stage2 settings fixed.
ABLATION GEOMETRY OFF: Replace each Poincare Frechet barycentre with the arithmetic Euclidean mean of the same assigned codepoints; curvature is absent everywhere in the behavior-to-offset path. Keep train-only behavior and all other settings fixed.
ABLATION BOTH ON: Use frozen training-only predecessor/Jaccard structures, c=1 Poincare Frechet barycentres refreshed once per epoch, concentration-gated contrast offset, and the ordinary own-latent first-level assignment.
SPEC EQUATIONS: For codepoints v_k inside the unit ball, project to radius <=1-eps. For nonempty context C_i, initialize m as Euclidean mean then iterate m←exp_m((1/|C_i|)Σ_j log_m(v_{a_1(j)})) for fixed small T; project each iterate. For empty context set m=0. Compute predecessor mass q_i(k)=count{j∈P(i):a_1(j)=k}/|P(i)|; gamma_i=max(0,min(1,1-H(q_i)/log(max(2,K)))). Then apply the coupling equation. Bound ||w*gamma_i*d_i|| <= 0.1*max(||x_i||,s_min) by radial rescaling, with w=0.1. Assignment scores are -||z_i-v_k||². All codebook reads under DDP use the unwrapped module.
SPEC INPUTS OUTPUTS: Inputs are differentiable batch latents x_i, current first-level codepoints and assignments, frozen predecessor lists, frozen training user sets/Jaccard hard negatives, w, and curvature c=1. Output is first-level assignment index a_1(i) for each item; downstream quantisation receives that index and unchanged residual inputs.
SAFEGUARDS: Clamp Poincare norms to 1-eps before log/exp, use stable small-norm series and eps in entropy/log denominators, cap Frechet iterations and stop on finite tolerance, map empty contexts to zero with gamma=0, deterministic tie-breaks, cache frozen graph data, bound offset norm, assert finite values and reconstruction loss near baseline (~1e-4), and benchmark a full four-rank epoch against ~0.15 s.
END IDEA

IDEA: concentration_gated_context_contrast
TITLE: Confidence-gated geodesic context contrast with item-preserving assignment
MOTIVATION: Some items have a coherent predecessor region while others occur after diverse histories; applying the same behavioral correction to both risks overwriting item semantics. Concentration should control how much a curved behavioral context can influence the item's own assignment.
NOVELTY: The mechanism couples incoming transition-region concentration and Poincare barycentres in a bounded offset of the item latent, not in an independent hyperbolic regularizer or a context-only code assignment. It is distinct in making the same train-only hard-negative contrast conditional on measured context certainty while preserving item-level code outcomes.
CHANGE: Reuse the frozen train-only directed predecessor and Jaccard-hard-negative signal, but explicitly let normalized predecessor-region entropy gate the contrastive Poincare barycentre displacement. The first-level code remains selected from the shifted, non-detached x_i, with the prescribed fixed w and bounded shift.
SPECIFICATION: Build P(i), U(i), and n(i) from training only as in the first idea. At each epoch derive b_i and r_i as c=1 Poincare Frechet means of the current first-level codepoints assigned to P(i) and n(i)'s predecessors. Define q_i as the histogram of first-level region assignments among P(i), gamma_i=0 for empty P(i), otherwise clip(1-H(q_i)/log(max(2,K)),0,1). Compute d_i=(b_i-x_i)-0.5(r_i-x_i), z_i=x_i+0.1*gamma_i*d_i, and select argmin_k ||z_i-v_k||². This is deliberately the fixed single-scalar offset, not an additional trainable gate.
COST: Sparse training graph and Jaccard negative are built once. Refreshing means once per epoch costs O(E_pred*d) accumulation and bounded Frechet iterations; calculating q and applying shifts costs O(E_pred+N*d), in addition to baseline quantization. At N=24,556, 24 steps/epoch, 3,000 epochs, process all items once for barycentre refresh and cache them for 24 steps; four-rank target remains ~0.15 s/epoch, subject to profiling Frechet iterations.
HYPOTHESIS: Entropy reliably distinguishes coherent from ambiguous incoming contexts, so the offset changes assignments primarily for context-consistent items; both-on should increase training-prefix predictability and Stage3 Recall@10 versus behavior-off and geometry-off, targeting >0.065 under frozen protocol.
RISKS: Region histograms depend on current assignments, and sparse contexts can give overconfident entropy estimates; small-count smoothing may be needed but must remain train-only. The hard negative may be an incidental co-consumer rather than a meaningful alternative. Curvature could add runtime without useful structure.
BEHAVIOR SIGNAL: Training-only incoming directed transitions, plus the training-user Jaccard strongest co-consumption item excluded from the predecessor set.
BEHAVIOR COMPUTATION: Extract immediate directed predecessor→target pairs from training sequences. Compute each item's user set on training interactions and pairwise Jaccard; choose the eligible maximum-Jaccard item deterministically. Freeze these inputs; recompute only the code-region histogram as the codebook/assignments evolve.
LEAKAGE BOUNDARY: All interaction-derived structures are made from the training partition and frozen before Stage2; no validation or test sequence, user set, item frequency, or outcome contributes to barycentres, gating, or SID construction.
HYPERBOLIC OPERATOR: Poincare Frechet barycentre at fixed negative curvature -1 (equivalently c=1), computed through exp/log maps over codepoints in the unit ball.
HYPERBOLIC LOCATION: The per-epoch refreshed predecessor and hard-negative context barycentres used directly to form the first-level latent offset.
COUPLING PATH: Training transitions determine assigned predecessor codepoints and their mass histogram; Poincare means of those codepoints and the hard-negative's predecessor codepoints produce the contrast vector; its entropy gate and offset alter x_i before actual nearest-code selection.
COUPLING EQUATION: z_i=x_i+0.1*gamma_i*((b_i^{Poincare(c=1)}-x_i)-0.5*(r_i^{Poincare(c=1)}-x_i)); a_1(i)=argmin_k ||z_i-v_k||², gamma_i=1-H(q_i)/log(max(2,K)) for nonempty training predecessor sets and 0 otherwise.
OBSERVABLES: Compare item-to-code assignments, assignment changes concentrated in high-gamma items, prefix transition predictability, cooccur_overlap_L3 and Stage3 test Recall@10; log offset-to-latent ratio, reconstruction loss and epoch runtime to ensure no collapse or scale drift.
ABLATION BEHAVIOR OFF: Set gamma=0 / bypass behavior; the exact assignment cost is plain squared Euclidean ||x_i-v_k||² with x_i differentiable and not detached.
ABLATION GEOMETRY OFF: Compute b_i and r_i as arithmetic Euclidean means of the identical training-assigned codepoint sets; retain behavior histogram, entropy gate, contrast coefficient, and all other settings.
ABLATION BOTH ON: Use behavior-derived transitions/Jaccard negatives, entropy gate, c=1 Poincare means refreshed once per epoch, and the bounded item-latent offset in first-level assignment.
SPEC EQUATIONS: For C_i={a_1(j):j∈P(i)}, q_i(k)=count(C_i=k)/|P(i)|. Set gamma_i=0 if |P(i)|=0 else clip(1+Σ_k q_i(k)log(q_i(k)+eps)/log(max(2,K)),0,1). Compute b_i=FrechetMean_{c=1}{v_k:k∈C_i}; compute r_i similarly from n(i)'s observed predecessors (empty means 0). Form d_i and z_i as in COUPLING EQUATION, radially cap ||z_i-x_i||≤0.1*max(||x_i||,s_min), choose first code by squared Euclidean distance, then run baseline residual levels.
SPEC INPUTS OUTPUTS: Inputs: x_i (gradient-connected), first-level codebook and current item assignments, frozen training predecessor lists and co-consumption hard negatives, scalar w=0.1. Output: first-level code assignment; later residual quantizer is unchanged.
SAFEGUARDS: Project codepoints/iterates into radius 1-eps; stable exp/log near origin; add eps to entropy terms; gamma=0 for empty predecessors; cap Frechet iterations; bound offset; deterministic negative tie-breaking; assert finite barycentres, assignments, and ~1e-4 reconstruction-loss scale. Unwrap DDP before codebook reads and run the required four-rank exercise.
END IDEA
