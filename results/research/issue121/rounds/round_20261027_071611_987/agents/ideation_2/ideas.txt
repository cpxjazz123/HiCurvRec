IDEA: incoming-own-shift
TITLE: Train-only incoming-region offset with Poincare predecessor/negative barycentres
MOTIVATION: A predecessor's region can predict a useful next-item region, but assigning an item solely from shared context erases item identity and structurally caps the number of distinct SID outcomes.
NOVELTY: Unlike context-as-assignment, the behavior and curved geometry generate a bounded offset to each item's differentiable own latent; the shifted latent, not a shared context prototype, still chooses the code. The repository already contains related incoming-context experiments, so this is the exact requested offset-form candidate rather than a claim that the general barycentre concept is unprecedented.
CHANGE: On level one only, construct per-item positive and hard-negative Poincare Frechet means from the current first-level codebook, then shift the item's own latent toward the positive region and away from the negative region in a bounded tangent-space step before ordinary Euclidean code scoring.
SPECIFICATION: Freeze training-only predecessor lists and a co-consumption hard negative n(i). Each epoch compute b_i=F_c({v_{a(j)}:j->i}) and r_i=F_c({v_{a(j)}:j->n(i)}), c=1; let d_i=(b_i-x_i)-0.5(r_i-x_i), z_i=x_i+w gamma_i d_i, and assign argmin_k ||z_i-v_k||^2. gamma_i=1-H(p_i)/log(max(2,R_i)), where p_i is predecessor mass aggregated by assigned code region; set gamma_i=0 for no predecessors. Keep x_i attached to autograd.
COST: Sparse graph/Jaccard construction is one-time O(E log U) approximately, with E training transitions and U users. At frozen scale (24,556 items, 24 steps/epoch, 3,000 epochs), per-epoch barycentres cost O((N+P+Q)K d I) for P positive and Q negative padded predecessor slots, K first-level codes, dimension d and I fixed Karcher iterations; cache padded sparse indices and run batched GPU reductions. Assignment adds O(NKd) already of baseline order; target total epoch near 0.15 s on four cards, so cap slots and I and benchmark all-rank.
HYPOTHESIS: If predecessor-region transitions carry signal beyond item identity, the offset should redirect first-level assignments toward likely next regions while preserving fine-grained distinct codes, raising Stage3 test Recall@10 above 0.065; observe SID assignments and frozen-protocol Stage3 Recall@10.
RISKS: Noisy/low-support transitions, unstable or costly barycentre updates, excessive shifts, stale assignments during refresh, or the Euclidean codebook scale making the curved barycentre offset ineffective may erase gains or hurt reconstruction.
BEHAVIOR SIGNAL: Directed training item transitions and a co-consumption hard negative for each item.
BEHAVIOR COMPUTATION: From training split only, count j->i within each user's ordered sequence to form incoming predecessor lists with counts. Build each item's user set from training interactions only; choose n(i) as maximum Jaccard user-set overlap among co-consumed candidates that are not observed predecessors of i (deterministic item-ID tie-break). Freeze these identities and weights before Stage2; validation/test are excluded.
LEAKAGE BOUNDARY: Build graph, user sets, Jaccards, negative identities and all list padding solely from the training split; never read validation/test interactions or future sequence events. Refresh only barycentre coordinates from current learned codebook, not behavior data.
HYPERBOLIC OPERATOR: Fixed-curvature c=1 Poincare Frechet/Karcher barycentre of codepoints, obtained by a fixed small number of Riemannian log-map, weighted tangent-mean, exp-map updates.
HYPERBOLIC LOCATION: Once-per-epoch cache refresh of positive predecessor and negative-item context barycentres; these curved points form the first-level latent offset before code selection. No curved code distance is needed.
COUPLING PATH: Training transitions choose predecessor codepoints; those codepoints are combined by a Poincare Frechet barycentre, contrasted against the barycentre from the co-consumption hard negative, and the result offsets each item's own latent before its level-one code assignment.
COUPLING EQUATION: b_i=F_{P,c=1}(v_{a(j)}:j->i), r_i=F_{P,c=1}(v_{a(j)}:j->n(i)); z_i=x_i+w gamma_i[(b_i-x_i)-0.5(r_i-x_i)]; S(i,k)=-||z_i-v_k||_2^2.
OBSERVABLES: With both-on, first-level codes and downstream SIDs should differ from baseline without collapsing to the limited number of context regions; measure changed code assignments, assignment entropy/collisions as diagnostics, and Stage3 test Recall@10 under frozen protocol.
ABLATION BEHAVIOR OFF: Set w=0; return exactly S(i,k)=-||x_i-v_k||^2 using attached x_i, with no detach or context term.
ABLATION GEOMETRY OFF: Replace each Poincare barycentre with the count-weighted Euclidean mean of the exact same assigned codepoints; keep offsets, weights, negatives and w unchanged (curvature removed throughout the pathway).
ABLATION BOTH ON: Use frozen train-only predecessor/Jaccard data, refreshed c=1 Poincare barycentres, bounded shift, and Euclidean score of shifted own latent; run all 3,000 epochs on four cards and then frozen Stage3 evaluation.
SPEC EQUATIONS: For each epoch e, a(j)=argmin_k ||x_j-v_k||^2. For each i with predecessor list L_i and normalized counts q_ij, initialize b_i to weighted Euclidean mean projected inside ball; iterate b <- exp_b(sum_j q_ij log_b(v_{a(j)})) for fixed I iterations. Compute r_i analogously from L_{n(i)}. Aggregate q by predecessor assigned region to p_ir; gamma_i=max(0,1+sum_r p_ir log(p_ir+eps)/log(max(2,R_i))) or 0 when empty. d_i=(b_i-x_i)-0.5(r_i-x_i); scale d_i by min(1, rho*max(||x_i||,s0)/(||d_i||+eps)) to bound the displacement; z_i=x_i+w gamma_i d_i; logits=-cdist_squared(z_i,v). A no-predecessor row must take z_i=x_i exactly.
SPEC INPUTS OUTPUTS: Inputs are current first-level codebook v[K,d], per-item encoder latent x[N,d], frozen weighted predecessor lists, frozen negative item IDs, assigned code IDs for the current epoch, curvature c=1, w≈0.1, and fixed Karcher iteration count. Outputs are refreshed b[N,d], r[N,d], gamma[N], and differentiable first-level scores S[N,K] / code IDs.
SAFEGUARDS: Project ball points to norm <=(1-eps)/sqrt(c); clamp acosh/log-map arguments and denominators; accumulate barycentres in float32; handle empty lists explicitly; epsilon-clamp entropy and Jaccard denominators; deterministic tie breaks; cap/pad predecessor slots; bound tangent/displacement norms and w; ensure finite-value checks. DDP codebook reads must unwrap the model at every refresh; synchronize resulting caches across ranks (or compute identically from synchronized codebooks).
END IDEA

IDEA: transition-geodesic-prior
TITLE: Sparse predecessor-conditioned geodesic prior on item-preserving soft assignments
MOTIVATION: A next-item model benefits when the first code expresses the item's own semantics while remaining compatible with where training predecessors tend to lead; direct context replacement risks collapsing many items onto a few regions.
NOVELTY: This couples behavior to curved code-to-code transition geometry in the assignment posterior rather than shifting the encoder latent by a context barycentre. A sparse per-item transition prior modifies candidate probabilities, while the hard code still depends on the item's own latent.
CHANGE: Form a train-only directed transition matrix between current code regions, score item-to-code candidates with own-latent Euclidean distortion plus a scaled Poincare geodesic transition penalty from incoming predecessor regions, and use the resulting soft assignment for the existing straight-through code choice.
SPECIFICATION: Let A_{rk}=sum_{j->i} count(j,i) 1[a(j)=r] 1[a(i)=k], smoothed and row-normalized each epoch. For item i, let u_ir be its normalized incoming predecessor-region mass. Set logits l_ik=-||x_i-v_k||^2/tau + eta sum_r u_ir log((A_{rk}+alpha exp(-d_P(v_r,v_k)^2/sigma^2))/(sum_q A_{rq}+alpha Z_r)); choose argmax l_ik. Thus behavior transitions gate a curved geodesic compatibility kernel without replacing x_i.
COST: Build frozen sparse transition edges once; per epoch aggregate at most P predecessor regions per item and evaluate candidate compatibility O(NPK), with cached code-distance kernel O(K^2 d) once per epoch. At N=24,556, 24 steps and 3,000 epochs, use compact KxK cache and sparse rows; likely extra cost versus baseline is one O(K^2d) distance refresh and O(NPK) gathers, target near 0.15 s/epoch on four GPUs requires profiling and P cap (e.g. 8).
HYPOTHESIS: If training transition dynamics are predictive and nearby Poincare code regions represent related branches, this prior should alter level-one code frequencies toward empirically plausible successors without destroying item-specific distinctions; retain only if Stage3 Recall@10 rises above 0.065.
RISKS: Epoch-wise hard assignments make A noisy; popular transitions can dominate despite smoothing; the extra candidate-score term may overwhelm reconstruction or make distributed updates inconsistent. Curvature kernel bandwidth and temperature require fixed, small calibration.
BEHAVIOR SIGNAL: Directed predecessor-to-target item transitions, mapped to assigned first-level code regions.
BEHAVIOR COMPUTATION: Count consecutive item transitions j->i from each ordered user's training sequence only; within each epoch map source and target items to their current first-level code IDs and accumulate weighted region edges. No validation/test transitions enter.
LEAKAGE BOUNDARY: Freeze training sequences and transition counts before quantizer training. The epoch matrix is an aggregation of those fixed edges through current model assignments only; it never consumes held-out interactions or future sequences.
HYPERBOLIC OPERATOR: Squared Poincare geodesic distance d_P^2(v_r,v_k) at fixed c=1, converted into a normalized radial transition kernel exp(-d_P^2/sigma^2).
HYPERBOLIC LOCATION: In the first-level candidate-assignment logits, as the curved kernel that smooths the behavior-derived code-region transition probabilities.
COUPLING PATH: Training predecessor region masses select rows of the learned transition table; each table entry is smoothed according to the Poincare distance between the corresponding codepoints; this behavior-and-geometry probability adjusts each item's own-latent candidate logits.
COUPLING EQUATION: l_ik=-||x_i-v_k||^2/tau + eta sum_r u_ir log[sum_s A_{rs} exp(-d_{P,c=1}(v_s,v_k)^2/sigma^2)+alpha]/Z_r; code_i=argmax_k l_ik.
OBSERVABLES: With both-on, first-level assignments and transition-conditioned prefix predictability should change, and Stage3 test Recall@10 should improve; also check finite logits and SID diversity as diagnostics, not admission criteria.
ABLATION BEHAVIOR OFF: Set eta=0 and use exact baseline plain squared Euclidean scores of attached x_i; no transition matrix influences assignment.
ABLATION GEOMETRY OFF: Replace exp(-d_P^2/sigma^2) with its parameter-matched Euclidean counterpart exp(-||v_s-v_k||^2/sigma_E^2), matched on median pairwise kernel value; preserve train-only transition counts and all other settings.
ABLATION BOTH ON: Use the train-only region transition table smoothed by c=1 Poincare geodesic kernel in the first-level logits; run full four-card 3,000-epoch Stage2 and frozen Stage3 protocol.
SPEC EQUATIONS: Initialize A_{rk}=alpha/K. For each fixed training edge j->i with weight c_ji, add c_ji to A_{a(j),a(i)}; row-normalize. Compute u_ir from weighted incoming predecessor code IDs. Let G_{sk}=exp(-min(d_P(v_s,v_k)^2,Dmax)/sigma^2); T_{rk}=sum_s A_{rs}G_{sk}, row-normalize T with epsilon. Then l_ik=-||x_i-v_k||^2/tau+eta sum_r u_ir log(T_{rk}+eps). Return argmax and baseline-compatible straight-through embedding. Cache G once per epoch; gradient through x_i and assignment logits, with codebook gradients as baseline.
SPEC INPUTS OUTPUTS: Inputs: attached item latents x[N,d], first-level codes v[K,d], frozen training edge list (j,i,count), current hard assignments a[N], c=1 and scalars alpha, sigma, eta, tau. Output: score/logit matrix [N,K] and code IDs; optionally sparse A/T for diagnostics.
SAFEGUARDS: Clamp ball norms below 1/sqrt(c), clamp distance/kernel exponents, add alpha smoothing and epsilon before logs/normalizers, accumulate A in fp32 and all-reduce it across ranks, deterministic edge order/ties, clip eta and logits, and cap predecessor support. Geometry-off matches kernel scale by a training-only median-distance calibration, never held-out data.
END IDEA
