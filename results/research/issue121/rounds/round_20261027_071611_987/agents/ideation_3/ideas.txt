IDEA: pred_offset
TITLE: Predecessor-region offset with hard-negative repulsion
MOTIVATION: A semantic code should reflect the destination structure implied by an item's training predecessors, while retaining item-specific latent information so shared context cannot collapse the SID partition.
NOVELTY: Unlike context-only code assignment, this uses directed predecessor and co-consumption evidence to perturb each item's own live encoder latent before first-level assignment. The hyperbolic operation is specifically the construction of the context barycentres in the shift; code selection remains the specified Euclidean nearest-code operation.
CHANGE: Freeze training-only predecessor and co-consumption relations once; at each epoch compute Poincare Frechet barycentres of current first-level codepoints for predecessor and hard-negative regions. Shift each item's undetached latent by the bounded, concentration-scaled difference d_i, then select its first code from the shifted item latent.
SPECIFICATION: Let P(i) be observed training items immediately preceding i in user sequences. Let N(i) be training items co-consumed by users with i, excluding i and P(i), ranked by user-set Jaccard; h(i)=argmax_{j in N(i)} J(i,j). Let A(j) be j's frozen first-level code assignment from the latest epoch. For nonempty P(i), b_i=Frechet_c=1({v_k:k=A(j), j in P(i)}), r_i=Frechet_c=1({v_k:k=A(j), j in P(h(i))}); otherwise set gamma_i=0 and d_i=0. Compute gamma_i=max(0,1-H(q_i)/log(max(2,R_i))), where q_i is the normalized mass of predecessor assignments over R_i occupied regions and H is entropy. Then d_i=(b_i-x_i)-0.5(r_i-x_i), z_i=x_i+w*gamma_i*d_i, S(i,k)=-||z_i-v_k||^2, code_i=argmax_k S(i,k), with w=0.1. Barycentres use codepoints mapped to the c=1 Poincare ball; apply the same convention consistently to both barycentre inputs and outputs.
COST: Freeze sparse P and Jaccard hard negatives once. Refresh region barycentres once per epoch using current codebook; per batch lookup b_i,r_i,gamma_i and do one vector shift plus existing first-level distance computation. With 24 steps/epoch and 3000 epochs, the extra epoch work is O(number of observed predecessor edges + hard-negative references + occupied-region barycentre work); batch overhead is O(batch_size*embedding_dim) plus barycentre lookup, not an additional item-by-code distance matrix. Expected small relative to baseline's ~0.15 s/epoch if cached sparse region memberships and vectorized; verify measured wall time and four-rank scaling.
HYPOTHESIS: Predecessor destinations and hard-negative separation provide useful local assignment bias without reducing item-level outcome capacity. Keep only if both-on improves Stage3 test Recall@10 over 0.065 (under frozen protocol) and improves calibration cooccur_overlap_L3 versus baseline without code collapse.
RISKS: Noisy/short histories, Jaccard ties, stale epoch assignments, or barycentre concentration can make offsets unhelpful; Poincare barycentre computation may cost more than budget or yield unstable values near the ball boundary. The fixed w may be too weak/strong; context-free items receive no effect.
BEHAVIOR SIGNAL: Directed item-predecessor relation from training user sequences plus training user-set co-consumption Jaccard for the hard negative.
BEHAVIOR COMPUTATION: From training split only, count directed adjacent transitions u->i across each user's ordered sequence. For each item pair compute user-set Jaccard |U(i) intersect U(j)|/|U(i) union U(j)| from training interactions; for each i choose the highest-scoring eligible j that is not i or an observed predecessor. Freeze lists and values before Stage2.
LEAKAGE BOUNDARY: Build and freeze all edges, user sets, Jaccards, predecessor memberships, and hard-negative identities exclusively from the training split. Validation/test interactions are never read by the builder, epoch refresh, or quantizer; only the learned codebook changes during Stage2.
HYPERBOLIC OPERATOR: Poincare Frechet barycentre at fixed negative curvature c=1, computed from first-level codepoints mapped to the unit ball; use the same operator for b_i and r_i.
HYPERBOLIC LOCATION: Once-per-epoch context-table refresh during Stage2, before batched first-level assignment; the resulting barycentres enter the item's latent offset, not a separate auxiliary loss.
COUPLING PATH: Training predecessors determine b_i and incoming concentration gamma_i; training co-consumption determines r_i; these curved barycentres jointly define d_i and shift the live x_i which is then assigned to a first-level code. Removing behaviour removes the shift; removing curvature changes the barycentres and therefore the shifted latent.
COUPLING EQUATION: d_i=(b_i^{Poincare,c=1}(P(i))-x_i)-0.5*(r_i^{Poincare,c=1}(P(h(i)))-x_i); z_i=x_i+w*gamma_i*d_i; code_i=argmin_k ||z_i-v_k||^2. Here gamma_i is the predecessor-region concentration and h(i) is the training co-consumption Jaccard hard negative.
OBSERVABLES: First-level assignments should move toward predecessor destination regions and away from hard-negative destination regions while preserving item-specific separation; measure assignment changes, occupancy/collisions, cooccur_overlap_L3, and frozen Stage3 test Recall@10. Compare behavior-off, geometry-off, and both-on.
ABLATION BEHAVIOR OFF: Set gamma_i=0 (equivalently d_i=0 for assignment); use the live, undetached x_i and the baseline squared Euclidean assignment cost exactly, with no context term.
ABLATION GEOMETRY OFF: Replace each c=1 Poincare Frechet barycentre by the ordinary Euclidean mean of the same assigned codepoints; retain the same frozen behaviour, gamma, d, w, and live x_i. This removes curvature everywhere in this coupling pathway.
ABLATION BOTH ON: Use training-only P(i), h(i), gamma_i and current-codebook c=1 Poincare Frechet barycentres in the exact latent-offset equation above, with w=0.1.
SPEC EQUATIONS: Once per epoch, from the current unwrapped first-level codebook V, form region barycentres B_g=Frechet_c=1({v_k:k in g}) for each occupied code region g; cache them. For each item i, aggregate predecessor region mass q_i(g)=count{j in P(i):A(j)=g}/|P(i)|; gamma_i=0 if P(i) empty, otherwise clamp(1-H(q_i)/log(max(2, number of occupied predecessor regions)),0,1). Let b_i=sum_g q_i(g)B_g under a Poincare Frechet barycentre operation (equivalently Frechet over predecessor-assigned codepoints), and r_i the analogous barycentre for h(i)'s predecessors. Per batch: x_i=encoder(item_i); d_i=(b_i-x_i)-0.5*(r_i-x_i); z_i=x_i+0.1*gamma_i*d_i; assign argmin_k squared_Euclidean(z_i,v_k). Keep x_i differentiable and do not detach it. In distributed training unwrap the model before reading codebook; refresh once per epoch and synchronize/consistently update cached tables on all ranks.
SPEC INPUTS OUTPUTS: Inputs: live batch encoder outputs x_i, current first-level codebook V, frozen predecessor lists P(i), frozen hard negative h(i), and frozen training assignment/region memberships used for the epoch refresh. Outputs: shifted latents z_i and first-level code indices; auxiliary cache contains per-item b_i,r_i,gamma_i refreshed once per epoch.
SAFEGUARDS: Project mapped points inside radius 1-epsilon; clamp norms before log/exp maps, use stable float32 or float64 accumulation for Frechet iterations, cap iterations/tolerance, and fall back to Euclidean initialization/last finite iterate on nonfinite values. Empty predecessor/hard-negative sets yield zero shift contribution; avoid log(0) with max(2,R); break Jaccard ties deterministically. Bound shift fraction, e.g. rescale w*gamma_i*d_i if its norm exceeds 0.1*max(||x_i||,epsilon), and log shift-to-latent ratio, reconstruction loss (~1e-4), assignment occupancy, and epoch time. Verify four-rank execution and unwrap model wherever codebook is read.
END IDEA
