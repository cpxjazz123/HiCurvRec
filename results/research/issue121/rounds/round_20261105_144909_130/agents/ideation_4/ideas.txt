IDEA: BEABLATE-CURVSCALE-RQ
TITLE: Level-1 curved assignment shifted by a mean-normalised, curved-metric behaviour-demand offset computed from the curved soft assignment itself.
MOTIVATION: Level-1 codes are chosen by nearest-Euclidean-residual only, so behaviourally hot items (many contributing outgoing train-split transitions) and behaviourally dead items can share the same top code, and the prefix the generator actually emits carries no behavioural information. A flat offset that is not expressed in the same metric as the distance cannot say how hot is hot relative to how far apart codes are, and its effect silently changes when curvature changes.
NOVELTY: Not cross-graph two-segment transport, not capacity cells, not a per-codeword curvature field, not hierarchical curvature plus Sinkhorn. Two mechanism-level differences from the earlier arms: the behaviour demand is measured through the curved soft assignment (geometry enters the behaviour statistic), and the offset is rescaled by a measured scale s_D so it lives in curved-distance units and the behaviour/geometry balance is curvature-invariant rather than confounded by c.
CHANGE: In level 1 only, exp-map the scale-normalised residual into the Poincare ball, score untrained baseline codewords with the Poincare distance, and assign k_1 = argmin_k (D_k - w*s_D*log(clip(demand_k))). Demand is a detached, mean-normalised EMA of train-split out-transition mass attributed to level-1 codes through the curved soft assignment; levels 2-3, loss, reconstruction codeword and STE are exactly the baseline.
SPECIFICATION: Conventions per the geometry contract: kappa = -c, c > 0, R_c = 1/sqrt(c); d_c(x,y) = (2/sqrt(c))artanh(sqrt(c)||(-x)(+)y||); exp_0^c(v) = tanh(sqrt(c)||v||)v/(sqrt(c)||v||); tangent Euclidean norm is not the Riemannian norm (||v||_{0,c} = 2||v||), so offsets are added to a length, never to a squared distance or a dot product. s = RMS of the level-1 residual over the train split, computed once, frozen. Derived curvature: x = r/s has RMS 1, so set R_c = 2 (ball radius twice the residual scale) => sqrt(c) = 1/2 => c = 0.25, giving sqrt(c)||u|| ~ 0.23 for a typical item. u = exp_0^c(x), q_k = exp_0^c(a_k) with a_k the untrained baseline level-1 codebook row, D_k = d_c(u,q_k). Behaviour: out-mass b_i = sum_j n_ij from train-split consecutive-item transition counts; p_ik = softmax_k(-D_ik/mean_k D_ik) detached; mass_k = sum_i p_ik b_i / sum_i p_ik; m_k <- (1-lambda)m_k + lambda*mass_k with m init 1 and lambda = 1/72000 (one e-fold over the frozen budget); demand_k = m_k/mean_k(m_k). Offset: g_k = log(clip(demand_k, e^-1, e^1)); s_D = mean_i min_k D_ik; off_k = w s_D g_k, w = 0.25. Assignment k_1 = argmin_k (D_k - off_k), ties to smallest index. Switches exist and are never exercised in this round: use_behaviour=False => m frozen at 1 => off_k = 0; use_curvature=False => sqrt(c)->0 => D_k = 2||x - a_k||, p_ik and s_D Euclidean. Gradients: D_k, p_ik, m, s_D, off_k all detached and used only in the argmin; reconstruction uses a_{k_1} exactly as the baseline; encoder gradient is the baseline identity STE dx/dr = 1/s plus the unchanged commitment term; no new loss term.
COST: At the frozen scale, 24556 training items, 24 steps per epoch, 3000 epochs = 72000 steps. Added per step: one exp map on B x d, one Mobius ad

d + artanh on B x K1 x d, one exp map on K1 x d, one scatter-add over K1. With B = 256, K1 = 256, d = 32 that is ~2e7 MACs and ~65k artanh evaluations per step, under ~2% step wall-clock, i.e. minutes of extra GPU time across the whole 72000-step run on four cards. One-time: O(#train transitions) graph build (tens of seconds) and one frozen encoder pass for s. Memory: K1 floats for m plus one B x K1 detached matrix.
HYPOTHESIS: Hot and dead items stop sharing a level-1 code, so the level-1 prefix becomes behaviourally predictable and the generator's first token carries information, lifting Stage3 test_recall@10 above 0.065 from the 0.0555 baseline and the 0.0638 prior best. Observed as recall above 0.065 in the single run, a level-1 code-change rate vs the Euclidean baseline of order 5-20%, preserved level-1 usage entropy with no dead-code blow-up, and a higher validation successor-same-level-1-code rate recorded as diagnostic only.
RISKS: The offset swamps the distance and collapses level 1 onto a few hot codes; the EMA is dominated by super-hot items so demand becomes a near-binary mask; s_D is noisy at small batch size so the offset jitters; the reassignment is partly re-absorbed by levels 2-3 giving flat recall because no gradient reaches the encoder through the detached argmin; fixed c = 0.25 may push outlier residuals near the ball boundary; single-seed noise may hide a small true effect.
BEHAVIOR SIGNAL: Directed item transitions of the training split, reduced to per-anchor out-transition mass b_i and attributed to level-1 codewords through the curved soft assignment to give per-codeword demand demand_k.
BEHAVIOR COMPUTATION: Train split only: count n_ij for consecutive items within each training sequence (deduplicated per sequence so one long sequence cannot flood the count); b_i = sum_j n_ij. Each Stage-2 step: for the batch items compute p_ik = softmax_k(-D_ik/mean_k D_ik) from the current curved distances, mass_k = sum_i p_ik b_i/sum_i p_ik, EMA m_k with lambda = 1/72000, return demand_k = m_k/mean_k(m_k). Detached, not backpropagated, never in a loss.
LEAKAGE BOUNDARY: The transition graph, b_i and s come only from the training split; the EMA only sees training batches because Stage 2 iterates training sequences, and no validation or test interaction is ever loaded into this path. m_k is frozen at the end of Stage 2 and used unchanged at evaluation, so no validation or test co-occurrence can influence the level-1 assignment. Nothing about the Stage-3 generator's targets touches level 1.
HYPERBOLIC OPERATOR: Fixed negative curvature Poincare ball, kappa = -c, c = 0.25 (sqrt(c) = 1/2, R_c = 2) in scale-normalised units: the exponential map exp_0^c for both residual and codewords, and the Poincare distance d_c(u,q_k) = (2/sqrt(c))artanh(sqrt(c)||(-u)(+)q_k||). No trainable curvature.
HYPERBOLIC LOCATION: Quantisation only, level 1 of the residual quantiser: it defines the distance over which both the behaviour soft assignment and the hard argmin are taken. Levels 2 and 3 keep the baseline Euclidean recursion, distances, assignment and loss.
COUPLING PATH: r -> x = r/s -> u = exp_0^c(x) -> D_k = d_c(u, exp_0^c(a_k)) -> both the soft assignment p_ik that builds demand_k and the offset off_k = w s_D log(clip(demand_k)) -> k_1 = argmin_k (D_k - off_k) -> reconstruction with a_{k_1} -> baseline loss and STE -> encoder parameters. Behaviour off sets off_k = 0 and freezes m, changing k_1; geometry off replaces D_k by 2||x - a_k||, whi

ch changes s_D and p_ik as well as the argmin. Neither branch can be removed without changing k_1, and there is no second loss for either to hide in.
COUPLING EQUATION: k_1 = argmin_k [ d_c(u, exp_0^c(a_k)) - w s_D log(clip(m_k/mean_k(m_k), e^-1, e^1)) ], with m_k itself built through p_ik = softmax_k(-d_c(u_i, exp_0^c(a_k))/mean_k d_c(u_i, exp_0^c(a_k))); behaviour term and curved term share one distance and one metric.
OBSERVABLES: Level-1 code-change rate vs the Euclidean baseline (target 5-20%); level-1 usage entropy and dead-code count; mean |off_k|/s_D (bounded by 0.25); validation successor-same-level-1-code rate; level-1 commitment contribution; Stage3 test_recall@10, the single judgement, target above 0.065.
ABLATION BEHAVIOR OFF: use_behaviour = False: m held at 1.0, off_k = 0 exactly, k_1 is the plain curved argmin. Implemented and correct, not trained in this round.
ABLATION GEOMETRY OFF: use_curvature = False: sqrt(c) -> 0, D_k = 2||x - a_k|| with u = x and q_k = a_k, and p_ik, s_D, off_k recomputed in Euclidean units. Implemented and correct, not trained in this round.
ABLATION BOTH ON: use_behaviour = True and use_curvature = True, the coupled mechanism above, trained once for 3000 Stage-2 epochs (72000 steps) on four cards with no early stopping, then the frozen Stage-3 protocol, single seed.
SPEC EQUATIONS: s = rms_train(||r||); x = r/s; u = tanh(sqrt(c)||x||) x/(sqrt(c)||x||) with u = x when sqrt(c)||x|| < 1e-4; q_k = tanh(sqrt(c)||a_k||) a_k/(sqrt(c)||a_k||); D_k = (2/sqrt(c)) artanh(clip(sqrt(c)||(-u)(+)q_k||, 0, 1-1e-6)); p_ik = softmax_k(-D_ik/(mean_k D_ik + eps)); mass_k = sum_i p_ik b_i/(sum_i p_ik + eps); m_k <- (1-lambda) m_k + lambda mass_k, m init 1, lambda = 1/72000; demand_k = m_k/(mean_k m_k + eps); g_k = log(clip(demand_k, e^-1, e^1)); s_D = mean_i min_k D_ik; off_k = w s_D g_k, w = 0.25; k_1 = argmin_k (D_k - off_k) with ties to smallest k; z_1 = a_{k_1}, r_2 = r - z_1, levels 2-3 and loss unchanged, STE dx/dr = 1/s with identity pass-through as baseline.
SPEC INPUTS OUTPUTS: Inputs: level-1 residual r (B x d), baseline level-1 codebook A (K1 x d), frozen scale s, frozen per-anchor out-mass b_i (N_train), running m (K1), curvature c, switches use_behaviour and use_curvature. Outputs: level-1 indices k_1 (B, int64), quantised level-1 vector a_{k_1} identical to the baseline for that index, updated m (K1), detached diagnostics D (B x K1), off (K1), s_D. Nothing else in the model changes.
SAFEGUARDS: Taylor branch for the exp map when sqrt(c)||x|| < 1e-4; artanh argument clamped to [0, 1-1e-6]; s and s_D floored at 1e-6; m floored at 1e-6 and demand clipped to [e^-1, e^1] so |off_k| <= 0.25 s_D and no dead code gets an unbounded bonus; m initialised at 1.0 so the mechanism starts behaviour-neutral; softmax temperature is the per-item mean distance so no free constant exists to tune; all scores detached so no shortcut gradient reaches the encoder and the commitment weight cannot be perturbed; deterministic tie-break and deterministic EMA order for reproducibility; use_curvature=False is a real branch that sets sqrt(c) = 0 and reverts every length-like quantity to the Euclidean formula, not a rescaling.
END IDEA
