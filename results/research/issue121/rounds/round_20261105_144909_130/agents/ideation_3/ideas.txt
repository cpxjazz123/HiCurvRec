IDEA: pmi-geomargin-l1-rq
TITLE: Popularity-adjusted transition-surplus geodesic margin on the level-1 Poincare assignment of an RQ-VAE Semantic ID
MOTIVATION: RQ-VAE level-1 codes are learned from reconstruction geometry only, so two items that are behaviourally interchangeable as next items (same directed-transition role) can land on different level-1 codes, and a level-1 code that is the true branching point of many training transitions gets no extra pull. The generative recommender then spends prefix capacity on distinctions the transition graph says are irrelevant and misses distinctions it says are load-bearing.
NOVELTY: The behaviour term is a popularity-adjusted directed-transition SURPLUS (PMI-style) aggregated per level-1 codeword, not raw demand, not branching entropy, not a per-codeword curvature field, not a stratified/Sinkhorn transport, not a curvature ladder, not a cross-graph two-segment transport and not a capacity unit. The curvature is a single FIXED value derived from the measured training latent RMS, and the offset weight is derived from a geodesic scale measured in epoch 1, so no constant is swept. Level 2, level 3, the residual recursion, the reconstruction codebook and the STE are byte-identical to baseline; the whole coupling lives in the level-1 score.
CHANGE: The level-1 assignment score becomes the Poincare distance between the level-1 residual lifted into a derived-curvature ball and the level-1 codeword lifted into the same ball, minus a derived scalar times the log of that codeword's popularity-adjusted transition surplus. Nothing downstream consumes the offset: shipped codebook positions, level-2/3 recursion, reconstruction and STE are unchanged.
SPECIFICATION: (1) s = RMS norm of the training-split latent vectors at step 0, frozen. (2) c = (rho/s)^2 with documented default rho = 0.5, so R_c = s/rho; c is fixed, never trained. (3) For a level-1 residual r: u = exp_0^c(r), q_k = exp_0^c(a_k), a_k the unmodified baseline level-1 codebook. (4) D_k = d_c(u,q_k) = (2/sqrt(c)) artanh( sqrt(c) * ||(-u)(+)q_k|| ). (5) off_k = w * log(1 + b_k) with b_k the frozen, mean-normalized popularity-adjusted transition surplus. (6) k1 = argmin_k (D_k - off_k), ties to smallest index. (7) loss = baseline reconstruction + baseline commitment, unchanged, with straight-through; dequantization uses a_{k1} (baseline codebook vector) so the offset never moves the reconstruction point. (8) w = rho_off * mean_scale / max_k log(1+b_k), rho_off = 0.10 documented default, mean_scale = running mean of min_k D_k over epoch 1, frozen from epoch 2. (9) switches: BEHAVIOUR_OFF sets m_i = 1 for all i so b_raw_k is constant and the implementation forces off_k = 0 exactly; GEOMETRY_OFF sets c = 0 with exp_0^0 = identity and D_k = 2||u - q_k||, all else identical. Only the both-on arm is trained this round.
COST: +2 to 4 percent wall clock on the same frozen 3000-epoch, 4-card Stage-2 protocol plus the untouched Stage-3 protocol. Per step (batch 24556/24 = 1023 items, K1 = 256 level-1 codes, 24 steps per epoch, 3000 epochs): one exp_0^c on 1023 vectors, one exp_0^c on 256 codebook rows (cacheable within the step), and 1023*256 artanh evaluations replacing 1023*256 Euclidean reductions inside the level-1 distance only, i.e. roughly 0.26 M extra transcendental ops and 0.26 M extra flops per step against an encoder/decoder forward-backward over 1023 items; levels 2-3, the decoder and the surplus-table refresh (a 1023-length scatter-add per step) add nothing measurable.
HYPOTHESIS: If the coupling is real, items in the same directed-transition role share level-1 codes and high-surplus codewords absorb more items, so the level-2/3 prefixes see a behaviour-aligned first bit. Observable: level-1 usage histogram mass shifts toward high-surplus codewords, the training-split prefix hit rate of the true next item's level-1 code (predicted from the item's training transition neighbours) rises, and Stage3 test_recall@10 exceeds 0.065 (baseline 0.0555, best so far 0.0638). If the level-1 usage histogram, margin distribution and prefix hit rate are indistinguishable from the behaviour-off/Euclidean control values, the idea is dead.
RISKS: A constant per-codeword offset can collapse several codewords onto one attractor and starve the rest, moving recall the wrong way.; The popularity-adjusted surplus may be dominated by a handful of hub items despite the sqrt normalization.; Level 1 may be washed out because levels 2 and 3 carry most of the prefix information.; Fixing rho = 0.5 may place residuals too close to the ball origin for curvature to matter, so the geometry-off arm would look identical.; A single fixed w cannot be tuned under the policy, so it may be too weak to move the argmin or strong enough to destabilize it.; With one run and no seed repetition, seed noise may exceed the gain.
BEHAVIOR SIGNAL: Popularity-adjusted directed item-transition surplus, aggregated per level-1 codeword by soft assignment weights (a training-only graph-centrality signal over observed consecutive-consumption transitions).
BEHAVIOR COMPUTATION: From training-split sessions only, build directed counts t_ij for consecutive pairs (i consumed before j, self-pairs dropped). For each training item i with out-degree out_i: m_i = sum_j t_ij / sqrt(out_i * in_j + eps), which damps hubs on both sides. Each epoch, using the current level-1 codes of the training latents, p_ik = softmax_k(-D_ik / tau) with tau = 1 (distances are already in ball units; documented default), b_raw_k = sum_i p_ik * m_i / (sum_i p_ik + eps) over the 24556 training items of that epoch, then an EMA b_raw <- (1 - eta) * b_raw + eta * b_raw_epoch with eta = 0.1 documented default, initialized to 1, detached and no_grad, and normalized to the codeword mean: b_k = log(1 + b_raw_k / mean_k b_raw_k). Only training items and training transitions ever enter m_i and b_k.
LEAKAGE BOUNDARY: m_i and b_k are built exclusively from training-split transition counts and training-split item latents; validation and test interaction logs are never read when the table is built, and the table is detached from the graph so no gradient can route test information back into it. The table is only 256 floats keyed by codeword and derived from training co-occurrence, so no per-example validation or test signal can be memorized; Stage-3 evaluation consumes only the trained encoder and codebook, exactly as in the baseline.
HYPERBOLIC OPERATOR: Poincare ball of fixed negative curvature kappa = -c with c = (rho/s)^2 and R_c = 1/sqrt(c); exp_0^c(v) = tanh(sqrt(c)||v||) * v / (sqrt(c)||v||) and d_c(x,y) = (2/sqrt(c)) * artanh( sqrt(c) * ||(-x)(+)y|| ) with Mobius addition; the tangent-space Euclidean norm is not the Riemannian norm (||v||_{0,c} = 2||v||) and appears only inside exp_0^c.
HYPERBOLIC LOCATION: In the level-1 quantization step of Stage-2 training: the residual lift, the codebook lift and the level-1 assignment distance. Levels 2 and 3, the residual recursion, the reconstruction and the STE stay Euclidean and identical to baseline.
COUPLING PATH: A single scalar per codeword, b_k, computed from the directed-transition graph, enters the same expression that contains the curved distance, so the level-1 argmin cannot be formed without both: behaviour off makes the margin vanish, geometry off makes the geodesic distance Euclidean, and either change alters the same argmin and hence the same residual handed to level 2.
COUPLING EQUATION: k1 = argmin_k [ d_c( exp_0^c(r), exp_0^c(a_k) ) - w * log(1 + b_k) ], with w = rho_off * mean_scale / max_k log(1 + b_k), b_k the popularity-adjusted transition surplus and mean_scale the frozen epoch-1 mean of min_k d_c.
OBSERVABLES: Level-1 code usage histogram and its entropy (diagnostic, not a gate); fraction of test sequences whose true next item's level-1 code is among the top-2 codes predicted from the item's training transition neighbours (prefix behaviour predictability, diagnostic); the distribution of the level-1 assignment margin D_(1) - D_(2) net of the offset difference; Stage3 test_recall@10, which is the judgement.
ABLATION BEHAVIOR OFF: Same code with m_i = 1 for every item: b_raw_k is identical for all k, b_k = log 2 for all k, and the implementation forces off_k = 0 exactly, so the level-1 assignment is pure geodesic nearest neighbour in the derived ball. Present and correct in code, never trained this round.
ABLATION GEOMETRY OFF: Same code with c = 0: exp_0^0 is the identity and d_0(x,y) = 2||x - y||, so the level-1 score is 2||r - a_k|| - w * log(1 + b_k), with w recomputed against the Euclidean run's mean_scale so the switch stays scale-consistent. Present and correct in code, never trained this round.
ABLATION BOTH ON: The single formal run: fixed derived curvature c = (rho/s)^2 with the Poincare lift and geodesic distance, plus the frozen popularity-adjusted transition surplus offset with its derived weight w. Trained once, no sweep, no seed repetition, no early stopping.
SPEC EQUATIONS: s = rms(latents_train) c = (rho/s)^2 ; R_c = 1/sqrt(c) LIFT(v) = tanh(sqrt(c)*||v||) * v / (sqrt(c)*||v|| + 1e-12), with LIFT(0) = 0 MOBIUS(x,y) = ((1 + 2c<x,y> + c||y||^2) x + (1 - c||x||^2) y) / (1 + 2c<x,y> + c^2||x||^2||y||^2 + eps) DIST(x,y) = (2/sqrt(c)) * artanh( min( sqrt(c)*||MOBIUS(-x,y)||, 1 - 1e-6 ) ) # per step for each residual r: u = LIFT(r) q_k = LIFT(a_k) for k = 1..K1 D_k = DIST(u, q_k) score_k = D_k - off_k ; off_k = w * log(1 + b_k) k1 = argmin_k score_k   (ties -> smallest k) r_next = r - a_{k1}      # baseline recursion, unchanged loss = baseline_recon + baseline_commit    # unchanged, STE on a_{k1} # per epoch b_raw <- (1 - eta) * b_raw + eta * b_raw_epoch ; b_k = log(1 + b_raw_k / mean(b_raw)) # after epoch 1 mean_scale = running_mean(min_k D_k) ; w = rho_off * mean_scale / max_k log(1 + b_k)
SPEC INPUTS OUTPUTS: Inputs: level-1 residual batch r (B x d), baseline level-1 codebook a (K1 x d), frozen per-codeword surplus b (K1), the fixed curvature c, the derived weight w, and the two switches. Outputs: level-1 indices k1 (B), the level-1 residual passed to level 2 (B x d, baseline formula), and the unchanged baseline loss; side outputs are the diagnostics (usage histogram, margin statistics, prefix hit rate).
SAFEGUARDS: Clamp sqrt(c)*||MOBIUS(-x,y)|| to 1 - 1e-6 before artanh, implemented as 0.5*log((1+z)/(1-z)) in float32; explicit c == 0 and ||v|| == 0 branches so the geometry-off switch can never produce NaN (exp_0^0 = identity, d_0 = 2||.||); clamp the lifted radius to (1 - 1e-4)*R_c; detach and no_grad the surplus table and its EMA so no gradient reaches behaviour statistics; eps = 1e-8 in every denominator of m_i and b_raw; force off_k = 0 exactly under BEHAVIOUR_OFF rather than relying on cancellation; keep reconstruction dequantization on a_{k1} so the offset cannot create a train/eval mismatch; deterministic smallest-index tie-break; cache the K1 lifted codewords once per step.
END IDEA
