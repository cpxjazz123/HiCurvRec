IDEA: TAPERINNOV-RQ
TITLE: Depth-tapered Poincare curvature with a sign-inverted per-pair behaviour term at the suffix level, dispatched by balanced curved Sinkhorn
MOTIVATION: Uniform-strength curvature reproduced the measured first-order gain (hard Euclidean assignment error 16.39 -> 2.49/3.89, positive-hit 0.079 -> 0.12-0.26) but collapsed the third level (l3_collision 0.55-1.00, only 784 level-2 distinct prefixes in the OCCURV arm), and every such arm was rejected by the 35% gate. The geometric cause is that with one curvature magnitude and shrinking deep residuals r_l, the hyperbolic load u_l = sqrt(kappa_l)*s_l stays large, the level-3 residuals are pushed toward the ball boundary where Poincare distances saturate, and the argmin returns the same code for nearly every item. The behavioural cause is that a purely attractive behaviour term lets the suffix code copy the dominant successor suffix. The idea fixes the first by a curvature schedule whose load decays with the measured residual scale and the second by inverting the sign of the same per-pair behaviour affinity at the last level, with balanced dispatch so no single code can absorb the batch.
NOVELTY: Not a uniform curvature field (OCCURV-FIELD), not popularity-sized capacity cells (GEOCAP), not two-leg parallel transport (holonomy-path-behaviour-rq). Three elements are new here: (1) a per-level curvature kappa_l = u1^2/(s_1*s_l) whose hyperbolic load u_l = u1*sqrt(s_l/s_1) is DERIVED from the measured per-level residual RMS, so curvature effect is strong at level 1 and decays at level 3 and the ball is never approached near its boundary (tanh(u_l) <= tanh(0.5) always); (2) the SAME per-pair behaviour affinity matrix enters with OPPOSITE sign per level (+ attraction at prefix levels 1-2, - repulsion at suffix level 3), making the prefix behaviour-predictive and the suffix an innovation digit that cannot copy the successor's suffix code; (3) the assignment is a balanced curved Sinkhorn whose cost is curvature-conditioned, so code occupancy at level 3 is bounded by construction instead of by a repulsion loss.
CHANGE: The residual quantiser's assignment cost becomes a per-level curved cost whose curvature is re-derived every step from a measured residual scale, with a signed per-pair behaviour term added inside that cost, rescaled by a batch-derived weight and dispatched by log-domain balanced Sinkhorn; codeword positions used in reconstruction are the same points produced by the same exp map at the same per-level curvature, and the straight-through estimator is kept on the Sinkhorn soft assignment.
SPECIFICATION: L=3 levels, K=256 codewords per level, B~1023 items per step (24556/24), tangent codebook parameters E_l in R^{K x d}. Per step and per level l: (i) compute the Euclidean residual r_l(i) from the previous levels' tangent codewords; (ii) update the scalar s_l by EMA over the batch of RMS(r_l); (iii) set kappa_l = u1^2/(s_1*s_l) with the documented default u1 = 0.5 (chosen so the load sqrt(kappa_l)*s_l = u1*sqrt(s_l/s_1) <= 0.5 and artanh stays finite; load decreases with depth because s_l decreases); (iv) map residuals and codewords with the SAME map: u_l(i) = exp_0^{kappa_l}(r_l(i)), c_{l,k} = exp_0^{kappa_l}(E_l[k]); (v) form the normalised curved cost C_l[i,k] = d_{kappa_l}(u_l(i), c_{l,k})^2 / s_l^2; (vi) add the signed per-pair behaviour term sigma_l * alpha_l * Ab_l[k, h_l(succ(i))], sigma_l = +1 for l<3 and -1 for l=3, alpha_l = std_batch(C_l)/std_batch(B_l) (derived equalisation, no tuned weight); (vii) solve log-domain Sinkhorn M_l = C_l - alpha_l*sigma_l*B_l with row marginals 1 and uniform column marginals B/K, T=1 in normalised cost units, 30 fixed iterations; (viii) hard code = argmax_k P_l[i,k], gradient via straight-through y = gather(E_l, hard) + (P_l @ E_l - (P_l @ E_l).detach()). Per epoch, from the codes assigned in the previous epoch and the training-only transition matrix, rebuild h_l (item -> level-l code) and the K x K row-normalised code-pair affinity Ab_l (Ab_l[k,k'] = mass of transitions from items in code k to items whose successor lies in code k'), and pick succ(i) = argmax_j T(i,j) once from the training split. Formula signature: TAPERINNOV(L=3, K=256, u1=0.5, sinkhorn_iters=30, eps=1e-8) -> per level: (s_l, kappa_l, C_l, Ab_l, sigma_l, alpha_l) -> (P_l, hard_l) -> tangent codebook update and decoder input sum_l E_l[hard_l]. Output: three SID digits per item, the same codebook points used for reconstruction, and the recorded diagnostics (s_l, kappa_l, u_l, l3_collision, level-2 distinct prefixes, hard ER, positive-hit rate).
COST: Per step at the frozen scale: the Poincare distance matrix is unchanged in size (L*B*K = 3*1023*256 = 786k distances, each exp/artanh, already present in the curved baseline); new cost is the Sinkhorn, 30 alternating normalisations over three B x K matrices = 30*3*1023*256 ~ 23.6M elementwise/reduction ops, a few percent of one transformer step, plus one 1023x256 fp32 buffer per level (~1 MB each). Per epoch the behaviour statistics (h_l over 24556 items, succ cached once, Ab_l 256x256 accumulations) are accumulated from the existing forward passes with no extra forward, so ~1-2 ms per epoch. Overall wall clock +10 to 18% over the baseline for 3000 epochs on four cards, memory +~5%, no extra data pass, no extra training run.
HYPOTHESIS: The coupling is worth keeping only if, in the single coupled run, level-3 occupancy stops collapsing (l3_collision below the 0.35 admission gate, i.e. clearly under the 0.549 Euclidean baseline and far under the 0.943 OCCURV value) while the first-order gain survives (valid_l1_hard_er <= 4 and positive_hit_rate >= 0.12) and level-2 prefix diversity stays large (level2_distinct_prefixes in the thousands, not hundreds). If those hold and Stage3 test Recall@10 exceeds 0.065 (baseline 0.0555, best 0.0638), the mechanism is confirmed; if the taper preserves ER but l3_collision stays above 0.35, the saturation diagnosis is wrong; if l3_collision falls but ER regresses to baseline scale, the balanced dispatch is destroying the curvature gain and the suffix-level sign inversion is not the right dispersion device.
RISKS: Per-batch balanced dispatch is computed on ~1023 items and 256 codes (~4 items per code), so the training assignment is batch-dependent; argmin at evaluation may not reproduce the balanced occupancy and l3_collision could come back above the gate.; The suffix-level negative behaviour term fights the generative objective: if the Stage-3 generator relies on the last digit being correlated with the successor's last digit, recall can drop even though occupancy spreads.; The curvature schedule depends on an EMA of residual RMS; early in training the estimate is noisy, kappa_l can swing, and the level-1 separation gain seen in GEOCAP/OCCURV may be delayed or lost in the first few hundred epochs (no early stopping is allowed, so a bad transient is paid for).; When the level-3 code map is already collapsed, h_3(succ(i)) is nearly constant, so the signed behaviour term is nearly constant across k and does nothing; only the Sinkhorn balancing would then be doing the dispersion work.; alpha_l = std(C)/std(B) equalisation can make the behaviour term dominate when the curved cost becomes nearly degenerate, re-introducing instability in exactly the regime it is meant to fix.; The taper keeps the deepest level nearly flat geometrically, so the hyperbolic part of the contribution at level 3 is small and the two-level prefix may carry most of the curvature benefit; the mechanism then rests on the sign inversion plus balancing alone.
BEHAVIOR SIGNAL: Directed training-only item transitions aggregated to a per-pair code affinity: T(i,j) = row-normalised count of consecutive (i -> j) pairs inside training-split sequences, reduced per epoch to Ab_l[k,k'] = transition mass from level-l code k to the level-l code of the successor, plus the single cached successor succ(i) = argmax_j T(i,j).
BEHAVIOR COMPUTATION: From the training split only: one pass over training sequences before Stage-2 training builds sparse counts N(i,j) over consecutive pairs within a session, row-normalised with epsilon smoothing to T; succ(i) is cached once. During Stage 2, at the end of every epoch, the level-l hard codes of all 24556 training items are tallied from the epoch's own forward passes, and Ab_l is rebuilt as the row-normalised 256x256 matrix of transition mass from code k to the code containing succ(i); no validation or test interaction is ever read.
LEAKAGE BOUNDARY: Every behaviour quantity is a function of training-split sequence pairs and of model-internal quantities (residuals, hard code ids) of the training items only. succ(i), T and Ab_l are built before or during Stage-2 training from the training split; they are frozen and reused at validation/test time and are never recomputed from validation or test sequences. The curvature schedule uses s_l, an EMA of training-batch residual RMS. Validation is used only to record diagnostics (which are never admission gates) and test only for the final Recall@10, so no validation or test interaction can enter SID construction.
HYPERBOLIC OPERATOR: Poincare ball model of constant negative curvature -kappa_l, exponential map exp_0^{kappa_l}(v) = tanh(sqrt(kappa_l)*||v||)/(sqrt(kappa_l)*||v||) * v (and its inverse log_0), Poincare distance d_{kappa_l}(u,v) = (2/sqrt(kappa_l)) * artanh(sqrt(kappa_l)*||(-u) xor v||), with the per-level curvature kappa_l = u1^2/(s_1*s_l), u1 = 0.5, s_l = EMA of the RMS of the level-l tangent residual, so the load u_l = sqrt(kappa_l)*s_l = u1*sqrt(s_l/s_1) is <= 0.5 and strictly decreasing with depth.
HYPERBOLIC LOCATION: Inside the residual-quantiser assignment and codebook placement: every level's assignment cost is a Poincare squared distance at that level's curvature, the codeword positions c_{l,k} = exp_0^{kappa_l}(E_l[k]) are produced by the same map from the tangent parameters that the decoder consumes, and the curvature used for a level is recomputed each step from the measured residual scale of that level.
COUPLING PATH: One score, two divisors of the same decision: M_l[i,k] = C_l[i,k] - alpha_l*sigma_l*B_l[i,k], where C_l is the tapered curved distance and B_l is the per-pair behaviour affinity of code k with the level-l code of the item's top training successor; the sign is +1 for levels 1-2 and -1 for level 3. M_l feeds the balanced Sinkhorn whose argmax produces the SID digit and whose straight-through gather selects the same codeword positions used by the decoder. Setting the behaviour matrix to zero removes B_l and changes every digit; replacing d_{kappa_l} by the Euclidean distance (kappa_l -> 0) changes C_l and the codeword placement and therefore changes every digit; neither arm exists without the other inside the same score.
COUPLING EQUATION: M_l[i,k] = d_{kappa_l}( exp_0^{kappa_l}(r_l(i)), exp_0^{kappa_l}(E_l[k]) )^2 / s_l^2  -  alpha_l * sigma_l * Ab_l[ k , h_l(succ(i)) ],  with kappa_l = u1^2/(s_1*s_l), alpha_l = std_batch(C_l)/std_batch(B_l), sigma_l = +1 (l<L), -1 (l=L), hard_l(i) = argmax_k Sinkhorn_{T=1}(M_l)[i,k].
OBSERVABLES: Recorded per epoch and at the end of the single run: per-level residual RMS s_l and curvature kappa_l with the load u_l = sqrt(kappa_l)*s_l (must stay <= 0.5 and decrease from level 1 to level 3), level-3 code occupancy histogram and l3_collision (target below the 0.35 gate, clearly under the 0.549 Euclidean baseline), level2_distinct_prefixes (thousands, not hundreds), valid_l1_hard_er and positive_hit_rate on the validation split (hard ER <= 4, positive-hit >= 0.12), prefix behaviour predictability (fraction of items whose training successor shares the level-1-2 prefix), Sinkhorn marginal residual per level as a numerical health check, and finally Stage3 test Recall@10, which must exceed 0.065.
ABLATION BEHAVIOR OFF: The same code path with Ab_l forced to zero (or the behaviour weight alpha_l set to 0) so the cost is the tapered curved distance alone inside the same balanced Sinkhorn: no successor affinity, no signed suffix term, prefixes no longer behaviour-predictive and the suffix no longer dispersive. Present and exercised in unit tests, not trained.
ABLATION GEOMETRY OFF: The same code path with kappa_l -> 0 in every map and distance (exp_0 becomes the identity, d becomes the Euclidean distance) and the codewords used directly, with the behaviour term, the sign schedule, alpha_l and the Sinkhorn unchanged: this is the Euclidean quantiser with behaviour only. Present and unit-tested, not trained.
ABLATION BOTH ON: The single formal run: tapered Poincare curvature per level (kappa_l = u1^2/(s_1*s_l)) plus the signed per-pair behaviour term plus balanced curved Sinkhorn dispatch, straight-through preserved, 3000 Stage-2 epochs on four cards, then the frozen Stage-3 protocol, one seed, no early stopping.
SPEC EQUATIONS: Inputs per step: batch of B items, tangent codebooks E_1,E_2,E_3 in R^{256 x d}, EMA scales s_1,s_2,s_3, per-epoch Ab_1,Ab_2,Ab_3 in R^{256x256}, cached succ(i), h_l. 1) r_1(i) = z(i); for l>1: r_l(i) = r_{l-1}(i) - straight_through(E_{l-1}[hard_{l-1}(i)]). 2) s_l <- (1-rho)*s_l + rho*RMS_batch(r_l) with rho = 1/24 (one epoch horizon, documented default). 3) kappa_l = u1^2/(s_1*s_l), u1 = 0.5. 4) u_l(i) = exp_0^{kappa_l}(r_l(i)); c_{l,k} = exp_0^{kappa_l}(E_l[k]). 5) C_l[i,k] = d_{kappa_l}(u_l(i), c_{l,k})^2 / s_l^2. 6) B_l[i,k] = Ab_l[k, h_l(succ(i))]; alpha_l = std(C_l)/std(B_l + eps). 7) M_l = C_l - alpha_l*sigma_l*B_l, sigma = (+1,+1,-1). 8) log-domain Sinkhorn, 30 iterations: f <- log(1) - logsumexp_k(M_l[i,k] + g_k); g <- log(B/K) - logsumexp_i(M_l[i,k] + f_i); P_l = exp(M_l + f + g). 9) hard_l = argmax_k P_l[i,k]; y_l = gather(E_l, hard_l) + (P_l @ E_l - (P_l @ E_l).detach()); decoder input = y_1 + y_2 + y_3; commitment and reconstruction losses in tangent space as in the baseline. 10) every epoch: update h_l from hard codes of all training items and rebuild Ab_l from T and succ; never from validation or test.
SPEC INPUTS OUTPUTS: Takes: item encoder output z, the three tangent codebooks E_l (256 x d each, trainable), the training-only transition matrix T (sparse, item x item), cached succ(i), an EMA residual-scale vector s in R^3, prior-epoch hard codes h_l, and the batch's residual tensors. Returns: per level a soft assignment P_l (B x 256), a hard code id hard_l (B), the straight-through codeword vector y_l fed to the decoder, and the recorded scalars s_l, kappa_l, u_l, plus the epoch-level code-pair affinity Ab_l and occupancy diagnostics.
SAFEGUARDS: Log-domain Sinkhorn with max-subtraction and 30 fixed iterations, eps = 1e-8 on all log and division arguments; column marginals uniform B/K with a guard that K <= B so the problem is feasible; NaN/Inf check after each iteration with fallback to the pure curved-cost argmin for that step; clamp ||r_l|| so sqrt(kappa_l)*||r_l|| <= tanh^{-1}(1 - 1e-6) and clamp s_l to [1e-6, 1e6]; kappa_l recomputed from an EMA so a single bad batch cannot swing the curvature; the negative suffix behaviour term is bounded by alpha_l and standardised per batch so it cannot dominate the curved cost; the level-3 sign inversion is structural (sigma_3 = -1) and its magnitude equalisation is measured per batch, never tuned; straight-through preserves the hard code as the forward value; the behaviour matrices are frozen at evaluation so validation and test cannot update any SID; and hard-ER, positive-hit and l3_collision are recorded as diagnostics only, never used as admission gates.
END IDEA
