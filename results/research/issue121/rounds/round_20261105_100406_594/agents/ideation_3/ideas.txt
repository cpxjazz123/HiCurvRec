IDEA: ANCHORLADDER-RQ
TITLE: Behaviour-anchored, depth-decayed curvature: each item's residual is quantised in the Poincare chart centred on its own behaviour neighbourhood, with curvature falling to exactly Euclidean at level 3.
MOTIVATION: The three measured curvature arms show that curvature in the RQ assignment buys a real first-order gain (l1 hard ER 2.49-3.89 and positive hit 0.12-0.26 versus baseline 16.39/0.079) but that the same curvature strength at every level funnels the deep residual into a few codewords (l3_collision 0.549 and 0.943), which is why both arms failed the 35% gate. The root cause is geometric: with one fixed chart every item shares the same attractor (the chart centre / the far-boundary region), so residuals of different behaviour groups map to the same level-3 codeword. The fix must keep the curved separation at shallow depth, remove the shared attractor, and end in a genuinely Euclidean deep level.
NOVELTY: Not holonomy (no two-leg transport), not GEOCAP (no popularity-sizing of codeword radii, no per-codeword capacity), not OCCURV-FIELD (no per-codeword learnable curvature field, and no uniform strength across levels). Here the behaviour signal is a POSITION, not a weight and not a capacity: the directed-transition neighbourhood of each item defines the base point of the exponential/log map used to compare that item's residual with the codebook, and the curvature magnitude is a derived ladder (-1, -0.5, 0) that reaches exactly Euclidean at level 3. There is no mixing coefficient to tune: the only coupling constant is the curvature itself, and it is a fixed unit default with a depth rule derived from L=3.
CHANGE: At every RQ level the residual and the codebook are pushed into the Poincare ball by the same curvature-c argument exp^c, and the codeword is chosen by the tangent-space distance measured at a per-item base point qbar, which is the exp^c image of the weighted mean codebook vector of that item's training-only behaviour neighbours. Curvature decreases with depth and is exactly zero at level 3, so the deep assignment is Euclidean while the shallow assignments stay curved and behaviour-specific.
SPECIFICATION: 1) Offline, from TRAINING interactions only, build directed transition counts C[i][j] over session windows; score pmi(i,j)=log( T*C[i][j] / (Cout[i]*Cin[j]+alpha) ) with alpha=1, T=total transitions; keep the top m=8 neighbours per item and normalise w_ij. 2) Constants: kappa=1 (unit curvature, documented default), c_l = -kappa*(L-l)/(L-1) for l=1..L, L=3 gives c=(-1,-0.5,0); K and d unchanged from the baseline RQ-VAE; commitment beta=0.25 unchanged. 3) Per step, for each level l: p = exp^{c_l}(r_l) (residual into the ball), q_k = exp^{c_l}(e_{l,k}) (codebook into the SAME ball with the SAME map), anchor a = sum_j w_ij * ehat_{l,z_j} using a lagged hard-assignment buffer, qbar = exp^{c_l}(a), then z_l = argmin_k (2/(1-c_l|qbar|^2)) * ||log^{c_l}_{qbar}(p) - log^{c_l}_{qbar}(q_k)||. 4) r_{l+1} = r_l - e_{l,z_l}; reconstruction uses the same ball positions decoded by log^{c_l} (which returns e_{l,z_l}); straight-through quant_l = e_{l,z_l}.detach() + r_l - r_l.detach(). 5) Buffer A[l,i] is updated after each optimiser step with the current z_l(i); unseen entries hold -1, i.e. origin anchor, which is the deterministic epoch-1 warm-up (no schedule to tune).
COST: Offline graph build once: O(number of transitions) with 24556 items, 8 stored neighbours each, ~200k edges, negligible memory. Per step at the frozen scale (24 steps per epoch, 3000 epochs, B=256, K=256, d=64, L=3): 3*256*8 gathers of 64-d codebook rows (~0.4 MFLOP) plus 3*256*256 pairs of Mobius-and-artanh evaluations (~1e8 flops) = roughly 3-5% of one transformer step; codebook parameters and memory unchanged, extra state is a 3x24556 int16 buffer; no extra epochs.
HYPOTHESIS: It is worth keeping iff curvature-at-shallow-plus-Euclidean-at-deep retains the first-order gain while restoring level-3 occupancy. Observable: valid_l1_hard_er stays well below the 16.39 baseline and at or under 4, positive_hit_rate at or above 0.12, level2_distinct_prefixes in the thousands rather than 1, l3_collision at or under 0.35, refinement at or above 2.3 bits, and Stage3 test_recall@10 above 0.065 in the single frozen run.
RISKS: The lagged assignment buffer can freeze an early bad partition while anchors keep reinforcing it (origin anchors until first sighting mitigates, but a bad first epoch is still possible).; Behaviour neighbours may be too dense or too sparse for some items, so anchors are noisy.; Behaviour-coherent prefixes at levels 1-2 could homogenise the level-3 residual so that even the Euclidean level-3 assignment collides.; If the encoder residual norm collapses, exp^c maps everything near the origin where curvature is locally negligible and the mechanism degrades to baseline.; Single run with no seed repetition: seed noise is part of the uncertainty.
BEHAVIOR SIGNAL: Directed item transitions (sequential co-consumption) from the training split, popularity-adjusted by pointwise mutual information, used per neighbour PAIR: each pair (i,j) contributes its weight to item i's base point.
BEHAVIOR COMPUTATION: From the Stage-2 training interactions only: for each user session every ordered pair (i followed by j within the session window) increments C[i][j]; Cout, Cin and T are the row, column and total sums; pmi(i,j) = log(T*C[i][j]/(Cout[i]*Cin[j]+1)); top-8 j per i by pmi; weights w_ij = pmi_ij^+ / sum_j' pmi_ij'^+, stored as int16 index arrays plus a float weight array of size 24556x8. No validation or test event is read at any point.
LEAKAGE BOUNDARY: The transition graph is built before Stage 2 training from training split sequences only; validation and test interactions are never parsed by the SID builder; anchors average codebook vectors of training items only; and the codebooks themselves are fitted on training item content/embeddings only, so no validation or test interaction can influence a SID, an anchor or a codeword position.
HYPERBOLIC OPERATOR: Poincare-ball exponential and logarithmic maps with fixed negative curvature magnitude per level, c_l = -kappa*(L-l)/(L-1) with kappa=1, i.e. c = (-1.0, -0.5, 0.0), combined with Mobius addition and the conformal factor lambda_c = 2/(1-c|q|^2): exp^c(v) = tanh(sqrt|c||v|)/(sqrt|c||v|) * v, log^c_a(x) = (2/sqrt|c|)*artanh(sqrt|c| |(-a) (+) x|) * ((-a)(+)x)/(sqrt|c| |(-a)(+)x|), whose c->0 limit is the identity/translation.
HYPERBOLIC LOCATION: In the quantiser, at every RQ level: the residual is mapped into the ball by exp^{c_l} before assignment, the codebook is mapped by the same exp^{c_l}, the assignment metric is the curvature-weighted tangent norm at the behaviour base point, and reconstruction decodes the chosen ball position with log^{c_l}. The encoder and decoder are untouched apart from the quantised code they receive.
COUPLING PATH: behaviour pairs -> weighted mean of neighbour codebook vectors -> base point qbar_{l,i} = exp^{c_l}(a_{l,i}) -> the log map at that base point produces both the residual tangent vector and every codeword tangent vector -> their difference, scaled by the curvature conformal factor, is the assignment score -> argmin selects the level-l codeword -> the residual recursion feeds level l+1. Removing behaviour (qbar=0) changes the score to the plain Poincare geodesic distance; removing curvature (c=0) makes the base point cancel identically so the score is the Euclidean distance; either removal changes the selected codeword and therefore the SID.
COUPLING EQUATION: s_l(i,k) = (2/(1 - c_l |qbar_{l,i}|^2)) * || log^{c_l}_{qbar_{l,i}}( exp^{c_l}(r_{l,i}) ) - log^{c_l}_{qbar_{l,i}}( exp^{c_l}(e_{l,k}) ) ||_2, with qbar_{l,i} = exp^{c_l}( sum_{j in N(i)} w_ij * e_{l, z_l(j)} ), z_l(i) = argmin_k s_l(i,k), and c_l = -(L-l)/(L-1).
OBSERVABLES: valid_l1_hard_er (expect <=4, target 2.5-3.5), positive_hit_rate (expect >=0.12, target >=0.20), level2_distinct_prefixes (expect thousands, not 1 and not 784-with-l3-collapse), l3_collision (must be <=0.35), refinement bits (>=2.3), Stage3 test_recall@10 (>0.065), plus the recorded-only behavioural diagnostics (prefix coherence, behaviour adjacency of SIDs, transfer predictability) which never gate admission.
ABLATION BEHAVIOR OFF: All neighbourhoods set to empty, hence a_{l,i}=0, qbar = origin, and s_l reduces to the ordinary Poincare geodesic distance to the codeword with the same curvature ladder: a layer-decayed curved RQ with no behaviour. The code path exists and is unit-tested; no arm is trained.
ABLATION GEOMETRY OFF: c_l = 0 at every level, so exp and log are the identity/translation, the qbar term cancels exactly in the difference, and s_l becomes ||r_{l,i} - e_{l,k}||_2, i.e. exactly the baseline Euclidean RQ-VAE assignment. The switch exists in code; no arm is trained.
ABLATION BOTH ON: The full mechanism: c = (-1,-0.5,0) plus per-item behaviour anchors qbar_{l,i}, giving s_l(i,k) = lambda_{c_l}(qbar) * ||log^{c_l}_{qbar}(p_i) - log^{c_l}_{qbar}(q_k)||. This single run is the only run performed.
SPEC EQUATIONS: Input item i with encoder output r_1 in R^d; codebooks E_l in R^{K x d}; neighbours (idx_i in Z^8, w_i in R^8). For l = 1..3: c = -(3-l)/2; p = exp_c(r_l); a = sum_{n=1..8} w_i[n] * E_l[ buffer_l[ idx_i[n] ] ] (missing entries skipped, weights renormalised); qbar = exp_c(a); if c>0: qbar = qbar * min(1, 0.95/(sqrt(c)*|qbar|)); for k=0..K-1: q = exp_c(E_l[k]); u_p = log_c(qbar, p); u_q = log_c(qbar, q); s[k] = (2/(1-c*|qbar|^2)) * |u_p - u_q|_2; z_l = argmin_k s[k]; qs = E_l[z_l]; quant_l = qs.detach() + r_l - r_l.detach(); r_{l+1} = r_l - qs; recon_code += quant_l; after the optimiser step buffer_l[i] = z_l. Loss = ||x - Decoder(sum_l quant_l)||^2 + 0.25 * sum_l ||r_l - qs_l||^2 (unchanged baseline losses). SID(i) = (z_1, z_2, z_3).
SPEC INPUTS OUTPUTS: Inputs: encoder residual r_l (B x d), per-level codebook E_l (K x d), curvature ladder c_l, behavioural neighbour indices and weights (B x 8 each), lagged assignment buffer (3 x 24556). Outputs: hard codes z_l (B,) per level, straight-through quantised vectors quant_l (B x d), updated buffer entries, and the SID tuple per item; the decoder interface is unchanged.
SAFEGUARDS: Mobius-addition denominators clamped at 1e-6; artanh arguments clamped to 1-1e-6; ball coordinates clipped to radius 0.95/sqrt|c| (a scale-relative bound derived from the curvature, not a swept constant); c=0 levels take a dedicated Euclidean branch so no division by sqrt|c| can occur at level 3; anchors and the assignment buffer are fully detached (stop-gradient) so no gradient flows through the argmin or across items; buffer entries initialise to -1 giving an origin anchor (deterministic warm-up) and missing neighbours are dropped with weight renormalisation; exp/log evaluated with the clamped forms and a finite-value assertion on s before the argmin, falling back to the Euclidean branch for a batch element if a non-finite score appears; commitment beta, codebook size K, width d, epoch count and the Stage-3 protocol are all inherited unchanged.
END IDEA
