IDEA: lorentz_prefix_mass
TITLE: Fit hierarchical code occupancy to training continuation mass in Lorentz space
MOTIVATION: Flat item reconstruction allocates RQ capacity without regard to how much next-item probability a prefix needs to distinguish; popular continuation regions can consume disproportionate prediction mass.
NOVELTY: This does not add successor geometry to each item's code score or steer residuals. It uses training-only continuation probability mass as a differentiable target for the occupancy of *entire code-prefix subtrees*, and matches that mass using Lorentzian subtree prototypes.
CHANGE: At each RQ level, derive a fixed continuation-mass target for each partial SID prefix from training transitions, and train prefix prototypes so their Lorentzian soft occupancy matches that distribution. The occupancy gradient changes the codebook parameters that determine the discrete prefixes.
SPECIFICATION: Build assignments p_i^l(k) with a temperature-softmax of negative Lorentz distances from current residual points to level-l code points; define soft prefix mass m_p^l as the sum over items of w_i times the product of their assignments along prefix p. Set w_i to a smoothed training continuation mass (defined below), normalize w to mean one, and minimize L_occ=Σ_l KL(stopgrad(t^l)||m^l), where t_p^l is the normalized training-only probability mass of transitions whose source item has prefix p. Compute m with differentiable products and normalize with epsilon. Keep baseline reconstruction and commitment losses; hard SID export remains ordinary argmin RQ.
COST: One training adjacency pass O(E_train), sparse prefix-target tables, plus soft assignment already comparable to baseline. At frozen full-item scale 24,556×24×3,000=1,768,032,000 item-stage evaluations; the added operation is O(BLK) for minibatch B, L levels, K codes, plus O(number of observed prefixes) target aggregation. Expect about 5–15% tokenizer wall-clock overhead with sparse prefix accumulation; Stage3 unchanged.
HYPOTHESIS: Training continuation mass has useful hierarchical structure that static content loss underrepresents; both-on should shift codebook gradients and prefix populations toward predictive continuation regions and improve validation-selected Stage3 test Recall@10, with target >0.065. Verify changed prefix occupancies and parameter updates, not just SID quality.
RISKS: Mass matching may merely encode popularity, overwhelm reconstruction, or create a few overloaded prefixes; soft products can vanish at deep levels; target counts may be sparse. Tune a small loss-weight grid on validation and report popularity-stratified recall.
BEHAVIOR SIGNAL: Training-only outgoing continuation mass per source item and per resulting SID prefix.
BEHAVIOR COMPUTATION: On train.parquet only, form within-user chronological adjacent pairs i→j. Set q_i=log(1+outdegree_i) and edge weight a_ij=count(i→j)/(sqrt(1+train_item_frequency(j))); define w_i=1+q_i and prefix target t_p^l proportional to Σ_i w_i·Σ_j a_ij for items i assigned under the current prefix p, with targets updated only from training-derived counts and frozen baseline prefix assignments (recommended to avoid target drift). Normalize targets separately per level.
LEAKAGE BOUNDARY: All edge counts, item frequencies, source weights, and baseline assignments are constructed from training rows only; validation/test interactions are not used in target formation, SID fitting, or cache updates. Evaluate held-out Stage3 splits only after the tokenizer and SIDs are frozen.
HYPERBOLIC OPERATOR: Lorentz-hyperboloid geodesic distance d_L at fixed curvature -κ, κ>0; use Lorentz exponential map at the origin for residual and code points.
HYPERBOLIC LOCATION: The soft code assignment probabilities used to compute differentiable subtree occupancies, and thus the prefix-mass training gradient in Stage2 RQ-VAE.
COUPLING PATH: Train transition mass defines the target distribution over prefixes; Lorentzian distances define soft code memberships and their multi-level prefix occupancy; the KL gradient moves code parameters until geometry-induced memberships better match behavior mass.
COUPLING EQUATION: p_i^l(k)=softmax_k[-d_L(exp_o(r_i^l),exp_o(c_k^l))²/τ]; m_p^l=Σ_i w_i Π_{s≤l}p_i^s(p_s); L_occ=Σ_l KL(t_beh^l || m_Lorentz^l). The behavior target t_beh and curved-distance-generated occupancy m_Lorentz meet in the same differentiable objective.
OBSERVABLES: Nonzero, finite gradients to codebooks/encoder; changed per-level hard prefixes relative to baseline; closer training-only prefix mass calibration; and, decisively, matched Stage3 test Recall@10. Compare all three required arms under identical selection and seeds.
ABLATION BEHAVIOR OFF: Set t_beh to the baseline empirical occupancy target independent of transition weights (or w_i=1 and t from item-uniform mass), while retaining Lorentz distances, soft occupancy, and loss weight.
ABLATION GEOMETRY OFF: Replace exp_o and d_L by matched-dimensional Euclidean squared distances in assignment probabilities; retain identical transition-derived targets, τ, objective and parameter budget.
ABLATION BOTH ON: Use train-only transition-mass targets and Lorentzian soft code assignments/prefix occupancy; export ordinary hard RQ SIDs and evaluate the locked Stage3 protocol.
SPEC EQUATIONS: For hyperboloid signature (-,+,...), <X,Y>_L=-X0Y0+Σ_{d>0}XdYd; d_L(X,Y)=acosh(max(1,-κ<X,Y>_L))/sqrt(κ). For each level l, x_i^l=exp_o(r_i^l), q_k^l=exp_o(c_k^l), p_i^l=softmax(-d_L(x_i^l,q_k^l)^2/τ). For prefix p=(k1,...,kl), m_p^l=ε+Σ_i w_i∏_{s=1}^l p_i^s(ks), normalize m over p. Freeze t_p^l from train-only baseline hard SID assignments and transition masses; L=L_base+λΣ_l KL(t^l||m^l). Stop gradient through t. Use straight-through hard argmin for normal RQ forward/export; soft occupancy is a training auxiliary directly shaping the same code vectors.
SPEC INPUTS OUTPUTS: Inputs: training sequences, frozen baseline SIDs for target aggregation, train item frequencies, current residuals and codebooks, κ, τ, λ. Outputs: frozen per-level prefix target tables, differentiable occupancy loss and gradients, then hard per-item RQ digits/SIDs.
SAFEGUARDS: Compute Lorentz vectors in float32/64; project to future hyperboloid after updates; clamp acosh argument to ≥1+ε and exp-map tangent norms; use log-domain products or clamp p≥ε at deeper levels; normalize t/m with epsilon and smooth rare prefixes; cap w_i and λ; monitor gradient norms, occupancy entropy and reconstruction; deterministic tie-breaking. Keep target table frozen to baseline assignments to prevent feedback loops.
END IDEA

IDEA: lorentz_user_cohort_margin
TITLE: Preserve cross-user successor contrasts with a Lorentzian pairwise code margin
MOTIVATION: A target item can follow similar textual items for one user cohort and a different set for another; ordinary itemwise quantization can erase these user-conditioned distinctions even when next-item prediction needs them.
NOVELTY: Rather than a per-item branch vector or successor barycenter, this uses pairwise contrastive comparisons between same-target transitions from different users, with the contrast margin defined by hyperbolic distance between quantized source representations. It is a relational training signal, not a behavior term appended to Euclidean nearest-code assignment.
CHANGE: Sample pairs of training examples with the same next item but different preceding user-context cohorts; encourage the source-item SID representations to preserve the observed cohort contrast at each RQ level via a Lorentzian geodesic margin. The contrast term acts on the actual residual/code representation used to construct SIDs.
SPECIFICATION: From each train transition (u,i→j), form context vector h_u,i as the mean of frozen Stage1 embeddings of up to the previous 5 train items, excluding j. For same target j, pair contexts from different users; define y_ab=1 if their contexts fall in different deterministic training-only k-means cohorts, else 0. Let z_ab be their source-item quantized Lorentz points at a selected level; optimize L_pair= y·max(0,m-d_L(z_a,z_b))² +(1-y)·max(0,d_L(z_a,z_b)-M)² with 0<m<M, sampled balanced pairs. To avoid pulling identical source item copies apart inconsistently, pair only distinct source items; use the item's code representation as z.
COST: One train transition/context preprocessing pass O(E_train·d), cohort clustering on sampled contexts, then O(Pd) Lorentz pair distances per step for P sampled pairs. At frozen scale 24,556 items ×24 steps/epoch ×3,000 epochs, cache transition pairs and draw e.g. P=2B per minibatch; expect 5–20% overhead depending on pair count/dimension, no Stage3 inference cost.
HYPOTHESIS: For targets with multiple user-context cohorts, the cohort distinction is predictive rather than noise; preserving it in curved code representations will change relevant SID digits and improve validation-selected Stage3 test Recall@10 toward/above 0.065. Confirm that pairwise distance margins and held-out-within-train cohort-conditioned next-item diagnostics change alongside test recall.
RISKS: Same-target cohort labels may reflect sampling noise, item popularity, or history length; the pair loss can conflict with semantic reconstruction or over-separate paraphrastic items. Sparse targets yield few reliable pairs; cohort clustering can be unstable.
BEHAVIOR SIGNAL: Cross-user context cohort identity for transitions into a shared next item.
BEHAVIOR COMPUTATION: Using only train sequences, enumerate (user, source i, target j) adjacent transitions; context is mean Stage1 vector of preceding up-to-five distinct training items. For each target j with ≥20 transitions, run deterministic k-means (K=min(4, floor(n_j/5))) on context vectors and label each transition; pair distinct source items with the same target and different cohort labels as positives, same cohort as negatives. Exclude users/targets below support threshold.
LEAKAGE BOUNDARY: Build contexts, target groupings, cohort centroids/labels and pairs strictly from train rows and training-period histories; freeze them before Stage2 fitting. Do not use validation/test targets, user histories, labels or interaction statistics for pairs or SID assignment.
HYPERBOLIC OPERATOR: Lorentz geodesic distance on curvature -κ, κ>0, between origin-exp-mapped quantized source representations.
HYPERBOLIC LOCATION: A contrastive margin loss on the level-l quantized item points; gradients pass through Lorentz distance to the encoder/codebook that produces the SID digits.
COUPLING PATH: Training user-context cohorts determine positive/negative pair labels; those labels select the margin branch applied to Lorentz distance between the exact quantized representations underlying the SIDs, changing their codebook/encoder updates.
COUPLING EQUATION: L_pair(a,b)=1[y_diff]·max(0,m-d_L(exp_o(q_a),exp_o(q_b)))² + 1[y_same]·max(0,d_L(exp_o(q_a),exp_o(q_b))-M)², where y_diff comes only from training-user context cohort labels.
OBSERVABLES: Pair margins become satisfied without reconstruction collapse; cohort-conditioned hard SID distances/assignments change; Stage3 test Recall@10 improves versus both toggles. Report performance by target support and cohort multiplicity.
ABLATION BEHAVIOR OFF: Shuffle cohort labels within each target while preserving class counts and all geometry/loss settings; this destroys user-behavior correspondence while retaining the same pair budget.
ABLATION GEOMETRY OFF: Replace Lorentz exp/distance by Euclidean representation and Euclidean norm in the same pair margin, keeping labels, dimensions, pair samples and margin calibration matched.
ABLATION BOTH ON: Train with the unshuffled train-only cohort labels and Lorentz geodesic margin, alongside baseline RQ-VAE losses; export hard SIDs and run the same Stage3 evaluation.
SPEC EQUATIONS: Let q_i^l be the straight-through quantized tangent representation at level l; map X_i=exp_o^{(-κ)}(q_i^l) to the Lorentz sheet. d(X,Y)=acosh(max(1,-κ<X,Y>_L))/sqrt(κ). Given pair label y=1 for different cohorts, L_pair=y[m-d]_+² +(1-y)[d-M]_+². Total objective L_base+λ L_pair; sample balanced pairs and average. Hard SID indices remain standard nearest-code indices, but the pair gradient updates the same encoder/codebook points and therefore can alter assignments on subsequent steps.
SPEC INPUTS OUTPUTS: Inputs: train-only transitions and contexts, frozen Stage1 item embeddings, deterministic per-target cohort labels/pair sampler, RQ-VAE level representations/codebooks, κ,m,M,λ. Outputs: pair loss/gradients and updated code parameters; ordinary hard SID digits.
SAFEGUARDS: Require target support and multiple cohorts; cap pairs per target/user to avoid popularity domination; L2-normalize context vectors before clustering; fix clustering seed and label ordering; compute Lorentz distance in float32/64 with acosh clamp and hyperboloid projection; clip gradients; use zero pair loss for invalid/rare items; monitor reconstruction and pair-label balance. Set m<M with margins selected on training-only distance quantiles and λ via validation protocol.
END IDEA
