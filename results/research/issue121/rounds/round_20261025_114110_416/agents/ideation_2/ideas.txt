IDEA: branch_shell
TITLE: User-branching-calibrated hyperbolic code shells
MOTIVATION: Items that occur after sharply different user-interest branches need semantic codes that preserve those distinct continuation roles, while generic item similarity can collapse them.
NOVELTY: Rather than append a graph feature, smooth embeddings, or add a separate hyperbolic loss, this changes the actual residual-code assignment metric: a train-only continuation-branch statistic determines each item's radial target in a negatively curved space.
CHANGE: Estimate item continuation branching from training sequences, map its normalized entropy to a desired hyperbolic radius, and jointly assign each item to the residual codeword minimizing a radius-calibrated Poincare distance. The resulting selected codeword is the RQ-VAE SID token and the assignment distance supplies the quantization gradient.
SPECIFICATION: For training sequences only, estimate smoothed next-item distributions p(j|i) from consecutive items; define h_i=H(p(.|i))/log(max(2, number_of_observed_successors_i)), with h_i=0 for no observed successors. Let z_i be the current Euclidean encoder output, map to ball x_i=exp^c_0(z_i), and set target radius rho_i=rho_min+(rho_max-rho_min)h_i. For each residual stage s and residual point x_i^s, project x_i^s to the ball, compute d_c(x_i^s,c_sk)^2 + lambda_r*(d_c(0,c_sk)-rho_i/S)^2 for each codeword k, choose argmin k, subtract the selected codeword via the existing residual update, and train with straight-through quantization plus commitment loss. Use shared fixed c>0; rho_i/S expresses a per-stage shell target, not a claim that residual radii add exactly.
COST: One train-only transition count pass O(number of training transitions), plus O(N*K*D) distance work per quantization stage, same asymptotic assignment cost as baseline and typically a modest constant-factor increase for Poincare distances and one scalar penalty. At frozen scale N=24,556, 24 steps/epoch, 3,000 epochs: 73,668,000 item-stage opportunities per stage over training; the extra radius/penalty is O(1) per item-codeword comparison, while distance computation is the dominant added work. Cache h_i and rho_i; no user graph is traversed during epochs.
HYPOTHESIS: Continuation branching varies meaningfully across items and is reflected in useful semantic hierarchy: higher-branching items should occupy broader/deeper code regions and yield more predictable generative prefixes, ultimately improving Stage3 test Recall@10, with a keep criterion of Recall@10 > 0.065 and a gain over both ablations.
RISKS: The static item-level branch entropy may conflate genuine multi-interest branching with sparse/noisy observations; radial pressure may distort reconstruction or cause codebook underuse. Fixed curvature and shell scale require tuning on training-only diagnostics/validation protocol without using validation interactions to construct SIDs.
BEHAVIOR SIGNAL: Directed item continuation branching entropy.
BEHAVIOR COMPUTATION: From the training split only, count consecutive item pairs (i,j) within each user's chronologically ordered training history, obtain smoothed p(j|i), then compute normalized outgoing entropy h_i. Do not use validation/test sequences or their item transitions.
LEAKAGE BOUNDARY: Freeze the training-derived h_i lookup before RQ-VAE SID export. Validation and test interactions are excluded from counts, smoothing support, entropy, shell targets, codebook assignments, and any SID-generation input; validation may only be used for model selection under the existing protocol.
HYPERBOLIC OPERATOR: Squared Poincare-ball distance d_c^2 at fixed negative curvature -c, plus geodesic distance from origin d_c(0,c_sk) as a radial shell measure; exp^c_0 maps encoder vectors into the ball.
HYPERBOLIC LOCATION: The residual quantizer's codeword assignment and straight-through quantization objective at every RQ stage.
COUPLING PATH: Training transitions -> h_i -> rho_i -> shell-calibrated Poincare codeword argmin -> selected residual codeword and SID; setting h_i constant removes item-specific shell calibration, while replacing d_c with Euclidean distance removes curved assignment geometry.
COUPLING EQUATION: k_i^s = argmin_k [ d_c(x_i^s,c_sk)^2 + lambda_r*(d_c(0,c_sk)-rho_i/S)^2 ], where rho_i=rho_min+(rho_max-rho_min)*h_i and d_c is the negatively curved Poincare distance.
OBSERVABLES: SID code assignments should shift systematically with h_i and codeword geodesic radii; quantizer gradients/codebook updates should change; measure prefix next-item accuracy and Stage3 test Recall@10, targeting >0.065. Report code utilization and reconstruction only as diagnostics, not admission criteria.
ABLATION BEHAVIOR OFF: Replace h_i by the training-item population mean (equivalently remove item-specific branch calibration), preserving the same hyperbolic distance and parameterization.
ABLATION GEOMETRY OFF: Keep the same training-derived h_i and radius penalty, but replace Poincare distances/maps/radii with Euclidean distance and Euclidean norm using matched scale.
ABLATION BOTH ON: Use training-only h_i, exp map, fixed-curvature Poincare distance and radial shell penalty in every residual code assignment as specified.
SPEC EQUATIONS: Counts n_ij from training-only consecutive pairs; p(j|i)=(n_ij+alpha)/(sum_l n_il+alpha*|N_i|) over observed successor support N_i; h_i=H(p_i)/log(max(2,|N_i|)) (set h_i=0 when |N_i|<2); rho_i=rho_min+(rho_max-rho_min)h_i. x_i=exp^c_0(z_i). At stage s, select k*=argmin_k d_c(x_i^s,c_sk)^2+lambda_r[d_c(0,c_sk)-rho_i/S]^2; q_i^s=c_sk*; update residual with the baseline RQ-VAE rule and optimize its reconstruction/commitment losses using straight-through gradients. Constants alpha, c, lambda_r, rho bounds are fixed before comparison and identical across behavior ablations where applicable.
SPEC INPUTS OUTPUTS: Inputs are training-only user-ordered item sequences, encoder outputs, residual codebooks, fixed c and shell hyperparameters. Outputs are cached h_i/rho_i, selected residual code indices at each stage, and the resulting SID sequence.
SAFEGUARDS: Clamp encoder/map inputs inside radius (1-epsilon)/sqrt(c); use stable log1p/atanh distance evaluation and epsilon denominators; clamp computed distances and h_i to finite ranges. Use a minimum successor count or smoothing, explicitly set under-supported items to h_i=0, normalize by log support only for support >=2, initialize codewords inside the ball, and monitor NaN/overflow and code occupancy. Detach h_i/rho_i from gradients.
END IDEA
