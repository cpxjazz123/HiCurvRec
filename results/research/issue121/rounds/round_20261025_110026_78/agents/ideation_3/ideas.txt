IDEA: branchcone
TITLE: User-branch-conditioned hyperbolic first-code assignment
MOTIVATION: A single semantic prefix can merge items that are substitutes for one audience but lead into distinct next-step intents for different users; preserve branching recommendation roles while retaining text-semantic reconstruction.
NOVELTY: Rather than append a behavioural token or regularize an independent graph loss, user-specific branching changes the curved distance that determines each item's first RQ assignment. It uses per-item dispersion over user-context branch directions, not global popularity balancing or a generic hyperbolic RQ-VAE.
CHANGE: Build training-only user-context branches and estimate a compact tangent-space branch prototype and dispersion for each item. During first-level quantization, use dispersion to modulate a Poincare geodesic cost between the encoded item and each codeword, so branch-rich items are assigned by a behaviour-conditioned curved metric; later residual levels stay baseline.
SPECIFICATION: For each training user sequence, form contexts from the preceding up-to-5 distinct items and target next item j. Encode context by the mean of frozen item embeddings, project to tangent space at origin, and cluster contexts into B=8 fixed k-means branch prototypes per target item (retain counts n_jb). Let h_j be the normalized weighted covariance trace of these branch vectors, clipped to [0,1]. With z_j=exp_0^c(a_j), codewords q_k=exp_0^c(v_k), define d_k=d_c(z_j,q_k), and g_jk=log(1+alpha*h_j*|<log_0(z_j)-log_0(q_k), u_j>|), where u_j is the leading eigenvector of the branch covariance (zero if undefined). Assign k*=argmin_k [d_k^2 + lambda*g_jk]; train reconstruction/codebook losses using that hard assignment and straight-through gradient. This is a curved, behaviour-conditioned assignment cost, not a post-hoc loss.
COST: Precompute sparse context summaries in O(number of training transitions); first-level assignment adds one scalar projection and cost term per item-codeword pair. At frozen scale 24,556 items and 24 steps/epoch, a full-item pass per step means about 24,556* K0 projections (K0=64: 1.57M scalar projections/step) and 72,000 steps over 3,000 epochs; cache item branch vectors/eigenvectors so only the inexpensive pairwise projection is added. Expected wall-clock overhead 5–15% versus the same curved baseline, excluding one-time sparse aggregation.
HYPOTHESIS: Items with genuine multi-intent use have behaviour branches that are not aligned with text-only nearest-code boundaries; branch-conditioned geodesic assignment should alter their first-token assignments and make next-token prefixes more predictive. Keep only if both-on improves validation-selected Stage3 test Recall@10 and exceeds 0.065, with reproducible seeds.
RISKS: Sparse per-item sequences make branch covariance noisy; the leading direction can capture popularity or sequence-position artifacts; lambda can overwhelm semantic reconstruction; freezing the branch statistics may miss evolving assignments.
BEHAVIOR SIGNAL: User-interest branching among contexts that precede the same target item.
BEHAVIOR COMPUTATION: Training split only: collect (user, preceding up-to-5 distinct item IDs, next target item) transitions; map history items to frozen Stage1 embeddings, mean-pool and project; cluster contexts per target into at most 8 branches, with minimum support 3, then compute count-weighted covariance. No held-out sequence is included.
LEAKAGE BOUNDARY: Generate statistics solely from the Stage2 training interaction split and the fixed Stage1 item embeddings; persist item-indexed statistics before SID fitting. Validation/test events are not read by preprocessing, assignment, checkpoint selection for SID, or cached statistics.
HYPERBOLIC OPERATOR: Poincare-ball exp_0^c/log_0^c and geodesic distance d_c for fixed negative curvature -c, c=1 initially.
HYPERBOLIC LOCATION: First residual-quantization level's hard codeword assignment during Stage2 fitting; the codeword vectors and encoded items are mapped to the ball before computing the behaviour-conditioned cost.
COUPLING PATH: Training-only branch covariance supplies h_j and direction u_j inside the same per-codeword curved assignment score; removing behaviour eliminates g, while replacing d_c/log/exp by Euclidean geometry changes the score and assignments.
COUPLING EQUATION: S(j,k)=d_c(exp_0^c(a_j),exp_0^c(v_k))^2 + lambda*log(1+alpha*h_j*|<log_0^c(exp_0^c(a_j))-log_0^c(exp_0^c(v_k)),u_j>|); k*(j)=argmin_k S(j,k).
OBSERVABLES: First-level SID changes concentrated on high-branch items; increased training-prefix predictability measured on held-out training contexts; Stage3 validation/test Recall@10 should rise, with target test Recall@10 >0.065.
ABLATION BEHAVIOR OFF: Set lambda=0 (same curved RQ-VAE, same schedule and seeds); branch statistics are not used.
ABLATION GEOMETRY OFF: Replace Poincare maps/geodesic with Euclidean vectors and squared Euclidean distance while retaining the exact branch penalty direction/projection; retune only a predeclared lambda grid.
ABLATION BOTH ON: Use the complete branch-conditioned Poincare assignment; compare all arms with matched Stage3 training and validation selection.
SPEC EQUATIONS: Given tangent vectors a_j,v_k with norm bounded below 1/sqrt(c), exp_0^c(x)=tanh(sqrt(c)||x||)x/(sqrt(c)||x||), log_0^c(y)=atanh(sqrt(c)||y||)y/(sqrt(c)||y||), d_c(x,y)=2/sqrt(c)*atanh(sqrt(c)||(-x)oplus_c y||). Use branch covariance C_j=sum_b p_jb(m_jb-m_j)(m_jb-m_j)^T, h_j=clip(tr(C_j)/(tr(C_j)+tau),0,1), u_j=top_eigenvector(C_j). Assignment uses S above, with deterministic tie-break by code index; backprop through selected code via standard straight-through estimator.
SPEC INPUTS OUTPUTS: Inputs: training-only transition records, frozen item embeddings, Stage2 encoder output a_j, first-level tangent codewords v_k, c, lambda, alpha. Outputs: per-item branch statistics (h_j,u_j) and first-level code index k*(j), then ordinary residual codes.
SAFEGUARDS: Clamp sqrt(c)||x|| <= 1-epsilon before exp/log; clamp atanh input to 1-epsilon; normalize u_j and set it to zero for fewer than 3 contexts or near-zero covariance; cap alpha and lambda; accumulate statistics in float64, costs in float32; use deterministic clustering seed and stable tie-breaking.
END IDEA

IDEA: flowresid
TITLE: Transition-flow geodesic residual quantization
MOTIVATION: Text reconstruction alone can spend residual capacity on distinctions that do not help predict what users consume next; directed training transitions provide an explicit recommendation-oriented direction for residual code selection.
NOVELTY: Unlike graph-neighbour reweighting of ordinary nearest-neighbour VQ, transition flow is transported into the Poincare tangent space and steers the residual along a curved geodesic before each residual quantization decision. It modifies the residual state itself, so behaviour and geometry cannot be separated into unrelated losses.
CHANGE: Estimate each item's popularity-adjusted outgoing transition barycenter from training sequences, then at each RQ level move the current residual a small fraction along the Poincare log-map direction toward that barycenter. Quantize the moved residual by Poincare distance and subtract the chosen codeword using the same curved residual operation.
SPECIFICATION: From training directed counts A_ij, set P_ij=(A_ij+eps)/(sum_l A_il+eps*|N(i)|), retaining at most 32 outgoing neighbours by P_ij; downweight each count by target popularity^-0.5 before row normalization. Let b_i be the Poincare weighted Frechet-mean approximation exp_0^c(sum_j P_ij log_0^c(z_j)), z_j=exp_0^c(enc(x_j)). For item i at level l, residual r_l in tangent coordinates maps to R_l=exp_0^c(r_l); compute flow f_i=log_{R_l}(b_i), clip norm, and set R'_l=exp_{R_l}^c(eta_l * sigmoid(s_i) * f_i), where s_i=log(1+outdegree_i). Choose k_l=argmin_k d_c(R'_l, exp_0^c(v_lk))^2; update R_{l+1}=log_0^c((-q_lk)oplus_c R'_l), where q_lk=exp_0^c(v_lk). Use straight-through assignment and baseline reconstruction plus commitment losses.
COST: Precompute truncated outgoing distributions/barycenters in O(E_train log 32) and store one tangent vector per item. Each RQ level adds one log-map/geodesic step per item and a scalar gate; pairwise codeword distance remains baseline complexity. At 24,556 items, 24 steps/epoch, 3,000 epochs (72,000 steps), cache b_i and compute the per-item flow once per quantizer forward; expected 10–25% overhead depending on latent dimension and number of residual levels.
HYPOTHESIS: Directed consumption flow has a useful local tangent direction not recoverable from static item text; steering residual quantization toward that direction should shift residual SIDs to encode successor-relevant distinctions and raise Stage3 test Recall@10 above 0.065.
RISKS: Flow may encode popularity rather than conditional preference; outgoing neighbours can be noisy for low-degree items; repeated steering can distort reconstruction or erase useful semantics; Frechet-mean approximation in a tangent chart may be biased for broad neighbourhoods.
BEHAVIOR SIGNAL: Popularity-adjusted directed next-item transition distribution for each item.
BEHAVIOR COMPUTATION: On Stage2 training interactions only, count adjacent distinct items within each user's ordered sequence; divide transition counts by source row sum after multiplying each edge count by (1+target training frequency)^-0.5; retain top 32 outgoing targets and normalize. Create barycenters from frozen Stage1 embeddings mapped into the fixed-curvature ball.
LEAKAGE BOUNDARY: The transition matrix is built only from training users' training-period adjacent pairs. Item frequencies, neighbour lists, and barycenters are frozen before tokenizer fitting; no validation/test sequence, target, frequency, or model output participates.
HYPERBOLIC OPERATOR: Poincare exp/log maps, parallel point displacement via exp_R, Mobius subtraction, and geodesic distance with fixed curvature -c (c=1).
HYPERBOLIC LOCATION: In every residual quantization level of Stage2: the current residual is geometrically displaced toward its training-only outgoing barycenter before code assignment, and residual subtraction returns through the curved log map.
COUPLING PATH: The row-normalized training transition distribution determines b_i; b_i enters the Poincare log/exp residual displacement; the displaced curved point is the actual input to the codeword argmin. Removing either makes a different residual and SID.
COUPLING EQUATION: R'_l=exp_{R_l}^c(eta_l*sigmoid(log(1+outdegree_i))*log_{R_l}(exp_0^c(sum_j P_ij log_0^c(z_j)))); k_l=argmin_k d_c(R'_l,exp_0^c(v_lk))^2.
OBSERVABLES: Residual digits should change more for items with confident outgoing distributions; held-out prefix-to-next-item accuracy and Stage3 Recall@10 should improve. Main target is Stage3 test Recall@10 >0.065, compared at matched validation selection.
ABLATION BEHAVIOR OFF: Set eta_l=0 at every level, leaving the same Poincare RQ-VAE and all other losses unchanged.
ABLATION GEOMETRY OFF: Replace exp/log/Mobius operations and d_c with Euclidean vector addition/subtraction and squared Euclidean distance, retaining identical transition distributions, gates, eta schedule, and codebook sizes.
ABLATION BOTH ON: Use transition-derived b_i and Poincare residual displacement/assignment/subtraction throughout; train and evaluate the same Stage3 pipeline.
SPEC EQUATIONS: For curvature -c, Mobius addition x opplus_c y=((1+2c<x,y>+c||y||^2)x+(1-c||x||^2)y)/(1+2c<x,y>+c^2||x||^2||y||^2); d_c(x,y)=2/sqrt(c)*atanh(sqrt(c)||(-x)oplus_c y||); log_x(y)=2/(sqrt(c)*lambda_x)*atanh(sqrt(c)||(-x)oplus_c y||)*((-x)oplus_c y), lambda_x=2/(1-c||x||^2); exp_x(v)=x opplus_c [tanh(sqrt(c)*lambda_x||v||/2)*v/(sqrt(c)||v||)]. Use these formulae for displacement and assignment; use tangent residual norm clipping.
SPEC INPUTS OUTPUTS: Inputs: train-only ordered user sequences, frozen item embeddings, encoder outputs, per-item outgoing distribution P_i, tangent codebooks at each level, curvature c and eta_l. Outputs: first-level and residual SID indices, plus reconstructed embedding for the standard RQ-VAE losses.
SAFEGUARDS: Project ball points to norm <=(1-epsilon)/sqrt(c); clamp atanh arguments; clip tangent norms before exp; if no outgoing transition set eta=0; smooth popularity with +1; cap neighbour probabilities and eta (initial eta <=0.1); detach cached barycenters; monitor reconstruction and flow displacement norms for divergence; use fixed seed and identical preprocessing in geometry-off arm.
END IDEA
