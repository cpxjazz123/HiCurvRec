IDEA: lorentz_flow_code
TITLE: Encode directed next-item flow as Lorentzian code assignment energy
MOTIVATION: Content embeddings can group items by static similarity while ignoring that users move asymmetrically between them; the SID should let the next-item model express directed continuation without making successors indistinguishable from predecessors.
NOVELTY: Unlike transition-residual quantization, this leaves the residual updates intact and inserts a train-only directed flow potential directly into the discrete code assignment score. Unlike symmetric graph smoothing, incoming and outgoing transition roles remain distinct in a curved Lorentz space.
CHANGE: Build a smoothed train-only successor distribution for each item and learn small Lorentzian source/target flow points for items. At each RQ level, choose the code minimizing content reconstruction distance plus a behavior-weighted mismatch between the item's predicted successor-flow point and the flow point induced by that candidate code.
SPECIFICATION: Let z_i be the current Euclidean residual input at a quantization level and c_k its code vectors. Map normalized z_i and c_k to the Lorentz hyperboloid with curvature -κ using exp_o; denote these points x_i and q_k. From training sequences form P(j|i)=(n_ij+α)/(n_i+α|N|), and a fixed train-only target y_i=normalize(Σ_j P(j|i) v_j), where v_j is a learned target-role Lorentz point. Maintain a learned source-role point u_k per code. For every item/code pair score E(i,k)=d_L(exp_o(z_i),exp_o(c_k))² + λ b_i d_L(exp_{u_k}(0), y_i)², with the second distance evaluated on the hyperboloid after mapping the code source point through exp_o (equivalently use learned hyperboloid code-role points q^src_k); b_i=min(1, log(1+n_i)/log(1+n_95)); assign argmin_k E(i,k), use the ordinary straight-through RQ update/reconstruction loss, and train role points by the same selected-score gradient. More implementably, use learned unit-hyperboloid q^src_k and y_i directly, with second term λ b_i d_L(q^src_k,y_i)^2. Recompute hard assignments each forward pass.
COST: One train-only transition pass over at most the observed training adjacencies, then one vectorized Lorentz distance against code-role points per item per level. If all 24,556 items are scored each of 24 steps/epoch for 3,000 epochs, upper bound is 72,000 passes × 24,556 × L × K pair distances; in normal minibatch training it scales as batch_size × L × K per optimizer step, plus O(edges) one-time preprocessing. Expect roughly 10–30% tokenizer-step overhead depending on L,K and implementation; Stage 3 cost is unchanged.
HYPOTHESIS: Directed successor-flow compatibility will make codes (and therefore SID prefixes) more predictive of next-item continuation than static content-only assignments, improving Stage 3 test Recall@10; retain only if the both-on run beats the matched baseline and the measured train-flow predictability gain is not confined to training metrics.
RISKS: Sparse item transitions make y_i noisy; high-degree successors can dominate; flow and content objectives can conflict, destabilizing assignments; the added code-role points may overfit the training graph or yield no Stage 3 gain. Tune λ on validation only, without using validation interactions to construct SIDs.
BEHAVIOR SIGNAL: Directed immediate next-item transition distribution P(j|i), with source-specific support count n_i.
BEHAVIOR COMPUTATION: Count adjacent item pairs i→j within each training sequence only; add α=1 smoothing over the training item universe and compute n_i. Derive b_i from the train count quantile as specified. Do not count within validation/test sequences or cross split boundaries.
LEAKAGE BOUNDARY: Freeze transition counts, target-role training data, and b_i using training sequences only; construct validation/test item SIDs by applying the learned tokenizer and frozen train-derived quantities, never by updating graph statistics or assignments from their interactions.
HYPERBOLIC OPERATOR: Lorentz-model geodesic distance d_L on curvature -κ (κ>0), with origin exponential map exp_o for residual/code inputs; learned flow points are projected to the Lorentz hyperboloid.
HYPERBOLIC LOCATION: Hard RQ code selection during each tokenizer training forward pass, in a behavior-dependent energy that combines content quantization distance and directed-flow compatibility; it therefore changes assignments and assignment gradients.
COUPLING PATH: Train transitions create each item's successor target y_i and support weight b_i; the Lorentz distance from y_i to a candidate code's source-role point enters the very energy whose argmin selects that item's RQ code.
COUPLING EQUATION: k*(i)=argmin_k [d_L(exp_o(z_i),exp_o(c_k))² + λ b_i d_L(q^src_k,y_i)²], where y_i is computed from train-only P(j|i) and d_L is the curvature -κ geodesic distance.
OBSERVABLES: Compare per-level code assignments, successor conditional entropy from SID prefixes, train-only held-out-within-train transition NLL diagnostic, and—decisively—Stage 3 test Recall@10 under identical training/evaluation settings; inspect code utilization and assignment churn for instability.
ABLATION BEHAVIOR OFF: Set λ=0 (or b_i=0 for all i); retain identical Lorentz content distance, model size, training schedule and random seeds where possible.
ABLATION GEOMETRY OFF: Replace both d_L terms by squared Euclidean distances in matched-dimensional coordinates, retaining the same train transition targets, b_i, λ, code-role parameters and training budget.
ABLATION BOTH ON: Use train-only P(j|i), b_i, and the Lorentzian coupled assignment energy above; evaluate Stage 3 Recall@10 on the locked test split.
SPEC EQUATIONS: For train adjacencies, n_ij←count(i→j), n_i=Σ_j n_ij, P_ij=(n_ij+α)/(n_i+αM). Set y_i=normalize_H(Σ_j P_ij v_j), where normalize_H projects the weighted ambient sum onto the future Lorentz sheet. For level residual z_i and candidates c_k, compute x_i=exp_o(z_i), q_k=exp_o(c_k), and E_ik=d_L(x_i,q_k)^2+λb_i d_L(q^src_k,y_i)^2; k*=argmin_k E_ik. Quantize with c_k* and update residual as baseline RQ-VAE. Optimize reconstruction/codebook/commitment objectives as baseline plus selected E behavior term; use straight-through assignment for encoder gradients. Hyperboloid constraint: -X_0²+Σ_{r>0}X_r²=-1/κ and X_0>0. Lorentz distance: d_L(X,Y)=acosh(max(1, -κ⟨X,Y⟩_L))/sqrt(κ).
SPEC INPUTS OUTPUTS: Inputs: frozen training adjacency counts, item residual vectors z_i, RQ code vectors, trainable code source-role and item target-role Lorentz points, λ, κ, and count weights b_i. Output: hard code index k* per item/level and the differentiable selected energy for tokenizer optimization; exported SIDs are the resulting ordinary ordered RQ indices.
SAFEGUARDS: Keep κ in a fixed bounded positive range; perform Lorentz calculations in float32 or float64; clamp acosh arguments to at least 1+ε and radicands/denominators; project points back to the future hyperboloid after updates; clip tangent norms before exp maps; use α=1 and a support floor/shrinkage for rare items; normalize weighted target sums with an origin fallback when norm is tiny; cap b_i at 1 and λ modestly; log assignment churn and finite-value checks.
END IDEA
