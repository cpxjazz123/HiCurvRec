IDEA: symgeo_region
TITLE: Co-consumption-led Poincare code assignment with a directed near-tie radar
MOTIVATION: Preserve the symmetric co-consumption structure that directly measures item cohesion while retaining directed transition information only as a small tie-break, rather than allowing sequence direction to reshape the partition.
NOVELTY: The symmetric train-only co-consumption cosine is the primary assignment evidence and is coupled directly to Poincare geodesic distance; directed predecessor-region evidence is bounded to at most one percent of that signal. This is not a Euclidean quantizer with a detached behaviour loss.
CHANGE: Map encoder latents and first-level code vectors into the curvature-c=1 Poincare ball and choose each first-level code by the prescribed joint score. Refresh each code's co-consumption region profile once per epoch from current hard assignments; compute directed region-transition support from frozen training transitions.
SPECIFICATION: Let A be the symmetric cosine matrix of train-only co-consumption rows, z_i=exp_0^(-1)(encoder(x_i)) (with the implementation convention that exp_0 maps tangent latents into the ball), and v_k the code vector mapped into the ball. Each epoch set g_k=normalize(sum_i 1[a_i=k] A_i). Let P_ab be normalized train transition counts between current first-level regions. For item i define D_ik=sum_a p(a| predecessor of i) P_ak, using only its training predecessor counts. Assign a_i=argmax_k{-d_c(z_i,v_k)^2/T + lambda A_i dot g_k + eps D_ik}; use c=1, fixed T, lambda approximately 1 after scale matching, and eps<=0.01 lambda. Update codebook/encoder with the existing RQ-VAE objective and the selected hard assignment; no gradient is detached or added as an unrelated loss.
COST: One-time sparse co-occurrence construction and transition construction; frozen sparse structures are reused. Per epoch, batched item-by-code Poincare distances and sparse A_i dot g_k profile scores, plus one vectorized profile refresh; no per-item Python loops and no rebuilding transition pairs. Target about baseline 0.15 s/epoch on four cards; at 24 steps x 3000 epochs this is 72,000 steps and about 450 s baseline epoch time in aggregate wall-clock terms, so the arm must benchmark under one hour. Sparse/top-K A storage and blockwise score computation bound memory; profile work is approximately O(nnz(A)+N K) only if dense scoring is already needed, otherwise sparse gather/scatter avoids dense N-by-N work.
HYPOTHESIS: Co-consumption alignment increases cooccur_overlap_L3 beyond 0.0756 while the small directed term improves sequential predictability without moving the partition materially; retain only if the gate clears and frozen-protocol Stage3 test_R@10 exceeds 0.065.
RISKS: Co-occurrence profiles can become self-reinforcing, hubs can dominate cosine structure, scales can overwhelm geometric distances, and Poincare distances can be expensive or numerically unstable. The prescribed coherence metric may not translate to Stage3 recall.
BEHAVIOR SIGNAL: Symmetric train-only user co-consumption cosine A_ij, with the permitted directed train transition counts used only as a near-tie term.
BEHAVIOR COMPUTATION: For each user's longest training sequence, increment every unordered pair of distinct items at most once; symmetrize counts, form each item's co-consumption row, L2-normalize rows, and compute pairwise cosine. Separately count adjacent directed pairs from those same longest training sequences once. Build both once before training and freeze. Region profiles and region transitions are recomputed from current assignments, but only from these frozen train-only item signals/counts.
LEAKAGE BOUNDARY: Construct A and directed counts exclusively from the training split before Stage2; do not load validation/test sequences during profile construction, transition construction, assignment, or tuning. Freeze all source constants before Stage3 evaluation.
HYPERBOLIC OPERATOR: Poincare-ball geodesic distance d_c for fixed negative curvature -c=-1, with exp/log maps at the origin.
HYPERBOLIC LOCATION: First-level quantization assignment score (and consistent mapping of encoder/codebook vectors); geometry-off replaces distance and region-vector geometry throughout with Euclidean operations.
COUPLING PATH: The item-to-code assignment score sums Poincare geodesic proximity and symmetric co-consumption compatibility, with the frozen directed region support as a capped tie-break; each term changes the same argmax and hence the selected code and RQ-VAE update.
COUPLING EQUATION: S_ik=-d_c(z_i,v_k)^2/T + lambda <A_i,g_k> + eps D_ik, with c=1 and eps<=0.01 lambda; a_i=argmax_k S_ik.
OBSERVABLES: Report L1 Hard ER, cooccur_overlap_L3 (gate: strictly above 0.0756 before Stage3 budget), adjacency_L3, largest first-level bucket share, extension alphabet, and Stage3 test_R@10. Also compare assignment changes and training time/epoch to diagnose the tie-break.
ABLATION BEHAVIOR OFF: Set lambda=0 and eps=0; use the plain squared Euclidean assignment, with no detached behaviour losses or behaviour-derived offsets.
ABLATION GEOMETRY OFF: Replace Poincare distance by squared Euclidean distance and use Euclidean region means/scoring everywhere (curvature removed throughout); preserve the same A and directed signals and weights for a controlled geometry comparison.
ABLATION BOTH ON: Run c=1 Poincare assignment with lambda>0 and eps>0 at no more than 0.01 lambda; additionally run eps=0 as the mandatory directed-off diagnostic to isolate the tie-break.
SPEC EQUATIONS: A_ij=cos(row_i,row_j), where row_i is the L2-normalized symmetric training co-consumption count row. At each epoch g_k=normalize(mean_{i:a_i=k} A_i). Let n_i(a) be training predecessor counts by current region and P_ab be the frozen-count, current-region transition matrix; D_ik=sum_a normalize(n_i)_a P_ak. Then a_i=argmax_k[-d_{-1}(z_i,v_k)^2/T+lambda(A_i dot g_k)+eps D_ik]. If no predecessor exists, set D_ik=0. Update the RQ-VAE using these assignments and its ordinary objective.
SPEC INPUTS OUTPUTS: Inputs: train-only sparse A, train adjacent transition pair arrays, encoder item latents, first-level code vectors, current assignments, fixed T/lambda/eps. Output: one first-level code index per training item, refreshed region profiles, and vectorized scores for diagnostics.
SAFEGUARDS: Use float32 or better for scores and accumulate counts in int64; clamp Poincare norms below (1-1e-5)/sqrt(c), clamp acosh arguments to at least 1+1e-7, normalize zero rows/profiles with epsilon and return zero vectors for empty codes, define empty predecessor support as zero, clip/normalize transition probabilities, blockwise score evaluation, and assert finite scores. Scale-match the two primary terms on a fixed training-only calibration batch; do not tune from validation/test. Fix T, lambda, eps as source constants.
END IDEA

IDEA: symgeo_profile_memory
TITLE: Epoch-lagged co-consumption region profiles with the same curved joint assignment
MOTIVATION: Reduce feedback oscillation when hard assignments change, while preserving co-consumption as the partition's primary evidence and directed transitions as a bounded tie-break.
NOVELTY: Instead of letting newly assigned items instantly redefine region profiles in the same epoch, use a deterministic one-epoch-lagged profile computed from the prior epoch's assignments. The behavior signal still enters the same Poincare assignment pathway, not a side loss; this is a distinct stabilization position rather than another directed-assignment mechanism.
CHANGE: Cache g_k from the previous epoch's assignments and score current assignments with the same fixed-curvature joint score. After assignments are finalized, update the profile cache once for the next epoch; initialize it from the initial baseline assignments before epoch one.
SPECIFICATION: Initialize a_i^0 using baseline initialization, then g_k^0=normalize(mean_{i:a_i^0=k} A_i). For epoch t, compute D^t from frozen train transition pairs and current region assignments, then set a_i^{t+1}=argmax_k[-d_{-1}(z_i,v_k)^2/T+lambda<A_i,g_k^t>+eps D^t_ik]. Recompute g_k^{t+1}=normalize(mean_{i:a_i^{t+1}=k} A_i) once after the batched argmax. Use c=1, fixed T and lambda approximately 1 after scale matching, and eps<=0.01 lambda. The normal RQ-VAE update follows the selected assignments.
COST: Same one-time sparse A/transition construction and same per-epoch batched geodesic score and profile refresh as symgeo_region, with one cached K-by-N profile buffer; no additional per-item loops, no transition-pair rebuilding. At frozen scale 24 steps/epoch x 3000 epochs, estimate near the baseline 0.15 s/epoch on four cards; measure actual epoch time and abort neither early nor change protocol, but require full run under one hour.
HYPOTHESIS: One-epoch lag damps assignment/profile oscillations without losing the co-consumption advantage; observe lower epoch-to-epoch assignment churn, cooccur_overlap_L3 above 0.0756, and ultimately Stage3 test_R@10 above 0.065.
RISKS: Lag can make profiles stale when the partition moves rapidly, preserve a poor initialization, or slow convergence; the extra stability may not help recommendation recall. It must be compared fairly against the immediate-refresh version.
BEHAVIOR SIGNAL: The symmetric cosine A_ij of train-only co-consumption rows; directed adjacent transition support is retained only as a capped near-tie signal.
BEHAVIOR COMPUTATION: From each user's longest training sequence, count each unordered item pair once, symmetrize and L2-normalize item rows, then form cosine similarities. Count adjacent ordered pairs from the same training sequences for the region-transition tie-break. Compute once before Stage2 and freeze all item-level behavior arrays.
LEAKAGE BOUNDARY: Neither A nor directed counts use validation/test events; cached region profiles are aggregates of frozen training-only A rows under assignments learned in Stage2. No validation/test interactions are consulted for profile updates, constants, or checkpoint selection.
HYPERBOLIC OPERATOR: Fixed-curvature c=1 Poincare geodesic distance with exp/log maps at the origin.
HYPERBOLIC LOCATION: First-level code assignment score and latent/code mapping; geometry-off substitutes Euclidean distance and Euclidean profile operations throughout.
COUPLING PATH: The cached co-consumption profile for code k scores each item's compatibility with that code in the very argmax that also uses Poincare geodesic distance and the bounded directed support; changing the profile signal or curvature changes selected codes and subsequent RQ-VAE updates.
COUPLING EQUATION: S^t_ik=-d_{-1}(z_i,v_k)^2/T + lambda<A_i,g_k^t> + eps D^t_ik; a_i^{t+1}=argmax_k S^t_ik and g_k^{t+1}=normalize(mean_{i:a_i^{t+1}=k}A_i).
OBSERVABLES: Report L1 Hard ER, cooccur_overlap_L3 (must clear 0.0756 before Stage3), adjacency_L3, largest first-level bucket share, extension alphabet, Stage3 test_R@10, assignment churn per epoch, and epoch wall time.
ABLATION BEHAVIOR OFF: lambda=eps=0 and use plain squared Euclidean assignment, with no detached behavior term.
ABLATION GEOMETRY OFF: Replace Poincare distance/maps by Euclidean counterparts and use Euclidean region means throughout; keep behavior arrays and coefficients fixed.
ABLATION BOTH ON: Use the cached-profile joint Poincare score at c=1 with symmetric lambda term and capped directed eps term; include eps=0 directed-off control.
SPEC EQUATIONS: Set g^0 from initial baseline assignments. For t=0,...,2999: compute D^t from fixed training transition pairs and current region labels; assign a_i^{t+1}=argmax_k[-d_{-1}(z_i,v_k)^2/T+lambda sum_j A_ij g^t_kj+eps D^t_ik]; then refresh g^{t+1}_k=normalize(sum_i 1[a_i^{t+1}=k] A_i). If a code is empty retain its previous profile; if an item has no training predecessor set D=0.
SPEC INPUTS OUTPUTS: Inputs: frozen sparse co-consumption rows/cosines A, frozen directed training transition pairs, baseline initialization, encoder latents/code vectors, fixed constants. Outputs: assigned first-level codes, profile cache for next epoch, and assignment churn/scores.
SAFEGUARDS: Apply the same Poincare norm and acosh clamps as the baseline hyperbolic implementation; epsilon-safe normalization; retain prior profile for empty codes; use int64 transition accumulators and float32+ score accumulation; clip probabilities, block scores, check finite values. Calibrate lambda/T only on training data, freeze source constants, and ensure eps<=0.01 lambda.
END IDEA
