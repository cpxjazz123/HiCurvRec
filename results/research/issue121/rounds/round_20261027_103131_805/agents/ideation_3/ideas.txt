IDEA: cogeo_region_argmax
TITLE: Co-consumption-led Poincare region assignment with directed near-tie radar
MOTIVATION: The measured target is symmetric co-consumption coherence, while directed transitions carry useful sequential information but have repeatedly damaged that target when allowed to control partitions. Make symmetric neighbourhood agreement determine the partition and reserve directed context for genuinely ambiguous code choices.
NOVELTY: Unlike prior transition-led assignments, Sinkhorn, latent-offset, and co-consumption-row grouping followed by an unchanged Euclidean quantizer, this makes co-consumption and Poincare distance jointly determine every first-level assignment; directed transition information is strictly a bounded tie-break. It is the prescribed inversion of the previous composition, not a reuse of those earlier mechanisms.
CHANGE: Freeze normalized train-only co-consumption rows A_i and directed transition counts; once per epoch form code-region profiles g_k from current hard assignments. Score every item/code pair with negative squared Poincare distance plus dominant symmetric profile agreement and a <=1%-strength directed predecessor-region term, then use the selected code in ordinary residual quantization.
SPECIFICATION: Initialize a_i from the training split only. At each epoch compute g_k=normalize(sum_{j:a_j=k} A_j / max(1,n_k)); if empty retain its prior profile (initially the global mean). Build P_{r,k}=count of train-only adjacent transitions r->j with a_j=k, normalized over k with smoothing. For item i let d_{i,k}=sum_r p(r|i)P_{r,k}, zero for no incoming transitions. Set s_{i,k}=-d_c(z_i,v_k)^2/T + lambda(A_i dot g_k) + eps*d_{i,k}; a_i=argmax_k s_{i,k}. Choose source constants T and lambda after train-only score-scale calibration; normalize d into [0,1], and constrain eps<=0.01 lambda. The selected first code feeds the existing later residual stages.
COST: One sparse train-split co-consumption construction and one transition count pass before training. Per epoch, profile aggregation costs O(nnz(A)) with sparse rows and current item assignments, plus vectorized assignment O(N*K*D) and directed score O(N*K) using cached P and batched sparse/dense products; no per-item Python loop or transition-pair rebuild. At frozen scale (N=24,556; 24 steps/epoch; 3,000 epochs), 73,668,000 item/code opportunities per first-level pass over the run. Expect a modest constant-factor increase over baseline; keep one epoch near 0.15 s on four cards by sparse/dense batching and cache reuse.
HYPOTHESIS: Co-consumption agreement dominates partition movement and raises cooccur_overlap_L3 above the 0.0756 plain baseline before Stage 3 is run; the weak directed term improves sequence usefulness without eroding that gain. Keep only if measured cooccur_overlap_L3 clears 0.0756 and Stage3 test_R@10 exceeds 0.065, with the coupled run beating both controls.
RISKS: Sparse row/profile reductions or Poincare distance may exceed the epoch budget; stale/noisy hard assignments may make profiles oscillate; the directed term may be too weak to matter or, if scales are mismatched, cease to be a tie-break. Co-consumption coherence can improve without improving next-item recall.
BEHAVIOR SIGNAL: Symmetric train-only co-consumption cosine A_ij plus directed train-only predecessor-to-target transition counts used only as a small near-tie radar.
BEHAVIOR COMPUTATION: For each user's longest chronological training sequence, count each distinct item pair once in a symmetric co-consumption matrix; L2-normalize each row to obtain A_i. Separately count adjacent directed transitions r->i over training sequences. Freeze both before Stage2; recompute only code-region aggregation g_k once per epoch from assignments, not from new interactions.
LEAKAGE BOUNDARY: Construct A and transition counts exclusively from the training split and freeze them before Stage2 optimization. Validation/test interactions, future events, and Stage3 context do not enter A, transition counts, profiles, assignments, or SID export.
HYPERBOLIC OPERATOR: Fixed-curvature Poincare-ball exponential map and squared geodesic distance d_c^2 at curvature -c (c=1), between mapped item latent and mapped first-level code vector.
HYPERBOLIC LOCATION: First-level candidate assignment score; this changes the emitted first SID token and its quantization gradient.
COUPLING PATH: Frozen A_i and current-assignment region profiles g_k provide a dominant per-candidate behavior score in the same argmax as the Poincare geodesic score; cached train transition-region masses provide only a bounded secondary score. Removing A removes the coherence drive; replacing the Poincare score by Euclidean distance changes the same candidate computation.
COUPLING EQUATION: s_{i,k}= -d_{c=1}(exp_0(z_i),exp_0(v_k))^2/T + lambda <A_i,g_k> + eps*d_{i,k}, with eps<=0.01 lambda; a_i=argmax_k s_{i,k}.
OBSERVABLES: Compare L1 Hard ER, cooccur_overlap_L3, adjacency_L3, largest first-level bucket share, extension alphabet, and (only after the gate clears) Stage3 test_R@10. Also inspect changed first-level assignments and the fraction of assignments for which the directed term actually breaks a near-tie. Require both-on cooccur_overlap_L3>0.0756 before spending Stage3 budget.
ABLATION BEHAVIOR OFF: Set lambda=eps=0 and use the plain squared Euclidean assignment required for the behavior-off control; no detached behavior term remains.
ABLATION GEOMETRY OFF: Retain the same A_i, g_k, directed counts, coefficients, and assignment pathway, but replace Poincare maps/distance with squared Euclidean distance/norm everywhere in the assignment and profile geometry.
ABLATION BOTH ON: Use fixed-curvature Poincare distance, dominant co-consumption profile agreement, and bounded directed tie-break exactly as in the coupling equation.
SPEC EQUATIONS: Train counts C_sym[i,j]=sum_u 1[i,j in unique(items(seq_u))]; A_i=C_sym[i,:]/max(||C_sym[i,:]||_2,delta). At epoch e, g_k=normalize(sum_{j:a_j=k} A_j/max(1,n_k)); P_{r,k}=(sum_{j:a_j=k} n_{r,j}+alpha)/(sum_{k'}sum_{j:a_j=k'}n_{r,j}+K alpha); d_{i,k}=normalize_k(sum_r n_{r,i}P_{r,k}) (zero vector if no incoming edges). Compute all scores in batches and update hard assignment. Use row-normalized sparse A for profile aggregation and cached transition matrices.
SPEC INPUTS OUTPUTS: Inputs: training-only longest sequences, frozen A and adjacent-transition counts, current encoder/code vectors and assignments, fixed c=1, source constants T/lambda/eps/alpha. Outputs: per-item first-level hard assignment, per-code region profile refreshed each epoch, and downstream RQ-VAE SIDs.
SAFEGUARDS: Use float32 for geometry; project mapped points to norm <=(1-delta)/sqrt(c); clamp Poincare acosh/atanh arguments; normalize sparse rows with denominator at least delta; smooth transition rows by alpha and define zero-incoming items as d=0; retain prior profile for empty codes; cap eps at 0.01 lambda; calibrate score scales using training data only; check finite scores and gradients. Avoid materializing dense N-by-N A if the train matrix is sparse.
END IDEA

IDEA: cogeo_symmetric_gate
TITLE: Co-consumption-confidence-gated hyperbolic assignment with a directed tie-break
MOTIVATION: Co-consumption rows with stronger support should exert more reliable pressure on code membership, while sparse or ambiguous rows should defer more to the item's learned representation. This preserves the symmetric measured target without forcing weakly observed items into noisy neighbourhood regions.
NOVELTY: The coupling is a per-item confidence gate on a curved-versus-behavior candidate score, rather than a behavior replacement, Sinkhorn constraint, latent offset, or post-hoc Euclidean grouping. It retains the round's symmetric-first/directed-tie-break composition but tests a distinct mechanism: reliability-weighted symmetric region evidence.
CHANGE: Compute a train-only reliability q_i from the support count underlying each normalized co-consumption row; blend profile coherence and squared Poincare distance within each candidate score using q_i, and include directed predecessor-region mass only as a <=1%-strength tie-break. A high-support item is assigned more by agreement with its code's co-consumption region, while a low-support item is assigned more by its curved latent proximity.
SPECIFICATION: Let m_i be the number of distinct training users in whose longest training sequence item i appears; q_i=m_i/(m_i+tau), with fixed source tau. Construct normalized A_i as in the round definition and refresh g_k=normalize(mean_{j:a_j=k} A_j) once per epoch. Define a train-only directed transition-to-current-region score d_{i,k} from cached adjacent-transition counts. Let D_i be the train-only median Poincare squared distance for the batch/code scale (a fixed source calibration constant after initial train-only calibration). Use s_{i,k}= -[(1-q_i)d_c(z_i,v_k)^2 + q_i*D_i*(1-<A_i,g_k>)]/T + eps*d_{i,k}, with eps<=0.01*lambda where lambda is represented by the q_i*D_i term. Assign argmax. When q_i approaches one, symmetric region agreement is the main distance correction; when q_i is small, curved latent proximity dominates.
COST: One train-only user-support count, co-consumption rows, and transition count pass. Epoch cost remains O(nnz(A)+N*K*D) with vectorized q_i broadcasting and cached transition-region products; profile refresh is once per epoch. At the frozen scale, 73,668,000 item/code comparisons per first-level assignment pass across 3,000 epochs (24,556 items x 24 steps/epoch); expected modest constant-factor overhead, target ~0.15 s/epoch on four cards and comfortably under one hour overall.
HYPOTHESIS: Confidence weighting suppresses noise from weakly supported items while strong rows raise shared-prefix co-consumption coherence. The proposal is worth retaining only if both-on cooccur_overlap_L3 exceeds 0.0756 before Stage3 and Stage3 test_R@10 exceeds 0.065, with gains not reproduced by either required control.
RISKS: User-count confidence may track popularity rather than reliability; the gate may over-privilege head items, and calibration D_i may make behavior or curvature dominate unintentionally. If support counts are nearly uniform, this reduces to the first idea without a useful distinction.
BEHAVIOR SIGNAL: Symmetric train-only co-consumption cosine rows A_i, their distinct-training-user support counts m_i, and directed adjacent-item transitions for the bounded tie-break.
BEHAVIOR COMPUTATION: From each user's longest chronological training sequence, count each distinct item pair once into a symmetric co-consumption matrix; L2-normalize rows and count distinct training users per item. Independently count adjacent directed item transitions. Freeze all counts and normalized rows before Stage2; recompute only g_k once per epoch.
LEAKAGE BOUNDARY: Every count and row is made solely from training users/events and frozen before SID learning. No validation/test interactions, target sequences, or future events affect q_i, A_i, transition counts, region profiles, or exported SIDs.
HYPERBOLIC OPERATOR: Squared Poincare geodesic distance with fixed negative curvature -1; map encoder latents and code vectors to the unit-curvature Poincare ball via exp_0 before distance evaluation.
HYPERBOLIC LOCATION: Candidate first-level assignment, inside the same confidence-weighted score that includes the train-only co-consumption region profile.
COUPLING PATH: Training support counts set q_i; the same candidate score combines q_i-weighted <A_i,g_k> with (1-q_i)-weighted Poincare geodesic distance, and directed region mass is a bounded tie-break. Removing behavior makes q_i/profile contributions vanish and returns plain Euclidean assignment for the behavior-off run; Euclidean replacement changes the core score.
COUPLING EQUATION: s_{i,k}= -[(1-q_i)d_{-1}(exp_0(z_i),exp_0(v_k))^2 + q_i D(1-<A_i,g_k>)]/T + eps*d_{i,k}, q_i=m_i/(m_i+tau), eps<=0.01 lambda; a_i=argmax_k s_{i,k}.
OBSERVABLES: Report L1 Hard ER, cooccur_overlap_L3, adjacency_L3, largest first-level bucket share, extension alphabet, and gated Stage3 test_R@10. Inspect assignment changes stratified by m_i and require cooccur_overlap_L3>0.0756 before Stage3; compare behavior-off, Euclidean geometry-off, and both-on. A separate directed-off run with eps=0 isolates the tie-break.
ABLATION BEHAVIOR OFF: Use plain squared Euclidean assignment only, disabling q_i, A_i, profiles, and directed counts; do not leave a detached behavior loss.
ABLATION GEOMETRY OFF: Keep the behavior rows, q_i, profiles, and directed tie-break unchanged but replace the Poincare distance/maps and any curvature-dependent scale with matched Euclidean squared distance/norm everywhere.
ABLATION BOTH ON: Run the confidence-gated Poincare candidate score with symmetric region agreement dominant for supported rows and directed score bounded by the specified 1% cap.
SPEC EQUATIONS: q_i=m_i/(m_i+tau); A_i=L2norm(C_sym[i,:]); g_k=L2norm(mean_{j:a_j=k} A_j); P_{r,k} from cached adjacent transition counts into current region k; d_{i,k}=normalize_k(sum_r n_{r,i}P_{r,k}); score as given in COUPLING EQUATION. Set D once from the median training-only squared Poincare assignment distance, stop-gradient that calibration, and freeze it; refresh g once per epoch. Include a dedicated directed-off comparison by setting eps=0.
SPEC INPUTS OUTPUTS: Inputs: train-only sequences and resulting C_sym/m_i/transition counts; encoder latents, code vectors, assignments; fixed c=-1, tau, T, eps, alpha and train-calibrated D. Outputs: per-item gated first-level candidate scores and hard SID assignments, plus refreshed code-region profiles.
SAFEGUARDS: Clamp q_i to [0,1] and denominator m_i+tau away from zero; use sparse normalized A; use a fixed train-only D with bounded range to prevent score-scale collapse; clamp/project ball points away from its boundary, compute geometry in float32, clamp inverse-hyperbolic arguments, smooth transition probabilities, handle empty codes and zero-edge items explicitly, and assert finite scores. Match Euclidean control scale using training-only calibration; never tune constants on validation/test or Stage3.
END IDEA
