IDEA: profile-curved-assignment
TITLE: Co-consumption region profiles steer Poincare first-level assignments
MOTIVATION: Directed predecessors/successors encode order, whereas the target coherence metric measures symmetric co-consumption. Let the symmetric signal choose among geometrically plausible first-level regions, retaining directed evidence only as a tiny near-tie preference.
NOVELTY: Existing repository variants test directed behavior inside assignment, Sinkhorn, or latent offsets, and separately group by co-consumption cosine; this couples a per-code co-consumption region profile directly to the same Poincare-geodesic assignment score, with direction strictly bounded to a tie-break. It is not a behavior suffix on an unchanged Euclidean quantizer.
CHANGE: At each epoch, form a normalized co-consumption prototype for every current first-level code. Assign using the sum of negative squared Poincare distance, symmetric item-to-region co-consumption, and a 1%-scale directed tie-break; later RQ levels and the encoder/decoder remain the baseline.
SPECIFICATION: Freeze sparse symmetric A, with A_ij the cosine of L2-normalized rows of train-only per-user co-occurrence counts. For first-level assignment a_i, set g_k = normalize(sum_{j:a_j=k} A_j); if the sum is zero, retain the previous g_k (initially zero). Let z_i=exp^c_0(h_i), v_k=exp^c_0(e_k), c=1, and d_c be Poincare distance. Let q_ik be frozen directed predecessor-region mass, normalized per item and per code to [0,1]. Choose argmax_k[-d_c(z_i,v_k)^2/T + lambda(A_i dot g_k) + eps q_ik], T=1, lambda=1 after calibrating the median nonzero geometric and symmetric score ranges on the first epoch, and eps=0.01 lambda. Refresh g once per epoch from previous epoch assignments; no per-item Python loops. Output normal RQ-VAE codes/SIDs.
COST: Dense implementation is not viable: retain A as CSR/top-neighbor rows (e.g. top-64 nonzero cosine neighbors per item, row-renormalized), and compute region profiles by scatter-add neighbor weights followed by rowwise sparse-to-dense coalescing only over touched code/neighbor indices. Per epoch: one sparse aggregation O(nnz(A)) plus vectorized N x K x d hyperbolic distance scoring (N=24,556, K=256, d=32), directed tie-break via precomputed sparse edge-to-region reductions; no rebuilding transition pairs. Expected modest relative to baseline, but benchmark must confirm ~0.15 s/epoch on four cards. At frozen scale (24 steps x 3000 epochs), scoring is about 154M point-code coordinate contributions/epoch and 72,000 steps total; profile work ~1.57M sparse edge updates/epoch at 64 neighbors, plus precomputed directed-edge reductions. If wall time exceeds target, reduce top-neighbor cap before training, not per-item loops.
HYPOTHESIS: The symmetric profile term must produce more coherent first-level regions than the baseline without collapsing occupancy; observe cooccur_overlap_L3 above 0.0756 before Stage 3, then compare frozen-protocol test_R@10 (target >0.065). Report L1 Hard ER, adjacency_L3, largest first-level bucket share, extension alphabet, and test_R@10 as well as target metric.
RISKS: Sparse top-neighbor truncation may alter the measured coherence signal; profile feedback can self-reinforce early errors; hyperbolic distances can dominate or vanish unless score ranges are calibrated; excessive lambda can collapse buckets. Do not spend Stage 3 budget unless cooccur_overlap_L3 clears 0.0756.
BEHAVIOR SIGNAL: Symmetric train-only co-consumption cosine A_ij; directed predecessor-region mass is permitted only as the prescribed tiny tie-break.
BEHAVIOR COMPUTATION: From train.parquet only, for each user's longest training sequence add one to each unordered pair of distinct items in that sequence, symmetrize counts, L2-normalize each row, then compute cosine similarities and retain the top 64 positive neighbors per row. Separately count directed immediate transitions from each training row's last history item to its target, and freeze the resulting item-to-region transition-pair representation before training.
LEAKAGE BOUNDARY: Build both signals exclusively from the training split before Stage 2; freeze them for all epochs. Never read validation/test interactions or update A/q from Stage 3 or held-out events; assignment profiles use only frozen A and current model assignments.
HYPERBOLIC OPERATOR: Poincare-ball exp map at origin and squared geodesic distance d_c^2 with fixed negative curvature -c=-1.
HYPERBOLIC LOCATION: First-level code assignment, after mapping encoder outputs and code vectors to the Poincare ball; the geometry is in the assignment score itself.
COUPLING PATH: Frozen A and current assignments produce g_k; A_i dot g_k is added to the Poincare distance score for the very same item-code candidates before argmax. Directed q_ik enters only as a capped 1%-scale tie-break.
COUPLING EQUATION: a_i = argmax_k[-d_{-1}(exp_0(h_i),exp_0(e_k))^2/T + lambda <A_i,g_k> + eps q_ik], with eps <= 0.01 lambda.
OBSERVABLES: First-level assignments and gradients/centroids change; the intended measurable change is higher cooccur_overlap_L3 (gate >0.0756), acceptable largest bucket share and ER, then Stage 3 test_R@10 >0.065. Also log adjacency_L3, extension alphabet, and all mandated metrics.
ABLATION BEHAVIOR OFF: Set lambda=0 and eps=0; use the plain baseline squared Euclidean assignment, with ordinary attached model computation (no detached substitute term).
ABLATION GEOMETRY OFF: Replace Poincare distance by squared Euclidean distance and use Euclidean-space code and region means throughout; remove curvature from maps, distances, profile geometry, and regularization. Preserve the same A, lambda, and tie-break so geometry is isolated.
ABLATION BOTH ON: Use symmetric A profiles in the Poincare score and frozen directed q tie-break at eps<=0.01 lambda. Also run directed-off eps=0 to isolate whether the tie-break helps without shifting the main partition.
SPEC EQUATIONS: Given current a_i, compute G[k,:] = normalize(sum_{i:a_i=k} A[i,:]); S_geo = -d_{-1}(z[:,None,:],v[None,:,:])^2/T; S_sym = A @ G.T; S_dir = precomputed_directed_region_mass(items,codes); a = argmax(S_geo + lambda*S_sym + eps*S_dir). Recompute G once at epoch boundary. A is CSR with fixed top-64 row neighbors; aggregate profiles through sparse scatter-add, and precompute directed transition pairs once, updating only their code-region lookup vector when assignments change.
SPEC INPUTS OUTPUTS: Inputs: encoder item latents h[N,d], first-level code vectors e[K,d], current assignments a[N], frozen co-consumption CSR A[N,N], frozen train-only directed transition pairs, c=1, T/lambda/eps constants. Output: assignments [N], refreshed normalized region profiles [K,N] represented sparsely or as neighbor-weight maps, and the standard multi-level RQ-VAE codes.
SAFEGUARDS: Clamp ball norms to at most (1-1e-5)/sqrt(c); use stable log1p/atanh distance implementation and clamp distance arguments; normalize profiles with denominator >=1e-12 and preserve previous/zero profile for empty codes; row-normalize A/q with zero-row handling; clamp q to [0,1], cap eps <=0.01 lambda; fp32 score accumulation, deterministic argmax tie policy; log score-term quantiles, empty-code counts, and largest bucket each epoch. Keep sparse truncation and its metric impact explicit; never densify N x N A.
END IDEA

IDEA: profile-curved-residual
TITLE: Co-consumption profile steers the hyperbolic residual quantizer
MOTIVATION: An item can be near one semantic region but still have unexplained co-consumption neighbors after its first code. Use the residual quantization stage to encode that remaining symmetric neighborhood signal, without asking directed transitions to reshape the main partition.
NOVELTY: Unlike the repository's Euclidean residual vector quantization and directed behavior-as-latent-offset experiments, this applies the train-only symmetric profile signal to residual-code choice through a curved geodesic residual, so the profile term and negative-curvature residual geometry jointly choose the same code.
CHANGE: After each RQ level, map the current residual into a fixed-curvature Poincare tangent representation; select the next code by geodesic residual fit plus co-consumption agreement with that level's current region profile. Retain directed transitions solely as an eps-bounded tie-break in the first level to respect the round's prescribed composition.
SPECIFICATION: At level l, let r_i^l be residual after subtracting prior selected code vectors in tangent coordinates, and let g^l_k=normalize(mean_{i:a_i^l=k} A_i) from previous epoch assignments. Map r_i^l and code e^l_k through exp_0 at curvature c=1; score s^l_ik=-d_c(exp_0(r_i^l),exp_0(e^l_k))^2/T_l + lambda_l <A_i,g^l_k>. For level 0 add eps q_ik (eps<=0.01 lambda_0); later levels use eps=0. Set a_i^l=argmax s; update residual r_i^{l+1}=log_0(exp_0(r_i^l) MobiusMinus exp_0(e^l_{a_i^l})). Use the baseline commitment/EMA loss and codebook sizes; initially test only level 0 if stable residual mapping is unavailable.
COST: Requires an additional co-consumption profile-score pass for each of four levels plus Poincare maps/distances; use top-64 CSR A and sparse region profiles, never dense N x N. At frozen scale, score work is approximately 4 x 154M point-code coordinate contributions/epoch (about 616M), plus ~6.3M sparse-neighbor updates/epoch and 72,000 training steps; likely materially slower than the 0.15 s baseline, so it is only viable if fused/vectorized kernels and four-card timing show 3000 epochs finish well under one hour. Abort this idea before full run if an epoch benchmark misses the wall-clock budget.
HYPOTHESIS: The residual code should resolve co-consumption neighbors left mixed by earlier levels, raising cooccur_overlap_L3 beyond 0.0756 while keeping largest first-level bucket share and L1 Hard ER near healthy baseline values; only then spend Stage 3 budget to test test_R@10 >0.065.
RISKS: Curved residual subtraction may be unstable or not align with the baseline's additive residual semantics; applying A at later levels may overfit repeated co-consumption or create code collapse; cost may exceed budget. Treat this as a gated pilot, not presumed improvement.
BEHAVIOR SIGNAL: Symmetric train-only co-consumption cosine A_ij, with directed immediate-predecessor region mass as first-level tie-break only.
BEHAVIOR COMPUTATION: Use train.parquet longest per-user training sequences to count each unordered within-sequence item pair once; symmetrize and L2-normalize rows, compute cosine similarities, retain top 64 positive row neighbors. Count last-history-item -> target transitions from training rows to build frozen directed pair masses; no held-out split is read.
LEAKAGE BOUNDARY: Both A and directed transition pairs are constructed once from training split and frozen. Per-epoch profiles derive only from A and current model assignments; validation/test events never affect code selection, profiles, schedules, or checkpoints.
HYPERBOLIC OPERATOR: Poincare exp_0/log_0, geodesic distance and Mobius subtraction at fixed curvature -1 (c=1).
HYPERBOLIC LOCATION: Each residual level's candidate code scoring and residual update, not an unrelated auxiliary loss.
COUPLING PATH: At a given residual level, current item residual is mapped to the ball, scored by Poincare distance to candidate code, and the same candidate receives its frozen-A co-consumption-profile affinity; that combined score selects the residual code. The first-level directed term only breaks ties at <=1% scale.
COUPLING EQUATION: a^l_i=argmax_k[-d_{-1}(exp_0(r^l_i),exp_0(e^l_k))^2/T_l + lambda_l <A_i,g^l_k> + 1_{l=0} eps q_ik], eps<=0.01 lambda_0.
OBSERVABLES: Level-wise assignments and residual/codebook gradients change; evaluate cooccur_overlap_L3 against the 0.0756 gate, L1 Hard ER, adjacency_L3, largest bucket share, extension alphabet, then Stage 3 test_R@10 under the frozen protocol. A positive target metric is required before Stage 3.
ABLATION BEHAVIOR OFF: Set every lambda_l=0 and eps=0, and use the unmodified plain Euclidean RQ-VAE residual assignment path (no detached auxiliary behavior loss).
ABLATION GEOMETRY OFF: Replace exp/log, Mobius residual update, and geodesic score by the baseline Euclidean residual arithmetic and squared Euclidean code distance at every level; keep the same A profiles and weights.
ABLATION BOTH ON: Use A-profile plus Poincare residual score at each level and first-level directed tie-break eps<=0.01 lambda_0. Include directed-off eps=0 as a separate control to isolate its effect.
SPEC EQUATIONS: For l=0..3: G_l[k]=normalize(sum_{i:a_i^l=k} A_i); u_i=exp_0(r_i^l); w_k=exp_0(e_k^l); a_i^l=argmax_k[-d(u_i,w_k)^2/T_l + lambda_l(A_i dot G_l[k]) + 1_{l=0}eps q_ik]; r_i^{l+1}=log_0(u_i MobiusMinus w_{a_i^l}). Refresh G_l once per epoch; train existing RQ-VAE losses on selected indices. Sparse top-neighbor aggregation only.
SPEC INPUTS OUTPUTS: Inputs: item residuals [N,d], codebooks [4,256,d], current per-level assignments, frozen CSR A, frozen directed transition pairs, fixed c/T_l/lambda_l/eps. Outputs: per-level code indices, next residuals, profiles, and ordinary 4-token SIDs.
SAFEGUARDS: Project ball points inside radius (1-1e-5)/sqrt(c); clamp arguments in exp/log/distance and use fp32; bound Mobius denominators away from zero; normalize sparse profiles with 1e-12 floor; keep empty regions stable; cap q and eps; monitor residual norms, geodesic scores, code usage, largest bucket and finite gradients. Benchmark vectorized epoch time before committing to 3000 epochs; never materialize dense A.
END IDEA
