IDEA: PTDIR-RQ
TITLE: Parallel-transported successor-direction gate in the residual quantizer: level-2+ SID tokens become cross-cell-aligned intent directions
MOTIVATION: Under the current RQ-VAE, level-1 partitions items into cells for spatial proximity, and levels 2..L carve each cell's residual independently. Stage 3 therefore has to estimate P(t2 | t1, history) separately inside every level-1 cell. For tail cells that conditional is estimated from a handful of transitions, so the generator's second-token distribution is essentially unlearned and the item-level history carries no usable evidence. Earlier rounds improved identifier statistics (radius, successor overlap, branching curvature, per-level feedback curvature) but left this per-cell estimation problem intact, which is consistent with recall staying at or below the 0.0553 baseline.
NOVELTY: The curved quantity is a DIRECTION (tangent angle), not a radius or a magnitude, and it is not a per-item codebook property: each item carries a successor-direction field computed from training-only directed transitions, and that field is PARALLEL-TRANSPORTED from the origin to the residual point before it is compared with the candidate centre. The transport is what makes the same direction number mean the same intent at two different residual locations, so a level-2 token id denotes the same forward-intent sector in every level-1 cell. This is mechanically different from successor-weighted Frechet codebook updates (which move centres), successor-overlap ranking (which reorders centres), behaviour-ranked radius (which scales distance), per-item branching curvature (which changes the metric per item) and per-level feedback curvature (which changes a level hyperparameter).
CHANGE: For levels l >= 2 the soft assignment score of every candidate centre gains a cosine term between the transported successor-direction of the item and the geodesic direction from the residual point to that centre; the hard index is still straight-through nearest-centre, so only the token semantics move, not the generator.
SPECIFICATION: Poincare ball D_c^d with trainable/fixed curvature c. Item embedding u_i (encoder output, radius-clamped). Behaviour field from the training split only: A_ij = count of directed training transitions i->j; p_ij = A_ij^0.75 / sum_k A_ik^0.75 (popularity discount, 0.75 is a documented default, not tuned); d_i = sum_j p_ij * log_0(u_j), unit-normalised, zero if item i has fewer than 2 distinct successors. At level l with residual point r_i (the baseline residual update, unchanged): transport the field with the Lorentz/hyperboloid closed form PT_{x->y}(v) = v + (<y,v>_L / (K - <x,y>_L))(x + y), K = -1/c, using the hyperboloid lift of (0, d_i) and of r_i, then map back. Assignment score s_ik = -d_P(r_i, c_k)^2 / (2 sigma^2) + cos( PT_{0->r_i}(d_i), log_{r_i}(c_k) ). sigma = median over centres of d_P(c_k, nearest_other_centre), measured once at initialisation and frozen; the cosine term is dimensionless so its weight is 1 by construction (no free coupling constant). Softmax over k gives the soft code; hard index = argmax; both feed the straight-through estimator and the existing RQ loss; d_i is a stop-gradient buffer.
COST: One offline pass over training transitions (E distinct edges, E much smaller than 24556 * mean successors) to build d_i, done once before epoch 1. Per step at the frozen scale: for each item in the batch and each of the L-1 coupled levels, one log map, one Lorentz parallel transport and one cosine, about 5d flops with d in [32, 64]; at 24 steps/epoch x 3000 epochs = 72000 steps, batch 1024, L=3, d=32 this is roughly 2.4e10 extra flops in total, i.e. low single-digit percent Stage-2 wall clock, and no measurable Stage-3 cost (Stage 3 only consumes the frozen SIDs).
HYPOTHESIS: If the level-2 token is a transported direction rather than a per-cell spatial residual, then transitions observed in other level-1 cells inform the same token, so the generator's conditional P(t2 | t1, h) for rare t1 is estimated from pooled evidence and the token is predictable from the history's direction (the last item's successor field) even when the exact (t1,t2) pair was never seen in that cell. Observable in the single run: Stage-3 conditional next-token loss/accuracy on low-count (t1,t2) pairs improves over the frozen-protocol baseline value on the same pairs, the transported-direction/assigned-centre cosine alignment is high and stable across levels, and Stage-3 test_recall@10 exceeds 0.065. It would be falsified if alignment is achieved but Stage-3 conditional loss on rare t1 cells is unchanged and recall stays at or below 0.0553.
RISKS: Near the origin the tangent direction is noisy, so items with small radius get unreliable d_i (guarded by the radius clamp and a Euclidean-cosine fallback). The popularity exponent 0.75 is a fixed prior and could over- or under-discount on this dataset. Direction pooling can blur genuinely cell-specific intent and hurt exactly the popular cells that dominate recall. The extra term can dominate the distance term if sigma is measured badly, collapsing levels 2+ into a pure angle partition. None of these is detectable without the logs, so all alignment/loss traces have to be recorded per epoch.
BEHAVIOR SIGNAL: Popularity-discounted directed successor direction per item, derived from training-only item-to-item transitions.
BEHAVIOR COMPUTATION: From the Stage-2 training interaction sequences only: count directed transitions A_ij between consecutive items, discount by the 0.75 power, row-normalise, average the tangent-space log-maps log_0(u_j) of the successors, then unit-normalise. Stored as a fixed per-item vector (24556 x d) before training and never recomputed.
LEAKAGE BOUNDARY: A_ij is built from the same training sequences the RQ-VAE is fitted on, and the SID table is frozen and written before the Stage-3 model is trained. No validation or test sequence, and no Stage-3 sampled interaction, is ever read while building d_i or assigning SIDs; diagnostics that use held-out data read the frozen SIDs and never write back.
HYPERBOLIC OPERATOR: Poincare distance d_P with curvature c (trainable through the existing radius/scale parameterisation, initialised at c=1) plus Lorentz-model parallel transport PT_{x->y} along the geodesic from the origin to the residual point, curvature K = -1/c.
HYPERBOLIC LOCATION: Inside the residual quantizer's per-level coding step for levels l >= 2, in the assignment score that produces the soft code and the straight-through hard index; the encoder, the residual update and the Stage-3 generator are untouched.
COUPLING PATH: behaviour field d_i -> transport to residual point r_i -> cosine with log_{r_i}(c_k) -> added to the same softmax that selects the level-l token -> token id -> Stage-3 prefix. Removing the behaviour term makes the assignment pure geodesic; removing the transport/curvature makes the direction comparison a flat-space cosine, which no longer aligns direction across cells and hence destroys the pooling; either removal changes the produced token ids.
COUPLING EQUATION: s_ik = -d_P(r_i, c_k)^2 / (2 sigma^2) + cos( PT_{0->r_i}( d_i^behaviour ), log_{r_i}(c_k) )
OBSERVABLES: (1) Stage-3 test_recall@10 against the 0.0553 baseline and the 0.065 target. (2) Stage-3 teacher-forced next-token loss and top-1 accuracy on the frozen SID prefixes, split by the training count of the (t1,t2) pair, to show whether rare-cell conditional estimation actually improved. (3) The mean cosine alignment between transported behaviour direction and assigned centre direction per level, plus the fraction of level-2 tokens that appear in more than one level-1 cell, as the mechanism check that pooling is real rather than a diagnostic of identifier quality. (4) Prefix behaviour predictability: accuracy of predicting t2 from the last history item's own direction field without seeing t1. Identifier-quality numbers (ER, prefix counts, collisions) are logged but are not the claim.
ABLATION BEHAVIOR OFF: d_i is set to the zero vector, the cosine term becomes exactly 0, and the level-2+ assignment reduces to the plain curved RQ-VAE; the switch is a boolean on the buffer, present in the code and unused in this round's single run.
ABLATION GEOMETRY OFF: PT is replaced by the identity and d_P by the Euclidean distance, so the score becomes -||r_i - c_k||^2/(2 sigma^2) + cos(d_i, c_k - r_i); same behaviour buffer, flat geometry.
ABLATION BOTH ON: The full equation above, with the successor-direction buffer, Poincare distance and Lorentz transport all active; this is the only arm trained.
SPEC EQUATIONS:
  p_ij = A_ij^0.75 / max(eps, sum_k A_ik^0.75);  d_i = normalize( sum_j p_ij log_0(u_j) )
  lift (0, d_i) to the hyperboloid; PT_{x->y}(v) = v + (<y,v>_L / (K - <x,y>_L))(x + y), K = -1/c
  a_ik = cos( PT_{0->r_i}(d_i), log_{r_i}(c_k) )
  s_ik = -d_P(r_i, c_k)^2 / (2 sigma^2) + a_ik
  q_ik = softmax_k(s_ik / T); hard_i = argmax_k s_ik; code = q + (onehot(hard) - q).detach()
  loss unchanged: RQ reconstruction + commit + codebook, plus the existing usage term
SPEC INPUTS OUTPUTS: Inputs: item embeddings u_i (24556 x d), transition counts A (sparse, training split), per-level residual points r_i and centres c_k, curvature c, measured sigma. Outputs: per-item per-level soft code q_i, hard token id, and the modified gradient to the encoder and the level-l codebook.
SAFEGUARDS: clamp the Poincare radius to (1 - 1e-3)/sqrt(c) before every log/exp map; compute PT and log in float64; floor sigma at 1e-3 of the ball diameter; skip (a_ik = 0) items with fewer than 2 distinct successors or with ||d_i|| < 1e-8; renormalise log_{r_i}(c_k) before the cosine; stop-gradient on d_i so training cannot collapse the behaviour field; assert finite scores and fall back to the pure distance term for that batch if a NaN appears.
END IDEA
