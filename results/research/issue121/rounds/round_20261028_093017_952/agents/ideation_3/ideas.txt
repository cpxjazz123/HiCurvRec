IDEA: incoming-cone-context
TITLE: Encode concentrated incoming contexts as hyperbolic tangent directions
MOTIVATION: Items reached from a concentrated set of predecessor regions are more predictable than items reached from diffuse contexts; preserve that useful incoming-context structure in the representation consumed by the quantizer, rather than optimizing SID granularity.
NOVELTY: Unlike successor-set radial hierarchy or sibling attraction, this uses the distribution of distinct training predecessors as a context prototype and learns a target's direction by a curved barycentric transport objective. No validation/test sequences are used.
CHANGE: For each target item, form a frequency-capped distribution over its predecessor items, map its predecessor context and target encoder output to the Poincare ball, then minimize geodesic distance from the target to the predecessor-context Frechet mean, weighted by concentration. Feed the resulting target representation directly to the unchanged RQ-VAE quantizer.
SPECIFICATION: From training transitions a->b, form p(a|b)=count(a,b)/sum_x count(x,b), with duplicate event counts retained. Let c_b=1-H(p(.|b))/log(max(2, number_of_distinct_predecessors(b))) for targets with at least two distinct predecessors; otherwise set c_b=0. For encoder output z_b, x_b=exp_0^k(Wz_b). For each minibatch target b, compute m_b as one differentiable Karcher-mean step from 0: m_b=exp_0^k(sum_a p(a|b) log_0^k(x_a)); minimize Lctx=mean_b c_b*d_k(x_b,m_b)^2. Quantize x_b using the baseline's explicit Euclidean tangent representation log_0^k(x_b) so SID export remains compatible. Switches: behaviour-off sets c_b=0; geometry-off replaces exp/log/d_k by identity/Euclidean weighted squared distance; both-on is the specified curved context loss.
COST: Precompute sparse predecessor distributions once. Per step at frozen scale, at most 24,556 sparse edge lookups and weighted reductions for batch items, plus O(Bd) exp/log/distance operations for B<=4096; no all-pairs matrix. One loss/gradient pass per step across 24 steps/epoch x 3000 epochs, expected modest overhead relative to baseline; cache x for unique batch items where practical.
HYPOTHESIS: If concentrated incoming contexts are a learnable predictive signal, both-on should produce target latents whose geodesic proximity to their actual predecessor-context prototypes improves and Stage3 test Recall@10 exceeds 0.065. Record context-loss and held-out diagnostics, but decide only on the single frozen Stage3 test score; compare conceptually against behaviour-off and Euclidean geometry-off definitions below, without training those arms.
RISKS: The incoming-context empirical distribution may be noisy for low-degree targets; a one-step mean is only an approximation; context averaging can over-smooth distinct modes; curvature may add no useful effect, and the target can drift from reconstruction/codebook fit.
BEHAVIOR SIGNAL: Directed immediate item transitions and per-target predecessor concentration.
BEHAVIOR COMPUTATION: Count adjacent (a,b) events in the training split only; normalize each target's incoming counts to p(a|b), and compute normalized entropy as specified. Use no validation/test edges.
LEAKAGE BOUNDARY: Build and freeze the sparse table exclusively from training interactions before Stage2; each item's global embedding/latent is shared across batches, and neither validation/test interactions nor user identity at inference enters SID construction.
HYPERBOLIC OPERATOR: Poincare ball exp_0^k/log_0^k maps and squared Poincare geodesic distance d_k, fixed negative curvature -k with k derived as inverse squared median encoder-latent norm on the first training pass, then frozen.
HYPERBOLIC LOCATION: The context-loss pathway on encoder latents during Stage2, before conversion back to tangent coordinates for baseline residual quantization.
COUPLING PATH: Training predecessor probabilities and concentration weight determine the context barycenter; the target and predecessor latents are compared by Poincare geodesic distance, so removing either behavior or curvature changes the same loss and its encoder gradients.
COUPLING EQUATION: Lctx=mean_b c_b*d_k(exp_0^k(Wz_b), exp_0^k(sum_a p(a|b)log_0^k(exp_0^k(Wz_a))))^2.
OBSERVABLES: Changes encoder gradients and item latents, particularly for concentrated-context targets; record training context geodesic loss, the fraction of target-context pairs closer than shuffled-context pairs, SID assignments, and Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: Set all c_b=0, making this pathway contribute zero and leaving baseline RQ-VAE training otherwise unchanged; this is a code switch only, not a trained arm.
ABLATION GEOMETRY OFF: Replace ball maps and geodesic distance by identity maps and squared Euclidean distance using the same p(a|b), c_b and loss normalization; code switch only, not trained.
ABLATION BOTH ON: Use the fully specified curved, training-predecessor-weighted context pathway; this is the sole trained candidate.
SPEC EQUATIONS: N_b={a: count_train(a,b)>0}; p_ab=count_train(a,b)/sum_{x in N_b}count_train(x,b). If |N_b|>1, c_b=1-[-sum_a p_ab log p_ab]/log|N_b|, else c_b=0. x_i=exp_0^k(Wz_i); m_b=exp_0^k(sum_{a in N_b}p_ab log_0^k(x_a)); Lctx=(sum_{b in batch}c_b*d_k(x_b,m_b)^2)/(sum_{b in batch}c_b+eps). Add Lctx to the existing Stage2 objective with coefficient 1, since it is a mean squared distance in the same curvature-scaled latent units and introduces no tuned coefficient. Export quantizer input as log_0^k(x_i).
SPEC INPUTS OUTPUTS: Inputs are encoder latents for batch items and training-only sparse predecessor lists/probabilities/concentration. Outputs are a scalar context loss and tangent-space quantizer inputs; gradients flow through target and predecessor encoder latents.
SAFEGUARDS: Use float32 for ball operations; clamp k||v|| to at most 1-1e-5 before atanh; use stable series near zero for exp/log; clamp squared-distance acosh arguments to >=1+1e-7; normalize probabilities with eps and skip empty predecessor rows/c_b=0; use the weighted denominator plus eps; detach no latent in the prototype pathway; verify finite loss and gradients. Freeze k from the first-pass median norm with a documented positive floor.
END IDEA
IDEA: transition-transport-residual
TITLE: Curved predecessor-to-target transport as a residual prediction task
MOTIVATION: A next-item identifier should encode which transitions a source item tends to make, not merely which items share a broad successor set. The directed transition map can be represented as a curved displacement whose endpoint is the target item.
NOVELTY: This optimizes a directed transport residual in the hyperbolic tangent space rather than sibling coherence, radial successor hierarchy, or behavior-weighted code assignment. The signal is specifically the source-conditioned target distribution, and the curved operation constructs the target candidate used by the residual loss.
CHANGE: Learn a small linear map from each source item's Poincare log-coordinate to a tangent displacement, apply the Poincare exp map to obtain a predicted successor point, and train that point toward the observed destination using geodesic distance; quantization still reads the item encoder representation, which receives gradients through both source and destination roles.
SPECIFICATION: Estimate transition probabilities q(b|a)=count_train(a,b)/sum_y count_train(a,y). Let u_i=log_0^k(exp_0^k(Wz_i)). Set v_ab=A u_a, y_ab=exp_{x_a}^k(v_ab), the Poincare exp map at source x_a. For sampled training transition (a,b), use Ltrans=E[q-sampled weight * d_k(y_ab,x_b)^2], with event sampling from the observed training transition multiset (equivalently each observed edge contributes its empirical probability). Add loss coefficient 1 after expressing all coordinates in curvature-normalized units. Behaviour-off samples item pairs uniformly independent of transitions; geometry-off uses y=a+v and Euclidean squared distance. Both-on uses observed directed transitions and manifold exp/distance; only both-on is trained.
COST: Store a sparse training transition table; the per-step cost is O(Bd^2) for a shared low-rank map A (rank r, cost O(Bdr)) plus O(Bd) curved maps/distances, with B<=4096, at 24 steps per epoch for 3000 epochs. Use r=min(d, number of nonzero singular directions in training transition covariance) chosen once by matrix rank threshold at machine precision; materially smaller than full pairwise scoring. Sampling incurs no full-catalogue operation.
HYPOTHESIS: If directed local transitions share a compositional curved displacement that encoder latents can capture, transport loss will reshape item representations in a way useful to the generative next-item model; observable evidence is a lower training transition geodesic error and above-threshold Stage3 test Recall@10. No behavioural diagnostic is an admission gate.
RISKS: Transitions can be multimodal, making a single linear map predict an average destination; popular sources may dominate unless empirical edge sampling is normalized; this may encode sequence noise or conflict with reconstruction. Curvature can be unnecessary despite a useful transition objective.
BEHAVIOR SIGNAL: Directed adjacent-item transition distribution q(b|a), computed from training histories.
BEHAVIOR COMPUTATION: Count every adjacent pair in each training user sequence, create sparse source rows and normalize row counts to q(b|a); use training transition events only, never validation/test pairs.
LEAKAGE BOUNDARY: Freeze the transition table from the training split before optimization. The mapping is global by item and needs no current-user history for a SID; no held-out transition or user-specific test context is used in the loss or export.
HYPERBOLIC OPERATOR: Poincare exp at x_a of a learned tangent displacement and Poincare geodesic distance, fixed curvature -k; set k to the inverse square of the first-pass median latent norm and freeze it.
HYPERBOLIC LOCATION: Transition prediction loss before quantization, with both source and target encoder latents lying on the same ball representation read by the RQ-VAE.
COUPLING PATH: The observed directed edge selects the source and target and supplies q(b|a); the source determines a curved exp-map endpoint and the target is compared to that endpoint with geodesic distance. Removing the edge signal changes the pairs; removing curvature changes predicted endpoints and the metric in the same loss.
COUPLING EQUATION: Ltrans=E_(a,b)~q_train [d_k(exp_{x_a}^k(A log_0^k(x_a)), x_b)^2], x_i=exp_0^k(Wz_i).
OBSERVABLES: Encoder and transport-map gradients/updates should change; measure transition geodesic error versus frequency-matched shuffled pairs, per-item latent displacement norms, SID assignment changes, and the single Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: Replace observed transition sampling with a deterministic frequency-matched permutation of destination items, preserving batch shape but removing directed behaviour; implementation switch only, no training arm.
ABLATION GEOMETRY OFF: Replace exp-at-source with vector addition and d_k with Euclidean squared distance, retaining exactly the same observed transitions and model capacity; implementation switch only, no training arm.
ABLATION BOTH ON: Use observed training transitions, Poincare exp-at-source and Poincare geodesic loss as written; this is the sole trained candidate.
SPEC EQUATIONS: x_i=exp_0^k(Wz_i); u_a=log_0^k(x_a); v_ab=A u_a; y_ab=exp_{x_a}^k(v_ab); Ltrans=sum_(a,b in E_train) w_ab*d_k(y_ab,x_b)^2/sum_E w_ab, with w_ab=count_train(a,b)/sum_E count_train. Add Ltrans with coefficient 1 after curvature normalization. Use minibatch edges sampled proportionally to w_ab and an unbiased mean estimator; keep the baseline reconstruction/commitment losses intact. Quantizer input is log_0^k(x_i).
SPEC INPUTS OUTPUTS: Inputs are encoder latents for source/destination item IDs, a low-rank transition map A, and the frozen sparse training edge distribution. Outputs are scalar transition loss and tangent-space quantizer vectors.
SAFEGUARDS: Use float32 manifold functions, clamp ball norms to (1-1e-5)/sqrt(k), stable small-norm exp/log limits, clamp acosh arguments, reject nonfinite values, and add eps to probability denominators. Initialize A to zero so the initial endpoint is x_a; constrain its spectral norm to the scale of the latent covariance using a one-time covariance-derived bound (not a searched clip). Normalize edge loss by total edge weight; use deterministic sampler seed inherited from the frozen run. Ensure tangent coordinates and loss use the same fixed k.
END IDEA
