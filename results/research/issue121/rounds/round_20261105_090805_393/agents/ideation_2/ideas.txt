IDEA: RSPC-RQ
TITLE: Residual-scaled Poincaré assignment with a per-pair successor-code prior and same-chart curved residual subtraction
MOTIVATION: This is a curvature mechanism, and it repairs the second-order collapse that GEOCAP-RQ showed. GEOCAP's first-order gain was real (valid_l1_hard_er 3.885 vs baseline 16.390; valid_l1_positive_hit_rate 0.1222 vs 0.0794; level2_distinct_prefixes 4236; l3_refinement_gain_bits 2.82), but its third level degenerated (l3_collision 0.549 against the 35% Stage-3 gate), so no recall was measured. The cause is structural: GEOCAP made each codeword's cell size and a per-codeword additive distance offset grow with that item's *own* demand, so a few high-demand cells absorbed the residual mass at level 3. RSPC-RQ changes both quantities: the cell size becomes the layer's measured residual scale (a residual/occupancy statistic), and the behaviour term becomes a row-normalised, pair-conditioned log-likelihood ratio whose mean log-weight inside every context row is 0 unless that row carries real transition information, so it can tilt which code an item takes inside its context but can never globally inflate demand for a codeword. A straight-through soft assignment with a measured temperature keeps deep codewords receiving gradient instead of starving, which is the concrete mechanism that makes level 3 spread.
NOVELTY: Different from the three earlier rounds. It is not GEOCAP (no per-codeword demand-derived area-law radius, no per-codeword additive offset; no popularity term anywhere). It is not holonomy-path-behaviour-rq (there is no transport of the residual into a second chart: exponentiate, subtract and decode all happen at the origin of one Poincaré ball with curvature −1, and log_0 is the exact inverse of exp_0). It is not BRad-RQ (the behaviour signal is not a per-item context entropy used to rank radii; it is a sparse per-pair transition count matrix between the item's own level-(l−1) code and its successors' level-l code). It is also not a Euclidean quantiser with a behaviour suffix: the geodesic distance is the term that separates items inside a context row, the curved subtraction defines the residual that the next level sees, and the temperature is measured from the geodesic cost margin.
CHANGE: The assignment logit at level l is the Poincaré geodesic distance between the residual and the code, both exponentiated into the same ball after dividing by the layer's measured residual scale β_l, minus a 1/lnK-scaled log of the row-normalised pair transition prior between the item's level-(l−1) code and the candidate level-l code. Codes are selected by a straight-through softmax whose temperature is the measured median top1–top2 cost margin, and the residual is re-projected with Möbius subtraction inside the same chart.
SPECIFICATION: Parameters and buffers (d = encoder output width, K = 256 codes per level, L = 3 levels): learnable code tangents U ∈ R^{L×K×d} (exactly the baseline codebook shape, initialised from the baseline Euclidean codebook); non-trainable buffers β_1..β_L ∈ R_+ (EMA of the per-level residual RMS, detached); τ_1..τ_L ∈ R_+ (EMA of the measured median top1–top2 geodesic cost margin, detached); B_1 ∈ Z^{1×K}, B_2, B_3 ∈ Z^{K×K} (training-split directed transition counts, refreshed once per epoch, detached, no gradient). Per level l = 1..L, on a minibatch of residuals r_{l−1}: (1) β_l ← (1−μ)β_l + μ·RMS(r_{l−1}) with μ = 0.01 and floor 1e-3 (detached); buffer initialised on the first minibatch, not at zero. (2) u_i = r_{l−1,i}/β_l; p_i = tanh(||u_i||/2)·u_i/(||u_i||+1e-8); q_{l,k} = tanh(||U_{l,k}||/2)·U_{l,k}/(||U_{l,k}||+1e-8), with ||U_{l,k}|| clamped to ≤ 6. (3) d_H(i,k) = arcosh(1 + 2||p_i − q_{l,k}||²/((1−||p_i||²)(1−||q_{l,k}||²))). (4) k'_i = the level-(l−1) code already chosen for item i in this forward pass (k'=0 dummy for l=1); prior row π_{k'} = (B_l[k',:] + 1)/(S_l[k'] + K)·K with S_l[k'] = Σ_k B_l[k',k]. (5) logit_{i,k} = −d_H(i,k) − (1/ln K)·log π_{k'}[k]; s_{i,k} = softmax_k(logit_{i,k}/τ_l); h_i = one_hot(argmax_k s_{i,k}) − s_{i,k}.detach() + s_{i,k} (straight-through hard code, soft gradient to costs, no detach on the decode path). (6) Decode with the SAME code positions: x_q = x + (Σ_l β_l·log_0(q_{l,argmax}) − x).detach(), i.e. the explicit STE x_q = x + (x_q − x).detach() is preserved and β_l·log_0(q) = β_l·U_{l,k} is used both in the reconstruction and in the assignment (identical positions, one chart). (7) Curved residual: r_l = β_l·log_0(p_i ⊖ q_{l,argmax}). Epoch boundary only: one no-grad forward pass over the 24556 training items caches the argmax code per level, then B_l[k',k] is rebuilt from the training-split directed pairs (i_t → i_{t+1}).
COST: Relative to the baseline RQ-VAE Stage 2, ≈1.02× per step plus ≈4% per epoch. At the frozen scale, 24556 training items over 24 steps/epoch gives ≈1023 items per step; the per-level cost matrix is 1023×256 geodesic distances (3 levels, d=64 ⇒ ≈50 MFLOP of matmul-equivalent work, the same order as the baseline Euclidean assignment it replaces), and the added hyperbolic elementwise work (tanh, 2·artanh, arcosh, Möbius subtraction) touches only 1023×64 and 256×64 arrays, well under 2% of the step. The prior step is three row gathers plus a log — negligible. The only real addition is the epoch-boundary refresh: one no-grad encoder forward over 24556 items (≈24 steps' worth) plus a sparse scatter-add, ≈+4.2% per epoch. Total Stage 2 wall clock ≈+5–8%; Stage 3 protocol, epochs and card count unchanged. Extra parameters: zero (U has the baseline codebook shape). Extra buffers: three K×K int32 tables and three K×K float priors (≈0.25 MB and 0.75 MB), plus 2L scalars.
HYPOTHESIS: The idea is worth keeping only if: (i) the first-order gain survives — valid_l1_hard_er ≤ 6 and valid_l1_positive_hit_rate ≥ 0.11, i.e. no return to the baseline order of magnitude (16.390 / 0.0794); (ii) the third level spreads — l3_collision < 0.25, i.e. clears the 35% Stage-3 gate that GEOCAP's 0.549 broke, with level-3 effective code count (perplexity of the l3 code histogram over training items) materially above 256·exp(−0.549·ln?) ≈ the GEOCAP collapse level and with level2_distinct_prefixes ≥ 4000; (iii) the behaviour prior is predictable rather than noise — the l3 code actually chosen lies in the top-5 of its own prior row π_{k'} at a rate above the 5/256 uniform baseline, measured on training item pairs only as a diagnostic; (iv) the single frozen Stage-3 run reports test_recall@10 > 0.065 (baseline 0.0555, historical best 0.0638). Any one of (i)–(iii) failing means the coupling is decorative even if recall moves.
RISKS: At l=1 the prior row is the single dummy row 0, so the prior degenerates into a global successor-code distribution — a bounded (row-normalised to mean 1) popularity tilt. If it is strong enough to bias the l1 partition, the GEOCAP-style demand bias can partially return; the row normalisation bounds but does not eliminate this.; A self-confirming loop: B_l is built from the previous epoch's argmax assignments, so early bad prefixes can be reinforced for several epochs. The mitigation is that the conditioning code k'_i is the item's own level-(l−1) code, which moves with the encoder, and that the prior is only a bounded tilt against a geodesic term that is O(1); if the encoder is slow to move, prefixed lock-in is still possible.; Poincaré numerics: as ||p|| → 1 with clamped ||U|| ≤ 6 the conformal factor (1−||q||²) becomes small (≈0.01) and arcosh arguments can overflow or become NaN, especially with small β_l (large residuals).; The measured temperature τ_l could collapse (near-zero margin) and saturate the softmax to one-hot, or blow up and make every assignment uniform, which would destroy the residual chain; the EMA of a median is robust but not guaranteed to stay in a useful range.; The prior strength 1/ln K is derived, not tuned: if it is far too weak the run reduces to a pure curved residual quantiser and the behaviour side contributes nothing observable; that outcome cannot be repaired without a sweep, which the policy forbids.; Soft straight-through assignment changes the codebook gradient relative to hard RQ, so the comparison to the historical best 0.0638 is not perfectly like-for-like; a single run also cannot separate the coupling gain from seed noise.
BEHAVIOR SIGNAL: Per-pair directed successor-code transition counts: for each level l, the count of training-split sequences in which an item i with level-(l−1) code k' is immediately followed by an item j whose level-l code is k. The signal is the code-level successor distribution B_l[k',·], used as a row-normalised prior over level-l codes; it is not item popularity, and it is not the item's own context entropy.
BEHAVIOR COMPUTATION: From the Stage-2 training split only (the same training user sequences with adjacent timestamps used to form the training items): form the directed multiset of consecutive pairs (i_t → i_{t+1}) with gap 1 inside each user sequence; add the Stage-1 co-consumption pairs only if the baseline already uses them for training items, otherwise not. Once per epoch, run one no-grad forward pass over the 24556 training items' encoder outputs with the current codebook, cache T_l(i) = argmax code at level l, and accumulate B_l[k',k] += 1 for every training pair with T_{l−1}(i)=k' and T_l(j)=k (k'=0 dummy at l=1). The table is frozen for the whole following epoch, is integer-valued, and never carries gradient.
LEAKAGE BOUNDARY: The transition counts use only interactions from the training split, over the 24556 training items, and only the previous epoch's cached argmax codes of those training items. Validation and test interactions never enter B_l, never enter β_l or τ_l (which are minibatch training statistics), and never enter the codebook or the SID assignment. No Stage-3 label, no test sequence and no validation split item is read during SID construction; Stage 3 consumes the frozen SIDs and interacts with nothing in this mechanism.
HYPERBOLIC OPERATOR: Fixed negative curvature c = −1 in the Poincaré ball: geodesic distance d_H(p,q) = arcosh(1 + 2||p−q||²/((1−||p||²)(1−||q||²))), exponential map at the origin exp_0(v) = tanh(||v||/2)·v/(||v||+1e-8), logarithmic map log_0(p) = 2·artanh(||p||)·p/(||p||+1e-8), and Möbius subtraction a ⊖ b = a ⊕ (−b) with a ⊕ b = ((1+2a·b+||b||²)a + (1−||a||²)b)/(1+2a·b+||a||²||b||²). Curvature is fixed, not trainable; no constant is chosen by search.
HYPERBOLIC LOCATION: In quantisation, at every level of the residual-quantiser chain: the residual and the code tangents are exponentiated into the ball and compared by the geodesic distance in the assignment cost; the same exp_0/log_0 pair defines the decoded code vector for the straight-through reconstruction; and the residual passed to the next level is produced by Möbius subtraction inside that same ball. It also sets the cell size, because the tangent-space normalisation is β_l, the measured residual RMS of that level.
COUPLING PATH: One pathway, no parallel branch: r_{l−1} → normalise by measured β_l → exp_0 into the ball → geodesic distance to exp_0(U_{l,k}) → combined in a single logit with the pair prior log π_{k'_i}[k], where k'_i is the item's own level-(l−1) code and π is the row-normalised training transition count → straight-through softmax → argmax code k_l → (a) decodes through the same log_0 position into the STE reconstruction, and (b) produces the next residual by Möbius subtraction in the same ball. Removing the prior changes the logit (behaviour-off) and removing the curvature changes the distance, the decode and the residual (geometry-off), so neither term is a decoration.
COUPLING EQUATION: logit_{i,k}^{(l)} = −d_H( exp_0(r_{l−1,i}/β_l), exp_0(U_{l,k}) ) − (1/ln K)·log( K·(B_l[k'_i,k] + 1)/(S_l[k'_i] + K) ), with d_H the arcosh Poincaré distance of curvature −1, B_l[k'_i,·] the training-only successor-code transition counts conditioned on the item's own level-(l−1) code, and β_l the measured residual RMS of level l; the code exponentiated is exactly the code decoded: β_l·log_0(q_{l,k}) = β_l·U_{l,k}.
OBSERVABLES: (1) SID assignment: valid_l1_hard_er stays ≤ 6 and valid_l1_positive_hit_rate ≥ 0.11 (no return to the baseline 16.390 / 0.0794 order of magnitude); level2_distinct_prefixes ≥ 4000. (2) Third-level dispersion: l3_collision falls below 0.25 (from GEOCAP's 0.549) and the perplexity of the level-3 code histogram over training items rises materially, so the Stage-3 35% gate passes. (3) Parameter update: the codebook gradient is spread over more than one code per item at level 3 (nonzero mass in the softmax above the argmax), and the level-3 codebook rows all receive nonzero accumulated gradient. (4) Prefix behaviour predictability: the chosen level-3 code is in the top-5 of its own prior row π_{k'} at a rate above the uniform 5/256 baseline. (5) Stage 3: test_recall@10 > 0.065 on the single frozen run.
ABLATION BEHAVIOR OFF: PRIOR_MODE = uniform: the prior term is replaced by log 1 = 0 (equivalently B_l ≡ 0), so logit = −d_H only; β_l, τ_l, the curved residual, the Möbius subtraction and the straight-through soft assignment are all unchanged. The switch exists in the code and is exercised by a unit check that the prior term is exactly zero, but this arm is never trained.
ABLATION GEOMETRY OFF: GEOM_MODE = euclidean: d_H becomes ||p−q||, and exp_0 / log_0 / ⊖ become the identity (β_l·U_{l,k} and plain r_{l−1} − β_l·U_{l,k}), so the label is the same residual-scaled Euclidean residual quantiser; the behaviour prior is retained with the Euclidean cost. The switch exists in the code and is checked by asserting that no arcosh/tanh/artanh is on the forward path, but this arm is never trained.
ABLATION BOTH ON: The default and only trained configuration: PRIOR_MODE = behaviour and GEOM_MODE = poincare simultaneously, i.e. curved assignment, curved residual, curved decode and the pair transition prior in one logit. One run, 3000 Stage-2 epochs on four cards, frozen Stage-3 protocol, no early stopping, no sweep, no second seed.
SPEC EQUATIONS: Inputs: encoder output z ∈ R^d (baseline width), r_0 = z. Buffers: β ∈ R_+^L (EMA of per-level residual RMS, μ = 0.01, floor 1e-3), τ ∈ R_+^L (EMA of per-level median top1−top2 cost margin, floor 1e-3), B_l ∈ Z^{(K^{l−1} or K)×K} (l=1: 1×K; l≥2: K×K), S_l = B_l·1. Constants (all derived, none tuned): curvature c = −1; codebook size K (baseline, 256); prior scale 1/ln K; Laplace smoothing α = 1; EMA rate μ = 0.01; clamps listed under safeguards. Per level l = 1..L:   β_l ← (1−μ)·β_l + μ·sqrt(mean_batch ||r_{l−1}||²)   u_i ← r_{l−1,i}/β_l ;  p_i ← tanh(||u_i||/2)·u_i/(||u_i||+1e-8)   V_{l,k} ← clamp(U_{l,k}, ||·|| ≤ 6) ;  q_{l,k} ← tanh(||V_{l,k}||/2)·V_{l,k}/(||V_{l,k}||+1e-8)   D_{i,k} ← arcosh( max(1 + 2||p_i−q_{l,k}||²/((1−||p_i||²)(1−||q_{l,k}||²)), 1+1e-8) )   k'_i ← (l == 1 ? 0 : argmax_{k} s_{i,k} from level l−1)   π_{k'} ← (B_l[k',:] + 1)/(S_l[k'] + K)·K ;  L_{i,k} ← −D_{i,k} − (1/ln K)·log π_{k'_i}[k]   m_i ← median_k_of(L_{i,(1)} − L_{i,(2)})  (two smallest costs, per minibatch)   τ_l ← (1−μ)·τ_l + μ·m_i   s_{i,·} ← softmax(L_{i,·}/τ_l) ;  ĥ_{i,k} ← 1[k = argmax s_{i,k}]   h_i ← ĥ_i − s_i.detach() + s_i   x_q ← x + (Σ_l β_l·log_0(q_{l,argmax}) − x).detach()          # explicit STE, preserved   r_{l,i} ← β_l·log_0( p_i ⊖ q_{l,argmax} )                     # same chart Loss: L_recon(x, x_q) + baseline commit/entropy terms, unchanged. Epoch boundary: one no-grad forward over 24556 training items → T_l(i) = argmax s; rebuild B_l from training pairs (i_t → i_{t+1}). Outputs: prefix tuple (k_1,k_2,k_3) per item, x_q, and the level-wise code histograms.
SPEC INPUTS OUTPUTS: Takes: the encoder output z ∈ R^d of a training item (plus β, τ and B_l buffers), the learnable code tangents U ∈ R^{L×K×d}, and the training-split directed pairs (i_t → i_{t+1}) at epoch boundaries. Returns: per level l the straight-through soft assignment s_i ∈ Δ^{K−1} and hard code k_l ∈ {1..K}; the reconstructed vector x_q = x + (Σ_l β_l U_{l,argmax} − x).detach() ∈ R^d; the next residual r_l ∈ R^d; and, at epoch boundaries, the refreshed integer tables B_l. The SID handed to the generative recommender is (k_1,k_2,k_3).
SAFEGUARDS: (1) STE is mandatory and explicit: x_q = x + (x_q − x).detach() on the decode path, and the softmax supplies gradient only through h = ĥ − s.detach() + s; the encoder is never fed a constant target. (2) Assignment and decode share the same code position β_l·log_0(q_{l,k}) = β_l·U_{l,k}: one chart, one set of positions, so the codebook cannot be optimised to a different location than the one it is scored against (the failure of the holonomy arm). (3) Norm clamps: ||V|| ≤ 6 so ||q|| ≤ tanh(3) ≈ 0.995; p_i rescaled to ||p|| ≤ 1 − 1e-5; both conformal factors floored at 1e-3; arcosh argument floored at 1 + 1e-8; ||p−q|| floored at 0. (4) Möbius subtraction denominator floored at 1e-8, with an automatic fallback to plain Euclidean subtraction for that step if the floor is hit, so a NaN cannot propagate into the residual chain. (5) β_l floor 1e-3 and initialisation from the first minibatch rather than zero; no division by an untrained statistic. (6) τ_l EMA floored at 1e-3 and initialised from the first minibatch margin. (7) Prior is row-normalised with Laplace smoothing, so a context row with no training transitions becomes exactly uniform (log π = 0) and no code can be favoured by absence of data; all counts are integers, refreshed only from training pairs and only from detached previous-epoch assignments. (8) The three switches PRIOR_MODE ∈ {behaviour, uniform} and GEOM_MODE ∈ {poincare, euclidean} exist as explicit code paths defaulting to [behaviour, poincare]; a shape-and-finiteness assertion runs before the first optimiser step; no arm is trained with either switch off, and no constant is swept.
END IDEA
