IDEA: successor-anchor-l2-poincare-sinkhorn-v1
TITLE: Level-1 untouched; a successor-anchored Poincare term inside the level-2 Sinkhorn cost so the fine SID token encodes where the item leads
MOTIVATION: round_20261106_020541_888 fixed L1 (Hard ER 16.39->6.36, 256/256 codes) but merged the fine layer (955 distinct L2 prefixes vs 7414; weighted 3-level collision 0.771 vs 0.065) and was refused before Stage3. Coarse re-drawing ate the fine resolution: once L1 absorbed the within-cluster variance the residual had nothing left to separate. Fix: never redraw L1; spend behaviour+curvature on making the level-2 code behaviourally predictive, since a TIGER-style decoder commits token 2 before token 3, so an L2 code naming the coarse neighbourhood the item leads to is directly usable.
NOVELTY: Not a coarse re-weighting, not a Euclidean behaviour suffix, not a side loss. Training transitions are projected INTO the same Poincare ball through the coarse codebook (exp-of-log-mean successor anchor b_i) and enter as the second term of the level-2 cost matrix the baseline Sinkhorn plan already consumes; L1 and L3 stay byte-identical. The term is a DIFFERENTIATOR, not the attractor-to-one-shared-rank that merged items last round; anti-collapse rests on the baseline column marginals, which a cost-only term cannot escape.
CHANGE: C2(i,k) = d_k(r_i,c_k)^2/a_i - beta_i*d_k(b_i,c_k)^2/m_i with per-row medians a_i, m_i and a derived switch beta_i in {0,1}; the level-2 assignment remains the baseline balanced Sinkhorn plan on C2.
SPECIFICATION: L1 cost, plan and codebook unchanged (asserted equal at step 0). Per epoch, from the Stage-2 training split only: S_i = top-M directed successors of item i (M = ceil(median positive out-degree), cap 20; |S_i|<2 gives beta_i=0); b_i = exp_0^k((1/|S_i|) sum_{j in S_i} log_0^k(u_{g(j)})), u_{g(j)} the detached L1 code embedding of successor j; stored detached (24556 x d). Per step, inside each L1 group over the 256 L2 codes: d2_r = d_k(r_i,c_k)^2, d2_b = d_k(b_i,c_k)^2, a_i = median_k d2_r, m_i = median_k d2_b (floored at 1e-8), C2 = d2_r/a_i - beta_i*d2_b/m_i, P2 = baseline level-2 Sinkhorn(C2) with the baseline's iterations, marginals and temperature. beta_i = 1 is the documented neutral default because both terms are median-normalised to one per-row scale, so no weight is chosen by trying values. No argmin anywhere; kappa = 1 fixed via model/poincare_contract.
COST: L1 unchanged. Per step (24556 items, 24 steps/epoch, ~1023 items/step): one extra 1023 x 256 Poincare distance matrix at L2 (~8 MFLOP, doubling only the L2 distance evaluation, not the encoder) plus per-row medians; per-epoch anchor precompute ~5 MFLOP, sub-second on four cards. Total ~1-2% of Stage-2 wall clock over 3000 epochs; no extra arm, epoch or sweep.
HYPOTHESIS: (i) MI(level-2 code; successor coarse group) rises on train data versus the geometry-only form; (ii) distinct L2 prefixes stay >= ~7414 (not 955) and the weighted 3-level collision stays <= 0.275, far under the 35% gate; (iii) Stage-3 teacher-forced token-2 accuracy given a correct token 1 rises, carrying test_recall@10 above 0.065. If the L2 prefix count falls or the collision rises, the anchor is acting as an attractor and the idea is refuted.
RISKS: ["Tail items with <2 successors give a noisy anchor; beta_i=0 protects them, but a long weak tail could dominate the term.","The reward can still concentrate a group on the codes nearest a dominant successor coarse code; the column marginal li

mits but does not forbid it, and no ablation is trained.","Behaviour-optimised L2 against an appearance reconstruction loss can raise ER and degrade the residual codebook.","Anchors use last epoch's coarse codebook, so early anchors are stale while L1 moves.","beta_i=1 with median normalisation assumes comparable tails; heavy tails let one term dominate.","Single seed: gains inside seed noise cannot be separated."]
BEHAVIOR SIGNAL: Directed training-sequence item-to-item transitions (one-step co-consumption), aggregated per item into a successor multiset and, through the coarse codebook, into a hyperbolic successor anchor.
BEHAVIOR COMPUTATION: Stage-2 TRAINING split only: count i->j over consecutive positions in i's training sequences (symmetric co-consumption enters both directions), keep top-M by count (M = ceil(median positive out-degree), cap 20), form S_i, then b_i = exp_0(mean over S_i of log_0(L1 code embedding of j)). Recomputed once per epoch from training sequences and the current coarse codebook; no val/test sequence is read.
LEAKAGE BOUNDARY: Every successor, count and anchor comes from training sequences only and the vocabulary is frozen to the 24556 training items, so no val/test item can enter S_i or any embedding used by b_i. Nothing in the SID construction reads val/test interactions, Stage-3 output or any metric: no early stopping, no selection, one 3000-epoch pass; diagnostics are recorded, never gating.
HYPERBOLIC OPERATOR: Poincare squared distance d_kappa^2 with fixed negative curvature -kappa (kappa = 1), applied twice per pair (residual/code and successor-anchor/code) inside the level-2 cost; exp_0/log_0 at the origin build the anchor.
HYPERBOLIC LOCATION: Quantisation, at the level-2 (fine residual) Sinkhorn cost matrix: anchor precompute once per epoch, cost once per step; L1 and L3 keep the baseline metric.
COUPLING PATH: training transitions -> S_i -> curved anchor b_i in the ball -> second term of C2 -> baseline Sinkhorn-balanced level-2 plan -> level-2 SID token -> Stage-3 prefix generation. beta_i=0 deletes the behaviour information from the plan; d_k -> d_E changes both terms, so the plan changes too. Both multiply into one scalar consumed by one plan.
COUPLING EQUATION: C2(i,k) = d_kappa(r_i,c_k)^2/a_i - beta_i*d_kappa(b_i,c_k)^2/m_i, with b_i = exp_0^k((1/|S_i|) sum_{j in S_i} log_0^k(u_{g(j)})), plan = baseline Sinkhorn(C2).
OBSERVABLES: distinct L2 prefixes (>= ~7414, not 955); weighted 3-level collision (<= 0.275); L1 code usage (baseline, L1 untouched); MI(L2 code; successor coarse group) on train data; Stage-3 teacher-forced token-2 accuracy given correct token 1; Stage3 test_recall@10 > 0.065.
ABLATION BEHAVIOR OFF: beta_i = 0 for all i; the anchor is never built; C2 is the pure curved residual cost. Exact switch, no arm trained.
ABLATION GEOMETRY OFF: d_kappa replaced by Euclidean on the same vectors in both terms and exp_0/log_0 by identity (b_i = plain mean of successor coarse embeddings); everything else identical including the Sinkhorn plan. Exact switch, no arm trained.
ABLATION BOTH ON: the full coupled run above; the single trained arm, one 3000-epoch four-card pass, no early stopping.
SPEC EQUATIONS: per epoch: S_i = topM(train transition counts out of i); |S_i| >= 2 else beta_i = 0; b_i = exp_0(mean_{j in S_i} log_0(u[g(j)])). Per step: d2_r = d_k(r_i,c_k)^2; d2_b = d_k(b_i,c_k)^2; a_i = max(median_k d2_r, 1e-8); m_i = max(median_k d2_b, 1e-8); C2 = d2_r/a_i - beta_i*d2_b/m_i; P2 = Sink

hornBaseline(C2); L1 and L3 use the baseline cost and plan. Pseudocode: for each epoch { rebuild b detached from train transitions and the current coarse codebook; for each of 24 steps { encode batch; P1 = baseline Sinkhorn(baseline L1 cost); build C2 as above inside each L1 group; P2 = baseline Sinkhorn(C2); P3 = baseline Sinkhorn(baseline L3 cost); baseline losses; backward } }.
SPEC INPUTS OUTPUTS: Inputs: batch L2 residuals r_i in the ball (dim d), the 256 L2 code embeddings c_k, the detached 24556 x d anchor table b_i, the switch beta_i, kappa. Outputs: the level-2 cost matrix C2 (shape the baseline plan consumes), the plan P2, each item's level-2 SID token, plus logged per-row medians, beta coverage and anchor norms.
SAFEGUARDS: clamp Poincare norms to (1-1e-5)/sqrt(kappa) and atanh args to 1-1e-7; floor squared distances and a_i, m_i at 1e-8; fall back to beta_i = 0 when a row median is degenerate (<1e-6); beta_i = 0 for |S_i|<2 so an empty or singleton anchor never enters; b_i detached and rebuilt once per epoch only; assert at step 0 that the L1 cost tensor and the L2/L3 column marginals match the baseline within 1e-6 so the balanced assignment provably survives; S_i read-only on the training split, no val/test sequence, no evaluation feedback, no early stopping; L2 code count and collision logged as observations only, never as a gate.
END IDEA
