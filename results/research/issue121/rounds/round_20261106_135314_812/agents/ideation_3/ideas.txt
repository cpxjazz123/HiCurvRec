IDEA: fine-residual-behaviour-geodesic-transport-v1
TITLE: Behaviour-transported hyperbolic residual coding: levels 2 and 3 quantise a per-item geodesically shifted residual, never a re-stratified level 1
MOTIVATION: The rejected round biased the LEVEL-1 Sinkhorn cost with a behaviour cohesion reward. It bought the coarse level (Hard ER 16.39 -> 6.36, 256/256 codes, max 0.54%) and destroyed the fine levels: 955 distinct L2 prefixes (baseline 7414, resample reference 16145), weighted 3-level collision 0.771 (reference 0.065), refused at the 35% collision gate, so no Stage3 and no test_R@10. The real recommender problem is that the low-order digits of a Semantic ID must keep enough resolution to separate items that share a coarse category but are consumed very differently, otherwise the generative model cannot condition its next-item distribution finely enough on the prefix. This idea targets exactly that: keep level 1 as the baseline, and make the residual that levels 2 and 3 quantise carry training-only behaviour, without ever pulling two items onto the same codeword.
NOVELTY: Different level, different sign, different operator from curvature-stratum-sinkhorn-v1. (a) Level 1 is untouched (baseline Sinkhorn on the Euclidean distance), so the baseline's 241/256 code usage is inherited unchanged. (b) The behaviour field is a DIVERGENCE (expected directed-transition displacement) instead of a cohesion/compactness reward, so it pushes behaviourally diverging residuals apart rather than together. (c) The curved operation is a Mobius (exp-map) geodesic translation of each item's own residual followed by the Poincare distance; a hyperbolic translation is a bijection and an isometry, so it cannot merge two distinct residual vectors onto one codeword, which structurally excludes the previous round's failure mode. (d) No existing repository mechanism transports residuals: the curvature acts on the residual metric, not on a stratum bias.
CHANGE: For levels 2 and 3 only, the residual r that the Sinkhorn cost matrix scores is replaced by x = r (+)_c eta_i * bhat_i (a Poincare-ball geodesic translation whose direction is the item's train-only expected transition displacement and whose length is a batch-measured, bounded scale), and the cost becomes the Poincare distance d_P(x, q_k) to the code centroid; the balanced assignment rule, marginals, temperature and solver iterations are the baseline's, unchanged.
SPECIFICATION: D is the encoder width as given, c the fixed ball curvature taken from model/poincare_contract (c = 1, curvature -1), K the per-level codebook size as baseline, B ~= 1023 items/step. (1) Train-only behaviour field, refreshed once per epoch with stop-gradient: A_ij = #{train transitions item_t=i -> item_{t+1}=j}; w_ij = A_ij / sum_j' A_ij'; phi_j = sg[E_j] with E the encoder item embedding table; b_i = sum_j w_ij (phi_j - phi_i), s_i = ||b_i||, bhat_i = b_i/(s_i+1e-8), and bhat_i = 0 for items with no outgoing train transition. (2) Level 1: exactly baseline, k1(i) from the baseline Sinkhorn plan on the Euclidean cost; r1_i = z_i - e1_{k1(i)}. (3) For l in {2,3}: u_i = r^{(l-1)}_i; rho_l = median_i ||u_i|| over the batch (detached); sbar = mean_i s_i over the batch (detached); eta_i = rho_l * tanh(s_i/(sbar+1e-8)); x_i = u_i (+)_c eta_i bhat_i with the explicit Mobius sum x = ((1+2c<u,p>+c||p||^2)u + (1-c||u||^2)p)/(1+2c<u,p>+c^2||u||^2||p||^2), p = eta_i bhat_i; cost C^{(l)}_{i,k} = d_P(x_i, q^{(l)}_k) with d_P(a,b) = (1/sqrt(c)) arcosh(1 + 2c||a-b||^2/((1-c||a||^2)(1-c||b||^2))); then the baseline Sinkhorn solver on C^{(l)}/tau with the baseline marginals and iteration count produces the plan and the code index is taken from it exactly as baseline; r^{(l)}_i = x_i - q^{(l)}_{k_l(i)}.
COST: Per step at the frozen scale (24556 training items, 24 steps per epoch, B ~= 1023 items): two extra Poincare cost matrices of 1023 x 256 x D (about 17 MFLOP each at D = 64), two Mobius translations and two arctanh/clamp passes, ballpark 60 MFLOP and about +2 to +4 ms per step, i.e. about +3 to +5% wall clock over 72000 steps (roughly +3 to +5 minutes on the 3000-epoch four-card run). No extra epochs, no extra forward pass (the behaviour field reuses the existing item embedding table and a precomputed sparse transition matrix storing only observed train pairs), and no new learnable constant.
HYPOTHESIS: If the fine-level collapse came from behaviourally distinct items having residuals too close for the L2/L3 codebooks to separate, then a bounded isometric behaviour translation will restore fine resolution while keeping level 1 intact: distinct L2 prefixes should rise from 955 to at least the baseline order of magnitude (target >= 4000, ideally >= 7414), weighted 3-level collision should fall from 0.771 toward the 0.275 baseline and below the 35% owner gate, level-1 Hard ER should stay near the baseline 16.39 with >= 241/256 level-1 codes used, and prefix behaviour predictability (top-1 next item from the (L1,L2) prefix via train-only adjacency) should rise versus an Euclidean arm. The judgement is Stage3 test_recall@10 > 0.065 in the single 3000-epoch run.
RISKS: The translation is an isometry, so it may mostly permute which codeword a residual lands on without adding next-item information, leaving Recall flat while the collision gate passes.; eta_i may saturate (tanh) and become nearly item-independent if behaviour strengths are uniform, degenerating to a global rotation-like shift.; The hyperbolic conformal factor blows distances up near the ball boundary, so large-norm residuals could dominate the cost and starve some codes despite Sinkhorn.; The stop-grad item embedding table makes the behaviour field stale within an epoch.; Parent-conditioned level-3 codebooks may still collide independently of the level-2 improvement.; Single-run seed noise is part of the uncertainty.; Behaviour strengths near sbar could give a push of about half a median residual norm, large enough to reshuffle many level-2 assignments at once.
BEHAVIOR SIGNAL: Train-only expected directed-transition displacement per item (a divergent behaviour field: where the training sequences take you from item i, in embedding space), with its magnitude s_i used as the transport length.
BEHAVIOR COMPUTATION: Built once per epoch from the TRAIN split only: for each item i, count directed transitions i -> j where j is the next item of the same training sequence, aggregate over users, row-normalise to w_ij, then b_i = sum_j w_ij (phi_j - phi_i) with phi = stop-gradient of the current encoder item embedding table (24556 rows). Items with zero outgoing train transitions get b_i = 0 and therefore exactly the baseline fine-level cost. Nothing is computed from validation or test, and no gradient flows through phi.
LEAKAGE BOUNDARY: The transition matrix is counted only over training-split sequences; the item embedding table used for phi is fit on training interactions only and is read with stop-gradient, so the behaviour field can neither see a validation/test interaction nor backpropagate into the encoder; the L2/L3 Sinkhorn cost is computed only over training items, and the SID construction never reads validation or test sequences, so no validation or test interaction can enter the Semantic IDs. Validation is used only for after-the-fact diagnostics and Stage3 test is touched once.
HYPERBOLIC OPERATOR: Mobius addition / exp-map geodesic translation x = u (+)_c eta_i bhat_i inside the Poincare ball of fixed curvature c = 1 (curvature -1, from model/poincare_contract), followed by the Poincare geodesic distance d_P(x,q_k) = (1/sqrt(c)) arcosh(1 + 2c||x-q||^2/((1-c||x||^2)(1-c||q||^2))); no trainable curvature, so there is no curvature knob to tune.
HYPERBOLIC LOCATION: Inside the quantisation of the fine levels: it acts on the residual that levels 2 and 3 quantise, and on the cost matrix of the baseline balanced (Sinkhorn) assignment at those two levels. Level 1 and the encoder loss are untouched.
COUPLING PATH: One connected pathway: the train-only transition field sets the direction bhat_i and strength s_i; these set the Mobius translation of the item's own residual; the translated residual x_i enters the Poincare distance that forms the L2 (and then L3) Sinkhorn cost matrix; the balanced plan chooses the fine codewords and hence the residual handed to the next level and the resulting SID prefix. Removing the behaviour (bhat = 0) makes the translation the identity and every level-2/3 cost collapses to the pure Poincare residual distance; removing the curvature (Euclidean add + Euclidean cost) removes the ball, the conformal factor and the geodesic structure from the same cost matrix. Either removal changes the same cost matrix, so the coupling is real and not a side loss.
COUPLING EQUATION: C^{(l)}_{i,k} = d_P( r^{(l-1)}_i (+)_c [ eta_i(s_i, b_i) * bhat_i ] , q^{(l)}_k ), l in {2,3}, with the behaviour term eta_i*bhat_i = rho_l * tanh(s_i/sbar) * b_i/||b_i||, the curved term d_P (Poincare geodesic distance, curvature -1) and (+)_c the Mobius geodesic translation; the plan is the baseline Sinkhorn plan on C^{(l)}/tau.
OBSERVABLES: (i) number of distinct level-2 prefixes (rejected round 955; baseline 7414) and level-3 prefix count; (ii) item-weighted three-level collision (rejected round 0.771; baseline 0.275; reference 0.065) against the 35% gate; (iii) level-1 Hard ER and level-1 code usage (baseline 16.39, 241/256), which must stay at baseline by construction; (iv) prefix behaviour predictability: top-1 next-item hit rate when the (L1,L2) prefix is looked up in the train-only adjacency on held-out train sequences; (v) Stage3 test_recall@10 > 0.065 as the single judgement.
ABLATION BEHAVIOR OFF: The same code with bhat_i := 0 for all items (hence eta_i = 0, the Mobius translation is the identity): levels 2 and 3 score d_P(r, q_k) with the curved metric only, everything else identical. This arm exists and is correct in the code but is NOT trained in this round.
ABLATION GEOMETRY OFF: The same code with the curved operation replaced by the Euclidean one: transport becomes the plain additive shift x_i = u_i + eta_i bhat_i, the cost becomes ||x_i - q^{(l)}_k||^2, and the same baseline Sinkhorn rule is applied. This arm exists and is correct in the code but is NOT trained in this round.
ABLATION BOTH ON: The coupled run described here (behaviour transport inside the Poincare distance inside the baseline balanced fine-level assignment) is the one and only arm trained, once, 3000 Stage 2 epochs on four cards, frozen Stage 3 protocol, no early stopping.
SPEC EQUATIONS: p = eta_i * bhat_i with eta_i = rho_l * tanh(s_i/(sbar+1e-8)), rho_l = median_batch ||u_i||, sbar = mean_batch s_i, s_i = ||b_i||, b_i = sum_j w_ij (phi_j - phi_i), w_ij = A_ij / sum_j' A_ij', phi_j = sg[E_j]; Mobius sum x = ((1+2c<u,p>+c||p||^2)u + (1-c||u||^2)p)/(1+2c<u,p>+c^2||u||^2||p||^2); d_P(a,b) = (1/sqrt(c)) arcosh(1 + 2c||a-b||^2/((1-c||a||^2)(1-c||b||^2))); C^{(l)}_{i,k} = d_P(x_i, q^{(l)}_k); P^{(l)} = Sinkhorn(C^{(l)}/tau, baseline marginals, baseline iterations); k_l(i) from P^{(l)} as baseline; r^{(l)}_i = x_i - q^{(l)}_{k_l(i)}. Per step: gather z for the batch -> baseline level-1 plan (untouched) -> r1 = z - e1 -> for l in 2,3: u = r^(l-1); rho = median||u||.detach(); eta = rho*tanh(s/(sbar+eps)); x = mobius_add(u, eta*bhat, c); C = poincare_dist(x, q^(l), c); plan = baseline_sinkhorn(C/tau); assign k_l; r^(l) = x - q^(l)_{k_l}. The behaviour field is recomputed once per epoch before the epoch's steps, detached.
SPEC INPUTS OUTPUTS: Inputs: encoder output z_i (D-dim), the baseline level-1 code e1_{k1(i)}, the code centroids q^{(l)}_k for l in {2,3} (parent-conditioned on the chosen grandparent prefix as in the baseline), the train-only sparse transition matrix A and the current encoder item embedding table E, the fixed curvature c from poincare_contract, and the baseline Sinkhorn hyperparameters. Outputs: the level-2 and level-3 code indices for every item (hence the full Semantic ID), the level-2 and level-3 Sinkhorn plans, plus diagnostics (eta distribution, median residual norm, fraction of items with bhat = 0, prefix counts, collision).
SAFEGUARDS: Clamp ||x|| <= 0.999/sqrt(c) and likewise ||u|| and ||q||, and clamp the arcosh argument to >= 1 + 1e-8, so the Poincare distance never returns NaN or Inf at the boundary; eps = 1e-8 in every denominator and in the bhat normalisation; eta_i is bounded by rho_l (one median residual norm) and further by tanh, so the translation can never swamp the residual; items with no train transition get eta_i = 0 and hence exactly the baseline fine-level cost, and that fraction is logged; the behaviour field is detached and rebuilt once per epoch so it cannot feed back into the encoder; the step scale is measured (median residual norm, mean behaviour strength) rather than tuned, and the clip bound, curvature, temperature, Sinkhorn iterations and usage weights all inherit baseline values, so the run needs no sweep; an assert checks that the level-1 cost matrix and plan are bit-identical to the baseline path, which protects the 241/256 usage and the Sinkhorn balancing; a divergence check asserts that the number of distinct level-2 codes used does not fall below the baseline's in the first epochs.
END IDEA
