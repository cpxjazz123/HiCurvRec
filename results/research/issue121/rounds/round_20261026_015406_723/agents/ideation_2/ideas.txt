IDEA: userbranch_hyperbolic_transport
TITLE: Branch-conditioned hyperbolic child-code transport
MOTIVATION: A first token that identifies a broad continuation family is useful only if its residual children distinguish likely continuations; averaging all outgoing transitions into one direction destroys user-interest branches.
NOVELTY: Rather than add a successor direction to an assignment score or warp each item's latent, this builds a compact per-parent child frame from training-only transition branches and transports the residual through that frame by a curved isometry-like Mobius operation before each child quantization.
CHANGE: At each residual level after T1, use the already assigned parent code plus a train-only branch-conditioned tangent offset to Mobius-translate the residual and child codebook into a Poincare local frame. This should make the child token encode the branch-specific residual (and hence make T2/T3 predictable from the parent and observed continuation family), not merely rename T1.
SPECIFICATION: From training sequences only, compute smoothed top-M outgoing successor groups per item using popularity-adjusted transition counts; group by frozen item-embedding cosine similarity and keep group centroids v_{i,m}. For item i use its assigned parent p and residual r_l, form b_{i,p}=sum_m pi(m|i,p) A_p v_{i,m}, where pi(m|i,p) is the normalized training transition mass of successors whose item prefix is p, and A_p is a learned low-rank map. At curvature -c, x=exp_0^c(r_l), t=exp_0^c(rho*tanh(b_{i,p})); x'=log_0^c(t ⊕_c x). Assign child k=argmin_k d_c(x', exp_0^c(q_{l,k}))^2; quantize with the corresponding inverse transport, and continue residual RQ. During training use soft assignment probabilities for gradients and hard argmin for emitted SID. If no parent-conditioned evidence, set b=0.
COST: One sparse training-transition pass O(E_train), cached top-M profiles, and O(B*K*D) geometry at each affected quantizer, same asymptotic assignment complexity but roughly 1.5–2x baseline quantization wall-time depending on number of coupled levels. Frozen scale: 24,556 items/24 steps means about 1,023 items per step; 3,000 epochs = 72,000 optimizer steps and 73,668,000 item presentations. Added sparse lookup is O(B*M), with per-item map/Mobius operations O(D) and per-codeword geodesic score O(KD) on each coupled level; no user sequence scan per step.
HYPOTHESIS: Parent-conditioned branch centroids explain meaningful residual variation: both-on should lower teacher-forced T3/T4 NLL and raise top-1 while preserving T1 survival, producing improved joint beam survival and test_R@10 > 0.065. Observe canonical 52,855-pair L1 Hard ER (expect modest increase or unchanged, not a collapse), gold-prefix survival at depths 1–4 (T1 stable, T2–T4 higher), T3/T4 NLL down and top-1 up, and Stage 3 test_R@10 up. If T1 Hard ER rises sharply without tail gains, reject.
RISKS: Sparse parent-conditioned branches may be unavailable or noisy; the train prefix is not identical to Stage3 sequence context; translation can overfit item identity, distort reconstruction, or amplify errors in early parent assignment. Low-rank A, confidence shrinkage, small rho, and zero fallback limit damage.
BEHAVIOR SIGNAL: Popularity-adjusted, directed next-item transition mass partitioned into local successor branches for each source item and assigned parent prefix.
BEHAVIOR COMPUTATION: On training user sequences only, count adjacent i->j, estimate training popularity pi_j, weight counts by (count(i->j)+alpha*pi_j)/(outcount(i)+alpha), and group the top-M successors by frozen embedding similarity; cache group centroids and parent-specific masses. Use no validation/test sequences.
LEAKAGE BOUNDARY: Freeze and hash the transition/branch cache built exclusively from train sequences and the fixed item inventory before SID generation. Validation/test are not read for grouping, map fitting, hyperparameter choice, or SID assignment; downstream evaluation follows the frozen protocol.
HYPERBOLIC OPERATOR: Poincare exp_0^c/log_0^c maps, Mobius addition ⊕_c, and geodesic distance d_c with fixed c=0.5 (sectional curvature -0.5).
HYPERBOLIC LOCATION: Parent-conditioned residual-frame transport immediately before child residual quantizer assignment at T2 and T3; the transported residual is the actual argument to curved assignment.
COUPLING PATH: Train-only branch masses and centroids -> parent-specific tangent offset -> exp/Mobius transport of residual -> Poincare child-code distance ranking -> child SID and residual gradient; removing the branch cache makes the offset zero, and flattening geometry replaces the transport and distance with ordinary vector addition and Euclidean distance.
COUPLING EQUATION: b_{i,p}=A_p sum_m pi(m|i,p)v_{i,m}; x'=log_0^c(exp_0^c(r_l) ⊕_c exp_0^c(rho*tanh(b_{i,p}))); k*=argmin_k d_c(x',exp_0^c(q_{l,k}))^2.
OBSERVABLES: Report L1 Hard ER on the canonical 52,855 pairs with ten fixed negatives; expect near-baseline L1 ER. Report gold-prefix survival at depths 1–4 under width-20 beam (T1 approximately maintained, later survival increased), teacher-forced T3/T4 NLL (decrease) and top-1 (increase, target T3 around 0.7 and T4 near deterministic), plus Stage 3 test_R@10 (increase, target >0.065).
ABLATION BEHAVIOR OFF: Set b_{i,p}=0 but retain fixed-curvature transport, Poincare distances, parameters, steps, and all other settings; tests whether branch behavior adds value.
ABLATION GEOMETRY OFF: Retain identical cached branch offsets and learned maps, but use x'=r_l+rho*tanh(b_{i,p}) and Euclidean child-code distance/quantization; tests whether curved transport is essential.
ABLATION BOTH ON: Use the training-only parent-conditioned branch offset inside Poincare Mobius transport and curved child assignment as specified; compare all metrics under identical frozen Stage2/Stage3 protocols.
SPEC EQUATIONS: For training transitions n_ij and train popularity pi_j, set w_ij=(n_ij+alpha*pi_j)/(sum_h n_ih+alpha). Cluster top-M successors j by embedding cosine into groups m; v_im=sum_{j in m}w_ij e_j/sum_{j in m}w_ij. Given current parent token p, pi(m|i,p)=sum_{j in m: prefix(j)=p}w_ij / (sum_{j:prefix(j)=p}w_ij+eps). b=A_p sum_m pi(m|i,p)v_im. At levels l=2,3: x=exp_0^c(r_l), t=exp_0^c(rho*tanh(b)), x'=log_0^c(t⊕_c x), score S_k=d_c(x',exp_0^c(q_lk))^2; choose argmin S and subtract the transported code from residual using the same local frame. Use straight-through hard quantization; reconstruction and standard VQ losses unchanged.
SPEC INPUTS OUTPUTS: Inputs: train-only sequences, fixed item embeddings, frozen parent-prefix inventory, encoder residuals, codebooks, c, alpha, M, rho and low-rank A_p. Outputs: cached branch statistics, transformed residuals, child code indices, four-token SIDs and normal quantizer gradients.
SAFEGUARDS: Project ball points to norm <=(1-1e-5)/sqrt(c); compute maps/distances in float32; clamp atanh arguments to 1-1e-6; use eps=1e-8 in mass normalization; shrink offsets by confidence log(1+n_i)/log(1+n95); cap rho*tanh offset norm; deterministic tie-break; zero fallback for missing parent support; gradient/finite checks and training-only scale matching.
END IDEA

IDEA: train_cooccur_hyperbolic_capacity
TITLE: Behaviour-weighted hyperbolic balanced prefix assignment
MOTIVATION: A coarse first token must be predictable without collapsing most items into one code, while the later residual tokens must retain fine distinctions that expose continuation structure.
NOVELTY: Unlike itemwise curved successor scoring, this couples batch-level training co-consumption affinity to a curvature-aware entropic transport assignment at T1; the resulting soft parent mass is also the conditioning context for residual quantization, so balance and tail predictability are optimized through one assignment pathway.
CHANGE: For each training minibatch, build a sparse co-consumption affinity from train-only users' nearby item pairs. Use that affinity to tilt a Poincare-distance cost matrix before log-domain Sinkhorn assignment to a controlled 16–64 effective parent capacity; feed each item's soft parent barycenter into a curved residual coordinate transform for T2/T3. The soft parent acts as a denoised behavioral context, making later tokens more predictable without simply collapsing the alphabet.
SPECIFICATION: Precompute train-only within-window co-consumption counts C_ij, PMI-like a_ij=clip(log((C_ij+eps)*T/((C_i+eps)(C_j+eps))),-a_max,a_max). For a minibatch items i and K1 parent prototypes y_k on Poincare ball, cost M_ik=d_c(exp_0^c(z_i),y_k)^2 - lambda sum_{j in batch} a_ij softmax_k(-d_c(exp_0^c(z_j),y_k)^2/tau). Compute entropic transport P=Sinkhorn(exp(-M/epsilon), row mass 1/B, column mass target rho_k) where rho has 16–64 active groups, then use soft parent tangent mu_i=log_0^c(sum_k P_ik y_k / sum_k P_ik) (projected weighted ball mean) as context: r'_i=log_0^c(exp_0^c(r_i)⊕_c exp_0^c(g(mu_i))). Quantize r' with Poincare child assignments. Anneal Sinkhorn temperature only on the fixed schedule; final SID uses hard nearest parent and deterministic collision extension.
COST: Co-consumption preprocessing O(E_window) once; minibatch affinity multiplication O(B^2) and Sinkhorn O(I*B*K1) per step, plus curved assignments. At frozen scale B≈1,023, 24 steps/epoch and 3,000 epochs = 72,000 steps / 73,668,000 item presentations; dense B² is about 1.05M affinity entries per step (~75.6B over the run), so implement sparse top-neighbor affinity or minibatch blocks (target <5% extra wall time with sparse top-32 and 5–10 Sinkhorn iterations). Geometric cost remains O(B*K1*D).
HYPOTHESIS: Nearby co-consumed items share a useful broad continuation family, while Sinkhorn capacity avoids the single-code collapse seen in purely behavior-driven coarse assignments. Both-on should reduce L1 Hard ER only modestly (or leave it stable), improve L1 gold survival and preserve high T3/T4 accuracy by carrying soft parent context into residuals; retain only if Stage 3 test_R@10 exceeds 0.065 and beats both ablations. Measure L1 ER, gold-prefix survival at every depth, T3/T4 NLL/top-1, parent effective group count and test_R@10.
RISKS: Co-consumption proximity may reflect popularity rather than substitutable intent; PMI is unstable for rare pairs; batchwise transport can be noisy and expensive; soft parent barycenter can blur distinct branches; capacity schedule may trade T1 for T2 losses. Sparse clipping, count shrinkage, fixed deterministic batching, and small lambda are required.
BEHAVIOR SIGNAL: Training-only sequential co-consumption affinity between items appearing within a bounded window of the same user's sequence.
BEHAVIOR COMPUTATION: From training sequences only, count unordered/position-discounted pairs within window ±3, compute smoothed PMI against train item frequencies, clip and retain top 32 neighbors per item. Do not construct from validation/test interactions.
LEAKAGE BOUNDARY: Build and freeze co-consumption counts from train split before Stage2; train minibatch composition only indexes this fixed cache. No validation/test interaction, ordering, or target enters affinity, Sinkhorn fitting, assignment, or SID generation; evaluate only after SIDs are frozen.
HYPERBOLIC OPERATOR: Fixed-curvature -0.5 Poincare exp/log maps, squared geodesic distance, Mobius addition, and a projected Poincare weighted barycenter.
HYPERBOLIC LOCATION: T1 batch assignment cost and the soft-parent-to-residual transport feeding T2/T3; both the behavior tilt and the curvature enter the actual transport/assignment computation.
COUPLING PATH: Train co-consumption affinities alter each item’s Poincare parent-cost row -> Sinkhorn soft assignments and barycenters -> curved residual transport -> later child token assignments; without affinity the cost becomes behavior-neutral, and without curvature the cost, barycenter transport, and residual transform become Euclidean.
COUPLING EQUATION: M_ik=d_c(x_i,y_k)^2 - lambda sum_j a_ij softmax_k(-d_c(x_j,y_k)^2/tau); P=Sinkhorn(exp(-M/epsilon),rho); r'_i=log_0^c(exp_0^c(r_i)⊕_c exp_0^c(g(log_0^c(bar_y_i(P))))).
OBSERVABLES: On canonical 52,855-pair/ten-fixed-negative evaluation, L1 Hard ER should remain low or fall slightly versus baseline, not spike. Width-20 gold-prefix survival should improve at L1 and not sacrifice T2–T4; teacher-forced T3/T4 NLL should decrease and top-1 rise (T3 aim >=0.7, T4 near deterministic); Stage 3 test_R@10 should rise above 0.065. Also log effective T1 groups and assignment entropy to distinguish useful coarse structure from collapse.
ABLATION BEHAVIOR OFF: Set lambda=0 and remove the co-consumption term, keeping the same Poincare cost, capacity vector, Sinkhorn iterations, residual transform, training schedule and code dimensions.
ABLATION GEOMETRY OFF: Keep co-consumption affinities and same Sinkhorn/capacity, but replace d_c by squared Euclidean distance, weighted barycenter by Euclidean mean, and Mobius residual transport by vector addition; match cost scale on training-only batches.
ABLATION BOTH ON: Use clipped train-only PMI affinity in Poincare batch costs, balanced Sinkhorn parent assignment and the resulting curved soft-parent residual transport. Keep frozen four-token SID, 3,000 Stage2 epochs, collision extension and Stage3 protocol unchanged.
SPEC EQUATIONS: C_ij=sum_{u,t:0<|s-t|<=3}1[i_t=i,i_s=j]/|s-t| on train sequences. Let f_i=sum_j C_ij, T=sum_ij C_ij; a_ij=clip(log((C_ij+alpha*T/V^2)*T/((f_i+alpha*T/V)(f_j+alpha*T/V))),-4,4), retaining top 32 neighbors. x_i=exp_0^c(z_i), y_k=exp_0^c(q_1k). Q_ik=softmax_k(-d_c(x_i,y_k)^2/tau). M_ik=d_c(x_i,y_k)^2-lambda sum_j a_ij Q_jk; compute P=Sinkhorn(exp(-M/epsilon), row=1/B, col=rho/K1), with rho fixed uniform over chosen K_eff=32 active groups and small floor for remaining codes. bar_y_i=Proj_ball(sum_k P_ik y_k/(sum_k P_ik+eps)). r'_i=log_0^c(exp_0^c(r_i)⊕_c exp_0^c(g(log_0^c(bar_y_i)))); quantize r'_i against child codebook using d_c. Optimize standard reconstruction/VQ losses plus straight-through transport; hard argmin at SID export.
SPEC INPUTS OUTPUTS: Inputs: training-only sequences and item frequencies, frozen item embeddings, minibatch item IDs, encoder latents/residuals, Poincare parent/child codebooks, target capacity rho, c, lambda, epsilon and tau. Outputs: cached sparse affinity, balanced soft/hard parent assignments, curved parent-conditioned residuals, four SID tokens and VQ gradients.
SAFEGUARDS: Smooth counts and PMI; clip affinity [-4,4], cap neighbor degree at 32; normalize sparse rows; use log-domain Sinkhorn with 5–10 iterations and epsilon floor; float32 geometry; clamp ball norms below (1-1e-5)/sqrt(c); project barycenters into ball; finite gradient checks; freeze deterministic batches and tie-breaks; monitor column mass and effective groups; ensure same assignment capacity in all arms.
END IDEA
