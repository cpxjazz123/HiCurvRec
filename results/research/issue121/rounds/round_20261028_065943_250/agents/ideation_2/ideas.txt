IDEA: flowtree_poincare_parent
TITLE: Directed-flow parent codes with within-parent Poincare assignment
MOTIVATION: Items with similar training-only continuation distributions should share a coarse first token, while the later tokens must retain enough capacity to distinguish item identity.
NOVELTY: The training transition graph constructs a fixed coarse partition before quantization; unlike transition-scored global assignments or co-consumption region scoring, hyperbolic distance only chooses among codewords inside the item's behavior-defined parent.
CHANGE: Build a deterministic balanced partition of items from smoothed outgoing-transition distributions and allocate first-level codewords to those groups. Assign each item to a codeword only within its group using fixed-negative-curvature Poincare distance; keep the remaining residual quantizers unchanged so the third token can preserve distinctions.
SPECIFICATION: From training-only counts \(C_{ij}\), let \(p_i(j)=(C_{ij}+\alpha q(j))/(\sum_j C_{ij}+\alpha)\), where \(q(j)\) is the training-item unigram distribution and \(\alpha=1\) is a documented Dirichlet default. Define symmetric affinity \(A_{ij}=\sum_v \min(p_i(v),p_j(v))\); recursively bisect the weighted affinity graph by deterministic normalized spectral bisection until \(K_1\) groups are formed, with ties broken by item ID. Give each group at least one first-level codeword, allocating any excess in proportion to its item count by largest remainder. For item \(i\) in group \(g(i)\), choose \(k=\arg\min_{k\in\mathcal C_{g(i)}}d_{-1}(\exp_0(z_i),\exp_0(c_k))^2\). Continue ordinary Euclidean residual quantization at levels 2–3. If the existing codebook count is smaller than the number of nonempty groups, merge the smallest group into its highest-affinity neighbor.
COST: One preprocessing pass over training transitions, plus sparse distribution/affinity construction and partitioning; worst-case pairwise affinity is \(O(N^2V)\), but top-neighbor sparsification from the training graph makes it \(O(EV)\) or less with sparse distributions. Per Stage 2 step, assignment compares each of about 1,023 items only with its group’s codewords, at most the baseline \(O(BK_1D)\) Poincare work; extra cost is the affinity lookup and partitioning once, not repeated across 72,000 optimizer steps (24 steps/epoch × 3,000 epochs; 24,556 items).
HYPOTHESIS: Continuation-distribution similarity defines a useful coarse partition, and within-parent curved assignment consolidates first-level codes without forcing third-level identity loss. Observe first-level distinct-code count and assignment changes, training-prefix successor predictability, third-level distinct triples, and—judgment criterion—whether the single Stage 3 run exceeds Recall@10 0.065.
RISKS: Sparse or low-support transition rows may yield noisy affinities; graph partitioning may group items by popularity rather than continuation structure; hard parent constraints may block useful semantic neighbors; within-parent code capacity could be too small.
BEHAVIOR SIGNAL: Smoothed outgoing next-item distributions from directed training transitions.
BEHAVIOR COMPUTATION: Count adjacent item pairs in the Stage 2 training split only, aggregate \(C_{ij}\), and construct \(p_i\) and \(A_{ij}\) as specified. Do not use validation or test sequences or interactions.
LEAKAGE BOUNDARY: Freeze the partition from the training split before Stage 2 fitting and SID export; validation/test data are never read by preprocessing, partitioning, code assignment, or codebook updates.
HYPERBOLIC OPERATOR: Squared Poincare geodesic distance at fixed curvature \(-1\), with origin exponential maps.
HYPERBOLIC LOCATION: The first-level hard assignment, restricted to the item's behavior-defined parent group.
COUPLING PATH: Training transitions determine the admissible first-level codeword set; Poincare distance chooses the code within that set and therefore determines the first SID token and its quantization gradient. Removing behavior removes the parent restriction; replacing the curved distance changes the within-parent choice.
COUPLING EQUATION: \(g(i)=\mathrm{Partition}(A)_i;\quad k_i=\arg\min_{k\in\mathcal C_{g(i)}}d_{-1}(\exp_0(z_i),\exp_0(c_k))^2.\) The behavior term is the training-derived parent \(g(i)\); the curved term is \(d_{-1}\).
OBSERVABLES: First-token assignments become confined to behavior-derived groups; changing either switch changes the candidate set or within-group argmin. Record first-level occupancy, third-level distinct triples, training-prefix successor predictability, and Stage 3 test Recall@10.
ABLATION BEHAVIOR OFF: Set every item’s parent to the single unrestricted codebook, leaving the Poincare first-level assignment and all other settings unchanged.
ABLATION GEOMETRY OFF: Keep the training-derived parent groups and candidate sets, but replace \(d_{-1}(\exp_0(z_i),\exp_0(c_k))^2\) with squared Euclidean distance \(\|z_i-c_k\|_2^2\).
ABLATION BOTH ON: Use the training-derived parent groups and the within-parent fixed-curvature Poincare assignment above. These switches are implemented for comparison but are not trained as separate arms.
SPEC EQUATIONS: \(C_{ij}=\#\{(i,j)\text{ adjacent in training sequences}\}\); \(p_i(j)=(C_{ij}+q(j))/(\sum_v C_{iv}+1)\); \(A_{ij}=\sum_v\min(p_i(v),p_j(v))\); \(g=\mathrm{BalancedPartition}(A,K_1)\); \(k_i=\arg\min_{k\in\mathcal C_{g(i)}}d_{-1}(\exp_0(z_i),\exp_0(c_k))^2\). Use deterministic bisection and tie-breaking; quantize levels 2–3 with the unchanged baseline residual quantizer.
SPEC INPUTS OUTPUTS: Inputs are training-only directed transition counts, training unigram counts, item latents \(z_i\), and first-level codebook vectors \(c_k\). Outputs are frozen parent labels \(g(i)\), first-level code assignments \(k_i\), and standard residual assignments for later SID tokens.
SAFEGUARDS: Normalize distributions with denominator at least \(10^{-12}\); keep graph affinities sparse; use deterministic partition initialization and item-ID tie-breaking; ensure every item has a parent and every nonempty parent at least one code; use float32 for Poincare operations, project ball norms below \(1-10^{-5}\), clamp distance intermediates, and fall back to Euclidean initialization only if a Poincare calculation is nonfinite. Record third-level occupancy diagnostically, never as an admission gate.
END IDEA

IDEA: transition_mass_radial_shells
TITLE: Transition-mass shells with hyperbolic within-shell quantization
MOTIVATION: Popular and broadly connected items may consume disproportionate first-level capacity even when their continuation patterns are not distinctive; a training-only transition hierarchy can make the first token deliberately coarse while preserving later identity.
NOVELTY: This uses transition-derived scalar continuation mass to define fixed radial shells of a negatively curved code space, then assigns items to codewords within each shell by geodesic distance. It does not append a behavior token, use a behavior-conditioned score over the full codebook, or optimize transition pairs with a hyperbolic loss.
CHANGE: Compute each item's smoothed outgoing transition mass and assign items to a small number of mass quantile bands, merging empty bands deterministically. Place first-level codewords in matching Poincare radial annuli, with shell radii derived from latent scale; choose the item’s first code by Poincare distance only among its shell’s codewords. Leave later residual quantization unchanged.
SPECIFICATION: Let \(s_i=\sum_j C_{ij}\), and define \(r_i=\log(1+s_i)\). Sort items by \(r_i\), tie-break by ID, and form \(G=\min(K_1,\lceil\sqrt{K_1}\rceil)\) contiguous equal-count bands. For each band \(g\), allocate \(\max(1,\lfloor K_1|g|/N\rfloor)\) codewords, then distribute remaining codewords by largest fractional remainder. Compute shell radius \(\rho_g\) as the median norm of the current encoder latents in that band, clipped to the Poincare ball radius \(1-\epsilon\); initialize codewords by projecting band centroids to \(\rho_g\) and train them normally. Assignment is \(k=\arg\min_{k\in\mathcal C_g}d_{-1}(\exp_0(z_i),\exp_0(c_k))^2\); update \(\rho_g\) from training-item latent norms once per epoch using an exponential moving average with fixed documented decay 0.9. Residual levels 2–3 remain baseline.
COST: One \(O(T)\) transition-count pass, sorting \(O(N\log N)\), and a per-epoch band-radius reduction \(O(ND)\). At each of 24 steps per epoch, about 1,023 items undergo a restricted Poincare assignment, no more comparisons than the baseline \(O(BK_1D)\); 72,000 steps total at the frozen 24,556-item/3,000-epoch scale. This adds scalar grouping and radius reductions, with no pairwise graph or extra optimizer step.
HYPOTHESIS: Coarsening first-token distinctions by observed continuation mass reduces unhelpful first-level separation while shell-constrained curved assignment preserves meaningful within-band distinctions. Observe first-token occupancy and changed assignments, third-level distinct triples, prefix successor predictability, and Stage 3 Recall@10; keep only if the one Stage 3 run exceeds 0.065.
RISKS: Outgoing count is an imperfect proxy for predictive usefulness; bands may mostly encode popularity, and shell constraints may place semantically similar items in separate bands. Encoder latent norms may not align with transition mass; poor shell allocation can starve some first-level codewords.
BEHAVIOR SIGNAL: Per-item outgoing directed transition mass.
BEHAVIOR COMPUTATION: Count adjacent item pairs \(C_{ij}\) in training sequences only; compute \(s_i=\sum_j C_{ij}\), then \(r_i=\log(1+s_i)\). Validation and test interactions are excluded.
LEAKAGE BOUNDARY: Bands are constructed once from Stage 2 training sequences and then frozen; quantization uses only training item content latents and learned codebooks. No validation or test interaction is read or used in SID construction.
HYPERBOLIC OPERATOR: Origin exponential map and squared Poincare geodesic distance at fixed curvature \(-1\), with a radial projection to a shell in the ball.
HYPERBOLIC LOCATION: First-level codebook initialization and hard assignment within each behavior-defined shell.
COUPLING PATH: Training transition mass determines each item’s shell and the codewords it may select; radial projection and Poincare geodesic distance determine the actual assignment inside that shell. Removing behavior removes the shell constraint; flattening geometry replaces both projection and assignment distance.
COUPLING EQUATION: \(g(i)=\mathrm{QuantileBand}(\log(1+\sum_j C_{ij}));\quad k_i=\arg\min_{k\in\mathcal C_{g(i)}}d_{-1}(\exp_0(z_i),\Pi_{\rho_{g(i)}}(\exp_0(c_k)))^2.\) Here \(\Pi_{\rho_g}\) is radial projection onto the band’s Poincare shell; behavior enters through \(g(i)\), and curvature enters through projection and \(d_{-1}\).
OBSERVABLES: Items are assigned only within their transition-mass shell; shell radii and Poincare argmins alter first-token assignments and their gradients. Record shell occupancy, third-level distinct triples, training-prefix predictability, and Stage 3 test Recall@10.
ABLATION BEHAVIOR OFF: Assign all items to one unrestricted shell and codeword set, retaining Poincare projection/distance and the same training schedule.
ABLATION GEOMETRY OFF: Retain the training-derived mass bands and codeword restrictions, but use Euclidean latent/codeword distance and Euclidean radial projection to each band’s median latent norm.
ABLATION BOTH ON: Use transition-mass bands, Poincare shell projections, and within-shell Poincare geodesic assignment. These switches are part of the implementation contract; do not train separate ablation arms.
SPEC EQUATIONS: \(s_i=\sum_j C_{ij}\); \(r_i=\log(1+s_i)\); \(g(i)=\mathrm{EqualCountBand}(r_i,G)\), \(G=\min(K_1,\lceil\sqrt{K_1}\rceil)\); \(\rho_g=\mathrm{median}_{i:g(i)=g}\|\exp_0(z_i)\|_2\); \(k_i=\arg\min_{k\in\mathcal C_g}d_{-1}(\exp_0(z_i),\Pi_{\rho_g}(\exp_0(c_k)))^2\). Set \(K_g\) by proportional largest-remainder allocation with at least one code per nonempty band. Use the resulting first code and unchanged residual levels 2–3.
SPEC INPUTS OUTPUTS: Inputs are Stage 2 training transition counts, training item latents, first-level codebook size \(K_1\), and Poincare codeword parameters. Outputs are frozen mass-band labels, shell radii, first-level assignments, and unchanged later residual assignments.
SAFEGUARDS: Use \(\log1p\) for counts; deterministic sorting and ID tie-breaks; define a fallback band for zero-outgoing items; clamp shell radii to \([0,1-10^{-5}]\); project codewords strictly inside the ball; compute geometry in float32 and clamp distance intermediates; retain at least one code per nonempty band and handle rounding by largest remainder. Monitor but do not admission-gate on shell or third-level occupancy.
END IDEA
