IDEA: flow_capacity_lorentz_sinkhorn
TITLE: Transition-flow capacities create a coarse first-code allocation under Lorentzian Sinkhorn assignment
MOTIVATION: The observed useful regime needs a coarse first token without erasing the fine identity suffix. Training transition flow can specify which first-level codes should absorb broad continuation roles, while a curved assignment allocates individual items to those codes and levels two and three retain the original latent detail.
NOVELTY: Unlike the collected candidates' hard behavior-derived item partitions, branches, shells, or behavior-derived prototypes, this assigns no item to a predetermined group. Instead, a training-only directed-flow statistic sets the *column marginals* of a global soft transport over first-level codes; Lorentz geometry supplies the transport costs, coupling behavioral coarse-code mass and curved per-item assignment in one constrained optimization.
CHANGE: Compute each item's popularity-adjusted outgoing continuation mass from training transitions, aggregate it into a fixed target usage distribution over existing first-level codes by deterministic quantile binning, and solve a batch Sinkhorn assignment using negative squared Lorentz distance as logits and those behavior-derived code capacities as the column marginal. Hard row argmax gives level one; compute subsequent baseline Euclidean residual quantizers from the original encoder latent minus the selected first code, preserving suffix identity.
SPECIFICATION: For item i let n_ij be training adjacent-transition counts, out_i=Σ_j n_ij, and s_i=Σ_j n_ij/(sqrt((out_i+1)(in_j+1))). Sort s_i (ties item-ID) into K1 equal-count quantile bins; define π_k=(count in bin k + 1)/(N+K1), a positive target first-code mass distribution. For each batch B, compute C_ik=d_L(L(exp_0(z_i)),L(exp_0(e_k)))² at curvature -1. Set A_ik=exp(−C_ik/τ), with τ the median positive C over the first initialization batch, then one log-domain Sinkhorn solve for Q≥0 with row sums 1 and column sums |B|π_k (renormalize π over columns only if needed for batch integer-free marginals). Use q_i=argmax_k Q_ik as hard first token via straight-through selected code vector; later residual levels take z_i−e_qi, not a transport-averaged vector.
COST: Preprocessing is O(E_train+N log N) for transition flow and sorting. At the frozen scale 24,556 items, 24 steps/epoch, 3,000 epochs (72,000 steps), each step computes B×K1 Lorentz distances and a fixed 20 Sinkhorn row/column reductions, O(BK1) reductions and storage; relative to baseline this is a small constant-factor first-level assignment overhead, with no extra optimizer steps or training run. 20 iterations is a documented fixed default, not swept.
HYPOTHESIS: Popularity-adjusted continuation-flow quantiles induce a useful, intentionally uneven coarse code mass distribution, while hyperbolic transport assigns embeddings to those code masses in a way aligned with semantic neighborhoods. Observe changed first-level assignments/code frequencies and assignment gradients, retain third-level distinctions through the untouched-latent residual, and keep only if the sole frozen Stage3 test Recall@10 exceeds 0.065; behavior diagnostics are descriptive, not gates.
RISKS: Code mass from outgoing flow may encode exposure rather than predictiveness; Sinkhorn marginals can force bad assignments in a batch, especially when batch flow distribution differs from global π; fixed temperature from initialization may be poorly scaled; suffix quantizers may not recover identity after a poor first code.
BEHAVIOR SIGNAL: Popularity-adjusted directed outgoing next-item flow per item.
BEHAVIOR COMPUTATION: From Stage2 training sequences only, count immediate directed pairs n_ij and compute s_i=Σ_j n_ij/sqrt((out_i+1)(in_j+1)); quantile-rank the 24,556 training catalog items into K1 equal-count bins, yielding target code masses π. Validation/test interactions do not enter counts, ranks, marginals, or assignments.
LEAKAGE BOUNDARY: Freeze n_ij, item flow ranks and π using the Stage2 training split before optimization. The per-step transport uses only these frozen marginals and training item embeddings/latents; SID export repeats the deterministic assignment rule using the frozen flow map and learned parameters, without reading validation/test interactions.
HYPERBOLIC OPERATOR: Lorentz hyperboloid lift and squared geodesic distance at fixed curvature −1, C_ik=acosh(max(1,−<L(x_i),L(c_k)>_L))².
HYPERBOLIC LOCATION: The cost matrix inside the first-level log-domain Sinkhorn transport during training; geometry directly sets transport probabilities, gradients, and the hard first SID assignment.
COUPLING PATH: Training-only transition flow determines the desired first-code column mass π; Lorentz distances determine the cost matrix whose Sinkhorn solution allocates each item to satisfy π. Removing behavior changes the transport marginal; replacing Lorentz costs changes the transport solution and thus first-code choices and residuals.
COUPLING EQUATION: Q=Sinkhorn(exp(−d_L(L(exp_0(z_i)),L(exp_0(e_k)))²/τ), row=1, col=|B|π_k(s_train)); q_i=argmax_k Q_ik; r_i=z_i−e_qi. Here π(s_train) is explicit behavior structure and d_L is the curved operation in the same assignment pathway.
OBSERVABLES: First-code assignment frequencies should track the training-flow-derived π more closely than the baseline, while code identities should vary with Lorentz costs; first-level assignments, first-code gradients and residual inputs change. Record flow-to-code association, transition predictability, L1 hard error, and distinct third-level triples as diagnostics only; judge solely by Stage3 test Recall@10 > 0.065.
ABLATION BEHAVIOR OFF: Mechanism switch uses uniform column marginal π_k=1/K1, preserving Lorentz cost and Sinkhorn; this is a defined comparison only, not a trained arm.
ABLATION GEOMETRY OFF: Mechanism switch replaces Lorentz distance cost with ||z_i−e_k||², retaining the exact training-derived π and Sinkhorn; this is a defined comparison only, not a trained arm.
ABLATION BOTH ON: Use training-flow-derived π and Lorentz-distance costs as specified; this is the single trained candidate. No off-arm is trained.
SPEC EQUATIONS: n_ij=Σ_{u,t in train}1[x_ut=i,x_u,t+1=j]; s_i=Σ_j n_ij/√((out_i+1)(in_j+1)); π_k=(|{i:rank(s_i) in bin k}|+1)/(N+K1). x_i=exp_0^{-1}(z_i), c_k=exp_0^{-1}(e_k), D_ik=acosh(max(1,−<L(x_i),L(c_k)>_L))². K_ik=exp(−D_ik/τ); Q=diag(a)Kdiag(b), iterating a_i=1/(Σ_k K_ik b_k+ε), b_k=(|B|π_k)/(Σ_i a_iK_ik+ε) for 20 fixed iterations; q_i=argmax_k Q_ik; r_i=z_i−e_qi; apply baseline Euclidean RQ levels 2–3 to r_i.
SPEC INPUTS OUTPUTS: Inputs: training-only directed counts and item IDs, encoder latents z_i, first-level code vectors e_k, K1 and fixed curvature. Outputs: frozen flow-derived π, per-batch soft transport Q, hard first-level SIDs, and ordinary second/third residual SIDs.
SAFEGUARDS: Use +1 only in degree denominators and π smoothing; compute Sinkhorn in log space with logsumexp, ε=1e−8, and exactly 20 iterations; use τ=max(median positive initialization cost, machine epsilon), measured once without tuning. Lift points after ball projection to norm ≤1−1e−5; clamp Lorentz inner-product argument to at least 1+1e−7 before acosh and compute in FP32. Batch row/column marginals have equal total |B| by construction; tie-break hard argmax by lowest code index. Keep z_i unchanged for residual calculation and use the existing baseline straight-through/update convention.
END IDEA
