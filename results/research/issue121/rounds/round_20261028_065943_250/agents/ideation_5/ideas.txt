IDEA: branch_busemann_collapse
TITLE: Train-only successor branches define a hyperbolic first-level bottleneck
MOTIVATION: Next-item prediction needs a coarse first code that groups items with similar *sets of likely next items*, while preserving later residual capacity to identify the item. This targets the observed useful regime of a collapsed first level and informative third level.
NOVELTY: Unlike transition-geodesic scoring or branch-anchored fine-level quantization, this uses successor branches to construct a fixed coarse codebook, then uses hyperbolic distance to assign items to that codebook at level one only. Later residual levels remain the ordinary Euclidean RQ-VAE quantizers.
CHANGE: From training transitions, cluster items by their popularity-adjusted successor distributions into the existing first-level code count, and map each cluster to a Poincaré-ball prototype. Replace only the first-level nearest-code assignment with nearest hyperbolic prototype assignment; compute residuals for later levels from the original encoder latent so that the coarse assignment does not erase their item-specific signal.
SPECIFICATION: Let \(P_{ij}=n_{ij}/\sum_k n_{ik}\) be the row-normalized count of adjacent training-only transitions \(i\to j\). Cluster rows with weighted spherical k-means on \(P_i\), using \(w_i=\sqrt{\sum_j n_{ij}}\), into \(K_1\) branches \(b_i\). For each branch, compute its weighted mean successor row \(q_b\), project \(s_b=\operatorname{norm}(q_b)\) into a fixed-curvature Poincaré ball via \(c_b=\exp_0(\alpha s_b)\), where \(\alpha=\min(1,\operatorname{median}_i\|z_i\|/(\operatorname{median}_b\|s_b\|+\epsilon))\). Map encoder latents to the ball as \(u_i=\exp_0(z_i)\), assign \(a_i=\arg\min_b d_{\mathbb B}(u_i,c_b)^2\), and emit \(a_i\) as SID level one. Compute levels two and three by baseline Euclidean residual quantization of \(z_i-e_{a_i}\), not the ball residual.
COST: One-time preprocessing is sparse transition aggregation plus \(O(K_1 I T)\) clustering work for \(I=24{,}556\) items and \(T\) clustering iterations; \(T\) is fixed to the baseline clustering iteration count, not swept. Training adds one exp-map per item and \(K_1\) Poincaré distances per item per epoch: \(24\times24=576\) batch steps per epoch and 1,728,000 steps over 3,000 epochs; assignment work is about \(24{,}556K_1\) distances per epoch (about \(K_1\) per step at the frozen item scale), with no extra learned parameters.
HYPOTHESIS: Success requires successor-distribution branches to align with useful next-item generalization, and the hyperbolic Voronoi boundaries to yield a substantially more frequent first-level reassignment than baseline without making later residuals uninformative. Record first-level reassignment rate, third-level distinct item codes, transition predictability from prefixes, and judge solely by Stage3 test Recall@10 against 0.065.
RISKS: Successor rows may be too sparse or popularity-dominated; fixed prototypes may be poorly aligned with encoder latents; a hard branch assignment may make the first-level code overly dominant. The untouched-latent residual path is intended to limit loss of third-level identity.
BEHAVIOR SIGNAL: Directed next-item transition distributions.
BEHAVIOR COMPUTATION: Count adjacent item pairs within each user’s training-split sequence only; normalize each source row and take square-root source-frequency weights. No validation or test sequences are read.
LEAKAGE BOUNDARY: Branches and prototypes are constructed only from training sequences and frozen before Stage2 training. SID assignment consumes item latents and these frozen training-derived prototypes only.
HYPERBOLIC OPERATOR: Poincaré distance \(d_{\mathbb B}^{c}\) and exponential map \(\exp_0^c\), with fixed negative curvature \(c=-1\).
HYPERBOLIC LOCATION: Level-one item-to-branch assignment in every Stage2 forward pass.
COUPLING PATH: Training transitions determine successor branches and their prototypes; Poincaré distance to those behavior-derived prototypes determines the actual first-level SID assignment.
COUPLING EQUATION: \(a_i=\arg\min_b d_{\mathbb B}^{-1}(\exp_0^{-1}(z_i),\,\exp_0^{-1}(\alpha\,\operatorname{norm}(q_b)))^2,\quad q_b=\frac{\sum_{i:b_i=b}w_iP_i}{\sum_{i:b_i=b}w_i}\).
OBSERVABLES: The first-level SID distribution and item assignments should change; first-level transitions should become more predictable from training-derived successor branches, while levels two and three should retain substantial item discrimination. Final judgement is Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: For the comparison only, replace transition-derived branches and prototypes with the baseline first-level Euclidean codebook assignment; retain all other settings.
ABLATION GEOMETRY OFF: For the comparison only, keep the transition-derived branches and prototypes but assign by squared Euclidean distance between tangent vectors \(z_i\) and \(\alpha\,\operatorname{norm}(q_b)\).
ABLATION BOTH ON: Use training-transition-derived successor branches and the Poincaré-distance assignment specified above. These are mechanism switches for interpretability; train only this both-on candidate, with no ablation runs.
SPEC EQUATIONS: \(n_{ij}=\sum_{u,t}\mathbf1[x_{u,t}=i,x_{u,t+1}=j]\); \(P_{ij}=n_{ij}/(\sum_k n_{ik}+\epsilon)\); \(b_i=\operatorname{cluster}(P_i,w_i,K_1)\); \(q_b=\sum_{i:b_i=b}w_iP_i/(\sum_{i:b_i=b}w_i+\epsilon)\); \(c_b=\exp_0^{-1}(\alpha\operatorname{norm}(q_b))\); \(a_i=\arg\min_b d_{\mathbb B}^{-1}(\exp_0^{-1}(z_i),c_b)^2\). Set \(r_i^{(1)}=z_i-e_{a_i}\), then apply baseline Euclidean levels two and three to \(r_i^{(1)}\).
SPEC INPUTS OUTPUTS: Inputs are training-only adjacent transition counts, encoder latents \(z_i\), and the baseline first-level code count \(K_1\). Outputs are fixed behavior branch labels and prototypes, first-level SID assignments, and the unchanged-format three-level SID.
SAFEGUARDS: Add \(\epsilon=10^{-8}\) to row and cluster denominators; define zero-outdegree rows as zero vectors and deterministically assign them by the nearest prototype; clip Poincaré radii to \((1-10^{-5})/\sqrt c\) for \(c=1\); compute distances with the standard stable \(\operatorname{atanh}\) argument clamp \(1-10^{-5}\). Fix clustering initialization and iteration count to documented deterministic defaults. Derive \(\alpha\) from the stated median latent scale, not a sweep.
END IDEA

IDEA: transition_mass_radial_shell
TITLE: Successor mass sets hyperbolic depth; angular assignment coarsens level one
MOTIVATION: A first-level code can become common for items with broadly similar continuation behavior without collapsing the later codes that distinguish the exact item. Successor uncertainty provides a training-only measure of how broadly an item’s future branches, while hyperbolic radial depth can represent that uncertainty separately from directional code assignment.
NOVELTY: Rather than matching transition neighbors with a graph loss or using a behavior-conditioned tangent residual, this makes the observed successor entropy directly set each item’s hyperbolic radius and lets the first-level codebook partition directions on that behavior-controlled shell. Fine-level quantization remains in the baseline Euclidean residual space.
CHANGE: Compute each item’s training-only successor entropy, convert it to a bounded radius using its empirical quantile, and lift its encoder direction to that radius in a Poincaré ball. Assign the first-level code by hyperbolic distance from this behavior-conditioned point to trainable Poincaré codewords; leave subsequent residual quantization on the original latent.
SPECIFICATION: For transition counts \(n_{ij}\), compute \(H_i=-\sum_jP_{ij}\log(P_{ij}+\epsilon)\), and let \(h_i=(\operatorname{rank}(H_i)-1)/(I-1)\), with ties assigned their average rank. Let \(v_i=z_i/(\|z_i\|+\epsilon)\) and set \(x_i=\exp_0^1(\rho_i v_i)\), where \(\rho_i=\rho_{\max}(h_i-\tfrac12)\), \(\rho_{\max}\) is the median nonzero \(\|z_i\|\) mapped to a ball radius and clipped to \(0.9\). Map each trainable first codeword \(e_k\) to \(c_k=\exp_0^1(e_k)\), assign \(a_i=\arg\min_k d_{\mathbb B}^{-1}(x_i,c_k)^2\), and use baseline residual \(z_i-e_{a_i}\) for levels two and three.
COST: Precompute transition entropies and ranks in \(O(E+I\log I)\), where \(E\) is the number of unique observed training transitions. Each training step adds one exp-map for each item latent and \(K_1\) hyperbolic distances per item: 576 steps per epoch, 1,728,000 total; approximately \(24{,}556K_1\) distances per epoch, or \(K_1\) per step at the frozen scale. No added learned parameters; the existing first codebook is used.
HYPOTHESIS: Success requires successor entropy to capture useful diversity of future continuations and its radial ordering to organize the first-code Voronoi cells in a way that coarsens first-level assignment without removing residual identity. Observe first-level assignment changes and prefix-based next-item predictability as diagnostics; Stage3 test Recall@10 above 0.065 is the sole keep criterion.
RISKS: Entropy may mostly encode item popularity or sparsity; average-rank radii discard meaningful entropy gaps; the radial mapping may disrupt useful latent norms. The radius is bounded and based on a robust latent-scale statistic, and the original latent is preserved for all residual levels.
BEHAVIOR SIGNAL: Per-item entropy of directed next-item transitions.
BEHAVIOR COMPUTATION: Count adjacent item pairs per user from the training split; normalize outgoing counts into \(P_{ij}\), then calculate \(H_i\). Items with no outgoing training transitions receive entropy zero and average-rank treatment. No held-out sequence contributes.
LEAKAGE BOUNDARY: Entropies and ranks are calculated once from training interactions only. No validation or test data are used in radius construction, codeword learning, or SID assignment.
HYPERBOLIC OPERATOR: Poincaré exponential map and distance, fixed curvature \(c=-1\).
HYPERBOLIC LOCATION: Transformation of each item latent into the behavior-conditioned point used by first-level quantization.
COUPLING PATH: Training-only successor entropy sets the radius of the point created by the Poincaré exponential map; Poincaré distance from that point to codewords determines the emitted first-level code.
COUPLING EQUATION: \(x_i=\exp_0^{-1}(\rho_{\max}(h_i-\tfrac12)\,z_i/(\|z_i\|+\epsilon));\quad a_i=\arg\min_k d_{\mathbb B}^{-1}(x_i,\exp_0^{-1}(e_k))^2\).
OBSERVABLES: First-level assignments and their frequency distribution should change as a function of successor entropy; level-two/three assignments should continue to differentiate items because their residual input remains the original Euclidean latent minus the selected first codeword. Record entropy-to-code association and training-prefix predictability, but decide only on Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: For the comparison only, set all behavior quantiles to \(h_i=\tfrac12\), making every transformed point the origin, while retaining the Poincaré assignment.
ABLATION GEOMETRY OFF: For the comparison only, use the behavior-conditioned tangent points \(\rho_i v_i\) and Euclidean nearest-codeword distance to \(e_k\).
ABLATION BOTH ON: Use successor-entropy radii and Poincaré distance as specified. These switches are required to demonstrate coupling; train only this both-on candidate, with no ablation runs.
SPEC EQUATIONS: \(P_{ij}=n_{ij}/(\sum_k n_{ik}+\epsilon)\); \(H_i=-\sum_jP_{ij}\log(P_{ij}+\epsilon)\); \(h_i=(\operatorname{average\_rank}(H_i)-1)/(I-1)\); \(v_i=z_i/(\|z_i\|+\epsilon)\); \(\rho_i=\rho_{\max}(h_i-\tfrac12)\); \(x_i=\exp_0^{-1}(\rho_i v_i)\); \(a_i=\arg\min_k d_{\mathbb B}^{-1}(x_i,\exp_0^{-1}(e_k))^2\). Use \(z_i-e_{a_i}\) as the residual input to ordinary Euclidean levels two and three.
SPEC INPUTS OUTPUTS: Inputs are training-only transition counts, encoder latents, and the existing first-level codebook. Outputs are entropy-derived radii, first-level SID assignments, and the baseline-format three-level semantic IDs.
SAFEGUARDS: Set \(\epsilon=10^{-8}\), use average ranks for entropy ties, and define no-successor entropy as zero. Bound the Poincaré radius to \(0.9\), clamp the \(\operatorname{atanh}\) argument below \(1-10^{-5}\), and use the exact latent-median-derived radius scale specified above. Preserve the unmodified latent for the residual path.
END IDEA
