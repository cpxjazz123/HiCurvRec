IDEA: transition-radial-sector-vq
TITLE: Transition sectors with hyperbolic radial first-token assignment
MOTIVATION: The first SID level should be deliberately coarser and predictive of training next-item flow, while levels two and three retain enough residual capacity to distinguish individual items.
NOVELTY: Instead of assigning items to behavior-derived parent/child sets or fixing one graph partition cell as the first token, this builds behavior-defined sectors of the first-level codebook and uses a behavior-conditioned radial coordinate in hyperbolic space to choose among codes inside a sector. The behavior signal changes the point being quantized, not merely the candidate set or an auxiliary loss.
CHANGE: Build item sectors by deterministic clustering of training-only, popularity-adjusted successor profiles; allocate contiguous level-1 code IDs to each sector in proportion to its training item mass, with at least one code per sector. At each RQ-VAE update, combine the encoder latent with its training-derived sector prototype, map the result and sector's code vectors to a fixed-curvature Poincaré ball, and select the nearest code geodesically; leave later residual levels as baseline Euclidean quantizers.
SPECIFICATION: For each training item i compute successor distribution q_i[j]=(n_ij+α p[j])/(out_i+α), where n_ij counts adjacent training-only transitions, p is the training-only successor marginal, and α=1 is a documented unit pseudocount. Set sector prototypes μ_g by deterministic spherical k-means on q_i, with G=min(K0, ceil(sqrt(K0))) sectors; assign each item g(i)=argmin_g KL(q_i||μ_g). Allocate K0 first-level IDs to sectors by largest-remainder rounding of their training item counts, enforcing one per nonempty sector. Define behavior-conditioned latent y_i=z_i+μ_g(i) projected to the encoder latent dimension by a fixed seeded PCA fitted only on training items (if dimensions already match, use identity); normalize μ to unit norm and scale it by median training ||z||. Assign c1(i)=argmin_{k∈C_g(i)} d_{-κ}(exp_0(s y_i),exp_0(s e_k))². Subtract the selected Euclidean prototype from z_i and quantize residual levels 2 and 3 with the baseline RQ-VAE. κ=1/median(||s y||²) over training items, clamped to finite positive values, makes curvature scale-relative rather than tuned.
COST: One-time sparse transition/profile construction O(E_train), profiling/clustering O(N·G·M) for M nonzero successor bins in sparse form, and a training-only PCA. Per step, batch B≈24556/24≈1024 evaluates roughly B·(K0/G) Poincaré distances plus O(Bd) maps; over 24 steps/epoch × 3000 epochs =72,000 steps (about 73.7M·K0/G distance evaluations), plus the baseline. This is one run only; no ablation arms, sweeps, or seed repetitions.
HYPOTHESIS: Successor-profile sectors coarsen level 1 around items that serve similar next-item roles; adding the sector prototype before curved assignment causes geodesically nearby codes to encode within-sector semantic variation, while later residual levels preserve item identity. Keep only if the single frozen Stage3 run exceeds test Recall@10 0.065; diagnostics are descriptive only.
RISKS: Sparse item transition profiles may be dominated by the pseudocount or popularity; KL sectors may not align with predictive prefixes; adding a behavior vector may distort semantic reconstruction; sector code allocation can starve rare sectors; curved assignment may provide no gain. The fixed topology also cannot adapt if training behaviors shift during optimization.
BEHAVIOR SIGNAL: Popularity-smoothed directed next-item distribution for each item.
BEHAVIOR COMPUTATION: Count adjacent i→j transitions separately within each user's Stage2 training sequence. Compute out_i and the successor marginal p[j] from those same training transitions, then q_i[j]=(n_ij+p[j])/(out_i+1). No validation/test sequence or interaction contributes to counts, marginal, clustering, or code allocation.
LEAKAGE BOUNDARY: Cache q_i, sector labels, sector prototypes, PCA, and code allocation using Stage2 training interactions and training-item embeddings only; freeze those objects before SID export. Stage3 validation/test interactions are not inputs to any SID construction or update.
HYPERBOLIC OPERATOR: Exponential map at the Poincaré origin and squared geodesic distance for fixed negative curvature −κ, with κ derived from the median squared mapped-input scale.
HYPERBOLIC LOCATION: First-level quantizer assignment; the behavior-conditioned latent and trainable first-level code vectors are mapped into the ball and compared by geodesic distance. Levels two and three remain ordinary residual quantizers so the final token can preserve item identity.
COUPLING PATH: Training successor distribution determines sector prototype μ_g; μ_g shifts the current latent before exp_0, and the resulting Poincaré geodesic distance selects c1 and changes the residual sent to later levels. Setting behavior off removes μ_g from y_i; replacing hyperbolic geometry removes the exp-map/geodesic assignment, so both switches alter the same first-token computation.
COUPLING EQUATION: q_i=TrainSuccessorProfile(i); g_i=Sector(q_i); y_i=z_i+scale·PCA(μ_{g_i}); c1(i)=argmin_{k∈C_{g_i}} d_{−κ}(exp_0(s y_i),exp_0(s e_k))²; r1(i)=z_i−e_{c1(i)}.
OBSERVABLES: Record first-level assignment changes, first-token next-item predictability and prefix behavior statistics, level-three distinct triples, finite gradient/update statistics, and frozen Stage3 test Recall@10. The behavioral diagnostics do not decide admission; Recall@10 is the judgement.
ABLATION BEHAVIOR OFF: Set the behavior shift μ_g to zero and remove sector restriction, assigning over all K0 codes by the same Poincaré distance. This comparison is specified in code but is not trained in this round.
ABLATION GEOMETRY OFF: Preserve training sectors, behavior shifts, and candidate code sets, but replace exp_0 plus Poincaré distance with squared Euclidean distance on y_i and e_k. This comparison is specified in code but is not trained.
ABLATION BOTH ON: Use the training-derived sector shift and sector-restricted Poincaré geodesic assignment above; this is the sole candidate trained once under the frozen Stage2/Stage3 budget.
SPEC EQUATIONS: n_ij=Σ_{u,t}1[i_{u,t}=i,i_{u,t+1}=j]; p_j=Σ_i n_ij/Σ_{i,j}n_ij; q_ij=(n_ij+p_j)/(out_i+1); g_i=argmin_g KL(q_i||μ_g); a_g=largest_remainder(K0·N_g/N), min 1; h_i=PCA(μ_{g_i})·median_j||z_j||; y_i=z_i+h_i; s=1/median_i||y_i||; κ=1/median_i||s y_i||²; c1_i=argmin_{k∈C_{g_i}} [acosh(1+2κ||x_i−v_k||²/((1−κ||x_i||²)(1−κ||v_k||²)))/sqrt(κ)]², x_i=exp_0^{−κ}(s y_i), v_k=exp_0^{−κ}(s e_k); r_i=z_i−e_{c1_i}; (c2,c3)=baseline_RQ(r_i). Use deterministic clustering/ties; constants α=1 and G=ceil(sqrt(K0)) are fixed documented rules, not tuned.
SPEC INPUTS OUTPUTS: Inputs: Stage2 training sequences, training item embeddings, batch encoder latents z, configured first-level codebook size K0, trainable first-level prototypes, and baseline residual quantizers. Outputs: frozen item sector labels and code allocation; first-level assignments and quantization values; residual levels 2/3; full SIDs.
SAFEGUARDS: Store profiles sparsely; define q for zero-outdegree items as p; normalize distributions with a 1e−12 floor; normalize behavior prototypes and use FP32. Use an orthonormal PCA projection and a training-latent median with 1e−12 floor. Clamp κ||x||² and κ||v||² to at most 1−1e−5, clamp acosh argument to ≥1, clamp atanh arguments where exp/log maps require them, and fail fast on nonfinite distances. Empty sectors are omitted; deterministic smallest-index ties and largest-remainder tie breaks; do not merge residual levels or postprocess away third-level identity.
END IDEA
