IDEA: flowcone_first
TITLE: Transition-flow cones for a deliberately coarse first code
MOTIVATION: Item identities can be poorly organized for next-item generation when the first RQ-VAE code over-separates items that occupy the same outgoing-transition role. Make the first code express training-observed successor-flow roles, while retaining item-specific residual capacity in level three.
NOVELTY: Unlike a behaviour suffix or a transition loss added beside quantization, this uses directed successor-flow to define a hierarchy of admissible first-level cells, and uses hyperbolic distance to select the cell itself. It does not use branch-anchored tangent quantization or rank-sum co-occurrence weighting.
CHANGE: From training-only directed transition distributions, construct a small fixed set of flow-role prototypes; map these prototypes to negatively curved Poincare-ball anchors. Replace unconstrained first-level Euclidean nearest-code assignment with behaviour-conditioned hyperbolic assignment to those anchors, and quantize the remaining representation with the existing second and third RQ levels. Keep the downstream codebook sizes and training schedule unchanged.
SPECIFICATION: Let z_i be the encoder output, and p_i(j)=(N_ij+alpha)/(sum_k N_ik+alpha M), where N_ij counts consecutive training-split transitions i->j and alpha=1/M. Form x_i as the concatenation of sqrt(p_i) and log(1+outdegree_i), then L2-normalize. Run deterministic spherical k-means with K1 clusters on x_i to obtain flow-role labels g_i and centroids mu_k. Map normalized centroids to Poincare anchors a_k=exp_0^c(s mu_k), where s is the median norm of encoder latents after the first warmup epoch and c=1/s^2. At every training step, choose k*=argmin_k d_c(exp_0^c(z_i),a_k); use code e^1_k* as level one and pass z_i-e^1_k* through unchanged level-two/three residual quantization. The differentiable first-level assignment uses softmax(-d_c/tau) during training and hard argmin for SID export; tau is the documented RQ-VAE assignment temperature, not swept. The behavior switch selects these flow anchors versus the ordinary learned first-level codebook; the geometry switch replaces d_c with matched squared Euclidean distance between log-map coordinates and log-map anchors. These switches define comparisons only; train the both-on candidate once.
COST: One-time training-item transition count and deterministic spherical k-means, O(E_train + n_iter*24556*K1*d_flow); cached role labels and anchors thereafter. Per step at the frozen scale: 24,556 items/24 steps/epoch means 1,023 batches per epoch (last batch partial); compute one K1-way distance/soft assignment per item in the batch, O(B*K1*d), versus O(B*K1*d) baseline first-level search, plus negligible cached label lookup. Total 3,000 epochs, no extra runs; expected wall-clock increase is the first-level Poincare distance kernel and one preprocessing pass.
HYPOTHESIS: If directed successor-flow roles are more predictive of next-item structure than unconstrained first-level reconstruction clusters, flow-cone assignment will pool semantically interchangeable origins into fewer first-level prefixes while the unchanged residual levels preserve item identity, raising Stage3 test Recall@10 above 0.065. Observe first-level assignment concentration, third-level distinct-item coverage, training-only transition-role predictability, and ultimately the frozen Stage3 Recall@10; diagnostics are recorded, never admission gates.
RISKS: Sparse or shifting transition rows may yield noisy roles; fixed role labels may not track encoder drift; coarse first-level pooling may erase useful distinctions, or hyperbolic radial scale may saturate despite scale-derived curvature.
BEHAVIOR SIGNAL: Directed immediate item-to-item transition frequency, normalized as each source item's successor probability distribution.
BEHAVIOR COMPUTATION: Count consecutive item pairs in training interactions only, ordered by user and timestamp, excluding cross-user boundaries; add alpha=1/M smoothing, where M is the number of training items, then form normalized successor distributions and deterministic spherical-k-means role labels. No validation/test sequence, target, or interaction is read.
LEAKAGE BOUNDARY: Build counts, item universe, prototypes and anchors solely from the training split before SID construction. Validation/test are unavailable to preprocessing and can only be used in the separately frozen Stage3 evaluation.
HYPERBOLIC OPERATOR: Poincare-ball distance d_c with fixed negative curvature -c, c=1/s^2 and s the median encoder-latent norm measured after warmup; exp_0^c maps latents and role centroids into the ball.
HYPERBOLIC LOCATION: First-level RQ-VAE code assignment during Stage2 training and deterministic SID export; levels two and three remain the existing residual quantizers.
COUPLING PATH: Training successor distributions determine flow-role centroids and hence the available first-level anchors; Poincare distance from each encoded item to those anchors determines its first-level assignment and thus the residual presented to both later levels. Turning behaviour off restores learned unrestricted first-level codes; turning geometry off changes the actual assignment metric.
COUPLING EQUATION: p_i(j)=(N_ij+1/M)/(sum_l N_il+1); mu_k=mean_{i:g_i=k} normalize([sqrt(p_i),log(1+outdegree_i)]); a_k=exp_0^c(s*mu_k); q1(i)=argmin_k d_c(exp_0^c(z_i),a_k). Thus the behaviour-derived a_k and curved d_c jointly determine q1.
OBSERVABLES: With both switches on, first-level assignments should concentrate into transition-role cells and predict training successor roles better, while level-three distinct triples remain near the item count rather than collapsing. The decisive observable is frozen Stage3 test Recall@10; compare directionally to the stated baseline, without using SID diagnostics as a gate.
ABLATION BEHAVIOR OFF: Defined code switch substitutes the ordinary learned first-level RQ-VAE codebook/assignment, preserving the same Poincare distance operator for its anchors; not trained as an additional arm.
ABLATION GEOMETRY OFF: Defined code switch uses squared Euclidean distance from log-map latent to log-map anchor for the same behavior-derived anchors; not trained as an additional arm.
ABLATION BOTH ON: The sole candidate run uses training-derived flow-role anchors and Poincare distance assignment; no ablation arm, sweep, or seed repetition is run.
SPEC EQUATIONS: N_ij=sum_{u,t} 1[i_{u,t}=i and i_{u,t+1}=j] over training only; p_i(j)=(N_ij+1/M)/(N_i.+1); x_i=normalize([sqrt(p_i),log(1+N_i.)]); g_i=kmeans_spherical(x_i,K1); mu_k=mean_{i:g_i=k}x_i; s=median_i ||z_i|| after warmup; c=s^-2; a_k=exp_0^c(s*mu_k); q1(i)=argmin_k d_c(exp_0^c(z_i),a_k); r_i=z_i-e^1_{q1(i)}; (q2,q3)=existing_RQ(r_i). Use same fixed K1 and downstream quantizer as baseline.
SPEC INPUTS OUTPUTS: Inputs are training-only timestamped user-item sequences, training item universe, Stage2 encoder latents, fixed baseline K1/codebooks, and documented RQ-VAE temperature. Outputs are cached transition role anchors, first-level code assignments, residuals, and ordinary second/third-level SID codes.
SAFEGUARDS: Use alpha=1/M smoothing; clamp norms away from zero; project ball points to radius (1-1e-5)/sqrt(c); clamp arcosh arguments to >=1+1e-7 and denominators in Mobius distance away from zero; use float32 or higher for geometry. If s is zero/nonfinite, use the documented encoder latent RMS as fallback and record it. Empty roles are excluded from anchor assignment; ties use smallest code index. Fix k-means initialization/order deterministically from training item IDs, with no validation-based choices.
END IDEA
