IDEA: trans_tree_ball
TITLE: Training-transition tree fixes coarse prefixes; Poincare residuals choose identity-preserving leaves
MOTIVATION: Encourage a deliberately coarse first-level partition informed by next-item behaviour, without collapsing later digits that distinguish items.
NOVELTY: Behaviour constructs a fixed coarse code tree before RQ-VAE training; unlike behavior-weighted scoring over an unchanged codebook, a Poincare residual assignment is restricted to the behaviour-selected subtree and determines the next digit.
CHANGE: Build a deterministic balanced hierarchy of item groups from train-only directed transition similarity and map each group to one first-level prefix. At each residual quantizer level, use the current residual's Poincare distance to choose among child codes in that prefix; reserve the final level for ordinary residual reconstruction so identity-bearing codes remain available.
SPECIFICATION: Let W_ij=count_train(i→j), symmetrize S_ij=W_ij+W_ji and degree-normalize S. Recursively bisect the induced graph by the sign of its Fiedler vector until K1 leaves (K1 equals the existing first-level code count); deterministic item-ID tie break. Assign prefix p(i) to its leaf. For levels l≥2, select child k in that leaf by argmin d^2_{-1}(exp_0(r_i),exp_0(c_{p,k})); train the ordinary straight-through RQ-VAE reconstruction/commitment objective with these constrained assignments. No new loss coefficient.
COST: One-time sparse graph build and spectral partition, amortized across training; per step distance work is O(batch×children×dimension), the same order as baseline assignment, with map/distance overhead. At 24 steps/epoch × 3000 epochs = 72,000 steps; expected modest constant-factor assignment overhead, no additional trainable network or per-step graph work.
HYPOTHESIS: Transition-derived coarse prefixes reduce first-level separation while curved residual selection retains third-level item identity; observe L1 hard error moving upward and third-level triples remaining close to item count, then retain only if the single frozen Stage3 test Recall@10 exceeds 0.065.
RISKS: Spectral communities may reflect popularity rather than useful continuation structure; hard prefix constraints can strand an item outside a useful residual code, and tree imbalance may create oversized buckets.
BEHAVIOR SIGNAL: Directed item-to-item next-event transition counts.
BEHAVIOR COMPUTATION: Count consecutive item pairs in training sequences only; W_ij is the number of training occurrences of i immediately followed by j. Symmetrize solely for stable hierarchical partitioning; discard user IDs after aggregation.
LEAKAGE BOUNDARY: Construct the graph and tree once from the training split before Stage2. Validation/test sequences, labels, metrics, and interactions are not loaded by tree construction, assignment, or checkpoint choice.
HYPERBOLIC OPERATOR: Poincare-ball geodesic distance at fixed curvature -1, with exp_0 map from tangent residual/code vectors.
HYPERBOLIC LOCATION: Child-code quantization at residual levels beneath the behavior-fixed first-level prefix.
COUPLING PATH: The training-transition tree selects the permitted child-code set for each item's prefix; Poincare distance within that set selects its residual code and therefore its RQ-VAE updates. Removing either changes the assignment pathway.
COUPLING EQUATION: p(i)=Tree_{W}(i); k_l(i)=argmin_{k∈Children(p(i))} d_{-1}(exp_0(r_i^l),exp_0(c_{p(i),k}^l))^2. The behavior term is the transition-derived membership constraint, and the curved term is the within-subtree assignment metric.
OBSERVABLES: Record prefix count/size distribution, L1 hard error, per-level active-code counts, distinct third-level triples, assignment churn, and Stage3 test Recall@10; diagnostics do not gate admission.
ABLATION BEHAVIOR OFF: Replace the transition-derived tree with the baseline fixed Euclidean RQ-VAE code partition; retain the same Poincare child-distance assignment.
ABLATION GEOMETRY OFF: Keep the exact training-derived tree and subtree constraints, but replace Poincare distance/maps with Euclidean residual distance/maps.
ABLATION BOTH ON: Use the training-transition-derived fixed prefix tree and Poincare child assignment as specified. These switches are implemented for counterfactual definition only; train one both-on candidate, no ablation arm.
SPEC EQUATIONS: W_ij=Σ_{u,t}1[x_{u,t}=i,x_{u,t+1}=j]; S=W+Wᵀ; recursively spectral-bisect S into K1 leaves. At level l, r_i^l=z_i−Σ_{q<l}c_{i,q}; q_i,l=argmin_{k∈C(p(i),l)}d_{-1}(exp_0(r_i^l),exp_0(c_{p(i),l,k}))²; r_i^{l+1}=r_i^l−c_{p(i),l,q}. Optimize existing RQ-VAE objective with straight-through selected vectors.
SPEC INPUTS OUTPUTS: Inputs are training sequences, item embeddings, existing codebook sizes, encoder outputs, and fixed code vectors. Outputs are a frozen item→prefix tree, constrained per-level code assignments, and standard RQ-VAE SIDs.
SAFEGUARDS: Sparse degree-normalized graph; deterministic eigensolver initialization and ID tie-break; isolate nodes assigned deterministically by item ID; ensure every leaf has at least one item and nonempty child code set. Clamp ball norm to 1−1e−5, stabilize acosh argument to ≥1+1e−7, use float32+ distances, finite checks, and safe zero-norm exp/log maps. K1 is the existing architecture value, not swept.
END IDEA

IDEA: branch_mass_shell
TITLE: User-interest branch masses define coarse radial shells for hyperbolic leaf quantization
MOTIVATION: Items that occupy different next-item branches for the same training users need distinct coarse neighborhoods, while a highly shared continuation core can be intentionally represented by a small number of coarse prefixes.
NOVELTY: A training-only branch decomposition determines a constrained coarse shell layout, then item-specific branch mass continuously changes the radial hyperbolic assignment geometry. This is neither a standalone behavior loss nor a behavior suffix on a fixed Euclidean quantizer.
CHANGE: Derive each item's normalized outgoing-neighbour distribution and partition items into a fixed number of coarse branch-mass groups using deterministic quantiles of its train-only branch entropy and dominant-neighbour community. Assign a first-level prefix from that group; within the group, score deeper codes by Poincare distance after a branch-mass-dependent radial map. Keep all later residual levels available to encode distinctions within broad groups.
SPECIFICATION: From W_ij training transitions, define p_i(j)=W_ij/Σ_jW_ij, entropy h_i=−Σ_j p_i(j)log p_i(j), and dominant neighbour b_i=argmax_j p_i(j) (ID tie break). Form coarse groups by connected components of the undirected top-1 successor graph, then deterministically merge smallest components by least increase in entropy-mean difference until K1 groups; map groups to prefixes. Let a_i=1+h_i/log(max(2,outdeg_i)) (set h_i=0 if outdegree≤1). Map tangent latent z_i to exp_0(a_i z_i) and choose deeper residual codes by Poincare distance within its prefix; update using existing RQ-VAE objective.
COST: O(nnz(W)) preprocessing plus component/merge bookkeeping; each training assignment adds one scalar multiply per latent and standard Poincare distances. At frozen scale 72,000 steps, overhead is small versus baseline distance evaluation; no extra epochs, model, or learned graph.
HYPOTHESIS: Behaviour-defined groups create coarse first-level IDs while entropy-scaled curvature makes branch-diverse items occupy different geodesic regions inside each group; observe upward L1 hard error without loss of distinct third-level triples, and judge solely by one Stage3 test Recall@10 run against 0.065.
RISKS: Entropy is an imperfect proxy for useful branch diversity; sparse/low-frequency items may have unstable distributions, component merges may be arbitrary, and radial scaling may push points near the ball boundary.
BEHAVIOR SIGNAL: Per-item branching of directed next-item transitions.
BEHAVIOR COMPUTATION: Count immediate directed successors from training sequences. For each item normalize its outgoing successor histogram, compute entropy and dominant successor, and build top-1 successor components; all statistics use training events only.
LEAKAGE BOUNDARY: Tree/group and entropy statistics are frozen before training from the training split. No validation/test interactions participate in quantiles, component merges, scales, model selection, or SID generation.
HYPERBOLIC OPERATOR: Origin exponential map and Poincare geodesic distance on curvature -1 ball; behaviour-derived radial factor is applied before the map.
HYPERBOLIC LOCATION: The latent-to-ball map and constrained deeper-level code assignment during Stage2 quantization.
COUPLING PATH: The train-only branch group selects the candidate prefix and its code set; its measured branch entropy sets the radial scale of the point whose Poincare distance chooses a leaf. Removing behaviour removes both group and scale; removing curvature replaces the actual map and metric.
COUPLING EQUATION: g_i=Group(W,i), a_i=1+h_i/log(max(2,outdeg_i)); k_i=argmin_{k∈C(g_i)} d_{-1}(exp_0(a_i r_i), exp_0(c_{g_i,k}))². Here g_i is the transition-branch constraint and a_i is its entropy-derived behaviour factor, coupled to curved scoring.
OBSERVABLES: Log group sizes, entropy/radial-factor distribution, L1 hard error, active codes and distinct third-level triples, assignment stability, and Stage3 test Recall@10. These are diagnostics, not admission thresholds.
ABLATION BEHAVIOR OFF: Set a_i=1 and replace transition-derived groups by the baseline unconstrained prefix assignment; use the same Poincare operation for the comparison definition.
ABLATION GEOMETRY OFF: Preserve training-derived groups and a_i, but use Euclidean distance and identity tangent mapping instead of exp_0/Poincare distance.
ABLATION BOTH ON: Use the train-only branch groups, entropy-derived radial factor, exp_0 and curvature -1 distance as specified. Switches are present in implementation, but train only this both-on candidate.
SPEC EQUATIONS: p_i(j)=W_ij/(Σ_jW_ij+ε); h_i=−Σ_jp_i(j)log(p_i(j)+ε); a_i=1+h_i/log(max(2,|{j:W_ij>0}|)); form top-1 successor components and merge smallest components deterministically to K1 groups. For each level below first: q_i=argmin_{k∈C(g_i)}d_{-1}(exp_0(a_i r_i),exp_0(c_{g_i,k}))². Quantize and update the ordinary residual RQ-VAE objective.
SPEC INPUTS OUTPUTS: Inputs: train transition counts, item embeddings, existing RQ-VAE code sizes and encoder residuals. Outputs: frozen item→group map, behaviour-scaled curved code assignments, and final SIDs.
SAFEGUARDS: Use ε=machine-safe count smoothing only for logarithms; define no-successor items as entropy zero and singleton components. Fix tie-breaking by item ID and merge order. Cap a_i by the analytically derived bound a_i≤2 since normalized entropy is in [0,1]; cap mapped norm below 1−1e−5, stabilize acosh ≥1+1e−7, use float32+ and finite checks. No fitted or swept constants.
END IDEA
