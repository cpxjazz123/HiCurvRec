IDEA: TRANSITION_GEODESIC_FINE_MARGIN
TITLE: Use directed-transition geodesic margins to preserve fine-level distinctions
MOTIVATION: Items that frequently follow one another in training sequences may need compatible representations, but forcing them into the same early code can erase distinctions needed to predict the next item. This mechanism makes observed transitions shape the fine-level decision: frequent successors should be directionally predictable without being collapsed into identical residual codes.
NOVELTY: Unlike behaviour-weighted assignment or codeword-margin mechanisms, it acts on the *residual after each coarse assignment* and compares successor residuals to the source residual by a directed hyperbolic geodesic prediction error. It targets fine-level separability rather than concentrating the first code level.
CHANGE: After each quantization level, predict a successor’s residual from the source residual using a trainable tangent-space transition map, then use the resulting hyperbolic prediction error to modulate the next-level assignment logits. The same error also supplies a training gradient to the map and residual encoder.
SPECIFICATION: For each training transition edge \(i\to j\), at level \(l\) let \(r_i^l,r_j^l\) be the residuals after levels \(<l\). Map both to the Poincaré tangent space at the origin, predict \(p_{ij}^l=\exp_0(A_l\log_0(r_i^l))\), and compute \(e_{ij}^l=d_{-c}(p_{ij}^l,r_j^l)^2\). For item \(i\), use the weighted mean successor error \(\bar e_i^l\) to scale the level-\(l\) code distances: \(D_{ik}^l=d_{-c}(r_i^l,c_k^l)^2(1+\bar e_i^l/s_l)\), where \(s_l\) is the detached training-batch median positive \(e^l\) (fallback to the running median, then 1). Soft assignment logits are \(-D_{ik}^l/\tau_l\); retain the baseline hard argmin for SID export. Train the transition maps through the batch-mean \(e^l\), with its scale normalized by the same \(s_l\). Use only levels \(l\ge2\), so the behaviour signal cannot alter the coarse partition directly.
COST: Precompute and store a sparse, training-only outgoing edge list. At the frozen scale, 24 steps/epoch × 3000 epochs = 72,000 steps; for batch size \(B\), each step costs \(O(BK d + E_B d)\), where \(K\) is codebook size and \(E_B\) is the number of sampled in-batch outgoing edges, capped at one successor per source item by selecting the highest-count successor. The additional hyperbolic maps/distances apply only to those edges and levels \(l\ge2\); no all-pairs item computation. One model training run, with the frozen budget and no ablation arms.
HYPOTHESIS: It is worth keeping if directed successors become more predictable from fine-level residuals while remaining distinguishable at those levels, and frozen Stage3 test Recall@10 exceeds 0.065. Record transition prediction error and SID assignment changes as diagnostics, not admission gates.
RISKS: Sparse or noisy transitions may make successor prediction unrepresentative; a high-error source may receive distorted logits; median normalization can be unstable in a small batch. The map may learn broad transition regularities without improving next-item generation.
BEHAVIOR SIGNAL: Directed item-to-item transitions.
BEHAVIOR COMPUTATION: From training interactions only, count adjacent item pairs within each user’s time-ordered training sequence; discard self-transitions and retain the highest-count outgoing successor per source item, with edge weight equal to its count divided by that source’s outgoing count.
LEAKAGE BOUNDARY: Build the edge list strictly from the training split before Stage 2 training. Do not read validation/test sequences, co-occurrence, or statistics; freeze the list for the entire run and SID export.
HYPERBOLIC OPERATOR: Poincaré-ball \(\log_0\), \(\exp_0\), and squared geodesic distance \(d_{-c}^2\), with fixed negative curvature \(-c\), where \(c=1/R^2\) and \(R\) is the baseline encoder’s documented output radius.
HYPERBOLIC LOCATION: Fine-level residual assignment logits and the directed transition-prediction path during Stage 2 training.
COUPLING PATH: Training transitions define \(e_{ij}^l\); that error both trains the transition map and changes the fine-level code distances for the source item. Without transitions the error and its modulation vanish; replacing the curved maps and distance with their Euclidean counterparts changes both the error and the logits.
COUPLING EQUATION: \(e_{ij}^l=d_{-c}(\exp_0(A_l\log_0 r_i^l),r_j^l)^2;\quad D_{ik}^l=d_{-c}(r_i^l,c_k^l)^2(1+\bar e_i^l/s_l)\), for \(l\ge2\).
OBSERVABLES: Compare fine-level assignments, batch transition prediction error, and Stage3 test Recall@10. The mechanism predicts changed fine-level assignments and improved successor predictability; the judgement is the frozen-protocol Recall@10, with target \(>0.065\).
ABLATION BEHAVIOR OFF: Code switch `behavior_on=False` sets all \(\bar e_i^l=0\) and disables transition-map loss; assignment uses the unmodulated curved distances.
ABLATION GEOMETRY OFF: Code switch `geometry_on=False` replaces \(\log_0,\exp_0,d_{-c}\) with tangent-space identity maps and Euclidean squared distance, leaving the same training-only transition edges and connected modulation path.
ABLATION BOTH ON: `behavior_on=True, geometry_on=True` uses the training-only directed edges, curved transition prediction, and its error-modulated fine-level assignments. This is the sole trained configuration.
SPEC EQUATIONS: For each \(i\to j\) and \(l\ge2\): \(p=\exp_0(A_l\log_0 r_i^l)\); \(e=d_{-c}(p,r_j^l)^2\); \(\bar e_i^l=\sum_j w_{ij}e_{ij}^l/\sum_jw_{ij}\); \(s_l=\operatorname{median}_{e>0}(\operatorname{stopgrad}(e))\); \(D_{ik}^l=d_{-c}(r_i^l,c_k^l)^2(1+\bar e_i^l/s_l)\). Train with the baseline reconstruction/quantization losses plus \(\operatorname{mean}(e/s_l)\); use the baseline temperature and hard-quantization/export procedure unchanged.
SPEC INPUTS OUTPUTS: Inputs are current-level residuals, codebook vectors, and a sparse training-only directed weighted edge list. Output is a per-item fine-level assignment-logit matrix and transition-prediction loss; exported output remains the baseline-format item SID table.
SAFEGUARDS: Project points to radius at most \((1-\epsilon)/\sqrt c\); clamp norms before \(\log_0\), clamp distance arguments and denominators, detach the batch median, and fall back to a running median then 1 if there are no positive errors. Use the baseline’s documented \(\epsilon\) and optimizer settings; do not tune constants.

END IDEA

IDEA: BRANCH_CONDITIONED_FRECHET_RESIDUAL
TITLE: Quantize fine residuals around behaviour-branch Fréchet anchors
MOTIVATION: A single item can participate in multiple user-interest branches. A global residual quantizer may blur these roles, particularly when a frequent successor relation applies only within one branch. This mechanism uses the item’s training-derived branch context to choose a curved residual anchor, while keeping the item’s residual code assignment responsible for its identity.
NOVELTY: Rather than add a behaviour suffix, supervise a separate branch label, or move only the first-level codebook, it computes branch-specific Fréchet anchors in the hyperbolic space and subtracts the selected anchor along a geodesic before each fine-level quantization. Thus behaviour and curvature jointly define the input to the fine quantizer.
CHANGE: Derive a small set of training-only interest branches from each item’s outgoing-transition profile. At fine levels, represent the item residual relative to the Fréchet mean of its branch’s successor residuals, using a curved log/exp residual; quantize that residual with the existing fine codebook.
SPECIFICATION: Build each item’s normalized sparse outgoing-transition distribution \(q_i\) from training sequences. Cluster these distributions into \(G\) branches using deterministic spherical \(k\)-means, with \(G\) set to the baseline number of first-level codes and the baseline initialization seed. For each fine level \(l\ge2\), assign item \(i\) to its nearest branch centroid \(g(i)\) by cosine distance of \(q_i\). Compute the branch anchor \(a_g^l\) as the Fréchet mean of residuals \(r_j^l\) over training edges \(i\to j\) with \(g(i)=g\), weighted by edge counts; approximate the mean by a fixed three log/exp averaging iterations initialized at the weighted Euclidean mean projected into the ball. Quantize \(u_i^l=\log_{a_{g(i)}^l}(r_i^l)\) using the baseline codebook mapped into the anchor’s tangent space, and update residuals by subtracting the selected code in that tangent space then applying \(\exp_{a_{g(i)}^l}\).
COST: Precompute \(q_i\), branch labels, and sparse edges once from training data. At the frozen scale of 72,000 steps, each step adds \(O(Bd)\) log/exp operations per fine level and anchor lookup; anchors are computed from the batch’s sampled training edges, with three averaging iterations costing \(O(E_B d)\) per fine level. No extra neural network or all-item pairwise distance matrix. One training run only.
HYPOTHESIS: It is worth keeping if fine-level assignments differ by branch in a way that preserves branch-specific successors and frozen Stage3 test Recall@10 exceeds 0.065. Record branch-conditioned transition predictability and SID changes as diagnostics only.
RISKS: Branches may be unstable for items with few outgoing transitions; branch anchors may be biased by popular successors; approximate Fréchet means may lag under changing residuals. Discrete branch membership can also over-specialize code usage.
BEHAVIOR SIGNAL: User-interest branching, represented by each item’s outgoing-transition distribution.
BEHAVIOR COMPUTATION: Count adjacent directed item transitions in each user’s time-ordered training sequence only; form one normalized outgoing distribution per item and cluster those distributions into \(G\) deterministic cosine clusters. Items with no outgoing transitions receive the global training-only distribution and are marked as such for diagnostics.
LEAKAGE BOUNDARY: All transition counts, distributions, clusters, and branch labels are computed from training interactions only. Recompute anchors only from current Stage 2 residuals and the frozen training edge list; no validation/test interactions or item statistics enter branch assignment or SID construction.
HYPERBOLIC OPERATOR: Fixed-curvature Poincaré-ball logarithmic and exponential maps at branch-specific base points, with geodesic Fréchet averaging and tangent-space residual quantization; curvature is \(-c\), \(c=1/R^2\), with \(R\) the baseline encoder’s documented output radius.
HYPERBOLIC LOCATION: Fine-level residual construction and code assignment in Stage 2; coarse-level assignments remain the baseline’s.
COUPLING PATH: Training-only transition profiles select the branch; those branch labels select the anchor computed from training-transition successor residuals; the anchor’s curved tangent residual is the actual fine-quantizer input. Removing behaviour replaces all labels/anchors with one global anchor; removing geometry replaces the curved anchor-relative residual with ordinary Euclidean subtraction.
COUPLING EQUATION: \(g(i)=\arg\min_g\|\hat q_i-\mu_g\|_2^2;\quad a_g^l=\operatorname{Frechet}_{-c}\{r_j^l:(i\to j),g(i)=g\};\quad u_i^l=\log_{a_{g(i)}^l}^{-c}(r_i^l)\).
OBSERVABLES: Compare fine-level SID assignments, per-branch successor predictability, and frozen Stage3 test Recall@10. The predicted effect is branch-conditioned fine-code allocation; only test Recall@10 judges success.
ABLATION BEHAVIOR OFF: Code switch `behavior_on=False` sets every item to one global branch and uses the global successor-residual anchor; curved residual quantization remains active.
ABLATION GEOMETRY OFF: Code switch `geometry_on=False` uses Euclidean branch means and residuals \(r_i^l-a_{g(i)}^l\), retaining the same training-only branch labels and connected fine-level quantization path.
ABLATION BOTH ON: `behavior_on=True, geometry_on=True` uses transition-profile branches, successor-derived Fréchet anchors, and curved anchor-relative fine quantization. This is the sole trained configuration.
SPEC EQUATIONS: \(q_i(j)=N_{\rm train}(i\to j)/\sum_kN_{\rm train}(i\to k)\). Cluster \(\hat q_i\) into \(G\) groups. For \(l\ge2\), \(a_g^l\leftarrow\) three iterations of \(a\gets\exp_a(\sum_j\alpha_j\log_a r_j^l/\sum_j\alpha_j)\), with \(\alpha_j=N_{\rm train}(i\to j)\) over edges whose source branch is \(g\). Set \(u_i^l=\log_{a_{g(i)}^l}r_i^l\); map each existing fine code \(c_k^l\) into that tangent space using \(\log_{a_{g(i)}^l}c_k^l\), assign by minimum squared tangent norm, and update via the corresponding \(\exp_{a_{g(i)}^l}\) reconstruction.
SPEC INPUTS OUTPUTS: Inputs are training-only transition counts, per-item residuals at fine levels, and baseline fine codebooks. Outputs are fine-level assignments and updated residuals, followed by the baseline-format SID table.
SAFEGUARDS: Use baseline \(G\), initialization seed, optimizer settings, and three fixed Fréchet iterations, without sweeps. Project points inside radius \((1-\epsilon)/\sqrt c\), clamp log-map norms and denominators, use a global anchor for empty branches, and fall back to the Euclidean initialization if a Fréchet iteration is non-finite. Apply one consistent projection and distance convention to residuals, anchors, and code vectors.

END IDEA
