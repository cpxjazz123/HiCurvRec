IDEA: TRANSITION_TANGENT_FINE
TITLE: Transition-conditioned tangent residual quantization for fine SID levels
MOTIVATION: Items with similar content embeddings can lead to different next items in training sequences. The fine SID levels should preserve those successor distinctions rather than spending their capacity only on reconstruction.
NOVELTY: Behavior enters the residual presented to each fine quantizer through a transition-derived tangent vector. This differs from applying a successor loss beside quantization or using behavior only to bias a coarse assignment.
CHANGE: For each item, compute a smoothed mean successor embedding from training transitions. Map that signal to the tangent space at the item’s hyperbolic embedding, and add a scale-normalized version to the residual before each fine-level code assignment.
SPECIFICATION: Let \(x_i\) be the item embedding and \(h_i=\exp_o(x_i)\) its Poincaré-ball representation. From training transitions, compute \(m_i\), the mean embedding of observed successors, with a global-mean fallback for items without successors. Set \(t_i=\log_{h_i}(m_i)\), and let \(r_{i,\ell}\) be the tangent residual at fine level \(\ell\). Quantize by \(k^*=\arg\min_k d_{-1}(\exp_{q_{i,\ell}}(r_{i,\ell}+\alpha_\ell t_i),c_{\ell k})^2\), where \(q_{i,\ell}\) is the current residual base point and \(\alpha_\ell=\mathrm{RMS}(r_{\ell})/(\mathrm{RMS}(t)+\epsilon)\). Subtract the selected code via the corresponding log/exp maps to form the next residual.
COST: Baseline is 24,556 items × 24 steps/epoch × 3,000 epochs. Precompute successor means once from training interactions. Per training step, the extra work is one batched log-map and tangent-vector addition for the step’s items; for hard assignment, add one batched exp-map per fine level and code-distance computation already of quantization scale. No extra interaction-level pass per epoch.
HYPOTHESIS: Worth keeping if transition direction carries fine-grained next-item distinctions that the content residual alone misses. Observe changed fine-level assignments and prefix-conditioned next-item predictability; retain only if frozen-protocol Stage3 test Recall@10 exceeds 0.065.
RISKS: Sparse successors, noisy transition means, or a mismatch between the static mean successor and context-dependent intent may blur useful residual directions. Fine-level geometry may be sensitive to the tangent-space scale estimate.
BEHAVIOR SIGNAL: Directed item-transition successor means.
BEHAVIOR COMPUTATION: Count consecutive item pairs in the Stage2 training interaction split only; for each source item, average the target-item embeddings, using a global training successor mean when no outgoing pair exists. Do not use validation or test sequences.
LEAKAGE BOUNDARY: Successor counts and means are constructed only from the Stage2 training split and frozen before SID export; validation/test interactions are never read by the operator.
HYPERBOLIC OPERATOR: Poincaré-ball log and exp maps and squared geodesic distance with fixed curvature \(-1\).
HYPERBOLIC LOCATION: The transition tangent is added to the residual immediately before each fine-level RQ-VAE code assignment; the selected code is removed through curved residual updates.
COUPLING PATH: Training transitions determine \(t_i\); \(t_i\) changes the fine residual’s location in the tangent space; the exp map places that residual on the curved manifold; geodesic code distances decide the fine SID.
COUPLING EQUATION: \(k^*_{i,\ell}=\arg\min_k d_{-1}(\exp_{q_{i,\ell}}(r_{i,\ell}+\alpha_\ell t_i),c_{\ell k})^2,\quad t_i=\log_{h_i}(m_i^{\mathrm{succ}})\).
OBSERVABLES: Fine-level code assignments and residual reconstruction change as a function of successor direction; measure transition-conditioned prefix predictability and Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: Set \(t_i=0\); retain the same Poincaré residual quantization.
ABLATION GEOMETRY OFF: Replace log/exp maps and geodesic code distances with their Euclidean tangent/residual and Euclidean code-distance counterparts.
ABLATION BOTH ON: Use the training-only successor mean in the tangent residual and Poincaré log/exp/geodesic quantization as specified. These are code switches for interpretation; train only the both-on candidate.
SPEC EQUATIONS: \(m_i^{\mathrm{succ}}=\frac{\sum_j n_{ij}x_j+\lambda\mu_{\mathrm{succ}}}{\sum_j n_{ij}+\lambda}\), with \(\lambda=1\) as a documented unit pseudocount; \(t_i=\log_{h_i}(\exp_o(m_i^{\mathrm{succ}}))\); \(\alpha_\ell=\mathrm{RMS}(r_\ell)/(\mathrm{RMS}(t)+\epsilon)\); \(z_{i,\ell}=\exp_{q_{i,\ell}}(r_{i,\ell}+\alpha_\ell t_i)\); \(k^*=\arg\min_k d_{-1}(z_{i,\ell},c_{\ell k})^2\). Apply standard curved residual subtraction after selection.
SPEC INPUTS OUTPUTS: Inputs: item embeddings, training-only directed transition counts, current curved residual and codebooks. Output: fine-level code index per item and updated curved residual.
SAFEGUARDS: Use float32 or higher for maps and distances; clamp ball norms to \(1-\epsilon\); stabilize log/exp near zero; add \(\epsilon\) to RMS denominators; use a global-mean fallback for missing successors; detach transition means so they are fixed training-derived statistics. Derive the residual multiplier from batch RMS rather than tuning it.

IDEA: TRANSITION_MARGIN_GEODESIC
TITLE: Successor-weighted geodesic separation for fine code assignments
MOTIVATION: Fine codes can merge items that look close in embedding space even when their observed successors differ. Use training-only transition divergence to discourage such merges specifically at fine quantization levels.
NOVELTY: The behavior signal weights a pairwise geodesic separation term on the fine quantized representations themselves, so transition incompatibility changes the fine codebook/encoder updates rather than only adding a separate behavior objective.
CHANGE: For item pairs with shared training successors, compute a smoothed divergence between their successor distributions. Weight their fine-level geodesic distance by that divergence, encouraging transition-distinct items to remain separated while leaving transition-similar pairs governed by reconstruction.
SPECIFICATION: For each item \(i\), form smoothed successor distribution \(p_i(j)=(n_{ij}+\beta p_0(j))/(N_i+\beta)\), with \(p_0\) the training-wide successor distribution and \(\beta=1\). For each minibatch pair, define \(b_{ij}=\mathrm{JS}(p_i,p_j)/\log 2\). On the final fine-level quantized points \(z_i,z_j\), add \(L_{\mathrm{sep}}=\frac{1}{|P|}\sum_{(i,j)\in P}b_{ij}\max(0,\rho-d_{-1}(z_i,z_j))^2\). Set \(\rho\) to the median positive geodesic distance of the current batch, stop-gradient through this scale estimate, and optimize jointly with the existing RQ-VAE objective.
COST: At the frozen scale of 24,556 training items, 24 steps/epoch and 3,000 epochs, precompute sparse successor distributions once. Pair only items co-occurring in a training minibatch; extra cost is \(O(B^2)\) JS-weight lookups and geodesic distances per step for batch size \(B\), with no full item-pair matrix. No extra training run or hyperparameter sweep.
HYPOTHESIS: Worth keeping if transition-distribution differences identify items that must retain distinct fine codes, and if the geodesic penalty improves next-item discrimination without harming reconstruction. Observe changed fine assignments, higher transition-conditioned prefix predictability, and frozen-protocol Stage3 test Recall@10 above 0.065.
RISKS: Minibatch pairs may not cover enough relevant item pairs; sparse or noisy successor distributions may cause false separation. Excessive separation could consume fine code capacity and reduce useful generalization.
BEHAVIOR SIGNAL: Smoothed directed successor-distribution divergence between item pairs.
BEHAVIOR COMPUTATION: Count consecutive item transitions on the Stage2 training interaction split; derive each item’s successor distribution with the training-wide successor distribution as the prior. Exclude validation and test interactions.
LEAKAGE BOUNDARY: The pair weights are computed from training-only transition counts, and the batch pair set comes only from Stage2 training items. No validation/test interaction contributes to distributions, pair selection, or code assignment.
HYPERBOLIC OPERATOR: Squared Poincaré geodesic distance on the final fine-level quantized points, fixed curvature \(-1\).
HYPERBOLIC LOCATION: Fine-level quantized representation training objective; the weighted geodesic margin directly updates the encoder and fine codebooks.
COUPLING PATH: Training successor distributions produce \(b_{ij}\); \(b_{ij}\) scales a margin penalty on the Poincaré geodesic distance between fine quantized points; its gradients update the representations that determine fine SIDs.
COUPLING EQUATION: \(L_{\mathrm{sep}}=\frac{1}{|P|}\sum_{(i,j)\in P}\frac{\mathrm{JS}(p_i,p_j)}{\log 2}\max(0,\rho-d_{-1}(z_i,z_j))^2\).
OBSERVABLES: Fine-level assignments for high-divergence successor pairs should separate more often than for low-divergence pairs; observe assignment changes, transition-conditioned prefix predictability and Stage3 test Recall@10.
ABLATION BEHAVIOR OFF: Set every \(b_{ij}=0\); retain the same hyperbolic fine quantization and its ordinary objective.
ABLATION GEOMETRY OFF: Replace \(d_{-1}(z_i,z_j)\) with Euclidean distance between matched unconstrained vectors; retain the same training-derived \(b_{ij}\) and batch pairs.
ABLATION BOTH ON: Use the successor-distribution weights and Poincaré geodesic fine-level margin together. The switches are implemented for attribution, but only the both-on candidate is trained.
SPEC EQUATIONS: \(p_i(j)=(n_{ij}+p_0(j))/(N_i+1)\); \(b_{ij}=\mathrm{JS}(p_i,p_j)/\log2\); \(\rho=\mathrm{stopgrad}(\mathrm{median}\{d_{-1}(z_a,z_b)>0\})\); \(L=L_{\mathrm{RQ-VAE}}+L_{\mathrm{sep}}\). The unit coefficient on \(L_{\mathrm{sep}}\) fixes the contribution without tuning.
SPEC INPUTS OUTPUTS: Inputs: training transition counts, minibatch item IDs, final fine-level quantized points. Output: scalar fine-level separation loss and gradients to encoder/codebooks.
SAFEGUARDS: Use sparse distributions and compute JS only over the union of pair supports plus prior mass; clamp Poincaré norms below one; clamp geodesic arguments to valid ranges; skip empty pair sets and use a finite fallback for \(\rho\); detach \(\rho\) to prevent scale gaming.
END IDEA
