IDEA: branch_radial_anchor
TITLE: Branch-radius Poincare anchors with a compact first alphabet
MOTIVATION: Items with diffuse successor futures should share a broad, predictable prefix region, while items with concentrated futures can occupy more peripheral, discriminative regions; this puts useful transition branching into the first-level choice without forcing all information into T4.
NOVELTY: Unlike a behavior suffix, independent branch loss, category cone, or Euclidean first-level clustering, the same per-item branch statistic sets a target hyperbolic radius that directly changes the first-level codeword argmin. Use K1=32 and retain [32,256,256,1] effective codebook capacities; T4 remains only deterministic collision extension.
CHANGE: Compute successor-branch entropy from training-only consecutive item pairs, map it to a target radius in a Poincare ball, and assign the first residual to the codeword minimizing Poincare distance plus a radius-shell penalty; optimize the existing RQ-VAE reconstruction/commitment objectives at all levels.
SPECIFICATION: For train transitions (i,j), define n_ij counts and q_ij=(n_ij+alpha)/(sum_j n_ij+alpha*M_i), H_i=-sum_j q_ij log q_ij, b_i=H_i/log(max(2,M_i)). Set rho_i=rho_min+(rho_max-rho_min)*b_i, with 0<rho_min<rho_max<1/sqrt(c). For first-layer latent z_i and Euclidean code vector e_k, x_i=exp^c_0(z_i), p_k=exp^c_0(e_k), assign a_i=argmin_k [d_c(x_i,p_k)^2+lambda_r*(||p_k||_c-rho_i)^2]. Straight-through quantize to p_a, log-map for the next Euclidean residual stage. Fit c>0 and codewords jointly; T2/T3 distinguish within-anchor items and T4 is fixed collision extension.
COST: Cache entropy/radius once from the training graph. Per assignment cost O(B*K1*d) hyperbolic distances and shell penalties, versus O(B*K1*d) baseline Euclidean distances; constant-factor (roughly 1.5-2x first-level assignment arithmetic), negligible versus full 3000-epoch Stage 2. At frozen 24 steps/epoch: 24,556 item rows/epoch, 73,668,000 item-visits total; 32*dimension pair distances per row and no dense all-items matrix. Four cards, frozen 3000 epochs, no early stop.
HYPOTHESIS: Branch entropy predicts whether a broad prefix can retain multiple plausible future targets; it must shift first-level assignments and raise width-20 early-depth survival enough to produce Stage3 test_R@10 > 0.065. Keep only if paired seed/protocol runs improve test_R@10 and canonical-pair depth-1/2 survival versus both controls, without T4 NLL becoming the source of apparent gains.
RISKS: Successor entropy may reflect sparse-tail noise or item frequency, and entropy-to-radius can make popular broad-branch items collapse into overloaded anchors. Radius scale can dominate reconstruction; assess entropy shrinkage and ensure exact same behavior graph in controls.
BEHAVIOR SIGNAL: Per-item entropy of the directed next-item successor distribution.
BEHAVIOR COMPUTATION: From training split only, count consecutive target transitions within each user's training sequence; smooth each source's outgoing counts with alpha=1 over its observed successor support (or fixed train item universe with explicit sparse representation), normalize, and compute entropy. Items without outgoing edges receive the training-global median entropy. No valid/test rows.
LEAKAGE BOUNDARY: Build and serialize the radius lookup solely from the frozen training sequences before Stage 2; validation and test are not read by graph construction, assignment, hyperparameter selection, or SID export.
HYPERBOLIC OPERATOR: Poincare-ball exp map and squared geodesic distance d_c^2 at fixed negative curvature -c, plus geodesic-radius shell penalty.
HYPERBOLIC LOCATION: First-level codeword assignment and its selected-distance gradient during Stage 2 quantization.
COUPLING PATH: Training-only outgoing entropy -> target radius rho_i -> radius-shell term in each first-level Poincare assignment cost -> changed hard prefix token and gradient.
COUPLING EQUATION: a_i=argmin_k { d_{P_c}(exp_0(z_i),exp_0(e_k))^2 + lambda_r [||exp_0(e_k)||-rho(H_i)]^2 }; both H_i and P_c distance occur inside the assignment that produces SID token 1.
OBSERVABLES: On canonical 52,855 train/valid anchor-target pairs with ten fixed negatives, report L1 Hard ER and width-20 gold-prefix survival at depths 1,2,3,4; report teacher-forced T4 NLL and Stage3 test_R@10. Both-on predicts more useful shared L1 groups and higher depth-1/2 survival; L1 ER may decrease relative to 256-way systems due to 32-way capacity, but must be reported, not optimized as a standalone target. T4 NLL should remain approximately baseline and T4 must not absorb target discrimination. Target test_R@10 > 0.065.
ABLATION BEHAVIOR OFF: Replace rho(H_i) with a single training-set constant median rho for every item, holding curvature, K1=32, seed and all other hyperparameters fixed. Predict assignments and depth survival change; useful behavior-conditioned grouping is absent.
ABLATION GEOMETRY OFF: Replace exp/log maps and d_P with identity and squared Euclidean distance; retain the same behavior-derived rho and Euclidean norm shell penalty, same K1=32. This isolates whether curved distance changes assignments rather than removing behavior too.
ABLATION BOTH ON: Use per-item training entropy radii and Poincare distance/shell penalty together, K1=32, same frozen 3000-epoch protocol; compare all listed observables against both single-off arms.
SPEC EQUATIONS: Build n_ij from train-only consecutive transitions; q_ij=(n_ij+1)/(sum_j n_ij+M_i); H_i=-sum q_ij log q_ij; rho_i=clip(rho_min+(rho_max-rho_min)H_i/log(max(2,M_i)),rho_min,rho_max). For Poincare ball B_c, exp_0(v)=tanh(sqrt(c)||v||)v/(sqrt(c)||v||); d_c(x,y)=2/sqrt(c)*atanh(sqrt(c)||(-x)oplus_c y||). C_ik=d_c(exp_0(z_i),exp_0(e_k))^2+lambda_r(||exp_0(e_k)||-rho_i)^2; a_i=argmin_k C_ik; use straight-through selected code and existing residual quantization. Radius term is retained in Euclidean control as lambda_r(||e_k||-rho_i)^2.
SPEC INPUTS OUTPUTS: Inputs are Stage1 item vectors, train-only transition counts/entropy, K1=32 trainable first-level code vectors, fixed curvature c>0 and lambda_r; output is first SID token a_i and its selected quantized vector passed to subsequent residual levels.
SAFEGUARDS: Compute distances in float32; clamp ball norms to (1-epsilon)/sqrt(c), atanh arguments to [-1+epsilon,1-epsilon], protect zero norms in exp/log maps, clamp entropy denominators and use alpha smoothing, clip rho below the ball boundary, normalize shell penalty scale against median d^2, and log assignment occupancy/dead codes. No validation/test-derived statistics.
END IDEA

IDEA: successor_geodesic_transport
TITLE: Train-only successor barycentres steer a hyperbolic coarse partition
MOTIVATION: The next-item recommender benefits when an anchor and its likely next items can be retrieved through a small number of high-probability prefixes, even when their frozen content embeddings are not close; explicitly warp coarse codeword positions toward observed successor futures while retaining a small first alphabet.
NOVELTY: This uses a directed transition barycentre as a per-item target in a geodesic transport term that updates first-level codewords and assignments jointly. It is not behavior-conditioned soft assignment weights, graph-neighbour sampling, codeword margin, or an extra independent transition objective: the geodesic term is inside the same argmin cost used to emit the prefix.
CHANGE: Create a fixed, training-only successor barycentre for each item in the tangent space at the Poincare origin, map it into the ball, and select the first token by reconstruction geodesic distance plus a directed geodesic-to-successor-barycentre cost. Use K1=32; keep T2/T3 as the main within-prefix discrimination and T4 constant collision extension.
SPECIFICATION: Let u_i=exp_0(W x_i) be the learned first-layer item representation in B_c and let m_i=sum_j q_ij log_0(v_j), where v_j=exp_0(W x_j), q_ij are smoothed train-only outgoing transition probabilities; define s_i=exp_0(gamma m_i). For candidate first codeword p_k=exp_0(e_k), choose a_i=argmin_k d_c(u_i,p_k)^2 + lambda_t*d_c(p_k,s_i)^2. Train W/e jointly with RQ-VAE reconstruction and commitment losses using straight-through quantization. The second term transports a codeword toward the item's likely successor direction in the curved space, directly altering first token selection.
COST: Precompute q and sparse tangent barycentres once, O(E*d), where E is observed training transitions. Per item/step, evaluate K1=32 geodesic pairs for reconstruction and K1 for transport, O(B*32*d), approximately up to 2x first-level distance work; no per-batch graph traversal and no dense 24,556^2 matrix. Frozen workload is 24 steps/epoch and 3000 epochs (73,668,000 item-visits); additional cached barycentre storage O(N*d), under 25k vectors. Four cards.
HYPOTHESIS: Directed successors contain useful information absent from item-vector proximity, and geodesically transporting coarse prototypes will keep likely anchor-target paths in the beam while leaving finer levels to distinguish alternatives. Worth keeping only if both-on raises width-20 depth-1/2 survival and Stage3 test_R@10 exceeds 0.065, while T4 NLL stays flat and gains are not just due to L1 frequency skew.
RISKS: Deterministic successor barycentres can blur multi-modal futures; transition direction may not be representable by one prototype per source, and popular successors can attract too many anchors. Use temperature/smoothing and cap q support, inspect occupancy and branch-stratified survival.
BEHAVIOR SIGNAL: Directed next-item transition distribution q(j|i) across items.
BEHAVIOR COMPUTATION: Count each adjacent pair of target items in each user's training sequence only; row-normalize with additive alpha smoothing on observed edges and retain at most 64 largest training successors per source, renormalizing. Derive m_i from those weights and the frozen Stage1 vectors transformed by W. Missing rows use zero tangent barycentre. Train sequences only.
LEAKAGE BOUNDARY: Transition counts, support truncation, and any default values are computed from training split before Stage 2 and frozen; no validation/test interactions or metrics enter barycentres, SID assignments, training, or selection.
HYPERBOLIC OPERATOR: Poincare exp_0/log_0 maps and geodesic distance d_c on curvature -c<0; the explicit geodesic transport cost is d_c(p_k,s_i)^2.
HYPERBOLIC LOCATION: First-level coarse codebook assignment cost during Stage 2, with gradients flowing to the representation and codewords through the selected geodesic cost.
COUPLING PATH: Training-only directed q(j|i) weights -> tangent successor barycentre m_i -> curved target s_i -> geodesic transport term added to first-level codeword argmin -> emitted first SID token.
COUPLING EQUATION: a_i=argmin_k [ d_{P_c}(u_i,p_k)^2 + lambda_t*d_{P_c}(p_k, exp_0(sum_j q_train(j|i) log_0(v_j)))^2 ]; removing q changes s_i, while removing P_c changes both distances/maps in this exact assignment.
OBSERVABLES: Evaluate L1 Hard ER on canonical 52,855 pairs with ten fixed negatives, width-20 gold-prefix survival at each depth 1-4, teacher-forced T4 NLL, and Stage3 test_R@10. Predict stronger depth-1/2 survival from directed futures; L1 ER can fall as a consequence of compact 32-way grouping and is not a success criterion alone. T2/T3 should retain discrimination; T4 NLL should remain near baseline. Stage3 test_R@10 target is >0.065.
ABLATION BEHAVIOR OFF: Set q(j|i) to a shared uniform distribution over training items (so all source barycentres are the same) while retaining the exact curved transport and reconstruction terms, K1=32, and training budget. This removes source-specific transition information.
ABLATION GEOMETRY OFF: Use identity maps and Euclidean squared norms for reconstruction and transport, with the same train-only q, same W/e initialization, K1=32, lambda_t and training budget; this tests whether curved transport contributes beyond the behavior signal.
ABLATION BOTH ON: Use sparse q_train successor barycentres and Poincare exp/log/geodesic transport jointly in first-level assignments; freeze all other protocol details. Compare both-off-factor arms via behavior-off and Euclidean controls.
SPEC EQUATIONS: q_ij=(n_ij+alpha)/sum_l(n_il+alpha) over retained train successors; v_j=exp^c_0(Wx_j); m_i=sum_j q_ij log^c_0(v_j); s_i=exp^c_0(gamma*m_i); u_i=exp^c_0(Wx_i); p_k=exp^c_0(e_k); C_ik=d_c(u_i,p_k)^2+lambda_t*d_c(p_k,s_i)^2; a_i=argmin_{k=1..32} C_ik. Apply straight-through quantization for subsequent residual levels, with K2=K3=256 and T4 fixed collision extension.
SPEC INPUTS OUTPUTS: Inputs are frozen Stage1 item vectors x_i, sparse training transition counts n_ij, first-level map W, 32 trainable code vectors e_k, curvature c and lambda_t. Outputs are coarse token a_i and selected code vector p_a fed to ordinary T2/T3 residual quantization and deterministic T4 extension.
SAFEGUARDS: Use float32 manifold arithmetic; stable log/exp maps with zero-norm limits; clamp norms inside radius (1-epsilon)/sqrt(c), clamp atanh inputs, sparsify/cap and smooth transition rows, use zero barycentre for no-successor rows, gradient-clip W/codewords, warm lambda_t from zero over first 10% epochs, monitor per-token occupancy and T4 NLL. Never construct a dense item-item matrix.
END IDEA
