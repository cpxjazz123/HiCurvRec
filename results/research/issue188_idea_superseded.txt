Idea：RCS——按商品曲率的**径向一致性**损失（商品位置与其被分配码的半径对齐；非成对、两块都有梯度）
英文名称：RCS — Radial Consistency under the Item's Measured Curvature

两条硬约束（已被实测钉死，不得再违反）：

1. **禁止成对/对比**：边采样、三元组、margin、InfoNCE、BCE、源-目标残差一律不做。
2. **两项分布的损失必须同时给 `encoder` 与 `codebooks` 非零结构梯度**，否则仓库冻结的 λ 预算规则（`λ*=min_blocks‖g_base‖/‖g_struct‖`，任一 block 梯度为 0 即退化）必然拒绝训练。
   RAD 的死因正是窗口 1：半径只由位置决定 ⇒ 码本侧梯度恒 0。

推论：新项必须**同时引用商品位置与被分配码的位置**（各自走一条梯度），且曲率要显式出现在几何量里。

## 二、主张（一句话）

要求每件商品到原点的**径向双曲距离**（用它自己的曲率 κ_i 度量）与它被分配到的**码**到原点、同一曲率下的径向距离一致：
结构（实测 κ_i）→ 显式双曲运算（按 κ_i 的径向测地距离）→ 码与商品在球里占同一层"壳" → 选码 → SID。

## 三、公式（唯一改动）

```
κ_i    = 冻结 AF3 表 results/research/issue167/kappa.json（均值 1.0、中位 0.9147、max 8.2671；缺失 31 项按 mean_frozen）
pos_i  = 商品量化位置（E16 欧氏块 + H16 双曲块，与 TIGER_struct_mixed_rq 的 _positions 同口径）
c_{k(i)} = 一级 Sinkhorn 赋值（argmax，detach 索引）对应的**码向量**（含梯度，来自码本参数）
ρ_κ(x) = d_κ(0,x) = (2/√κ)·atanh( √κ·‖x_ε‖ )，   ‖x_ε‖ = sqrt(‖x‖² + finfo(dtype).eps)，并在 atanh 前取 min(·, 1−1e-6)
L_rcs  = mean_i [ ρ_{κ_i}(pos_i) − ρ_{κ_i}(c_{k(i)}) ]²  /  ( mean_i ρ_{κ_i}(pos_i) )²      # 无量纲
L_total= L_base + λ·L_rcs
λ      = 仓库既有冻结预算规则（初始化时一次，之后冻死；无 ε、无回退；退化即不训练）
```

- **两条梯度**：`pos_i` → 编码器；`c_{k(i)}` → 码本。二者都不为 0（残差非零），故预算规则可定义。
- **不是成对项**：每件商品只与**它自己的码**比较，不采样边、不采样负样本、无 margin、无 InfoNCE/BCE。
- **不改分配**：Sinkhorn（ε=0.003、50 sweeps、centring）、码本 K=256、三级递推、读出与导出全不动；κ_i 只出现在损失内的径向量里。
- **无新增可调常数**：`L_rcs` 无量纲；曲率来自实测表；λ 来自冻结规则。

## 四、开关（存在且接线正确，**不训练关闭臂**）

- `TERM_OFF`：`L_rcs ≡ 0` → **必须与冻结基线逐位一致**（每步 loss、码分配、导出 SID）。
- `GEOMETRY_OFF`：`ρ` 改为欧氏范数 `‖x‖`（同式，但量不是双曲径向距离）。
- `BOTH_ON`：出厂（κ_i 下的双曲径向一致性）。

## 五、验收（派发前，全部可测）

1. **`TERM_OFF` 逐位一致**（对冻结基线）。
2. **`ρ_κ` 性质**：`κ=1` 与冻结 `poincare_contract` 的径向距离一致（rtol 1e-6）；`x=0 ⇒ 0`；`‖x‖→1` 时有限（atanh 钳位生效）且梯度有限；`κ∈{1e-6,1e-3,0.1,1,8.2671}` 全部有限。
3. **两块梯度非零**：机器断言 `‖g_encoder‖>0` 且 `‖g_codebook‖>0`（这正是 RAD 的失败点，必须先测）。
4. **λ 预算**：`λ*` 与各 block 的 base/struct 梯度范数落盘；退化即拒绝训练，**不得**改规则或加 ε。
5. **无量纲性**：整体尺度重参数化下 `L_rcs` 行为符合定义；实际数量级落盘。
6. **无成对/对比残留**：机器断言不含边采样、三元组、`margin`、`InfoNCE`、`BCE`、源-目标残差。
7. **gradcheck**（双精度）；DDP 一 epoch 真实入口冒烟：损失有限、`L_rcs` 分位数与 `λ` 落盘、导出 SID 有效。
8. **导出统计**：全量 24587，逐层码数/最大份额（≤10%）、二级前缀、三级碰撞（并列 0.162444）、§63 `l3_collision`；`collision < 0.40`。
9. **TDD**：先写失败测试（退化逐位一致、ρ 性质与钳位、两块梯度非零、λ 退化拒绝），确认红后再实现。

## 六、边界与不变项

- 起点：冻结基线 `stage2_RQ-VAE/TIGER_mixed_rq`（只读、逐文件 SHA 记 manifest）→ 新树 `stage2_RQ-VAE/TIGER_rcs_rq`
  （`ARM_NAME="TIGER_rcs_rq"`、`ARM_VARIANT="RCS"`）。
- 分配规则、码本、预算、导出、E16×H16 装配一律不动；树内无绝对路径；`/tmp` 不落产物。
- 一个候选只跑一次正式训练（§19g）：seed 42、3000 epoch、全局 batch 4096、四卡 50202。
- 判据唯一：`test_R@10`；参照 0.05622 / 0.057905 / 成功线 0.065。
- 若本臂仍 ≤ 基线：在当前禁止项下"结构 → 几何 → 选码"已无带正证据的杠杆（允许类最好为 LKC 的 +0.3%，唯一 +3.0% 属禁止的成对项），应据实记录并交由 owner 决策，而不是再换一个标量。
